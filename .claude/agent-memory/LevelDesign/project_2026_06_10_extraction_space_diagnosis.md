유저 판정 "구성이 잘못됐다, 익스트랙션 같지 않다, 쫄깃함 0"에 대한 레벨/공간 진단 (구현 없이 분석만). Fable 직접.

**진단 한 줄**: 현재 맵은 익스트랙션 공간이 아니라 "전투 아레나"다. 익스트랙션 긴장은 적의 수가 아니라 *공간 비대칭(깊이↔부↔위험, 들어온 길↔나갈 길)*에서 나오는데 그게 0. 트레드밀 스포너가 남은 공간 정보(어디가 위험)마저 균질화.

**"전진 압력 0·위치 결정 무의미" 책임 분해**: 공간 균질 ~55% (스포너 고쳐도 안 풀림 — 맵에 의미 없으면 어떤 스폰도 무의미) / 트레드밀 스포너 ~35% (코드 확인: ZombieSpawner가 min/max 15~25를 반경 20~35m에 항상 유지, despawn 60m, backfill 0.3s = 폐기 결정난 추종 트레드밀이 씬에서 아직 돌고 있음) / 탈출1개·자동수집 ~10%.

**익스트랙션 공간 문법 5개 (레퍼런스 원리)**: ①리스크 그라디언트=깊이=부=위험 한 축(Tarkov/ZS) ②POI 구조=부는 장소에 응축, 풍경에 안 뿌림(루팅=머무름=등 뒤 열림) ③진입≠탈출 비대칭, 복수 조건부 출구(Tarkov/Lethal) ④회랑vs개방지=공간이 교전규모 정함(Hunt 사운드지형, 우리 소리사다리의 무대) ⑤익스트랙션 지점=출입 자체가 연출된 취약구간(헬기 묶임+수렴). **현재 5개 중 0개 구현, 타이머 하나가 유일 = "survive the timer 스크린세이버".**

**탑다운 58° 제약**: 수직 차폐 무력(3m건물=1.9m만 가림, 좀비키 4m) → 사각 주력=수평 차폐(L-코너·골목·통로 꺾임). 실내는 오클루전 마스킹 없으면 사각 안 생김 → "천장 없는 벽 구획"으로.

**strain 2층 분리 (★전제, 코어 §8 OPEN이라 제안)**: 벌크 strain=킬 드롭 자동수집 유지(뱀서 도파민) / 목표strain·고등급코어·이벤트보상=POI에 응축(공간 결정 만드는 부). 이 분리 없으면 문법 ①② 원천 차단.

**맵 구조 후보 3안**:
- A 시설 동심원(ZS섹터/Lethal): 외곽 인서션→중심 깊이=부=위험. 비용 중, 효과 최고, 익스트랙션 정체성 ◎. 익스트랙션을 핵심 반대편 외곽에 둬 왕복복도화 방지.
- B 허브&스포크 POI(Tarkov다거점): 독립 POI 3~4개+회랑+조건부 출구. 재플레이성 1위, 비용 중~상, 솔로 MVP엔 과부하 → 정식출시용.
- C 단일 POI 침투-탈출(Lethal 시설한채): 입구(좁음)→내부(개방·부)→목표방(막다른끝·최고부+엘리트), 깨어난 복귀경로가 클라이맥스. 비용 하~중, 데모/랩 친화 ◎, 전투질감 §7 랩정신과 직결.
- **★권고: C로 데모 검증 → A로 확장(A=C를 동심원 반복). B는 정식출시용.**

**한 런 공간 페이싱 곡선(C 기준, 톱니파)**: ①인서션(외곽,정찰,낮음) ②침투(회랑,소리사다리 첫결정,고조) ③루팅묶임(목표방=막다른끝, 한자리 묶임=등뒤 열림, 첫피크+호드수렴) ④의도적 이완(클리어 직후 Relax 30~45s 무스폰+이벤트cull 밀도−40%, 풍경 비워짐=보상, 타이머는 가지만 밀도 비움=시간≠밀도 분리) ⑤복귀 각성(들어온길 되짚기, Dormant였던게 총성에 다 깨어 Chase중=같은 공간이 달라짐, 런 최고점) ⑥탈출연출(헬기 15~20s 묶임+수렴, 마커밟기 아님). **⑤가 "왔다가 되돌아가는 가짜보상"(재미진단 병폐)을 차단 — 깨어난 길은 같은 좌표 다른 게임.**

**핵심 전제 3개 (유저 yes/no 대기, Gameplay 구현 전 동결)**: ①strain 2층 분리 ②인서션≠익스트랙션 ③트레드밀→배치형 전환(코어 §4.1, 문서상 폐기났으나 씬 미반영, Gameplay 구현영역+디렉터 통합).

**How to apply**: 맵/스폰/페이싱 작업 시 이 5문법으로 점검. 어느 안이든 strain 2층분리+인서션≠익스트랙션이 공통전제(없으면 셋 다 아레나로 회귀). 유저가 안 택1+전제 yes/no 하면 → Greybox 씬에 관문벽·POI·인서션/익스트랙션 마커 손배치 + 배치좀비 마커 + POI 인카운터 SO초안 author → Gameplay에 디렉터·POI트리거·조건부익스트랙션 핸드오프.
