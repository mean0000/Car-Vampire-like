맵 아키텍처 방향 설계 세션. 문서=`docs/02_logs/2026-06-13-map-architecture-proposal.md` (제안 초안, 유저+오케 판정 대기). Fable 직접 D존.

**A vs B 판정 (오케 원안과 갈린 지점)**: 오케 잠정결론="A(큰 맵 구역분할) 먼저, 모듈식으로 B 싸지게". 내 판정=**세로축(A=런 내부 호) 먼저는 동의, 단 첫 삽 크기에서 반박**. 큰 맵 구역분할이 아니라 **단일 침투-탈출 시설 한 채(내 이전 진단의 C안)**부터.
**Why**: ①솔로 스코프—큰 맵=구역3~5×손배치+이음새+전이, 시설 한 채는 같은 페이싱곡선을 1/3규모로 검증(킬도파민랩 ~10.5h 추산 근거) ②미증명 루프 4번 "아니다"—작게 지어 빨리 5번째 판정(나침반§1 스켈레톤 단위) ③모듈성으로 큰 맵 공짜—시설을 모듈청크(인서션/회랑/루팅방/탈출)로 지으면 큰 맵=동심원 반복, 바이옴=키트스왑. **오케의 "모듈식으로 B 싸지게"와 같은 의도, 단 큰 맵 쪼개기가 아니라 작은 맵 쌓기로 모듈 획득.**
**용어 정렬 핵심**: 오케 "A"=세로축 갖는다는 결정(맞다), 내 진단 "A/B/C"=세로축 *모양* 선택(동심원/허브스포크/단일POI). 둘은 충돌 아님—같은 산 다른 절단. 둘 다 "세로축 먼저", 차이는 첫 삽 크기뿐.

**뱀서밀도 vs 익스트랙션 공간성 해소**: "둘 중 택1"이 아니라 **공간 리듬으로 교대**. 회랑(좁음)=익스트랙션 비트(코너피킹·한발의식), 광장(넓음)=뱀서 비트(시차쇄도·연사). 한 시설 안 교대=장르다이얼(나침반§4.2)의 물리 구현. 평지 아레나 실패=전 구간 광장이라 익스트랙션 담을 닫힌 공간 0.

**첫 맵 구체안 "통제구역 한 채"**: 선형 침투(+복귀 각성으로 비선형화). 5구역 Z0인서션(24×20 개방·정찰)→Z1회랑(4~4.5m·L코너·익스트랙션 본진)→Z2중정광장(14~16m·호드 시차쇄도·뱀서 도입)→Z3목표방(18~24m·막다른끝·최고부+LV4엘리트·첫피크)→Z4탈출(진입≠탈출 별도좌표). 전체 ~120×80m(큰 맵 1/3).
**복귀 각성**=재미진단 병폐("왔다가 되돌아가는 가짜보상") 차단—들어올 때 Dormant가 총성에 다 깨어 Chase, 같은 좌표 다른 게임, 런 최고점. 선형 1축이라 이 대비 가장 선명.
**LV 배치**: Z0 LV1산발(Lacercharias)/Z1 LV1떼+Venodonte 산성조준탄(정지사격 대가)/Z2 Caniathrox 사냥개+Kupolojuve 비행/Z3 Fulgurodonte 램돌진(벽그로기)+호위 Venosaur/Z4 Crustaspikan 유생 디제틱예고(보스본체는 큰맵 예약). 가족3계보 유생만 배치=당김엔진.

**판정포인트 7개 (P1 가장 중요)**: P1 첫삽크기(권고=단일시설 b) / P2 깊이=선형침투 / P3 바이옴=폐허도시 / P4 구역수=5 / P5 추출=별도출구Z4(솔로상 Z3측면 봉인셔터로 시작) / P6 유생 디제틱예고 넣음 / P7 사전배치80%+디렉터20%.

**스코프**: 그레이박스 정적씬 ~4일(솔로). 자르기=Z4완전독립경로→봉인셔터, LV5보스본체→유생예고만, 비상탈출 보전율→경제스켈레톤 차례. ★측정 의존: 교전질감 *측정*은 게이트0(인식3상태·피격사다리·히트스탑) Gameplay 구현 의존—그 전엔 "공간 검증용 정적씬"까지만(공간이 의도대로 읽히나=캡처 검증 가능, 쫄깃한가=게이트0 후 플레이만).

**스폰/NavMesh 의도**: 디렉터=배치 깨우기+복귀보충(대량신규 아님). ★스태거 필수—Z2·Z3 호드 한 프레임 동시 깨우면 60agent 패스 스파이크, 0.3~0.5s 시차 발동(시차쇄도=쾌감 게임플레이와 일치). 구역전이=proximity, 폭격데드라인=time(공유클락 드리프트 방지 명시분리). 모듈 이음새 0.01u갭=#1버그, 초크3m NavMesh막힘, 가벽 비균일스케일 베이크오류 경고.

**How to apply**: P1~P7 동결되면 신규 ContainmentZone.unity에 모듈청크4+Z0~Z4 손배치→스폰마커→인카운터SO초안→NavMesh검증→Gameplay 핸드오프. [[2026-06-10 익스트랙션 공간 문법 진단]](풀맵 문법·후보ABC)과 [[2026-06-10 킬 도파민 랩 공간 설계]](L코너 수치)가 이 제안의 직접 전신—진단C가 여기서 "통제구역 한 채"로 구체화됨.
