ZombieCrush(현 "사후처리부") 주인공/캐릭터 아트를 **AI 3D 생성 + Mixamo 리깅(좀비·월드와 동일 3D 파이프라인)** 으로 레벨디자인 관점 권고. 2026-06-07 결정.

**Why:**
- 톱다운 고밀도 군중에서 2D 스프라이트는 평면이라 3D 좀비와 픽셀단위 깊이 교차 불가 → painter's algo(중심점 거리) 정렬뿐 → 무리에 묻히거나 항상 떠 보임. "내 캐릭터 위치 즉각 파악"이 둠클락 호드 게이트에서 생존 직결인데 이걸 깬다.
- 장르 레퍼런스(Vampire Survivors / 20 Minutes Till Dawn / Brotato) 전부 단일 충실도(2D 통일)로 정렬문제 회피. 혼합 충실도 쓴 레퍼런스가 없음 = 그 자체가 답. 가독성은 충실도 아닌 대비(크기/밝기/팔레트 분리)로 푼다.
- 좀비 60종 이미 3D 보유 → 3D 주인공이면 동일 라이팅·림 라이트로 실루엣 일관성 단일 레버 확보. 기존 "분위기=월드 / 가독성=액터(actor fresnel rim)" 처리를 주인공에도 그대로 적용 가능.

**How to apply:**
- 캐릭터 군중 가독성 = 모델 선택이 아니라 셰이딩 처리(액터 림 + 채도/명도 분리)로 푸는 별도 과제로 다룰 것.
- 2D 도트 주인공 재제안 금지(깊이정렬 영구부채 + 장르합의 위반).
