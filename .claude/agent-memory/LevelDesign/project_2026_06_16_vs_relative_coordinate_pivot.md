유저가 오케스트레이터의 Phase1 디테일 맵(균열↔탈출구 두 극 + 디제틱 발생원) 반려. **"뱀서류에선 그런 디테일한 맵은 옳지 않다."** 정확한 지적.

**핵심 교훈 (이전 메모리 갱신):** VS류 아레나에서 공간은 "장소"가 아니라 **플레이어 주변 매 프레임 생성되는 상대 좌표계**다. 시민을 건물문에서 내보내면 그 문이 고정점이 되고, 고정점이 생기면 플레이어가 끌려가 카이팅이 죽는다. **디테일 맵이 틀린 게 아니라 고정점 자체가 틀렸다.**

**Why:** VS류 = 열린 무특징 아레나 + 지오메트리 0 + 플레이어 기준 절차 스폰. 월드 고정점은 카이팅(=한 지점에 안 묶이고 떼를 끌고 도는 것)을 직접 죽인다.

**How to apply:** Phase1(또는 임의 뱀서 구간) 시민/오브젝트 배치 설계 시 **모든 것을 플레이어 상대 좌표로 재정의**. 월드 고정 발생원·고정 LZ·월드 핀 마커 전부 금지.

**이전 "이동 행렬=카이팅 트랙" 갱신 (★중요):** [[2026-06-10 킬 도파민 랩 공간 설계]]의 월드 기하 카이팅 트랙은 VS류엔 틀림. 무특징 아레나에선 **카이팅 트랙 = 적 밀도 그라디언트** (기하 아님). 플레이어는 저밀도(빈 곳)로 돌고 고밀도(떼)를 끌고 다닌다. 트랙은 매 순간 적 분포가 그린다 — 월드에 그어져 있지 않다.

**Phase1 시민 연출 최소안 (디테일 맵 0):**
1. **시민 출처** = 떠도는 무리(3~5명 1뭉치 = 실루엣 단위, 단독❌ 가독성). 좀비 디렉터의 화면밖 링 스폰 공유(role=CitizenCluster), 별도 시스템❌. 스폰 후 플레이어 반대 벡터로 표류(속도 < 플레이어 < 좀비), 능동 도주❌(규칙 "멋대로 안 샘").
2. **탈출구** = 고정 LZ❌. 무리가 화면 밖 가장자리 도달 = 상태전이(정산+디스폰). 플레이어는 따라갈 필요 없음, 무리 근처 좀비만 솎음(호위❌=압력 제거).
3. **카이팅 유지** = 시민 무리는 밀도 그라디언트에 역방향 인력 얹는 토큰(좀비 +방향, 시민 −방향). "무리를 위험에 안 빠뜨리려면 어디로 도느냐"가 카이팅 결정에 얹힘. 고정점 0.
4. **트리아지("모두 못 구함")** = 갈림길 없는 평원에선 **방위 대립**으로. 두 무리 반대 방위 동시 스폰 → 한 방향만 쏠 수 있어 둘 다 못 지킴 = 공간적 선택압. 긴급개입(넉백/실드 1회+쿨타임)이 "모두 못 구함"을 자원으로 명시.
5. **경고** = ★월드 핀❌(고정점 재발) → 화면 가장자리 방향 화살표 + 무리 위 위협 게이지. "어디 있다"가 아니라 "저쪽이 더 급하다"를 읽힘.

**NavMesh:** 평원은 함정 대폭 감소(이음새 갭/초크막힘/off-mesh링크 전부 소멸). ★권고: **NavMesh 버리고 단순 벡터 이동 검토** — 피할 기하 0이면 길찾기는 순수 오버헤드+떨림 소스. (Gameplay 판정 영역, 스펙에 플래그만.)

**톱 공간 함정 3:** ①경고를 월드 핀으로 그리면 고정점 재발=카이팅 사망(반드시 가장자리 방향 신호) ②시민 너무 많이 흘리면 좀비 위협 묻힘(동시 캡 2~3 짜게) ③무특징 평원에 NavMesh 습관적으로 깔고 떨림 디버깅 시간낭비.
