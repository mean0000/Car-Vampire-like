첫 스테이지 맵 = **탐색형 도심 구역** 설계 제안. 경로 = `docs/02_logs/2026-06-13-first-stage-district-design.md`. 산출물 = 설계 제안서(유저 판정 대기, 씬/코드 미수정).

**핵심 = 위상 전환**: 직전 산출물 [[project_2026_06_13_containment_build_spec]](`containment-zone-graybox-build-spec.md`)은 **선형 +Z 침투 시설**(Z0→Z4 일자). 본 문서는 그걸 **광장 중심 방사형 누비기 구역**으로 교체 제안 — 동심원 3띠(중앙 고노출·고보상 ↔ 외곽 저밀도·안전) + 비대칭 추출구 3종(X1 개방/X2 키/X3 플레어).

**Why:** ①유저 지시 = "도심 한 구역 *안을* Duckov처럼 누비고 탐색→추출". 선형 1축엔 누비기·추출구3종·동심원이 안 들어감 — 위상이 다름. ②유저가 직전에 임의 설계를 반려 → **이번 절대 규칙 = 모든 주요 설계에 외부 레퍼 출처 명시("← Duckov" 식), 감 설계 금지.** ③선형이 바로 그 반려 대상일 개연성 → 그래서 방사형이 정답일 가능성.

**계승(전투 동사 불변)**: 액션 돌파 앵커(처단·돌파·매복·대시) / 시야 콘=매복 발생기+전방 학살 / 공격 밀도 규율(직사≤4·곡사≤2·빔≤1) / 스태거 0.3~0.5s / 출현 문법 LV배치 / NavMesh 함정 / 키트 실선별. **공간 위상만 선형→방사 교체, 전투는 그대로.**

**레퍼 추적표 핵심(문서 §6)**: 방사 누비기·동심원·추출구3종·콘=Duckov / 줍는순간노출·다중경로=Zero Sievert / 무리압축=DRG:S+Megabonk / 광장이 적 규정+램 벽치기·방 점층=Hades II / 40-30-30·색대비·메모러블피처=craft 원론 / 평면반복금지=Death Must Die 반례. ★경계: **Duckov는 맵/추출 *구조*만 훔침, 전투는 안 훔침**(택티컬=좀보이드 회귀 금지).

**키트 실재 확인(Glob, 2026-06-13)**: 거리=BR `SM_Env_Road_*`(Straight/Damaged/Corner/T/Cross), 건물=BR `SM_Bld_SmallBuilding/House/Warehouse`, 구조/벽/바닥=Construction `SM_Bld_Concrete*`. 추출구 소품 실재=`SM_Wep_Pistol_Flare_01`(플레어)·`SM_Prop_Key_01/02/03`(키)·`SM_Env_Bridge_Broken_01`(고가 잔해=메모러블 피처)·`SM_Env_Port_Wall_*`·`SM_Env_Concrete_Base_01`(패드). PolygonGeneric=판타지 배제.

**판정 포인트(P0 가장 중요)**: P0=직전 선형이 반려된 게 *선형성*인가 *디테일*인가(선형성이면 본 방사 채택). P1 방사 전환(권고 예) / P3 추출구 3종→**2종(X1+X3) 먼저**, X2키 2차 / P4 중앙광장=선택(강제 아님, Duckov 위험 자가조절) / P5 LV4피크=Fulgurodonte 램 광장 벽치기.

**스코프**: 솔로 그레이박스 ~5일. 측정 의존=공간 가독성(누비기·동심원 노출·추출 비대칭·콘 매복사각)까지만 캡처 검증, 쫄깃함은 게이트0 전투감 후 플레이로만.

**How to apply:** P0~P7 동결되면 신규 `District_01.unity`에 동심원3띠+4갈래거리+중앙광장+고가잔해+추출구3종 손배치→스폰마커→인카운터SO→NavMesh V검증→Gameplay 핸드오프. 추출/전이=proximity, 작전타이머=별개 글로벌클락(드리프트 방지). ⚠️톤게이트 미통과 시 리스킨. ★어느 스펙이 사는지 헷갈림 주의: 선형(containment) vs 방사(district)는 P0이 가른다 — 둘 다 살아있는 게 아니라 택1.

**★상위 교체됨(2026-06-13 후반)**: 본 문서는 **방사 *고정 한 장*** 전제. 유저가 그 뒤 "고정 한 장 ❌ → 모듈 라이브러리+절차 조립" 확정 → [[project_2026_06_13_modular_assembly_design]](`modular-district-assembly-design.md`)이 공간 *만드는 방식*을 위상 교체 제안(매 런 다른 오픈 존). **단 본 문서의 동심원·추출구3종·고가 랜드마크·인카운터·키트·콘 매복은 "고정 좌표"→"조립 불변식"으로 재해석돼 전부 계승됨.** 새 P0 = 고정 한 장 vs 모듈 조립.
