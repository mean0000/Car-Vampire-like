2026-06-16 두 방향 전환 확정 + 맵 문법 동결.

**전환 1 — "황혼의 적막" 톤 폐기.** 더 이상 이 무드에 끼워맞추지 않는다. (메모리 [[city-design-direction]]의 "황혼의 적막" 항목, [[graphics_treatment_not_per_scene]]은 톤 네임 한정 폐기 — 그래픽=불변처리 원칙 자체는 유효.)

**전환 2 — 적 정체성: 나노좀비 → "해괴망측한 괴물"(바디호러/이형/그로테스크).** 살덩이 증식·돌연변이·끈적 분비물·잠식된 구조물이 풍경 자체가 되는 세계. (좀비 로스터 메모리들은 이 렌즈로 재해석 필요.)

**★동결된 맵 문법 (유저 동결):** **바닥(반복 타일=무드 베이스) + 흩뿌림 레이어(서사 프롭=한눈에 세계를 말함).** 도시를 *짓는* 게 아니라 땅 텍스처 1장에 프롭 몇 종을 회전·재배치로 무한 산포. 싸고·무한타일링·한눈 몰입.
**Why:** 솔로 개발 제작비 최소화 + 한눈 가독성. 무드를 라이팅이 아니라 *바닥+프롭*이 정한다.
**How to apply:** 새 맵 설계 시 ①바닥 타일 1종 ②흩뿌림 프롭 3~6종만 정의. 판단 한 줄 = "프롭만 보고 세계가 읽히나 + 그 프롭이 곧 싸울 지형인가."

**★우리 게임 보너스 제약 = 흩뿌림 프롭이 곧 전투 지형(차폐 3단위계).** 모든 프롭이 벽(하드/시야·탄 차단) / 하프월(중간/넘어보임) / 개활(킬존/차폐0) 중 하나를 생성해야 한다. (메모리 [[reference_competitor_research]] 차폐 3단위계와 정합.)

**컨셉 슬레이트 7종 (산출=이 대화 메시지):**
- C1 무너진 대로 — BR Damaged Road+Destroyed차량+Rubble. 제작비 0. ★1순위 첫맵(외곽/튜토)
- C2 검문 격리선 — BR군사+Construction 바리케이드. 1차 게이트
- C3 버려진 건설현장 — Construction 팩 통째. 중간
- C4 살덩이 둥지 ★바디호러 핵심 — 살점카펫 바닥+육질프롭6종. 보유에셋 0개=커스텀/구매. 보스전 클라이맥스
- C5 잠식된 거리 ★바디호러 전이 — C1+C4 혼합, 바닥 살점밀도=escalation게이지. 육질차량 소수 커스텀. 중간→중심 전이
- C6 고철 집하장 — ⚠Industrial PBR은 톤충돌 배제, BR/Construction 내 조달. C3 대체안
- C7 마른 평원 — Nature+Rocks+Destroyed. 평원(차 전용 최종)

**여정 배치 = 바디호러 점증 곡선:** 외곽 C1~C3(인간이 버린 폐허, 친숙) → C5(살점 번짐) → C4(만개, 보스) → C7(평원 탈출). 바닥 살점밀도가 진행도를 공간으로 말함 = 뱀서 escalation = 익스트랙션 긴장.

**★1순위 첫맵 = C1 무너진 대로.**
**Why:** ①제작비 0·즉시빌드(메모리 [[art_family_judgment]] BR 단일셰이더가족 검증)→재미검증 루프 최속 ②차폐3단위계 자연발생(전복차=벽/잔해=하프월/도로=개활) ③외곽=튜토 자리 정합 ④흩뿌림 문법 순수 증명(도로타일1+프롭5회전만으로 구역 성립). 현 병목=메커닉 재미지 그래픽 아님.
**How to apply:** 다음 산출 후보 = C1 그레이박스 빌드 스펙(바닥타일 사양+프롭5종 산포규칙+차폐등급별 밀도+스폰마커+모듈이음새 NavMesh체크). 바디호러 정체성 먼저 원하면 C4/C5 살점프롭 구매리서치부터. 어느쪽 먼저인지 유저 판정 대기.
