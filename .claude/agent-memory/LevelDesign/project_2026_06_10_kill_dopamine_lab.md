킬 도파민 스켈레톤의 공간 파트 (구현 금지, 설계만, Fable 직접 D존). 권위=docs/00_authority/2026-06-10-combat-texture-foundation.md (§2 인식·§5.2 탑다운 사각·§7 랩방법론).

**판타지 도입 비트(유저 확정)**: "모퉁이에서 적 발견, 적은 못 봄, 조용히 조준 후 탕" → 이후 그르렁 쇄도 연사 → 성장 → 산데비스탄 호드 클리어.

**핵심 통찰**: 선제발견 = 공간이 만드는 3비대칭. ①시야(화면20m>좀비12m·120°, 단 코너가 화면시야를 깎아 "거의 못볼뻔"을 만들어야 드라마) ②각도(좀비 원뿔이 진입축 빗겨야 미발견 — 공간이 facing을 디제틱 앵커로 정당화해야 "공짜 발견" 안됨) ③소리(권총25m가 다음방 깨움, 벽감쇠가 조절판). 탑다운58° 차폐=수평전용(§5.2), 코너 직각 동선으로 "서서히 드러남" 번역.

**L-코너 발견 비트 수치 (★권위 초안)**: 골목폭 4.0~4.5m(5m+ 시 대각노출로 드라마소멸) / 코너각 90°직각(둔각=일찍드러남) / 코너외벽 Concrete_Wall 3m+(좀비아닌 "코너너머 지면"을 시선차단 — h×0.62 무관, 시선경로 차단) / **발견거리밴드 8~11m**(좀비시야12m 살짝안=방금 들어옴, 권총25m 사정권) / 좀비facing 진입축에서 90~150°돌림(랩 첫코너=120°=반쯤위험 "들킬뻔") / 상태 Dormant. **facing 디제틱 앵커 필수**(시체/잔해·꺼진불빛Ember·벽모서리기댐) — 없으면 발견이 공짜.

**랩 = 선형 4방 (분기·복귀 없음, 익스트랙션 공간문법은 이 랩 이후 별도)**:
- A 복도 4×14m, 좀비1 Dormant(등돌림 완전안전). 교육="조용히=안깨움" 기준선.
- B L-코너 폭4m·90°·코너후10m, 좀비1 Dormant facing120°빗김+잔해앵커, 발견거리9m. 판타지 그 비트. 첫스파이크.
- C 소광장 12×12 개방+둘레엄폐물(Barrier_Long/PalletStack)3~4개 6m이격, 좀비5(Dormant2+Wander3). 트리거=B총성25m가 C를 Investigate로 깨움+그르렁8m 연쇄. 연사비트(시차쇄도=떼어내기보장). 둘레엄폐=등뒤 한면축소(360°포위=처벌 방지).
- D 밀집실 16×14 실내(ithappy Office_2 천장없는 벽구획, 내부2~3구획), 입구=폭3m 단일초크. 좀비12~16 Dormant응집(+디렉터Mob0~4 선택). 트리거=입구 proximity(시간아님, 랩은 진행속도변수 제거). 산데비스탄 클라이맥스. 직후 무스폰정적3~5s(여운).

**총원 19~23**(A1·B1·C5·D12~16). Dormant비율 앞방↑(주도권보장) 뒷방엔 Wander섞임(예측불가).

**도파민 곡선(톱니)**: A기준선→A/B골(음미)→B선제스파이크→C톱니속톱니(5마리 시차=킬마다 스파이크-회복)→C/D초크긴장상승(각오비트)→D클라이맥스→정적여운. C가 동시쇄도면 처벌, 시차여야 쾌감.

**카메라 합작 = 공간80%+카메라20%**: 직각코너+4m폭+벽 6m연장으로 "코너뒤 안보임" 대부분 공간이 풂. 단 좀비키4m라 벽(1.9m가림) 너머 좀비상체가 화면에 미리샐 위험. 카메라요구 3개: ①진입축 팔로우묶기(이미 커서오프셋 존재, 필수아님 마감용) ②벽 6m연장(순수공간) ③상체노출시 거리페이드(★줌/시야마스킹 비채택 — 익스트랙션 정찰성 깸). 랩1차검증은 공간만으로 가능.

**비용 ≈10.5h(솔로1.5일)**: 씬0.5+A0.5+B1.5+C1.5+D2+마커1.5+SO초안1+NavMesh검증1+캡처1. ⚠️모듈이음매 NavMesh갭(#1버그)·Office가벽 비균일스케일 베이크오류·초크3m NavMesh막힘 주의. **단 교전질감 측정은 §8 게이트0(인식3상태·피격사다리·히트스탑) Gameplay구현 의존** — 그전엔 "공간검증용 정적씬"까지만 산출 가능.
