2026-06-28 몬스터 공격 재설계 채점 루프(설계→채점→재작업, 린모드) 시작. 진입점 = `docs/01_handoffs/2026-06-28-monster-attack-redesign-grounding-handoff.md`(루브릭 §5·아키타입 §3·클립 인벤토리). 10종을 1~2종씩 끊어 채점. 내가 리드(공간/인카운터/페이싱), 점수 ≥8 게이트.

**Caniathrox v1 결과 = 불합격(가중평균 7.1/임계8.0). 바닥①⑤⑥=7/7/8 통과, 그러나 리드점수<8.**

**Caniathrox v2 결과 = 불합격이나 간발(가중8.53✅·바닥8/7/8✅·치명0✅·리드7.5❌ 단독으로 걸림).** v2가 v1의 빈 호드레이어를 대부분 메움(토큰2/팩·홀딩링5~7m·커밋데드라인0.5s·멀티런지분산·핸드오프0.3~0.4·스키드데칼+오버레이상단). 4대기준 재적용: ①해소(밴드 4.0~5.3=4.67센터링), ②부분(데드라인OK지만 "현각강행 or 토큰반납→홀딩"의 or 미정의=뱅뱅 문 열림), ③팩내부해소(예측점분산+착지라인별개+0.2s스태거)지만 **cross-pack 미처리(2팩×토큰2=4동시런지 무조정)**, ④명시는됨이나 평탄상수(파동레버 선언無). **리드7.5의 단일 결정요인=cross-pack 동시런지 상한 미정의 — 이건 폴리시아니라 내가소유한 인카운터결정(max-simultaneous-alive)을 런타임에 떠넘긴 것이라 양보불가.** 라운드3 펀치리스트(재설계❌, 3줄): (1)현각강행=기본·토큰반납은 플레이어 밴드완전이탈시만 (2)동시런지≤2를 *플레이어타깃 단위* 글로벌아비터로(팩무관)=리드 가르는핵심 (3)토큰수·핸드오프=디렉터 파동레버로 선언. +보조: 런지=커밋시 리드점회전후 고정RM직진(위치스크럽 봉쇄, ①⑥잔존 동시해소). 1·2닫히면 ④⑤→8, 리드→8 합격.

**핵심 = 마이크로 공격 타이밍(②속도감·⑥애니헌법)은 클립-그라운디드로 잘 나오는데, 내 렌즈 본체인 "호드 공간 레이어"가 비어서 떨어진다.** 1v1 스펙은 통과수준, 호드 스펙이 미완.

**리드 채점 시 매번 점검할 4대 공간 판정 기준(전 근접종 재발):**
1. **고정 루트모션 이동거리 vs 트리거 밴드 불일치** — 클립 이동(예: JumpLunge 4.67m)은 고정인데 발동 밴드(2.5~6m)가 넓으면 밴드 양끝서 오버슈트(뒤로 착지=팩 산개·왔다갔다 재발)/언더슈트(앞서 멈춤). 텔레그래프가 *공정성*은 살려도 *위협 일관성*은 깸. → 밴드를 이동거리±좁게 or 거리비례 발사속도(Animation 협의).
2. **token+팩 스티어링의 뱅뱅 경계** — attack-token=N + M마리 스폰 = 항상 (M-N)마리가 비공격 스티어링. 측면 스티어링은 멀뚱 방지 정답 도구지만 *경계 없으면 정반대(뱅뱅=바보AI)*로 읽힘. 필수 3종: ①스티어 최대시간→강제커밋 데드라인 ②비공격개체 홀딩패턴(공격링 *밖* standoff+플레이어 페이싱, 공격링 위 선회 금지) ③각도컷→반드시 공격 귀결. **재작업 1순위로 반복 등장 예상.**
3. **호드 다중-텔레그래프 수렴트랩** — 동시 공격 N개가 예측리드로 *같은 미래점*에 동일 레티클 → 개체 구분 정보 소실(한 대시로 다 회피=희석 or 다 명중=불공정). → 토큰 동시보유자 **예측점 오프셋 분산**.
4. **개체 공격 케이던스 = 페이싱의 진짜 변수** — 마이크로 윈드업/회수보다, "개체가 얼마나 자주 커밋하나 × token = 호드 위협 밀도곡선"이 페이싱을 정함. 스펙이 이걸 안 적으면 "끊임없는 리듬 vs 스파이크-소강" 판정 불가 → 리드 통과 불가.

**부수 재발 체크:** ▸그림자 블롭은 비행체(고도 read) device — Y-bake0 지상 유닛에 붙이면 오독(삭제, 지상 돌진=착지라인▬만). ▸4족 *주* 부감신호=제동 스키드(먼지/스크래치 끊김), 발밑 부채꼴은 surround/후방서 오클루전되니 스키드 필수. ▸회수창=경량종 0.25~0.35 적정(거구0.65~0.90 풀콤보창과 다름), 간지 처형은 회수길이 아니라 카타나적중→스태거 레이어가 전달(별도 저작). ▸트리거 proximity/time 명시(모호 금지, §검증게이트).
