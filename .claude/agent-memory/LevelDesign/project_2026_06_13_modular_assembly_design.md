첫 스테이지 맵 = **도심 모듈 라이브러리 + 절차 조립** 설계 제안(Phase 1, 설계만). 경로 = `docs/02_logs/2026-06-13-modular-district-assembly-design.md`. 산출물 = 설계 문서 1개(유저 판정 대기, 에디터/MCP 미사용·씬/프리팹/코드 미수정).

**핵심 = 또 한 번 위상 교체.** 위상 계보 = 선형 시설([[project_2026_06_13_containment_build_spec]]) → 방사 *고정 한 장*([[project_2026_06_13_district_design]]) → **방사 *모듈 조립*(본 문서)**. 셋 다 동심원·추출구3종·고가 랜드마크·인카운터·키트·콘 매복 공유 — 바뀐 건 *공간 만드는 방식*뿐.

**Why:** 유저가 `run_structure_pressure_engine` 맵구조 최종 확정에서 "고정 한 장 ❌ → 모듈 라이브러리 + 매 런 다른 절차 조립 = 매번 다른 오픈 존. 절차생성 ≠ 던전(오픈 존을 *조립*, Hades·Dead Cells·뱀서 솔로 증명)" 못박음. 직전 *고정* 방사 설계는 위상이 그것과 어긋남(매 런 동일). **단 바운디드 오픈 존·45°/15m·던전 금지·거대월드 금지는 잠긴 전제.**

**How to apply:** 직전 방사 설계의 동심원·추출구·랜드마크·인카운터·키트를 "고정 좌표"가 아니라 **"조립 규칙이 보장하는 불변식"으로 재해석**. 설계 산출 = ①모듈 12타입(코어광장M1/교차로M2/거리직선M3/코너T M4/외관건물M5/진입건물M6/골목M7/고가랜드마크M8/추출3 X1X2X3/봉쇄벽W) ②엣지 소켓 4종(ROAD/WALL/OPEN/ALLEY) 그리드 스냅(★10m 기준=Synty 도로 5/10/20 최소공배수) ③조립 7단계+불변식 6규칙(I1동심원·I2추출3비대칭·I3디제틱출처·I4랜드마크정위치·I5다중경로+데스트랩0·I6읽힘40/30/30) ④변주 4겹 매핑(레이아웃/내용/빌드/바이옴) + 키트 스왑 바이옴 재사용 ⑤레퍼 추적표 13행.

**★스코프 정직 경고(반드시 전달)**: "매 런 다른 오픈 존"은 공짜 아님 — 진짜 절차 조립기(엣지매칭·불변식·NavMesh 재베이크·시드 결정론)는 *중간 복잡도 Gameplay 시스템*. → **1차는 "수동 시드 3장" MVP로 시작 강력 권고**(절차의 재미 먼저 검증, Dead Cells 초기 패턴). 모듈 ~20변종+조립 ~6일(직전 고정 한 장 5일보다 +1일이나 바이옴 재사용으로 분할상환).
