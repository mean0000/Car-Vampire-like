**확정된 방향:**
- 장르: 뱀서라이크 (Vampire Survivors-like)
- 시점: 탑다운 쿼터뷰
- 플레이어: 자동차
- 이동: 관성이 느껴지되 답답하지 않게
- 플랫폼: Steam PC (확정 2026-05-19)
- 아트: B-Movie Grindhouse 스타일 유력
- 개발 형태: 1인 개발
- 목적: 실제 출시 (Steam) + 취업 포트폴리오 병행

**핵심 컨셉:** "뱀서라이크인데 플레이어가 자동차다"

**Why:** 뱀서 포화 시장에서 조작 레이어 변경으로 차별화. 자동차의 속도/드리프트/브레이크가 전술적 의미를 가짐.

**추가 확정 (2026-05-19):**
- 로드킬(충돌)이 주된 공격 수단 중 하나 — 핵심 루프에 포함
- 무기 역할: 충돌의 보조 (사전 딜, 사각 커버). 무기만으로 후반 돌파는 불가 방향
- 경험치 수집: 로드킬 즉시 지급 + 자동 흡입 반경(업그레이드 확장) 조합 유력
- 차별화 핵심: "뱀서라이크인데 조작 실력이 클리어 속도에 영향을 준다"

**미결 사항 (2026-05-19 기준):**
- 세션 길이 미결정
- 타겟 유저 미결정
- 차량 테마 시스템 미구체화
- 2D 스프라이트 vs 3D 탑다운 미결정

**How to apply:** 브레인스토밍 시 이미 확정된 것은 재논의 없이 전제로 삼을 것. 1인 개발 + 취업 포트폴리오 제약을 항상 고려해 현실적 스코프를 제안할 것.
