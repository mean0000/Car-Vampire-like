2026-06-13 gd 무기/성장 제안서 §15(런 밖 메타 경제)에 *디제틱+네이밍* 입힌 제안(`docs/03_reference/2026-06-13-meta-economy-diegetic-proposal.md`). 🟡 판정 대기. gd=구조, 나=이야기+어휘.

**★중심 서사 = "사내 매점 외상" (S1)**: 현금 쓰기 = 본사가 장비를 *떠안기고*(과잉공급 떡밥, 코어 §7) 그 값을 일당에서 *공제로 갚게*(비참) 함. **유저가 준 두 극(푼다 vs 공제)을 고르지 않고 *같은 행위*로 통합** — 이중 레지스터 엔진(§5.2)의 경제판. 현실 닻 = 특수청소+외주화에 *현물급여/사내강매/공제* 추가. ★못 갚는 외상 = 퇴사 엔딩 디제틱 엔진(강해질수록 보급↑=더 묶임 → 사직서가 잼). 단 "퇴사" 결말 전 金어 → 지금은 외상 무게만.

**★★성장의 디제틱 정체 = 三分 (S2, 가장 중요)**: 강해짐을 **나노봇 패치로 안 입힌다**(싱크=본사 제어채널이라 모든 파워가 본사 손목줄 = §2.3 무변론·§3 매개 역설 = 엘 싱크연동 붕괴의 주인공판). 대신 三分:
- ① **너의 무장** = 본사 장비 보급(authored, meta) — 몸이 아니라 *손에 든 게* 강해짐
- ② **너의 경력** = 처리 역량 인사 고과(경력직化, 나노봇 ❌) — 영구 패시브 = *인사기록이 두꺼워지는 것*(§3 회수)
- ③ **너의 동료** = 엘 *사비* 정비(관계, 싱크 비연동) — 패치되는 그릇 아니라 정비받는 동료
- (런 내) 현장 조달(draft) — 통제 밖
**분쇄기 앵커**(나침반 §3.3)를 *본사 제어채널 밖*에서 정당화: 네가 되는 '괴물'=나노봇 변종 아니라 *본사가 과잉무장시킨 숙련공*(더 차갑고 §3 정합).

**★결정적: 성장 三分은 싱크 독립 → gd Q20(드론 싱크 운명 A부활/B폐기)이 어디로 가도 성장 서사 안 흔들림.** 유저에게 Q20 판정 자유 돌려줌.

**★5대 사용처 = 세 소스 (한 소스 아님)**: 본사(①보급·⑤희귀·④보험) / 인사고과(②그리드) / 사비-지점(③엘). 이 분리가 엘 보호(S4)+나노봇 회피(S3) 동시 해소. *행위 3종*: 요청서 제출(본사) / 고과 반영(②) / 지점 자비 정비(③).

**네이밍(렉시콘 §5)**: ①현금=잔고/실수령(재사용,숫자만) ②메모리(재사용,4번고정) ③(선택)**갑호 회수물**(신규, K-등급 갑/을/병, 본사가 현금으로 안 푸는 정점). 사용처 공문: 보급자격상향/처리역량고과/보조시스템정비(지점자비)/산재보험등급/특수불출. ⚠️③엘 설비="엘 정비대"(본사 보급 단말과 분리, 입말 호칭=엘 not 드론).

**★최강 회수 2건**: 그리드↔인사기록 모티프(§3·§6, 영구 패시브=인사기록 두꺼워짐) · 보급↔과잉공급 떡밥(§7, "왜 챙겨주나"를 카피 아닌 *거래로 산다*).

**충돌 0건.** 미해결: 공제율 메커니즘 — (a)MVP 잔고 lump 소비(코드0, 상류출혈 버전) vs (b)리치 standing 공제율↑(E-002 필드 신설, 외상이 복리) → gd/오케 회부. 둘 다 디제틱 성립 보증.

**Why:** 유저가 "현금 쓰기=세계에서 뭔 이야기" + 성장 정체(나노봇/보급/엘) 별표 질문. 핵심 위험=성장을 싱크/나노봇에 묶으면 본사 손목줄化.

**How to apply:** 메타 경제/사무실 허브/성장 카피 작업 시 ①현금쓰기=외상 프레임 ②성장=三分(나노봇 패치 금지) ③엘 정비=사비/지점(본사 보급 어휘 금지, 싱크 비연동) ④그리드=경력/고과(나노봇 아님). 동결 시 렉시콘 §5.1+코어 §7 갱신, uiux(레이아웃)·Gameplay(결제 라벨) 인계.
