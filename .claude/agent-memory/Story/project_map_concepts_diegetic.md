2026-06-14 첫 바이옴(폐허 도심) 맵 4종에 디제틱 텍스처+명명 입힌 제안 (`docs/02_logs/2026-06-14-map-concepts-diegetic.md`). 🟡 판정 대기. LevelDesign이 공간/끌림 레이어 별도 파일로 병렬. 권위 경유 = 끌림 독트린(`00_authority/2026-06-14-natural-pull-doctrine.md`) + 렉시콘 §5.

**4종 = 끌림 §2.1 욕망 4축 1:1 분담 (의도된 다양성, 우연 아님):**
- ①입체교차로 = 솟은 거대 윤곽(엘리트 변이체) → "가장 인상적 윤곽". 맵명=「제2순환…상판 붕괴구간」, 배드로식=**「고가 잔무」**
- ②집하장 = 점멸 등주(★인공 비콘, 본사 거점) → "폐허 속 빛". 맵명=「제7보급거점—운영 중단」, 배드로식=**「집하 중단」**
- ③분화구 = 파인 구멍·빛기둥(지형/발원) → "오염 핵심 미스터리". 맵명=「발생원 미상 함몰지—격리 유지」, 배드로식=**「발원 격리」**(★폭로 떡밥 내장)
- ④분수광장 = 선회하는 떼(군집) → "빛나는 표적+적 뭉텅이". 맵명=「중앙광장—다중이용시설 집단발생」, 배드로식=**「광장 집회 해산」**(★인간 비애)

**★비콘 framing 규칙 (이 작업에서 확립)**: 비콘 디제틱 정체 = *미끼의 알리바이*다. "저 안에 뭐가 있나"+"저거 터뜨리고 싶다"를 정당화해야지 "할당량이 거기 있으니까"를 정당화하면 끌림 독트린 §2.3 위반(시스템 이유 금지, 지각·호기심만).

**★회수 가치 최강 2픽**: 「발원 격리」=본사가 발원을 "발생원 미상"으로 적는 거짓 → 첫 판독(§6.1) 후 맵 이름이 거짓말로 재의미화(축적 회수). 「광장 집회 해산」=과거(시민 집회)↔현재(군집 해산) 한 단어 겹침, 4종 중 인간 비애 최대.

**렉시콘 §5 신규 등록 제안 4건**: 운영 중단(거점 오염 완곡어) / 발생원 미상(본사가 자기 변이를 모른다 적는 행정 거짓, ★폭로 떡밥) / 다중이용시설·집단발생(K-방역 직수입) / 잔무(1차 후 미처리, K-직장 입말 겸용).

**캐넌 충돌 0건.** 주의 3건 적시: (가)집하장 보급등=현장 조달(draft)이지 메타 보급(허브 외상) 아님 — "보급료/요청서" 야드에 금지 ([[meta-economy-diegetic]]). (나)분화구 발원 "정체"를 카피로 설명 금지(무변론+완곡어 동시 위반) — 맵 카피는 끝까지 "발생원 미상" 고수, 발견은 메모리 판독으로만. (다)광장 비애=풍경+팀장 침묵으로만, 연출 해설 금지(신파/컷씬0).

**Why:** 맵 4종의 디제틱 텍스처·명명 양산 + 비콘이 "시스템 이유 아닌 욕망"으로 끌리게 framing.

**How to apply:** 후속 맵/비콘 카피 작업 시 ①비콘 정체=미끼 알리바이(할당량 framing 금지) ②집하장 보급등≠메타 보급 어휘 분리 ③발원=발생원 미상 끝까지(폭로는 판독만) ④광장 비애=풍경/침묵만. 동결 시 렉시콘 §5.1에 4어휘+공문 라벨 등재, uiux/Gameplay 인계.
