2026-06-13 유저 직접 지시("6무기 빌드 트리 다 설계 + ★우리 시대상에 맞춰야") → gd 메카닉 골격(Aspect식 가지) 위에 *시대상 옷* 입힌 제안(`docs/03_reference/2026-06-13-weapon-build-tree-diegetic-proposal.md`). 🟡 판정 대기. gd=메카닉/수치, 나=디제틱+어휘. 선행 무기 본체 문서 [[weapon-diegetic-naming]] v0.2 위에 *가지(트리) 층* 추가.

**★★Q1 = 이 문서 심장: 빌드 가지 = 디제틱하게 뭐냐 (유저: 모드/펌웨어/나노 vs 자격/숙련):**
- **나노 강화 = 금지(가장 중요 가드)**: 강해짐을 나노에 입히면 모든 파워가 본사 손목줄(싱크=제어채널 역설=제2조 무변론·제3조 매개). 엘 싱크연동 붕괴의 *주인공판*. → ★한줄: "강해지는 건 *너*가 아니라 *손에 든 것*. 가지는 몸(나노)에 안 들어감."
- **가지 = 두 디제틱 레이어의 곱** (gd 런내/런간 직역, [[skill-growth-diegetic-lens]] 동결 적용): ①**meta 가지(authored)="처리장비 개조 불출"** — 본사가 외장 모듈·펌웨어 사양 불출(몸엔 안 들어감=나노 회피), 과잉공급 떡밥 회수. 펌웨어 있음=본사것. ②**런 내 색깔(draft)="현장 조정/임기 조치"** — 통제 밖 즉흥, 펌웨어 없음=내것. 같은 가지가 *두 경로로* 손에 옴(보급/조달 2축의 가지판).
- **숙련은 버리는 게 아니라 *인사 고과*에 산다**(메타경제 三分 ②): 무기 가지=개조/조정(손에 든 것) ↔ 솜씨=처리역량 인사고과(경력, 나노❌, meta 그리드). 숙련을 무기 가지에 섞으면 三分 붕괴.

**★작업명 번역(산나비 원리, 톤붕괴 방지) — 유저 판정 가능 지점:**
- 칼: 카타나→**수입 절단구(정밀형)** / 대검(신규)→**중량 해체구/철거용 절단구(중량형)**. 둘 다 *산업 공구 사양*("사무라이 vs 버서커" 아님).
- 권총: 발도사격(거합도=디제틱 근거0)→**속사 정밀/단발 처형 사양**(작업명 폐기, 메카닉만 보존). 속사→연사 사양.
- 저격총: 차징관통→고관통 사양 / 연쇄→연속 처리 사양(★권총 속사와 안 겹치게 고배율 유지=gd 주의).
- 샷건: 풀블래스트/슬러그=실존 어휘라 번역부담 적음(공문만 광역산탄형/단발관통형).
- 주먹: ★공문 자체 없음(장비 미보유). 기술명 절대 금지(무장공백). 가지 거의 전부 *현장조정*쪽(맨손=불출 사양 0).

**★★Q4 엘 트리(사격 동기화/요격 칼) — 두 번째 심장:**
- 엘 트리 = "엘을 무기로 분화" ❌ → **"엘이 내 빈틈을 어느 쪽으로 메우나"의 동행 스타일 분기**. 두 가지 다 엘 성격키워드 "계속 살리려 함" 체화(사격=함께처리/요격=날지킴). 후반 강제패치 때 *함께 정비한 동행스타일째* 잃는 타격.
- ★**용어 충돌 발견(중요)**: "사격 **동기화**"의 동기화 = **싱크(본사 채널) 어휘와 정면 겹침**(렉시콘 §3 "동기화=복선"). 이대로면 "엘=본사 싱크 연동" 오독=가드① 위반. → **"협조 사격/호흡 맞추기"로 교정**, "동기화"는 본사-주인공 나노봇 채널 *전용*으로 보존. 엘=다른 단어여야 "본사 밖" 언어 증명.
- ★2가드 재확인([[weapon-diegetic-naming]]·[[skill-growth-diegetic-lens]]): ①엘 가지=싱크/본사보급에 안 묶음→*지점 자비 정비*(三分③, 싱크 비연동). ②엘 5단계=관계지 능력함 아님→*동행 스타일*이지 *엘 개조* 아님.

**발현색(색규약 정렬)**: 개조 사양(정규)=시안 / 화력도박·처형 스파이크(싱크태움)=마젠타 혼입 / ★엘 트리=엘 시그니처색(시안/마젠타 분리=드론 분리 가드). 정확한 색=art/오케 콜.

**충돌 0건.** 핵심 위험=①가지를 나노로 입힘(Q1 금지) ②엘 가지를 본사채널/패치에 묶음(Q4 해소).

**Why:** 유저가 가지(트리)별 시대상 정합을 별표 지시. gd가 메카닉(Aspect)은 잡았으나 *가지가 세계에서 뭔지*는 빈칸이었음. 핵심=나노 회피 + 두 층의 곱 + 엘 동기화 용어함정.
