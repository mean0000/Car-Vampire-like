**"반납·임차·반환" 어휘는 캐넌 금어다.** 본사 경제엔 *보급(불출)만 존재*하고 임차/반납 개념이 없다.

**Why:** 렉시콘 §5.1 E-002 정산서 볼트 판정(2026-06-12)에서 "사용료/임차료" 기각 — "캐넌에 임차/반납 개념 없음, '보급'만 존재"로 확정. 장비 비용은 "보급료"만.

**How to apply:**
- 무기/장비 비용 = "보급료" (임차료·사용료 금지)
- 본사가 보급 화기를 원격 제한/회수하는 후반 장치(직할 하드모드)는 "**불출 정지**" 또는 "**보급 자격 정지**"로 명명 — "반납/회수" 금지
- 새 장비·아이템 카피 쓸 때 이 금어 체크. GameDesign·UI에도 전파.
