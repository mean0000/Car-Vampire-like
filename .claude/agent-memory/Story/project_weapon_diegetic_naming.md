2026-06-13 무기 종류를 세계관에 맞게 확정하는 제안 문서(`docs/03_reference/2026-06-13-weapon-diegetic-naming-proposal.md`). GameDesign 무기 골격의 *서사/디제틱 정당화 + 네이밍* 층. **판정 대기.**

**v0.1 핵심(무기 정당화):**
- **정당화 2축 (Q1)**: ①본사 보급(펌웨어 있음=본사 제어 채널·추적가능·묶임) vs ②현장 조달(펌웨어 없음=장부 밖·자유). 시트 §3 시스템화. 무기 선택=본사와의 거리.
- **화기=방역/처리 장비 프레임 (Q2)**: 주인공 군인 아님 → 총을 "현장 처리 장비 P-#형"(P=Processing). 제3조 완곡어법을 무기 분류표까지.
- **화려 시그니처 액자 (Q3)**: 아키mbo=보급 *2식 불출* / 카타나=*수입 산업 절단구*(사무라이 0% 번역).

**★v0.2 (2026-06-13 유저 최종 로스터 + 엘 전장 현현):**
- **로스터 변경**: 라이플→**저격총**(공문 P-9형 원거리 정밀, 1발당 보급료 공제=조준의 무게), **몽둥이 폐기**, **주먹=무장공백 확정**(★무술가/격투가 아님, 도장·사부·기술명 금지. 화려해도 "맨몸으로 저걸" 비참 코미디. 입말=체념/자조).
- **★엘 전장 현현 캐넌 판정 = 충돌 아님, 오히려 회수**: 엘은 *이미* "소형 드론+UI 아바타"(바이블 §5-3 외형 확정)다. "드론=엘"은 신규 설정 아니라 기존 캐넌의 전투 시스템화. 엘 5단계 성장선이 전투 행동으로 체화.
- **★함정 2건(반드시 전파)**:
  1. **싱크 연동 금지**(Q7): 싱크=본사 제어 채널(렉시콘 §7). 엘 소환을 싱크로 묶으면 "본사가 엘을 먹인다"=엘이 본사 자산 됨 → 엘 정체성(본사 밖·낡음=방화벽) 역설. **별도 자원/쿨다운(구형 배터리·과열)** 권고. 후반 직할 때만 "보조 드론 출력 제한"(불출정지 드론판)으로 본사 손가락.
  2. **드론 분리 가드**(Q8): "엘 드론" ≠ "본사 보급 드론"(렉시콘 §7 기존). 섞으면 "엘=본사 감시견" 오독. **입말에서 엘은 "드론" 아니라 "엘"로 부름**(호칭=동료 표지). 코드/UI에서 두 드론 같은 클래스·라벨 금지.
- **정당화 3안(Q6, 택1)**: A 본사 하드웨어 탑승(엘 자유 훼손 위험)/**B 구형 지점 하드웨어=방화벽의 물리적 확장(권고)**/C 독자 홀로현현(싱크 역설 직결).
- **모드 전환(총/칼)**: 매끈한 변신 X → 구형 AI 임시 변통(칼 모드=§3.4 "보급 목록에 없습니다" 개그 물림).

**Why:** 유저가 6종 로스터 확정 + 드론=엘 현현이라는 서사-메카닉 대통합 추가. 핵심 위험=엘(본사 밖 존재)을 싱크/본사 드론에 묶으면 정체성 붕괴.

**How to apply:** 동결되면 렉시콘 §5.1 + 시트 §3 + **바이블 §5-3에 엘 전투 1줄** + GameDesign(엘 자원=싱크 비연동) + Gameplay/UI(드론 분리 클래스). 엘 관련 카피/메카닉 쓸 때 싱크 비연동·드론 분리 2가드 항상 체크.
