2026-06-12 시그니처 FX 확장 제안 작성. 권위 = `docs/03_reference/2026-06-12-signature-fx-expansion-proposal.md` (상태 🟡 유저 판정 대기, 동결 아님).

**핵심 발견 (진단):** 색 캐넌에서 **마젠타(붕괴) 축은 이미 풍부**(위상 잔상·싱크 글리치·규칙 폭로)한데 **시안(본사) 축은 시각적으로 거의 비어 있다**(보상 링 정도뿐). 본사의 시각 언어를 "차가운 시안 행정 그리드 + 무채색 양식"으로 정립하는 것이 지금 가장 큰 빈자리.

**Why:** 기존 3종 FX(처리 스냅샷=종결, 위상 잔상=위상 잔류, 싱크 글리치=연결 흔들림)는 전부 플레이어 쪽 현상. 세계/본사 쪽 시각 언어가 비어서 색 캐넌의 시안↔마젠타 대립이 한쪽만 채워져 있음.

**How to apply:** 향후 FX 논의 시 새 마젠타/글리치 효과를 더하기 전에 "시안(본사) 축에 회수할 빈자리가 먼저 있지 않은가"를 점검. strain 수확은 매 처리마다 일어나는데 FX 언어가 완전히 비어 있음 = 가장 큰 누락(후보 A 결정화=1순위).

**후보 5종 + 1FX=1단어:**
- A 결정화(Crystallize)=**응집** / strain 수확 / 시안or무채색 / 1순위
- B 판독 누설(Readout Bleed)=**열람** / 엘이 메모리 들여다봄 / 시안+마젠타 프린지 / ⚠️싱크 글리치와 마젠타 과포화 리스크
- C 소독 카운트다운=**소거** / 타이머·폭격 임박 / 시안 그리드→무채색 탈색(빨강 절대 금지, 폭격인데 빨강 없음=완곡어 공포)
- D 회수 마킹(Tagging)=**표식** / 메모리 보유 좀비 배경 림 / 시안 미세 / ★선결: 모든 좀비가 메모리 떨구나? 디렉터 확인 필요
- E 양식 정지(Form Lock)=**무응답** / 본사 직할 체제 / 무채색(색의 부재) / "FX를 빼는 연출"=무변론 룰의 시각화, 가장 우리다움·가장 쌈, 2순위

**가드레일:** 글리치=마젠타는 "연결이 흔들리는 서사적 순간"에만(핸드오프 §4). 단순 데미지 피드백 금지. A의 수확 FX는 의도적 미니멀 — 화려하면 톤(증거 인멸의 차가움) 죽고, 너무 조용하면 게임감 죽는 좁은 골목.
