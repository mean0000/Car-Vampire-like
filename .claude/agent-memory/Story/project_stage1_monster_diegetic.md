2026-06-14 폐허 도심 9종에 디제틱 정체성 입힌 제안 (`docs/02_logs/2026-06-14-stage1-monster-diegetic.md`). 🟡 **v0.2 판정 대기**. LevelDesign이 역할/인카운터 선별 병렬. 권위 경유=로스터분류·렉시콘 §1·§3·§5·끌림독트린. 권위 §3 "인간 변이 앵커" 단서 계승(덮어쓰기 ❌).

**★v0.2 변경 3건 (유저 승인 2 + 오케스트레이터 결정 1):**
1. **유생 디제틱 역전(승인)**: Crustaspikan 유생=말기 종착 ❌ → **"성체로 가는 소거 *진행 중*"**. 근거=실측상 유생 메시 직립+굵은앞팔 잔존(인간 흔적 O), 진짜 인간0=13.2m 성체. → "유생→성체" 성장 자체가 인간 소거 진행을 시연(축 B 강화). 연출 가드: 유생은 인간흔적 살려야(완전이형 ❌=성체와 구분 소멸).
2. **축 B 이중 경로(승인)**: 단일축(직립↔이형) ❌ → **경로①형태 소거(개체 보존, 몸 뭉개짐: Dimax→…→Crusta성체) / 경로②개체성 소거(군체화: Lacercharias 익명다수)**. 둘 다 인간 소거의 다른 길(형태 지움 vs 이름 지움). 저자세 fodder 위치 모호 해소.
3. **★코어 비콘 재배치(오케스트레이터 결정, 실측)**: Fulgurodonte=거대 거미/절지(직립 ❌)라 직립 비콘 윤곽 불가 → **코어 비콘=성체 Crustaspikan(13.2m 직립 타이탄)에 이관**. Fulgurodonte=비콘 없는 LV4 거대거미 램 엘리트로 유지. "기사님" 통칭=살림(거미라도 "한때 몰던 양반" 자조 성립, 오히려 추락 자조로 톤 강화)+대안 통칭("기는 놈/다리 많은 거") 병기. Fulgurodonte 알리바이도 신체 정합(직립 운전석→완전 무너진 절지 돌진).

**★설계 헌법 4원칙 (이 도메인 재작업 방지):**
1. **변이 알리바이 = 작가용 내부 논리, 게임 내 미설명** (§2.2 본사 동기와 같은 층위). 카피는 영원히 "이상개체"(제3조). 정체성은 형태·실루엣·배치 행간으로만.
2. **변이 진행도 = 실루엣 인간성 잔존도.** 직립+팔=초기(사람 잔존), 완전 이형(게/민달팽이)=말기. ★불편한 행간: 약한 LV3 직립이 인간성 최대(최근에 사람), LV5 거물이 인간성 0(말기). 카피 0줄, 실루엣만.
3. **명명 2층**: 종명(라틴학명)=본사 분류코드=사람이름 지운 완곡어(제3조 정합, 에셋 고정 안 건드림, ★배드로식 비적용=사람 이름 명명법 아님). 한글통칭=렉시콘 §5 경유(공문 「…형 이상개체」 / 입말 직종 잔흔).
4. **무게=사연 아니라 구조**(외주화 §3). 회수픽 기준="본사 서류가 그 사연을 어떻게 지웠나"(신파 ❌).

**★9종 직종 알리바이 (한 줄):** Lacercharias=보행자(익명다수) / Venodonte=방역소독반(★주인공 직종 거울상) / Caniathrox=경비순찰 / Kupolojuve=배전고소 / Dimaxillosaurus=사무직(앵커①·턱=책상문법라임) / Venosaur=건설작업조(×5틴트=작업조색) / Fulgurodonte=운전중장비(앵커②·코어비콘윤곽) / Crustaspikan유생=정체성소실(변이말기종착) / Carcinoptera=항공방역인프라(★소독드론 소급떡밥).

**로스터 응집 2축:** A 직종(블루칼라+화이트칼라+익명다수+통제) B 변이진행도(직립→사족→이형). 한 도시 노동인구 단면.

**★명명 규칙 (이중 레지스터 신규 적용처):** 공문=직종 명시 절대금지(제3조), 속성/행동만(쾌속추격형). 직종 잔흔=입말에서만(순찰개·양복·기사님·조끼들), 자조/무심 톤. 신규 어휘 거의 불요(전부 「이상개체」 파생), 「유생 단계」만 §5.1 등재 제안 + 「고위험군」 LV4 적용 확인.

**★회수 4픽:** ①Venodonte=주인공 직종 거울상(소독하러 온 자가 소독대상, 운명 예고) ②Carcinoptera=항공방역→본사 드론과 시각혼선(§7 오인사격 소급) ③Dimaxillosaurus=책상문법 라임(§2.2 책임세탁) ④"직종은 입말에서만" 규칙=이중레지스터 엔진 몬스터 확장.

**캐넌 충돌 0.** ⚠️구현 가드: 인게임 공문 통칭만 노출(HUD/정산서/도감), 입말 통칭=무전 대사만. 섞으면 제3조 붕괴([[lexicon-guard-no-return]] 채널분리). 비행 3종(Kupolojuve/Carcinoptera) 평면강하(끌림 §3 높이규칙).

**Why:** LevelDesign 병렬 역할선별의 *서사/디제틱* 층. 핵심위험=공문에 직종 노출(제3조 위반)·변이 알리바이 신파화.

**How to apply:** 몬스터 카피/도감/이름 작업 시 ①공문=「…형 이상개체」 직종금지 ②입말만 직종 잔흔 ③변이진행도=실루엣축(카피 0줄) ④회수=구조 무게(사연신파 ❌). 동결 시 §5.1 「유생 단계」 등재+권위 로스터에 알리바이 컬럼 추가+uiux/Gameplay 채널분리 인계. 연관 [[map-concepts-diegetic]](발원격리=Crustaspikan말기/광장=보행자떼).
