2026-06-12 E-002 경제 볼트 정산서 어휘·양식 감사 + 카피 제안 작성(🟡 유저 판정 대기, 동결 아님). 파일 쓰기 거부되어 제안서는 본문 메시지로만 반환됨(원래 경로 docs/03_reference/2026-06-12-settlement-sheet-copy-proposal.md).

**판정 입력 4건(유저가 내림):** ①통화=숫자만(단위 무표기) ②공제 어휘 §5.1 제안중→재검토 회부 ③소독(Swept)=산재 미인정·보전 0%+미인정 사유 행 ④사망=산재 보전 30%(§4.7).

**핵심 제안:**
- 어휘: **장비 임차료 → 장비 보급료** 교체 권고(캐넌 §4에 임차/반납 개념 없음, "보급"만 — 임차료 쓰면 "반납하나?" 미설계 질문을 카피가 만듦). 산재보험료/실수령액/공제 내역/금일 정산액 유지.
- 신규어휘: **잔고**(보유 strain 위반 대체) / **산재 미인정 (구역 소독)**("무단 잔류"보다 차가움 — 직원 탓 명시 안 함) / **0 처리**(음수 안 찍고 0+부기).
- **★양식 핵심(P3): 메모리 회수 항상 4번 고정.** 조건부 행(소실·미인정)은 번호를 먹지 않는 **들여쓴 부기(注記)**로. 1~6번 골격은 전 결과 동일 → §5.4 "정산서 4번 항목" + §6.1 "50번 반복 리듬" 폭로 장치 전제 보존. 실물 급여명세서 문법(0이라도 자리는 지킨다)이 우리 폭로 원리와 동일.
- 사망/소독 적자: 산재 30%=공제 부분상쇄 +행, 소독=산재 0행. 나란히 놓으면 산재 행 하나만 다름(차별이 행간에). 실수령 0+"이월 없음"=회사가 빚 탕감(친절 아닌 무관심)=블랙코미디(해설 0줄, 폭탄은 숫자 0).

**Why:** 폭로(§6.1 첫 판독)가 정산서 리듬의 반복성에 의존하는데 현행 임시양식은 조건부 행이 번호를 밀어 회수량 위치가 결과마다 흔들렸음.

**How to apply:** 정산서/공제 카피 작업 시 ①장비 어휘는 "보급료"(임차X) ②번호 행은 절대 조건부로 만들지 말 것(부기로 빼라) ③블랙코미디는 플레이버 문장이 아니라 숫자0+부기가 친다(절제).

**기존 위반 발견(인계):** RunLoopUI.cs 189·223행 "누적 보유 strain"/"보유 strain" = 렉시콘 §5.4 위반(개발어 strain 노출). 정산 UI 스펙 v1.2 §2.4 "XXX 단위" 잔존도 판정① 숫자만과 충돌. 둘 다 판정 후 Gameplay 인계 필요.

**표기차 미해결:** 작업코드 OP-0417(§6.1) vs OP-XXXX(§6-3) vs #0419(데모) — 유저 확인 대기(렉시콘 v1.7 비고).
