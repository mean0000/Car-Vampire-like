- **"너무 판타지스러운 건 현실로 치환. 사이버펑크 잘 찾아보면 된다."** 단 ⚠️*네온 애니 사이버펑크 ❌* → 우리 톤=칙칙한 K-행정 산재 디스토피아+코퍼테크. **현실 치환=실물 군용/코퍼 장비처럼 들리게**(제품 데이터시트 톤).
- ★핵심 발견: 우리에 맞는 사이버펑크 = **제품-사양서 사이버펑크**. 그 레지스터는 *이미 관료적*이라 K-행정 톤과 안 싸우고 슬롯됨(본사 정산서 = 코퍼 제품 사양서 = 같은 차가운 문서 장르).
- **어휘축 전환**: 절단/절삭/베기 폐기 → **모노엣지(단분자날)·출력·캘리브레이션·프리셋·모듈·리미터·Mod**.

## v2 제안 7노드 (공문 / 입말 / 레퍼)
- 무기 = **수입형 모노엣지 단도 C-7형**("단분자 날·펌웨어 미적용") / "카타나" — Cyberpunk monomolecular blade(분자 단위 날). 외산 코퍼(Tsunami식)+펌웨어 stripped
- 【거합】 = **충전 사출 모드 (Mod-A·인증 작업자 한정)** / "거합" — 군용 Mk-Mod 표기. 인증한정=고수 진입장벽
- 【참격】 = **연속 가동 모드 (Mod-B·자격 불요)** / "참격" — 같은 라인 B변형. 자격불요=뉴비
- [벽력일섬] = **돌파 사출 (관통 프리셋)** / "벽력·치고빠지기" — 사출=실물 발사 어휘
- [반격베기] = **반격 방전 (피격 환류 프리셋)** / "되치기" — ★E-002 정산 "환류" 회수 유지
- [플리커] = **근접 연쇄 가동 (밀도 동기 프리셋)** / "플리커·순삭" — ★"동기"는 *밀도-동기*로 한정(싱크 "동기화" 분리 가드)

## ★[검기 발사] 디제틱 해법(가장 판타지)
바이브로블레이드(진동/공진장으로 스스로 베는 칼) = 실물 근거. 펌웨어 없어 장 제어 못 함 → **출력 리미터 강제 해제(비인가) 오버클럭 = 공진장이 날 끝 넘어 공기 중 방전.** "검기"가 아니라 *고장난 장비의 절단장 누설* = 화려하되 불안(산재 톤 정합). 옛 "비인가 출력" 액자 위에 바이브로 디테일.
