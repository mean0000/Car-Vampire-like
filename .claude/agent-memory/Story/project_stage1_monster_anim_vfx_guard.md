2026-06-14 1차 스테이지(폐허 도심) 9종에 애니/VFX 붙기 전, 모션·이펙트가 디제틱 2축(직종 거울상 / 인간 소거)과 충돌하는지 사전 감사. [[stage1-monster-diegetic]] v0.1→**v0.2 해소 반영**(유저 승인 2+오케스트레이터 결정 1). 산출=감사 의견+종별 가드(권위 동결 ❌, 제안만).

**★핵심 발견 = 비주얼이 알리바이를 일부 배신.** 디제틱 문서는 권위 로스터의 *텍스트 킷*만 보고 알리바이를 짰는데, 실제 메시를 보니 형태가 직종 모션과 어긋나는 종이 있다. 애니/VFX는 *형태 위에* 붙으므로, 모션 가드가 텍스트보다 형태를 따라야 한다.

**구멍 2건 → v0.2에서 해소 완료(2026-06-14 유저 승인 반영):**
1. **★유생 인간윤곽 역전(해소).** 유생=말기 종착 ❌ → **"성체로 가는 소거 진행 중"**. 유생 직립+굵은앞팔 잔존(인간 흔적 O), 진짜 인간0=13.2m 성체. 가족 시스템="유생→성체=인간 소거 시연"이라 축 B 강화. **연출 가드: 유생은 인간흔적(직립·앞팔)을 살려야** — 완전이형으로 만들면 역전 무효+성체와 구분 소멸.
2. **저자세 LV1 축 B 위치(해소).** 축 B=단일축 ❌ → **이중 경로**: 경로①형태 소거(개체 보존·몸 뭉개짐) / 경로②개체성 소거(군체화). Lacercharias=경로②(저자세=개성 소거, 군체로만 존재). 둘 다 인간 소거의 다른 길.
3. **★코어 비콘 재배치(오케스트레이터 결정).** Fulgurodonte=거대 거미/절지(직립 ❌)라 비콘 책무 제거→**성체 Crustaspikan(직립 타이탄)에 이관**. 끌림 윤곽 주체만 교체.

**★종별 애니/VFX 서사 가드 (1줄씩, 형태 실측 + v0.2 반영) — Animation/artist 인계용:**
- **Lacercharias**(입+이빨덩어리, 저자세, 작은팔): 경로②=개체성 0. 군체 모션은 다 똑같이 굴러야 "익명 다수"가 산다. 영웅적 개별 동작 ❌.
- **★Venodonte**(가재/곤충형, 집게다리, 직립❌) — **요청 종**: ★거울상 핵심인데 형태가 인간 손과 멀다. 산성 분사를 *구기/집게를 노즐처럼 겨눠 뿜는* **조준 행동**으로 → "분무기 들던 손이 분무기가 됐다"가 **분무 노즐 조준의 잔흔**으로 읽혀야. 머리째 기울여 짐승 침뱉기로 보이면 거울상 死. 분사 전 *겨눔 프레임*(노즐 정렬) 한 박자 필수.
- **Caniathrox**(직립몸통+긴양팔+입, 사족❌): 배역표="사족 추격"인데 비주얼=직립+팔. "두 발로 돌던 경비가 짐승처럼 쫓되 *직립 잔흔* 남은" 반인반수 질주. 완전 네발 ❌(경비 행간 소멸+비주얼 모순).
- **Kupolojuve**(돔+가시+다리, 비행): 배전·고소. 전격 VFX=*전선에 매달리던* 잔흔(감전된 채 부유). ⚠️끌림 §3=평면 강하, 옥상 체류 ❌.
- **Dimaxillosaurus**(직립+긴팔+가슴께 입): 사무직 앵커①, 경로①초기(인간 잔존 최대). 클로 콤보="결재/지시하던 팔" 잔흔으로 직립 보존. 짐승 네발 ❌.
- **★Venosaur**(직립 근육질+팔+가시틴트) — **요청 종**: 건설 작업조. ×5 틴트=안전조끼 색 → 같은 모션 떼가 "한 현장조 통째 변이"로. **★조 단위 동질성=틴트별 개별모션 절대 ❌** — 5색이 *완전 동일 모션*으로 떼지어 움직여야 "작업조가 통째로" 읽힌다. 색만 다르고 행동은 한 몸처럼.
- **Fulgurodonte**(거대 거미/절지, 직립❌ — ★v0.2 실측 정정): ⚠️**비콘 책무 제거됨**(직립 아님). 알리바이=운전기사지만 형태는 "운전석 직립이 완전 무너져 여러 다리로 땅 긁으며 돌진". 램 돌진=낮은 무게중심 절지가 기관차처럼. 직립 솟구침 ❌(거미 신체). 입말="기사님"(추락 자조) 또는 "기는 놈/다리 많은 거".
- **★Carcinoptera**(날개+게다리, 완전 곤충) — **요청 종**: 항공 인프라. ★소급 떡밥=비행 실루엣이 본사 드론과 혼선. **★드론식 호버=다이브/비행을 *기계적으로 정연하게*** (짐승 펄럭임 ❌ → 정지 호버→직선 강하→복귀의 드론 패턴 잔흔). 후반 "머리 위 그것도 본사였나" 소급이 이 기계감에서 산다. ⚠️평면 강하.
- **CrustaspikanLarvae**(직립+굵은앞팔 잔존): ★v0.2 역전=**"소거 진행 중"**. 유생은 인간흔적(직립·앞팔) **살려야**(완전이형 ❌). 입말 통칭 금지 유지("새끼 나왔다/곧 큰 거 나온다", 직종 호칭 ❌)=정체성 소거 중.
- **Crustaspikan 성체**(13.2m 완전 이형 게): ★v0.2=**코어 비콘**(Fulgurodonte에서 이관). 거대 타이탄 실루엣이 멀리서 끌림 §2.1 "가장 인상적 윤곽" 담당. 인간 윤곽 0(소거 완성)=직종 못 붙임. 비콘=공포와 끌림이 한 실루엣에 겹침.

**입말 통칭 블랙코미디 강도 점검:**
- 톤 일관성 양호(자조·체념·무심). "기사님"(존대의 폐허)·"양복"·"조끼들"·"순찰개"=직종 잔흔 무심코 흘림 = 이중레지스터 우수.
- ⚠️강도 편차: "잡것들/쓸 거"(Lacercharias)는 무심함 정점, "다 컸으면 어쩔 뻔"(유생)은 살짝 농담 과함 — 공포 비트(보스 예고)에 농담 과하면 긴장 샘. 입말은 자유변주라 강제 ❌, 단 유생 줄은 톤 조절 권고.
- 과한 것 없음. 약한 것=Kupolojuve "위에 거"는 밋밋(직종 잔흔 약함). "전봇대"류 한 마디 더 흘릴 여지(입말 자유).

**렉시콘 신규 등록 필요(판정 대기):** [[stage1-monster-diegetic]]와 동일 — 공문 「유생 단계」 §5.1 신규 1건 + 「고위험군」 LV4 적용 확인 1건. 입말 통칭은 등재 ❌(자유변주, 등재하면 즉흥성 死). 본 감사로 추가 어휘 발생 0.

**캐넌 충돌 감사 = 0건.** Carcinoptera 본사 드론 혼선 떡밥=렉시콘 §7 "소독 드론 오인사격" 기존 항목의 시각 회수라 신규 캐넌 아님 → 충돌 불가. 단 위 구멍 2건은 *충돌이 아니라 디제틱 내부 정합 보강*(비주얼↔축 B 동기화).

**Why:** 애니/VFX가 붙으면 *형태 위 모션*이 서사를 확정한다. 텍스트 알리바이만 맞고 모션이 형태를 배신하면(Caniathrox 사족화·Venodonte 짐승침) 직종 거울상이 死. 비주얼 실측 없이 텍스트만 본 v0.1의 사각.

**How to apply:** ①Animation/artist 인계 시 위 종별 가드 1줄 전달(특히 Venodonte 분무자세·Caniathrox 직립잔흔·Carcinoptera 기계적호버). ②디제틱 v0.2 갱신 시 구멍 2건(유생 역전·저자세 축위치) 해소안 반영해 유저 판정 올림. ③공문/입말 채널분리 가드 유지([[lexicon-guard-no-return]]). 동결은 유저.
