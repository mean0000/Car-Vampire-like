2026-06-16 두 전환(①"황혼의 적막" 톤 폐기 ②적=나노좀비→해괴망측한 괴물) 재정합 제안. 권위=`docs/03_reference/2026-06-16-monster-grotesque-tone-realign.md`. 🟡 판정 4건 대기.

**★핵심 통찰(재작업 방지): "좀비→괴물"은 기원 폐기가 아니라 변환 *결과물(외형)*의 격상.**
**Why:** 나노봇은 외형 설정이 아니라 세계 작동 *기전*이다 — strain=메모리(§5.4)·싱크게이지(제어채널)·§7 정합표 8행·기원 타임라인 통제기가 전부 나노에 절대 의존. 빼면 게임 코어 재설계.
**How to apply:** 적 외형 그로테스크화 작업이 와도 나노 기전은 건드리지 말 것. 충돌이라 부를 진짜 충돌 없음. 버릴 건 "좀비=부패시체 머릿속 이미지" 하나(공식 명사 "이상개체"는 이미 정식이라 무피해).

**★stage1 몬스터 작업과 정렬(충돌 0):** [[stage1-monster-diegetic]] 9종이 이미 라틴학명+"사람이 이형으로 소거"+변이진행도(직립→이형) 축으로 짜여 있었음 → 괴물 격상이 *전제였다.* 이형 강해질수록 "변이진행도=인간성 잔존도" 행간 선명. 제3조 낙차도 강화(형태 끔찍↔서류 무심).

**기원 톤 3후보(유저 판정):** A="오류로서의 이형"(나노 폭주, 본사도 형태 예측 못함)=★추천, §2.1 미결("예측 못한 사건") 떡밥 회수+신규캐넌0+무변론정합 / B="설계로서의 이형"(직종→형태 의도)=⚠️제3조 약화·본사 전능화 위험 / C=혼종(변환은 의도/형태는 폭주, 직종↔형태는 입말 농담만)=A+stage1 "직종 잔흔 입말만" 규칙과 정확 일치.

**대체 톤:** "황혼의 적막"(적막=빈것) 폐기 → "처리되지 않은 흔적"(행정 멀끔함↔못치운 살덩이의 *부조화*). 서사 충돌 0, 톤 단어 교체뿐. graphics 무드 최종콜은 유저.

**맵 흩뿌림 프롭 카탈로그 3분류:** 괴물흔적(살덩이증식/결정화잔해/둥지-고치/분비물/융합사물/바닥균열) + 인간흔적(통제선/★소독스티커위 증식/빈 집결지/민원보험서류/추락드론/빈 방호복+사번/'특이사항없음' 게시판) + 경계프롭(소독스티커↔증식=A기원 1프롭 요약). 흩뿌림 3원칙=대비로 읽힘/밀도가 변이진행도 따라감/라벨=§5어휘+"사람"0. ★시신 금지(신파)=빈 방호복·빈 집결지로만.

**판정 4건:** ①큰틀(나노 기전 유지=맞나) ②기원톤 A/B/C ③대체톤 부조화 방향 ④1차맵 핵심프롭 5~6종 선별→LevelDesign 인계. 오케 추천코어=소독스티커↔증식/통제선/특이사항없음게시판/결정화잔해/빈방호복/추락드론.
