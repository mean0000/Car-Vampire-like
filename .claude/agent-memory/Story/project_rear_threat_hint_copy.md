2026-06-12 "후방 위협 청각 힌트" 시스템(같은 날 동결, 시야 콘 밖 좀비 접근 시 파문 아크+발자국 얼룩, 디제틱=엘 나노봇 패시브 스캔의 지면 진동 감지) PartnerAIUI 토스트 2종 렉시콘 감사 완료.

**확정 카피(유저 판정 대기였던 감사 산출):**
- 티칭(최초 1회): 「안내. 바닥 무늬는 진동 기록임. 위치 보증 없음.」 — uiux 초안에서 소리→**진동**, 발밑→**바닥** 2어절 수정
- 위급(TTC≤1.2s): 「후방 진동. 판독 불가.」 — 원안 통과

**Why:** ①디제틱이 "지면 진동"이고 위급 토스트가 이미 "진동" — 한 시스템에 소리/진동 공존은 1시스템 1어휘 위반 ②"발밑"은 플레이어 발치 파문만 가리키고 좀비 자리 발자국 얼룩을 못 덮음 — "바닥"이 포괄 ③"판독 불가"는 §5.4 기등록 어휘 적립 — 평시에 익숙해져야 중반 "비인가 판독"(§6.1)이 익숙한 단어의 금지 위반으로 떨어짐.

**How to apply:** 이 시스템 관련 후속 카피(업그레이드 설명·튜토리얼 등)는 전부 "진동" 축("소리" 표기 금지). §5.1 등재 제안 1행(후방 위협 힌트 = 진동 감지/진동 기록) — 유저 동결 확인 후 렉시콘 갱신 필요(아직 미반영).
