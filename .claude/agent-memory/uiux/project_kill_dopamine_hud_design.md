## 1. 선제 발견 — "쟤가 날 못 봤다"

### 결론: 아웃라인 2단계 + 엘 텍스트 토스트

- Dormant: 아웃라인 없음. 배경에 섞임.
- Investigate/Alert: 얇은 흰색 아웃라인 (기존 어그로 두께의 절반)
  + 엘 토스트: "반응 감지 / 미확인"
- Chase 이상: 기존 시안 두꺼운 아웃라인 (IsAggro — 기존 구현)
  + 엘 토스트: "위협 확정 / 적대적"

디제틱 근거: 김도현은 나노봇 억제 시스템 운용 현장 기술자, 엘이 실시간 감염체 활성 상태 스캔. 기존 ScanPulseController 확장.

**Solo Dev Cost: S**

## 2. 타격·킬 피드백

### BulletHitTier별 임팩트 VFX (가장 중요한 미싱 레이어)

- Full: 시안 작은 다이아몬드 팝 (피격점, 0.12s) + 좀비 흰 플래시 + 넉백+히트스탑 (기존)
- Graze: 앰버 작은 스파크 팝 (피격점), 좀비 플래시 없음
- NearMiss: 기존 스파크PS만 (이미 구현)

탑다운에서 히트마커는 커서가 아닌 피격점(3D 월드 공간)에 붙인다.

**Solo Dev Cost: S** — PlayImpact()에 BulletHitTier 파라미터 추가

### 킬 확정 신호

- 킬 즉시: 3D 월드 좌표 TMP 팝 "CONTAINED" (0.8s, 위로 이동+페이드)
  디제틱: 엘이 격리 확인 음성 보고 = UI 텍스트로 표현
- 킬카운터(상단 중앙): DOPunchPosition 짧은 흔들림

**Solo Dev Cost: S**

### 연속 킬 모멘텀 — 콤보 숫자 카운터 NO

콤보 UI 패널 없이 엘 텍스트 톤 변화로 모멘텀 전달:
- 1초 내 2킬: "효율적이에요." (건조)
- 1초 내 4킬+: "..잠깐, 이게 즐기는 건가요?" (우려)
- 15초 킬 없음: "감지 범위 내 위협 없음." (안심)

**Solo Dev Cost: S**

## 3. 무기 스왑 UI

우하단 무기박스를 2슬롯으로 확장:
- ACTIVE 슬롯: 100% 밝기, 무기이름+아이콘+탄약+대시핍
- STANDBY 슬롯: 75% 알파, 라벨만
- 스왑 애니메이션: 0.08~0.12초 DOTween 상하 크로스페이드

알트파이어 구분:
- 같은 슬롯 내 ALT 핍 2~3개 (앰버, 대시핍과 같은 점 형태)
- 탄약 표시와 독립

**Solo Dev Cost: S** — 스왑 동작 구현이 먼저, UI는 그 다음

## 4. 산데비스탄 게이지 (SYNC 바 확장)

### 발동 밴드 개념

SYNC 40%~89% = 산데비스탄 발동 가능 구간. 90%+ = 폭주(발동 불가).

딜레마 디자인: SYNC 높을수록 위험 + 더 강한 능력 사용 가능.

### 시각화

- 기존 SYNC 바 위에 발동 밴드 브래킷 마커 두 개 (40%, 89%)
- 발동 가능 구간: 브래킷 시안 펄스 (0.8Hz 호흡)
- 발동 불가 (미달 또는 폭주): 브래킷 dim

상태 텍스트 확장:
- 0~39%: "동기화율: 미달 / INSUFFICIENT"
- 40~59%: "동기화율: 가용 / AVAILABLE"
- 60~89%: "동기화율: 한계 / THRESHOLD"
- 90~99%: "동기화율: 폭주 / OVERRIDE" (발동 불가)
- 100%: "격리 실패 / CONTAINMENT FAILED" (기존)

**Solo Dev Cost: M** — 산데비스탄 능력 구현 후에 붙임

## 5. 이번 스켈레톤 우선순위

### 필수 (지금 넣을 것)
1. BulletHitTier별 임팩트 VFX 구분 — 3계층 판정이 손맛으로 읽히는 최소 조건
2. 킬 확정 "CONTAINED" 팝 + 킬카운터 흔들림 — 킬 확정 신호 없음이 현재 가장 큰 구멍
3. 적 인식 아웃라인 2단계 — 선제 발견 판타지의 전제 조건

### 미룰 것
- 무기 스왑 UI: 스왑 동작 자체가 미구현. 순서: 동작 → UI
- 산데비스탄 게이지 밴드: 능력 자체가 미구현. 순서: 능력 → 게이지
- 연속 킬 엘 텍스트: 킬이 재미있어진 다음 레이어로 얹는다

**Why:** 플레이어 판타지에서 정보 끊김이 가장 큰 지점은 "맞았나 안 맞았나"다. A(타격VFX)+B(킬확정)+C(아웃라인) 세 가지가 갖춰지면 나머지는 polish 레이어.

**How to apply:** 다음 킬 도파민 구현 세션에서 A→B→C 순서로 작업.
