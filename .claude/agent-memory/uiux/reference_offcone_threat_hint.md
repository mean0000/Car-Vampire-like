# 콘 밖 위협 힌트 — 최종 채택 + 감사 (2026-06-12)

## 힌트 해상도 다이얼 (리서치 유산 — 계속 유효)
L0 없음(Darkwood) / L1 존재만(DbD) / L2 방향만(Hellblade) / L3 방향+거리감 / L4 근사 위치(PZ 모드, MotN) / L5 정확 위치+정체(TLOU 반면교사).
**전락 경계 = "힌트만으로 조준이 가능해지는 순간."** 핵심 교훈: 소리는 위협이 아니라 수신자에게 그린다(DbD), MotN처럼 소스 현재 위치에 실시간으로 그리면 정답 UI.

## 최종 채택 스펙 (유저 몸판정 "확실히 괜찮네")
- **하이브리드 동시 발화**: 발치 60° 아크(수신자 측 방향, 원안) + 시간차 발자국(위협 측 흔적). 유저 논거="둘 다가 직관적" — 발자국이 아크의 의미를 역으로 티칭.
- 발자국 가드: 걸음 후 **0.5s 지연**(1.5는 "판정 너무 늦어"로 기각 — 표식이 거짓말함), 수명 0.8s, 좌/우 교차 ±0.18m, 가청 12m, 침식 블롯(아이콘 아님), 케이던스=발소리 박자(섹터당 최근접 1마리).
- 아크: TTC 3단(4.5/2.5/1.2s), 무채 회백→강 단계만 앰버, 60° 양자화, 동시 섹터 ≤3, 절규 즉발.
- 렌더 = Screen Space Overlay 캔버스 order 10(콘 합성 패스가 월드 투명을 지움 — 실측 후 전환), 45° 피치 세로 ×0.7.
- 엘 토스트 "후방 진동. 판독 불가." 강 단계 첫 진입 1회/10s.
- 코드: Assets/_Project/Scripts/RearThreatHint.cs + ThreatArc.shader.

## 최종 감사 판정 (uiux, 06-12)
- **L3~L3.5로 합격.** 원칙("수신자 측") 문구 위반이나 목적(조준 대체 방지) 비위반. **0.5s 지연 = 안전 하한선, 더 내리면 L4**(걷는 좀비 변위 0.5m ≈ 블롯 지름 — 이미 한계).
- **진짜 누설 채널 = 위치가 아니라 속도.** 스프린터는 케이던스 0.175s × 수명 0.8s = 동시 4~5점 트레일 → 방향+속도 → 외삽 사격 제원 성립.
- **지표 ②(블라인드 처치=0)는 "조준=시야 콘" 구조가 지킴** — 돌려야 쏘고, 돌리면 보인다. ★비조준 무기(설치형/투척/360°/보조사격 Q)가 들어올 때마다 이 시스템 재감사.
- **②가 열리면 노브 순서**: ①발자국 수명 0.8→0.5(수명<케이던스면 트레일 물리적 불가 — 신뢰 무손상, 1순위) ②속도 비례 지연(스프린터만) ③위치 노이즈(최후 — 표식 거짓말). **전역 지연 증가는 금지 노브**(1.5 기각 재현).
- **색채 규율 권고(미반영)**: 발자국은 전 단계 무채 고정, 앰버는 아크(수신자 측)에만 — 강 단계 앰버 점이 좀비 좌표에 찍히는 건 정답 UI 문법.
- 절규 발자국(지연 0.3s, 정확 위치)은 관찰 항목 — 플릭 선발사 패턴 보이면 1.0s로.

## 잔여 액션
- **미결 2건 추천**: 아크 모양=침식 단겹(발자국과 같은 잔해 질감 언어, 동심원=소나 도상이라 정답 인상), 강도=B 표준(A 약단계 0.14는 전투 중 비가시→지표① 조용히 깨짐, C는 주의 예산 침범. B→C는 가능, 역방향 불가).
- **티칭 토스트 1안(사전 게이트 미통과)**: 생애 첫 힌트 1회 「안내. 발밑 무늬는 소리 기록임. 위치 보증 없음.」 — 핵심="정답 아님"의 멘탈 모델 선제 주입. 기존 강단계 토스트는 경보, 이건 제도 안내.
- DebugDiag=true 출하 차단급(1s 로그 스팸), 코드 주석 토스트 임계 0.8s는 낡음(실제 1.2).
