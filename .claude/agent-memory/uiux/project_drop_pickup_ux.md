# 드랍·픽업 UX 확정 스펙 및 점검 결과 (2026-06-12)

## 동결된 구현 기준선
- 좀비 사망 → 0.05s 후 크리스탈(세로 팔면체, 높이 0.5m, Y스핀 80°/s, 보빙 ±0.08m, 시안 HDR 2.2) + 바닥 시안 원형 마커(지름 0.5m, 강도 0.35)
- 픽업: 플레이어 1.3m 반경 진입 시 즉시 입금 + 호밍 쿼드 4개 플레이어로 0.35s 수렴 + 링 펄스
- 수명 10s, 마지막 2s 4Hz 점멸, 만료 시 0.3s 페이드 소멸
- 자동 흡수 방식은 유저가 기각 — 능동 픽업 유지

## 지금 고칠 것 (확정)
1. **크리스탈 높이 0.8–1.0m** (시체에 묻힘 방지, 부감 가독성)
2. **바닥 마커 지름 0.8–1.0m** (부감에서 마커가 주 시그널이므로)
3. **다중 스폰 산란 로직** — 반경 0.3m 이내 기존 드랍 있으면 ±0.25m 오프셋 적용
4. **수명 만료 점멸 4Hz → 서서히 페이드 아웃** (평시 클린 원칙 위반)
5. **드랍을 ConeGhost 탈색 마스크에서 제외** — 정보 레이어 승격 (레이어 세팅만으로 가능, 시안=보상 캐넌 강화 효과)

## 플레이테스트 후 판단할 것
- **수명 10s 수치**: 3–5마리 교전 후 드랍 주울 수 있나 실측. "아깝다" = 유지 / "억울하다" = 12–15s로 상향
- **호밍 쿼드 수렴 방향**: "내가 밟아서 터뜨렸다" 감촉 오면 유지, "아이템이 나한테 붙었다" 피드백 나오면 방사형 폭발로 교체

## 그대로 둘 것
- 자동 흡수 기각 유지 (능동 픽업 = 작전 타이머 압박 연결)
- 기회비용 메커니즘 구조 (수치만 검증)
- 시안 색 캐넌 (드랍=시안)

## 설계 원칙
- 부감 15–20m에서 드랍 가독성의 주 채널은 바닥 마커. 크리스탈은 보조.
- 픽업 손맛은 "플레이어가 밟는 순간 임팩트"에서 온다. 호밍 수렴은 "아이템이 나한테 붙음" 인과로 읽힐 수 있다.
- 조준 게이트는 위협 위치 정보를 차단. 드랍(보상)은 위협 정보 아님 → 탈색 마스크 제외가 맞음.
- 4Hz 깜박임은 평시 클린 원칙 위반. 경고 표현은 페이드 아웃으로.
