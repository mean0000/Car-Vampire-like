# 카타나 타격음 아이덴티티 삼각 (2026-07-04 총지휘 Fable 지령)

**규칙:** 카타나 임팩트 음색 = **즙(meaty juice) × 무게(DD 저역 묵직) × 드라이(dry)**. "살+뼈 '촥-턱'" 2음절(촥=베는 트랜지언트, 턱=꽂히는 바디). **젖은 영웅검격 금지 — 리버브·긴 잔향·wet splatter 테일 ❌. 톤은 "사무적 학살".**

**Why:** 총지휘가 wet 방향을 명시 기각(내가 Liquid_Hit 기반 wet 후보 C를 냈다가 즉시 교체). 이 게임 톤은 화려한 영웅검이 아니라 건조한/행정적 처형. 젖은 잔향은 세계관 톤과 충돌.

**How to apply:**
- 임팩트 스파인 고를 때 wet/liquid/splatter 계열(Vefects Liquid_Hit·Impact_Blood 91% brite 스프레이) 배제. **드라이 dry hit**(Combat Hit_03/05/09 = 짧고 중역 위주)를 스파인으로.
- 리버브/딜레이/롱테일 넣지 마라. 테일은 짧게(<250ms), 붐 아닌 thud.
- **SFX 팩 구매 판정 시에도 같은 렌즈**: 즙×무게×드라이. 최종 아이덴티티는 R1 통과 후 구매 팩에서 옴 — 내 절차 합성은 R1 게이트용 "충분히 그럴싸한 플레이스홀더"지 완성품 아님(과다 폴리싱 금지).
- R1 게이트 질문 = "소리가 손맛의 몇 %냐"(소리 유무 A/B). 완성도 아니라 **3레이어 구조 잡힌 그럴싸함**이면 통과 조건 충족.
