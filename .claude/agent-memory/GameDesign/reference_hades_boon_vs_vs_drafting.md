2026-06-17 웹조사 (유저 명제 검증: "엠버 축복=하데스 Boon 직접 원본" / "우리 1순위 레퍼=엠버 한다리 말고 하데스 직접 해부"). 카타나 첫 볼트 카드 설계 전 레퍼 추적·재정합 검증.

## 하데스 2 Boon 실측 구조 (Fandom/Mobalytics)
- **레어도**: common→rare→epic→heroic. 레어도는 *숫자만* 키움(동사 동일). = 우리 [[project-card-system-research]] "숫자등급" 축 = 하데스 추적 맞음.
- **신 카테고리**: 신별 고유 효과(번개·방어·유틸). *단 락인 아님* — 한 런에 여러 신 섞는 게 본질.
- **듀오 Boon**: 두 신 *교집합*에서만 태어남, 양쪽서 일정 Boon 보유 요구. = G3 시너지 활성. 하드월 아님(보너스).
- **레전더리 Boon**: 단일 신 주황테, 최상위 유니크 스킬, **각 신서 3 Boon 보유 요구**. = 깊이 보상.
- **인퓨전 Boon**: 원소 친화도 충족 시 등장. 별도 풀.

## ★명제 판정 (3종 모두 부분수정)
**명제1 "엠버 축복=하데스 직접 원본" = 부분수정(인과 과장).**
- 진실: 엠버≈하데스 레어도+축복 *느낌*은 닮음. **그러나 핵심 차이** = 엠버는 "천사별 계열 *락인*"(정화 시 그 계열만 강화), 하데스는 **다신 혼합이 본질**(락인 없음, 듀오=신들 *섞을 때* 보상). → 엠버는 하데스보다 **단일계열 집중**(Death Must Die 신3명 게이트·Brotato 세트에 더 가까움). "하데스를 옮겼다"는 한 갈래만 맞고 락인 부분은 하데스에 없는 것 = 비약.

**명제2 "1순위 레퍼=하데스 직접 해부" = 부분수정(우선순위 재배치).**
- 하데스 해부는 옳으나 *어느 부분이냐*가 중요. 하데스가 우리에 직접 이식되는 건 **(a)레어도=숫자축 (b)듀오=G3 시너지** 둘 뿐 — 이미 [[project-card-system-research]] 3종 하이브리드에 박혀 있음(재발명 불요). **"신별 계열 락인"은 하데스에 *없다*** → 단일무기에 이식 시도 자체가 잘못된 출처.

## ★(a)~(d) 따짐 결론
- **(a) Boon(조건부 패시브) vs 뱀서 레벨업카드(독립 슬롯) 동일시 = 비약 맞음.** 하데스 Boon은 *기존 공격/대시에 조건부로 얹히는* 패시브. 뱀서 카드는 독립 무기/슬롯 누적. 구조 다름. 단 *내용 문법*(G1~G6)은 양쪽 다 통용 → "구조는 다르나 카드 내용 짜는 법은 훔칠 만"이 정확.
- **(b) 단일무기에 다신 계열구조 이식 = 직접은 불가, 재해석은 가능.** 하데스 "여러 신"=우리 "여러 무기"에 대응(다무기 빌드면 성립). *단일 카타나* 내부엔 "신=계열"이 없음. → 대안: **계열=무기 내부 *동사 가지*** (거합/참격 등). [[project-katana-cascade-design]] 분기(연/살/류)가 곧 이것. 락인 레퍼는 하데스가 아니라 **20MTD 트리** 또는 **DMD 신3 게이트**.
- **(c) "누를때만+타이밍윈도우" vs Boon 자동발동 = 충돌 아니라 시너지.** 하데스 Boon도 *플레이어가 공격/대시를 쳐야* 발동(완전 자동 아님). 우리는 그 입력을 더 의도적으로(타이밍) 만들 뿐 → 카드는 "잘 친 입력에 보상 얹기"(완벽콤보 시 발동)로 설계하면 수동성이 카드를 *더* 살림. 충돌 0.
- **(d) 기존 권위 재정합**: weapon-progression·build-tree-controls는 **익스트랙션·6무기·엘/드론·키스톤(화려함=돈)·퇴근정산 = 전부 vampire_survivors_pivot로 폐기**. 살아남는 건 *카드 내용 문법(§16 카드문법 v2 / reference-card-content-grammar G1~G6)*와 *카타나 거합/참격 2트리 동사 구별*뿐. [[project-katana-cascade-design]]·[[project-card-system-research]]는 피벗 후에도 유효(무기 내부 설계라 익스트랙션 무관).

## ★단일무기 "계열 락인" 대안 레퍼 (하데스 아님)
- **20MTD**: 68 gun upgrade, 4개씩 트리 묶음. **첫 노드 잡으면 관련 2개 출현 → 궁극 진화**. = *단일무기 내부* 트리 락인의 직접 선례(우리 카타나에 정확히 맞음). 진화는 레벨20 3택1.
- **DMD**: 런당 신 3명 게이트 = 집중 강제. 우리=카타나 동사 가지 2~3개로 게이트.
- → 카타나 카드는 "거합/참격 가지를 *고르면 그 가지 카드가 더 자주 뜸*"(20MTD 출현 가중)으로 락인. 하드월(다른 가지 0) ❌ = [[feedback-pong-over-systematization]] 위반·편식 하드월 금지.

**How to apply**: 카타나 첫 볼트 카드 풀 짤 때 — 하데스에서 훔칠 건 레어도(숫자축)+듀오(G3시너지) 둘뿐(이미 박힘). 락인은 20MTD 트리 출현가중으로. "누를때만" 입력은 완벽콤보 보상 카드로 시너지화. 명제 인과("하데스 옮김")는 유저에게 부분수정으로 보고.
