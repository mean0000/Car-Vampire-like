무기·성장 관련 권위 문서 재정합 결론 (2026-06-13, 익스트랙션 대전환 이후 기준).

**🟥 폐기 (메커니즘 죽음, 개념만 흡수)**:
- `2026-05-29-progression-system.md` — 문서 자체에 🟥마크. 설계도/부품 파밍·감염 화폐·접근게이트(방독면)·현장기지 제작분리 전부 익스트랙션이 무효화. **살릴 개념만**: 해금/성장 분리(Dead Cells), "숫자 아닌 동사" 레벨업, 개조슬롯=같은장비 변형(→무기 Aspect로).
- `2026-06-03-demo-weapon-lineup.md` — 무기 2종 한정·소음=대가축 폐기. **살릴 원리**: 대가 트레이드오프 원칙(순수상향 금지), 약넉백=run-and-bash 근접 게임감.

**⚠️ 자기모순 발견**: 핸드오프 §2가 "줍는것=무기강화 설계도/부품"을 *동결 컨텍스트*로 인용하나, 그 출처 progression-system은 🟥폐기. → **E-002(현금)가 이긴다.** 줍는것=메모리(납품), 강해지는흐름=메모리→현금→보급. "부품으로 무기제작" 없음.

**🟡 부분 구식 (구조 살리고 재배선)**:
- `2026-05-31-levelup-cards-catalog.md` — 구조(누적청크+진화+2층풀+드로우곡선+시그니처) 100% 살아있음. **자원축만 재배선**: 소음축(소음대가가 보급/공제 구조에 없음)·시계축(감염둠클락=재제안금지) → **킬/기동/화력/정밀** 4축. ⚠️코드 enum 재정합 필요: `RunUpgradeDef.ResourceAxis`={Noise,Clock,Kill,Mobility,None} → {Kill,Mobility,Firepower,Precision,None}.

**★🟥 런 구조 대전환으로 *추가* 무효화 (2026-06-13 병렬 세션, v0.6 재정합 — load-bearing)**:
- **싱크 = 마스터 압박 시계 폐기.** `02_logs/2026-06-13-run-loop-system-architecture.md`(권위=[[project_2026_06_13_run_structure_pressure_engine]])가 **위협 레벨 단일 다이얼**(티어깊이+시간초과 → 스탯/밀도/변이 곱셈자)로 교체. 싱크=플레이버/사망FX로만 잔류.
- **★"화력 도박 대가=싱크 충전 가속"(구 §5.2) 무효** → **카드 자체 −스탯 트레이드오프(Brotato)**로 교체. 위협 다이얼에 카드가 기여하는 것도 ❌(아키텍처 §4.1 = 위협은 깊이+시간만, 단일 다이얼 순수성).
- **★"드론 싱크 라이딩 대가"(§11.4) 부분 무효** → Q20: A(싱크를 드론 전용 게이지로 부활) vs B(드론 자체 자원). 코어 싱크 운명 직결, 오케+유저 직접.
- **하드 타임아웃 사망 폐기** — 시간초과=위협 가속(사망 아님). "시계축" 카드 잔재 완전 폐기.
- **★새로 생긴 성장 척추**: 티어 커밋("한 탕 더") = XP 배수↑(`QuotaTierConfig.tierXpMult`, 코드 존재). 러시안 룰렛 할당량이 in-run 성장 페이싱의 엔진.
- ⚠️**재제안 금지 추가**: "싱크가 능력/화력/드론의 대가"는 *구식 전제*. 싱크를 압박/대가 자원으로 다시 제안하지 말 것(Q20 A로 부활하면 *드론 전용*으로만, 마스터 시계로는 ❌).

**🟢 살아있음·동결 (그대로 위에 쌓음)**:
- E-001(판돈 볼트온)·E-002(정산서 경제) — 런 간 성장의 척추. 현금잔고·메모리=납품·업그레이드=현금구매(UpgradeDef). 무기 체계는 이 위에 보급티어 + 업그레이드 그리드를 끼움. UpgradeDef가 현재 Damage/FireRate 플랫뿐 = 무기 연결할 빈칸.
- `2026-06-13-topdown-attack-grammar.md` — 곡사→장판/직사→탄막, 적 위협 9형식. 무기가 *무엇을 상대하나*의 기준(권총=조준탄 사수 거울, 샷건=접촉/돌진 해소).

**Why**: 익스트랙션 대전환(06-09)·보급개정(06-11) 이전 산물을 그대로 쓰면 죽은 메커니즘(감염화폐·소음축)을 부활시킴.
**How to apply**: 무기·성장 제안 시 항상 "E-002 현금경제가 척추, progression-system은 역사참고용" 전제. 소음축·시계축·설계도/부품 어휘 재등장하면 구식 신호.
