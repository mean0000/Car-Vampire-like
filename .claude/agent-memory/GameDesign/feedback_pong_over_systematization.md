무기/성장 트리 설계의 **단일 판정 기준 = 뽕 = "이게 *시각적 파워 판타지 러시*를 주나"**. 경제 루트 분류·스타일 친화 분류·"어떤 적을 farm 하나" 스프레드시트는 **유저가 죽인 것**.

**Why**: 2026-06-14 유저가 검→카타나 트리를 의뢰하며 명시 — "의견 있게(opinionated), 뽕 우선, 근거는 레퍼." 이전 §17.10(6무기 지배 친화=런 경제 루트)·Codex farm 테스트 류의 *systematization*이 뽕을 죽이는 방향이었음. 트리는 표 위에서 깔끔하게 갈리는 게 목적이 아니라 *플레이어가 화면에서 카타르시스를 느끼는 게* 목적.

**How to apply**:
- 무기 트리/카드 제안 시 각 가지·잎의 1순위 정당화 = "이 순간이 뽕인가"(시각적 파워 스파이크). "이건 정밀축 farm 루트라 깔끔히 갈린다"는 *부차*.
- 극단으로 갈수록 *더 큰 뽕*으로 에스컬레이트해야(분쇄기 성장, 액션 앵커). AFK·수동화 ❌.
- 레퍼 추적은 여전히 의무지만, 추적의 목적 = "이 레퍼가 *어떻게 뽕을 만드나*"이지 "어떻게 분류하나"가 아님.
- 경제 루트/farm 분류를 *완전히* 버리란 건 아니나(임무2 LevelDesign 경계엔 살아있음), 트리 *구조 설계의 운전대*는 뽕이 잡는다.
