2026-06-25 웹조사. 핀 사냥("단순 입력→과장된 호쾌함→플레이어가 크레딧"). 전부 실측. 관전자 함정("게임이 멋진 거지 내가 멋진 게 아님") 회피 메커니즘에 집중.

**★핵심 패턴 = "자동화는 화려함을 깔되, *의미 있는 결정*에 보상(점수=우리는 돈)을 더 준다"가 관전자 함정의 정답.** 순수 자동(보상 평탄)이면 관객, 자동+결정보상이면 플레이어.

**실측 메커니즘:**
- **DMC5 Auto-Assist(Automatic Mode)** — 한 버튼 연타로 컨텍스트 화려 콤보 자동 연결(타이밍·방향 불요). 핵심=**미션 결과 ×0.8 스코어 패널티**(수동이 더 높은 Stylish=점수). 즉 *접근성(화려함)은 주되, 크레딧/점수는 수동에 더 준다.* → 우리 화려함=돈 이코노미와 메커니즘 동형(자동 베기는 베기, 결정 베기는 더 큰 돈).
- **Hi-Fi Rush** — 공격이 자동으로 음악에 싱크(리듬 못 맞춰도 진행), 단 **타이밍 맞추면 데미지↑ + 타이밍 피니셔 추가뎀**. 비트 강제 미니게임은 단일버튼으로 낮출 수 있음(접근성). → "관대한 바닥 + 결정 보상 천장"의 정전. 시각 어시스트(808 고양이가 비트 시각화, 피니셔 타이밍 인디케이터)로 결정을 *읽히게*.
- **Warframe Excalibur Slash Dash** — ★"선을 고른다"의 실존 메커니즘: 방향 입력→전방 대시하며 **사거리 내 적들에게 자동 연쇄(auto-chain)** + 모멘텀(멈출 때까지 진행방향 유지). 입력은 방향·위치 결정뿐, 절단은 시스템이 완성. = 오케 "선을 고른다" 동사의 직접 선례.
- **Katana Zero — Dragon(드래곤) 칩**: 평타가 사실상 대시 = *경로상 전부 절단*. 사이드뷰지만 "선=학살"의 원형. Katana Zero 전체=원킬·시간슬로우·흠없는 한 sweep으로 방 정리("플로우 클리어").
- **Shovel Knight Dash Slash / Turbo Overkill 대시-체인소** — 대시 한 줄에 적 줄 학살. 모멘텀 체인.
- **Prototype** — 단순 접근 입력(소어/스프린트/변신무기 클로·블레이드·해머·휩)인데 *움직이며 스타일리시 학살*=역량 파워판타지의 정전. 메커니즘 복잡도 낮음, 스펙터클·이동자유가 "잘해 보임"을 만듦. 단 3D 수직 호쾌함 의존(탑다운은 못 줌).

**탑다운 갭(중요)**: Prototype·DMC·Hi-Fi Rush·Katana Zero 다 3D 또는 사이드뷰. 탑다운에서 이 "잘해 보임"을 *공간 결정*(어느 선/표적군)으로 푼 선례=Warframe Slash Dash가 가장 근접(단 3D). 탑다운 전용 성공 사례는 [[reference-distinctive-action-roguelikes]] 참조(Explore 조사분).

**How to apply**: 핀 후보 "선을 고른다"의 기계 선례=Slash Dash. 관전자 함정 해법=DMC ×0.8/Hi-Fi 타이밍보상 패턴(자동 깔되 결정에 돈 더). 우리 화려함=돈 이코노미가 이미 이 패턴의 절반(돈축)을 갖고 있음 → 결정을 *돈에 연동*하면 정합.
