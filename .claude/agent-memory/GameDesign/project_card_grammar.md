**판정 Q28~Q32**: Q28(6동사 클래스+순수%금지)·Q29(분기 3장치)·Q30(검 트리 7노드 형태)·Q31(스코프)·Q32(분기를 게이트 이벤트로 격상=LevelDesign 경계). ★가장 중요=Q30+Q31(솔로 감당 게이트).

**Why**: 유저 "직접 지으면 한계 명백, 레퍼 파악하고 와라" = 임의설계 폐기 의무. 이전 §13은 빌드 *고수준 좌표*였고, 카드 *내용 문법*은 한 층 아래 미답이었음.
**How to apply**: 카드 내용 신규 제안 시 G1~G6 명시 + 레퍼 추적. 검 트리 변경은 Q30 판정 후. 동결되면 enum 재정합 스펙 Gameplay 인계 + 검 노드명 Story 렉시콘 의뢰.
