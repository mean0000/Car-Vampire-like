2026-06-14 레벨업 카드 시스템 *전체* 설계 제안서 (`docs/03_reference/2026-06-14-card-system-research.md`, **v2.0**). §16(카드 문법)·§17(6무기 트리)의 *위층 질문*(몇 장·어떻게 제시·등급 붙이나). 11게임 4차원(풀크기·등급·드래프트·뽕유지) 웹 실측 표.

**★★등급 결정 = 3종 하이브리드 (유저 *확정*, 2026-06-14) — v1.0 "등급 NO" 기각·대체. load-bearing.**
- ★**유저가 내 "등급 NO" 권고를 기각하고 3종 하이브리드로 확정**(오케 종합=gd↔Codex 충돌 해소). 카드 "특별함"=세 *다른 도파민* 층:
  - **① 숫자 등급 (Common/Rare/Epic)** — *일반 카드(연료·시너지) 인스턴스*에만 붙는 *숫자 롤*. 정체성 불변(Hades 모델). 잦은 작은 도파민. 코드=인스턴스 `Rarity` 필드 1개(잎②·신화③엔 ❌). StS pity는 ①에만.
  - **② 전설 잎 + 변형** — 트리 종착 잎 *도달*(결정론, 주사위 0)→**변형 갈래**(예 벽력일섬: [중심 과부하]/[귀환 라인]/[2차 기폭])→변형 안에서 *또* 재분기(PoE 키스톤 뒤 노드). 빌드크래프트 깊이. per-잎 변형 전면작성=§17.1.D 갱신=별건(후속).
  - **③ 신화 와일드카드** — *완전 새 명사/동사*(숫자·변형 아님). 트리 *밖* 별도 풀. 가끔 RNG, **화려함=돈(처리평가) 가중**(Brotato Luck 레버를 처리평가가 대신). 런당 캡+쿨다운. 잭팟. → §6 풀.
- ★**reframe (핵심)**: 질문="등급 넣나 마나" ❌ → "등급이 *어디* 사느냐" ⭕. **충돌 0·스택**: 처리평가 S~D=*런 경제* / ①=*카드 인스턴스 파워* / ③=*새 메커 출현* 게이트 = 각자 다른 것 등급화. 처리평가↑→③신화↑→더 화려→처리평가↑ 양의 루프.
- ★**v1.0 틀린 전제 2개 폐기**: ~~트리=무등급~~(**SoD가 실제로 에센스 common/flawed/rare/legendary 등급화** — Codex 지적·재검증, §1.1 셀 정정) · ~~등급 2개 충돌~~(Balatro 3직교축이 반증).
- ★**Codex vs gd 충돌 해소 지점**: Codex "결정론 잎=Legendary 떴다 도파민 손실"=**③신화가 메움**. gd "결정론 빌드크래프트가 더 뽕"=**②잎이 보존**. 다른 층이라 둘 다 가짐.
- **How to apply**: 카드 신규 제안 시 ①숫자 등급은 *연료/일반 시너지 인스턴스에만*, ②잎·③신화엔 등급 ❌. 신화 신규=새 메커(새 코드, 비용 플래그 필수). "등급 NO"는 *죽은 권고* — 다시 꺼내지 말 것.

**다른 3결정**:
- **개수**: Hades급 소수 정예. 데모(검+드론)=손설계 ≈28장 / 풀게임(6무기)=손설계 ≈55장 + 연료 템플릿 1세트. ★깊이=카드 수 아니라 *조합/시너지*(SoD·Hades·VS 본진). Balatro 150·StS 75보다 적음. 2층(척추 손설계 / 연료·시너지 재사용)이라 무기 수에 선형 비례 안 함.
- **드래프트**: 레벨업 **3택 1** + "열린 트리 자격 게이팅"(prereq 충족 노드만 풀에 = PoE 경로 할당). 가중 3축(주사위 없이): ⓐ시그니처 무기 가중(isSignature) ⓑ연료:정체성 비율(verbWeightByLevel 0.25→0.60, 초반 연료↑/후반 정체성↑, Hades 곡선·코드 기존) ⓒ미보유 약가중(연료 범람 방지). ★등급 주사위 없어 StS pity 불필요.

- **방향 한 줄**: "등급 없는 열린 트리 + 3택 드래프트. 카드는 정체성만, 주사위 안 굴림. 희소성=트리 깊이, 화려함 등급=처리평가 S~D = 두 등급 충돌 0."
