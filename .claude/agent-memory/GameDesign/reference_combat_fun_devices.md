2026-07-04 웹리서치. 카타나 평타(LMB 3타) *하나뿐*인 화이트박스 랩에, 반복해도 안 질리는 장치를 ①타격감 ②배려감 축으로 추적. [[reference_horde_suppression_care_economy]](같은 편성 다른 파트=클리브/스태거/처형/마그네티즘)·[[reference_sword_action_pong_engines]](검 뽕=연쇄가속)·[[reference_simple_input_power_fantasy]]의 후속. 07-02 배려 v0(docs/02_logs/2026-07-02-combat-care-catalog.md) 위에 얹음.

**진단 = 기존 카탈로그의 빈 칸은 "에스컬레이션·맥락 변주·리듬(프레이즈) 릴리스".** 07-02 v0/억제 스택은 *per-hit 느낌 + 방어적 배려*는 두껍게 덮었으나, **여러 타격/킬에 걸친 상승 곡선**과 **같은 입력이 맥락으로 달라지는 변주**는 거의 비어 있음. Hades 교훈("기본기는 다 피할 수 있으니 게임이 자신있게 더 안-기본적 패턴을 던진다")=변주는 *입력*이 아니라 *맥락(적/상황)*에서 나온다.

## 웹리서치 실측
- **가변 히트스탑(SF6/격겜 통설):** 히트스탑 길이는 공격 무게에 비례, 펀ish 카운터/특수는 *extra-long*. 히트스탑은 (a)충돌을 팔고 (b)눈에 확인 프레임 주고 (c)취소창을 넓힘(SF: 취소 5f→10f). **우리 HitStop.Do는 현재 flat일 것 → 계단화가 가장 싼 고레버 개선.**
- **히트스탑 중 진동(Smash):** 프리즈 프레임 동안 캐릭터가 미세 진동(지상=수평/공중=수직). "인게임선 의식 못하나 없으면 티가 남." → 우리 프리즈에 얹을 값싼 NEW 크래프트 층.
- **Musou 파워판타지:** 적이 *날아가고 찢기는* 스펙터클 + Bravery/격노 게이지→화면청소 궁 + chokepoint 소탕의 OCD 만족 + 1대1000 스케일. 반복이 곧 매력(정리감).
- **HLD:** 플레이어=메트로놈(규칙적 tick으로 카오스를 정렬), 대시-슬래시 융합, 체인대시=리듬기반. Arkham 댄스-플로우 + 탑다운 검술.
- **Katana Zero:** 빠른 슬래시+시간조작→flow state. **패턴 인식·리듬이지 버튼 난타 아님.**
- **ULTRAKILL/Doom:** 스타일미터→회복(=화려함=실적=생존, 우리 코어와 동형·이미 v0에 반영). UT99 킬스트릭 아나운서=화면 킬 피드백의 원형.

## 장치 카탈로그 (기존 미보유 NEW만)
1. **맥락 감응 타격 피드백** — 같은 스윙이 {콤보 index, 대상 상태(멀쩡/경직/저HP), 킬/논킬}로 *다른* 피드백. 주채널=가변 히트스탑(예 3f→8f), 부채널=VFX 크기·사운드 레이어. 반복 변주의 *엔진*. 싸다.
2. **콤보 3타 라이징 프레이즈** — hit1 작게→2 중간→3 크게(히트스탑·VFX·베이스·카메라킥은 3타만). 같은 3버튼이 상승 악구로. Musou 경타-경타-강타 피니셔.
3. **연쇄 가속 Heat + 청소 릴리스** — 다운타임 없는 연속 처리가 *보이지 않는* heat를 쌓아 주스(셰이크/VFX/피치)를 상승, 팩 전멸 순간 릴리스 비트(큰 마지막 히트스탑+"청소완료" 스팅+짧은 슬로모). **UI 없음=관리 자원 아님=over-systematization 회피.** idle 감쇠=대기 처벌(v0 §1.5 게이지 감쇠와 정합). L4D Peak-Fade 리듬.
4. **연쇄 자동 리타겟(시체 스킵)** — 콤보 중 대상 사망 시 다음 타가 콘 내 *살아있는* 가장 가까운 적으로 페이싱 자동 전환→호드에서 스윙2/3이 시체/허공에 헛나가지 않음. **회전만(전진 병진 없음)→전진 금지 프리즈 통과.** 배려+플로우 이중.
5. **처형 피니셔** — 이미 경직/저HP 적을 치면 전용 처형 플래시(현행 ×2뎀 위에 *피드백 층*)+저HP round-to-kill(1HP 생존자 좌절 제거). Doom/GoW 상태게이트 처형의 뽕 스파이크.
6. **히트스탑 중 미세 진동(Smash)** — 프리즈 동안 적/칼이 지터. 값 매우 쌈.
7. **화면 청소 펄스** — 킬/멀티킬에 짧은 방사 왜곡·비네트 펄스(포스트). TA 트랙 친화. 잡몹 남발 금지→티어에만.
