2026-06-25 오케스트레이터가 gd에 의뢰: 러프 빌드가 *균일하게 밋밋*(좋은 순간 0) → 핀(pin) 찾기. 핀=2초마다 반복·오직 이 게임만의 단일 표현 동사·단순입력이 과장된 호쾌함·플레이어가 크레딧.

**★진짜 갈림길 = 메커니즘이 아니라 *감정 목표*다 (가장 중요한 발견):**
- **새 북극성(이번 브리프)** = **Prototype 역량 파워판타지**: 어려운 액션 없는데 연출이 플레이어를 *잘해 보이게*. "내가 굉장하다." 가볍고 호쾌.
- **06-24 코어전투 로그**(`docs/02_logs/2026-06-24-core-combat-direction-exploration.md`, 상태=탐색·동결아님) = **dread(두려운 압박)**: Devil Daggers식 공포·쫄깃함이 toy. "칼날 위 생존·한 발 뒤."
- **코어디자인 §0.1**(2026-06-09 권위) = "한 마리 한 마리 쫄깃하게" = 무거운 방향.
- → 이 셋의 충돌은 *타이밍 메커니즘 유무가 아니라* **공포 vs 파워판타지 톤**이다. 같은 핀이 둘 다 못 섬긴다(공포=능력은 적, 파워판타지=능력이 주인공).

**Why**: 브리프가 06-24를 "버려진 무거운 방향, 피벗과 정반대"로 단순 프레이밍했으나, 06-24 §3은 사실 핀 브리프와 *같은 해법*을 씀 — "화려함은 플레이어가 실행❌ 시스템이 응답으로 줌"·"세짐=크리티컬 묶음↑이지 안전❌". 즉 *메커니즘은 양립*하고 *감정 목표만 충돌*. 유저가 이 톤 갈림길을 판정해야 핀이 정해짐.

**읽고-베기(06-24) 거취 = 제거❌ / 관대화+톤전환하면 핀의 엔진으로 생존:**
- 메커니즘(커밋한 적에 타이밍→시스템이 화려 응답+전파+체인)은 핀과 양립.
- 충돌점=①관대함(현재 "빗나가면 피격"=고난도 dread / 파워판타지는 "맞추면 보너스, 놓쳐도 진행"=Hi-Fi Rush 관대) ②톤(공포 vs 역량).
- 판정 권고=관대화(실패 처벌→성공 보너스로 부호 전환)+dread톤 강등. 단 "타이밍 결정"은 관전자 함정 해법으로 *유지*(결정 없으면 순수 자동=관객).

**핀 후보(제안서 = `docs/03_reference/2026-06-25-core-pin-proposal.md`, 🟡판정대기):**
- **핀 A 주력 = 「관통선 처형」** = 오케 "선을 고른다" 정련. 군중 사이 한 줄 긋기(조준+발동)→선 위 커밋한 적 한 흐름 처형·호쾌함=걸린 수 비례·크레딧="선은 내가 골랐다". 기계선례=Warframe Slash Dash. 관전자함정방어 3겹=선선택+커밋보너스(06-24 흡수)+모멘텀체인.
- **핀 B 대안 = 「쇄도 처형」** = 대시 방향=선(조준 0, 입력단순, 단 결정얕음). A vs B 발산점=조준비용(Q3).
- 진부함 경계 직답=탑다운 런타임-공간 핀은 비어있음(해자, [[reference-distinctive-action-roguelikes]]).
- 판정 5문: Q1 톤갈림길(상위·gd권한밖)·Q2 핀A방향·Q3 A/B입력·Q4 읽고-베기거취·Q5 노브.

**관전자 함정 해법(레퍼 실측)**: DMC ×0.8(수동에 점수 더)·Hi-Fi Rush(자동싱크+타이밍보상). 우리는 화려함=돈 이코노미가 이미 절반 → 결정을 돈에 연동.

**How to apply**: 핀 제안 시 톤 갈림길(공포 vs 파워판타지)을 유저 판정 1번으로 명시. 메커니즘 충돌로 오해하지 말 것. 읽고-베기는 메커니즘 보존·관대화·톤 재배선이 권고(전면 폐기 아님).
