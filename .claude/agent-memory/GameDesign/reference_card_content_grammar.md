2026-06-13 v0.7 깊은 웹조사 (유저 지시 "직접 짓지 말고 레퍼가 *카드 내용을* 어떻게 설계하는지"). [[reference-roguelike-systems]]가 *구조/altitude*라면 이건 *카드 1장 내용 문법*. 전부 실측 인용.

**★두 altitude 분리 (중요 — 혼동하면 "PoE처럼 보여도 VS처럼 노는" 트리)**:
- **PoE = 메타 영구 트리**(수백 노드·리스펙·캐릭터 전체). *구조*는 20분 런에 안 맞음 → *노드 정체성 문법*만 훔친다.
- **Hades Boon/VS 진화/Brotato/Windblown = 인-런 드래프트**(한 런 ~10-15픽). = 우리 altitude.

**★v2 서바이버 보정 (2026-06-13, 유저 승인 + 오케 직접 조사 통합 — v0.7 "G0 금지"를 뒤집음)**:
- v0.7이 ARPG(PoE/Hades)에 과교정 → 서바이버 본진 조사로 두 군데 보정.
- **보정 A — 순수 +%는 금지가 아니라 *방향성 스노볼 연료층*.** Halls of Torment 레벨 80~100+(+데미지·+공속 반복) = *숫자 오르는 감각 자체가 도파민*. 못 없앤다. → **2층 분리**: 연료층(G0, 잦음, 가지 정체성 *방향으로* 흐름) / 정체성 스파이크층(G1~G6, 드묾, 가지 정의). 중립 +% ❌, "이 가지가 키우는 수치" ✅ = 연료 줍기도 *커밋 강화*(집중 강제 양립).
- **보정 B — G3 시너지가 *심장*, 가장 무겁게.** SoD Exodia 실측 = Clemency(피해→회복, G2) + Guidance(초과회복→실드, 그 회복을 *증폭* = G3) + Momentum(Frostbite에 평타 쿨감, G2) *서로 먹여주는 사슬*. 빌드 절정 = 고립 동사 ❌, *사슬이 돌기 시작하는 순간* ✅. → G3을 6클래스 중 하나에서 *문법 최상위*로. **가지마다 "서로 먹여주는 묶음"(엔진)을 의도 배치** + "이 가지 엔진" 한 줄.
- **확증 C — 집중 강제는 서바이버에서도 옳다.** Halls of Torment·Soulstone "다 못 올림 골라야" → PoE식 커밋 트리 장르 정당(유지 근거).
- ★G3 사슬 = "다른 카드 보유 시 효과 태어남"이라 코드에 `requires` held-predicate 필요(EffectKind로 표현 불가). 연료(G0)는 EffectKind+가지태그로 *지금 표현 가능*=절반은 이미 맞음.

**"+5% 함정" 답 = 카드를 6동사 클래스 중 하나로 (v0.7 실측 추적 — v2에서 G0만 복권):**
- **G1 규칙변경+대가 (PoE 키스톤)**: 스탯 0, *게임 규칙* 갈아끼우고 *반드시 한 가지 포기*. 실측: Resolute Technique("명중2배/크리 절대 안 터짐"), Chaos Inoculation("최대생명1/카오스면역"=생명회복 무용), Avatar of Fire("75%화염전환/비화염 데미지0"), Blood Magic("마나없음/스킬비용→생명"). → 가장 강한 정체성 노드.
- **G2 조건부 새 행동 (Hades Demeter Frozen Touch)**: "*피격당할 때* 빙결"=스탯 아니라 *조건*에 묶인 신규 행동. Dead Cells affix도 동일("X상태 적에게 Y").
- **G3 시너지 활성 (Hades Duo + Gunfire Gemini + Brotato 세트)**: 단독으론 없는 효과가 *두 축 교집합에서만* 태어남. 실측: Hail Storm(제우스+데메테르=빙결+번개 다중타격), Sea Storm(포세이돈+아폴로=대시마다 물구체). ★Gemini=같은 인스크립션 *양손 둘 다*(회색→보라 활성, 불일치=비활성)=*하드월 아님 보너스 유도*.
- **G4 임계 변태 (VS 진화)**: 누적 임계→*다른 형태*(조준/발사 모델 변경). 실측: Knife→Thousand Edge(단발→이동방향 끝없는 스트림, 조준="바라보는 곳"으로 변경), Whip→Bloody Tear(앞뒤 교대발사+크리 회복). ★*강화형 아니라 변태*.
- **G5 전환 증폭 (Windblown Alterattack)**: 무기/상태 *전환 순간* 시그니처 발동, 카드가 그 전환을 키움.
- **G6 대안 정체성 (Hades Aspect + SoD Memory 대안)**: 같은 베이스의 *다른 동사 버전*(업글 아니라 *대체*). ★실측 Aspect of Guan Yu(창): 스페셜이 *회수불가·원거리 AoE·흡혈* = 완전 *다른 무기*(빠름/느림 아님).
- **G0 순수 +%**: ★**v2 복권 = 방향성 스노볼 연료층**(v0.7 "❌ 금지"는 폐기). 잦고, 가지 정체성 방향으로만 채널. 대가 없음(그게 스노볼 쾌감) — 방향성이 기회비용 대신.

**★레어도 ≠ 동사 (Hades 추적)**: 레어도(Common→Heroic)는 *숫자만* 커짐. *새 동사*는 *다른 카드*가 줌. "20%공속(20히트/초 곱)>70%평뎀1회"=시너지>생뎀.

**분기를 *구별되는 극단*으로 가르는 3장치**:
1. 다른 *동사* (Hades Aspect): 같은 동작 빠르게 ❌ → 동작 자체가 다름.
2. 다른 *대가* (PoE 키스톤): 분기마다 포기하는 게 다름 → *서로 약점이 반대*, 빌드가 약점 메우는 방향으로 자람.
3. 다른 *시너지 풀* (Brotato 세트+PoE 클러스터): 분기 선택이 *이후 카드 생태계* 가중을 바꿈.

**솔로 스코프 실측 (캘리브레이션)**:
- 20MTD: 레벨업당 5택1, 무기 진화는 *레벨20에 1회 3택*, 리롤은 *특정 캐릭터 고유 특성*(보편 아님). → 소규모 authored로 충분히 깊다.
- Death Must Die: 런당 *신 3명까지*(채우면 나머지 안 뜸)=드래프트 *집중 게이트*(빌드 쏠림=정체성).
- Windblown: 무기 적음·깊음(MonHun 영감), 깊이=*수* 아니라 *상호작용*.
- Hades: 무기6×Aspect4=authored 소수, 무한 다양성은 boon *조합*.

**Why**: 유저 동결 규칙=임의설계 폐기·레퍼 추적. 핵심질문 답이 전부 여기 근거.
**How to apply**: 카드/노드 내용 제안 시 G1~G6 중 무엇인지 명시 + 레퍼 추적. 순수 +% 카드는 받침대 외 금지. 분기는 3장치(동사/대가/풀) 전부 만족하는지 검사. 스코프는 무기당 ~7 authored·동사 100% 손설계.
