2026-06-14. v1(연쇄 가속 테제·連殺流 3분기) → **★v2 탑다운 상세 스펙으로 전면 재작성**(유저 일갈: "단순 연출 카피 금지, 탑뷰 45°/15m에서 실제 입력·작동·읽히는지 세세히"). 산출 = 제안서 §17.1 통째 교체 + §17.0 엔진맵 칼 2행 교체. docs/03_reference/2026-06-13-weapon-progression-proposal.md §17.1.A/B/C.

**★v2 구조 = 독립 2트리(連殺流 3분기 폐기, 유저가 "거합/참격 2개를 깊게" 지정)**:
- **거합 트리** (§17.1.A): 정지 충전 발도, 킬 환류 가속. 레퍼=MGR 잔타츠(킬=재충전, 우리 추출코어 동형)+GoT.
- **참격 트리** (§17.1.B): 위빙 콤보 가속(베기 적중=충전, 피격=리셋), 임계 5단→참격파. 레퍼=GoT 스탠드오프 스트릭+무쌍 격노.

**★실측 코드 위에 얹음 (진공설계 탈피 — 이게 v2 핵심)**: PlayerCombat.cs + MeleeAttacker.cs 정독.
- 조준=`_aimDir`(마우스→지면투영, 몸 안 돎). 기본공격=좌클릭 홀드→쿨마다 `Swing`. 판정=`OverlapSphere(range+0.5)` + 부채꼴 `arcHalfAngle` 필터, 초근접 0.9m(`PointBlankRadius`) 각도무시, 벽 occlusion 레이.
- 히트스탑=피격자 전용(`TakeMeleeHit(...,hitstop)`), 전역 timeScale 금지.
- ★거합 차지 = **기존 우클릭 정조준 + 수렴 의식(`_convergeTarget`→2x) 재활용**(새 시스템 최소화). 발도 돌진 = 캡슐 캐스트(직선, OverlapSphere 아님 — MGR 절단선).
- 색: 시안=수렴/킬(아군 차지·발도=시안), 마젠타=신호붕괴(아군 베기에 금지), 적색=적 장판(아군 금지). 텔레그래프=ThreatArc SDF 재활용, killburst 재활용.

**★탑다운 7항목 다 채움**(이게 유저 요구): 입력/기하(미터·각도 전부 숫자)/45° 가독(무엇으로 안 뭉개지나)/타이밍(초)/노브 시작값/1초 단위 루프/탑다운 함정(스냅어시·정지=충전 가독·벽관통·카메라밖). ★텔레=**발밑 링/호**(머리 위 아님 — 부감 가림, §grammar 원칙4).

**구별(§17.1.C)**: 충전동사(정지↔적중)·방출(직선돌진↔확장부채꼴)·대가(평타−40%↔리셋)·위치(거점↔유동) 4축 정반대. 같은 카타나 두 다른 게임.

**상태 = 🟡 오케 합치 대기.** 동결 권한 없음.
**⚠️재정합 잔무(다음 패스)**: §17.8 트리표·§17.10 지배친화·Q41·아키타입표가 아직 구 "카타나↔대검 점/면" 표기. v2는 카타나=거합/참격 내부 2트리 → 대검은 별도 무기 표기로 일괄 갱신 필요. §17.7 line은 갱신함(구 표기 충돌 명시).
**미해결**: 작업명(거합/참격/발도/참격파)→Story 렉시콘. 참격 위빙이 서바이버 고밀도서 위협 가독 충돌 안 하나(콘 면제 캐넌으로 완화). 거합 정지가 호드 한가운데서 위험 vs 보상 균형(노브).

**Why**: 유저 일갈의 핵심 = *연출 형용사가 아니라 메카닉·숫자*. "탑뷰인 걸 알고 짜라" = 부감 기하(발밑 텔·캡슐캐스트·15m 최소크기)·트윈스틱 함정(스냅·정지충전 가독)이 본진.
**How to apply**: 오케 합치 후 §17.1 동결되면 노드명 Story 의뢰 + enum/캡슐캐스트/게이지 환류 Gameplay 인계. 재정합 잔무 먼저 정리.
