2026-06-13 웹 심층조사. 유저가 "런 밖 재화 사용처가 가장 부족"이라 직접 지목 → 메타 경제 8게임 추적. 각 게임 "훔친 메커니즘 1 + 우리 적용".

**Hades II (메타 경제 교과서 — 다중통화+그리드)**:
- 다중 통화: Bones·Moondust·Gold·Fate Fabric·Cinder·Star Dust. Arcana 카드(=Mirror 후속) 영구 강화.
- ★**런 중 Gold 1000당 → Obol → Moondust 4 환전** = 런 내 경제↔메타 경제 *끊김 없이 흐름*. Bones로 Wretched Broker에서 Moondust 구매.
- ★**그래스프(Grasp) = 제한 포인트** — Arcana 아무 조합 장착 가능하나 Grasp가 총량 제한 = *전부 못 켬*(선택압). Grasp 자체를 런 간 업글.
- ★영구 업글 **비가역**(Moondust 환불 불가, Consecration of Ashes로 3단 강화) → 신중한 계획.
- Cinder/Star Dust=희귀 통화 → 최상위 크래프트 게이트(고난도 보상).
- **우리 적용**: 환전 다리(메모리→현금=추출정산) + 메타 그리드 선택압(Grasp=업그레이드 그리드 제한 포인트) + 희귀자원=질적 게이트(③).

**Hyper Light Breaker (★2층 추출 분리 — 우리 stake 골격)**:
- ★**영구(사망 보존)**: Golden Rations → Player.EXE(영구 퍽: 투사체 패링·시작기어) + 벤더 관계(가격·상품 해금). The Vault(잉여 장비 보관, 다음 런 회수).
- ★**임시(사망 손실)**: Cores → SyCom 능력 런 내 레벨업(매 사이클 리셋). 런 내 장비(Vault 미보관 시 소실).
- 추출=안전 귀환(잃는 것 0, 장비·자원 보존). 사이클=부활 소진 or 추출 4회.
- **우리 적용**: 재화 구조 골격(현금=Golden Rations 위상 영구 / 메모리=런 루트 위상 휘발) + 추출 stake 정합(영구 통화는 사망에도 보존 = 복리, 런 루트만 stake).

**Escape from Tarkov (은신처 = 머니싱크 모듈)**:
- 은신처 모듈: 스태시(인벤↑)·작업대(제작 해금)·발전기(전력+연료 소비)·비트코인 농장(패시브 인컴)·인텔센터(보험/쿨다운)·의무실(힐 제작).
- 모듈 업글=영구 천장 상향이 *다음 런을 바꿈*(스태시↑=더 들고 나감). 모든 재료 FiR(Found-in-Raid) 전용.
- **우리 적용**: 사용처의 *디제틱 모듈* 프레임(사무실=경량 은신처). ⚠️**안 가져옴**: 공간 퍼즐·FiR 그라인드·연료 시뮬·비트코인식 패시브 인컴(우리 톱다운 액션 템포에 무거움, 본진=전투지 기지경영 아님).

**ZERO Sievert (톱다운 추출 현금흐름 — 장르 표준 증명)**:
- 줍는것→트레이드→벙커 모듈·워크벤치 업글 + gun XP 퍽 + player XP 영구 퍽. 힐/수리 비용도 글로벌 트레이더 통화로.
- **우리 적용**: 메모리→현금→보급이 *변종 아님 = 톱다운 추출 장르 표준* 확증(Q3 모순). 벙커 업글=우리 보급 티어 직계.

**Dead Cells vs Rogue Legacy (★성장 체감의 분기 — 결정적)**:
- ★**Dead Cells**: 셀(Cells)→영구 *해금*(무기/뮤테이션/플라스크). *스탯이 아니라 옵션*(더 많은 무기·경로). "전투 시스템 숙련에 보상". 후반 난이도=플라스크 리필 제거(난이도 아크).
- **Rogue Legacy**: 골드→성 업글(증분 스탯 트리 HP+5%…). 일부 "지겨운 그라인드"로 느낌. RL2=장비 무게·룬 슬롯·클래스 마스터리로 깊이. 런 끝 골드 *전액 몰수*(쟁여두기 방지).
- ★**핵심 차이 = 의미있는 선택 아키텍처.** Dead Cells=숙련 보상(옵션), RL=숫자 누적(완성주의자용).
- **우리 적용**: ★성장 철학=**Dead Cells "옵션 not 스탯"으로 강하게 기움**(액션 파워판타지=숙련 표현이지 숫자 누적 아님). 영구 그리드/보급=옵션 확장, 무한 누적 ❌. 단 약한 베이스 스탯 혼합(VS식 즉각 도파민). RL 몰수는 우리 stake와 결 다름(우리는 추출 성공분 보존) — 단 "쟁여두기 방지" 교훈만.

**Slay the Spire (메타=파워 아니라 풀+난이도)**:
- ★언락(카드/유물 풀 확장) + 승천(Ascension) 난이도 래더. 영구 파워 *증가 아니라* 풀 다양성 + 도전 상향.
- **우리 적용**: 보급 티어=카드/Aspect 풀 확장(파워 아닌 옵션) + 미션 티어=승천식 난이도 선택(코어 §4 미션 티어 정합).

**Hunt: Showdown (★바운티 = 회피-최적 해소)**:
- ★바운티(목표) 중심 — 루트 호딩이 아니라 *바운티가 전투를 강제*. 계정 레벨 영구 해금 vs 헌터(런 캐릭터) 퍼머데스 2층. 공격적/신중 둘 다 유효(한 전략 지배 ❌).
- **우리 적용**: ★**Codex 회피-최적 긴장 해소의 핵심** — 우리 할당량(처리 카운터)=바운티. **처리해야 CanExtract 열림 → 회피하면 퇴근 버튼 안 켜짐**(이미 06-13 코드). 추출 stake 2층(현금=영구 해금 / 메모리=런 자산 소실).

**채택 보류**: Returnal·Risk of Rain 메타(얕은 영구 해금, 새 레버리지 약함). Backpack Hero/Duckov 베이스(§2.4 이미 추적, 인접그리드 채택 안 함).

**Why**: 임의설계 폐기=레퍼 추적 의무(유저 동결). 메타 경제는 우리가 안 풀어본 빈칸이라 깊은 조사 필수.
**How to apply**: 메타 경제/재화/사용처 신규 제안 시 이 8게임 매핑부터 대조. 특히 ①HLB 2층(영구/임시 분리=stake) ②Hades II Grasp+환전(그리드 선택압+런내외 다리) ③Dead Cells "옵션 not 스탯"(성장 철학) ④Hunt 바운티(회피-최적 해소=할당량). 근거 없는 발명=최악 산출물.
