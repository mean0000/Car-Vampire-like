2026-06-15 코어루프 가설(흩어진 군집→급습 한방 즉발성장 OR 정면→발각시 호드폭발→정리하며 성장→다음군집, 익스트랙션 없음) 검증 리서치. 임의설계 금지 추적.

**핵심 판정 — "급습+호드+성장" 한 게임 결합은 드묾(부분만 존재). 함정 아니라 빈 공간.**
누구도 셋을 *동시에* 안 한 이유는 어려워서가 아니라 장르가 갈라져서임: 스텔스액션(급습O 호드X 성장X)·호드서바이버(호드O 성장O 급습X)·로그라이트(성장O 방클리어O 군집생태X). 우리 결합=빈 공간. 단 각 조각의 검증된 메커니즘을 빌려야지 발명 금지.

**문제1 (급습할 기계적 이유) — 검증된 답들:**
- ★Dishonored: 미발각 유지 시 **아드레날린 게이지**가 차서 *발각 후 전투가 더 강해짐*. "no trouble"이 아니라 진짜 기계 이득. 우리 잠정안(급습 첫일격=즉발성장)과 동형. 차용 1순위.
- 백스탭 배수 실측: Valheim 3~10x, Skyrim 30x. 급습=프론트로드 파워는 *큰 배수*로 튜닝됨(미지근한 +20%는 무시당함). 우리 "급습=앞당긴 파워"는 과감해야 작동.
- ★반례 Intravenous 2: 고스팅 보상=오직 "no trouble"(맵 탐색 막힘만). 순수 회피보상=약함. → 급습엔 *능동적 이득*(성장/화력)을 박아야지 "안 깨우면 편함"만으론 우성전략 못 됨.

**문제2 (플레이스타일 쿠션, 둘 다 살리기) — 검증:**
- ★Desperados III가 정답형: 발각=리로드 강제 아님. 정밀 사격(랜덤 제거, 항상 명중)+유한 증원풀 → "발각돼도 총싸움 이길 수 있음". 적대존에선 어차피 상시 적대 → 정면이 처벌 아닌 *전략 선택*. Shadow Tactics(발각=거의 리로드)와 대비.
- ★반례 Dishonored 1: 스텔스 플레이어용 진행 보상이 빈약 → 한쪽만 보상. Dishonored 2가 양쪽 밸런스로 수정. 교훈=한 스타일만 보상하면 다른 스타일이 벌받음(=우리 우려 그대로).
- 우리 잠정안(급습=앞당긴 파워·안전요구 / 정면=즉각 카오스·콤보멀티 잘 쌓임, 둘 다 호드전 수렴) 정합.

**문제3 (발각→호드 리듬, 다시 소강) — 검증:**
- ★L4D AI Director 4상태: Build-up(위협인구 풀+스폰)→Sustained Peak(짧게 유지)→**Peak Fade(위협인구 최소·신규스폰0, 기존만 잔존)**→stress가 peak임계 밑으로 decay하면 다음상태. = 호드는 *벌/사건*이고 스트레스 감쇠로 자동 소강. 이미 zombie-roster-director 메모리에 채택됨.
- DRG:S 하드넘버: 동시 어그로 캡 32지상+32공중/플레이어. 스폰=난이도포인트 예산(웨이브당 20~40pt, Grunt10·Swarmer6·Spitter25pt 합산). 시간경과=적 강화 메시지. → 호드 "폭발"의 상한·구성을 예산제로.
- RoR2: 디렉터 크레딧 시간선형 증가, 약한적은 "너무 싸면" 스폰 안함→시간갈수록 잡몹 사라지고 고급화. = 성장에 맞춰 위협 질 상승(우리 두 축 철학 정합).
- Hades II Trial of Gods: 보상 거절=거절당한 신이 *무장 웨이브 소환*. 호드=선택의 대가(벌-as-이벤트)의 깔끔한 모델.

**차용 Top5 (구체→적용):**
1. Dishonored 아드레날린형 — 급습 첫일격=즉발 strain 대량+그자리 강화(앞당긴 파워). 배수 과감히.
2. L4D Peak Fade — 발각호드는 스폰0+기존잔존+stress decay로 소강. 무한분출 금지(=잠입 죽임).
3. DRG:S 예산제 호드 — 발각 폭발을 난이도포인트 예산+어그로캡으로. 시각카타르시스는 풀, 실제 동시교전은 캡.
4. Desperados 유한증원 — 정면진입도 이길 수 있게(처벌 아닌 선택). 증원 유한.
5. Brotato/VS 즉발 도파민 — strain 즉발드랍→즉발레벨업, 몇초마다 좋은일. 회수없는 보상엔진=리플레이.

**회피 실패사례:** Intravenous2(회피보상만=약함)·Dishonored1(한스타일만보상)·Shadow Tactics(발각=리로드강제, 정면 비non-viable)·DarkSwarm(트레일러 물량≠실제, 느린호드)·미지근한 배수(급습+20%=무시).
