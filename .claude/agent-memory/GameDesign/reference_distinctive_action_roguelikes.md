2026-06-25 Explore 조사(유저 "요즘 게임 자기특색 강함, 진부함 경계"). 12+게임 실측. 출처 URL은 project_pin_point_hunt 산출 제안서 참조.

**★최대 발견 = 탑다운/아이소 로그라이트의 "잘해 보임"은 거의 다 *사전 빌드 결정*에 산다, *런타임 액션 입력*이 아니라.**
- 사전빌드형(빌드 고를 때 화려함 결정): Hades II(무기×Aspect20×Boon 3층)·Brotato(6무기 동시발사)·Balatro(Joker 배치→포커 수식 폭발)·Vampire Crawlers(카드순서→배수스택)·Mewgenics(번식→그리드)·Caves of Qud(뮤테이션70).
- 런타임입력형(그 순간 손이 화려함 만듦): **Megabonk**(점프·슬라이드 1/60초 정밀=검 서핑, 단 3D)·**Windblown**(무한대시+2무기 Alterattack, 아이소). 둘 다 *이동 기반*.
- → **탑다운 단일 평면에서 "런타임 단일 입력의 공간 결정"으로 파워판타지를 준 사례 = 거의 비어 있음.** 우리 핀("선을 고른다")이 여기 = 해자(진부 아님). Slash Dash(3D)가 가장 근접 선례.

**관전자 함정 회피 공통 비결(전 게임)**: *게임이 자동으로 화려하게 하는 부분*과 *플레이어가 결정하는 부분*을 명확 분리. "게임의 화려함≠내 화려함"이 아니라 **내 선택이 화려함의 *형태*를 결정**. (Hades II=Boon자동폭발이 화려하나 어느Boon은 나 / Brotato=자동발사지만 무기유지·버림 반복판단 / DRG:S=오토슈팅이지만 채광경로는 나.)

**진부함 경계(06-24 메모교훈 정합)**: 신선함=피치 아니라 *실행*. "대시-슬래시"는 한문장 흔함. 우리 신선=실행(탑다운+군중밀도+화려함=돈 연동+커밋타이밍 결정).

**주목 신작(우리 톤·메커니즘 인접)**:
- **Go Mecha Ball**(아이소·트윈스틱): 적 차징 중 치면 캔슬+탄약드롭→공격적플레이 권장. = 06-24 "커밋한 적 보너스"가 *공격적 파워판타지* 톤으로 작동하는 선례(처벌 아닌 보너스).
- **Dark Light: Survivor**(2025 EA): 탑다운↔3인칭 전환, 약점조준(3인칭)·회피(탑다운) 트레이드오프 — 우리 단일평면 동결과 대비.
- Shape of Dreams(레퍼 앵커): MOBA식 탑다운, Memory 4개+100개 선택(사전빌드형).

**How to apply**: 핀 후보가 진부하냐 물으면 = 콘셉트는 흔해도 *탑다운 런타임-공간 결정*은 비어 있다고 답. 관전자 함정 해법은 "결정이 화려함의 형태를 정하게". 사전빌드 화려함(카드/무기)도 우리에 이미 있음(병행 OK)·핀은 *런타임* 층을 채움.
