# VS류 "보호·영토·구조액션" 선례 추적 (2026-06-16)

조준형 로그라이트 뱀서(20MTD형)로 급진 재설계된 척추 위에 "사후처리부"(시민 보호) 개성 4기능 평가용. 웹리서치 결과.

## 핵심 정합 사실: VS 코어 = 카이팅
- VS의 유일한 방어는 **이동(움직임)**. 정지=초보 실수, 항상 적을 원형으로 끌고 다니며 젬 줍기. 무기는 자동발사, 플레이어는 포지셔닝만. (lostatticgames / nme 리뷰)
- 함의: **한 곳 사수(농성)·고정 점거(영토)는 카이팅 본능과 정면 충돌.** 이게 1차 감사 기준.

## 선례별 결론
- **DRG: Survivor 에스코트 모드** = "캡처존에 머물며 타이머 닳을 때까지 호드 버팀". 우리 격리구역/농성과 거의 동형. 평가=호불호 갈림. 호평="클린 런=진짜 성취감, 보상 큼". 악평="고난도 밸런스 미검증, 스폰 불만". → **정지 디펜스는 VS에 *모드로* 얹힐 수 있으나 항상 마찰을 낳는다(상시 척추로 만들면 위험, 간헐 이벤트면 작동).**
- **Death Must Die** = "포지셔닝 게임 → 반응 게임으로의 전환"(닷지롤 추가가 핵심). 제네릭 최초의 진짜 진화로 평가. **액티브 회피/스킬이 VS에 정당하게 들어간 선례.** 우리 "구조 패링 대시"의 직접 근거. 단 DMD는 *상시 회피*지 특정 트리거 한정이 아님.
- **Monsters are Coming! Rock and Road** = VS+타워디펜스 멀티장르. 영토/디펜스가 VS와 결합 가능함의 증거(단 "frantic 멀티장르 밸런싱"=과설계 위험 신호).
- **Escorted (itch)** = 에스코트 반전(NPC가 주인공 보호). 보호 대상↔보호자 관계 재설계의 인디 실험.

## 적용 원칙(이 게임)
- 보호/농성/영토는 **간헐 이벤트(미션 변주)로는 검증된 길**, **상시 척추로는 카이팅과 싸움**.
- 액티브 패링/대시는 DMD 선례로 정당 — 단 *상시 회피 동사*로 넣어야지 "시민 피격 트리거 한정"은 좁고 작위적.
- 멀티장르 동시구동(보호+영토+패링+호드+보스게이지)=과설계. VS 미덕=적은 규칙·깊은 창발.
