2026-06-13 웹조사. 핸드오프 §4 레퍼 추적. 각 게임이 우리 무기·성장 문제를 푸는 법.

**Shape of Dreams (전투 본진 레퍼 — ★유저 지목 최우선, 2026-06-13 심층 재조사로 정정)**:
- ★**얕은 "샤시·엔진" 메모는 불완전. SoD = 3층 하이브리드, 순수 draft 아님**:
  - **Traveler(히어로)** = authored 고정 정체성 + *캐릭터 전용 패시브 트리*. 런 시작 시 선택(고정 킷).
  - **Memory ×4슬롯** = 액티브 스킬(핫키). 보상/상점/바닥 획득, ★*대안 버전이 플레이스타일 통째 뒤집음*, Well에서 업글(주력 먼저 키움). = 반-드래프트(슬롯 고정, 무엇/어떤 대안이냐가 변수).
  - **Essence(젬)** = 패시브 모디파이어. ★자유 스왑(런 중 언제든) + 중복 자동 융합(고품질화). 락인 없음 = draft 극단.
- 메타=Dream Dust: 안쓰는 Memory/Essence 해체→Dust→Well 영구강화. 초반좌절 해소=런간이 런내 천장 연다.
- Hunter 방=들어갈수록 위협↑보상↑(단일 강적 교전이 빌드 시험대). = 우리 정예+추출 stake 선례.
- **우리 역산**: ★빌드 *뼈대=authored*(Traveler+어떤 Memory) / *살=draft*(Essence 자유 융합). 우리는 이 구조를 *이미 절반 가짐* — 무기6+Aspect+드론=Traveler+Memory 역할, 카드=Essence 역할. 빠진 건 별도 트리가 아니라 "조각들이 SoD식 하이브리드로 정렬됐다는 선언"(제안서 §13).

**Hades II (성장 구조 모델 — 3층)**:
- Arcana(런간·영구): 제한 포인트 그리드, 첫방 전 패시브빌드. "영구파워 최대 단일소스", Moondust 업글.
- Boon(런내·방단위): 신이 방클리어마다 제안, 매런 빌드심장. 단일 데미지타입 집중=시너지 선명(혼합=희석).
- 주무기 Aspect(런시작): 6무기 각 3+1 Aspect, 같은무기 완전다른 플레이(Argent Skull→Medea="수류탄서핑").
- 6무기 매핑: Witch Staff(올라운더 베이스=권총), Sister Blades(속도근접=칼), Moonstone Axe(묵직느림=몽둥이), Umbral Flames(지속스페이싱=라이플), Argent Skull(근접고위험=샷건), Black Coat(맨손=주먹).
- **우리 역산**: 3층=런간그리드(Arcana)+런내카드(Boon)+무기Aspect(보급티어 해금).

**Brotato (인-런 무기강화)**:
- 무기 4티어, 같은무기 2개 병합→1티어↑. "2~4종 집중" 권장빌드.
- **우리 역산**: 우리는 메모리=납품(소실)이라 인벤병합과 충돌→병합은 런간 보급티어로 흡수. "2~4종 집중"=동시장착 제한 시사(주무기 슬롯 2개 제안).

**Backpack Battles / Duckov (추출경제)**:
- Backpack=인접배치 시너지. Duckov=워크벤치 부착물 슬롯해금.
- **우리 역산**: 슬롯해금=보급티어가 모드슬롯 여는 구조. 단 인접그리드 인벤은 톱다운 액션에 무거움→공간퍼즐 채택안함, 슬롯끼움 단순형만.

**합성 4층 지도**: 무기=샤시(SoD+HadesII주무기) / Aspect=변형(HadesII) / 런내카드=엔진(SoD Essence+HadesII Boon) / 런간그리드=영구(HadesII Arcana+SoD DreamDust).

**★최신작 6종 보강 (2026-06-13 v0.2, 유저 지시 "최신·다양 레퍼 추가")** — 각 게임 훔친 메커니즘 1개:
- **Windblown(2024, 데드셀 후속)**: ★스왑 어택(Alterattack) — 두 무기 휴대, 한 무기로 히트 쌓다 *다른 무기로 스왑하는 순간* 그 무기 시그니처 발동. 보너스=히트수×페어궁합, Super/Ultra=더 오래 쌓고 스왑. → **우리 §3.4.1: 슬롯 2개를 핫스왑(편의)에서 *콤보 피니셔 발동기*로 격상.** "묵직→체인지"가 발동 가능한 동사로. Q7.
- **Hyper Light Breaker(2025)**: ★SyCom 서브클래스 — 런 시작 드론이 베이스 스탯+코어 패시브 규정, 메타로 업글/해금. 추출=영구보존/사망=리셋. → **우리 §5.3 ③ 캐릭터 베이스 정체성 검토층(플레이어블 2종 정합). Q8.** + Golden Rations=추출 현금경제 선례.
- **Gunfire Reborn**: ★인스크립션 Gemini — 같은 모디파이어 2개 모으면 특수효과. "완벽인스크립션 평범총>어긋난전설". → **우리 §5.3.1 모드 슬롯에 세트/공명 차원**(같은태그 2개=공명). 자원축 공명 철학을 모드 층에도. 하드월 아님(보너스 유도).
- **Roboquest(2023)**: ★베이스캠프 업글이 무기 affix·alt-fire를 *해금* — 강해지는게 아니라 *잠재력 풀 확장*. → **우리 §5.3 ① 보급티어=잠재력 해금 재정의.** 코어 §4.3 "더 높이 클 도구"의 정확한 메커니즘. 플랫파워 0, 천장만 상향.
- **Death Must Die(2023)**: ★Class Sign — 메타 해금 패시브를 런 전 슬롯. → **우리 §5.3 ② 그리드 제한포인트 선택압 지지**(Hades II Arcana와 독립 수렴).
- **ZERO Sievert(2024, 톱다운 싱글 추출슈터)**: ★줍는것→트레이드/벙커모듈→현금·gun XP 퍽. → **우리 Q3 모순 확증**: "줍는것=설계도/부품"(폐기) 아니라 "메모리→현금→보급"이 *톱다운 추출 장르 표준*. E-002가 변종 아님 증명.

**채택 보류(새 레버리지 약함)**: RPoP·Ravenswatch·DRG:S(호드지형은 LevelDesign 보유)·Soulstone·Halls of Torment·Megabonk — 이미 추적한 메커니즘 변주.

**Why**: 임의설계 폐기=레퍼추적 의무(유저 동결). 모든 제안에 "레퍼 X의 Y 추적" 명시.
**How to apply**: 무기·성장 신규 제안 시 이 4게임 매핑부터 대조. 근거없는 발명=최악 산출물.
