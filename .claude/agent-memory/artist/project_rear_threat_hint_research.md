후방 근접 위협(~8m) "청각의 시각화" 힌트 기법 리서치 완료(2026-06-12), 유저 판정 대기. 권고=1안: A1 헤드 룩앳 IK(머리70%+가슴15~20%, 8m 간헐→4m 지속) 척추 + 4m부터 발치 아크 펄스(무채, 가장자리 노이즈 침식) + 2m 기존 공격모션 실물 공개. 조준 중엔 평시 힌트 페이드아웃→콘 어둠 국소 꿈틀이 인계.

**Why:** 시야 콘 정보 게이트 채택 후 LOS 공정성 완충 4종 중 "360°" 슬롯의 시각 언어. 정답 UI 금지 — 음악 3단이 강도를 소유하므로 시각은 방향만 담당.

**How to apply:**
- 구조 전제 1: 콘 어둠·탈색 비주얼은 전부 조준 게이트 — 평시 상시 힌트는 콘 마스크 변조로 못 만든다(조준 채널 전용).
- 구조 전제 2: 풀스크린 힌트가 필요하면 렌더러 피처 말고 **Screen Space Overlay 캔버스**(포스트·SyncGlitch 이후 합성이라 순서 문제 면제, sortingOrder ~10).
- 기각 확정: 림라이트(15m 픽셀 단위), 가장자리 색수차(글리치 어휘 오염), 동심원 링 상시용(정답 UI), 먼지 퍼프(작은 파티클 함정), 지면 라이트(COZY 시간대 가독 출렁임).
- 색=무채/회백 단일([[phase-split-afterimage]] 색 캐넌 보존). LKP 스미어 블롭 쓸 경우 양자화 0.5~1m+갱신 0.5s+점멸 3종 완화 필수, InkBlob 셰이더([[purge-snapshot-fx]]) 재활용 가능. B/C/D군 중 하나만 — 합산 화면 점령 금지.
