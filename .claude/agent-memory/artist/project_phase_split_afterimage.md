대시 잔상이 PsyOps풍 "위상 분리"로 업그레이드됨 (PlayerAfterimage.cs, 2026-06-11). 스폰 1회=마젠타+시안 고스트 페어, 가산(SrcAlpha,One)+HDR(×2.5)로 겹친 초기엔 화이트 코어, t에 따라 진행방향 수직축으로 0.02→0.14m 분리. 대시 중 스트레치드 빌보드 스피드 스트릭 PS(수동 Emit ~40/s) 동반.

**Why:** 디제틱 — 나노봇 신호가 이동 속도를 못 따라와 채널이 갈라진다("위상 잔류"). 색상 예산: 시안(0.35,0.75,0.85)=정상 신호(기존 캐넌), **마젠타(1.0,0.17,0.84)=신호 붕괴/규정 외(신규 캐넌)**, 빨강 금지. 다크 무드라 가산+HDR로 블룸 통과 — 킬 링·머즐 플래시와 같은 문법.

**How to apply:** 이후 "규정 외/신호 붕괴" 계열 VFX는 이 마젠타를 쓴다. PlayerController는 _dashDir 비공개 — 잔상류는 위치 델타로 방향 추정(컨트롤러 수정 금지 관행). 시간축은 scaled 유지(히트스탑 중 잔상 정지=정합). 페어 구조라 풀 워밍업 ×2 필요. [[sync-glitch-fx]]처럼 Particles/Unlit 빌드 Always Included 이슈 공유.
