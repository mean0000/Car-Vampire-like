> 트리거: Stab + Codex 합의 비판 — "MVP 스코프 과대 → 가설 검증 단위로 쪼개야"

## 0. 이 문서의 목적

GDD v0.2 §15에서 정의된 MVP는 *Early Access 직전 단계*에 가깝다.
1인 개발 + 가설 미검증 상태에서 그걸 한 번에 만드는 건 위험하다.

이 문서는 MVP를 **검증할 가설 1개 = 1단계** 원칙으로 α/β/γ 3구간으로 쪼개고,
각 단계마다 plug를 뽑을 **명확한 게이트 조건**을 명시한다.

가설이 단계별로 통과하면 다음 단계로 진입하고,
가설이 깨지면 다음 단계 비용을 쓰기 전에 코어 디자인을 재검토한다.

## 1. 분리 원칙

### 축: 검증 가설 1개 = 1단계

| 원칙 | 의미 |
|---|---|
| **가설 단위 분리** | 한 단계는 하나의 핵심 가설만 검증. 변수 섞이면 실패 원인 추적 불가. |
| **게이트 조건 사전 정의** | 단계 종료 = 사전 합의된 측정 조건 충족. "감으로 OK" 금지. |
| **이전 단계 = 다음 단계 토대** | β는 α를, γ는 β를 그대로 확장. 단계마다 폐기·재작성 X. |
| **plug-pull 시그널 명시** | 가설 실패 시 무엇을 보면 알 수 있는지 사전 합의. |

### 분리 축 후보 비교 (결정 근거)

| 축 | 채택 | 사유 |
|---|---|---|
| 검증 가설 | ✅ | Stab/Codex 비판의 직접 해법. 게이트가 분명. |
| 위험도 / 기술 난이도 | ❌ | 단계 간 가설 분리가 안 되어 검증 효과 약함. |
| 1인 개발 부담 (작업량) | ❌ | 만드는 입장에선 편하지만 *재미 검증*이 안 됨. |

## 2. 단계 요약 표

| 단계 | 검증 가설 | 스코프 한 줄 | 게이트 조건 (요약) |

| **α** | "차로 좀비 갈아엎는 게 그 자체로 재미있나" | 차량 1대(Daily), 무기 1, 적 1~2종, 무한 평지, 5~10분 단판 | 외부 테스터의 ≥70%가 죽은 직후 30초 안에 "한 번 더" 자발 재시작 |

## 3. α — 충돌 검증

### 3.1 검증 가설

> **"차로 좀비를 갈아엎는 행위 자체가 30초 안에 '한 번 더'를 끌어내는가."**

뱀서식 카타르시스의 코어. 메타·BGM·돌파 다 빼고, *손맛 하나만* 검증.
이게 안 되면 그 위에 어떤 메타를 얹어도 무너진다.

### 3.2 스코프

| 포함 | 제외 |
|---|---|
| 차량 1대 (Daily) | 차량 선택 |
| 자동 기본 무기 1종 (출격 중 픽업 없음) | 모듈, 픽업, 레벨업 |
| 적 1~2종 (걷는 좀비 + Herd 없는 단순 분포) | 좀비 Herd, 미니맵 마커 |
| 무한 평지 (텍스처 1종) | 부서진 도심, 환경 떠먹임 |
| 5~10분 단판 (시간 종료 = 자연사) | 거리 보상 곡선, 자원 시스템 |
| 죽음 → 즉시 "한 번 더" 버튼 | 집, 결과 화면, 메타 |
| 충돌 피해 모델 (욕심으로 죽도록) | BGM, 돌파, 사운드 큐 |

### 3.3 게이트 조건 (정량)

| 지표 | 통과 기준 |
|---|---|
| 자발 재시작률 | 외부 테스터 5~10명 중 ≥70%가 죽은 직후 30초 안에 재시작 |
| 평균 단판 길이 | 3~7분으로 자연 수렴 (너무 짧으면 코어 약함 / 너무 길면 페이스 문제) |
| 첫 반응 키워드 | "재밌다 / 시원하다 / 한 판 더" > "지루하다 / 짜증나 / 별로" |

### 3.4 가설 실패 시 plug-pull 시그널

- 테스터들이 "그냥 무쌍 게임 같다 (지루함)" → 충돌 피드백·카메라·사운드 코어 재설계 필요
- 평균 단판 길이가 1~2분에 수렴 → 죽음이 너무 빠름 = 학습 곡선 문제
- "한 번 더" 본능 < 50% → **자동차 뱀서라이크 컨셉 자체 재검토**. β 진입 금지.

### 3.5 Codex 비판 흡수

> Codex: "15분 중간값 애매 — 초반 5분 임팩트 보강 필요"

→ α 자체가 "초반 5분 임팩트"의 직접 검증. α 통과 = 초반 임팩트 확보 증명.

## 4. β — 귀환 본능 검증

### 4.1 검증 가설

> **"BGM 컷 전환 + 좀비 Herd + 거리 보상 곡선만으로,
> UI 알림 0개 상태에서 플레이어가 자발적으로 멀리 가고 자발적으로 돌아오는가."**

GDD 디자인 원칙 4번("강요 X, 욕망 O")과 원칙 1번("압박 없는 떠먹임")의 직접 검증.
이게 안 되면 명시 마커·미션 UI를 추가해야 하는데, 그건 톤 정체성 포기를 의미.

### 4.2 스코프

α 위에 다음만 얹는다. **차량은 1대 유지** (메타 변수 분리).

| 추가 포함 | 여전히 제외 |
|---|---|
| 거리 보상 곡선 (비대칭 보상) | 차량 2~3대, 모듈, 잠금 해제 |
| 좀비 Herd 방향성 스폰 | 집 부품, 자원 이중 구조 |
| 미니맵 모호 마커 | Tier 1 시설 (정비소·차고) |
| BGM 3단계 (손상도50/시간30/거리20) | 환경 떠먹임 (표지판·메모·라디오) |
| 귀환 돌파 (집 근처 30초~1분 컷 전환) | 부서진 도심 (여전히 무한 평지) |
| "집" = 결과 화면 + "다시 출격" 버튼 1개 | 영구 강화, 외형, 시설 UI |
| 스크랩 (그 판 안에서만 의미, 종료 시 리셋) | |

### 4.3 게이트 조건 (정량)

| 지표 | 통과 기준 |
|---|---|
| 자발 귀환률 | UI 알림 0개로 ≥70%가 BGM 강렬 단계 진입 후 90초 내 집 방향으로 전환 |
| 거리 분포 | 출격당 도달 거리가 정규 분포 (집 근처 농사 모드 <20%, 무한 전진 사망 <20%) |
| 본능 작동 | 첫 출격에서 튜토리얼 없이 ≥60%가 좀비 Herd 역방향으로 전진 |
| 안전 그라인드 회피 | 집 근처 5분 농사 vs 멀리 5분 농사의 보상 격차가 ≥3배로 체감 |

### 4.4 가설 실패 시 plug-pull 시그널

- 자발 귀환률 < 50% → BGM 신호 부족, 명시 마커·텍스트 알림 추가 검토 필요 (톤 정체성 양보 결정)
- 집 근처 농사 모드가 다수 → 거리 보상 곡선 기울기 부족, 패널티 추가 검토
- "BGM이 바뀐 줄도 몰랐다" 다수 → 사운드 디자인 재작업
- "어디로 가야 할지 모르겠다" 다수 → Herd 단독으로 약함, 채널 보강 필요

### 4.5 Stab 비판 흡수

> Stab: "안전 그라인드 허점" — 집 근처에서만 안전하게 농사하면?

→ β의 "안전 그라인드 회피" 게이트가 직접 검증. 거리 보상 곡선이 작동하면 안전 그라인드는 *비효율의 시각적 증거*가 되어야 한다.

## 5. γ — 풀 코어 루프 (Early Access 직전)

### 5.1 검증 가설

> **"차고 진척감(잠금 해제 + 영구 강화)이 5~10시간 플레이 후에도 다음 출격 동기로 작동하는가."**

메타 + 인게임 빌드의 *곱셈*이 작동하는지. 동시에 부서진 도심·환경 떠먹임의 톤 검증.
γ가 곧 EA 직전 단계 = 시장 검증 진입 게이트.

### 5.2 스코프

β 위에 다음을 얹는다. 이 시점부터 **부서진 도심** 진입.

| 추가 포함 | EA 후로 미룸 (γ에 미포함) |
|---|---|
| **부서진 도심 1구역** (지역 다양성은 미정) | Tier 2/3 시설 (무전기, 연료, 방어, 연구소) |
| 차량 3대 (Daily / Old Bull / Ghost) | 차량 4~6대 (Boulder / Patrol / Sweet Tooth) |
| 집 부품 (특별 픽업) + 잠금 해제 곡선 | 보스 |
| 자원 이중 구조 (스크랩 + 집 부품) | 수동 특수 스킬 |
| 모듈 6~8종 + 무기 슬롯 시스템 | 돌파 변주 시스템 (반복 피로 방지) |
| Tier 1 시설 2개 (정비소 + 차고) 완성 | 비상 방송 라디오 풀 확장 (최소 풀만) |
| 환경 떠먹임 4채널 최소 풀 (표지판 20+, 차량 메모 6+, 집 디테일 3티어, 라디오 멘트 10+) | |
| 픽업 신선도 (재스폰 룰) | |
| 사망 패널티 모델 (다음 세션 결정) | |

### 5.3 게이트 조건 (정량)

| 지표 | 통과 기준 |
|---|---|
| 장기 동기 유지 | 5~10시간 플레이 후 ≥50%가 "다음 차량/모듈 잠금 해제"를 자발 재출격 동기로 응답 |
| 차량 다양성 | 3대 모두 ≥30% 출격 비율 (편중 시 빌드 다양성 미작동) |
| 잠금 해제 곡선 | 첫 차량 잠금 해제까지 90~120분 (너무 빠르면 가치 절하, 너무 느리면 진척감 단절) |
| 환경 떠먹임 발견율 | "애기" 모드(빠른 진행) 플레이어도 게임 진행 막힘 없음 + "천재 해커" 모드(탐색) 플레이어가 ≥50% 떠먹임 발견 |
| 톤 일관성 | "Hades식 따뜻한 어두움"이 외부 리뷰어 키워드에 나타남 |

### 5.4 가설 실패 시 plug-pull 시그널

- "잠긴 슬롯이 보여도 갖고 싶지 않다" → 잠금 해제 곡선·차량 정체성 차별화 부족
- 3대 중 1대만 압도적으로 선택됨 → 차량 빌드 균형 재설계
- "환경 텍스트는 안 본다 / 봐도 영향 모르겠다" → 떠먹임 채널 비율 재조정 (그러나 *명시 미션은 여전히 X*)
- EA 시점 wishlist 컨버전이 비교작 평균의 50% 미만 → 마케팅 후크·트레일러 재작업 (게임 자체보다 표현 문제일 수 있음)

## 7. 단계 전환 운영 룰

| 룰 | 의미 |
|---|---|
| **단계 게이트는 사전 합의된 정량 기준만 통과 인정** | "감으로 OK" 금지. 측정 안 되면 통과 불가. |
| **게이트 통과 전 다음 단계 작업 금지** | β 작업 중 γ 자산 만들기 시작하면 분리 의미 없음. |
| **가설 실패 = 단계 재실행 또는 전체 재검토** | 다음 단계로 도주 금지. 잘못된 토대 위에 쌓지 않는다. |
| **각 단계 끝에 *기록*** | 무엇이 통과했고 무엇이 *예상과 달랐는지*. γ까지 가는 동안 가설 진화 추적. |

## 8. 분리 후에도 미해결인 결정 (다음 세션 주제)

이 분리는 **스코프 게이트**일 뿐, GDD §18의 미해결 결정은 여전히 남아 있다:

1. **사망 패널티 강도 구체화** — β/γ 진입 전 결정 필요 (β: 1판 안에서 의미 / γ: 영구 자원 회수율)
2. **귀환 돌파 변주 디자인** — β 게이트 통과 후 결정 (Task #5)
3. **위협도 진행 곡선 디테일** — α 게이트 통과 후 β 진입 전 결정
4. **인게임 무기/모듈 풀 구체화 (8~10종)** — γ 진입 전 결정
5. **첫 출격 자연스러운 학습 흐름** — β 게이트의 핵심 변수
6. **비상 방송 멘트 풀 50~100줄** — γ 진입 전 작성
