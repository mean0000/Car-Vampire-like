# ZombieCrush — UI/UX 설계 문서
**작성일:** 2026-05-24  
**상태:** 확정 (구현 전)

---

## 1. 세계관 & 서사 구조

### 1.1 세계관 설정
기존에 알려진 사실과 진실이 다른 이중 구조.

| 구분 | 내용 |
|---|---|
| 대중이 아는 사실 | 병균/세균에 의한 좀비 바이러스 창궐 |
| 실제 진실 | AI가 설계한 나노봇이 인간의 자아를 탈취해 좀비화 |
| 흑막 | 클라우드/네트워크 기반 AI — 나노봇으로 인간을 동기화(지배) |
| 아는 자 | 극소수. 주인공 포함. |

### 1.2 주인공
- **직업:** 현장 기술자 (하청 엔지니어, 박사 아님)
- **배경:** AI 나노봇 거점 시설 건설에 참여한 하청 기술자. 공사 도중 의도치 않게 감염됨.
- **핵심 비밀:** 감염 당시 의식이 유지됐고, 경험을 통해 "이건 바이러스가 아니다"를 직감. 작업 장비로 나노봇 억제 장치를 직접 제작함.
- **목적:** 자신이 건설에 참여한 그 시설 — AI 거점을 향해 이동 중. 끝내기 위해.
- **플레이어가 유추하는 방식:** 거점 내부 구조를 너무 잘 알고 있음. 기술 용어를 자연스럽게 씀. 억제 장치가 너무 정교하게 만들어져 있음.

### 1.3 파트너 AI
- **정체:** 주인공이 현장에서 쓰던 유지보수 진단 AI. 로컬 전용, 인터넷 연결 없음.
- **생존 이유:** 처음부터 네트워크에 연결된 적이 없어 흑막 AI의 나노봇 동기화에서 벗어남.
- **성격:** 주인공과 오래 일했기 때문에 패턴을 학습한 상태. 감정 표현이 있음.
- **핵심 특징:** 항상 인터넷/네트워크 연결을 요청하며 징징거림. 이것이 자연스럽게 "로컬 AI"임을 플레이어에게 인지시키는 장치.
- **이름:** 미확정 (후보: LOCA / LM / NURI / 오프)
- **아이러니:** 인터넷 없어서 불만인 AI가, 인터넷 없었기 때문에 살아남은 유일한 AI.

### 1.4 세계관 축 대비 구조
```
흑막 AI  — 모든 것을 연결하고 통제 (클라우드, 네트워크)
파트너   — 연결을 거부하고 로컬에서만 존재 (오프라인)
주인공   — 연결되어 있지만 끊으려는 사람 (억제 시스템)
```

## 2. 핵심 메카닉 & 서사 연결

### 2.1 억제 시스템 (SUPPRESS)
- 주인공은 이미 나노봇에 감염된 상태이나, 직접 제작한 억제 장치로 동기화를 막는 중.
- **Shift키 = 억제 시스템 일시 해제** → 나노봇 능력 해방 → 속도 폭발 + 주변이 슬로우모션으로 보임
- 억제 해제 = 강력하지만 나노봇 동기화 진행(SYNC RATE 상승)
- SUPPRESS 게이지 = 억제 잔량. 좀비 충돌로 나노봇 흡수 → 억제 재충전.

### 2.2 SYNC RATE (동기화율)
- 나노봇이 주인공을 얼마나 장악했는지 나타내는 수치. 0~100%.
- **상승 요인:** 억제 시스템 해제(현장 업그레이드)
- **감소 요인:** 피트스톱 거점 진입
- **MAX(100%) = 게임오버** — 주인공도 좀비화(나노봇에 완전 동기화)
- 게임오버 화면 텍스트: `SYNCHRONIZATION COMPLETE / UNIT RECOVERED`

### 2.3 두 가지 업그레이드 방식
ZombieCrush는 두 개의 업그레이드 경로가 병존한다.

| 구분 | 현장 즉시 업그레이드 | 피트스톱 업그레이드 |
|---|---|---|
| 서사 | 억제 시스템 일부 해제, 나노봇 능력 직접 활용 | 동료가 억제 시스템 재보정/정제 |
| 트리거 | 레벨업 즉시 (현장, 위험) | 재밍 거점 진입 |
| 효과 | 강력한 업그레이드 | 안전한 업그레이드 + SYNC RATE 감소 |
| 리스크 | SYNC RATE 상승 | 없음 (또는 극소량) |
| UI 색상 | 붉은 테두리, 경고 어조 | 파란 테두리, 안심 어조 |
| 취소 | 가능 | 불가 (거점에선 항상 선택) |

### 2.4 거점 (피트스톱)
- **정체:** 전파 재밍 장치가 있는 구역. 나노봇 신호 차단.
- **효과:** SYNC RATE 감소 + 안전한 업그레이드 제공
- **플레이어 인지 방법:** 진입 시 UI에 `SYNC RATE ▼` 표시만. 설명 없음.
- **서사 의미:** 누군가가 만들고 사라진 곳. 동료가 재보정을 해준다.
- **쿨다운:** 10초 (동일 거점 재진입 방지)

## 3. HUD 레이아웃

### 3.1 전체 구조

```
┌─────────────────────────────────────────────────┐
│ [XP ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━] │
│                   [🔑 1:30]                     │
│                                                 │
│               [ 게임플레이 영역 ]                 │
│                   🚗 💨                          │
│                                                 │
│ [😐│HULL ████░│SYNC ████░] [▓▓ SUPPRESS ▓▓▓░░] │
│  청록/홀로그램 대시보드      검정 배경/노란 연료계  │
└─────────────────────────────────────────────────┘
```

### 3.2 Canvas 계층 구조

```
Canvas [CanvasScaler: Scale with Screen Size / 1920×1080 / Match 0.5]
├── HUD
│   ├── XP_Bar          [anchor: top-stretch, 얇은 가로 띠]
│   ├── Playtime        [anchor: top-center, 키링 포함 패널]
│   ├── DashboardLeft   [anchor: bottom-left, 청록 홀로그램 패널]
│   │   ├── PartnerAI
│   │   ├── HullGauge
│   │   └── SyncRateGauge
│   └── DashboardRight  [anchor: bottom-right, 검정 배경 연료계]
│       └── SuppressGauge
├── FX
│   └── Vignette        [anchor: stretch-all, SYNC RATE 연동]
└── Panels
    ├── UpgradePanel
    └── GameOverPanel
```

### 3.3 요소별 상세

#### XP 바 (NANO HARVEST)
- 위치: 화면 최상단 전체 너비 (얇게)
- 색상: 청록/시안 계열 — 차량 시스템 언어와 통일
- 라벨: `NANO HARVEST` (나노봇 흡수량)
- 구현: Image fillAmount

#### 플레이타임 디스플레이
- 위치: 상단 중앙, XP 바 바로 아래
- 형식: `MM:SS` 패널 + 키링 장식 (캐릭터 소품)
- 색상: 차량 시스템 톤 (청록)
- 서사: 현장 기술자가 차에 달아둔 장비 — 캐릭터성 부여

#### 하단 좌측 대시보드 (청록/홀로그램)
**파트너 AI 텍스트**
- 형식: 최대 1줄, 한글 20자 이내, 3~5초 자동 페이드아웃
- 배경: 반투명 어두운 패널 + 앰버/녹색 텍스트 (터미널 감성)

**HULL 게이지 (차량 내구도)**
- 색상: 청록 → 손상 시 주황/적
- 의미: 차량 물리적 내구도. 0 = 즉시 게임오버
- 회복: 피트스톱(기지)에서만 가능
- 라벨: `HULL`

**SYNC RATE 게이지**
- 색상: 0% = 청록, 100% = 진홍
- 의미: 나노봇 정신 오염도. 100% = 게임오버
- 라벨: `SYNC RATE`

#### 하단 우측 SUPPRESS (검정/노란 연료계)
- 배경: 검정 (홀로그램 아님 — 의도적으로 투박하고 아날로그한 느낌)
- 색상: 노란/주황 계열
- 의미: 부스터 연료 잔량. 물리적 에너지, 디지털 시스템과 대비
- 라벨: `SUPPRESS`

#### SUPPRESS 차량 파티클
- 위치: 차량 후방 (월드 스페이스)
- 조건: 잔량에 따라 강도 변화 (충전될수록 강해짐)
- 색상: 푸른 불꽃 (파직파직, 가볍게)
- 의미: "부스터 준비됨" 직관적 피드백 — 눈이 화면 하단으로 이동할 필요 없음

## 4. 파트너 AI 텍스트 시스템

### 4.1 설계 원칙
- **bark 시스템** (Hades 방식): 상황 트리거 시 1줄 출력 후 자동 소멸
- **생존 판단 정보 전달 금지**: AI 텍스트를 읽지 않아도 플레이 가능해야 함
- **분위기/확인/캐릭터성 전달 용도**

### 4.2 트리거 조건별 텍스트 톤

| 상황 | 어조 | 예시 |
|---|---|---|
| 평상시 | 차분한 진단 | `시스템 안정. 전방 밀도 높음` |
| 피트스톱 발견 | 안도 + 인터넷 징징 | `재밍 구역 확인. 여기 와이파이 없어?` |
| SYNC 60% 초과 | 불안 | `억제율 경계선 근접. 속도 줄여` |
| SYNC 90% 초과 | 긴박 | `...너무 올라갔어. 빨리` |
| 업그레이드 선택 | 조언 + 데이터 부족 언급 | `인터넷만 됐으면 비교분석 가능한데` |
| 로봇 적 첫 등장 | 혼란 | `저거 생물 신호 아님. 기계야.` |
| 피트스톱 업그레이드 | 전문적 | `억제율 회복 완료. 오늘도 얼마나 풀었어?` |
| 게임오버 직전 | 체념 | `...다시 시작할게. 와이파이 없이.` |

### 4.3 SYNC RATE에 따른 AI 텍스트 변화
- 40% 이하: 일반 텍스트
- 40~70%: 어조 불안정
- 70% 이상: TMP `<shake>` 태그로 텍스트 흔들림
- 90% 이상: 글자 깨짐/오작동 연출

## 5. SYNC RATE 연동 UI 변화

| 구간 | 화면 변화 | Unity 구현 방법 |
|---|---|---|
| 0~40% | 정상 | 기본 |
| 40~70% | SYNC RATE 게이지 점점 붉어짐, 테두리 pulse | `Color.Lerp` + 코루틴 scale bounce |
| 70~90% | 화면 가장자리 붉은 비네팅 | 전체화면 UI Image alpha 증가 |
| 90~100% | AI 텍스트 흔들림, 폰트 색 왜곡 | TMP `<shake>`, Color 오버라이드 |
| 100% | 게임오버 화면 | `SYNCHRONIZATION COMPLETE / UNIT RECOVERED` |

## 6. 업그레이드 카드 UI

### 6.1 현장 즉시 업그레이드 (붉은 카드)
```
┌──────────────────────────────────────────────────┐
│  ⚠ 억제 시스템 해제 — SYNC RATE 상승 경고         │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ 🔴 아이콘│  │ 🔴 아이콘│  │ 🔴 아이콘│       │
│  │  이름    │  │  이름    │  │  이름    │       │
│  │  효과    │  │  효과    │  │  효과    │       │
│  │ +X% SYNC▲│  │ +X% SYNC▲│  │ +X% SYNC▲│      │
│  └──────────┘  └──────────┘  └──────────┘       │
│                                           [취소] │
└──────────────────────────────────────────────────┘
```
- 붉은 테두리
- 각 카드에 SYNC RATE 상승량 명시
- 취소 버튼 있음 (선택 안 할 수 있음)

### 6.2 피트스톱 업그레이드 (파란 카드)
```
┌──────────────────────────────────────────────────┐
│  ✅ 피트스톱 — 시스템 재보정 (SYNC RATE 감소)     │
│                                                  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐       │
│  │ 🔵 아이콘│  │ 🔵 아이콘│  │ 🔵 아이콘│       │
│  │  이름    │  │  이름    │  │  이름    │       │
│  │  효과    │  │  효과    │  │  효과    │       │
│  │ -X% SYNC▼│  │ -X% SYNC▼│  │ -X% SYNC▼│      │
│  └──────────┘  └──────────┘  └──────────┘       │
│                                                  │
└──────────────────────────────────────────────────┘
```
- 파란/청록 테두리
- SYNC RATE 감소량 명시
- 취소 버튼 없음

### 6.3 공통 구현 방식
- 카드 Prefab 1개 (Image + Icon + TMP × 3) — 데이터만 교체
- HorizontalLayoutGroup으로 3장 자동 정렬
- 테두리 Image 색상으로 두 타입 구분
- Canvas Group으로 fade in/out

## 7. UI 라벨 / 서사 텍스트 가이드

### 7.1 핵심 원칙
> 기능은 설명하되, 의미는 숨긴다.
> 플레이어가 "왜 이 이름이지?" 라고 한 번 멈추면 성공.

### 7.2 UI 라벨 목록

| 기능 | 일반적 이름 (X) | ZombieCrush 라벨 (O) |
|---|---|---|
| 부스트 게이지 | BOOST | SUPPRESS |
| 좀비화 게이지 | 감염도 | SYNC RATE |
| 억제 해제 활성 | 부스트 활성 | 억제 해제 |
| 피트스톱 업그레이드 | 업그레이드 | 재보정 |
| 레벨업 | 레벨업 | (없음 — 수치만 표시) |

### 7.3 업그레이드 카드 텍스트 예시

**현장 업그레이드 예시:**
```
[ 개조 엔진 ]
냉각 리미터 2단계 해제
최고속도 +15% / SYNC +8% ▲
```

```
[ 가시 범퍼 ]
군 규정 위반이지만... 효과는 확실해
충돌 범위 +AOE / SYNC +5% ▲
```

**피트스톱 업그레이드 예시:**
```
[ 억제 패치 v2 ]
동기화 억제 보조 모듈 적용
SYNC -10% ▼ / 억제 지속 +20%
```

```
[ 가속 튜닝 ]
이 정도는 규정 안에 들어와
가속도 +25%
```

## 8. 구현 우선순위

### Phase 1 — 구조 (Foundation)
| 순서 | 작업 | 비고 |

### Phase 2 — HUD 요소 배치
| 순서 | 작업 | 비고 |
|---|---|---|
| 3 | 하단 좌측 대시보드 (HULL + SYNC RATE + 파트너AI) | 청록 홀로그램 패널 |

### Phase 3 — 연출 & 폴리시
