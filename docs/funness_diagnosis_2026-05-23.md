# ZombieCrush — 재미없음 진단 보고서
> 작성일: 2026-05-23  
> 작성: Codex(시스템) + Gameplay(게임필) + PM(플레이어경험) 교차 분석

---

## TL;DR

**핵심 문제 한 줄:** 드리프트는 보상 없는 위험이고, 스핀아웃은 예고 없는 처벌이며, 좀비를 치는 행위가 아무것도 돌려주지 않는다.

---

## 1. Codex 관점 — 시스템 레벨에서 "보이지 않는 것들"

코드를 분석한 결과, 플레이어에게 숨겨진 상태변화가 너무 많다.

| 항목 | 실제 동작 | 플레이어가 보는 것 |
|------|-----------|-------------------|
| Shift 누름 | grip × 0.15 = 사실상 무그립 | 아무 반응 없음 (즉시 피드백 없음) |
| 스핀아웃 트리거 | lateralRatio > 0.7 수학 조건 | 갑자기 차가 돌아버림 |
| 속도 35% 손실 | spinoutSpeedRetain = 0.65 | 설명 없이 느려짐 |
| 360° 업그레이드 | S→A/D 0.5초 내 시퀀스 | 게임 내 힌트 없음 |
| 카메라 야우 고정 | `if (!car.IsSpinning)` 분기 | 스핀 중 카메라가 이상하게 느껴짐 |

**Codex 결론:** 이 게임은 플레이어에게 읽기 불가능한 시스템이다. 모든 주요 상태 변화가 내부에서만 일어나고, 어떤 것도 외부로 노출되지 않는다.

## 2. Gameplay 관점 — 게임 필(느낌)이 빠진 곳들

### 드리프트의 절벽 문제
- 그립은 `lowSpeedGrip(0.6) × 속도비율`로 점진적으로 줄어드는데
- Shift 누르면 추가로 ×0.15 → 유효 그립 `0.0225` (사실상 0)
- 경고 없이 lateralRatio 0.7을 넘으면 즉시 스핀아웃
- **경사로가 아니라 낭떠러지.** 플레이어가 한계에 다가가는 감각이 없다

### 스핀아웃이 재미없는 이유
- 차가 제자리에서 도는 느낌 (arcStrength=0.35가 너무 낮음)
- 스핀 시작 시 임팩트 프레임 없음 — 갑자기 시작됨
- 스핀 후 카메라가 새 방향으로 따라오는 데 0.4~0.6초 걸림 → 이 시간 동안 플레이어는 장님

### 카메라의 숨은 문제
- `lookaheadMax = 0.5` — 고도 20m에서 월드 좌표 0.5m 앞을 보여줌 (사실상 의미 없음)
- FOV 변화 속도(`fovSpeed=3`) 너무 느려 가속감이 약함
- 틸트 효과(`maxPitchOffset=4°`, `maxRollOffset=3°`) — 80° 하향 시점에서 거의 안 보임

### 즉각 피드백이 없는 것들
- Shift 누를 때: 차에서 아무 반응 없음 (타이어 소리, 파티클, 모션 없음)
- 스핀아웃 시작: TriggerShake 호출 없음 (카메라 흔들림 없음)
- 360° 콤보: 게임 내 힌트 없음

## 3. PM 관점 — 플레이어 경험 레벨 진단

### 핵심 판타지 vs 실제 경험

**팔고 있는 판타지:** "나는 좀비 무리를 박살내는 파괴 기계다"  
**실제로 요구하는 것:** "횡방향 슬립 계수를 관리하라"

이것이 근본적인 불일치다.

### 드리프트가 사용되지 않는 이유

Mario Kart에서 드리프트는 **충전 메커니즘** — 오래 드리프트할수록 더 강한 부스트.  
Burnout에서 드리프트는 **아드레날린 리스크** — 빠를수록 보상.

이 게임에서 드리프트는: **순수한 위험만 있고 보상이 없다.**

좀비 게임에서 드리프트를 왜 써야 하는가? 직선으로 달리면 안 되는가? 생태학적 이유가 없다. 플레이어는 합리적이다 — 위험하고 보상 없는 조작은 쓰지 않는다.

### 스핀아웃: 처벌인가 스킬인가

**처벌처럼 느껴지는 구조:**
1. 게임이 (보이지 않는 조건으로) 스핀아웃 발동
2. 플레이어가 0.5초 안에 숨겨진 시퀀스 입력 안 하면
3. 뒤를 보는 채로 좀비 떼 한가운데 남겨짐

**스킬처럼 느껴지려면:**
1. 플레이어가 스핀아웃을 **선택하거나 예측**해야 함
2. 실행이 성공했을 때 **명확한 보상**이 있어야 함
3. 실패해도 회복 경로가 **보여야** 함

현재는 아무것도 해당하지 않는다.

### Vampire Survivors가 중독성 있는 이유와 비교

| 요소 | Vampire Survivors | 현재 ZombieCrush |
|------|-------------------|-----------------|
| 킬당 보상 | XP 오브, 소리, 숫자 | (미확인, 아마 없음) |
| 에스컬레이션 | 적 밀도 지속 증가 | 없음 |
| 플레이어 주도권 | 업그레이드 선택 | 없음 |
| 피드백 밀도 | 매 초마다 수십 개 | 드물음 |

**ZombieCrush의 "XP 오브"에 해당하는 것이 없다** — 매 순간 "내가 뭔가를 했고, 그게 중요했다"는 작은 보상 루프가 없다.

## 4. 교차 분석 — 세 관점이 동의한 것

모든 분석이 수렴하는 핵심 문제 3개:

### ① 드리프트에 보상이 없다
- **Codex:** Shift는 grip 수치만 바꾸고 다른 시스템과 연결 없음
- **Gameplay:** 드리프트가 좀비 사냥에 전술적으로 유리하지 않음
- **PM:** 위험만 있고 보상 없으면 플레이어는 쓰지 않는다

→ **드리프트는 보상이 필요하다.** 킬 배율, 속도 부스트, 좀비 광역 피해 등 형태는 다양할 수 있다.

### ② 스핀아웃은 예고 없이 처벌한다
- **Codex:** lateralRatio는 내부 변수, 플레이어에게 노출 없음
- **Gameplay:** 경고 없이 임계값 도달 → 즉시 제어권 박탈
- **PM:** 플레이어가 개시하지 않은 상태변화는 항상 처벌로 느껴진다

→ **스핀아웃 임계값 시각화가 필요하다.** 드리프트 게이지, 타이어 연기 강도, 사운드 피치 등.

### ③ 피드백 루프가 없다
- **Codex:** spinout에 TriggerShake 없음, Shift에 즉시 반응 없음
- **Gameplay:** 모든 임팩트 포인트에 주스(피드백)가 없음
- **PM:** 매 순간 "내가 뭔가를 했다"는 확인이 없음

→ **최소한 이 세 가지에 즉각 피드백 필요:** Shift 눌림, 스핀아웃 발동, 좀비 킬

## 5. 우선순위 개선 목록

### 즉시 효과가 큰 것 (재미 직결)

| 순위 | 항목 | 왜 중요한가 |
|------|------|-------------|
| 1 | **드리프트 보상 설계** | 쓸 이유가 생겨야 시스템 전체가 의미를 갖는다 |
| 2 | **스핀아웃 사전 경고 신호** | 드리프트 게이지 or 사운드 피치 상승 |
| 3 | **좀비 킬 피드백** | 사운드 + 파티클 + 숫자 (무엇이든 하나라도) |
| 4 | **스핀아웃 임팩트 프레임** | 발동 시 카메라 흔들림 + 속도감 |
| 5 | **스핀 후 카메라 빠른 재정렬** | yawSpeed를 스핀 직후 0.3초간 고속으로 |

### 중기 개선 (구조적)

| 항목 | 내용 |
|------|------|
| 360° 시퀀스 튜토리얼 | 첫 스핀아웃 시 HUD 힌트 표시 |
| lookahead 재설계 | 화면 공간 기준으로 재계산 (현재 0.5m는 의미 없음) |
| 드리프트 시각화 | 차체 기울기 or 타이어 스모크 강도 |
| 에스컬레이션 곡선 | 좀비 밀도가 시간에 따라 증가하는 구조 |

1. **드리프트의 보상은 무엇인가?** — 속도 부스트? 킬 멀티플라이어? 특수 공격?
2. **스핀아웃을 처벌로 유지할 것인가, 스킬로 전환할 것인가?** — 방향이 달라지면 구현도 달라진다
3. **좀비 킬의 루프는 어떻게 되는가?** — XP, 자원, 점수? 이것이 없으면 나머지는 의미가 없다
