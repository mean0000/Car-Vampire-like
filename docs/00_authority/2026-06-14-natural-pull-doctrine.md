## 0. 루프 (정정 확정 — 2026-06-14 유저)

- **서바이버즈 농성.** 한 맵에 **15분+** 눌러앉아 처리. 타르코프 추출 ❌.
- **할당량 N + 무한 스폰.** 처리 할당량 N 채워야 **퇴근(추출) 점등**. 몬스터는 마르지 않음.
- **중도 탈출 불가(한 탕 더).** 채운 뒤 선택: 퇴근 vs 다음 할당량 커밋(잠김). 실패=사망=수익 전손(룰렛).
- **못 채우고 끌면 escalation** — 몬스터 능력치↑·밀도↑·변이(처리 지연=이상개체 변이 가속). 하드 타임아웃 사망 ❌.
- **인-런 성장 = 처리에 붙음** (XP=레벨업=카드). 메타 성장은 별도(퇴근 정산).

## 1. 공간 골격 (불변식)

- **바운디드 오픈 존** ~100×100m. 거대 오픈월드 ❌·던전 ❌.
- **동심원 = LV/밀도 그라디언트**: 외곽 LV1(안전·빈약) → 중간 LV2~3(카이팅 본전장) → **코어 LV4~5(할당량·돈·XP 잭팟)**.
- **카이팅 루프 + 카빙 레인**이 생명선 (15분 무한스폰 농성). **데스트랩 0**(막다른 곳=긴 전투선 즉사). 모든 포켓 ≥2 출구.
- **단일 추출 LZ** = 할당량 채우면 점등되는 *끝맺음*(매순간 결정 아님). 추출구 3종 비대칭(옛 I2)은 **폐기** — 루프가 추출-선택형이 아님.
- **모듈 라이브러리 + 절차 조립** (재플레이성). **1차 = 수동 시드 몇 장 MVP**(진짜 조립기 전 재미 검증, Dead Cells 패턴).

## 2. ★자연스러운 끌림 독트린 (본 문서의 핵심)

> **할당량 때문에 들어가게 하지 마라. 뽕(파워판타지 한탕) 때문에 들어가게 하고, 할당량을 뽕이 있는 곳에 놔라.**
> 젤다는 "사당=토큰"이라 안 한다 — 빛나는 게 궁금하게 만들고, 토큰은 도착하면 거기 있다. **목표가 욕망을 타고 간다.** 밀도/LV는 무대일 뿐, 끌림의 이유는 **"값어치 ∈ 위험."**

### 2.1 먼저 — 우리 플레이어가 뭐에 끌리나 (젤다처럼 "판단 후 배치")
뽕·파워판타지 러시 플레이어가 본능적으로 끌리는 것:
1. **큰 뽕의 약속** — 빛나는 표적 둘러싼 적 뭉텅이 = "저거 터뜨리고 싶다"
2. **가장 인상적인 윤곽** — 제일 크고 기괴한 괴수(엘리트/보스) = "저걸 잡고 싶다"
3. **폐허 속 빛** — 칙칙한 데서 발광(광주성)
4. **오염 핵심의 미스터리** — 저 안에 뭐가 있나(서사적 호기심)

### 2.2 BotW → 우리 탑다운 번역 (동결 캐넌 두 개가 reveal 장치)
- **시야 콘**(콘 밖 숨김) = "이동하면 공개" = **점진적 공개**
- **45° 틸트 15m 카메라** = 키 큰 비콘이 클러터 *위로* 솟아 멀리서도 윤곽 = **상시 중력**(Hyrule 성/산)

### 2.3 끌림 합성 = 4겹 (시스템 이유 ❌ → 지각·호기심 ✓)
1. **상시 중력 (비콘)** — 틸트로 솟은 발광 코어(첨탑+괴수 윤곽)가 늘 곁눈에. "저 안에 대단한 게."
2. **리딩 라인** — 거리·붕괴 고가·잔해·컨테이너 열이 시선·발을 코어로 꺾음(수렴선).
3. **콘 릴레이 공개** — 들어갈수록 콘이 *다음 미끼*를 깜: ① 글린트 캐시 → ② 엘리트 윤곽 → ③ 코어 잭팟. **사선에서 다음 장소가 떠오르듯**(젤다 그 효과).
4. **뽕 약속이 미끼** — 목표(할당량)는 욕망(뽕)을 타고 묻어옴. "저거 터뜨리고 싶다"가 진짜 엔진.

**핵심 구분**: 키 큰 비콘 = **상시 보임**(틸트). 지상 미끼 = **콘이 차례로 공개**. + **압박 하 작동** — 카이팅 중 *곁눈질 한 번*에 꽂혀야 함 → 단서는 굵고 즉각.

### 2.4 시드 성격 = "리딩 라인이 비콘을 *어떻게 드러내나*"(공개 드라마)
비콘·릴레이 공개·뽕 약속 = **공통 불변식**. 시드별 차이 = 공개 드라마:
- 방사 직선=정조준(또렷·기준선) / 건물이 가렸다 골목 끝 **왈칵**(최강 드라마) / 나선 휘어들며 **점층**(궁금증 최대).

## 2.5 ★스폰 디렉터 = 뱀서류 동적 젠 (2026-06-14 유저 확정 — 정적 배치 폐기)

시각: `docs/02_logs/2026-06-14-spawn-director.html`. **고정 토큰 배치 ❌ → 동심원 = 젠 존.** 몰려오는 호드 속 액션이 본질(뱀서류). 정적 인카운터(타르코프/MOBA)로 읽히면 실패.

1. **착지 = 즉시 교전** — 드랍하는 순간 주변 몬스터가 바로 인식·어그로. 워밍업 0, 첫 발부터 전투.
2. **표효 호출** — 한 마리가 포효하면 **유사 몬스터(같은 종/밴드)가 그 방향으로 수렴**(어그로 전파 + 호드 형성). 한 곳에서 갑자기 호드가 불어나는 액션 무대.
3. **밴드 = 젠 존(무한)** — 동심원 각 띠가 자기 LV 풀을 플레이어 주위로 계속 스폰(수렴). 외곽 LV1 / 중간 LV2~3 / 코어 LV4~5.
4. **구심 변조(공간)** — 중심에 가까울수록 **강몹 젠율 ↑**. 코어로 갈수록 위험·밀도↑ = 끌림의 대가.
5. **시간 변조(번짐)** — 시간이 갈수록 **안쪽(강한) 몹이 바깥 띠에서도 스폰**. 안전 외곽이 점점 잠식 = §0 escalation의 공간 구현.

※ **비콘/잭팟 끌림·콘 릴레이 공개(§2.3)는 *지각* 레이어로 유지**(들어가고 싶게). 릴레이 ①②③ = 지각 비트지 고정 스폰 카운트가 아님. **젠율·표효 쿨/반경·구심 주입 곡선·번짐 곡선·동시 alive 캡 = Gameplay 디렉터 수치**(본 문서는 규칙·의도).

## 3. 제약 (위반 금지)

- ★**높이 규칙 = 단일 전투 평면** (2026-06-14 유저 확정, 객관 판정 — 시각: `docs/02_logs/_img/2026-06-14-height-rule.png`). 모든 적·플레이어·조준은 *한 지상 평면* 위. **옥상 저격수·층 등반 ❌**(탑뷰 조준 모델 붕괴·근접 못 닿음·카이팅 깨짐·수용성↓·멀티 navmesh 솔로 매몰·장르 이탈). 높이는 **①비콘 실루엣/끌림·오클루전용**(올라가지 않음, 보상·코어 엘리트는 *발밑* 평면) **②비행체 전용**(평면으로 내려와 치거나 평면에 텔레그래프 투사) **③얕은 단차/경사**(나선 보울 ≤30°, 한 navmesh)만 허용. ⇒ 젤다 "높은 곳에 정답"의 *지각적 끌림*은 얻되 *등반*은 안 함.
- 탑다운 45°/15m, 시야 콘 동결. 스텔스 ❌. 택티컬 코너피킹/소리사다리 ❌(액션 돌파 앵커).
- **owned Synty 키트만** (자작 큐브 ❌): BR 도로/건물/다리, Construction 콘크리트/컨테이너/차량/바리케이드. **PolygonGeneric 판타지 배제.**
- **임의 설계 ❌** — 모든 주요 선택에 레퍼/잠긴 결정 출처 명시.
- NavMesh 함정: 모듈 이음새 0.01u 갭(#1), 비균일 스케일 오베이크, 지면 Y=0, 스폰 마커 ≥1.5m 분리.
- 측정 의존: **공간 가독성/끌림 합성까지만 캡처 검증**, 쫄깃함=전투감(게이트0) 후 플레이로만. 맵=무대, 전투감=배우.
