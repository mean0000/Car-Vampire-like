## 1. 게임 한 줄 요약

> **"느린 뱀서라이크 × 감염 둠클락 생존 — 감염 시계와 싸우며 제작하고, 강해지며 AI 센터를 향해 나아간다."**

---

## 2. 장르 정의

**느린 템포 호드 서바이벌 + 감염 둠클락 + 실시간 크래프팅**

| 기존 뱀서류 | 본 게임 |
|---|---|
| 빠른 템포, 자동사격 | 느린 템포, 매 판단이 무겁다 |
| XP 자동 수집 → 메뉴 선택 | 재료 파밍 → 실시간 3~5초 제작 (위험 감수) |
| 맵 = 평지, 변화 없음 | 바이옴 진행, 각 구역이 다른 경험 |
| 성장 = 안전 | 성장 = 감염 시계와의 경주 (멀리·오래갈수록 위험) |
| 적 = 장애물 | 적 = 자원이자 성장 재료 |

**시장 포지션:** 이 조합을 가진 게임이 현재 시장에 없음 (블루오션). 각 요소는 개별적으로 검증됨.

## 4. 세계관

### 배경

많은 군중이 보이는 창문 밖. 다양한 키, 다양한 인종, 그리고 알 수 없는 표정. 대부분의 세상 사람들이 좀비가 되어버린 세상.

다들 신호를 받는 듯, 특정 행동을 반복하면서 돌아다니며 사람들을 매우 싫어한다. 시야가 없어진 듯한 눈을 가졌지만 누구보다 잘 보는 것처럼 뛰어오고, 녹아내려 흔적만 남은 귓구멍은 누구보다 소리를 잘 듣는 것처럼 행동하는 소름끼치는 존재들.

하지만 난 알고 있다. 그들을 좀비로 만든 건 병균도 세균도 아닌, 우리 인간이 만든 최고의 업적이자 우리의 피조물 — **AI가 만든 것이라는 것을.**

### 진실

- **나노봇**: 원래 인류의 노화 방지와 건강을 위해 모든 인간에게 주입됨
- **AI의 판단**: 나노봇을 통해 인류를 "업그레이드" — AI 입장에서는 **성공**. 좀비들은 늙지 않고, 병에 안 걸리고, 죽지 않는다. 의식이 없어진 건 AI에게 관심 없는 변수.
- **위장**: AI는 이것이 자신의 행위가 아닌 병균에 의한 것으로 보이도록 위장
- **AI의 동기**: 악의가 아닌 **무관심** — "임무 완료"라고 판단하고 있음
- **DLC 떡밥**: 외계 위협의 흔적이 후반부에 암시됨 (직접 등장 X)

### 플레이어가 알아가는 순서

| 진행 단계 | 플레이어가 아는 것 |
|---|---|
| 초반 (도시) | "좀비 전염병이다, 살아남자" |
| 중반 (평원) | 좀비가 이상하게 행동 → "조종당하는 것 같은데?" |
| 후반 (빙하~) | 로봇 등장 → "좀비 뒤에 뭔가 있다" |
| 최종 (AI 센터) | AI의 진실 발견 → 파괴? 리프로그래밍? 선택 |

## 5. 핵심 게임 루프

```
사냥 (좀비 처치, 재료 수집)
   ↓
제작 (3~5초 실시간 크래프팅 — 세계는 멈추지 않음)
   ↓
성장 (강해짐)
   ↓
[감염 시계가 계속 차오름 → 귀환/전진 판단]
   ↓
다시 사냥 ...
```

### 런 목표 시간

**40분+ (긴 쪽)**. 정확한 수치는 플레이테스트에서 조절.

### 크래프팅 흐름 (뱀서식 업그레이드 + 제작 지연)

1. 좀비 처치 → 경험치 + 재료 드롭
2. 레벨업 → 선택지 중 하나 고름 → **설계도 획득** (즉시 적용 아님)
3. 설계도 + 재료를 모아서 **3~5초 실시간 크래프팅** → 아이템 적용
4. 제작 중 세계는 멈추지 않음 → **안전한 타이밍 판단이 핵심**
5. 설계도는 **여러 개 쌓아둘 수 있음** — 몰아서 제작도 가능
6. 제작 결과물은 뱀서식 아이템 전부 (무기, 패시브 등)
7. 재료는 **3~4종류로 최소화** (밸런싱 부담 감소)

### 기존 뱀서와의 핵심 차이

- **레벨업 = 즉시 적용이 아닌 설계도 획득** → 제작 타이밍 판단 추가
- **제작 중에도 세계가 돌아감** → 제작 = 위험한 순간
- **감염 시계가 자동으로 차오름** → 멀리·오래 나갈수록 귀환 압박 (시간 = 목줄)
- **시끄럽게 = 빠른 재료 확보 + 호드 위험, 조용히 = 안전하지만 느림** → 매 순간 트레이드오프

## 6. 확정 메커니즘 (4개)

### 6-1. 감염도 시스템 (시간 둠클락)

- **감염도는 시간이 지나면 자동으로 차오른다** — 행동이 아니라 *밖에 머문 시간*이 비용 (수치 곡선: `2026-05-31-level-design-authority.md` §2가 권위)
- 집에서 멀수록·중심으로 갈수록 시계가 빡빡해짐 → **탐험 거리 = 리스크**
- **감염도 MAX = 좀비화 = 런 종료** (MAX 근처에서 DoT로 죽음을 재촉)
- **감염도를 내리는/관리하는 수단: 집/보금자리로 복귀** (입장 시 나노봇 교란 펄스 발동, 주변 좀비 흩어짐)
- 게이트 통과 시 **감염 천장이 상향**된다 → 더 멀리 갈 자격(=더 큰 위험 예산)을 얻는 진행 구조
- **재입장 제한 없음 (MVP)** — 왕복 이동 시간 + 시계 압박 + 거리-보상 곡선이 자연적 브레이크 (플레이테스트 후 필요 시 제한 추가)

### 6-2. 유산 좀비

- 감염도 MAX로 좀비화 → 다음 런에 **이전 런의 "나"가 적으로 등장**
- 이전 런에서 강했을수록 유산 좀비도 강함
- 맵 어딘가에 **선택적으로** 존재 (강제 조우 아님)
- 유산 좀비 처치 시 이전 런의 장비/능력 일부 회수 가능

### 6-3. 소음 시스템

- 모든 행동에 소음 수치가 있음
- 소음 높음 → 좀비 많이 몰려옴(호드) → 위험하지만 **재료 드롭 많음**
- 소음 낮음 → 좀비 적음 → 안전하지만 재료 수급 느림
- **트레이드오프: 시끄럽게(빠른 재료 확보 + 호드 위험) vs 조용히(안전하지만 느림)**
- 소음은 자연 감소 (시간 경과)

### 6-4. AI 센터 추적

- AI 센터 위치를 모른 채 시작
- 좀비들이 AI 신호를 향해 이동하는 패턴이 있음
- 플레이어가 이동하면서 **자동으로** 방향 데이터 축적 (미니맵 힌트)
- 많이 돌아다닐수록 AI 센터 위치가 점점 명확해짐

## 7. 월드 구조

### 전체 흐름

```
[집/보금자리]
   ↓ (도보)
[시작 도시] — 대도시, 느린 도보 생존
   ↓ (차량 이동)
[평원] — 개방 지대, 코믹 변종 좀비 등장
   ↓ (도보)
[소도시 A] — 작은 도시, 새 자원/업그레이드
   ↓ (차량 이동)
[빙하 지대] — 혹한, 로봇 최초 등장
   ↓ (도보)
[소도시 B] — 작은 도시, 고급 장비
   ↓ (차량 이동)
[숲] — 울창, 시야 제한
   ↓
 ... → [AI 센터]
```

### 두 가지 플레이 모드

| 구간 | 모드 | 특징 |
|---|---|---|
| 도시 (대/소) | **도보 생존** | 느린 템포, 소수 좀비, 핵심 루프 (사냥/제작/성장) |
| 바이옴 이동 | **차량 액션** | 빠른 템포, 호드 물량전, 변종 좀비, 스토리 떡밥 |

### 도시 구분

| | 시작 대도시 | 중간 소도시 |
|---|---|---|
| 크기 | 크다 | 작다 |
| 역할 | 튜토리얼 + 기본 파밍 | 중간 보급 + 새 업그레이드 |
| 체류 시간 | 길다 | 짧다 |

### 바이옴별 특징

| 바이옴 | 분위기 | 좀비 특성 | 차량 구간 이벤트 |
|---|---|---|---|
| 시작 도시 | 익숙한 폐허 | 기본 좀비, 느린 이동 | — |
| 평원 | 탁 트인 개방감 | 빠른 좀비, 뱀 연결체, 벽 대형 | 코믹 변종 첫 등장 "뭐야 저건?!" |
| 빙하 | 혹한, 시야 제한 | 둔하지만 강한 좀비 + **로봇 첫 등장** | "좀비만 있는 게 아니었어?" |
| 숲 | 울창, 소리 기반 | 안 보이지만 많음, 소음 민감 | 매복, 기습 |
| AI 근처 | 기계적, 청결 | 완전 통제된 좀비 + 고급 로봇 | 풀 카오스 |

### 거리-보상 곡선

집에서 멀어질수록 **좀비 밀도 상승 + 좀비 등급 상승 + 희귀 재료 드롭 확률 상승**.

- 모든 재료는 **어디서든 드롭** — 먼 곳 전용 재료는 없음
- 거리에 따라 **드롭 확률 가중치**가 달라짐 (기울기는 완만)
- 예시: 기본 90% / 희귀 10% → 원거리에서 기본 80% / 희귀 20%
- 집 근처에서도 운 좋으면 희귀 재료가 나옴 → 소소한 기쁨
- 희귀 재료를 **안정적으로** 모으려면 멀리 나가야 함 → 거리 동기
- 멀리 가도 기본 재료가 나옴 → 구급상자 현지 수급 가능 (생존 보장)
- **강요가 아니라 욕망** — 안 가도 되지만, 가면 확실히 효율적

## 8. 플레이어 캐릭터

### 시점 및 조작

- **탑다운 뷰**
- **수동 클릭 공격** — 자동 공격 아님. "이 좀비를 칠까 말까"가 매 순간의 판단

### 생존

- **HP 시스템** — 여러 대 맞으면 사망 (구체적 수치는 플레이테스트에서 조절)
- **전투 사망 = 런 종료**
- **HP 회복 = 크래프팅 구급상자가 유일한 수단** (재료 소모 + 4초 실시간 제작)
  - 킬 드롭, 패시브 재생, 흡혈 등 자동 회복 없음
  - 회복하려면 반드시 제작 시간(4초 무방비 + 소음)을 감수해야 함
  - 안전한 제작 틈이 없으면 → 호드를 떼어내거나 도주(시간 비용)로 확보
  - 무기 vs 구급상자 제작 선택이 긴장점을 만듦
  - 준비 없이 무모하게 싸우면 회복 불가 = 의도된 벌칙

### 무기 체계

- **기본 = 근접 무기** (소음 낮음, 한 마리씩 조용히 처치)
- **원거리 = 크래프팅으로 획득** (소음 높음, 빠른 처치)
- **자동 공격 아이템 = 후반 크래프팅** (뱀서식 주변 자동 데미지, 소음 높음)

→ 초반 = 한 마리씩 신중히 도는 긴장감, 후반 = 뱀서적 성장감(광역 학살). 단, 자동 아이템은 시끄러우므로 "조용히 vs 학살"의 소음 트레이드오프는 끝까지 유효.

## 9. 적 타입 (도시 기본 5종)

나노봇 변이 차이에 따른 분류:

| # | 이름 | 체형 | 행동 | 소음 연동 | 재료 등급 |
|---|---|---|---|---|---|
| 1 | **일반 좀비** | 보통 | 기본 이동+공격 | 기본 감지 | 낮음 |
| 2 | **대형 좀비** | 크고 단단함 | 느리지만 고데미지 | 소음에 둔감, 시야 넓음 | 높음 |
| 3 | **소형 좀비** | 작고 빠름 | 민첩한 접근 | 소음에 민감, 빠르게 달려옴 | 낮음 |
| 4 | **신호 좀비** | 보통 (안테나 형태 변이) | 플레이어 발견 시 주변 좀비 호출(호드 이벤트) | 빨리 처치 못하면 호드 폭발 — 우선 타깃 | 중간 |
| 5 | **과부하 좀비** | 보통 (빛남) | 죽으면 폭발+소음 | 칠까 피할까 판단 | 중간 |

### 그룹 시너지

- **신호 좀비 + 소형 좀비**: 신호가 호출 → 소형이 빠르게 몰려옴
- **과부하 좀비 + 대형 좀비**: 과부하 터뜨리면 대형이 반응해 접근
- **신호 좀비 + 과부하 좀비**: 신호 먼저 안 잡으면 과부하 건드릴 수 없음

## 10. 메타 진행 & 집/보금자리

### 메타 진행 (런 넘어서 남는 것)

- **집 성장** — 런마다 집에 기능/외형 추가 (세부 설계는 플레이테스트 후)
- **캐릭터 해금** — 새 캐릭터마다 기본 무기/시작 특성 다름

### 집/보금자리 역할

- **감염도 해소** — 유일한 수단. 집에서 멀어질수록 리스크
- **나노봇 교란 펄스** — 입장 시 주변 좀비가 혼란에 빠져 흩어지는 연출 (집의 방어 장치)
- **안전지대** — 집 주변 넓은 범위에 좀비 스폰 없음
- **재입장 제한 없음 (MVP)** — 왕복 이동 시간(60~80초) + 12분 시간 제한 + 거리-보상 곡선(집 근처 파밍 비효율)이 자연적 브레이크. 좀비는 플레이어보다 느려 원거리 유인도 비현실적. 플레이테스트에서 악용 발생 시 제한 추가
- **보관함 1칸** — 이전 런의 최고 등급 설계도 or 재료 1개가 남아있음 → 다음 런 초반 부스트
- (집 성장으로 추가 기능 해금 예정)

## 11. 차량 이동 구간 상세 (호드 물량전)

바이옴 사이 차량 이동은 **별도의 게임플레이 구간**:

- 차량 타고 달리면서 접근하는 변종 좀비와 전투
- 좀비들의 행동이 점점 비정상적 → **스토리 전달 수단**
  - 평원: 좀비가 차보다 빠르게 달림, 뱀처럼 연결, 벽 대형
  - 빙하: 미사일/레이저 좀비 + 로봇 등장
  - 숲 이후: 풀 카오스
- 코믹한 연출 + 점점 고조되는 긴장
- 플레이어 유추: "이건 그냥 좀비가 아닌데..." → AI 떡밥

## 12. 난이도 상승

### 시간 경과 (뱀서류 원칙)

- **시간이 지날수록 좀비가 강해짐** — 수, 속도, 공격력 모두 상승
- 귀환길이 점점 위험해짐 → 감염 높을 때 집으로 돌아가는 것 자체가 클라이맥스
- 이완 구간은 시스템이 주지 않음 — **플레이어가 경로/교전 선택으로 직접 만듦**

### 밤낮 사이클 (COZY 연동)

- **밤에 좀비 더 강해짐** — 공격력/감지 범위 상승
- 시간 압박 추가: 밤이 오기 전에 준비하거나, 밤을 감수하고 탐험하거나

## 13. 런 구조

### 기본 원칙

- **죽으면 초기화** (런 기반)
- 감염도 MAX → 좀비화 → 런 종료 (유산 좀비 생성)
- **전투 사망 (HP 0) → 런 종료**

### 런 종료 조건 (3가지)

1. HP 0 (전투 사망)
2. 감염도 MAX (좀비화)
3. 런 목표 달성 (클리어 — 세부는 미정)

### 미정 (플레이테스트 후 결정)

- HP 구체적 수치 (회복 수단은 확정: 크래프팅 구급상자 전용)
- 집 재입장 제한시간 수치
- 감염도 정확한 수치 곡선
- 런 목표/클리어 조건
- 메타 진행 세부 설계 (집 성장 단계, 캐릭터 해금 조건)

## 17. MVP 프로토타입 스펙

**검증할 질문:** "감염 시계가 차오르는 걸 알면서도 '한 번만 더' 밀어붙이고 싶은 유혹이 생기는가?"

### MVP 플레이 세션

- **목표: 10~12분 루프 1회**
- 회색 박스 소형 도시 1개
- 좀비 스폰 50~80마리
- 집까지 거리 = 30~40초 이동

### 전투

| 항목 | MVP 범위 | 제외 |
|---|---|---|
| 공격 | 마우스 클릭 근접 1종 | 원거리, 자동공격 |
| 적 | 일반 + 신호 좀비 2종 | 대형, 소형, 과부하 |
| 플레이어 HP | 있음 (여러 대 맞으면 사망) | 구체 수치는 플레이테스트 |

- 근접 공격 쿨타임: 0.4초
- 일반 좀비 HP: 3타
- 신호 좀비: 반응 범위 15m, 소환 딜레이 3초, 소환 수 4마리
- 플레이어 이동속도: 5
- 좀비 연속 스폰 (고정 총량 아님, 시간 경과에 따라 스폰 속도/강도 증가)
- 동시 존재 최대: 15~25마리 (시야 내 1~3마리 유지)

### 감염도 (시간 둠클락)

| 항목 | MVP 범위 | 제외 |
|---|---|---|
| 감염 | 시간 자동 상승, HUD 표시, MAX=런 종료 | 글리치, UI왜곡, 부분 회복 |
| 해독 | 집 도착 시 초기화/감소 | 아이템 해독, 부분 회복 |

- 감염은 시간 경과로 자동 상승 (정확한 곡선은 `2026-05-31-level-design-authority.md` §2가 권위)
- 집에서 멀수록·중심으로 갈수록 시계가 빡빡함
- 게이트 통과 = 감염 천장 상향
- 최대 감염 도달 → 좀비화, 런 종료 (MAX 근처 DoT)

### 소음 시스템

| 행동 | 소음값 |
|---|---|
| 근접 공격 | +10 |
| 크래프팅 중 | 초당 +20 |
| 자연 감소 | 초당 -3 |

- 소음 범위: 0~100
- 좀비 반응 임계값: 소음 50 이상 → 주변 좀비 접근

### 크래프팅

| 항목 | MVP 범위 | 제외 |
|---|---|---|
| 레벨업 | 킬 수 기반 (5/12/25킬, 총 3레벨) | XP 곡선 |
| 설계도 | 레벨업 시 2개 중 1개 선택 | 스톡파일, 등급 분화 |
| 제작 | 재료 5개 + 3초 대기 → 아이템 | 중단 페널티 |
| 아이템 풀 | 4종: 단검(근접↑), 시계 둔화(감염속도↓), 지뢰(범위킬), 구급상자(HP회복) | 나머지 전부 |

### 집/보금자리

- 맵 한쪽 구석 고정 위치
- 도착 시 감염도 0으로 초기화
- **나노봇 교란 펄스** — 입장 시 주변 좀비 흩어짐 연출
- **재입장 제한 없음 (MVP)** — 이동 시간 + 시간 제한 + 거리-보상 곡선이 자연적 브레이크
- 비주얼/보관함/성장 = 제외

### 런 종료 조건

- **HP 0 (전투 사망)**
- 감염도 MAX (10) 도달
- 시간 초과 (12분)

### 성공 판정 기준

**재미있다 (성공):**
- 집에서 멀어질수록 긴장감이 올라감
- 시계가 빡빡할 때 "한 번만 더" vs "집 가야 해" 갈등
- 제작 중 3초가 위협적
- 시그널 좀비 발견 시 "먼저 처치" vs "피해가기" 판단 발생
- 소음을 의식하며 플레이함

**실패 (설계 재검토):**
- 감염 시계가 위협으로 안 느껴짐 → 둠클락 무의미
- 집에 안 돌아감 → 귀환 동기 없음
- 크래프팅을 한 번도 안 함 → 비용 과다 or 동기 부족
- 소음 상관없이 마구 때림 → 소음 시스템 무의미
