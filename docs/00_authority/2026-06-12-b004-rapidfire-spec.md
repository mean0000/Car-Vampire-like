# B-004 — 연사 타격감 "트랜지언트의 행렬" 스펙

> **작성**: 2026-06-12 · **상태**: v1.0 동결 (유저 판정 2건: ①범위=코어 4채널만 — 탄피 카펫·이동 제약 제외 ②명중 thud 포함) · **위상**: 필-볼트, **착공은 E-002 게이트 후**
> **재료**: 코드 현황 조사(Explore) + 부감 연사 레퍼런스 리서치(Vlambeer 30트릭·Nuclear Throne·The Ascent·SYNTHETIK) — 본 문서가 둘의 종합 권위.

## 1. 가설 재정의 (원문이 낡았다)

- **백로그 원문**: "연사의 빈자리(카메라 충격 0)는 히트스탑·머즐 리듬·사운드로 채울 수 있다"
- **코드 조사 발견**: 빈자리의 절반은 이미 차 있다 — 개체 단위 히트스탑(hitStopNormal 0.04s, 전역 timeScale 아님), 경직 사다리(flinch 0.15→3타 stagger 0.4→6타 knockdown 1.5), 머즐 플래시/라이트, 서스테인 카메라 오프셋(0.05m), 넉백, 흰 점멸, 스쿼시. **주스 교과서 ②와의 모순은 없었다** — 이미 올바른(개체 단위) 방식으로 구현돼 있음.
- **진짜 빈자리**: 채널이 아니라 **리듬**. 현재 연사는 매 발이 균질하다(같은 플래시·같은 소리·같은 잔광) → 루프로 뭉개져 무게가 죽는다.

> **개정 가설 (게이트 질문)**: "연사가 균질한 루프가 아니라 **세어지는 트랜지언트의 행렬**(시각 박자 + 세계의 반응 + 소리 행렬)이 되면, 카메라 충격 없이도 대량 정화 동사가 노래한다."
> 게이트: 연사로 호드를 갈 때 발 하나하나가 세어지는가? 카메라 충격이 그립지 않은가?

## 2. 리서치 3대 원칙 (종합 판정)

1. **카메라가 못 떨면 세계가 떨어라** — 충격 예산을 카메라에서 월드로 전액 이전: 실루엣 변위(넉백 누적·경직·시체)와 영구 흔적(탄흔·탄피·시체)이 부감의 화폐. (기존 판정 "실루엣 변위+영구 흔적"의 연사 확장)
2. **연사는 루프가 아니라 트랜지언트의 행렬** — 균질 반복(매 발 동일 플래시·트레이서·사운드)이 무게를 죽인다. 발당 개별성 + 주기적 박자(N발당 1 강조)로 "세어지는 연사"를 만든다.
3. **반동은 카메라가 아니라 몸과 선택이 먹는다** — 셀프 넉백·이동 제약·조준선 거칠어짐 = 연사를 비용 있는 전술 선택으로. (B-009 "원샷↔이동둔화 짝"과 같은 문법)

## 4. 옵션 채널 (판정 대상 — 포함 여부 유저 콜)

- **O1 탄피 카펫**: 연사한 자리에 쌓이는 놋쇠 데칼(상한 풀) — "여기서 갈겼다"는 영구 증거. 난이도 낮음, 단 채널 수 +1.
- **O2 연사 중 이동 제약/셀프 푸시**: 연사 지속 시 이속 저하 — 전술 비용 축. 핸들링이 바뀌는 결정이라 단독 게이트 가치가 있음(이번 볼트에 섞으면 가설 오염 위험).

## 5. 기각/이연 채널

- 글로벌 히트스탑 — 기각 유지(레퍼런스도 만장일치로 "파티클·카메라는 흐르게").
- 매 발 스크린쉐이크/킥 — 킥 예약제 판정 위반(Gungeon도 멀미 슬라이더 논쟁).
- 조준선 확산 원뿔 — 수렴 시스템(시안)과 정면충돌. 변형(연사 시 풀라인 거칠어짐)만 후보로 보관.
- 카메라 정적 변위 — 서스테인 오프셋(0.05m)이 이미 존재. 이번 볼트에서 체감 확인만.
- 시체 발사/관통 연쇄 — 사망 연출은 FX 세션 영역(ZombieDeathFX·StrainHarvestFX)과 얽힘 + 물리 드랍 동결 직후라 이연.
