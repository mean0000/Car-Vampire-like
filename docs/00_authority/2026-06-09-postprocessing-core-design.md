## 0. 한 줄 요약

> **회사가 시키는 청소. 세계는 일정대로 폭격되고(작전 타이머), 내 힘은 내 몸을 갉아 산다(싱크). 끓어넘치기 전에 정화하고, strain 챙겨 빠져라.**

### 0.1 ★재미 본진 (2026-06-10 유저 확정 — 모든 시스템 우선순위의 기준)

> **쫄깃하게 좀비 한 마리 한 마리를 잘 잡으면서 성장하고, 그 성장의 도파민으로 더 많은 좀비·엘리트·보스를 처치하고, 일을 끝낸 뒤 탈출한다.**

탈출은 재미가 아니라 **런의 마무리**다. 한 마리의 쫄깃함 × 성장 도파민이 본진이고, 메타 루프(메모리 납품·보급/공제)는 그 위에 선다. 상세: `2026-06-10-combat-texture-foundation.md` (전투 질감 파운데이션).

## 2. 런 구조

```
[사후처리부 사무실] ─ 허브: 본사 지령 · 미션 선택 · 장비 보급 신청(요청서) · 메타 성장
        │ 미션(정화 계약) 선택 → 헬기 안착
        ▼
[미션 = 한 런] ─ 좀비 정화하며 뱀서식 레벨업
        │   (미션마다 위협 프로파일 = strain 풀 + 타이머 천장 차등)
        ├─ 작전 타이머: 소독 폭격까지 카운트다운
        ├─ 싱크 게이지: 능력 자원 (폭주/좀비화)
        ├─ 이벤트: 돌발·기회·외부세력·계약형 (랜덤 발생, 시간대 escalating)
        ▼
[보스] (선택적 대박) → [탈출 = 캐시아웃] "더 긁을까 / 지금 빠질까"
        ▼
[사무실] ─ 납품 일당 − 공제로 더 나은 보급 장비 → 더 위험한 계약 → 반복
```

- **사무실 = 허브** (옛 "집/보금자리"의 승격). 미션 선택이 곧 strain 타게팅 + 리스크 선택의 전략 레이어.
- **미션 = 이산(discrete) 런.** 옛 연속 바이옴 여정(집→도시→평원→…)을 대체.

## 3. 3축 게이지 + 죽음

| 축 | 정체 | 채우는 것 | 100%(끝) |
|---|---|---|---|
| **HP** | 전투 생존 | 피격 | 사망 |
| **작전 타이머** | 외부 데드라인(회사 소독 일정) | 시간(카운트다운) | 폭격 = sweep |
| **싱크 게이지** | 내부 자원(나노봇 동기화) | 능력 사용 | 좀비화 = sweep |

- **싱크**: 능력 쓰면 ↑, 느린 자연 회복. **90~99% = 폭주 버프**(공격력↑, 칼날 위 — 100% 즉사라 캠핑 불가). **능력은 싱크만 소모**(타이머·스폰엔 영향 없음 → "능력 쓰면 좀비 더 나옴" 불공정 구조적 제거).
- **죽음 통일**: 타이머 0(꾸물댐) & 싱크 100(과욕) 둘 다 **같은 sweep 연출**("회사가 날 포함해 구역을 폭격으로 치운다" = "부서원 없음 처리"). + HP 0(전투). 게이지는 둘이지만 죽음의 얼굴은 하나.

### 3.1 파워 철학 — 두 축 (강함 ≠ 트리비얼)

"강한 무기 = 다 쓸어버림 = 트리비얼"은 *챌린지 = 적 개체 난이도*일 때만 참. 호드 서바이벌 + 익스트랙션에선 챌린지가 다른 축에 있다.

- **축1 = 처치력** (강한 무기). 호드를 쓸어버리며 **FEEL 강함 = 파워 판타지.** 너프하지 않는다.
- **축2 = 위협** (밀도 · 엘리트 · 작전 타이머 · 싱크 · 미션 티어). 쓸어버려도 *이기는 게 아니다* — 타이머·strain 획득·생존·싱크에 진다.
- → 강함을 죽이지 말고 **위협을 축2에 실어라.** VS/Brotato/Hades 시그니처 = "신이 된 동시에 죽기 직전." 익스트랙션이 거기에 "신인데 시계가 똑딱이고 빈손으로 나갈 수도 있다"를 더한다.
- **미션 티어**가 메타 파워를 스케일(강해지면 더 위험한 계약) → 쉬운 콘텐츠 OP 재탕 방지, 초반 루즈 방지.

## 4. 코어 루프 — 메모리 납품 → 일당 정산 → 본사 보급(공제) → 출전

> **★2026-06-11 개정 (유저 판정 — 방향 동결, 세부 미설계)**: 무기는 strain으로 제작하지 않는다. **본사가 직접 보급해 지급한다**(장비 요청서 제출 → 보급 — 렉시콘 §5.1 기존 어휘와 정합). 재화 구조는 하청답게 — **런에서 번 일당(보수)에서 장비 보급 비용 등을 회사가 공제**한다. 사유: ①주인공 시트 "펌웨어 없는 물건" ↔ 나노봇제 무기 캐넌 긴장 해소 ②K-하청 새티어 강화(내 목숨값에서 장비값을 떼간다). **미설계**: 일당 산식·공제 항목·보급 UI 흐름·메모리 등급↔단가 관계 전부.

### 4.1 수확 = 나노봇 strain(메모리) (★약탈 아님, 정화의 산물)

- 플레이어는 **단순히 정화**만 한다(약탈/스캐빈징 동기 없음). 수확은 환경에서 줍는 약탈품이 아니라 **정화(좀비 중화)가 만드는 부산물** — 뱀서의 XP/골드 드롭과 동일 위상. 중화된 좀비가 나노봇 코어를 남긴다(자동 수집).
- 메모리 = 무기 재료가 아니라 **납품 품목**이다(렉시콘 §5.4 — 증거 인멸의 외주화). 회수 → 납품 → 일당 정산.

### 4.2 strain 2축 — 계열(적 타입) × 등급(확률)

> ⚠️ **2026-06-11 플래그**: 아래는 크래프팅 재료 표였음 — 새 구조(보급/공제)에서의 역할(납품 단가 차등? 보급 요건?)은 **미설계**. 단 적 로스터 1:1 설계(§4.5)는 유효하므로 표는 보존.

**계열 5종 — 적 타입 1:1 (적 로스터가 곧 재료 표):**

| 계열 strain | 출처(적) | 무기 성격 |
|---|---|---|
| 생체 | 일반 좀비 | 베이스 — 기본 제작 + 화폐 |
| 강골 | 대형 좀비 | 중량·방어·넉백 |
| 신경 | 소형·빠른 좀비 | 속도·연사·기동 |
| 제어 | 신호 좀비 | 유틸·디버프·범위 |
| 과열 | 과부하 좀비 | 화력·폭발·관통 |

**등급 3성 — 확률 드롭 (그라인드의 핵심):**

| 등급 | 출처 | 드롭 확률(시작값) | 역할 |
|---|---|---|---|
| 1성(조악) | 일반 개체 | 생체 ~80% / 특수계열 ~40% | 기본 무기 |
| 2성(정제) | 엘리트·변이 | 엘리트 처치 ~50% | 중급 무기 |
| 3성(고순도) | 보스·희귀 변이 | 보스 보장 / 희귀 ~8% | 무기 정의급 |

### 4.3 보급 = 메타 목적지

- 메모리 납품 → 일당 정산(공제 후 실수령) → 상위 보급 장비 → 출전. **이것이 로그라이트 "런 너머 뭘 향해 가나"(당김 엔진)를 채운다** — 목적지가 크래프팅 해금에서 **보급 장비 티어**로 치환됨(2026-06-11 개정).
- **계열 = 무기 성격, 등급 = 빌드 천장/진화/시그니처** 원칙은 보급 라인업에 승계 후보 (★플랫 파워 아님 — "강한 시작"이 아니라 "더 높이 클 도구"). 구체 구조 미설계.
- 무기 4~6종 확장이 보급 티어 해금으로 연결. (옛 재료→설계도→제작 루프는 이 개정으로 폐기)

### 4.4 익스트랙션 stake & 타게팅

- **죽으면 이번 런에 모은 strain(메모리) 상실 / 보급 장비는 집에 안전**(Monster Hunter식). = "수확 소실 = cash-out"의 press-your-luck.
- **타게팅**: 미션(계약) = 위협 프로파일 → 어느 메모리 풀(납품 단가/요건 차등 — 미설계). 동사(표적 제거) = 특정 변종 = 특정 메모리. → "고단가 납품 요건 → 과부하 변종이 뜨는 계약 수주."

### 4.5 적 로스터 (strain 출처) — 5계열, 각자 다른 동사를 강제

> 원칙: 적은 데미지/HP가 아니라 **"무슨 결정·움직임을 강제하느냐"**로 정의. 5계열은 색만 다르면 안 되고 각자 다른 동사를 강제(안 겹치는 5문제) — 그래야 strain 5종이 의미를 가짐.

| 계열 | role | 강제하는 동사 | 일반→엘리트 (HP 아닌 행동 변화) |
|---|---|---|---|
| 생체(일반) | Grunt/매스 | 없음 — 처치력(축1) 파워판타지 무대 + 밀도 | 사망 시 분열 / 오염 장판 |
| 강골(대형) | Tank/앵커·벽 | 회피 + 후면/약점으로 돌아서 치기 | 약점 다단계 + 짧은 돌진 |
| 신경(소형빠름) | Swarm/쇄도 | 멈춤 금지(카이팅) — 빈틈 즉시 닫음 | 점멸/순간이동 |
| 제어(신호) | Controller | ★타겟 선택("쟤 먼저") | 캔슬 난이도↑·역할 중첩 |
| 과열(과부하) | 공간거부 | 흩어져·타이밍 — 죽거나 접근 시 위험지대화 | 잔류 장판 / 연쇄 폭발 |

- **결정 종류 5개가 다 다름**(매스/봉쇄/멈춤금지/우선순위/스페이싱). 강골·제어·과열이 축2(강한 무기에도 긴장)를 분담.
- **★제어 = 디스럽터/증폭기 (무스텔스 재정의):** 살아있는 동안 *주변 호드 버프 + 내 무기 효과 약화(반경)*. "강한 무기로도 호드가 안 녹는다 → 제어부터 끊어라" = 우선순위 + 축2. 트리거 = **탐지/존재**(소음 아님). 영구 소환이 아니라 서 있는 동안 버프라 죽이면 즉시 정상화(복귀-경로 사망나선 없음). **⚠ 근거 갱신(2026-06-10)**: 옛 근거 "소음 이중처벌 소멸"은 전투 질감 파운데이션의 소리 사다리 채택으로 **"소리→소환/스폰 금지"로 재해석**됨(소리→기존 좀비 유인은 코어 채택). 제어의 탐지/존재 트리거 자체는 유지 — 근거는 "디스럽터는 존재 자체가 위협"이라는 정체성.
- **★단일 스폰 디렉터 (L4D AI Director식):** 좀비 스폰을 결정하는 단일 두뇌. intensity 추적 → Build Up → Peak → **Relax(30~45초 강제 무스폰=숨 고르기)** → 반복 = 긴장 톱니파. 소음·이벤트·제어는 직접 스폰하지 않고 **디렉터의 입력값**. 효과: 가독성(스폰 출처 단일) + 리듬(단조 우상향 깸) + Relax가 Chase→Idle 복귀 자동 보장(사망나선 해결) + 밀도를 처치력에 맞춰 조율.
- **등급 1/2/3성 = HP 아니라 행동/영향반경 변화** (스탯 스펀지 금지). 1성 일반 / 2성 엘리트 / 3성 보스·희귀.
- **가독성**: 제어/엘리트는 시각적으로 반드시 튀어야(오라·색·체력바) — 그레이박스 우선 검증.
- **★MVP 로스터 = 3계열 (2026-06-10 확정)**: 생체(매스) / 신경(쇄도·멈춤금지) / 제어(우선순위) 먼저 — 동사 대비가 성립하는 최소셋이고 strain 경제도 단순하게 출발. 강골·과열은 생산 단계에서 추가 (5계열 설계 자체는 유효, 투입 순서만 조정).

### 4.6 ★장르 다이얼 — 계약 유형 (2026-06-10 확정)

**문제**: 뱀서 재미 곡선(런 내 빌드 만개 = 15~25분)과 익스트랙션 재미 곡선(조기 탈출도 좋은 선택)은 서로 반대로 당긴다. 혼합 비율을 상수로 두면 이 충돌이 매 런 안에서 일어난다.

**해법**: 혼합 비율을 **진행·선택 축**으로 만든다. 초반(약한 무기) = 적은 좀비·한 발이 무거운 익스트랙션 느낌 → 메타 성장(보급 장비·티어)할수록 호드 분쇄 뱀서 느낌으로 이동. 실제 파워 상태와 게임이 파는 판타지를 일치시킨다.

| 계약 유형 | 느낌 | 적 구성 | strain 보상 |
|---|---|---|---|
| **정밀 처리 계약** | 익스트랙션 (적지만 하나하나 위험) | 특수 개체 중심·소수 | 제어/과열/강골 + 고등급 확률 |
| **대량 정화 계약** | 뱀서 (호드 분쇄) | 생체/신경 물량 | 생체/신경 벌크 |

- **다이얼은 플레이어의 손에**: 계약 선택 = 장르 선택 = 메모리(납품) 타게팅이 같은 버튼. "고단가 납품 필요 → 정밀 계약 수주"가 곧 익스트랙션 모드 선택. 후반에도 정밀 계약으로 "좋은 장비 + 긴장" 성립.
- **구현 실체 = 새 시스템 아님**: 스폰 디렉터가 메타 티어를 읽어 밀도↑/개체위협↓ 곡선을 옮기는 파라미터 + 계약별 스폰 프로파일.
- **★온보딩 역전 방지**: 1번 미션 피날레 = **스크립트 고정 호드 웨이브** (탈출 직전 한 번, "강해지면 이게 일상" 맛보기 → 2~4번 미션 희소 모드가 그 맛에 대한 갈증을 만들고, 갈증 끝에 첫 상위 보급 장비). 희소 모드도 1~2마리가 아니라 **5~10마리 팩 단위** — 총기 타격감은 항상 노래해야 한다.
- **성장 역할 분리 (곡선 충돌 재발 방지)**: 다이얼을 움직이는 건 **메타만**(보급 장비·티어). 런 내 레벨업 카드 = 어느 모드에서든 "그 판의 불꽃놀이"로 역할 고정. 런 내 성장 = 불꽃놀이, 메타 = 대포.

### 4.7 ★산재 보험 (2026-06-10 확정)

- **사망 시 이번 런 수확 strain(메모리)의 일부 보전 (시작값 30%)**. 보험료 = 공제 항목 후보(2026-06-11 개정 — 미설계), 사무실에서 갱신. 보험 등급 업그레이드 = 메타 성장 한 줄.
- 효과 셋: ① 무게 유지(여전히 크게 잃음) + 죽음의 바닥(빈손 귀환 이탈 방지) ② **"내 목숨값이 정산서로 돌아온다"** — 톤 원칙(§7)의 블랙코미디 장치 ③ 온보딩 안전망.
- 세계관 근거: "사람들은 보험을 갱신하고 평범하게 산다" (worldbuilding-pitch §2) — 시민의 보험이 곧 직원의 산재 보험으로.
- **드롭 세리머니 (소품 확정)**: 엘리트 처치 순간 코어가 눈에 띄게 튀어나오고 엘이 한 줄 분석("과부하 계열 2등급. 회수 권장."). strain이 "색깔 토큰"으로 전락하지 않게 — 몬헌 소재가 트로피인 이유는 출처가 보여서다.

## 5. 작전 타이머 상세

- **카운트다운, 0 전에 탈출 못하면 폭격 = 죽음.** 픽션: 회사가 구역 소독(폭격)을 *일정*에 예약 — 그 전에 일 끝내고 빠져라.
- **바닥 15분**(업무 안 깨도 보장) ~ **하드 천장 30분**(무조건 폭격, 클라이맥스 강제).
- **업무(이벤트) 완수 = +시간 연장**(체감 4.5/4/3.5/3 → **업무 4건이 정확히 30분 수렴**; 5번째는 시간 아닌 다른 보상).
- ~~탈출 = 언제든 헬기 호출~~ → **★2026-06-10 개정: 중간 탈출 없음.** 런 = 목표(업무)·엘리트·보스를 처리하고 **일을 끝낸 뒤** 탈출이 정식 경로. **비상 탈출**은 상시 가능하되 긴급 베일아웃 전용(보전율 페널티 등 비용 — 수치 OPEN). press-your-luck은 "언제 나갈까"가 아니라 "보스까지 가느냐 vs 비상 탈출로 확정하느냐"로 이동. 헬기 딜레이 15~20초(이동/공격/취소 가능)는 유지.
- 시간 경과 = 좀비 escalation(장르 표준).

### 5.1 페이싱 — "항상 30분" 결함의 고침 묶음 (3에이전트 만장일치)

"탈출 언제든 + escalation 점진적"이면 *항상 천장까지 밀고 안전 탈출*이 우성전략 → 조기탈출 죽은 선택지 → 가변폭 허상 → 익스트랙션 핵심 결정 증발. 막는 묶음:

1. **죽으면 수확(strain) 소실 / 탈출=확정** — cash-out(§4.4에서 확정).
2. **escalation 후반 불연속 급가속 + 실경과시간 기준** — 오래=더 위험+파밍 효율 역전. 22분쯤 추격 밀도 급증 같은 *명시적 분기점*(결정은 계단에서 태어남).
3. ~~조기탈출 고유 보상~~ → **2026-06-10 재배선**: 중간 탈출 제거(§5 개정)로 이 항목은 **비상 탈출의 보전율 설계**로 흡수 — 비상 탈출이 "패배"가 아니라 "손절이라는 유효한 결정"이 되게 하는 비용·보전 곡선. 수치 OPEN.
4. **톱니 = 이벤트 완수 시 escalation cull**(맵 밀도 일시 −40%/10초). +시간이 아니라 *밀도 비움*이 이완 비트(시간은 누적되지 비워지지 않으므로).
5. **욕심 제동축 = 싱크**(escalation 아님) — 타이머+싱크 비동기 이중 데드라인.

> ⚠️ **"+시간 밸브가 거꾸로(액셀)"** 주의: 시간 연장은 escalation을 *늘린다.* 시간은 "도박 잔액", 페이싱은 escalation 밀도(cull)로 분리할 것.

## 6. 이벤트 풀

- **이벤트 = 랜덤 발생 + 시간대별 escalating 풀** (스크립트 사다리 아님). *무엇이 터질지 = 랜덤, 얼마나 센 게 가능한가 = 시간.* 매 런 다른 시퀀스.

**A. 돌발 상황 (위협·강제이동, VS 박쥐떼류):** 감염 군집 이동 / 오염 확산 지대 / 변이 경보(방치 시 전체 강화) / 구조신호 변종(N초 내 못 끊으면 호드 증원) / 변종 스웜 경보(단일 변종, 20초 예고).

**B. 기회 이벤트 (밸브·리스크/리워드):** 보급 투하(흩뿌림) / 표적 지령 Bounty / 현장 비품(30초 버프·영구 스탯·응급 키트) / 긴급 정화(위험 자청, 보상 2배).

**C. 외부 세력 개입 (★시그니처):** **소독 드론 오인사격**(회사 폭탄 피하며 싸움) / 정찰 드론 유인(소음으로 호드 유인) / 통제구역 격상(회사 룰 변경) / 고가치 표적 추적(보상 획득 순간 호드 수렴 = 탈출 직전 최대 위험).

**D. 계약형 미니 이벤트 (★트위스트, catch=영혼):**
- 격리 봉인(버프, **결계** 다 정화해야 풀림)
- 수거 드론 추격(잡으면 대박, **놓치면 갖고 탈출**)
- 과부하 계약(무한 폭주, **끝나면 싱크 대폭 상승**)
- 블랙박스 회수(점령, **떠나면 리셋**)
- 샘플 과채취(즉시 strain, **HP/싱크 바친 만큼 약해짐**)
- 나노봇 증폭 노드(파괴=차단+strain, **방치하면 주변 좀비 강화** — 기계라 인간 죽임 무게 0)
- 현장 감사(목표 달성=보너스, **실패=페널티**)
- 고립된 부서원(구출=동료/메타 보상, 구출 중 호드 몰림)

**MVP 검증 최소셋**: 감염 군집 이동(돌발) / 보급 투하(기회) / 소독 드론 오인사격(외부=시그니처) / 격리 봉인(계약형).

## 7. 톤 원칙

1. **★전환된 인간이라는 진실 = 배경 공포(서사·환경·로어)지 전투 전면 아님.** 전투에선 몬스터(나노봇 구성체)를 정화 — 적은 연민 대상이 아니라 처리 대상. ("미전환체=사람 죽이는 느낌"은 호드 파워 판타지+블랙코미디와 충돌 → 거부.)
2. **회사·익스트랙션 테마가 이벤트의 내러티브 래퍼.** 같은 메커닉도 "본사 지령/소독/보급"으로 감싸 우리 톤을 만든다.
3. **회사는 직원 목숨보다 일정을 친다** — 소독은 일정대로(네가 안에 있든 말든). 블랙코미디의 핵심.

## 8. OPEN (플레이테스트/미정)

- **보급/공제 경제 디테일** (2026-06-11 개정으로 크래프팅 디테일 항목 대체): 일당 산식 · 공제 내역 구성 · 메모리 등급↔납품 단가 · 보급 티어 구조 · "빌드 천장/진화" 원칙의 보급 라인업 승계 방식.
- strain 드롭 확률 정확값, 이벤트 발생 빈도·밴드 스케줄, MVP 셋 확정.
- 타이머·싱크·escalation 수치 곡선 전반.
- **"업무 완수 = +시간" 재심** (2026-06-10): §5.1 경고대로 시간 연장은 액셀. 업무 보상을 시간 대신 cull+strain으로 통일하는 안 — 스켈레톤 게이트 통과 후 데이터로 결정. **⚠ 산술 모순 등재(pm 검토)**: "업무 4건=30분 수렴" ↔ "30분=폭격" ↔ "업무·보스 처리 후 탈출"이면 보스+탈출 시간 예산이 음수 — 업무 수·수렴 시간·천장을 함께 재설계해야 함.
- **★보전율 3종 단일 부등식 (pm 검토 치명)**: 산재 보험 보전율(30%) · 비상 탈출 보전율 · 보스 처치 기댓값 — 셋을 **하나의 부등식 위에서 동시에** 풀 것. 따로 정하면 "보스 직전 비상 탈출 파밍"(비상이 너무 후함) 또는 "차라리 죽는 게 이득"(비상<보험) 같은 우성전략/코미디가 숨는다.
- 산재 보험 수치(보전율·보험료·등급), 장르 다이얼 곡선(티어별 밀도/개체위협 값).
- 싱크 정체성 메모: "처벌"이 아니라 **칼날 위 라이딩**(90~99 폭주 밴드가 주인공)으로 튜닝할 것 — 능력 사용을 처벌하는 자원은 파워 판타지와 충돌.
- **좀비 로스터** — §4.5에서 확정(5계열 · 제어=디스럽터 · 단일 스폰 디렉터). 남은 OPEN = 디렉터 intensity/Relax 수치, 제어 버프·무기약화 수치, 약점 히트박스, strain 드롭 확률(엘리트=2성/보스=3성). 옛 `2026-05-29-zombie-ai-handoff.md`(스텔스 전제)는 폐기.
