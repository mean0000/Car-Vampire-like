# E-001 — 판돈 볼트온 (모퉁이 랩 × 최소 경제) 스펙

> 🟥 **폐기 (2026-06-16).** [[2026-06-16-vampire-survivors-pivot-spec]] §1 — 익스트랙션·판돈·strain 일체 폐기.

> **작성**: 2026-06-11 · **상태**: v1.0 동결 (PM 진단 → Fable 디렉팅) · **위상**: 필-볼트(1볼트=1가설=1게이트)
> **가설**: 쫄깃함의 70% = 수지(걸린 것). 무대(모퉁이 랩+시야 콘)는 완성 — 판돈이 들어가면 같은 코너가 쫄깃해진다.
> **게이트 질문(10분 플레이)**: **"strain(메모리) 12개를 주머니에 넣고 같은 코너를 돌 때, 빈손일 때와 긴장이 다른가?"**
> **선행 권위**: postprocessing-core-design §4(strain 경제), 2026-06-11-corner-lab-spec(무대), 렉시콘 v1.4(표기 = "메모리", 개발 용어/코드 = strain·StrainWallet 유지)

## 원칙

- **기존 RunLoop 스켈레톤 최대 재사용** (씬에 ExtractionPoint·RunLoop_Managers·RunLoopUI·MetaProgress 이미 존재). E-001은 신규 시스템이 아니라 **랩으로의 배선**이다.
- 과설계 금지: 크래프팅·허브 개편·미션 선택 없음. 카운터 1개 + 트리거 1개 + 훅 2개 + 웨이브 1개.
- UI 신규 텍스트는 렉시콘 §5 경유 — 인게임 표기는 "메모리", 쉬운 일상어만.

## 스펙 4요소

| # | 요소 | 내용 |
|---|---|---|
| 1 | **전리품** | 랩 좀비 처치 → strain 획득. **깊이 가중**: A구역 +1 / B구역 +2 / C구역 +3 (랩 로컬 z 구간 판정: z<28=A, 28~64=B, >64=C). 기존 드롭 연출(팝→자석 흡입)이 있으면 재사용, 없으면 카운터 직가산+킬 위치 가벼운 획득 신호 1개(과투자 금지) |
| 2 | **잃을 것** | 사망(HP 0) 시 이번 런 strain 전부 소실. 게임오버 화면에 소실 사실 1줄 표기(예: "메모리 N개 소실") — 잃었음이 보여야 판돈이다 |
| 3 | **들고 나가는 선택** | C구역 북단(랩 로컬 (14, 88) 부근)에 탈출 지점 배치(기존 ExtractionPoint 재사용/이전). 밟으면 런 종료 + strain 뱅킹(기존 RunLoop 흐름 정합 확인 — StartMission 시작점=랩 진입방과 한 루프로 닫혀야 함) |
| 4 | **회수 불확실성** | 탈출 지점 접근(반경 ~8m) 시 1회성 귀로 웨이브: C구역 출현 포인트(맨홀 C·창문 C) 경유 스태거드 4마리(0.6s 간격, Zombie.prefab=General 1발킬). 인구 상한(C 26) 준수, 정면 <8m 출현 금지(코너랩 스펙 §5.2) |

## HUD

- strain 카운터 1개 — RunLoopUI에 기존 카운터가 있으면 라벨만 "메모리"로 확인, 없으면 HUD에 텍스트 1개 추가. ⚠️한글 = **Pretendard Dynamic SDF만**(정적 SDF는 ASCII-only 함정).

## 게이트 판정 절차 (유저)

1. 빈손으로 A→B 코너 2개 통과 → 긴장 메모
2. C까지 진행해 메모리 ~12개 적재 → 탈출 지점으로 귀환하며 같은 동선 → 긴장 비교
3. 한 번은 일부러 죽어본다 → 소실이 아픈가
- 다르면 → 경제 본편(수지 곡선·메타 소비처) 직행. 같으면 → 70% 가설 기각, 진단 B(킬 루프 전개)로 선회.
