Core Design · v1.0 · 2026-06-09

사후처리부

탑다운 뱀서라이크 × 익스트랙션 × 로그라이트
회사가 시키는 청소. 세계는 일정대로 폭격되고(작전 타이머), 내 힘은 내 몸을 갉아 산다(싱크). 끓어넘치기 전에 정화하고, strain 챙겨 빠져라.
유저 + Claude 설계 세션 · pm/LevelDesign 적대검토 · 웹 리서치 기반  |  옛 게이트·감염·무기 설계를 대체

01 게임 정체성

톤

관료제 블랙코미디

"회사가 시키는 청소" + Hades식 따뜻한 어두움. 회사는 직원 목숨보다 일정을 친다 — 소독은 네가 안에 있든 말든 일정대로.

전제

나노봇 전환 세계

AI 나노봇이 인간을 좀비로 전환. 사후처리부 = 오염 구역 정화 회사. 플레이어 = 말단 정화 요원.

차별화 ①

외부 세력(회사) 개입

소독 드론 오인사격 등 — 내 회사가 날 위협이자 기회로 만든다.

차별화 ②

나노봇 strain 크래프팅

정화 산물로 나만의 무기를 만든다.

02 런 구조

[사무실] ─ 허브: 본사 지령 · 미션 선택 · strain 크래프팅 · 메타 성장
   │ 미션(정화 계약) 선택 → 헬기 안착
   ▼
[미션 = 한 런] ─ 좀비 정화하며 뱀서식 레벨업
   │   미션마다 위협 프로파일 = strain 풀 + 타이머 천장 차등
   ├─ 작전 타이머 : 소독 폭격까지 카운트다운
   ├─ 싱크 게이지 : 능력 자원 (폭주 / 좀비화)
   ├─ 이벤트       : 돌발 · 기회 · 외부세력 · 계약형 (랜덤, 시간대 escalating)
   ▼
[보스] (선택적 대박) → [탈출 = 캐시아웃] "더 긁을까 / 지금 빠질까"
   ▼
[사무실] ─ 모은 strain으로 더 나은 무기 → 더 위험한 계약 → 반복

사무실 = 허브(미션 선택이 곧 strain 타게팅 + 리스크 선택). 미션 = 이산 런 — 옛 연속 바이옴 여정을 대체.

03 3축 게이지 + 죽음

전투

HP

피격으로 감소. 0 = 사망.

외부 데드라인

작전 타이머

회사 소독 일정까지 카운트다운(바닥 15 ~ 천장 30분). 0 = 폭격 = sweep.

내부 자원

싱크 게이지

능력 사용 시 ↑, 느린 회복. 90~99% 폭주 버프. 100% = 좀비화 = sweep.

죽음 통일 — 타이머 0(꾸물댐) & 싱크 100(과욕) 둘 다 같은 sweep 연출("회사가 날 포함해 구역을 폭격으로 치운다"). 게이지는 둘이지만 죽음의 얼굴은 하나.

파워 철학 — 두 축 (강함 ≠ 트리비얼)

축1 · 처치력

강한 무기로 호드를 쓸어버리며 FEEL 강함 = 파워 판타지. 너프하지 않는다.

축2 · 위협

밀도 · 엘리트 · 타이머 · 싱크 · 미션 티어. 쓸어버려도 이기는 게 아니다.

강함을 죽이지 말고 위협을 축2에 실어라. "신이 된 동시에 죽기 직전" + "시계가 똑딱이고 빈손으로 나갈 수도."

04 코어 루프 — strain → 크래프팅 → 나만의 무기

재료 = 정화의 산물 (약탈 아님). 플레이어는 단순히 정화만 한다. 중화된 좀비가 나노봇 코어를 남긴다(XP/골드 드롭과 동일 위상). 무기 = 정화 산물 재활용.

계열 5종 — 적 타입 1:1 (적 로스터 = 재료 표)

계열출처(적)무기 성격
생체일반 좀비베이스 — 기본 제작 + 화폐
강골대형 좀비중량 · 방어 · 넉백
신경소형 · 빠른 좀비속도 · 연사 · 기동
제어신호 좀비유틸 · 디버프 · 범위
과열과부하 좀비화력 · 폭발 · 관통

등급 3성 — 확률 드롭

등급출처확률(시작값)역할
1성 조악일반 개체생체 ~80% / 특수 ~40%기본 무기
2성 정제엘리트 · 변이~50%중급 무기
3성 고순도보스 · 희귀 변이보스 보장 / 희귀 ~8%무기 정의급

크래프팅 = 메타 목적지

계열 = 무기 성격, 등급 = 빌드 천장/진화(플랫 파워 아님 — "강한 시작"이 아니라 "더 높이 클 도구"). "나만의" = 계열·등급 조합.

익스트랙션 stake

죽으면 이번 런 strain 상실 / 무기는 집에 안전(MH식). 타게팅 = 미션 + 동사("3성 과열 필요 → 과부하 계약 수주").

04·5 적 로스터 — strain 출처

원칙: 적은 데미지/HP가 아니라 "무슨 결정·움직임을 강제하느냐"로 정의. 5계열은 각자 다른 동사를 강제(안 겹치는 5문제).

계열역할강제하는 동사일반→엘리트(행동 변화)
생체 일반매스없음 — 처치력 파워판타지 무대 + 밀도사망 시 분열 / 오염 장판
강골 대형앵커·벽회피 + 후면 약점으로 돌아서 치기약점 다단계 + 짧은 돌진
신경 소형빠름쇄도멈춤 금지(카이팅) — 빈틈 즉시 닫음점멸 / 순간이동
제어 신호Controller★타겟 선택 "쟤 먼저"캔슬 난이도↑·역할 중첩
과열 과부하공간거부흩어져·타이밍 — 죽거나 접근 시 위험지대화잔류 장판 / 연쇄 폭발

제어 = 디스럽터 (무스텔스 재정의)

살아있는 동안 주변 호드 버프 + 내 무기 효과 약화(반경). "강한 무기로도 안 녹네 → 제어부터." 트리거=탐지(소음 아님 → 원거리 이중처벌 없음). 죽이면 즉시 정상화(사망나선 없음).

단일 스폰 디렉터 (L4D식)

좀비 스폰을 결정하는 단일 두뇌. Build Up → Peak → Relax(30~45초 무스폰) = 긴장 톱니파. 소음·이벤트·제어는 디렉터의 입력값. 가독성 + 리듬 + 사망나선 자동 해결.

등급(1/2/3성) = HP 아니라 행동/영향반경 변화(스탯 스펀지 금지). 제어/엘리트는 시각적으로 반드시 튀어야(오라·색·체력바) — 그레이박스 가독성 우선.

05 작전 타이머 — "항상 30분" 결함의 고침

바닥 15분 ~ 하드 천장 30분. 업무 완수 = +시간(체감 4.5/4/3.5/3 → 4건이 정확히 30분 수렴). 탈출 언제든(딜레이 15~20초) + 보스 = 천장 직전 선택적 대박.

"탈출 언제든 + escalation 점진적"이면 항상 30분이 우성전략 → 조기탈출 죽음 → 익스트랙션 결정 증발. 고침 묶음:
  • 죽으면 수확 소실 / 탈출=확정 — cash-out.
  • escalation 후반 불연속 급가속 + 실경과시간 기준 — 오래 = 위험↑ + 파밍 효율 역전. 결정은 계단에서 태어남.
  • 조기탈출 고유 보상 — 15분 탈출 = "안전하게 챙긴 승리."
  • 톱니 = 이벤트 완수 시 escalation cull(밀도 −40%/10초). +시간이 아니라 밀도 비움이 이완.
  • 욕심 제동축 = 싱크 — 타이머+싱크 비동기 이중 데드라인.

⚠️ "+시간 밸브가 거꾸로(액셀)" — 시간 연장은 escalation을 늘린다. 시간 = 도박 잔액, 페이싱 = 밀도(cull)로 분리.

06 이벤트 풀 — 랜덤 발생 + 시간대 escalating

A · 돌발 상황 위협

VS 박쥐떼류. 강제 이동·스파이크.

감염 군집 이동 · 오염 확산 지대 · 변이 경보 · 구조신호 변종(N초 내 끊기) · 변종 스웜 경보

B · 기회 이벤트 밸브

리스크/리워드.

보급 투하(흩뿌림) · 표적 지령 Bounty · 현장 비품(버프/스탯/회복) · 긴급 정화(위험 자청, 보상 2배)

C · 외부 세력 개입 시그니처

회사가 개입 = 우리만의 축.

소독 드론 오인사격 · 정찰 드론 유인 · 통제구역 격상(룰 변경) · 고가치 표적 추적

D · 계약형 미니 이벤트 트위스트

catch = 영혼.

격리 봉인(결계) · 수거 드론 추격(놓치면 탈취) · 과부하 계약(싱크↑) · 블랙박스 회수(점령) · 샘플 과채취(거래) · 나노봇 증폭 노드(눈덩이) · 현장 감사(실패=벌칙) · 고립된 부서원(구출)

MVP 검증 최소셋 — 감염 군집 이동(돌발) / 보급 투하(기회) / 소독 드론 오인사격(시그니처) / 격리 봉인(계약형). 4갈래 대표 + 시그니처.

07 톤 원칙

  • 전환된 인간이라는 진실 = 배경 공포(서사·환경·로어)지 전투 전면 아님. 전투에선 몬스터(나노봇 구성체)를 정화 — 적은 연민 대상이 아니라 처리 대상.
  • 회사·익스트랙션 테마가 이벤트의 내러티브 래퍼. 같은 메커닉도 "본사 지령/소독/보급"으로 감싸 우리 톤을 만든다.
  • 회사는 직원 목숨보다 일정을 친다. 블랙코미디의 핵심.

08 OPEN — 플레이테스트 / 미정

  • 크래프팅 디테일(레시피 vs 모듈), 등급의 빌드 천장/진화 메커닉
  • strain 드롭 확률, 이벤트 발생 빈도·밴드 스케줄, MVP 셋 확정
  • 타이머·싱크·escalation 수치 곡선
  • 좀비 로스터 무스텔스 재정당화 — 옛 zombie-ai-handoff는 스텔스 전제라 오염. strain 출처(계열 5 = 적 5)와 정합하게 재정의 필요.
