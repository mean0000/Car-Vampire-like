# 레벨업 카드 카탈로그 — 전체 명세 (권위 문서)

> **작성일**: 2026-05-31
> **상태**: MVP 카드 전체 명세 + 수치 튜닝 시작값 확정. **이 문서가 카드 내용의 권위 출처.**
> **2026-05-31 개정**: 감염도 = *시간 구동 타임어택 둠클락*(게이트가 천장 상향) 확정 반영. 옛 감염축 카드(감염가속/전이/오염된귀환) **삭제** → **시계축**(목줄을 태워 힘을 얻는 도박: 소각전술/막장투자/사채계약/귀환호흡) + 거리/기동 정체성 카드로 교체. 자원축 `감염`→`시계`, 볼록 비용 폐기(충전율 페널티로 단일화).
> **2026-06-03 개정 (스텔스 제거)**: 스텔스 계열 카드(무음 보행/반향암살) → **기동 계열**(대시 회피/밀쳐내기)로 교체. 암살·웅크림 의존 효과 전면 폐기. 소음 미끼는 스텔스 태그만 제거(호드 유인 유틸로 유지). 방망이 시그니처 「무음 타격」의 스텔스 즉사 진화 → 소음 기반 강타로 교체.
> **선행(확정 규칙)**: `2026-05-31-levelup-cards-handoff.md` §1, `2026-05-29-levelup-verbs.md` §★, `2026-05-29-progression-system.md`
> **그라운딩**: 아래 수치는 2026-05-31 코드 실측(`PlayerCombat`/`PlayerController`/`NoiseManager`/`SyncRateManager`/`ZombieConfig`) 기준.

## 0. 읽는 법

- 카드 양식 = handoff §2. 태그: 🟢생산자 / 🔵소비자 / ⚙️인에이블러 / ⚖️양날검.
- **`🔧 훅`** 줄 = 이 카드를 코드로 옮길 때 **새로 만들어야 하는 의존**(handoff §4 감사 기준). 없으면 기존 훅으로 충분.
- 수치는 **시작값(튜닝 전제)** — 플레이테스트로 조정. 확정된 건 *구조와 청크 결*이지 절대 수치가 아니다.
- 감염은 코드 `SyncRate` 0~1 척도(감염 ≥7 = `0.7`).

## 1. 튜닝 항목 6종 — 이번 세션 결정 (handoff §5 응답)

### ① 청크 수치
각 카드 블록(§2)에 Lv1→3 시작값 명기. 원칙: **매 레벨 체감 가능**, +5% 같은 미미 증분 금지.

### ② 기본 : 동사 드로우 가중치 (드로우 = 2택1, 가중 추첨)
| 캐릭터 Lv | 기본 카드 | 동사 카드 | 비고 |
|---|---|---|---|
| 1~3 | 75% | 25% | 초반 = 굴러가게(쉬운 결정) |
| 4~6 | 55% | 45% | 빌드 정체성 형성 |
| 7+  | 40% | 60% | 후반 = 동사 위주 |
- **시그니처**는 동사 슬롯에 섞임(선택 무기 장착 시에만). 동사 추첨 시 시그니처 가중치 ≈ 일반 동사의 1/2.
- 이미 만렙(Lv3)인 카드는 추첨 풀에서 제외 → 자연히 새 카드/진화로 유도.

### ③ 진화 조건 (게이트)
**진화 = 그 카드 Lv3(만렙) + 같은 *자원축* 동사 2개 이상 보유.**
- 자원축 = `소음` / `시계`(옛 감염축, 타임어택 전환으로 개명) / `킬(연속·on-kill)` / `기동`(2026-06-03 스텔스 제거로 신설). (verbs §0.5 "자원 축 공명" 채택 — "같은 계열 N개"는 혼합빌드를 죽여서 폐기.)
- 예: 대시 회피 진화 = 대시 회피 Lv3 + 기동축 동사(밀쳐내기 등) 2개.
- **느슨/빡빡은 플레이테스트 항목** — 한 런 ~7픽 중 1~2개 진화 보는 게 목표.

### ④ 시계축 비용 모델 (★ 2026-05-31 개정 — 옛 "볼록 비용" 폐기)
- 감염=타임어택 둠클락 전환으로, **시계축 도박 카드의 비용 = 시계 충전율 가산**(목줄이 짧아짐 = 더 빨리 DoT). 카드별 충전율 페널티는 §2.4에 명기.
- 옛 모델("감염 ≥0.7 받는 피해 +15%, ≥0.9 +30%")은 *항상 차오르는* 둠클락과 이중 페널티 → **폐기**. 연출(화면/음향 부패)은 시계 % 기준으로 빌드 무관 항상 심화(유지).
- 🔧 훅: **시계 충전율 배수 레이어** 신규(`SyncRateManager` 시간 충전 `r`에 곱연산 진입점).

### ⑤ 카드 총량 — 검증
기본 8(+후보 2) + 동사 10(소음 4 / 킬 1 / 시계 4 / 거리 1) + 시그니처 4 + 폴백 1 = **~23장**.
- 한 런 ~7픽, 카드당 Lv1→3 누적이므로 집중 빌드는 같은 카드를 재픽 → 풀 고갈 없음.
- 무기별 시그니처 2장만 등장(선택 무기) → 실드로우 풀 = 기본10 + 동사10 + 시그니처2 + 폴백1 ≈ 23. **7픽 다양성 충분 판정.** (재검증: 플레이테스트)

### ⑥ 양날검(⚖️) 검증 — 플레이테스트 관찰 항목
- **소음 폭주**: 소음 유지가 "도박"인가 "그냥 죽음"인가. → 임계/배수 조절.
- **소각전술 / 막장투자**: "목줄을 태워 화력"이 짜릿한 도박인가 자살인가. → 충전율 페널티 곡선 조절.
- **사채계약**: 재료 욕심 vs 시계 압박의 긴장이 성립하는지.
- 판정 기준: 픽률이 극단(아무도 안 뽑음 / 무조건 뽑음)이면 실패. 빌드 분기 후보로 갈리면 성공.

### 2.4 동사 카드 — 빌드 정체성

> 진화 자원축(§1-③)의 `감염` → **`시계`**로 치환.

## 3. 코드 훅 의존 요약 (구현 착수용)

카드를 코드로 옮기기 전 **공통으로 먼저 만들 신규 시스템** (handoff §4 + 본 명세 교차):

| 신규 훅 | 의존 카드 | 우선도 |
|---|---|---|
| **스탯 mod 레이어** (공속/데미지/이속/maxHP/탐지반경/픽업반경/XP배수) | 거의 전 기본 카드 + 다수 동사 | **최상** (가장 많이 의존) |
| **AbilityManager / 카드 보유·레벨·적용·드로우** | 전부 | **최상** |
| **OnZombieKilled 이벤트 + 킬 카운터** | 연속 처치·풀스윙·학살의 박자 | 높음 |
| **시계 충전율 배수 레이어** (`SyncRateManager` `r`에 곱연산) | 소각전술·막장투자·사채계약·귀환호흡 | 높음 |
| **근접 공격(야구방망이) + 넉백** | 방망이 기본·시그니처 4장 | 높음(방망이 빌드 전제) |
| **대시/무적 프레임 + 부채꼴 넉백·비틀** (신규) | 대시 회피·밀쳐내기 | 높음(기동 빌드 전제) |
| **소음 억제/정지/감산 경로** (NoiseManager 공개 정지 없음) | 소음 폭주·연속 처치·관통탄 | 중 |
| **원점 거리/방향 판정** (BiomeResolver 좌표계) | 원정대원·귀환호흡 | 중 |
| **위치 기반 소음원** (현재 글로벌 단일값) | 소음 미끼·메아리 | 중 |
| **집 진입 이벤트** | 귀환호흡 Lv3 | post-MVP (귀환 트리거 도입 후) |

> **권장 구현 순서**: ① 스탯 mod 레이어 + AbilityManager 골격 → 기본 카드 8장으로 시스템 검증 → ② OnZombieKilled + 킬 카운터 → 연속 처치 → ③ 시계 충전율 배수 → 시계축 도박 동사 → ④ 근접 무기 → 방망이 카드 → ⑤ 소음 위치/억제 + 거리/기동 고급 동사. 진화는 전부 후순위.

## 4. 플레이테스트 미해결 (수치 검증)

1. **드로우 가중치 곡선** (§1-②) — 초반 동사 25%가 너무 적/많은지.
2. **진화 게이트** (§1-③) — "자원축 동사 2개"가 한 런에 1~2회 진화로 이어지는지.
3. **시계축 충전율 페널티** (§1-④) — 카드별 충전율 +30~40%가 "짜릿한 도박"인지 "그냥 자살"인지.
4. **양날검 픽률** (§1-⑥) — 소음 폭주·소각전술·막장투자가 빌드 분기 후보로 갈리는지.
5. **청크 절대 수치** — 각 카드 Lv1→3 증분이 "체감되는가" (특히 공속/이속 %).
6. **강선 +1의 파급** — General HP 3 기준 1발 처치가 밸런스를 깨는지(스폰 밀도와 연동).
