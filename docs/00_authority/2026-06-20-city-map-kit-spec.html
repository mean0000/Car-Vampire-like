도시 맵 모듈 키트 스펙 — 동결 v1

브루탈리스트 사이파이 · 탑다운 조준형 뱀서 첫 도시 맵 · 2026-06-20 · 결정: lv 에이전트 + Codex 독립 두 안 교차 → 유저 판정(48m 셀 · 2단 도로)

이 문서의 용도 — ① 유저가 타입별 건물 레퍼 이미지를 수급하는 쇼핑 리스트, ② 별도 세션이 그 이미지 + 이 스펙으로 모델링할 때 지킬 핸드오프 기준. 무드 레퍼 = docs/03_reference/reference_design/ (메가스트럭처 16장).

0동결 원칙 재논의 금지

  • 카메라 = 탑다운. 빌딩 = 벽/블로커, 도로·광장 = 플레이 네거티브 스페이스(액션 무대).
  • 탑다운 가시면 = 풋프린트 실루엣 + 옥상 + 도로변 하단 12~20m뿐. 중간 샤프트는 안 보임 → 모델링 디테일 예산을 거기 안 태운다.
  • 무드 = 브루탈리스트 사이파이 메가스트럭처(실사 A). 거대 단일 매스 · 하드서피스 그리블 · 수직 발광 스트립(주황/빨강) · 헤이즈/포그 · 억제된 청회색 도심.
  • 소품 전면 보류 — 전투 패스 검증 후 (§6).

1그리드 / 치수 유저 판정: 48m 셀

항목값
그리드 셀 (스냅 단위)48 m · 1 unit = 1 m
대로 (왕복 10차선)도로 ~35m + 커브/인도 버퍼 = 48m 타일 1셀
골목 (서비스 레인)24 m (반셀)
풋프린트 슬롯48² · 48×96 · 96² · 96×144 · L자(48/96 레그)
광장(킬존) 타일96² (2×2셀)
맵 전체6×6 셀 = 288×288 m
높이 티어저층 16~24m / 미드 50~70m / 메가 120~200m

2도로 유저 판정: 2단 · 셀 단위 타일 손배치

  • 대로 48m + 골목 24m. 트인 킬존 ↔ 조이는 매복 포켓의 공간 페이싱.
  • ★도로 = 한 장 슬래브 아님. 48m 셀 단위 모듈 타일을 유저가 그리드에 하나씩 손배치(오토 생성기 폐기).
  • 타일: 직선 · 코너 · T · 십자 · 막다른길 · 광장 — 유니크 ~5, 나머지 회전. 각 타일은 평평한 셀 면 + 차선/발광은 머티리얼·데칼.
  • 배치 환경: 48m 그리드 스냅 + 타일 팔레트(워크플로 미정 — 유저 호출 시 착수). 그리드 좌표 척추를 먼저 깐다.

3건물 타입 카탈로그 ★유저 레퍼 수급 타깃

각 타입마다 레퍼 1~3장 → reference_design/by_type/B{n}/ 정리. 별도 세션이 슬롯 치수에 맞춰 모델. owned 사이파이 빌딩 = 0개 → 손배치 불가. Synty 섞기 금지(셰이더 클래시). 3단 문법 공통: 포디움 + 샤프트 + 크라운.

역할 — 블록 경계 벽 · 채움

4모델링 핸드오프 기준 ★별도 세션이 지킬 것

  • 스케일 · 1 unit = 1 m, 실측. 풋프린트는 48m 그리드 배수 스냅(48/96/144). 건물은 풋프린트 셀을 채우되 도로 여유 남긴다.
  • 피벗/축 · 원점 = 베이스 중앙, 건물은 Z=0 위에 서고 +Z 업. (Unity FBX 임포트 축 정합 확인)
  • 비균일 스케일 금지 · 굽거나 늘인 스케일을 메시에 굽지 마라 → NavMesh 베이크 깨짐. 진짜 치수로 모델.
  • 탑다운 디테일 예산 · 디테일은 ⓐ옥상/크라운, ⓑ도로 면하는 하단 12~20m 파사드에만. 중간 샤프트는 플랫/저폴리.
  • 발광 스트립 = 별도 머티리얼/Emissive 맵 · 글로우를 알베도에 굽지 마라 — URP 포스트 블룸이 공짜로 띄움.
  • 서피싱 = 실사/PBR 브루탈리스트 · Synty식 플랫 셀 셰이딩 금지(클래시).
  • 익스포트 · 건물당 FBX(또는 .blend), 네이밍 B{타입}_{풋프린트}_{티어}, 원점 베이스 중앙.
  • 폴리 예산 · 메가/히어로는 소수라 밀도 허용, 양산 타입(B1/B2)은 모듈러/인스턴스 그리블로 절약.
