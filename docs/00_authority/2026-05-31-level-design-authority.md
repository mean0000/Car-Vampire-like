# 레벨 디자인 권위 문서 — 도심 구간 (감염 시계 × 3 프론트 게이트)

> 🟥 **전면 무효 (2026-06-09).** 거리 기반 3 프론트 게이트(300/650/1000m)는 폐기 → **이벤트 풀로 대체**. 현행 권위 = [[2026-06-09-postprocessing-core-design]](작전 타이머 + 이벤트). 이 문서는 역사 참고용.

> **작성일**: 2026-05-31
> **상태**: 설계 확정 (구현 핸드오프 전). 수치는 시작값 — §9 튜닝 가이드대로 플레이테스트에서 조정.
> **선행**: `2026-05-27-new-direction-gdd.md`(v2.7), `2026-05-29-infection-noise-design.md`, `2026-05-29-progression-system.md`
> **이 문서가 권위인 범위**: 도심(도보) 구간의 런 구조 · 맵 생성 · 감염 시계 · 게이트 · 스폰 페이싱. 평원(드라이브) 이후 구간은 범위 밖.

## 0. 멘탈 모델 (한 줄)

> **시계 = 내 목줄. 시간이 알아서 줄인다. 카드는 목줄을 더 빨리 줄이는 대신 힘을 주는 도박. 게이트 템은 목줄을 늘려준다. 귀환하면 목줄이 회복된다.**

이 문서의 모든 수치는 이 한 줄을 성립시키기 위한 도구다. 수치가 멘탈 모델과 충돌하면 멘탈 모델이 이긴다.

---

## 1. 런 구조 개요

```
[집/거점] (원점)
   │ 도보 — 감염 시계가 시간당 자동으로 차오름
   │ 시계가 차기 전에 귀환 = 시계 감소 (목줄 회복)
   ▼
프론트 게이트 ① — 엘리트 좀비 처치    → 시계 천장 +0.3 템 드롭 (목줄 +)
   ▼
프론트 게이트 ② — 대량 호드 정리       → 시계 천장 +0.3 템 드롭 (목줄 +)
   ▼
프론트 게이트 ③ — 보스                → 자동차 부품 드롭 → 평원 탈출
```

- **방향 전환의 핵심**: 감염도(SyncRate)를 **행동 비용 미터**에서 **시간 구동 둠클락**으로 전환. 시간이 곧 위험.
- **게이트 = 프론트형 관문** (단일 보스 1마리가 아니라 "그 구역을 돌파해야 열리는 지점"). 절차 생성 지형 위에 거리 임계마다 박는다.
- **3개 게이트, ③이 부품 드롭 → 평원(드라이브 구간)으로 전환.**

---

## 2. 감염 시계 (시간 = 감염도)

### 2.1 모델

`SyncRate ∈ [0, 1]`, 시작 0. **시간으로 자동 충전**된다.

| 파라미터 | 시작값 | 의미 |
|---|---|---|
| 기본 충전율 `r` | **0.0083 /s** (≈ 천장 1.0 / 120s) | 밖에서 가만히 있어도 ~2분이면 가득. 초기 목줄 길이 |
| 게이트 천장 상향 | **+0.3 (1.0 → 1.3 → 1.6)** (게이트당 1회 영구) | DoT 발동 임계를 올림 → 시계 만땅까지 더 오래 = 목줄이 길어짐 |
| 귀환 감소 | **0.6 즉시** (또는 전량 리셋) | 집 진입 시. 부분 감소가 "완전 리셋보다 다음 출발 긴장" 유지 |
| MAX 도달 (현재 천장) | **즉사 아님 → DoT 시작** | 천장을 넘긴 시점부터 지속 체력 감소로 전환 |
| DoT 비율 | **5 HP/s** (HP 100 기준) | 시계 넘겨도 ~20초 버틸 수 있음 = "넘긴 채 밀어붙이는" 그라데이션 압박 |

> **천장 누적 효과 (게이트별 목줄 길이):** `r=0.0083` 고정, 천장만 오른다.
> ```
> 게이트 0개: 천장 1.0  → 목줄 ~120초
> 게이트 1개: 천장 1.3  → 목줄 ~156초
> 게이트 2개: 천장 1.6  → 목줄 ~193초
> ```
> 게이트를 깰수록 더 깊이/오래 머물 수 있다 = "다음 단계로 나아가고 싶은 욕구"를 시스템이 직접 보상.

### 2.2 "시계를 늘린다"의 구현 = 천장 상향 (확정)

게이트는 **시계의 최대치(DoT 발동 임계)를 올린다.** `1.0 → 1.3 → 1.6`. 이게 멘탈 모델("게이트 템이 목줄을 늘린다")의 직역이고, 타임어택 프레임("제한선을 미는 게 게이트")과 정확히 일치한다.

> **HUD/카드 0~1 정규화 깨짐 우려 → 표시 정규화로 해소:**
> 내부 `SyncRate`는 절대값(천장 1.0~1.6), **HUD 게이지는 `SyncRate / 현재천장`으로 정규화 표시**한다. 그러면 바는 항상 0~100%로 보여 HUD·카드가 그대로 동작하고, 천장이 오르면 "같은 SyncRate라도 게이지가 덜 찬다"가 자연스럽게 체감된다.
> - 시계축 카드가 절대값을 가산하는 경우 **절대값 가산** 유지 → 천장이 클수록 한 번의 가산이 게이지의 더 작은 비율을 차지 = 후반 여유. 의도된 보상.
> - 한때 (A) 충전율 둔화를 권장했으나 폐기. 체감은 비슷해도 "게이트=최대치 상향"이라는 확정 멘탈 모델과 어긋난다.

### 2.3 카드 기반 감염 가속과의 공존 (시계축 카드 생존)

- 시계 = **기본 압박** (시간, 자동). 누구나 동일.
- 시계축 카드 = **추가 도박** (선택). 같은 게이지를 더 빨리 밀어 화력/보상을 산다:
  - **`소각전술`·`막장투자`·`사채계약`·`귀환호흡`** — raw 수치를 더하지 않고 **충전율 배수 / 귀환 감소량**을 조절. "남은 시간을 화력으로 환전."
- **추적할 숫자는 "목줄 하나"뿐** → 시간·카드 두 출처가 같은 게이지를 밀어도 복잡하지 않다.

> 카드 상세는 `2026-05-31-levelup-cards-catalog.md` 권위. (구) 행동 기반 감염(`Space 잠입 AddSync`)은 스텔스 제거(2026-06-03)와 함께 폐기 — 가속의 유일 출처는 시계축 카드.

## 3. 거리 기반 난이도 (BiomeResolver 재활용)

원점(집)에서의 **반경 거리** `d = √(x² + z²)`가 난이도·바이옴·게이트 배치의 단일 기준축.

밀도는 **거리에 따라 오르는 곡선이며, 바닥값이 0이 아니다.** 집 구조물 자체만 진짜 안전(스폰 0)하고, 집 인접부터도 약하게 위험하다. "안전지대"는 폐기 — 위험은 어디든 존재하고 **양만 다르다** (2026-06-03 확정).

| 거리대 (m) | 좀비 밀도 | 등급 분포 | 비고 |
|---|---|---|---|
| 집 구조물 내부 | 0 | — | 유일한 진짜 안전. PitStopZone 시계 회복 |
| 0 ~ 50 | 낮음(0 아님) | 일반 95% / 신호 5% | 집 인접, 소수 배회자 |
| 50 ~ 300 | 기본 | 일반 90% / 신호 8% | 게이트 ① 권역 |
| 300 ~ 650 | +30% | 일반 80% / 신호 12% / 대형 등장 | 게이트 ② 권역 |
| 650 ~ 1000 | +60% | 일반 70% / 신호 15% / 대형·소형 | 게이트 ③(보스) 권역 |

- **밀도는 "플레이어 추종 트레드밀"이 아니라 "블록별 유한 사전 배치"로 구현** (§7 참조). 위 밀도값은 거리 링별 블록 인구 예산의 기준.
- 거리는 **욕망**이지 강요가 아님(GDD v2.5). 멀수록 좋은 재료/진행이지만, 시계 목줄이 그만큼 빠듯해진다.

## 4. 거점/집 (귀환 루프)

- **위치**: 원점 고정. **집 구조물 내부만 스폰 0** (유일한 진짜 안전). 집 인접부(0~50m)부터는 약하게 위험 — "안전지대" 개념 폐기, §3 참조 (2026-06-03).
- **`PitStopZone`을 도보용으로 전환** — 현재 `CarController` 트리거 → `PlayerController`로 교체. 진입 시:
  - `SyncRateManager.ReduceSync(0.6)` (시계 목줄 회복)
  - 나노봇 교란 펄스 (주변 좀비 흩어짐 연출 — GDD v2.6)
  - 보류된 레벨업 카드 처리 (현재 `PendingLevels` 흐름 재활용)
- **재입장 제한 없음 (MVP)** — 왕복 이동 시간 + 시계 압박 + 거리-보상 곡선이 자연적 브레이크.

## 5. 프론트 게이트 3종

### 5.1 공통 규칙 (2026-06-03 확정)

- **거리 임계의 고정 슬롯** — 게이트 위치는 거리대별 고정. (지형은 Synty 손배치 고정맵, §6 참조.)
- **돌파 = 진행 잠금 해제** — 게이트를 깨면 다음 깊이로 나아갈 보상을 받는다.
- 게이트는 **AI 센터 신호 방향**(GDD §6-4)에 놓여 자연 유도. 미니맵 힌트가 점점 명확해지는 설계와 정합.
- **세 게이트는 서로 다른 축을 시험한다** (리듬·비(非)동질성): ① 듀얼 → ② 군중 → ③ 패턴 숙달. ③이 ①②를 종합. 서사 아크 = **유기 좀비 → 기계(로봇) → 다음 세계(평원)**.
- **★ 싸움 중 감염 시계는 계속 차오른다** (시그니처 압박, DPS 레이스 긴장). 압력 밸브 = ①②의 천장 상향(+0.3씩)이 "다음 더 어려운 싸움의 숨통"이 되는 파워 커브 + 귀환·재도전.
- **★ 이탈 = 보스/게이트 풀피 리셋.** 도중에 빠져나가면 진행이 초기화된다. 준비해서 커밋하라는 설계.
- **빌드 편식은 하드 월로 막지 않는다.** ①단일·②광역·③기동+타이밍으로 축이 갈리지만, **무기 파워 성장이 캐리**하므로 게이트는 "빌드 체크"가 아니라 **맛·리듬 스파이크 수준**으로 튜닝. 한 축만 판 플레이어도 돌파 가능해야 함.

### 5.2 게이트별 특징 (확정)

| # | 거리대 | 타입 | 돌파 동사 | 보상 | 시험 축 |
|---|---|---|---|---|---|
| ① | ~300m | **차저형 엘리트** | 엘리트 1마리 처치 | 시계 둔화 템 (×0.75, 천장 +0.3) | 듀얼 — 단일 화력·회피 |
| ② | ~650m | **점령 게이지 호드** | 점령 게이지 채우기(킬=게이지) | 시계 둔화 템 (×0.75, 천장 +0.3) | 군중 제어 — 광역·카이팅 |
| ③ | ~1000m | **페이즈 로봇 보스** | 보스 HP 0 | **자동차 부품** → 평원 탈출 | 패턴 숙달 — 실행력 |

### 5.3 게이트별 상세

**① 차저형 엘리트 (듀얼, 진입 워밍업)** — *전투 설계 확정 2026-06-03*
- 변종 거대 좀비. 첫 "이름 있는 위협" — "내 빌드가 굴러가나" 검증 + 게이트 의식(아레나·체력바·보상 드롭) 학습.
- HP 스펀지 금지. **3단 돌진 루프 하나**가 전투의 전부:
  1. **텔레그래프**(예고·정렬) — 몸이 플레이어 쪽으로 정렬 + 돌진 궤적 표시. 충분히 길어서 **맨몸 걷기로 피할 수 있어야 함**(아래 회피 참조).
  2. **돌진** — 정렬 방향 직선 고속 돌진.
  3. **헛침 후 경직(반격 창)** — 벽/허공에 박고 잠시 경직. 유효타 타이밍.
- **★ 방향성 장갑 (핵심 스킬 — 정면/후방):** 정면 피격은 **데미지 80% 감소**(20%만 박힘), **후방 피격은 정상 데미지**. → 돌진을 피한 뒤 **등 뒤로 돌아 때리는 것**이 승리 동선. HP를 깎는 게 아니라 위치를 따내는 싸움 = HP 스펀지 회피.
- **회피 수단 = 걷기(맨몸 사이드스텝)로 확정.** 기동 카드 없이도 텔레그래프를 보고 걸어서 피할 수 있다 = 빌드 편식 하드월 없음 원칙 준수. (대시 회피 등 추가 액션으로 더 안전·반격 타이밍을 벌 수 있게 할지는 **보류 — 추후 고민**.)
- **★ 돌진 외 추가 위협 = 잡몹 지속 스폰 (확정).** 엘리트와 싸우는 동안 **적은 수의 일반 좀비가 계속 흘러나옴** — 돌진 라인 회피 + 등 뒤 진입을 잡몹이 방해 = 공간 관리 압박. **이건 이벤트 범위의 저레이트 흐름이지 §7의 폐기된 추종 트레드밀이 아니다**(엘리트 권역 한정, 디제틱 출처). 레이트는 "적더라도 끊기지 않게" — 수치는 §5.4 미정.
- **★ 엘리트 리쉬 = 권역 밖 이탈 불가 (확정).** 엘리트는 게이트 권역을 벗어나지 않는다. 플레이어가 빠지면 엘리트는 복귀+풀피 리셋(§5.1 공통 규칙), 플레이어는 시계만 손해. "준비해서 다시 와라" 강화.
- 권역의 지정 엘리트 1마리 처치 → 드롭.

**② 점령 게이지 호드 (군중, 뱀서 정점)**
- 평소 세계가 패시브·희박하기에 **여기가 유일하게 "뱀서가 되는" 순간** (의도된 대비). 신규 스폰 모델의 **"건물에서 쏟아짐"을 풀가동** — 건물 밀집 광장 진입 시 사방 문·창문에서 호드 폭발(디제틱 시각 정점).
- 승리 = **점령 게이지** (킬이 게이지를 채움, 많이 죽일수록 빨리 클리어). **플레이어가 지속시간을 통제** → 시계와의 이중 압박을 스스로 조절. (순수 T초 생존은 시계와 겹쳐 가혹해서 폐기.)
- ①이 단일표적이었으니 **광역/군중 카드가 빛나는 무대** = 빌드 다양성 맛.

**③ 페이즈 로봇 보스 (패턴 숙달, 도심 종결)**
- **서사 전환점**: 유기 좀비 → 기계. 세계관(AI 나노봇, 향하는 곳=AI 센터)과 직결 — 더 깊은 테크 구역의 수문장. 처치 → 차 부품 드롭 → 평원 탈출(바이옴 전환).
- ①(스탯)·②(인내)와 달리 **배우고 실행하는 기믹 보스**. 로봇이니 좀비(근접·유기)와 대비되게 **원거리·기계적**:
  - 페이즈1: 레이저/미사일 원거리 → 거리 좁히며 회피 (기존 Laser 변종이 미니 티저).
  - 페이즈2: 좀비 소환 or 돌진 → ①②에서 배운 걸 종합.
  - 약점 코어: 평소 장갑, 특정 공격 후 코어 개방 → 타이밍 학습.
- 가장 긴 싸움 = 도착 시 시계 최고 → ①②의 천장 상향이 여기서 결실. 별도 핸드오프로 패턴 상세 설계.

- **`BossController`는 폐기→신규** — 현재 코드는 드라이브 시절 잔재(접촉 시 차 연료 충전). 게이트 로직과 무관.

### 5.4 미정 (구현/튜닝 시)
- 차저 돌진 텔 길이·쿨다운, 경직(반격 창) 길이, 엘리트 HP/데미지 배수, 정면 장갑 정확값(추천 80% 감소), 잡몹 지속 스폰 레이트("적더라도 끊기지 않게").
- 점령 게이지 총량, 킬당 게이지, 호드 스폰 레이트.
- 로봇 페이즈 전환 임계, 패턴 타이밍, 코어 개방 윈도우 — 별도 핸드오프.

## 6. 맵 생성 — 모듈형 절차 (전투 포지셔닝 양립)

> ⚠️ **이 절은 절차 생성(ChunkManager) 전제로 작성됨. 현재 맵 방향은 Synty 손제작 고정 맵으로 전환됨(메모리 `project_map_synty_handauthored`).** 두 방향이 충돌하므로 별도 설계 판단 필요 — 이 절은 절차 생성을 택할 경우의 참고로만 유지.

> **문제**: 순수 노이즈 산포(랜덤 프롭)는 전투가 요구하는 **의도된 교전선·엄폐물·호드 깔때기 배치**를 못 만든다. 하지만 매번 다른 맵이라는 절차 생성의 이점은 살리고 싶다.

> **해법: 오써드 블록을 절차적으로 조립.** 손으로 디자인한 도심 타일(시야선/엄폐/골목이 설계된 블록 몇 종)을 `ChunkManager`가 절차적으로 배치. = "구조는 보장, 배열은 매번 다름."

- **`ChunkManager` 재활용** (chunkSize=80, 7×7 스트리밍) — 청크 프리팹을 **단일 지형 → 도심 블록 팔레트에서 랜덤 추출**로 교체.
- **블록 종류 (MVP 최소)**: 교차로 / 직선 골목 / 광장(게이트 아레나용) / 막다른 길(엄폐). 각 블록은 교전선·엄폐·호드 깔때기가 손으로 설계됨.
- **`ZombieSpawner`의 `OverlapsObstacle`** (건물 footprint 안 스폰 금지)이 이미 있어 블록 콜라이더와 호환.
- 게이트 권역은 **광장 블록 고정 배치** — 절차 지형 안에 게이트만 결정론적.

## 7. 스폰 모델 (2026-06-03 전면 개정 — 트레드밀 폐기)

> **★ 현행 `ZombieSpawner`의 "플레이어 추종 트레드밀"(주변 15~25 항상 유지, 죽이면 즉시 보충, 화면밖 팝인)은 폐기.** 공간 정보를 죽이고 "패시브 좀비 + 거리=욕망 + 공간 정복" 정체성과 충돌하기 때문. PM·Codex 브레인스토밍 합의 + 사용자 확정.

### 7.1 핵심 모델 — "블록별 유한 + 시계가 미는 전진형 XP"

뱀서식 XP 루프는 *같은 자리 무한 리스폰*이 아니라 *움직이는 동안 꾸준한 킬*만 필요하다. 우리는 이미 **전진 엔진(감염 시계 + 거리=욕망)**을 갖고 있으므로, 트레드밀을 **"시계가 미는 전진"으로 대체**한다.

- **레벨업은 캠핑이 아니라 전진으로 번다.** 가만히 있으면 → 주변 좀비 고갈 + XP 마름 + 시계가 죽임 → 더 깊은(미정복) 블록으로 밀려난다. **XP 경제와 "깊이 들어가라" 압력이 같은 동작이 된다.**
- 후반 파밍 농도는 "세계가 깊을수록 밀도↑(§3)"로 자연 확보.

### 7.2 스폰 되는/안 되는 상황

| 상황 | 규칙 |
|---|---|
| 집 구조물 내부 | 스폰 0 (유일한 진짜 안전) |
| 집 인접~프런티어 | **블록별 유한 사전 배치.** 거리 링별 인구 예산(§3) |
| 이미 클리어한 블록 | **느린 저밀도 스밈** — 몇 분에 걸쳐 배회자 소수만 복귀. 원밀도로 절대 복구 안 됨. → 귀환로=숨통이되, "위험 0인 곳"은 없음 |
| 조용할 때(소음 없음) | 새 유입 없음. 배회자만 존재 |
| 이벤트 트리거 | 폭발적 동적 스폰, **1회성** (§7.4) |

### 7.3 스폰 방식 — 디제틱 (화면밖 마법 팝인 폐기)

- **사전 배치(베이스라인):** 월드 로드 시 블록별로 이미 좀비가 배치되어 배회. "세계가 살아있었다."
- **공정성 철칙:** 플레이어 정면 시야 안에 마법 팝인 금지. 동적 스폰은 **보이는 디제틱 출처**(문/창문/지하/폐허) 또는 등뒤에서, **텔(그림자·소리 0.5초)**과 함께.

### 7.4 이벤트 스폰 (폭발적·1회성)

- **건물 쏟아짐** — 빌딩 존 진입 트리거 → 문·창문 스폰포인트에서 방출. 건물당 1회(`triggered` 플래그, 런 단위, 세이브 불필요).
- **소음 호드** — *신규 스폰이 아니라 반경 내 배회자의 상태 전환*(활성화→몰려옴). 팝인 자체가 없음 + 유지된 "소음=전투 비용" 축과 직결. 고소음 임계(폭발)는 지도상 고정 스테이징(골목 입구)에서 추가 호드 + 연기 텔.
- **게이트 호드** — 게이트 ② 입장 연출. 1회 대량, 지하/폐허에서 솟는 디제틱.

### 7.5 구현 아키텍처 — 데이터/실체 분리

유한·정복형인데 성능 위해 디스폰을 쓰면 모순. 해소:
- **데이터 모델**(블록별 인구 예산 + `cleared` 플래그 + 스밈 타이머)는 영속. **실체**(좀비 GameObject)는 근접 시 스트리밍 인스턴스화/디스폰.
- 멀어져 디스폰돼도 `cleared`·스밈 상태는 데이터에 남음 → **재진입해도 비어있음(스밈분만 복귀).**
- **Synty 손배치 고정맵**(`project_map_synty_handauthored`)의 블록별 스폰 볼륨과 정합.

### 7.6 MVP 범위

1. **1단계:** 사전 배치 + 건물 쏟아짐 (사용자 요청 2개 직커버).
2. **2단계:** 소음 호드 + cleared 블록 스밈.
3. **3단계:** 게이트 호드 (게이트 구현 시 동반).
- 시간 가중(뱀서 원칙)은 시계가 이미 시간 압박이므로 **도입하지 않거나 극히 완만**(이중 압박 과부하 주의).

## 9. 플레이테스트 튜닝 가이드
