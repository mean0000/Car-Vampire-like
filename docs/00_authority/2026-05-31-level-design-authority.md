# 레벨 디자인 권위 문서 — 도심 구간 (감염 시계 × 3 프론트 게이트)

> **작성일**: 2026-05-31
> **상태**: 설계 확정 (구현 핸드오프 전). 수치는 시작값 — §9 튜닝 가이드대로 플레이테스트에서 조정.
> **선행**: `2026-05-27-new-direction-gdd.md`(v2.7), `2026-05-29-infection-noise-design.md`, `2026-05-29-progression-system.md`
> **이 문서가 권위인 범위**: 도심(도보·스텔스) 구간의 런 구조 · 맵 생성 · 감염 시계 · 게이트 · 스폰 페이싱. 평원(드라이브) 이후 구간은 범위 밖.

---

## 0. 멘탈 모델 (한 줄)

> **시계 = 내 목줄. 시간이 알아서 줄인다. 카드는 목줄을 더 빨리 줄이는 대신 힘을 주는 도박. 게이트 템은 목줄을 늘려준다. 귀환하면 목줄이 회복된다.**

이 문서의 모든 수치는 이 한 줄을 성립시키기 위한 도구다. 수치가 멘탈 모델과 충돌하면 멘탈 모델이 이긴다.

---

## 1. 런 구조 개요

```
[집/거점] (원점)
   │ 도보·스텔스 — 감염 시계가 시간당 자동으로 차오름
   │ 시계가 차기 전에 귀환 = 시계 감소 (목줄 회복)
   ▼
프론트 게이트 ① — 엘리트 좀비 처치    → 시계 천장 +0.3 템 드롭 (목줄 +)
   ▼
프론트 게이트 ② — 대량 호드 정리       → 시계 천장 +0.3 템 드롭 (목줄 +)
   ▼
프론트 게이트 ③ — 보스                → 자동차 부품 드롭 → 평원 탈출
```

- **방향 전환의 핵심**: 감염도(SyncRate)를 **행동 비용 미터**에서 **시간 구동 둠클락**으로 전환. 시간이 곧 위험.
- **게이트 = 프론트형 관문** (단일 보스 1마리가 아니라 "그 구역을 돌파해야 열리는 지점"). 절차 생성 지형 위에 거리 임계마다 박는다.
- **3개 게이트, ③이 부품 드롭 → 평원(드라이브 구간)으로 전환.**

---

## 2. 감염 시계 (시간 = 감염도)

### 2.1 모델

`SyncRate ∈ [0, 1]`, 시작 0. **시간으로 자동 충전**된다.

| 파라미터 | 시작값 | 의미 |
|---|---|---|
| 기본 충전율 `r` | **0.0083 /s** (≈ 천장 1.0 / 120s) | 밖에서 가만히 있어도 ~2분이면 가득. 초기 목줄 길이 |
| 게이트 천장 상향 | **+0.3 (1.0 → 1.3 → 1.6)** (게이트당 1회 영구) | DoT 발동 임계를 올림 → 시계 만땅까지 더 오래 = 목줄이 길어짐 |
| 귀환 감소 | **0.6 즉시** (또는 전량 리셋) | 집 진입 시. 부분 감소가 "완전 리셋보다 다음 출발 긴장" 유지 |
| MAX 도달 (현재 천장) | **즉사 아님 → DoT 시작** | 천장을 넘긴 시점부터 지속 체력 감소로 전환 |
| DoT 비율 | **5 HP/s** (HP 100 기준) | 시계 넘겨도 ~20초 버틸 수 있음 = "넘긴 채 밀어붙이는" 그라데이션 압박 |

> **천장 누적 효과 (게이트별 목줄 길이):** `r=0.0083` 고정, 천장만 오른다.
> ```
> 게이트 0개: 천장 1.0  → 목줄 ~120초
> 게이트 1개: 천장 1.3  → 목줄 ~156초
> 게이트 2개: 천장 1.6  → 목줄 ~193초
> ```
> 게이트를 깰수록 더 깊이/오래 머물 수 있다 = "다음 단계로 나아가고 싶은 욕구"를 시스템이 직접 보상.

### 2.2 "시계를 늘린다"의 구현 = 천장 상향 (확정)

게이트는 **시계의 최대치(DoT 발동 임계)를 올린다.** `1.0 → 1.3 → 1.6`. 이게 멘탈 모델("게이트 템이 목줄을 늘린다")의 직역이고, 타임어택 프레임("제한선을 미는 게 게이트")과 정확히 일치한다.

> **HUD/카드 0~1 정규화 깨짐 우려 → 표시 정규화로 해소:**
> 내부 `SyncRate`는 절대값(천장 1.0~1.6), **HUD 게이지는 `SyncRate / 현재천장`으로 정규화 표시**한다. 그러면 바는 항상 0~100%로 보여 HUD·카드가 그대로 동작하고, 천장이 오르면 "같은 SyncRate라도 게이지가 덜 찬다"가 자연스럽게 체감된다.
> - 행동 비용(잠입 `AddSync(0.1)` 등)은 **절대값 가산** 유지 → 천장이 클수록 한 행동이 게이지의 더 작은 비율을 차지 = 후반 행동 여유. 의도된 보상.
> - 한때 (A) 충전율 둔화를 권장했으나 폐기. 체감은 비슷해도 "게이트=최대치 상향"이라는 확정 멘탈 모델과 어긋난다.

### 2.3 행동 기반 감염과의 공존 (감염 카드 생존)

- 시계 = **기본 압박** (시간, 자동). 누구나 동일.
- 행동 = **추가 도박** (선택). 같은 게이지를 더 빨리 민다:
  - **Space 잠입** — 즉시 `+0.08` (현재 코드 `AddSync(0.1)` → 이 모델에 맞춰 조정). "사라지려고 동기화를 당겨썼다."
  - **감염 카드** (`감염 가속`·`오염된 귀환`·`볼록 비용`) — raw 수치를 더하지 않고 **충전율 배수 / 귀환 감소량**을 조절. "남은 시간을 화력으로 환전."
  - **`전이` 카드만 보류** — 별도 타깃(좀비 감염) 필요해 무거움. MVP 제외.
- **추적할 숫자는 "목줄 하나"뿐** → 시간·행동 두 출처가 같은 게이지를 밀어도 복잡하지 않다.

> 카드 상세는 `2026-05-31-levelup-cards-catalog.md` 권위. 이 전환으로 감염 카드의 **효과 정의만** "raw add → 충전율 배수"로 바뀐다(카드 자체는 유지).

## 3. 거리 기반 난이도 (BiomeResolver 재활용)

원점(집)에서의 **반경 거리** `d = √(x² + z²)`가 난이도·바이옴·게이트 배치의 단일 기준축.

| 거리대 (m) | 좀비 밀도 | 등급 분포 | 비고 |
|---|---|---|---|
| 0 ~ 30 | 0 (안전지대) | — | 집 주변, 스폰 없음 |
| 30 ~ 200 | 기본 (min15/max25) | 일반 90% / 신호 8% | 게이트 ① 권역 |
| 200 ~ 450 | +30% | 일반 80% / 신호 12% / 대형 등장 | 게이트 ② 권역 |
| 450 ~ 700 | +60% | 일반 70% / 신호 15% / 대형·소형 | 게이트 ③(보스) 권역 |

- **`ZombieSpawner`에 거리 가중 추가 필요** — 현재는 거리 무관 고정 인구. `playerTransform.position.magnitude`(원점 기준)로 `maxZombies`·`signalSpawnChance`를 스케일.
- 거리는 **욕망**이지 강요가 아님(GDD v2.5). 멀수록 좋은 재료/진행이지만, 시계 목줄이 그만큼 빠듯해진다.

## 4. 거점/집 (귀환 루프)

- **위치**: 원점 고정. 주변 30m 안전지대(스폰 없음).
- **`PitStopZone`을 도보용으로 전환** — 현재 `CarController` 트리거 → `PlayerController`로 교체. 진입 시:
  - `SyncRateManager.ReduceSync(0.6)` (시계 목줄 회복)
  - 나노봇 교란 펄스 (주변 좀비 흩어짐 연출 — GDD v2.6)
  - 보류된 레벨업 카드 처리 (현재 `PendingLevels` 흐름 재활용)
- **재입장 제한 없음 (MVP)** — 왕복 이동 시간 + 시계 압박 + 거리-보상 곡선이 자연적 브레이크.

## 5. 프론트 게이트 3종

### 5.1 공통 규칙

- **거리 임계의 오써드 슬롯** — 지형은 절차 생성(ChunkManager), 게이트 위치는 거리대별 **고정 슬롯**. "절차 지형 + 오써드 게이트 아레나".
- **돌파 = 진행 잠금 해제** — 게이트를 깨면 그 권역의 다음 깊이로 나아갈 동기(시계 둔화 템)를 받는다.
- 게이트는 **AI 센터 신호 방향**(GDD §6-5)에 놓여 자연 유도. 미니맵 힌트가 점점 명확해지는 기존 설계와 정합.

### 5.2 게이트별 동사 (난이도 상승 곡선)

| # | 거리대 | 돌파 동사 | 보상 | 설계 의도 |
|---|---|---|---|---|
| ① | ~200m | **엘리트 좀비 처치** | 시계 둔화 템 (×0.75) | 단일 강적, 진입 워밍업. "스텔스 암살 vs 정면" 선택 |
| ② | ~450m | **대량 호드 정리** (일정 수 처치 or 시간 점거) | 시계 둔화 템 (×0.75) | 물량 압박. 뱀서식 정점. 소음↔호드 시스템 풀가동 |
| ③ | ~700m | **보스** | **자동차 부품** → 평원 탈출 | 정점 스킬 체크. 도심 구간 종결 |

- **`BossController`는 폐기/신규** — 현재 코드는 드라이브 시절 잔재(접촉 시 차 연료 충전). 게이트 로직과 무관.
- ① 엘리트 = 일반 좀비 강화판(HP·데미지↑), ② 호드 = 기존 스폰 시스템 밀도 스파이크, ③ 보스 = 신규 디자인 필요(별도 핸드오프).

### 5.3 게이트 돌파 조건 상세 (구현 시 확정)

- **① 엘리트**: 권역의 지정 엘리트 1마리 처치 → 드롭.
- **② 호드**: 트리거 진입 시 호드 스폰 시작, **N마리 처치** 또는 **존 안에서 T초 생존**(둘 중 택1, 플레이테스트로 결정).
- **③ 보스**: 보스 HP 0 → 부품 드롭 + 평원 게이트 활성.

## 6. 맵 생성 — 모듈형 절차 (스텔스 양립)

> **문제**: 순수 노이즈 산포(랜덤 프롭)는 스텔스가 요구하는 **의도된 시야선·엄폐물 배치**를 못 만든다. 하지만 매번 다른 맵이라는 절차 생성의 이점은 살리고 싶다.

> **해법: 오써드 블록을 절차적으로 조립.** 손으로 디자인한 도심 타일(시야선/엄폐/골목이 설계된 블록 몇 종)을 `ChunkManager`가 절차적으로 배치. = "구조는 보장, 배열은 매번 다름."

- **`ChunkManager` 재활용** (chunkSize=80, 7×7 스트리밍) — 청크 프리팹을 **단일 지형 → 도심 블록 팔레트에서 랜덤 추출**로 교체.
- **블록 종류 (MVP 최소)**: 교차로 / 직선 골목 / 광장(게이트 아레나용) / 막다른 길(엄폐). 각 블록은 시야선·엄폐가 손으로 설계됨.
- **`ZombieSpawner`의 `OverlapsObstacle`** (건물 footprint 안 스폰 금지)이 이미 있어 블록 콜라이더와 호환.
- 게이트 권역은 **광장 블록 고정 배치** — 절차 지형 안에 게이트만 결정론적.

## 7. 스폰 페이싱

- 기본 인구는 `ZombieSpawner` 현행(min15/max25, 시야 내 1~3) 유지.
- **거리 가중 추가** (§3) — 원점 거리로 `maxZombies`·`signalSpawnChance` 스케일.
- **시간 가중 (뱀서 원칙, GDD §12)** — 런 경과 시간으로도 강도 상승. 단 시계가 이미 시간 압박이므로 **완만하게** (이중 압박 과부하 주의).
- **게이트 권역 스파이크** — 게이트 ② 진입 시 호드 버스트(별도 스폰 트리거).

## 9. 플레이테스트 튜닝 가이드

| 관찰된 증상 | 진단 | 조절 레버 |
|---|---|---|
| 귀환을 안 함 (시계 무시) | DoT 약함 / 충전 느림 | DoT 5→8 HP/s, `r` 0.0083→0.011 |
| 시계가 너무 빡빡 (밖에 못 나감) | 충전 빠름 / 둔화 약함 | `r`↓, 둔화 ×0.75→×0.65 |
| 게이트 깰 동기 약함 | 둔화 체감 약함 | 둔화 강화 + 게이트 권역 재료 등급↑ |
| 게이트가 너무 쉬움/어려움 | 권역 밀도·HP | §3 밀도 가중, 엘리트/보스 HP |
| 멀리 안 나감 | 거리 보상 약함 | 거리대별 등급 분포 기울기↑ |
| 시계+시간 이중 압박 답답 | 시간 가중 과함 | §7 시간 가중 완만화 |

> 측정 지표: 런당 귀환 횟수, 평균 귀환 시 SyncRate, 게이트 클리어율, 최대 도달 거리, DoT 진입 빈도.

## 10. 미정 (다음 결정)

- 게이트 ② 돌파 조건: 처치 수 N vs 점거 시간 T (§5.3).
- 귀환 감소: 부분(0.6) vs 전량 리셋 (§2.1).
- 보스 ③ 구체 디자인 (별도 핸드오프).
- 도심 블록 팔레트 실제 종류·개수 (§6).
- 평원 전환 연출/씬 흐름 (범위 밖, 후속).
