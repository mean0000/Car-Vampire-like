# 권위: 뱀서 대전환 + 사후처리부 2페이즈 개성 (2026-06-16)

**상태: 동결 (방향).** 이 문서는 2026-06-16 세션의 코어 방향 대전환을 못 박는다.
**이 문서가 이긴다** — 아래 "무효화" 목록의 옛 권위/메모리와 충돌하면 이 문서가 진실.

## 0. 한 줄 척추

> **조준형 로그라이트 뱀서.** 고정 보스마다 전용 그로테스크 야수 파벌이 (시간+처치로 차는 게이지를 타고) 몰려오고, 총기를 조준해 갈며 인런 무기 드래프트로 빌드를 쌓아 → **Peak에서 보스 격파로 런을 닫고** → 런 사이 **총기 업그레이드 + 캐릭터 성장(영구)**으로 다음 티어 보스에 도전.

장르 좌표 = **20 Minutes Till Dawn형** (조준 카이팅 뱀서 + 런마다 보스 클라이맥스).

- **저격 / 암살** — 정밀 조준 한 발·보장원샷·급습 보장즉살·스텔스 킬 (B-009 일체)

## 2. 잠근 것 — 새 척추 (positive)

| 항목 | 결정 |
|---|---|
| 장르 | 조준형 로그라이트 뱀서 (20MTD형) |
| 조작 | 방향 조준 + **총기** 사격 (무조준 자동공격 ❌) |
| 인런 무기 | 무기 드래프트 (레벨업→픽→진화), 매 런 리셋 = 그 판 손패 |
| 몬스터 미감 | 반실사 그로테스크 변종/외계 야수 베스티어리 (레퍼 = Protofactor 팩 이미지). 스워머→중형→브루트→거수 보스 |

| 보스 | **고정 보스** (런마다 동일/정해진 순서. 로테이션 전환은 언제든 가능, 지금은 고정) |
| 떼 구성 | 보스별 전용 야수 파벌이 몰려옴 = 런 = 하나의 생태/파벌 |
| 적 조직 | 스탯 티어(잡몹 떼→강몹→엘리트→보스) + 소수 특수 행동. **rigid 분류 금지** |
| 보스 게이지 | **시간(바닥 속도) + 처치(가속)**로 참 → 100%에 보스 등장. 빨리 죽일수록 일찍. 스폰 디렉터 Build→Peak에 동기화, 보스 = Peak |
| 메타 무기 (영구) | **총기 업그레이드** — 영구히 세짐 / 새 진화·티어 해금 = 도구함 |
| 메타 캐릭터 (영구) | **캐릭터 능력 상승** — 본체 스탯·고유 능력, 무기 무관 = 운영자 |
| 메타 재화 | **[추후] 적/보스가 총기 업그레이드 아이템 드랍** (상세 설계 미정) |

**살아남은 옛 자산:** 스폰 디렉터(Build→Peak→Relax), 즉발 레벨업·성장 도파민.

## 3. 개성 — 사후처리부 2페이즈 (이 게임을 다른 뱀서와 다르게)

테마 = **사후처리부서**: 이미 괴물로 진화한 것을 "처리"하는 부서. 단 아직 인간인 시민도 있다.
> 초반 = 살릴 수 있는 사람을 빼내는 시간 / 이후 = 남은 것을 처리하는 시간. ← 이름값을 게임플레이로 증명.

### Phase 1 — 초기 출동 / 시민 탈출 지원 (고정 타이머)
- 현장이 아직 완전히 안 망함. 시민이 도망치고, 괴물이 막 나타나는 중.
- 목표: 제한 시간 동안 시민이 탈출하도록 버틴다. **시민 보호 시스템은 이 페이즈에만.**
- 흐름: 시민이 탈출 지점으로 달림 → 괴물이 시민을 노림 → 플레이어가 길을 열어줌 → 위험 시민에게 **긴급 개입(쿨타임, "모두는 못 구함")** → 일정 수 이상 탈출 시 보상 증가 → 시간 끝나면 탈출구 폐쇄.

### → 봉쇄 전환 (연출)
UI: "민간인 대피 종료 / 현장 봉쇄 개시 / 잔류 생체 반응 확인 / 본사 지침에 따라 처리 절차로 전환합니다." 라이팅 따뜻→차가운 봉쇄 적색, 친화 비콘 소거.
- **다크 비트 (톤 콜, 연출 한정):** 못 구한 시민이 봉쇄선 안에 갇혀 전환됨 → 이제 당신이 *처리*할 대상. **단 기계적 패널티 0** (못 구한 수만큼 몹 증가 ❌ — 양수 규칙 위반 금지).

### Phase 2 — 구역 폐쇄 / 사후처리 개시 (순수 뱀서)
- 시민 거의 사라짐, 본격 뱀서. 보스 게이지(시간+처치) → Peak 보스 → 런 종료.

## 4. 시민 = 양수 자원 + 강요 금지 가드 (동결)

뱀서에 에스코트를 얹을 때의 핵심 — **강요감 제거.** 구조는 비강요(페널티 0), 연출만 지키면 됨:

- **시민 = 순수 양수.** 구하면 보너스, 놓쳐도 본전. **실패 처벌 = 끝까지 0** (이걸 깨면 DRG:S 에스코트 호불호 늪).
- 무시해도 유효한 플레이(평범한 뱀서 워밍업) — 관여 정도를 플레이어가 고른다.
- **마커 톤 = "기회(금빛 보상 비콘)"**, "긴급! 실패 중!"(적색 경보) ❌.
- **온스크린 죽음 스펙터클 없음** — 시민은 화면 밖에서 안 죽고, 멋대로 안 샘.
- **구조 수 = 양수 집계("+3 구조")만**, "2/10" 같은 전체 대비 분수(=실패 채점) ❌.
- Phase1 탈출자 수 → **Phase2 시작 어드밴티지**로 흘려보냄 (매 런 의미 부여, "스킵 의식" 방지).
- ⚠️ felt 강요는 플레이테스트 튜닝 노브(경고 강도·소리). 구조 비강요는 보장, 체감은 빌드→느껴보고 조정.

## 5. Phase 1 공간 연출 — 장르 정합 (디테일 맵 ❌)

레퍼런스 검증 결론: **VS류 맵 = 열린 무특징 평원/스크롤 필드. 저작된 디테일 지오메트리(건물·골목·버스)는 위반** (카메라 플레이어 중심 → 고정 두 극 불가 / 카이팅 콜리전 함정 / 호드 가독성 노이즈).

**핵심: 틀린 건 방향성이 아니라 "월드 고정점". VS 공간 = 장소가 아니라 플레이어 상대 좌표계.** 시민도 적처럼 플레이어 기준 이동체. 시민 레이어 = 적 밀도 그라디언트 위의 **역방향 인력(시민) + 방위 트리아지.**

| 요소 | 정합 방식 |
|---|---|
| 시민 등장 | **화면 가장자리 절차 스폰** (Brotato 문법, 위협과 반대 방위) |
| 위협 방향 | **스폰 방향 편향**(이 웨이브 한쪽이 더 진함) + 화살표/탈색고스트 마커 (기존 콘 문법 재활용) |
| 탈출구 | **동적 월드 핀**(오버레이 캔버스, 콜리전 0), 플레이어 상대. **단일 집결지 권고**(분산은 카메라 상대좌표라 흐름 추적 불가) |
| 시민 이동 | **벡터 이동** (평원=떨림·데드락 0) → **NavMesh 불요** |
| 트리아지 | 동시 2~3곳 핫(경고링+방위 마커) → 긴급개입 1개 쿨타임 |
