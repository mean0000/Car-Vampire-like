## 0. 가설 (한 줄)
> **무경계로 배회하는 적에게 카타나 발도 돌진으로 다가가 한 방에 확정 처형 →
> 그 자리에서 즉발 레벨업(파워 스파이크) → "한 번 더 하고 싶다"가 켜지는가.**

검증 질문(플레이게이트): 급습 첫일격의 *보장 처형 + 즉발 성장 스파이크* 한 사이클만으로
리플레이 당김(다음 군집으로 가고 싶음)이 생기나? 안 생기면 무엇이 빠졌나(물량? 위험? 연쇄?).

## 1. 무대 (최소 아레나)
- 깨끗한 작은 씬(빈 바닥 + 플레이어 + 무경계 적 1). 500m 도시 ❌(폐기됨, §6.2).

- 적 = 기존 좀비 1마리, **시작 상태 Dormant/Idle**(플레이어를 모른 채 배회). 스포너 off.

## 2. 메커닉 (새로 배선하는 3점)

### 2.1 무경계 판정 — `ZombieController.IsUnaware`
- `_state < ZombieState.Chase` (Dormant/Idle/Investigate/Alert = 아직 어그로 전).
- b009 동결("보장 원샷 = 미발각 한정")과 정합. `IsAggro`의 보수 대칭.
- ✅ **동결(2026-06-16): `< Chase` 전체 포함**. 의심 단계도 "날 특정 못 함" = 급습 성립. 어그로(Chase)부터 정면전.

### 2.2 보장 처형 — 발도 첫 적중이 무경계면 확정 킬
- `KatanaController.StepLunge`의 캡슐 캐스트 적중 루프에서, **이번 발도의 첫 적중 대상**이 `IsUnaware`면
  데미지를 무한대(보장 킬)로 덮어 `TakeMeleeHit`이 반드시 killed 반환.
- 군집당 1회 자연 제약: 발도 첫 적중이 적을 깨우므로(소음·피격) 이후 적들은 Chase = 급습 무자격.
- ✅ **동결(2026-06-16): 보장 즉살**(결정론적, b009식). HP 무시 한 방 확정. "한 방"의 명료함 = 신호가 결과를 가르침(juice 1원칙). 배수는 호드전 콤보가 담당.

### 2.3 즉발 성장 — 급습 킬 → 직접 대량 XP → 즉시 레벨업
- 일반 킬: XP 오브 버스트→수집(~1.5s 지연). 급습 킬은 **오브 우회**, `XPManager.AddXP`를 킬 순간 직접 큰 값 호출.
- 기존 `LevelUpChoiceUI`가 `OnLevelChanged` 구독 → **즉시 선택 팝업**(VS/Brotato식, 이미 작동).
- ✅ **동결(2026-06-16): XP만 크게, 자연 레벨업**. 급습 킬 = 큰 XP 청크를 직접 지급(오브 우회). 임계 넘으면 즉시 레벨업 팝업, 아니면 다음 급습으로 누적. 레벨을 강제하지 않아 곡선이 숨 쉰다.
- 레벨1 임계 = 20 XP. **급습 XP 기본값 = 12**(인스펙터 노브, ≈2급습/레벨) — 플레이게이트에서 손맛으로 튜닝. 일반 킬 오브 XP(1)와 대비되는 "급습은 크다"가 핵심.
- ⚠️ 검증 희석 리스크(유저 승인): 첫 급습에서 레벨업이 안 뜰 수 있음. 스파이크 부족하면 기본값↑로 대응(노브).

## 3. 주스 (기존 자산 조립 — 신규 0)
- 발도 잔상 선·발밑 시안 링(KatanaController 기존).
- 킬 버스트 VFX(Vefects 기반, 이미 증강됨) — 급습 킬에 **풀로**(군집당 1회라 비싸도 됨, §1).
- 즉발 레벨업 연출 = `LevelUpFeedback`(기존).
- ★폴리시는 게이트 통과 후. 이번엔 "보상 스파이크의 당김"만 본다.

## 4. 이 볼트에서 **빼는** 것 (스코프 잠금)
- **strain 드랍/소비** — 새 코어가 "strain 즉발 소비 → 죽음의 stake 비었음"을 미해결로 남김(핸드오프 §1 구멍).
  미해결 시스템 위에 안 쌓는다. 성장 도파민 = **즉발 레벨업**으로만 검증.
- **호드 폭발(L4D Peak Fade)** — 다음 볼트. 이번엔 급습 첫일격 한 사이클만.
- **정면 진입 viable / Desperados 유한 증원** — 핸드오프 §2 Q4, 별도.
- **죽음의 비용(stake) 재정의** — §2 Q3, 별도.
- **b009 정조준 단발 의식 폐기 확정** — §2 Q2. 이 볼트는 카타나 발도라 b009(총) 경로와 안 겹침 → 판정 보류 가능.

## 5. 성공 기준 (플레이게이트 — 에디터 복구 후)
1. 무경계 적에게 발도 → 확정 처형됨(보장 킬 작동).
2. 처형 즉시 레벨업 팝업이 그 자리에서 뜸(즉발, 지연 없음).
3. 어그로(Chase) 적엔 급습 무자격(보장 킬 안 됨) — 정면전과 질감 분리.
4. ★유저 판정: 이 한 사이클이 "한 번 더?"를 켜나. (켜면 호드 볼트로 / 안 켜면 무엇이 빠졌나 분해)

## 6. 착공 순서 (스펙 동결 후)
1. ✅ `ZombieController.IsUnaware` 접근자(`ZombieController.cs:131`).
2. ✅ `KatanaController.StepLunge` 발도 적중 무경계 분기 → 보장 킬(데미지 999999, int.MaxValue는 오버플로 회피로 기각) + 급습 XP(`KatanaController.cs:403~412`).
3. ✅ 급습 킬 → `XPManager.Instance?.AddXP(_iai.ambushXp)` 직접 지급(오브 우회). 노브 `IaiKnobs.ambushXp=12`(`KatanaController.cs:91`).
4. (생략) 별도 버스트 VFX 발화 안 함 — 보장 킬이 기존 ZombieDeathFX(킬 버스트)를 그대로 탐. 풀 연출은 폴리시 단계.
5. ⏳ **무대 세팅(에디터) → 플레이게이트** — unity-mcp 복구 대기. 에디터 살면: 작은 아레나 + 무경계 좀비 1 + XPManager 씬 배치 확인 → Play로 §5 성공기준 판정.
- 구현 = Gameplay(스펙 동결=기계적). ✅ Stab+Codex 병렬 리뷰 통과(Critical 0). 2026-06-16.

## 7. 검증 메모 (에디터 복구 시 체크)
- XPManager가 씬에 있어야 급습 XP가 들어간다(`?.` 무음 스킵 — XP 0이면 씬 배치부터 의심, Stab 지적).
- 발도 관통이라 한 번에 무경계 적 여럿 보장킬+XP n회(군집 sweep 의도). 1마리 아레나에선 무관, 호드 볼트에서 관찰.
- forceKatanaForTest=true(테스트 하네스) 상태 확인 — 카타나 강제 장착이라 발도 즉시 가능.
