# E-002 — 경제 본편 1볼트: "정산서가 수지를 말한다" 스펙

> **작성**: 2026-06-12 · **상태**: v1.0 동결 (Fable 디렉팅 + 유저 판정 8건) · **위상**: 필-볼트(1볼트=1가설=1게이트), **게이트 대기**
> **가설**: E-001이 "잃을 무게"를 증명했다. 메모리가 납품→일당→공제→실수령으로 변환되어 정산서에 찍히면 런이 "벌이"가 되고, 다음 런의 이유(당김)가 생긴다.
> **게이트 질문**: 정산서를 받고 사무실에 돌아왔을 때 "더 벌러 가야겠다"가 생기는가? 공제가 아픈가(웃긴가)?
> **선행 권위**: postprocessing-core-design §4(2026-06-11 개정 — 보급/공제 방향 동결), §4.7(산재보험 30%), 렉시콘 v1.8 §5.1(어휘 확정·골격 동결), E-001 스펙(판돈 볼트온)

## 산술 (동결)

```
gross(금일 정산액) = 납품 성사분만: Extracted = N × 단가 / Died·Swept = 0
insuranceCredit   = Died만: RoundToInt(N × 단가 × deathRetention)
net               = gross − equipmentFee − insuranceFee + insuranceCredit   (음수 가능)
deposited(입금)   = max(0, net)   — 표기도 0 바닥(음수 노출 금지)
```

**시작값 노브 (RunConfig — 코드 default, SO 에셋 무수정)**: `memoryUnitPrice=10000` / `equipmentFee=30000` / `insuranceFee=20000` / `deathRetention=0.3`

**수지 곡선 의도**: 좋은 런(랩 기준 N≈12) 실수령 70,000 ≈ 업그레이드 1틱(Lv1 70,000, +30,000/Lv — UpgradeDef 에셋 YAML 수정됨). 공제율 ~42% = 아픈데 살만함. 검산 3케이스: 탈출 70,000 / 사망 0−50,000+36,000=−14,000→0 / 소독 −50,000→0.

## 정산서 양식 (동결 — 렉시콘 v1.8 §5.1)

```
{플레이버}                          ← 탈출: "회수 헬기 탑승이 확인되었습니다. 공제 후 실수령액이 익일 지급됩니다."
                                      사망: "현장 인원 미회수 처리되었습니다. 산재 특약에 따라 일부 보전됩니다."
                                      소독: "구역 소독이 일정대로 집행되었습니다. 부서원 없음 처리. 본 건은 산재 미인정 사유에 해당합니다."
작업코드 OP-0382                    ← StartMission 시 D4 랜덤 발급. 양식 고정 = 중반 폭로(렉시콘 §6) 전제

1. 작전 결과: {탈출 성공 / 현장 인원 미회수 / 구역 소독 집행}
2. 이상개체 처리: {kills}           ← RunHarvest.Add 호출 1회 = 처치 1 (ZombieController 무수정)
3. 금일 정산액: {gross}
4. 메모리 회수량: {N}               ← ★항상 4번, 항상 표기
   └ 전량 소실 -{N}                 ← Died/Swept만
5. 공제 내역
   장비 보급료: -30,000
   산재보험료: -20,000
   산재 보전(특약 30%): +36,000     ← Died만
   산재 미인정 (구역 소독): 0        ← Swept만
6. 실수령액: {max(0,net)}
   └ 최저 지급액 보장 · 이월 없음    ← net<0만

잔고: {cash}
```

## 구조 변경 (구현 완료, 게이트 대기)

- **현금 잔고 신설**: MetaSaveData.cash(영구), MetaProgress.Cash/DepositCash/TrySpendCash/OnCashChanged(→Save). 기존 세이브 호환(누락 필드→0).
- **메모리=납품 품목**: 정산에서 StrainWallet 입금 제거(회사로 넘어감). StrainWallet 코드는 보존(미사용).
- **업그레이드 = 현금 구매**: MetaUpgrades 생성자 MetaProgress 기반 전환. 사무실 라벨 "보유 strain"→"잔고"(렉시콘 위반 해소).
- 변경 파일: RunManager/RunLoopUI/SettlementReport/RunHarvest/RunConfig/UpgradeDef + MetaSaveData/MetaProgress/MetaUpgrades + Upgrade_Damage·FireRate.asset(YAML).
- 리뷰: Stab(블로커 0)+Codex(CRITICAL 0) 통과. "정산서 순서 역전" 지적은 4번 고정 캐넌이 우선이라 기각.

## 게이트 판정 절차 (유저)

1. 랩 런 1회 정상 탈출 → 정산서 읽기 → 사무실 잔고로 업그레이드 1개 구매 시도
2. 한 번 일부러 죽기 → "산재 보전 +36,000에도 실수령 0"이 아픈가/웃긴가
3. (선택) 타이머 만료까지 버티기 → 산재 미인정 행 확인
- 당김이 생기면 → 채택, 경제 다음 층(소비처 확장·용역 단가표) 큐로. 안 생기면 → 수치 재조정(볼트 연장) 또는 가설 재진단.
