# Page 1 — 외곽 주택가 블루프린트 (주인공의 시작 동네)

> 2026-06-03. lv 세션. **Page 3(Village_Residential)는 풍요로운 도심 타운하우스**라 별도 페이지로 분리됨.
> Page 1 = 주인공이 사는 **낮은 단독주택 위주의 외곽**. 도시에서 벗어난, 검소하고 한적한 느낌.
> pm 브리프 + 보유 에셋 실측 기반.

## 0. 핵심 의도 (절대 어기지 말 것)
- **"작은 도시"가 아니라 "외곽"이다.** Page 3 격자/연립의 축소판 금지. 빈 땅이 ~60%.
- **낮은 집.** Page 3 브라운스톤(높음)이 아니라 Synty `SM_Bld_House`(높이 6.6~7.6m, 평지붕/단층 느낌).
- **개인 스케일의 방치.** 도심 정체(차량 잼)가 아니라 — 진입로의 차 한 대, 열린 현관문, 마당의 자전거, 텃밭, 쓰러진 울타리.
- **좀비 밀도 = Page 3의 40~50%.** 한적하다.

## 2. 레이아웃 (로컬 좌표, 루트 = `Village_Outskirts`)
메인 도로는 **+Z 축으로 1줄**. 직선 타일 3장.
- 타일 pivot z = 0, 51.9, 103.8 → 메시 z 범위 약 **[-45, +110]** (≈155m), 폭 X∈[-8.7, +9.4] (중심 x≈0.3).
- **남쪽 끝(z≈-45) = 진입구** (주인공이 게임 시작하는 곳, 열린 느낌 + 우편함/표지판).
- **북쪽 끝(z≈+110) = NE 시임** → `End_01` 캡 + 좁아짐. Page 3로 이어지는 단일 통로.

### 주택 배치 (도로변, 도로에서 ~11m 셋백, 전면이 도로를 향함)
도로 가장자리 x≈±9. 집은 x≈±20 (전면 x≈±14), 마당 깊이 확보.
- **동측(x=+20, 전면 -X 향함):** z = 0, 30, 60, 90 — 4채
- **서측(x=-20, 전면 +X 향함):** z = 15, 45, 75 — 3채
- 간격 30m(풋프린트 ~12 → 18m 빈 마당). 총 **7채**.
- **주인공 집 = 동측 z=0 (진입구 근처) `SM_Bld_House_02`(큰 집).** 자전거·열린 문·텃밭으로 개인화. 좀비 0~1만.
- 각 집에 `Driveway_01` 스퍼 1개(집 전면 → 도로 가장자리).

### 빈 땅 / 식생
집 사이·도로 뒤편 ~60%는 빈 흙/풀 지면. 드문 나무·덤불(군집 아님, 흩뿌림). Page 3보다 훨씬 성김.

## 3. 프롭 (개인 스케일 방치)
- 가로등 ~3개 (≈50m당 1개, 도로변).
- 울타리: 2채 마당만 부분적으로(쓰러진 구간 포함).
- 차량: **진입로의 차 1대**(도로 잼 아님) + 가능하면 버려진 자전거 1~2대.
- 텃밭/화분/쓰레기통/우편함 — 집 앞 소품. 검소함.

## 4. 좀비 (환경 단계에선 마커만, 본 빌드는 환경 우선)
- 밀도 = Page 3의 40~50%. 마당·도로에 흩어짐. 주인공 집 주변은 비움.

## 5. 빌드 단계 (각 단계 후 top-down 캡처 검증)
1. 지면 + 메인 도로(직선3 + 끝캡) → 검증
2. 7채 + 진입로 스퍼, 전면 방향 확인 → 검증
3. 프롭 + 개인 방치 비트 → 검증
4. codex 리뷰 → 수정 → 최종 캡처 + 정리

빌드는 임시로 월드 (200,0,0) 영역(빈 구역)에서 진행. Page 3(X[-422,-298]) 및 도로세션 카탈로그(X[-100..100])와 분리. 최종 월드 시임 조립은 후속 작업.
