## 0. 한 줄 요약

데모는 **시작 무기 2갈래(리볼버=원거리 / 야구방망이=근접) 중 택1**로 출발한다. 추가 파밍 무기 없음, 부착물은 소음기 1종만. 두 빌드의 대가축이 **소음(원거리) vs 체력(근접)**으로 갈린다.

---

## 1. 시작 분기 — 둘 중 택1

게임 시작 시 플레이어가 **원거리 빌드 / 근접 빌드** 중 하나를 골라 출발한다.

| 항목 | **리볼버** (원거리) | **야구방망이** (근접) |
|---|---|---|
| 에셋 프리팹 | `SM_Wep_Pistol_Revolver_01` (또는 `SM_Wep_Revolver_Snub_01`) | `SM_Wep_Bat_01` |
| 사거리 | 18m+ | 밀착 ~1.5m |
| 피해 결 | 묵직한 한 발, 낮은 연사 | 단타 고피해 |
| **대가(리스크)** | **소음 → 호드 유발** (숫자 압박) | **밀착 접촉 → HP 피격** (체력 압박) |
| 소음 | 높음 | 낮음 |
| 플레이 성향 | 거리 유지·소음 예산 계산 (포지셔닝형) | 무빙하며 패기 = run-and-bash (긴장 관리형) |
| 빌드 방향 | 소음축(메아리·소음폭주) | 킬축(연속 처치) + 기동축(밀쳐내기) |

**왜 리볼버인가**: 낮은 연사·묵직한 한 발·높은 소음 구조가 "강하지만 비용이 큰 선택"을 선명하게 보여준다. 헤비피스톨은 자동권총처럼 보여 대비가 흐려진다. 방망이(무겁고 한 방)와 톤이 통일된다.

**왜 야구방망이인가**: 카드 카탈로그가 이미 방망이 전제로 시그니처 4장(묵직한 스윙/긴 리치/풀스윙/무음 타격)을 짜놨다. 다른 근접무기로 바꾸면 카드 설계 전체를 재작성해야 한다. 둔기 = 넉백/스턴 방어적 역할과 톤이 맞는다.

---

## 2. 근접 게임감 — 약한 넉백, 무빙 타격 (확정)

- **넉백/경직을 약하게** 둔다. 좀비를 완전히 무력화하지 못한다 → 안전지대를 만들 수 없다 → **계속 움직이며 비집고 때려야 한다(run-and-bash).**
- **이게 곧 근접의 리스크 모델이다**: 좀비를 못 치우니 **접촉 피격을 계속 받는다.** 별도 "밀착 감염 가속존" 규칙 없이도, *못 밀어내니 맞는다*는 구조 자체가 원거리의 소음 대가와 대등한 체력 대가가 된다.
- **무한 카이팅 붕괴 회피**: 강한 넉백이면 느린 좀비를 영원히 밀어내며 무피해로 농락(degenerate)할 수 있다. 약한 넉백이 이를 자동 차단한다.
- **넉백은 성장 보상으로 전환**: 기본 넉백이 약하므로, 시그니처 **「풀스윙」**(넉백 반경·거리↑)이 넉백을 *얻어가는* 카드가 되고, 진화 **「철퇴」**(차지 광역 강타+다운)에서만 강한 CC가 해금된다. 성장 결이 자연스럽다.

## 3. 데모 무기 범위 (스코프 규율)

| 항목 | 데모 포함 | 비고 |
|---|---|---|
| 시작 무기 | 리볼버, 야구방망이 (택1) | |
| 추가 파밍 무기 | **없음** (산탄총·소총 제외) | 드롭은 재료/설계도만. 무기 추가는 카드 시스템 검증 후 다음 세션 |
| 부착물 | **소음기 1종만** (`SM_Wep_Attachment_Silencer_01`) | "주우면 소음 -30%, 즉시 영구 적용." 슬롯/장착 UI 없음. 소음 메카닉 체감용 교육 도구 |
| 레벨업 카드 풀 | 공통 기본 8장 + 선택 무기 시그니처 2장 ≈ **10장** | cards-catalog 기준 |

**스코프 유혹 거절 기록**: "산탄총 하나만 더 넣으면 소음 메카닉이 드라마틱하지 않나?" → 거절. 소음 메카닉은 리볼버+메아리 카드만으로 검증 충분. 산탄총은 카드 시스템 검증 후로 미룬다.

## 4. 구현 메모 (난이도/순서)

- **원거리(리볼버)**: 기존 `WeaponLoadout` struct + `PlayerCombat` 사격 로직 재사용. 저비용.
- **근접(야구방망이)**: 신규 시스템 다수 — 근접 무기 타입 분기, 공격 입력/쿨, 전방 히트판정, 중복 타격 방지, 스윙 지속시간, 약한 넉백/경직, 접촉 피격↔체력 연결. **원거리의 2~3배 공수.**
- 둘 다 Synty 프리팹은 **메시(외형)만** 제공 — 발사/타격 기능은 코드 연결 별도 필요.

---

## 5. 플레이테스트 미해결 (확정 아님, 관찰 항목)

1. **체력 압박 ↔ 소음 압박 대등성**: 근접이 조용한 대신 접촉 HP로 손해 보는데, 이 둘 밸런스가 맞는가. 안 맞으면 "근접=그냥 안전" 또는 "근접=못 버팀"으로 기운다.
2. **약한 넉백 근접의 호드 생존율**: 스웜에 갇혀 죽는 빈도가 적정한가.
3. **소음기 -30%**: 소음 예산에 미치는 영향이 "체감되는 완화"인지 "무의미"인지.
