# 감염도 · 소음 수치 곡선 상세 설계

> **작성일**: 2026-05-29
> **개정**: 2026-05-30 — **구현 기준으로 §1(소음) 재작성.** 그레이박스 플레이테스트에서 "이동 무음(+0)" 안을 폐기하고 **4단 이동 소음**을 핵심 긴장으로 채택, 소음 모델을 가산식 → **레벨식(지속 타깃 + 순간 충격 + 비대칭 엔벨로프)**으로 교체.

> **선행**: `2026-05-27-new-direction-gdd.md` §17 MVP 스펙, §13 (런 구조)
> **주의**: §1 수치는 현재 빌드 실측. 최종 밸런스는 §6 튜닝 가이드대로 계속 조정.

## 0. 설계 철학 — 두 축 = 시간(감염) × 공간(소음)

> **2026-06-03 개정**: 스텔스(잠입) 메커니즘 전면 제거(GDD v3.0). 감염도의 비용원이 "스텔스 사용"에서 **"밖에 머문 시간"**으로 바뀌었다. 두-비용 엔진은 그대로 살되, 축1이 *행동(스텔스)* → *시간(둠클락)*으로 교체됐다.

감염도와 소음은 따로 노는 두 미터가 아니라, **두 가지 압박의 축**이다.

| 축 | 얻는 것/누르는 것 | 비용 |
|---|---|---|
| **시간 (감염 둠클락)** | 멀리·오래 밀어붙여 희귀 보상·진행 | **감염도↑** (자동 상승 → 좀비화 + 귀환 압박) |
| **공간/소음 (전투)** | 빠른 처치, 레벨업 재료 | **소음↑** (호드 유발 + HP 위험) |

→ 어느 쪽도 공짜가 아니다. 시계가 탈수록 귀환이 급해지고, 시끄러울수록 호드가 깬다. 플레이어는 두 압박 사이를 **진동**하며, 이 진동이 GDD §15의 핵심 과제("이 요소들이 하나의 루프에서 작동하는가")의 답이다.

감염 곡선의 수치 권위는 `2026-05-31-level-design-authority.md` §2(시간 둠클락)다. 이 문서는 **소음(§1)**의 구현 확정값과, 그 소음이 감염 압박과 어떻게 맞물리는지를 다룬다.

## 1. 소음 시스템 (Noise)

### 1.1 소음 모델 — 레벨식 (구현 확정)

소음 `N ∈ [0, 100]`, 시작 0. **두 종류의 소스**를 분리한다:

- **지속 소스 (sustained)** — 이동. 매 프레임 `SetMovementNoise(level)`로 타깃 레벨을 지정하고, 호출이 없으면 자동으로 0이 된다(정지/사망 시 소음이 영구히 남지 않음).
- **순간 충격 (impulse)** — 총성 등. `EmitImpulse(value)`로 즉시 스파이크 후 엔벨로프를 따라 감쇄.

`N`은 타깃을 향해 **비대칭 지수 엔벨로프**로 따라간다 (프레임률 독립):
`N += (target - N) × (1 - exp(-Δt / τ))`, 오를 땐 `τ=attackTau`, 내릴 땐 `τ=releaseTau`.

| 파라미터 | 값 | 의미 |
|---|---|---|
| attackTau | **0.08** | 커질 때 — 짧을수록 확 오름 |
| releaseTau | **0.45** | 줄어들 때 — 멈추면 ~1.5초 안에 quiet |
| silenceSnap | **0.5** | 타깃 0 + 이 값 아래면 완전 무음으로 스냅 |

> 가산식(+N 누적/-3 감쇄) 폐기 이유: 이동을 무음으로 두면 소음 관리의 긴장이 사라짐. 이동 자체가 지속 소음을 내야 "앉기/걷기/달리기"의 매 순간 선택이 성립한다. 레벨+엔벨로프 모델이 "확 커졌다 확 줄어드는" 소리의 질감을 만든다.

### 1.2 값 테이블 (구현 확정 — 씬 실측)

| 행동 | 소음(타깃 N) | 속도배율 | 가청반경 R=N×0.25 | 비고 |
|---|---|---|---|---|
| 정지 | **0** | — | 0 | 완전 무음 |
| **앉기** (Ctrl) | **2** | 0.2x | ~0.5m | 사실상 무음 — 호드 안 깨우고 천천히 이동. 느린 대신 진짜 조용 |
| **걷기** (기본) | **30** | 1.0x | ~7.5m | 확실히 들림 — 기본 이동에 긴장 |
| **달리기** (Shift) | **60** | 1.7x | ~15m | 추격 임계(50) 초과 — 위험한 스파이크 |
| **총성** (좌클릭) | **90** (impulse) | — | ~22.5m | 게임 내 가장 큰 소음. 광역 호드 유인 |

- **앉기 = 호드 회피 이동** — 시끄러운 구역을 깨우지 않고 통과하는 페이싱 도구. 느린 게 비용.
- **총성은 게임 내 가장 큰 소음** — 쏘는 순간 임계의 1.8배 스파이크. 핵심 긴장(조용히 이동 vs 시끄러운 학살).
- **크래프팅 소음은 미구현** — 설계상 지속 소스(+20/s급)로 들어갈 예정. 구현 시 `SetMovementNoise`와 동일한 지속 타깃 채널로 합류시킨다. 수치는 구현 후 §6대로 튜닝.

### 1.3 레벨 감각 — 왜 이 레벨들이 맞는가

```
걷기(30): 임계 50 아래 → "조사" 구간. 반경 7.5m 안 좀비가 다가와 살핌→복귀.
          느리지만 꾸준한 노출. 근처 2~3마리는 반응.
달리기(60): 임계 초과 → "추적" 구간. 반경 15m. 빠르지만 호드를 깨운다.
앉기(2):   반경 0.5m. 좀비에 닿을 듯해야 들림 → 뒤에서 무음 접근 가능.
총성(90):  반경 22.5m 순간 확산 → 광역 호드 유인. release 0.45로 ~1.5초 꼬리.
```
→ "조용히 vs 학살"의 선택이 **매 순간 이동 입력**에서 성립한다. 앉으면 안전하지만 굼뜨고, 달리면 빠르지만 호드가 깬다.

### 1.4 감지 곡선 — 소음이 닿는 반경 (신규 설계)

GDD는 "임계값 50 → 주변 좀비 접근"만 명시. 0~49 구간이 무의미해지지 않도록 **연속 반경 모델**로 설계:

**가청 반경** `R(N) = N × 0.25` (미터), 0~25m로 클램프.

```
N    R(m)   좀비 거동
0    0.0    —
10   2.5    인접 좀비만 (단발 타격은 거의 조용)
20   5.0    │ <50: "조사" — 반경 내 좀비가 소음 지점으로
30   7.5    │        이동→3초 살핌→복귀 (비커밋)
49   12.2   │
─────────────── 임계 50 ───────────────
50   12.5   ≥50: "추적" — 반경 내 좀비가 플레이어를
70   17.5          타겟 락 → 시야상실/거리이탈까지 추격
100  25.0          최대 반경 = 호드
```

- **핵심**: 임계값 50은 하드 게이트가 아니라 **거동 전환선** — 아래는 "호기심(조사 후 복귀)", 위는 "커밋(추격)". 모든 소음 포인트가 반경에 기여하므로 0~49도 의미 있음 (가까운 좀비는 깨움).
- 이 반경 `R(N)`이 §1.5 행동 펄스(정식 목표)의 크기로 시각화된다 — **플레이어가 자기 소음이 어디까지 닿는지 눈으로 본다.** (현재 그레이박스는 지속 링으로 대체, §1.5 구현 현황)

### 1.5 소음 가독성 — 다이제틱 3층 (정식 목표)

> **설계 결정 (2026-05-29 개정)**: 소음은 "소리"라 게임틱한 지속 오버레이가 톤에 맞지 않는다. 대신 **행동 순간에 퍼졌다 사라지는 다이제틱 펄스 + 좀비 반응**으로 읽힌다. 레퍼런스: *Mark of the Ninja* (행동 소리를 지속 UI 링이 아니라 확산·소멸하는 파동으로 시각화한 사례). GDD "압박 없는 떠먹임 / 서사는 환경으로만" 원칙과 정합.

> **구현 현황 (2026-05-30)**: 현재 그레이박스 빌드는 **임시로 플레이어 발밑 지속 소음 링**(반경=HearingRadius, 소음↑→초록→빨강, 정지 시 숨김)을 쓰고 있다. 이동이 지속 소음을 내는 레벨식이라 "순간 펄스"보다 지속 링이 즉각적인 그레이박스 디버그·가독에 맞았기 때문. **아래 다이제틱 3층(펄스)은 여전히 정식 목표** — 폴리시 단계에서 지속 링을 펄스+좀비반응으로 교체한다.

**1층 — 오디오 (1차, 픽션)**
- 행동음(타격/발소리/제작) + 소음 누적될수록 차오르는 긴장음.
- ⚠️ 전투/환경 SFX 조달 필요 (기존 갭).

**2층 — 행동 펄스 (정밀도 도구)**
- 시끄러운 행동마다 **그 지점에서 순간 확산 후 소멸**하는 파동 (지속 X).
- **반경 = `R(행동 직후 누적 N)`** → 펄스 크기가 곧 "지금 내 소리가 닿는 범위". 펄스 자체가 미터 역할 → 별도 HUD 숫자 불필요.
- **색 = 임계 상태**: 50 미만 흰색 / 50 이상 빨강 (= "이번 행동이 커밋 추적을 유발했다").
- **크래프팅**: 3초간 펄스가 연속으로 커지며 빨강 도달 → "위협적인 3초"가 그대로 보임.
- 구현: 셰이더/파티클 1개 + DOTween 반경 스케일·색·페이드.

**3층 — 좀비 반응 (월드 확인)**
- 펄스 반경 내 좀비가 고개 돌림 → `?`(조사, <50) → `!`(추적, ≥50) → 행동.
- 결과를 월드가 직접 보여줌. 좀비 aggro 애니는 어차피 AI에 필요 → 추가 비용 거의 없음.

| 누적 N | 펄스 크기/색 | 좀비 반응 |
|---|---|---|
| 0–29 | 작음 / 흰색 | 인접 좀비만 잠깐 봄 |
| 30–49 | 중간 / 흰색 | 반경 내 조사(`?`) 후 복귀 |
| 50–79 | 큼 / 빨강 | 추적 커밋(`!`) |
| 80–100 | 최대 / 빨강 강조 | 광범위 호드 |

> **폐기**: 초안의 "플레이어 주위 지속 바닥 링". HUD를 월드에 붙인 느낌이라 톤·원칙 위반 + 비용도 더 큼. 행동 펄스가 더 싸고 더 맞다.

## 2. 감염도 시스템 (Infection)

### 2.1 값 (시간 둠클락)

> **수치 권위 = `2026-05-31-level-design-authority.md` §2.** 아래는 요약. 옛 "스텔스 1회 +1" 정수 모델은 폐기됨(스텔스 제거).

감염도 `I`는 **시간이 지나면 자동으로 차오른다** (level-design-authority: 정규화 `SyncRate ∈ [0,1]`, 기본 충전율 `r ≈ 0.0083/s`).

| 소스 | 감염 변화 |
|---|---|
| **시간 경과** | 자동 상승 (`r`/초, 중심·후반일수록 빡빡) |
| 게이트 통과 | **천장 상향** (1.0 → 1.3 → 1.6 …) = 더 멀리 갈 위험 예산 |
| 집 도착 | **초기화/감소** (나노봇 교란) |
| MAX 도달 | **DoT(5HP/s) → 좀비화 → 런 종료 (유산 좀비 생성)** |

- MVP는 **감염에 의한 조작 디버프 없음** (글리치/UI왜곡 = GDD 제외). 감염의 효과는 ①MAX=죽음 ②귀환 압박. 효과는 단순, 긴장은 구조에서.

> **cash-out 도박 화폐 층.** 감염도는 위험인 동시에 **귀환 시 배당 화폐** — 시계를 높이 끌어올린 채 살아 돌아올수록 희귀 보상(설계도/개조). 공포는 그대로(MAX=죽음), 상방만 추가. 상세: `2026-05-29-progression-system.md` §4.

### 2.2 감염 구간 & 피드백 (시각만, 게임플레이 영향 없음)

| 구간 | I (정규화) | 캐릭터 이미시브 | HUD | 의미 |
|---|---|---|---|---|
| 안전 | 0–0.3 | 없음 (녹색 미세) | 정적 | 여유 |
| 감염 | 0.4–0.6 | 약한 노랑 정맥 | 정적 | 비용 의식 시작 |
| 위험 | 0.7–0.8 | 주황 발광 | 천천히 맥동 | **"한 번만 더 vs 집" 갈등** |
| 임계 | 0.9 | 강한 빨강 + 심장박동음 | 빠른 맥동 | 곧 좀비화 |
| — | 천장 도달 | — | — | DoT → 좀비화, 런 종료 |

> 이미시브 강도 = `I / 천장` 램프, 색은 구간 매핑. DOTween yoyo로 0.9에서 맥동. 음향(심장박동)은 SFX 조달 후.

### 2.3 도박 구조 — 왜 위험을 무릅쓰고 더 머무는가

감염 천장 = **줄의 길이**. 얼마나 멀리/오래 밀어붙이고 귀환할 것인가. 시계는 가만히 있어도 탄다 → 머무는 시간 자체가 도박.

**귀환 비용 계산** (GDD: 집까지 30~40초, `r ≈ 0.0083/s`):
```
귀환 30~40초 동안 시계는 r×35 ≈ 0.29 더 차오른다 (천장 1.0 기준 ~29%)
안전 귀환선: 출발 시 여유가 ~0.4 이상 → 귀환 중 호드에 막혀도 천장 전 도착
도박 구간:   천장 0.85~0.9에서 출발 → 귀환 중 시계가 천장을 때림 = 탈출 실패
```
→ **"천장 가까이서 한 번만 더"가 위험한 수치적 이유**: 귀환 예산(남은 시계)이 거의 없어서, 돌아가는 길에 호드로 지체되면 시계가 천장을 먼저 친다. 이게 GDD "귀환길이 점점 위험해짐 = 클라이맥스"의 엔진.

### 2.4 시계 × 소음 (시스템 상호작용)

스텔스 탈출 버튼은 없다. 추적 호드를 떼어내는 수단은 **거리 벌리기(달리기) / 시야 차단 지형 / 엄폐**이며, 그 사이에도 시계는 계속 탄다.
→ 시끄럽게 굴어 호드를 부르면 떼어내는 데 시간이 들고, 그 시간만큼 감염이 차오른다. **소음(공간)이 시간(감염)을 갉아먹는** 지점에서 두 축이 맞물린다.

## 3. 두 시스템 상호작용 루프

```
   [시간이 흐른다 ──→ 감염 자동 상승 ──→ 귀환 압박]
              ▲                              │
              │ 지체 시간                     │
        시끄럽게 처치(+소음)                   ▼
   전투 ──────────────────► 호드 유발 ──→ 떼어내는 데 시간 소모
    ▲                                         │
    │                                         │
 레벨업/재료 ◄───────────────────────────────┘
              감염 천장 도달 → 좀비화
              또는 집 귀환 → 리셋
```

가만히 있어도 시계는 탄다(시간=감염). 시끄럽게 갈수록 호드를 떼어내느라 시간을 더 쓰고, 그만큼 시계가 빨리 찬다. 플레이어는 매 순간 "빨리 처치하고 시계를 아낄지, 조용히 돌아 호드를 피할지" 선택한다.

## 4. 시작 수치 요약 (구현용)

```
[소음 — 레벨식, 구현 확정]
  범위           0 ~ 100, 시작 0
  모델           지속 소스(이동, 매 프레임 타깃) + 순간 충격(총성)
                 비대칭 엔벨로프: attackτ=0.08, releaseτ=0.45, silenceSnap=0.5
  정지           0
  앉기(Ctrl)     2   (속도 0.2x, 반경 ~0.5m) — 호드 회피 이동
  걷기(기본)     30  (속도 1.0x, 반경 ~7.5m) — 조사 구간
  달리기(Shift)  60  (속도 1.7x, 반경 ~15m)  — 추적 구간(임계 초과)
  총성(좌클릭)   90 impulse (반경 ~22.5m) — 광역 호드 유인
  크래프팅       미구현 (예정: 지속 소스 +20/s급)
  가청 반경      R = N × 0.25 m (0~25m 클램프)
  임계값         50 (아래=조사, 위=추적)
  가독성         현재 그레이박스=발밑 지속 링(임시). 정식 목표=다이제틱 펄스+좀비 반응(?/!)

[감염도 — 시간 둠클락, 권위=level-design-authority §2]
  모델           시간 자동 상승 (SyncRate 0~1, r≈0.0083/s)
  게이트 통과    천장 상향 (1.0→1.3→1.6…)
  집 도착        초기화/감소
  천장 도달      DoT(5HP/s) → 좀비화, 런 종료
  이미시브       I/천장 램프, 0.9에서 맥동
```

## 5. GDD를 넘어 내린 판단 — 확정 현황

0. **이동 소음 + 레벨식 모델** — ✅ **확정 (2026-05-30, 그레이박스 플레이테스트)**: "이동 무음(+0)" 안 폐기. 이동이 지속 소음을 내야 앉기/걷기/달리기의 매 순간 선택이 성립한다(소음 시스템 공통 법칙: 걷기가 무음이면 앉기가 항상 정답이 돼 답답). 가산식(+N/감쇄) → 레벨식(지속 타깃+충격+비대칭 엔벨로프)으로 교체. 총성 impulse 90 신설.
1. **연속 감지 반경** (`R = N×0.25`) — GDD는 임계값 50만 명시. 0~49를 살리려 "조사 거동" 추가. 🟢 **채택** (이견 시 순수 임계 게이트로 조정 가능).
2. **호드 탈출 = 거리/엄폐** — 추적 호드는 달리기로 거리를 벌리거나 시야 차단 지형·엄폐로 떼어낸다(전용 스킬 없음). 그 사이 시계는 계속 탄다. ✅ **확정 (2026-06-03, 스텔스 제거)**.
3. **감염 디버프 없음** — MVP는 시각 경고만. 감염이 이동속도/시야 등에 영향 주는 건 post-MVP 노브. 🟢 채택.
4. **플레이어 HP** — ✅ **확정 (2026-05-29)**: **100 HP, 좀비 근접 타격 20 (5대 = 사망)**, 튜닝 범위 20~25(4~5대). 회복은 크래프팅 구급상자 전용(GDD v2.4) → HP 희소 → 신중한 교전 동기. 소음↔전투 균형의 전투측 비용.

## 6. 플레이테스트 튜닝 가이드 (§17 성공/실패 기준 연동)

| 관찰된 증상 | 진단 | 조절 레버 |
|---|---|---|
| 시계가 위협으로 안 느껴짐 | 충전율 너무 느림 | `r`↑, 또는 천장↓ |
| 집에 안 돌아감 | 귀환 동기 부족 | 거리-보상 곡선↑ (GDD v2.5), 천장↓ |
| 소음 무시하고 막 달리며 총질 | 소음 위협 부족 | 임계 50→40, 반경 계수 0.25→0.35, 걷기/달리기 소음↑(30/60→상향) |
| 제작이 안 위협적 | 소음 누적 약함 | 크래프팅 +20→+25/초, 또는 제작 3→4초 |
| "한 번만 더" 갈등이 없음 | 귀환 예산 너무 넉넉 | 집 거리↑ 또는 충전율 `r`↑ |

> 측정 지표: 평균 귀환 시 감염도, 천장 대비 도달률, 제작 시도 횟수, 소음 임계 돌파 빈도.
