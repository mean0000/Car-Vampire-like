# 필-볼트 프로세스 (Feel-Bolt — 우리식 AI-DLC)

> **작성일**: 2026-06-11 · **상태**: v1.0 채택 (유저 확정)
> **이 문서가 권위인 범위**: 작업 진행 방식 · 볼트 크기 · 게이트 판정 · 볼트 로그.
> **배경**: 동시 다중 변경은 "느낌 판정 대역폭"을 초과해 fun-finding을 fun-guessing으로 만든다.
> AI-DLC(AWS 2025)의 뼈대(Bolt·Elaboration·인간 검증 게이트)만 가져오고 엔터프라이즈 세리머니는 버린다.
> 볼트는 "기능 단위"가 아니라 **"가설 단위"** — 게이트 기준은 수용 조건이 아니라 유저의 주관 판정("쫄깃한가")이다.

## 규칙 (단 둘)

1. **볼트는 10분 플레이로 판정 가능한 크기.** 넘치면 쪼갠다.
2. **게이트 통과 전 다음 볼트 시작 금지 (WIP=1).** "이왕 하는 김에"는 스코프 크리프 — Claude가 스스로 차단할 의무.

## 볼트 사이클

```
백로그(가설 큐)에서 1개 선택
  ① Elaboration  — 브레인스토밍/리서치 → Claude가 명확화 질문 → 가설·스펙 동결
  ② Construction — 구현 (반드시 노브+롤백 경로 포함) → 캡처/정량 검증까지 Claude가
  ③ Gate         — 유저 플레이 → 판정: 채택 / 수치 재조정(볼트 연장) / 기각(노브 0)
  ④ 기록         — 아래 볼트 로그 1줄 + 관련 권위 문서 갱신 + 메모리 → 다음 볼트
```

- 작은 수치 조정은 볼트가 아니다 — 게이트 "연장" 안에서 즉석 처리.
- 결정만 필요한 브레인스토밍(구현 없음)은 볼트 밖에서 자유.

## 로드맵 (2026-06-11 확정 — 레퍼런스 3종 분석 반영)

```

  ↓
1. B-005a 음악 3단 스냅샷 — ✅구현 완료(06-11, **게이트 대기**): AudioListenerRig(리스너 카메라→플레이어 분리)+SfxOneShot 풀(3D·동시3·피치 ±5%)+TensionAudioDirector(절차 생성 3레이어 Calm/Alert/Combat 크로스페이드, 진입 0.5s/해소 5s, Combat 시 Calm −6dB 덕킹)+절차 그르렁 폴백(클립 미할당 보완). ※AudioMixer 에셋은 내부 API 제약으로 B-005b(USFX)로 연기 — 행동 등가물(코드 덕킹)로 검증
2. B-008 모퉁이 랩 시공 — lv 스펙 5건(차폐 3단/코너 킬존/사각 분출 스폰/양≠재미 가드/실루엣 체크).
   이후 모든 게이트의 무대 (Blindspot 교훈: 공간이 시스템을 받쳐야)
3. B-005b 사운드 에셋 와이어링 — ★유저 소스 픽업 필요(총성 크랙/저역 테일/그르렁/숨소리, freesound+녹음)
4. B-012 조준 완성 — 탄퍼짐 원호+벽 도트 색 (소형)

6. B-009 잔여 — Zone(수렴 가속 체인)+클리어 방점 슬로우+유지 윈도우 = 의식의 완성
이후: B-006 아웃라인 → B-004 연사(궤적 밀도로 절반 해결됨) → B-010 린
```

### B-001 연장 (2026-06-11, 게이트 전 유저 디렉션): 이원 카메라

- **평시 리드 0.18/2m** (더 차분하게) + **우클릭 홀드 = 주시**: 리드 ×2.2(실효 40%)/캡 5.5m — "내가 보겠다고 한 순간"에만 카메라가 커서 방향으로 넘어감. 45° 부감의 수평 차폐 덕에 카메라 시프트 자체가 "코너 너머 보기"로 기능.
- 주시 입력은 **B-009 정조준 의식의 자리** — 주시(정찰)→홀드 유지→수렴(조준)이 한 입력의 연속체.
- **보조사격(난사/차징/개머리)은 우클릭→Q 임시 이양** (`altFireKey`). 최종 배치는 B-009 게이트에서.
- **연장 2차** (게이트 1 피드백 "줌/집중 느낌이 약하다"): B-009의 집중 연출을 당겨옴 — 우클릭 홀드 시
  ①콘 수축 35°→22°(터널비전) ②콘 밖 어두워짐 −35%(집중이자 주변 시야 상실=비용)
  ③틸트시프트 포커스 풀(밴드 ×0.7·블러 ×1.3) ④블렌드 인 9/s. 노브: aimConeHalfAngle/aimOutsideDarken.
- **연장 3차** (유저 콜 "평시 틸트시프트 포기"): **평시 화면 완전 클린** — 밴드·콘 스택 전체가 조준 게이트
  (AimBlend 단일 구동). FOV 제약 해제로 **조준 줌 −8° = 진짜 줌** 확보. 카메라바이블 v1.3.
  ※부수효과: 콘 밖 좀비 고스트(B-002)·LKP(B-003)도 조준 중에만 발동 — 두 게이트는 이 맥락에서 판정.

### B-009 동결 스펙 (2026-06-11 유저 확정)

**전제(픽션 필러)**: 총성은 무조건 난다(소음기 없음) — 정조준의 목적은 은신 유지가 아니라 **"전투를 내 박자로 개전"**. 프로는 소리 안 나게 일하는 사람이 아니라 소리가 난 뒤에도 박자가 안 무너지는 사람(사후처리부=직장인 킬러).

1. **조준 의식** (우클릭 홀드) — ✅구현(06-11): 2단 구조. 1단 블렌드 0.25초(들숨 이징): 줌 −8°+콘 22°+어둠 0.5+리드 5.5m. 2단 수렴 0.6초: **콘 22°→8°로 붕괴(콘=수렴 게이지, UI 불필요)**+어둠 +0.12. 발사·해제 시 수렴 리셋(한 발 한 발의 리듬). ⏳잔여: 이동 둔화, 숨소리.
   - **수렴샷** ✅구현: 수렴 ≥95% 발사 = 탄퍼짐 0·데미지 ×2·넉백 ×2·머즐 ×1.5·캠 킥 ×1.4(예약제 무관)·**풀히트 시 전역 히트스탑 60ms**(HitStop.cs — 시간 사다리 최하단, 연사 매발 금지 원칙).
2. **보장 원샷 (수정 2026-06-11, pm 판정+유저 승인 — ✅구현)**: **수렴 완료(≥95%) + 비엘리트 좀비 = 보장 원샷 헤드팝(발각 여부 무관, 관통 차지샷 제외)**. 희소성은 *상태*가 아니라 **의식 비용(0.85초 노출 + 이동 둔화 0.5)과 전장 밀도**가 보장한다. 엘리트는 대크리(도입 시 분기). 근거: 저격의 1순위=확실성 — 확률적 죽음은 저격이 아니며, "가끔만 터지는 연출"은 운으로 읽혀 귀속이 깨진다. ★카이팅 치즈 방어 3종: 이동 둔화(원샷과 반드시 짝)·그르렁 전파·엘리트 면역.
3. **Zone** (정조준 킬로 진입, 3~4초): "더 세짐"이 아니라 "더 정확해짐" — 수렴 시간 단축(~0.2초) + 조준 중 둔화 완화 + 시안 연출/심박·숨소리. **시간은 1배속 유지** — 시간 조작은 산데비스탄 예약 카드(Zone=산데의 씨앗 포지션). 정조준 킬마다 +2초 연장, 피격/난사(비조준 사격)/만료로 종료.
4. **Zone 클리어 방점** (유사 킬무브): Zone 상태에서 **주위(≈화면 반경)의 마지막 발각 좀비를 처치하는 순간** 0.2~0.3초 슬로우(타임스케일 ~0.25) 1회. ★시간 원칙과의 구분: Zone "중"=1배속 불변(산데비스탄 보존), 클리어 "순간"=문장부호(지속 상태 아님). 카메라는 unscaled라 무사. 직후 한숨(RECOVER)→체크 틱으로 연결 = "작업 완료" 비트.
5. **루프**: 발견→의식→헤드팝(1막)→총성에 주변 기상→Zone 안에서 들어오는 적을 빠른 정조준 체인(2막)→마지막 처치 0.2초 방점→한숨(RECOVER)·체크 틱. "한 마리의 쫄깃함"→"한 무리의 리듬" 확장.
6. **게이트 질문**: "좀비 한 마리를 의식 갖춰 잡았을 때, 한 마리 더 잡으러 가고 싶은가? Zone이 끊겼을 때 아쉬운가? 클리어 방점이 '작업 완료'로 읽히는가?"
