# Synty 데모 씬 배치 규칙 (역설계 권위 문서)

> 2026-06-03. lv 세션. WestTown 1차 빌드가 "물 위에 뜬 사각 판때기"로 보인 사고 후, **실제 데모 씬의 transform 데이터를 직접 추출**해서 배치 논리를 역설계함. 눈대중 아님 — 아래 숫자는 전부 데모 씬 실측값.
> 분석 대상: `Assets/Synty/PolygonBattleRoyale/Scenes/Demo.unity` (DemoScene, 1517 오브젝트), `Assets/Synty/PolygonWestern/Scenes/Demo.unity` (Demo, 1012 오브젝트).
> **이 문서의 목적:** 내가(클로드) 맵을 지을 때마다 다시 읽어 적용하는 영속 레퍼런스. 매직넘버 즉흥 배치를 끝낸다.

## 0. 가장 중요한 교훈 — 지면은 절대 Unity Plane/Terrain이 아니다

두 데모 모두 **Unity Terrain 0개**. 지면은 **팩의 지면 메시 프리팹을 겹쳐 깔아서** 만든다. WestTown 1차 실패 원인 = 지면을 Unity `Plane` 프리미티브로 깔고 물도 사각 평면 → 하드엣지 사각 슬랩이 물 위에 떠 보임. **다시는 Plane으로 지면 만들지 말 것.**

### 보편 지면 레시피 (BR·Western 공통 패턴)
1. **플레이 표면** = 팩의 큰 지면 메시 타일을 겹쳐서 연속 바닥 형성.
   - BR: `SM_Env_Grass_Square_01`(28.8×0.5×19.2, 평평) + `SM_Env_Concrete_Base_01`(10×0.1×10, 군용 베이스 바닥).
   - Western: `SM_Env_Sand_Ground_02/05/06`(유기적 모래 메시, 10~47m, 큰 베이스는 165×154) — **y를 −0.4~−1.3로 살짝 가라앉혀** 평평한 윗면만 바닥으로 읽히게. 서로 겹쳐 타일링.
2. **가장자리(물/세계 끝과의 전환)** = 전용 엣지 메시로 하드엣지를 가린다.
   - BR: `SM_Env_Beach_01`·`_Staight_01`·`_Staight_02`(24.9×18.5) — 윗면 ~y0, **아랫면 ymin −6.6까지 경사**져 물속으로 내려감 → 자연스러운 해변. 섬 둘레를 두름.
   - Western: `SM_Env_Cliff_Cap/Straight/Curve/Arch`(절벽) — 타운을 협곡/분지로 **둘러싼다**. 사막 타운의 "해변" 등가물.
3. **수면선 디테일** = `SM_Generic_Small_Rocks_01/02`를 물가(y≈−0.2)에 **둘레로 흩뿌림**(BR에 81개, 섬 외곽선 추적).
4. **원경 배경 = 거대 메시를 멀리, 살짝 가라앉혀 두른다.**
   - BR: `SM_Generic_Mountains_*`(90~160m) at X·Z ±200, y −3.6~−5.
   - Western: `SM_Env_Butte_01/02`·`_Base_01/02`(195~247m!) at X ±150, Z −118~−215, y −10~+7.
   - ⚠️ **버트/마운틴은 원경 전용.** 플레이 구역 근처에 두면 타운을 파묻는다(1차 사고). 항상 ±150m 밖.
5. **물 평면**은 그 아래 깔되, 위 1~4가 가장자리를 처리하므로 사각 모서리가 노출 안 됨.

## 4. 회전(rotY) 규약 (탑다운 기준, +Z=북 +X=동)
- 건물 정면이 **거리를 향하게**. 거리가 동쪽이면 rotY=90, 서쪽이면 rotY=270, 북쪽이면 rotY=180, 남쪽이면 rotY=0(프리팹별 정면축 확인 필요).
- 도로/다리 직선 타일: rotY=0이 기본(폭=X, 깊이=Z 슬라이스 적층).

## 5. 좌석(seating) 규약
- 일반 프롭: 렌더러 bounds로 ymin을 0에 맞춰 앉힘.
- **건물 프리셋: 앉히지 말 것** — 기초가 묻히게 디자인됨(y=0 그대로).
- **지면 메시: 일부러 y를 음수로 가라앉힘**(Sand_Ground −0.4~−1.3, Beach 경사, Mountain/Butte −3~−10).

## 7. BR 섬 — 관계·동선·특이점 추론 (2026-06-03, 실측+탑다운 캡처 역설계)

> 단순 좌표가 아니라 "왜 거기에, 무엇 옆에, 어느 방향으로"를 읽어낸 분석. 데이터 출처: BR Demo 2195 메시 인스턴스 transform + 임시 탑다운 카메라 캡처.
> ⚠️ 전제: 데모는 **플레이 레벨이 아니라 쇼케이스 디오라마**다. 입구·시작·동선은 데모에 박혀있지 않다 — 아래 (D)는 우리가 *설계*하는 것이고 (A)(B)(C)는 데모에서 *읽어낸* 것이다.

### (A) 거시 구조 — 두 다리 사이의 "통과 회랑(corridor)" 섬
- 섬은 유기적 원형, 코어 ≈ X[−50..85] Z[−105..40] (~135×145m). 둘레 = 모래 비치 링 → 바위 군집(특히 동측 다수) → 수면선에 작은 WireFence 조각("여기서 끝").
- **중앙 N-S 고속도로 1줄이 척추.** 도로 양 끝이 두 다리와 정렬: **남쪽 다리(X=0, Z−108~−148)** + **북쪽 다리(X=25, Z+43~+158)**. 즉 섬은 **다리→섬→다리 일방 통과로**. 도로망 = 직선 척추 + T자 분기 1(상단, 서측 주거로) + 코너 1. Damaged 도로 변종 섞어 마모감.
- **두 다리 다 먼 끝에 Bridge_Broken 세그먼트** → "끊긴 다리" 실루엣. (우리 둠클락 전진압력과 직결: 돌아갈 길이 끊겨 있음.)

### (B) 기능 조닝 = 동/서 분할 (관계성의 핵심 논리)
- **서측 = 민간 주거.** House_01/02/03 + SmallBuilding 군집, 펜스로 닫은 마당 플롯, 초록 지면. **앵커 세트피스 = 추락 비행기 잔해(서측 하단).** 톤이 조용함.
- **동측 = 군용/산업.** 컨테이너 야적(색깔 스택 격자), 창고/행어(큰 어두운 매스), 연료탱크 실린더, 차량 군집, 텐트 캠프, 동쪽 물가에 **부두+보트**.
- **중앙 고속도로 = 두 구역의 솔기(seam).** 플레이어는 민간↔군용 경계를 따라 종주. 한 플랭크는 부드럽고 한 플랭크는 위협적 — 비대칭이 읽힘을 만든다.

### (C) 밀도·클러스터·특이점 문법
- **밀도 그라디언트:** 최고밀도 열이 X≈30~45(군용 척추: BaseWall+컨테이너+창고), 셀당 43~71. 서측 주거 중간, 최서단·수변 행은 거의 0 → **기능 클러스터에 밀도를 몰고 가장자리는 비운다.**
- **컨테이너:** 항상 Container_01 + Door 4조각 세트, 단독 금지 → **사각 야드(격자 행)로 빽빽이** 적층 = 화물 창고로 읽힘.
- **BaseWall:** 흩뿌리지 않고 **연속 직선 런**으로 깔아 컴파운드 풋프린트(벽)를 그림. Broken 변종을 중간중간 박아 파괴 서사. GuardTower(수직)는 컴파운드 코너 + **다리 착지 양옆**((10,−99)(53,−99)(77,−94))에 = 게이트 감시.
- **RadioTower** = 키 큰 항법 비콘(북단 (8,35), 동측 (58,−25)) — 멀리서 보이는 방향 기준점.
- **주택:** 3~5채 소규모 동네로 뭉치고 사이를 펜스 마당으로 채움, T분기 뒤로 셋백.
- **텐트:** 줄지어 = 전진 캠프, 남쪽 다리 착지 근처 + 동측에 배치.

### (D) 동선·입구·시작 — **우리가 설계하는 것** (데모엔 없음)
- 섬 = 두 다리 사이 회랑 → 우리 레벨 매핑: **플레이어는 남쪽 다리로 진입(서부 타운 측에서)** → 남쪽 착지 체크포인트(GuardTower 양옆 + 전진 텐트캠프 + 소규모 정착지가 도로 입구를 프레임) → 중앙 고속도로 북상하며 **분쟁 군용 베이스 + 컨테이너 미로(섬 중앙=전투 피크)** 통과 → **북쪽 다리로 다음 존 이탈.**
- **다리 착지 = 자연스러운 체크포인트/게이트 컴포지션**: GuardTower + 바리케이드 + 도로 어귀를 감싼 구조물 군집. ← 이번 즉시범위 "다리 착지 체크포인트"가 바로 이것.
- **끊긴 다리 끝** = "돌아갈 길 없음" → 일방 전진압력(둠클락과 합치).
- 적용: 우리 BR 섬 진입부는 (1) 남쪽 다리 착지면에 GuardTower 2 + 바리케이드로 게이트, (2) 어귀 안쪽에 텐트 전진캠프 1군집 + 소형 구조물 2~3, (3) 도로가 군용 베이스를 향해 북상하도록 깔되 좌(민간)·우(군용) 비대칭 유지.

## 8. Western 타운 — 관계·동선·특이점 추론 (2026-06-03, 실측+탑다운 캡처). ★ 게임 시작 지점

> 데이터: Western Demo 1515 메시 transform + 탑다운 캡처. 이곳이 **게임 오프닝**이라 입구·시작·동선 설계가 BR보다 더 중요.

### (A) 거시 구조 — "T자": E-W 마차길 척추 + 남향 보드워크 가지

### (D) 동선·입구·시작 — **게임 오프닝 설계** (우리가 정함)
- 타운 = "T자"(E-W 마차길 + 남향 보드워크). 게임 매핑 제안:
