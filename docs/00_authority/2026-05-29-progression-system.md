## 0. 왜 이 구조인가 (배경)

기획자 두 비판:
1. **스탯 체감 안 됨** — +20 HP, +0.5 속도는 미미해 재미를 못 당김
2. **소모품-only면 설계도 무의미화** — 한 번 해금하면 "쓸모없는 종이"

공통 뿌리: **눈에 보이게 자라나는 "진행의 척추"가 없다.**

세 분석(Codex + 생존게임 + 로그라이트)의 수렴:
- **크래프팅은 "힘"이 아니라 "접근(access)"을 게이트하라** (Valheim/Subnautica) → 옛 장비가 영원히 다음 단계의 전제 → 절대 종이가 안 됨
- **해금(UNLOCK)과 성장(GROWTH)을 분리하라** (Dead Cells) → 설계도=옵션 풀 확장, 별도 트랙=장비가 계속 자람
- **숫자가 아니라 사건(EVENT)** → 레벨업은 +%가 아니라 새 동사(임계값 질적 변화)
- **키스톤**: 감염도 = 피할 게이지가 아니라 **press-your-luck 도박 화폐**

## 1. 진행의 3기둥

```
┌─ 기둥1: 장비 ──────────┐ ┌─ 기둥2: 레벨업 ──────┐ ┌─ 기둥3: 감염도 ──────┐
│ 탐험→설계도(옵션풀)     │ │ 킬→질적 동사 임계값    │ │ 고위험 귀환→배당 화폐 │
│ + 개조슬롯(성장축)      │ │ (기동/전투/감염 계열)   │ │ (press-your-luck)    │
│ + 접근 게이트          │ │                      │ │                      │
│ 해결: 설계도 무의미화   │ │ 해결: 스탯 체감 안됨   │ │ 해결: 두-비용 통합    │
└───────────────────────┘ └──────────────────────┘ └──────────────────────┘
        ↑ 셋 다 기존 시스템(소음/감염/크래프팅) 재조합 — 새 시스템 거의 없음
```

## 2. 기둥 1 — 장비: 개조슬롯 + 접근 게이트

### 두 축 분리 (Dead Cells 모델)
- **해금 축**: 설계도 발견(먼 구역 파밍) = 제작 가능한 *옵션 풀*에 영구 추가 → 탐험에 지속 가치
- **성장 축**: 장비에 **개조 슬롯** → 같은 장비를 계속 강화/변형 → "쓸모없는 종이" 해결

### 아이템 3 카테고리 (기획자 확정)

| 카테고리 | 성격 | 예시 | 진행 역할 |
|---|---|---|---|
| **총기/무기 부착물** | 영구 장비 + 개조슬롯 | 소음기(소음↓), 확장탄창, 관통탄, 근접 강화날 | 성능 강화 (성장 축) |
| **약물** | 전술 소모품 (일시 버프) | 아드레날린(일시 속도/공격↑), 억제제(감염 일시 둔화) | 위기 순간 주도적 한 방 |
| **지역 체류 아이템** | 접근 게이트 (영구/소모) | 방독면·필터(오염지대 감염 둔화 → 더 오래 체류) | 새 구역 접근 (access) |

### 개조 슬롯 구조 (Codex 안 — 1인 개발 핵심)
설계도 = 제작법 + 개조 슬롯. 예시 (화염병):
- Lv1 기본 → Lv2 슬롯 해금 → 장착: 저소음 점화 / 기름 증폭 / 감염 연소(고감염 시 추가피해) / 점착 화염(지속 장판)
- **같은 장비도 런 방향 따라 완전히 달라짐.** 공통 슬롯 데이터 구조 하나로 대부분 데이터 추가 처리 → 스코프 안전.

### 접근 게이트 = 감염 테마 직결
방독면/필터가 없으면 고오염 고가치 구역에서 감염이 너무 빨리 차서 못 버팀 → **장비를 만들어야 그 구역에 "더 오래" 머물 수 있음.** 이게 기둥 3(감염 화폐)과 루프를 닫음 (§4).

### 제작 위치 규칙 (현장 vs 기지) — 영속성으로 가른다

위치는 *설계도 출처*가 아니라 **결과물의 영속성**을 따라간다:

| 위치 | 무엇 | 비고 |
|---|---|---|
| **현장 (어디서나)** | 소모품 (구급상자, 소음미끼, 약물) | 압박 속 즉석 제작 = 실시간 크래프팅 긴장 기둥 |
| **기지 (집)** | 영구 장비·개조·접근장비 | 안전하게 = 성장 축. 집에 "작업장" 목적 부여 |

**영구 장비를 현장에서 제작 = 가능하되 페널티 (하드 차단 X — 강요X 욕망O):**

| 페널티 층 | 내용 | 재활용 시스템 |
|---|---|---|
| 지속적 | 현장판 = **기본형, 개조 슬롯 없음 + 업그레이드 불가**. 기지판만 풀 슬롯 + 성장 | 개조슬롯 |
| 즉시적 | 제작 시간 길고(소모품보다↑) 소음 대폭 → 호드 유발 | 소음 |

- **시작값(튜닝)**: 현장 영구제작 = 시간 2x + 소음 대폭 + 슬롯 0(기본형) + 추후 업그레이드 불가. 기지 = 정상 시간 + 안전 + 풀 슬롯 + 업그레이드 가능.
- **degenerate 아님**: 현장판은 열등·업그레이드 불가라 결국 집에서 재제작하고 싶고, 시끄럽고, cash-out·감염리셋·회복 때문에 집은 허브로 남음. 현장 영구제작 = 비상 옵션.
- **집 진짜 목적 + 귀환 판돈**: 재료/설계도 들고 무사 귀환해야 제대로 빌드 → cash-out 도박과 겹쳐 귀환 긴장 강화. 작업대 업그레이드 층(post-MVP)의 토대.

## 3. 기둥 2 — 레벨업: 질적 동사 (스탯 아님)

| 항목 | 내용 |
|---|---|
| 트리거 | 누적 킬 |
| 보상 | **2개 중 1개 — 새 *동사*(행동)**. +%스탯 아님 |
| 연출 | Feel(히트스탑/쉐이크) + DOTween(팝) → "질적 변화 순간"을 *보이게* |

### 3 계열 (빌드 정체성)

| 계열 | 예시 동사 |
|---|---|
| **기동** | 대시 회피(짧은 무적 순간이동), 질주 관성(이동 중 다음 공격 강화), 밀쳐내기(피격/접촉 시 넉백) |
| **전투** | 연쇄 베기(N킬마다 다음 공격 강화·소음↑), 광폭(저HP 시 공속↑) |
| **감염 (옵트인)** | 감염 적응(고감염 시 이동속도↑), 후각 교란(고감염 시 좀비 인식↓ = "좀비 블렌드"), 변이 반사(피격 시 밀쳐냄) |

> **감염 계열 = 앞서 논의한 "감염을 무기로"의 그릇.** 모두가 받는 패시브가 아니라 *고른 사람만* 얻는 빌드 → 감염 기본값은 순수 공포로 유지(톤 보존), 빌드 선택자만 고감염을 이점으로. 강요X 욕망O.

## 4. 기둥 3 — 감염도: press-your-luck 도박 화폐

### 원리
감염도는 **여전히 100% 위험** (MAX=즉사, infection-noise 문서 그대로). 추가되는 것: **얼마나 높이 끌어올린 채 살아 돌아오느냐 = 귀환 시 배당.** 보상은 *집 도착(cash-out) 순간* 실현 → 감염 0 리셋.

### 귀환 시 감염도별 배당 (시작값)

| 귀환 감염도 | 배당 | 대가 |
|---|---|---|
| ~3 (안전) | 기본 재료 | 없음 |
| ~6 (보통) | + 일반 설계도/개조 부품 | 약간 |
| ~9 (도박) | + **희귀 개조/변이 설계도** | 시계가 천장 코앞 — 귀환 중 조금만 지체해도 죽음 |

- **공포를 빼지 않고 보상을 더한다**: 귀환길은 여전히 손에 땀 쥐는 지옥, 끝에 상품만 걸림. (실시간 파워 버프는 채택 안 함 — 공포를 빼서 톤을 깨므로)
- **각 트립(집→탐험→귀환) = 도박 라운드 한 판.** "얼마나 깊이 들어가 감염 올린 뒤 살아 돌아올까."
- 9까지 미는 게 무뇌 전략이 아닌 이유: 고감염 귀환은 남은 시계 예산이 거의 없어 호드에 막히면 곧장 천장 → 실력·배짱 표현.

### 두-비용 엔진과 통합
이로써 **시간↔전투 두-비용 엔진이 진행 시스템 그 자체**가 됨. 감염(시간 비용)은 화폐로, 소음(전투 비용)은 재료/레벨 속도로 환원. "오늘은 80 감염도로 귀환해 변이 설계도 노리는, 멀리 깊이 미는 런" 같은 자발적 목표 생성.

## 5. 통합 루프

```
        ┌──────────────── 집(HOME) ────────────────┐
        │  cash-out: 감염도→배당  │  감염 0 리셋     │
        └──────────▲───────────────────┬───────────┘
                   │                   │
            살아 돌아옴             탐험 출발
                   │                   ▼
        귀환 게이트 ◄── 더 깊은 구역 (방독면 등 접근장비 필요)
        (시계 압박)          │
                   │    파밍: 재료 + 설계도(옵션풀) + 킬(레벨업)
                   │         │
                   └─── 감염↑(시간)/소음↑(전투) ── 제작(개조/약물/소모품)
```

핵심 감정 매핑: 탐험(설렘 #1) → 장비/레벨업(성장 #2) → 귀환 도박(긴장 #3).

## 6. 아이템 재분류 (이전 4종 → 3축으로)

| 축 | 아이템 | 비고 |
|---|---|---|
| 접근 장비 | 방독면/필터 (체류 아이템) | 영구, 개조 가능, 새 구역 게이트 |
| 개조 가능 무기/가젯 | 총기+부착물, 근접 강화, 지뢰(설치형) | 성장 축 |
| 소모품 | 구급상자, 시계 둔화제, 투척단검, 약물류 | 반복 제작, 전술 타이밍 |

> 기존 "단검 근접↑" 류의 *패시브 효과*는 레벨업 동사로 흡수(§3). *액티브 도구*는 소모품으로.

## 7. ★ MVP 스코프 vs Post-MVP (스코프 규율)

이 문서는 **풀게임 비전**. MVP(10~12분 검증 프로토)는 핵심 가설만 검증:

### MVP 슬라이스
- **감염 cash-out 도박** (간단 버전): 귀환 감염도 높을수록 재료 더 줌 → "욕심" 가설 검증. ★ 핵심
- **레벨업 질적 동사**: 계열당 1~2개만 (기동·전투 각 1, 감염 1)
- **크래프팅**: 소모품 2~3종(구급/시계둔화제/지뢰) + 부착물 1종(개조슬롯 개념 검증용)
- **설계도**: 먼 구역 파밍 발견 (간단)
- 접근 게이트: 오염 구역 1개 + 방독면 1종 (개념 검증)

### Post-MVP (절대 MVP에 넣지 말 것 — 시스템 적게)
- 메타 진행 (런간 영구 해금, Dead Cells식)
- 무기 진화 / 시너지 태그
- 3 계열 풀 트리
- 약물 다양화, 개조 슬롯 다수
- 감염 계열 빌드 정교화 (고감염 이점화)
- 실시간 감염 버프 (채택 보류)
