★원리 = 화려함 = 베이스와의 낙차. 세계는 채도를 눌러 무대가 되고, 나(인공 3색)만 포화색으로 화면의 주인공이 된다. 적은 자연색(변이)으로 갈린다. 수치는 전부 제안 — 보고 조정.

나 — 인공 신호 3색 (회사 기술)

"인공색이 움직인다 = 나." 시안=액션 · 금=보상 · 마젠타=비용. 세 색이 화면의 유일한 포화색.
#2DE2E6
시안 — 액션/킬
슬래시 궤적·킬버스트·시야콘·정보 HUD. 평시 유일 포화색
#15C5C9
시안-딥(정보)
정보 시안=얇은 라인/윤곽(샤프). 스킬 시안=글로우/면과 형태 분리
#F5B73C
금 — 보상/돈 (신규)
정산·처리평가 S~D·카드 등급·돈 획득. "성과"의 색. 골든아워와 조화하되 보상 순간 포화로 팍
#FFD76E
금-라이트(잭팟)
S등급·신화 카드·대형 정산 = 더 밝은 금 + 파티클
#FF3D7F
마젠타 — 비용/붕괴
오버드라이브·신호붕괴. 강한 스킬일수록 섞임. 대시 위상 잔상
#FF157A
마젠타-풀워시
수렴샷·싱크 글리치·사망 전용. 평시 월드 마젠타=금지

카드 등급 색 — 표준 컨벤션 (UI 레이어, 전장 색과 분리)

★플레이어가 이미 아는 표준 등급색(흰→파→보라→주황→빨강). 카드 테두리/글로우는 *드래프트 메뉴* 레이어라 전장 색 규약(시안=나/자연색=적)과 충돌 안 함. 각 등급이 *확실히* 구별됨.

적 — 변이 자연색 + 위협 경고

자연색(변이)이라 인공색과 의미축이 갈린다. 속성 발광 vs 공격 텔레그래프는 다른 레이어.

에스컬레이션 4단 (시안→마젠타)

평시 절제 → 스킬 시안 → 오버드라이브 마젠타 → 풀워시(사망/수렴/글리치). 화면의 포화도가 곧 위험/화력 게이지.

풀워시 — 사망/수렴/글리치
