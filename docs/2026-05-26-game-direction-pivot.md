**날짜:** 2026-05-26

## 1. 현재 게임의 근본 문제

### 한 줄 요약
> **세 장르(뱀서+차량+생존)를 섞었는데 세 장르의 장점이 하나도 살아있지 않다.**

### 구체적 결함

| 문제 | 원인 |
|---|---|
| 재미가 없다 | 게임의 **목적**이 없다 (왜 좀비를 치는지 모름) |
| 긴장이 없다 | **잃을 것**이 없다 (자원/기지/진행도) |
| 성장감이 없다 | 성장이 **런 안에서 리셋**되니까 누적이 안 됨 |
| 쫄깃함이 없다 | **"이걸 넘기면 뭐가 열린다"**가 없다 |
| 뱀서 쾌감 없음 | 충돌 하나로는 학살감/성장 체감 불가 |
| 차량 재미 없음 | 직진해서 박으면 끝. 조작 선택지 없음 |
| 생존 긴장 없음 | 자원 압박 제로, 차가 좀비보다 5배 빠름 |

## 2. PM 분석: 수치적 결함 (5가지)

1. **차가 좀비보다 5배 빠름** (22 vs 4.5) → 포위/긴장 불가
2. **speedPenalty=2가 너무 작음** → 좀비 10마리 박아도 안전
3. **연료 경제가 너무 관대** → 2.5초에 1킬이면 무한 유지
4. **무한 직진 맵** → 좀비 밀도 누적 안됨
5. **공격 수단이 충돌 하나** → 성장 체감 단조

### PM 처방 (수치 리밸런싱)

| 파라미터 | 현재 | 제안 |
|---|---|---|
| speedPenalty | 2 | 5~7 |
| passiveDrainRate | 6 | 10~12 |
| killFuelAmount | 15 | 8~10 |
| emptyFuelSpeedMult | 0.4 | 0.25 |
| minSpeedAfterHit | 3 | 1.5 |

> **단, 수치 조정만으로는 근본 문제(목적/루프 부재)는 해결 불가.**

## 3. Codex 세컨드 오피니언

PM 진단에 대체로 동의하면서 추가로 지적한 것:

1. **운전 조작의 선택지 부족** — 가속/감속/드리프트/부스트가 "빠르게 박기"로 수렴
2. **지형이 플레이를 요구하지 않음** — 평지라 라인 선택이 없어서 차량 게임이 안 됨
3. **핵심 방향 전환**: "뱀서에 차를 얹기"가 아니라 **"운전의 위험한 선택을 뱀서식 성장으로 증폭하기"**

### 레퍼런스 게임 (Codex 추천)
- Zombie Driver HD — 탑다운 차량 좀비 학살감
- Earn to Die 2 — 차량 업그레이드 + 연료 압박
- Death Road to Canada — 차량 이동 + 자원 압박 + 이벤트 밀도
- Brotato — 짧은 런, 밀도 높은 적 압박, 빌드별 체감 차이
- Mad Max — 차량 전투의 무게감

## 4. 유저 본인의 깨달음 (핵심)

### "내가 재밌다고 느끼는 것"

> "템 모아서 강해진 나! 보스 잡기! 룩 꾸미기! 컨텐츠 해금!"
> — 테라리아, 굶지마, 세븐 데이스 투 다이

### 뱀서류의 진짜 재미 (유저 분석)

> "압박감 속에서 해결 방안이 바로바로 나와서 고민하고,
> 그 결과가 더 좋은 결과가 나옴으로서 도파민이 팡팡 터지는 것.
> 몬스터를 때려잡는 재미가 일방적으로 느껴져야 한다."

핵심: **압박 → 판단 → 일방적 학살 → 도파민**의 낙차.

## 5. 블루오션 발견

### 시장 조사 결과

"생존 게임(테라리아/굶지마/7DTD)의 깊은 루프 + 뱀서류의 호드 학살 쾌감"을
**제대로 섞은 게임은 시장에 없다.**

비슷한 시도들:

| 게임 | 뱀서 전투 | 자원수집 | 크래프팅 | 기지건설 | 보스→해금 |
|---|---|---|---|---|---|
| Crafty Survivors | O | O | O | O(약) | ? |
| Atomicrops | O | O(농사) | X | X | O |
| DRG: Survivor | O | O(채굴) | X | X | O |
| Death Must Die | O | X | O(대장간) | X | O |

→ 전부 "생존의 깊이"가 부족. **풀 패키지는 아무도 안 만들었음.**

## 6. 새로운 방향: 생존 액션 + 호드 서바이벌

### 핵심 구조 (테라리아/7DTD 모델)

```
[탐색/수집] 위험한 세계에서 자원 확보
     ↓
[강화] 차량/무기/기지 업그레이드
     ↓
[호드] 밤마다 좀비 웨이브 → 뱀서식 학살 쾌감
     ↓
[보스] N일마다 보스 호드 → 넘기면 새 바이옴/파츠/룩 해금
     ↓
[더 깊은 세계로] ...반복
```

### 기존 코드 재활용 가능 여부

| 기존 시스템 | 재활용 | 새 역할 |
|---|---|---|
| 차량 물리/드리프트 | O | 탐색+전투 수단 |
| 좀비 AI (3종) | O | 호드 전투의 적 |
| 좀비 스폰 시스템 | O | 밤 호드 웨이브 |
| Cozy Weather 밤/낮 | O | 낮=탐색, 밤=전투 자연 분리 |
| Feel 피드백 | O | 학살 쾌감 증폭 |
| 절차적 맵 생성 | O | 바이옴별 탐색 맵 |
| 연료 시스템 | O | 생존 자원 압박 |
| XP/레벨업 | 변경 필요 | 영구 진행으로 전환 |
| 피트스톱 업그레이드 | 변경 필요 | 차고 크래프팅으로 전환 |

→ **뼈대(코드)는 거의 다 살린다. 바꾸는 건 루프의 방향.**

## 7. 플레이어 모드: 도보 + 차량

### 핵심 결정
- **기본 플레이 = 도보 캐릭터** (탐색, 수집, 정밀 전투, 기지 건설)
- **차량 = 크래프팅으로 획득하는 성장 보상** (중후반 탈것)
- 자유 전환: 아무 때나 탑승/하차

### 차량 이탈 방지 설계

문제: "도보 전투가 재밌는데 차를 타라고?" → 이탈 위험

해결: **차량 = 학살 모드 전환**

| 도보 | 차량 |
|---|---|
| 정밀 조준, 회피 | 돌진 학살, 넓은 범위 |
| 소수 정예 상대 적합 | 대규모 호드 쓸어버리기 |
| 근접/원거리 무기 | 차체 충돌 + 장착 무기 |

→ 차를 타면 **더 강해진다**. "빨리 차 만들고 싶다"가 되어야 함.

### 전략적 선택지
- "오늘 밤 호드는 기지에서 도보로 버틸까, 차 타고 돌파할까?"
- 이 선택지 자체가 게임의 재미

### 성장 곡선
```
맨몸 → 무기 → 방어구 → 차량(게임체인저) → 차량 업그레이드
```

### 레퍼런스
- 7DTD: 바이크 타고 좀비 치며 이동, 내려서 루팅
- 굶지마: 비팔로 타도 전투 가능, 이동+전투 겸용
- 데스 로드 투 캐나다: 차 구간 = 학살 보너스 타임
