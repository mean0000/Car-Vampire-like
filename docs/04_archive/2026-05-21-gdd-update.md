## 0. 이 문서의 목적

2026-05-19 GDD 기초 작성 이후, 다음 문제를 인식하고 디자인을 진화시켰다:

1. "재미는 캐주얼한데 비주얼은 아포칼립스"라는 톤-메카닉 괴리
2. 메타 루프의 부재 → 행동 동기 약함
3. 시스템 동기가 약함 → 집 주위만 배회할 위험
4. 무기고/별도 무기 시스템 → "차량 = 무기" 컨셉과 충돌

본 문서는 2026-05-19 §2/§3.3/§5.1/§5.4/§8/§9 일부를 **갱신/대체**하며,
새로운 챕터(메타 루프, BGM, 돌파 모드, 환경 떠먹임, 자원 구조, 차량 라인업)를 추가한다.

비주얼 방향, 적 설계 원칙, 기술 구현 원칙은 그대로 유효.

## 1. 게임 정체성 (최종 확정)

> **"자동차 액션 로그라이트 + 뱀서 코어 전투"**
> 가장 가까운 비교: **Deep Rock Galactic: Survivor + Cult of the Lamb 톤**

### 핵심 컨셉 (한 줄)
> *"당신의 차고를 키우며, 박치기·드리프트·포탑 빌드로 좀비 도시를 더 깊이 뚫어라."*

### 시장 포지셔닝
- 첫인상 진입: **"자동차 뱀서라이크"** (뱀서 코어 팬 유입)
- 차별화 축: **메타 진척 + 귀환 돌파 클라이맥스**
- 톤 차별화: **"세상은 끝났다. 그래도 커피는 마신다."**
- 가격대: $10~15 (Brotato와 Hades 사이)
- 직접 경쟁작 차별화: Driveloop:Survivors는 순수 뱀서식, ZombieCrush는 메타 진척 + 톤

### 뱀서 DNA 보호 룰 (반드시 지킬 것)
```
1. 출격 진입 = 클릭 1~2회, 5초 이내
2. 출격 안에서의 빌드업이 진정한 메인
3. 메타 강화는 출격 시작점만 살짝 올림 (스탯 +5% 같은)
4. 출격 전 사전 결정 최소화 — 차량 선택 + 모듈 1~2개 정도
5. 죽음 후 결과 → "다음 출격" 큰 버튼 → 또 출격
6. 허브에서 보내는 시간 < 출격 시간 (체감)
```

## 2. 코어 루프 갱신

### 기존 (2026-05-19)
```
적 무리 확인 → 주행 라인 선택 → 돌파 → XP 획득 → 반복
```

### 갱신 (2026-05-21)
```
[집] 차고에서 차량/모듈 선택 → 출격
   ↓
출격 (최대 15분) — 좀비 쓸어버리며 인게임 빌드업
   ↓
멀리 갈수록 보상↑, 특별 픽업 등장
   ↓
귀환 신호 인지 (BGM/시각 변화)
   ↓
귀환 돌파 — 강해진 적 무리를 속도로 뚫고 집으로
   ↓
[집] 결과 → 스크랩으로 강화, 집 부품으로 잠금 해제
   ↓
"다음 출격" 버튼 → 재출격
```

- 출격 한 판: **최대 15분** (확정)
- 한 판은 그 자체로 완결 (뱀서 DNA)
- 메타는 가볍게, 출격이 메인

## 3. 죽음 모델 (확정)

B(뱀서표준) 기반, 패널티 약하게.

- 출격 중 사망 시 패널티 약함 (구체 비율은 프로토타입 튜닝)
- 귀환 성공 = 100% 보존 + 가벼운 보너스
- 죽음 원인이 "운전 미숙"이 아니라 **"내가 욕심내서 더 머물렀다"**로 인지되도록 충돌 피해 모델 설계

## 4. BGM 시스템 (통합 신호 채널)

게임 내 모든 페이스 신호의 **메인 채널은 BGM**.
UI 알림창은 띄우지 않는다 (톤 유지).

### 트리거 가중치
| 변수 | 가중치 | 의미 |
|---|---|---|
| 차량 손상도 | 50% | "내 차가 망가지고 있다" 직접 체감 |
| 시간 진행도 | 30% | 후반 강도 자동 증가 백업 |
| 거리/귀환 진행도 | 20% | "지금이 클라이맥스 구간" 진행감 |

설계 원칙: 클라이맥스가 **"죽을 것 같음"**이 아니라 **"집까지 뚫고 감"**으로 읽혀야 함.

### 음악 단계
1. **평온** — 출격 초반, 빌드업
2. **음산** — 위협 누적, 점진적 변화 (부드러운 전환)
3. **강렬** — 집 근처 도달 시 컷 전환, 마지막 돌파 클라이맥스

3단계는 안전 신호가 아닌 **마지막 돌파의 위험 + 카타르시스**.
실패하면 그 음악을 들으며 죽음 — 영화적 종결.

## 5. 돌파 모드 (Climax Sequence)

### 형태: 연속 + 강화형
씬 전환 없이 게임플레이가 그대로 이어지되, **집 근처 30초~1분 구간**에서 동시 발동:
- 음악 컷 전환 (음산 → 강렬)
- 좀비 밀집도 증가
- 카메라 살짝 줌아웃 (속도감 강조)
- 화면 채도 변화

조작은 평소와 동일 — 별도 학습 비용 없음.

### 시그니처 위치
- 표준 뱀서: 후반 = 버티거나 죽거나
- ZombieCrush: 후반 = **강해진 적을 쓸어버리며 귀환**
- 자동차만의 클라이맥스 (Risk of Rain 2 텔레포터·Hades 보스와 다른 결)

### 향후 리스크 (Task #5)
반복 피로 방지를 위해 도로 구조/적 조합/차량 빌드별 변주 필요. 별도 세션 주제.

## 6. 멀리 가게 만드는 본능 — 3채널 (탑다운 친화)

탑다운 시점은 "지평선 너머 베이컨"이 약함. 따라서 시각이 아닌 **다른 감각 채널**로 본능을 자극한다.

### 채널 1. 미니맵 모호 마커
- 점/얼룩 같은 모호한 표시 — "여기 뭔가 있다"
- 명시적 아이콘 (느낌표, GOAL) **절대 X**
- 색상으로 강도 암시
- 도달 시 사라짐, 다음 출격에서 새 위치

### 채널 2. 좀비 Herd (메인)
- 좀비가 무작위가 아니라 **특정 방향에서 흘러나옴**
- "저쪽에 뭔가 있어 좀비가 모인다" 직관
- 역추적 본능 → 멀리 가는 동선 자연 형성
- 영상적으로도 멋짐

### 채널 3. 사운드 큐 (보조)
- 멀리서 단편적으로 들리는 폭발음·총성
- 방향성 오디오로 위치 인지
- 직접 설명 X → "가봐야 알겠다" 미스터리

### 보조: 속도 기반 카메라 줌아웃
이미 결정됨 (2026-05-19 §4.3) — 빨리 갈수록 더 멀리 보임. 자연 보상.

## 7. 환경 떠먹임 (서사 채널)

### 톤 레퍼런스: Hades식 따뜻한 어두움 (확정)
- 아포칼립스지만 높지 않은 유머
- 주인공의 담담함, 다치면 웃으며 다시 나감
- "그냥, 살아있으니까. 어제도 나갔으니까."

### "왜 나가야 하는가" — 최종 답
> *"그냥, 살아있으니까."*

미션 X, 거대 목표 X, 일상감 O.
이 일상감이 아포칼립스 톤과 묘하게 어울림 — "세상은 끝났는데, 나는 또 커피 마시고 차에 시동 건다."

### 채널 4가지

| 채널 | 예시 |
|---|---|
| **도로 표지판** | "WELCOME TO ROCKVILLE pop. ~~12,000~~ 3" / "Best Pancakes! (CLOSED)" |
| **차량 메모** (글로브박스 픽업) | "오늘도 무사히 - M" / "스페어 키 글로브박스. 미안." |
| **집 디테일** | 벽 사진, X 표시 달력. 출격 횟수 따라 소품 점진 추가 |
| **비상 방송 라디오** | 끊긴 정부/구조대 송출, 가끔 잡힘 — **주 목표 전달 X**, 분위기·옛 안내문만 |

### 텍스트 작성 디렉션
- 담담 (NOT 비장)
- 가끔 유머 (NOT 농담)
- 작은 일상 디테일 (NOT 거대 서사)
- 모호한 슬픔이 새어 나옴 (NOT 명시적 설명)

### 비상 방송 정당화
"대부분 끊겼고 가끔만 잡힌다"는 설정이 Hades식 톤·"그냥 살아있으니까" 모놀로그와 맞물림.
주 목표 전달이 아니라 분위기·집 방향 암시·옛 안내문 같은 **보조 신호**로만 사용.

### 룰
- UI 알림창 X
- 강제 컷신·튜토리얼 X
- 모든 떠먹임은 **다 안 봐도 게임 진행 영향 없음**
  → "애기는 그냥 부수기 / 천재 해커는 다 찾아 읽기" 둘 다 충족

### 보조 시각 신호
- 화면 채도 변화 (BGM 보조, 음소거 플레이어 대응)

## 8. 자원 구조 (이중 화폐)

### 스크랩 (일상 화폐)
- 출처: 좀비 처치, 일반 픽업 (어디서나, 단 멀리 갈수록 양/등급↑)
- 사용처: 차고 안 차량 영구 강화, 모듈 강화, 정비소 사용료

### 집 부품 (특별 픽업)
- 출처: **멀리서만** 드롭 (가까운 곳 거의 X)
- 사용처: 차고/정비소 시설 잠금 해제, 새 차량 잠금 해제, 새 모듈 청사진 잠금 해제

### 거리 보상 곡선 (비대칭)
| 거리 | 시간당 효율 |
|---|---|
| 집 근처 | 매우 낮음 (가능은 하지만 답답) |
| 중간 | 보통 |
| 먼 곳 | **압도적으로 좋음** |
| 너무 먼 곳 | 좋지만 손상도/시간 한계로 자연 회수 |

가까운 곳도 농사 가능하나 비효율 → 본능적 효율 추구가 자연스럽게 멀리 가게 만듦. **강요 X, 욕망 O.**

### 픽업 신선도 (재스폰 룰)
- 한 번 정리한 좀비 구역은 일정 시간 재스폰 X
- 이미 정리한 곳은 빛 안 남
- "이 동네는 다 털었다" → 자연 영역 확장
- 출격 종료 시 리셋

### Steam 카피 정의
> *"좀비로 뒤덮인 먼 도로를 뚫고 더 값진 스크랩과 잊힌 생존 흔적을 싣고 돌아오는 것."*

## 9. 집 시스템 (메타 허브)

### 구조: 뱀서 표준 메뉴 화면 + 톤 포장
- 3D 공간 X, NPC X
- **일러스트 배경 + 시설 UI 슬롯**
- 1인 개발 비용 통제

### 핵심 통찰
우리 "집"은 본질적으로 뱀서류의 **메인 메뉴/캐릭터 선택 화면**과 같다.
- VS의 "Coffin" 메뉴, Brotato 캐릭터 선택, Halls of Torment 메뉴와 같은 자리
- 단, **톤(아포칼립스 생존)**을 입혀 차별화

### Tier 1 시설 (MVP)
| 시설 | 역할 |
|---|---|
| **정비소** | 출격 전 차량 수리 (손상도 시작점), 모듈 정비 |
| **차고** | 차량 선택 + 모듈 장착 + 영구 강화 + 새 차량/모듈 잠금 해제 + 외형 |

**무기고는 별도 시설로 두지 않음** — 차량 = 무기 컨셉을 시스템 레벨에서 통일하기 위해 차고에 흡수.

### Tier 2 시설 (출시 후 업데이트 / DLC1)
무전기 / 연료 저장고 / 방어 시설 등

### Tier 3 시설 (DLC2 / 1.0)
차량 커스터마이징 베이 / 연구소 / 새 지역 접근 등

### 진척감 시각화
- 잠긴 슬롯이 처음부터 보임 — "갖고 싶다" 욕망
- 채워질수록 차고 일러스트가 풍성해짐
- 플레이 시간에 비례한 시각적 보상

## 10. 차량 = 무기 통합 컨셉

기존 GDD §5.4의 4가지 성향이 차고 안의 **빌드 트리**가 됨.

| 성향 (기존 §5.4) | 빌드 정체성 |
|---|---|
| 안정형 | 핸들링·방어 |
| **돌진형** | **박치기 위주** |
| **드리프트형** | **드리프트 위주** |
| **자동전투형** | **포탑·자동 공격** |

### 두 레이어 빌드
| 레이어 | 결정 시점 | 깊이 |
|---|---|---|
| **메타 빌드** | 차고 (출격 전) | 차량 선택 + 모듈 슬롯 (얕음, 뱀서 진입 보호) |
| **인게임 빌드** | 출격 중 피트스톱 | 무기·파츠 픽업으로 형성 (깊음, 메인) |

두 레이어의 곱셈으로 빌드 다양성이 깊어지되, 메인은 인게임 — **뱀서 결 유지**.

## 11. 차량 라인업 (6대)

| 순번 | 이름 | 성향 | 시그니처 | 톤 디테일 |
|---|---|---|---|---|
| 1 | **The Daily** | 균형형 (시작) | 없음, 평범 | 아이 카시트, 쇼핑 리스트 메모 |
| 2 | **Old Bull** | 돌진형 | 정면 충돌 피해↑, 무게↑ | 농장 트럭, 짐칸 녹슨 도구 |
| 3 | **Ghost** | 드리프트형 | 드리프트 반경↓, 가속↑ | 라디오에 친구 이름, 사이드미러 깨짐 |
| 4 | **Boulder** | 안정형 | 체력↑, 흡수 범위↑ | 군용 페인트, 안에 인식표 한 개 |
| 5 | **Patrol** | 자동전투형 | 포탑 슬롯, 사이렌 도발 | 무전기 잡음 (비상 방송 시너지) |
| 6 | **Sweet Tooth** | 특수/하이브리드 | 음악으로 좀비 유인 후 박치기 | 아이스크림 트럭, 음악이 가끔 자동 |

### 잠금 해제 곡선

## 15. MVP 스코프 (재정의)

기존(2026-05-19 §8)에서 메타 진행은 제외였으나, 정체성 결정으로 **MVP에 포함**.

### 포함
- 차량 이동 (관성·가속·감속), 충돌 공격 판정
- 자동 기본 무기 1종 (출격 중 픽업 확장)
- 적 2~3종 (Herd 스폰 패턴 포함)
- 레벨업 선택 UI (피트스톱)
- 모듈/파츠 6~8종, 무기 슬롯 시스템
- XP 수집 + 거리 보상 곡선
- **집 (메뉴 화면 + 일러스트 배경)**
- **Tier 1 시설: 정비소 + 차고**
- **차량 3대로 시작** (Daily / Old Bull / Ghost — 빌드 다양성 검증용)
- **BGM 3단계 시스템 + 거리/손상도/시간 가중치**
- **귀환 돌파 모드** (집 근처 트리거 + 컷 전환)
- **환경 떠먹임**: 도로 표지판, 차량 메모, 집 디테일 일부
- **자원 이중 구조 (스크랩 + 집 부품)**
- **미니맵 모호 마커**
- **좀비 Herd 방향성 스폰**

### 제외 (이후 단계)
- Tier 2/3 시설 (무전기, 연료, 방어시설, 연구소 등)
- 보스
- 수동 특수 스킬
- 맵 다양성 (지역 확장)
- 차량 4~6번 (Boulder/Patrol/Sweet Tooth — DLC 후보)
- 돌파 변주 시스템 (Task #5)
- 비상 방송 라디오 풀 (출시 시점 최소 풀, 이후 확장)
