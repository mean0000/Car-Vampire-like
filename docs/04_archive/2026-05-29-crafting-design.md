## 0. 범위 & 핵심 긴장

**실시간 크래프팅 긴장감** (TLoU 레퍼런스): 제작 3초 동안 노출 + 소음 +20/초 → **완료 순간 임계 50 돌파**(infection-noise §1.2 검증). "지금 이 회복약이 필요한데 만드는 3초가 위험하다."

**두 플레이스타일이 각자 크래프팅에 도달** (두-비용 엔진 확장):

| 경로 | 재료 획득 | 레벨업(킬) | 비용 |
|---|---|---|---|
| 전투 | 좀비 처치 드롭 | 시끄러운 킬 | 소음↑ (호드+HP) |
| 스텔스 | 먼 구역 루트포인트 + 암살 | **암살(+0 소음)도 킬 카운트** | 감염↑ (귀환 압박) |

→ 스텔스 플레이어도 암살로 레벨업하고 루트로 재료를 모은다. 어느 쪽도 크래프팅에서 배제되지 않되, 각자 다른 대가를 치른다.

**MVP 제외** (GDD §17): 스톡파일, 등급 분화, 중단 페널티, 4종 외 아이템.

## 1. 2층 구조

```
[1층] 레벨업 → 설계도 해금        [2층] 재료 → 제작
  킬 5/12/25 → 레벨 1/2/3            설계도 보유 + 재료 5개
       │                                  │
   2개 중 1개 설계도 선택              제작 3초 (소음 +20/s)
       │                                  │
   레시피 영구 해금 (런 동안)          아이템 1개 생성
```

- **1층(해금)**: 무엇을 만들 수 있는지. 런당 최대 3종 해금(4종 중).
- **2층(제작)**: 해금된 것을 재료 5개로 실제 생산. 소모품은 반복 제작.

## 2. 레벨업 & 설계도 선택 (1층)

| 항목 | 값 |
|---|---|
| 레벨업 트리거 | 누적 킬 **5 / 12 / 25** (3레벨) |
| 킬 정의 | 근접 처치 **또는 암살** 모두 카운트 (암살=소음+0이라 스텔스 레벨업 가능) |
| 설계도 선택 | 레벨업 시 **미해금 아이템 2개 중 1개** |
| 풀 추출 | Lv1: 4종 중 2개 / Lv2: 남은 3종 중 2개 / Lv3: 남은 2종 |
| 등급/희귀도 | **없음** (GDD §17 등급 분화 제외) |

> 25킬에 3레벨 = 4종 중 3종 해금, 1종은 다음 런으로. 선택의 무게 = "이번 런에 뭘 포기하나".

## 3. 재료 시스템 (2층 입력)

| 항목 | 값 |
|---|---|
| 종류 | **단일 범용 재료** ("부품") — GDD v2.5 "거리 전용 재료 없음" |
| 제작 비용 | 아이템당 **5개** |
| 드롭원 | ①좀비 처치 ②먼 구역 루트포인트(큐브) |
| 거리-보상 곡선 | **드롭 확률·수량이 집에서 멀수록 완만히 상승** (GDD v2.5 밀도+확률 기울기) |

### 거리-보상 곡선 (시작값)

```
드롭 확률 = 0.3 + 0.5 × (집으로부터 거리 / 맵 최대거리)
  집 근처:  ~30% 확률, 1개
  먼 구역:  ~80% 확률, 가끔 2개
루트포인트: 먼 구역에 밀집, 개당 2~3개
```

- 25킬 + 평균 ~50% 드롭 ≈ 재료 12~15개 ≈ 런당 **2~3회 제작** + 루트 보너스. 스팸 불가, 의미 있는 선택.
- 등급 곡선(아이템 등급 상승)은 **post-MVP** (MVP는 밀도+확률만).

### 킬 = 수확 (Harvest) — "왜 좀비를 잡는가"의 답 (2026-05-29 확정)

**테마**: 좀비 = 나노봇 감염된 인간 = *걸어다니는 재료 캐시*. 죽이기 = 나노봇/바이오매스 **추출**. (AI 감염 세계관 직결.) → 킬의 만족은 "경험치 그라인드"가 아니라 **통쾌한 수확 + 빌드 엔진 가동**. 레벨업(질적 동사)은 *배경 트랙*으로 강등.

| 요소 | 설계 | 보유 에셋/기존 |
|---|---|---|
| 즉각 보상(모든 킬) | 재료 드롭 + 화려한 픽업 연출 + 손맛 사운드 | Ultimate Loot VFX, Complete UI Sound |
| 타격감 | 히트스탑 + 카메라 쉐이크 + 킬 범프 | Feel, `MMSpringScale`(기존 코드) |
| 수확 품질 | 암살(클린)=더 많/깨끗 · 시끄러운 킬=표준 · 신호/엘리트=희귀 드롭 | 기존 암살/소음 |
| 수확 콤보 | 빠른 연속 처치 → 수확량·드롭등급↑ ("질러서 한 무리 쓸면 대박") | C1 피의 리듬 연동 |
| 균형 | 콤보 수확 = 고소음 = 호드+HP 위험 | 두-비용 엔진 자동 |

**두 수확 경로**: 전투=빠른 *대량* 수확(시끄러움) / 스텔스=암살 *정밀* 수확 + 루트포인트(조용·느림). → 같은 재료, 다른 결.

> 철학: 킬은 *권능 판타지가 아니라 대가 있는 통쾌한 수확*. 긴장된 스텔스와의 대비가 "질러버리는" 순간을 짜릿하게 만든다. 새 시스템 0개 — 재료 시스템 + 보유 VFX/Feel/SFX + 기존 콤보 재조합.

## 4. 제작 행위 (2층)

| 항목 | 값 |
|---|---|
| 위치 | **어디서나** (실시간, 현장) — TLoU식 노출 긴장 |
| 제작 시간 | **3초** |
| 소음 | **초당 +20** → 완료 시 누적 ~51 (임계 돌파) |
| 재료 소모 | **완료 시점**에 5개 차감 |
| 중단 | **취소 자유, 페널티 없음** (MVP). 단, 진행 중 발생한 소음은 이미 남음 |
| 동시 진행 | 1개씩 |

> 페널티가 없어도 긴장은 **상황적 필요 + 기회비용**에서 나온다: "HP 20인데 회복약 3초가 급하다" / 취소하면 못 얻는다. 중단 페널티는 post-MVP 노브.

## 5. 아이템 4종 상세 (★ 확인 필요 — §9.1)

GDD 괄호 표기를 해석한 **권장안**: 단검=영구 업그레이드, 나머지 3종=소모품(반복 제작). 소모품 3종이 "반복 크래프팅 루프 + 실시간 긴장"을 만들고, 단검은 마일스톤 강화.

| 아이템 | 분류 | 효과 (시작값) | 루프 역할 |
|---|---|---|---|
| **단검** (근접↑) | 영구 업글 (1회) | 근접 데미지↑ → 일반 좀비 **3타→2타** | 전투 효율 마일스톤 |
| **연막탄** (스텔스쿨↓) | 소모품 | 투척 → 연막 AoE: 범위 내 좀비 **추적 해제** + 본인 **스텔스 쿨 즉시 리셋** | 스텔스 탈출 강화 콤보 |
| **지뢰** (범위킬) | 소모품 | 설치 → 무장 → 접근 좀비 **범위킬**(반경 ~3m, 일반 즉사, 넉백) | 호드 관리·후퇴 엄폐 |
| **구급상자** (HP회복) | 소모품 | 사용 → **HP +50** (회복 유일원, GDD v2.4) | 생존 자원 |

- **연막탄 ↔ 스텔스**: 호드 유발 → 연막으로 추적 끊고 즉시 재스텔스(감염+1) = 탈출 콤보. infection-noise §3.4와 직결.
- **구급상자**: 유일한 회복 → HP가 희소 → 전투 위험 → 스텔스 동기. 두-비용 엔진 강화.

## 9. 미정 / 확인 필요

### 9.1 아이템 분류 (★ 핵심 확인)
권장안은 **단검=영구, 나머지 3종=소모품**. 대안:
- **A. 권장 (1영구+3소모)** — 반복 크래프팅 루프 강함, 실시간 긴장 잦음.
- **B. 2영구+2소모** — 단검·연막탄 둘 다 영구(연막탄=스텔스 쿨 8→6초 영구). GDD 괄호에 더 문자적. 단, 영구 2개는 1회 제작이라 반복 긴장 약함.
- **C. 전부 소모품** — 단검도 임시 근접 버프(N초/M타). 가장 단순·균일하나 "근접↑"의 영구 성장감 약함.

→ **A vs B vs C 확정 필요.**

### 9.2 기타 노브 (post-MVP 후보)
- 중단 페널티 (재료 일부 손실)
- 아이템 등급 곡선 (먼 곳 = 강한 버전)
- 재료 종류 분화

## 10. 플레이테스트 튜닝 가이드 (§17 기준 연동)

| 증상 | 진단 | 레버 |
|---|---|---|
| 크래프팅 한 번도 안 함 | 비용 과다 or 동기 부족 | 재료비 5→3, 드롭 확률↑ |
| 제작이 안 위협적 | 노출 시간 짧음 | 제작 3→4초, 소음 +20→+25/s |
| 재료가 남아돎 | 드롭 과다 | 드롭 확률↓, 비용↑ |
| 스텔스 플레이어가 레벨업 못 함 | 암살 킬 불충분 | 루트포인트에 소량 킬카운트 부여 검토 |
| 설계도 선택이 안 고민됨 | 아이템 차별성 부족 | 효과값 차등 강화 |

> 측정: 런당 제작 횟수, 아이템별 제작 분포, 평균 재료 보유, 레벨3 도달률.
