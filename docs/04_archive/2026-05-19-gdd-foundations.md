## 2. 핵심 컨셉

> **"피하는 뱀서류가 아니라, 주행 라인을 설계해서 적 무리를 쓸어버리는 뱀서류"**

자동차의 관성은 플레이어를 방해하는 요소가 아니라,  
적·맵·무기·성장 전체를 연결하는 **중심 규칙**이다.

---

## 3. 확정된 기획 결정사항

### 3.1 코어 메카닉

- **충돌/로드킬이 주 공격 수단 중 하나**
- 차량의 속도, 관성, 드리프트, 충돌을 활용해 적을 회피하거나 처치
- "내가 속도 내서 박음 = 공격 / 멈춰있거나 옆에서 받힘 = 피해" 원칙

### 3.2 코어 게임플레이 루프

```
적 무리 확인
→ 주행 라인 선택
→ 드리프트/충돌/자동공격으로 돌파
→ XP 및 보급품 획득
→ 반복
```

### 3.3 코어 루프

```
차량 선택
→ 전투 진입
→ 전투 중 성장 (업그레이드 선택)
→ 보스/웨이브 돌파
→ 보상 획득
→ 차량/부품 강화
→ 재도전
```

---

## 4. 비주얼 방향

### 4.1 아트 스타일

**카툰 로우폴리 (Cartoon Low-poly)**

- 낮은 폴리곤 + 과감한 채도 높은 색감
- 레퍼런스: TABS, Trailmakers 계열 미학
- 뭉툭한 실루엣, 장난감 같은 물리감이 전체에 일관되게 적용
- 다크/그리티 소재감(녹슨 차, 폐허 도시)을 일부 가져오되 화면을 어둡게 만들지 않음

### 4.2 주요 에셋 방향

- **Synty POLYGON - Apocalypse Pack** 기반으로 스타일 통일
  - 좀비/차량/도시/무기/프롭 일괄 커버
  - 부족한 차량은 POLYGON - Street Racer 등으로 보강
- URP + 기본 Directional Light + Bloom 조합
- 텍스처 대신 Material Color 기반으로 처리 (텍스처 아티스트 불필요)

### 4.3 시점

탑다운 3D (카메라 고정, XZ 평면 게임플레이)

- 속도 방향으로 카메라가 살짝 앞을 보여주는 방식
- 속도에 따른 줌 아웃, 모션 블러, 화면 흔들림으로 속도감 표현

## 5. 시스템 설계

### 5.1 무기 시스템

| 단계 | 내용 |
|---|---|
| MVP | 완전 자동 발사 (조작 부하 최소화) |
| 이후 | 특수 수동 스킬 1개 추가 (스페이스바/마우스 클릭) |

- 기본 무기: 차량 이동/방향에 연동된 자동 발사
- 특수 스킬: "안 쓰면 확실히 손해"인 상황 설계 필요
- 무기는 차량 움직임과 연결: 전방 기관총, 사이드 톱날, 후방 지뢰, 드리프트 화염 등

### 5.2 경험치 수집

**로드킬 XP 생성 + 차량 흡수 범위**

- 좀비 사망 시 해당 위치에 XP orb 생성
- 차량 흡수 반경 내 자동 수집 (스크랩 흡입기/견인 자석으로 포장)
- 시체 오브젝트 실제 유지 X → 짧은 애니메이션 후 비활성화, Object Pool 사용
- 업그레이드로 흡수 범위 확장 가능

### 5.3 업그레이드 루프 (레이어드 구조)

| 레이어 | 역할 | 예시 |
|---|---|---|
| 엔진 | 이동속도, 가속, 관성, 최고속도 | 가속 강화, 핸들링 증가 |
| 무기 | 장착 무기 종류 및 강화 | 기관총 레벨업, 새 무기 장착 |
| 파츠 | 방어, 회복, 경험치 흡수 범위 등 패시브 | 방어막, 회복 부품 |
| 특수장치 | 빌드 정체성 완성 (후반부 등장) | 나이트로 과급기, 드리프트 제너레이터 |

**레벨업 UI: "피트스톱 (Pit Stop)"** 프레임  
- 선택지 3개, 가끔 리롤 1회
- 동일 아이템 2~3회 획득 시 업그레이드
- 특수장치는 10분 이후 등장

### 5.4 성장 성향 (4가지)

| 성향 | 특징 |
|---|---|
| 안정형 | 핸들링 증가, 방어 강화, 충돌 피해 감소 |
| 돌진형 | 최고속도 증가, 정면 충돌 피해 증가, 부스터 관통 |
| 드리프트형 | 드리프트 반경 감소, 드리프트 중 무적, 타이어 자국 피해 |
| 자동전투형 | 포탑 추가, 후방 지뢰, 자동 미사일 |

## 6. 적 설계 방향

적은 단순히 "플레이어를 둘러싸는 존재"가 아니라  
**주행 라인을 만들고 깨뜨리는 존재**여야 한다.

| 적 유형 | 역할 |
|---|---|
| 소형 적 | 들이받으면 밀려나거나 터짐 |
| 무거운 적 | 정면 충돌 위험, 측면 공략 가능 |
| 추격형 적 | 뒤를 따라오지만 급회전에 약함 |
| 길막형 적 | 경로를 막지만 부스터/드리프트로 돌파 |
| 원거리 적 | 이동 루트를 강제로 변경 |

## 7. 기술 구현 방향

### 7.1 충돌 공격 시스템

- 차량: Rigidbody (Y축 constraints 고정)
- 좀비: Trigger Collider 기반 판정 (실제 물리 충돌 최소화)
- 공격 판정: 속도 기반 피해량 + 방향 기반 가중치 (정면 > 측면 > 후방)
- 저속 접촉 피해 방지를 위한 속도 임계값 설정

### 7.2 성능 최적화 원칙

- 좀비끼리 충돌 비활성화
- 투사체 Object Pool 필수
- 공격/탐색 주기 0.1~0.25초 단위 분산
- XP orb, 시체, 피격 이펙트 전부 Pool 처리
- 화면 밖/먼 거리 좀비 낮은 빈도 업데이트

### 7.3 NavMesh

탑다운 3D 특성상 NavMesh로 좀비 AI 경로 탐색 구현

## 8. MVP 스코프

**목표: 핵심 루프 검증 가능한 최소 플레이어블**

### 포함
- 차량 이동 (관성, 가속, 감속)
- 충돌 공격 판정
- 자동 기본 무기 1종
- 적 2~3종
- 레벨업 선택 UI (피트스톱)
- 무기 8~10종, 파츠 6~8종
- XP 수집 시스템

### 제외 (이후 단계)
- 특수장치 레이어
- 보스
- 수동 특수 스킬
- 메타 진행 (차고 업그레이드)
- 맵 다양성

## 9. 개발 단계

| 단계 | 목표 | 성공 기준 |
|---|---|---|
| Phase 1 | 충돌 판정 프로토타입 | 처음 보는 사람이 5분 내 "속도 내서 박으면 공격"을 스스로 발견 |
| Phase 2 | 맵과 적 행동 검증 | 플레이어가 자발적으로 주행 라인을 선택하는 행동 관찰 |
| Phase 3 | 성장 루프 검증 | 돌진형 vs 드리프트형 2가지 성향이 다른 플레이 느낌 전달 |
| Early Access | 기본 콘텐츠 완성 | 무기 10종, 파츠 8종, 맵 1개, 웨이브 구조 |
| 1.0 | 정식 출시 | 메타 진행, 차량 3종 이상, 보스 시스템 |
