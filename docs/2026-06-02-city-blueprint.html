🏠 집 / 거점 (외곽, 0m)

정체주인공의 구역(외곽)이 평원과 접함. 차고를 낀 은신처. 평원은 차 + 통신차단 없이는 못 건넘.
기능① 감염 시계 회복 ② 설계도로 얻은 아이템 제작(작업대) ③ 탈출 준비 — 차에 이동식 통신 차단 시스템 장착
공간 / ★안전집 내부만 안전. 집 밖으로 나오는 순간 안전지대 없음(30m 버블 폐기). 차고 + 작업대 + 평원 출구.
★바리케이드거점 주위 바리케이드로 차가 도시 안으로 못 들어가게 막음 — 평원 방향 출구만 차 통행 가능. (도시는 도보 전투 공간 유지)
결정필요: 집에 메타 업그레이드/허브 기능을 둘지(영구 강화·해금) vs 회복+제작만.

🪖 Zone A — 군 검역 외곽 0–300m · 게이트① 엘리트 · 튜토리얼 구역

진입집에서 무너진 봉쇄선(검문소 잔해)을 넘어 도시로 첫발.
서브구역① 검문소 광장(트인 시작 파밍) → ② 버려진 차량 도로(레인 카이팅 연습) → ③ 게이트 접근로
랜드마크무너진 군 검문소 아치 — 콘크리트 장벽 + 가드타워 + 좌초된 장갑차. 멀리서도 "여기가 관문".
카이팅 지형바리케이드·컨테이너 줄 = 좀비 떼 유도 레인. 트여 있어 입문 친화(시야 확보 쉬움).
초크포인트(게이트①)검문소 아치 돌파구 = 좁은 통로. 엘리트가 막아섬.
인카운터일반 좀비 저밀도 + 게이트에 엘리트 1(HP·뎀↑). 처치 = 돌파 + 첫 시계 둔화템.
파밍/보상기본 무기·재료(저등급). 첫 레벨업 2~3회 분량.
체크포인트①아치 너머 전진 지점 — 회복 여부는 §결정0(안전지대 없음과 충돌).
무드따뜻한 황혼 앰버 + 모래먼지. (가장 밝음)
에셋BR 컨테이너·바리케이드·가드타워·장갑차 + StreetProps 콘/배리어 + Generic 도로.

🏗️ Zone B — 미완성 증축지구 300–650m · 게이트② 호드 · 밀집 상승

진입검문소 너머 첫 빌딩 군집 — 거리가 좁아지기 시작.
서브구역① 골조 빌딩 거리(중밀도 파밍) → ② 비계 미로(병목 카이팅) → ③ 크레인 붕괴 대로(게이트)
랜드마크멈춘 거대 크레인 + 철근 골조 타워(붕괴 직전). 수직 실루엣.
카이팅 지형좁은 골목·비계로 떼 병목 형성. ★결정: 비계 위 2층 경로(수직 이동) 넣을지.
초크포인트(게이트②)무너진 구조물/크레인 잔해로 막힌 대로 = 호드 점거 지점.
인카운터중밀도 + 대형 좀비 등장. 게이트 = 호드 웨이브(정면 떼전투 — 스텔스 없음). N처치 또는 T점거로 돌파.
파밍/보상중급 재료 + 골조 구조물 속 전리품 포켓. 빌드 본격화.
체크포인트②붕괴 대로 너머.
무드먼지·식어가는 빛, 콘크리트 회색 + 녹슨 철근 주황.
에셋Construction 골조·철근·크레인·비계·옹벽 + Generic Base(미완성 주거).

🌃 Zone C — 죽은 환락 도심핵 650–1000m · 게이트③ 보스 · 정점

진입골조지구에서 옛 도심 네온 가로로 — 가장 빽빽·어두움.
서브구역① 죽은 네온 골목 미로(고밀도 파밍) → ② 화재대피계단 수직 구간 → ③ 네온 광장(보스 아레나)
랜드마크죽은 네온 광장 + 머리 위 닿지 못하는 거대 타워(원경). 높이감은 배경이 담당.
카이팅 지형가장 폐소. 골목 병목 + 화재대피계단 수직. 실수 = 포위.
초크포인트(게이트③)무너진 대로/네온 광장 = 보스 아레나.
인카운터최고 밀도 + 보스. 처치 → 이동식 통신 차단 시스템 드롭(움직이며 AI 통신 교란).
파밍/보상고급 재료. 최종 빌드 완성 구간.
이후집 귀환 → 차에 통신차단기 장착 → 평원 탈출(이동 중 AI 통신 교란으로 돌파).
무드차갑게 죽은 적자홍 네온 + 짙은 헤이즈. (가장 어두움 — 온도 아크 끝)
에셋Nightclubs 셸·네온·화재대피계단·쇠창살 + Generic 도로 + 볼륨 보강용 Synty 추가팩.

★ 결정 필요 목록 (세분화하며 정할 것)

0. ★회복/생존 모델 (최우선) — "집 밖 안전지대 없음"이 기존 "게이트=전진 체크포인트(회복)"와 충돌. 1km를 어떻게 버티나? (a) 회복은 집에서만(난도↑·도달거리↓) (b) 체크포인트는 회복하되 안전하진 않음(좀비 계속, 압박 속 회복) (c) 이동식 통신 차단기 = 일시 좀비 흩어짐(이동식 숨돌리기, 정적 안전지대 대체) (d) 휴대 소모품 회복.
1. 집 허브 기능 — 메타 업그레이드/해금 둘지 vs 회복+제작만.
2. 수직 이동 — 비계·화재대피계단으로 2층/옥상 경로(수직 카이팅)를 게임플레이에 넣을지. (넣으면 카메라·이동 설계 영향)
3. 파밍 재료 (부분 확정) — 설계도 + 제작 재료를 주워 집 작업대에서 제작. 구체 재료군·설계도 종류는 crafting-design.md와 연동해 확정.
4. 되돌이 파밍 보상 곡선 — 얕은 구역 저보상 정도(전진 유도 강도). 수치는 플레이테스트.
5. 특수 좀비 — 옛 "신호 좀비"를 전투용(예: 죽이면 떼 유인하는 엘리트 트리거)으로 살릴지 폐기할지.
6. 사이드 포켓 — 병원·지하철 등 짧은 탈선 보상 구간을 둘지(정체성 희석 주의). 곁가지로만.
7. 서브구역 개수/크기 — 각 구역을 3비트로 잡았는데, 더 잘게/크게?
