1. 무엇을 보고 분석했나 (데모 스크린샷)

액션 임팩트방사형 백색 참격 버스트. 부감 쿼터뷰, 거대 호드 한가운데 "내가 군중을 밀어냈다"는 즉시 피드백. 좌하 HP/XP, 우상 타이머·축복 아이콘. 단 플레이어가 이펙트에 묻힐 위험.
보스 전조보스 Arcanus 'The Faceless'. 지면 빨간 빔 전조 패턴 + 청록 그리드로 화면 공간을 선·면으로 장악. 상단 보스 HP바. 색=위험(적)/환경(청록) 분리.
거점 · 출격망각의 성채 / 출격 포탈. 런 사이 운영 공간 + 3인칭 컷씬 무드. 다크판타지 톤.
서사 프레이밍천사 GALILIEL ("Angel of Poison & Conspiracy"). 드래프트 제공자에 캐릭터·서사를 입힘(Hades풍). 픽=스탯+세계관 사건.

2. 두 독립 눈의 분류

같은 질문을 시각 분석(Codex)과 시스템 정합(에이전트) 두 갈래로 던졌다. A=반드시 참고 / B=참고하면 좋을 것.

◆ Codex · gpt-5.5
크로스 프로바이더 · 이미지 직접 분석 (화면 가독성·연출 관점)
★ 유저 확정 (2026-06-16): Codex 항목은 A·B 전부 최우선으로 승격. 아래 11개 모두 "반드시" 등급.
A · 반드시 참고 (최우선)
  • 전조가 먼저, 폭발은 나중 — 지면 빔/라인 전조가 패턴 이해를 만듦. → 보스 탄막·돌진·포격을 빨간 위험영역 → 짧은 락온음 → 실제 피해 순서로, 총기 회피 리듬화.
  • 중앙 캐릭터 가독성 확보 — ss1은 플레이어가 묻힐 위험. → 조준형이므로 플레이어 실루엣·조준선·커서 1~2m는 항상 시각 우선권.
  • 방사형 임팩트의 쾌감 — 백색 참격버스트="군중을 밀어냈다". → 산탄·관통탄·충격파탄의 원형/부채꼴 넉백 연출로 변환.
  • 보스의 지형 점유감 — 보스가 선·면으로 공간 장악. → 체력몹 금지, 봉쇄선·생체 포탑·감염 장판·저격 레이저로 이동 경로 압박.
  • 색으로 피해 계층 분리 — 빨강=위험/청록=환경. → 적 전조·플레이어 탄·시민 목표·아이템 색을 엄격 분리.
  • 군중 속 한 방의 타격 피드백 — 다수 피격을 한 덩어리로. → 숫자보다 관통 궤적·탄착 스파크·사지 파편·웨이브 밀림으로 "탄이 군중을 찢었다".
B · 원래 "좋을 것" → ★최우선 승격 유저 확정 06-16
  • 보스명/체력바의 의식감 — 등장 시 이름·파벌 문양·봉쇄 단계·처치/시간 게이지를 한 번에.
  • 흔들림·히트스톱 제한 사용 — 샷건·저격·폭발·약점 파괴 때만 짧게(조준감 보호).
  • 보스별 컬러 아이덴티티 — 파벌별 감염색·탄막색·시체 잔흔색 차별화.
  • 전장 장식의 밀도 — 폐쇄구역·구조차량·방역벽·변종 둥지·민간인 잔해로 "사후처리부" 세계관.
  • 시그니처 패턴의 스크린샷성 — 보스마다 한 장면으로 알아보는 시그니처 패턴 1개씩.
◆ GameDesign 에이전트
코어 권위 정합 · 시스템/런구조 관점 (검→총 변환 + 충돌 감사)
A · 반드시 참고
  • A1 · 자동 베이스 + 수동 액션 레이어 — 순수 자동 뱀서의 "손맛 없음"을 푸는 검증된 해법. → 저쪽 수동=검 콤보, 우리 수동=방향 조준 사격. 정합: §2 "조준 사격 / 무조준 자동 ❌"와 일치.
  • A2 · 전조 → 회피 → 반격 데미지 창 — 카이팅에 "읽고 대응"하는 깊이. → 조준 회피 → 재조준 사격 보너스 창. ⚠ 이동+조준+회피 손가락 과부하 → 노브 검증 필수.
  • A3 · 적 등급 = 전조 강도의 다이얼 — HP 스펀지가 아니라 읽히는 위협 강도로 등급 표현. 정합: "등급=행동변화" 정신, 폐기된 5계열의 비-rigid 대체.
  • A4 · 화려함 ≤ 가독성 가드레일 — 경쟁작이 같은 함정을 밟음. → 정보 레이어(상시 클린) vs 연출 레이어 분리를 처음부터. [[juice_textbook_lessons]] 확증.
  • A5 · 보스 = 인런 클라이맥스 — 정교한 컨트롤+패턴 긴장이 런의 정점. → 조준 카이팅 패턴 회피 → 사격 윈도우. 전조는 A3 최댓값. ⚠ 카메라 전환 연출은 회수(아래).
B · 참고하면 좋을 것
  • B1 · 콤보 입력 리듬 — 자동 뱀서의 "구경만 함" 함정 해소. → 점사/풀오토/차징의 사격 리듬. ⚠ 카이팅 이동과 입력 과부하 트레이드오프.
  • B2 · 거점 허브 (망각의 성채) — 영구메타 2축에 물리적 장소. → 총기 업글(도구함) + 캐릭터 성장(운영자). 사후처리부 지부 톤. 이름=Story 의뢰.
  • B3 · 드래프트의 서사 프레이밍 (천사 축복) — 픽=스탯+세계관 사건. → 본사 지급/긴급 보급/현장 즉흥으로 프레이밍. 우리 천사 대응물=본사/지부.
  • B4 · 보스 = 일관 모티프 (영혼 판 인간) — 외형은 달라도 한 서사축으로 묶어 파편화 방지. → 보스별 파벌="각 보스=한 종의 변종 생태"로 묶음.
  • B5 · 경쾌 지향 핵슬 템포 — 무겁지 않게 튜닝한 타격감. → 사격 연사·처치 피드백의 경쾌함. ⚠ 15m 부감=히트스탑 구조적 기각, 방향만 참고.

시각 분석과 시스템 정합이 독립적으로 같은 결론에 도달한 항목. 가장 신뢰도 높은 "반드시".

4. 가져오지 말 것 (그들의 실패 = 우리 가드레일)

⚠ 화려함은 타격감이 아니다 — 그리고 보스 카메라 전환 금지

① 이펙트 과잉 (Codex + 시연 기자 합치): ss1처럼 백색 파편·적·UI·플레이어가 한곳에 겹치면 조준형에서는 커서·탄도·위험영역이 묻힌다. "멋진 폭발"보다 "내가 어디를 조준했고, 무엇을 맞혔고, 어디로 피해야 하는지"가 항상 먼저 읽혀야 한다.

② 보스 패턴 중 카메라 전환 (에이전트 명시 회수): 시연 기자가 "순간적 혼란"으로 지목. 카메라=정보 채널인데 멋 부리다 정보를 끊음. 우리 부감 카메라는 상시 클린 유지 — 보스에서 패턴/전조 깊이만 가져오고 카메라 연출은 버린다. ([[juice_textbook_lessons]] "카메라 거리가 채널을 결정"과 정면 충돌 → 재제안 금지급)

5. 유저 판정 대기 (🟡 코어 결정)

Q1. 전조→회피→반격 창(교집합 #1)을 우리 조준 뱀서에 진짜 얹나? — 깊이를 더하지만 이동+조준+회피 손가락 과부하 위험. 핵심 동사 추가 = 코어 결정.
Q2. 사격 리듬 입력(B1) 채택 여부 — 손맛 vs 손가락 과부하 트레이드오프.
Q3. 거점 허브(B2)를 영구메타 공간으로 확정하나? (이름은 Story 렉시콘 경유 전제)

6. 왜 그렇게 했나 — 설계 의도 역설계 (Codex × 오케스트레이터)

핵심 재정의 (Codex): 엠버앤블레이드는 액션게임처럼 보이지만, 전투 화면 설계의 진짜 우선순위는 "검술 몰입"이 아니라 "고밀도 위험 해석"이다. 근접검인데도 3인칭을 버린 이유가 그것. 우리 총기 뱀서도 정확히 같은 축에 있다 — 그래서 카메라·색·전조·UI 원리는 거의 다 가져온다. (④의 방사형 버스트는 기본기가 아니라 광역 슬램 스킬로 정정됨 — 기본 사격만 방향성 유지하면 됨.)

① 전투 카메라 — 왜 무쌍액션인데 3인칭을 버리고 부감 쿼터뷰?성립

문제: 캐릭터·포위 밀도·접근 방향·장판·탄막·쿨·보스 패턴을 한 화면에.
그들의 선택: 높은 부감 쿼터뷰 + 약한 틸트(완전 탑다운 아님). 캐릭터보다 전장 구조·위험 분포를 우선.
대가: 검술 육체감·1:1 긴장 약화 → 대신 광역 판단·반복 피로 감소.
내 판단: 성립. 단 우리 핵심동사=조준이라 완전 탑다운이면 총구·조준선 감각이 죽는다. 이미 우리가 푼 답 — 이원 카메라(평시 리드/우클릭 주시)+조준선 스택([[attention_channels_weapon_identity]])이 Codex가 말한 "캐릭터 실루엣 보강"이다. 교훈=지금 높이(15m)·틸트에서 더 올리거나 평평하게 하지 말 것.

② 위험 전조를 왜 '지면'에? (적 몸·공중 아니라)강하게 성립

문제: 부감에선 적 몸·이펙트·숫자·군중이 겹쳐 → 위험이 적 몸/공중에 붙으면 묻힌다.
그들의 선택: 빔·폭발·패턴 전조를 지면에 직접. 부감에선 지면이 곧 전술 UI. "저 적이 뭘 한다"보다 "어느 칸이 죽는 공간인가"를 먼저 읽힘.
내 판단: 우리에겐 더 강하게 성립. 조준·이동·회피가 분리돼 있으니 위험은 "적"이 아니라 "내 이동 경로"에 붙어야 한다. 고정보스는 보스 몸보다 바닥 패턴이 핵심. 우리 후방위협힌트(아크+발자국)·정보레이어 분리와 같은 계열.

③ 색 언어 — 왜 빨강=위험 / 청록=환경을 강제?성립 (우리는 더 엄격)

문제: 이펙트 많으면 "장식인가 위험인가" 매번 판단 → 피로 폭증.
그들의 선택: 색을 의미 체계로 고정 → 반응 시간을 줄이는 규칙(미술 취향 아님). 청록 배경이 아무리 강해도 빨강 빔이 즉시 위험으로.
내 판단 + 실행안(Codex 제안): 총기 게임은 더 엄격해야. 위험=빨강/주황 · 내 탄=노랑/백색 · 보상/상호작용=청록·초록 · 배경=저채도. 아군 탄과 적 위험색이 섞이면 조준형은 즉사. ⚠️ 일찍 동결할 것 — 색 의미를 나중에 갈아끼우는 건 비싸다. 경쟁작 리서치의 "적 발광 색코딩"도 이 팔레트와 충돌 안 나게 재정합 필요.

④ ss1 방사형 백색 버스트 — 광역기(쾅 슬램) 한 발의 연출정정: 스킬 이펙트

정정(2026-06-16, 유저 확인): 이건 그들의 기본 공격/시그니처 실루엣이 아니라 특정 광역 슬램 스킬("쾅 내려찍기")의 이펙트다. → "방향성으로 뒤집어라"는 과한 판정이었음.
그들의 크래프트: 중심→바깥 방사형 백색 버스트. 화려함은 흰색 밝기 피크로, 가독성은 얇고 긴 스트로크 + 빈 공간 + 짧은 버스트로. 화면을 흰 덩어리로 안 덮음. 대단히 잘 만듦.
내 판단(정정): 광역 슬램은 원래 방사형이 정답 — 조준 동사와 충돌이 아니라 별개의 도구다. 우리도 폭탄·충격파·슬램 같은 광역기는 똑같이 방사형으로 써도 된다. 좁혀진 진짜 교훈: ① 기본 공격(주 사격)은 방향성 유지(조준 보존) ② 방사형은 "의도적 광역기"일 때만. 그리고 이 스킬의 크래프트(흰 피크=화려 / 얇은 스트로크+빈공간+짧은 버스트=가독)는 우리 광역기에 그대로 훔쳐온다. 단 §4 경고(플레이어가 묻힘)는 슬램 순간엔 일부 용인되나, 우리 부감+조준에선 내 캐릭터·조준선은 끝까지 안 묻히게.

⑤ UI 배치 — 왜 타이머 상단/HP·XP 좌하/보스바 상단중앙?대체로 성립

논리: 타이머=진행정보(구석) · HP/XP=반복확인하되 전투공간 침범 금지(좌하) · 보스바=목표 그 자체(상단 크게).
내 판단: 보스게이지 상단중앙·HP/XP 좌하 그대로 채택. 단 한 가지 적응 — 조준형은 커서가 화면 전역을 이동하니 탄약·스킬 쿨 같은 즉시 조작 정보는 구석이면 늦다 → 캐릭터 주변 미니게이지 or 커서 근처 보조 피드백. (우리 "커서가 곧 눈" 원칙과 일치)

⑥ 거점은 왜 전투와 정반대로 낮고 가까운 3인칭으로?조건부 — 나는 보류 권고

그들의 선택: 거점/컷씬에서 낮은 3인칭으로 전환. 카메라 전환 자체가 "모드 전환 신호" — 반사신경→관찰·정비·서사.
대가: 카메라·입력 시스템 두 벌 + 에셋 근접 품질 요구↑ = 제작비 상승.
내 판단 (Codex와 갈림): 원리는 채택, 별도 3인칭 리그 구축은 지금 보류. 우리 P1 사후처리부는 장르정합(플레이어 상대좌표·디테일맵 금지·벡터이동 — [[vampire_survivors_pivot]])이라 풀 3인칭 시네마틱은 현 스코프 과욕. 대신 "카메라 전환=모드 전환 신호"는 부감 안에서도 싸게 지킬 수 있다(정비/드래프트 때 줌인·프레이밍 변화). 비용 대비 목적이 분명해질 때 3인칭 승격.

한 줄 결론

엠버앤블레이드의 모든 화면 선택은 "고밀도 위험 해석"이라는 하나의 문제를 푼다 — 카메라·지면 전조·색 규칙·UI 위치 전부. 우리도 같은 문제를 풀지만 핵심동사가 "조준"이라 — 그들의 해법(원리)은 거의 다 그대로 가져온다. 단 하나의 규율: 기본 사격은 방향성을 유지하고, 방사형은 의도적 광역기일 때만(④). 표면이 아니라 원리를 베끼면 우리 게임이 강해진다.
