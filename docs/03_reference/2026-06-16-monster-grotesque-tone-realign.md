# 톤 재정합 제안 — 적 정체성 "해괴망측한 괴물" + "황혼의 적막" 폐기

> **작성일**: 2026-06-16 · **상태**: 🟡 **제안 (유저 판정 대기)** — 동결 권한 없음
> **목적**: 두 방향 전환(①"황혼의 적막" 톤 폐기 ②적 정체성 나노좀비→해괴망측한 괴물)을 기존 캐넌과 재정합. **맵 "서사 흩뿌림 레이어" 설계용 톤 가이드** (공간 설계는 LevelDesign 병렬).
> **선행 권위**: `00_authority/2026-06-11-story-core-lexicon.md`(제1~3조·기원·메모리·§7 정합표) · `03_reference/2026-06-06-worldbuilding-pitch.md`(흑막·캐릭터) · `00_authority/2026-06-10-design-compass.md`(적 명사)

## 0. 한 줄 결론 (먼저)

**"나노좀비→해괴망측한 괴물"은 기원의 폐기가 아니라 *변환 결과물(외형)의 격상*으로 받으면 캐넌이 거의 다 산다.** 나노봇은 메모리·싱크게이지·본사 제어채널·§7 정합표 전체를 떠받치는 기둥이라 못 뺀다. 버릴 건 "좀비스러운(부패 시체) 외형 기대" 하나. **"황혼의 적막" 폐기는 별개 사안이고 서사 충돌 0** — 톤 단어만 교체하면 된다.

---

## 1. 충돌 감사 — 무엇이 깨지고 무엇이 사는가

### 1.1 적이 "괴물"이 되면 흔들리는 기둥부터 (위험 순)

| 캐넌 자산 | 나노 의존도 | 판정 |
|---|---|---|
| **strain = 메모리(나노 잔해)** — 화폐·크래프팅 재료 (렉시콘 §5.4) | 절대 의존 | **사수.** 나노봇이 빠지면 메모리의 정체("나노 군체가 숙주를 기록·결정화")가 통째로 증발. 폭로(정산서 4번)도 같이 무너짐 |
| **싱크 게이지 = 본사 제어채널** (렉시콘 §3, §7) | 절대 의존 | **사수.** 주인공 나노봇 = 본사가 재난을 일으키는 손. "동기화" 복선 전체가 여기 걸림 |
| **§7 메커닉 정합표 8행** (재난 발주·증거 인멸의 외주화) | 절대 의존 | **사수.** 나노가 빠지면 "본사가 어떻게 재난을 일으키나"의 기전이 사라짐 |
| **§2.1 기원 타임라인 5단계(통제기=나노봇 의도적 발생)** | 절대 의존 | **사수** |
| **신체 파츠 팝 = 나노봇 와해** (design-compass 코어, 2회 강조) | 강 의존 | **사수.** 디스폰 픽션이 나노 와해. 괴물이어도 그대로 작동 |

→ **나노봇은 "외형 설정"이 아니라 "세계 작동 기전"이다.** 적 외형을 좀비에서 괴물로 바꿔도 *기전은 건드릴 이유가 없다.* 따라서 이 5개는 전부 산다.

### 1.2 깨지는 것 (버릴 것)

| 자산 | 깨지는 이유 | 처리 |
|---|---|---|
| **"좀비"라는 임시 외형 기대** | 부패 시체·물어뜯기·전염 = 장르 관습. 이형/바디호러로 가면 충돌 | **버림.** 단 렉시콘은 이미 "좀비=임시어휘, 이상개체가 정식"(design-compass §72)이라 *공식 명사는 손 안 댐* — 깨지는 건 머릿속 이미지뿐 |
| **"황혼의 적막" 톤 단어** | 유저 지시로 폐기 | **버림.** §3에서 대체 톤 제안 |
| 부패/감염 계열 입말 어휘(있다면) | 이형 세계엔 안 맞음 | 입말 풀에서 제외 — 단 렉시콘 §5엔 부패 어휘 등재된 거 없음(이미 "이상개체·고위험군" 행정어) → **실질 피해 0** |

### 1.3 재해석되는 것 (의미가 더 강해지는 것)

| 자산 | 재해석 | 효과 |
|---|---|---|
| **9종 몬스터 알리바이** (stage1-monster-diegetic 메모리) | 이미 라틴학명+"사람이 이형으로 소거"로 짜여 있었음. 직립→사족→이형 변이진행도 축, 유생→성체 = 인간 소거 진행 | **충돌 0 — 오히려 정방향.** "괴물 격상"이 이 작업의 *전제였다.* 이형이 강해질수록 "변이진행도=인간성 잔존도" 행간이 선명해짐 |
| **제3조 완곡어법** ("사람이었다"고 안 말함) | 괴물이 해괴망측할수록 ↔ 서류는 더 차갑게 "이상개체"라 부름 = 낙차 증폭 | **강화.** 형태가 그로테스크할수록 서류의 무심함이 더 무서워짐 |
| **메모리 = 숙주를 기록하며 변환** (§5.4) | "변환"이 곧 이형화. 나노가 사람을 *어떤* 괴물로 만드는가 = 바디호러의 기전 자체 | **강화.** 괴물 외형 = 나노 변환 과정의 가시화 |
| **싱크 100% = 죽음**(미결 §8-1) | 주인공도 같은 나노 변환의 끝 = 이형화. "내가 처리하던 게 내 종착지" | 미결이지만 **이형 전환이 답을 더 선명하게 함** (여전히 유저 판정) |

> **감사 결론: 충돌이라 부를 만한 진짜 충돌은 없다.** "좀비→괴물"은 나노봇 위에 얹힌 *결과물 레이어*의 교체일 뿐, 기전(나노)은 불변. 오히려 이미 진행 중이던 몬스터 디제틱 작업과 정렬된다.

## 2. 단 하나의 진짜 분기점 (유저가 골라야 할 것)

충돌은 없지만, **"괴물의 기원을 나노봇 단독으로 둘 거냐"**는 갈린다. 적이 해괴망측할수록 "왜 이렇게까지 이형인가?"라는 질문이 생기고, 이건 §2.1 미결("예측하지 못한 사건의 정체")·§8-1(싱크 100%)과 직결된다. 아래 §3은 그 기원 톤 후보다.

## 3. 재해석 제안 — 괴물의 기원·세계 톤 후보 (2~3개, 판정용)

> 공통 제약: **나노봇 기전은 셋 다 유지**(못 뺌). 다른 건 "나노가 *왜* 이렇게 해괴한 형태를 만드나"의 작가용 내부 논리 + 그에 따른 세계 무드뿐. 셋 다 무변론 룰·게임 내 미설명 원칙 준수.

### 후보 A — "오류로서의 이형" (나노봇 폭주, 본사도 의도 안 함) ★추천

- **기전**: 본사 나노봇의 변환은 원래 "관리 가능한 처리 단위"를 만드는 것. 그런데 변환은 *완벽히 통제되지 않는다* — 나노 군체가 숙주 조직을 재구성할 때 형태가 폭주한다. 본사조차 결과 형태는 예측 못 함. 해괴망측 = **통제 강박(§2.2)의 단 하나의 균열**.
- **세계 톤**: 행정은 이 폭주를 *없는 셈* 친다. 서류는 끝까지 "이상개체"라 부르고 형태 다양성을 등급코드로만 분류(고위험군 등). **공포 = 시스템이 자기 손에서 벗어난 것을 양식으로 덮는 것.**
- **레퍼런스 추적**:
  - *The Sculptor / Tetsuo: 살(肉)의 폭주* 계열 — 기계/유기물 융합이 통제를 벗어나 증식.
  - *SCP / Control(Remedy)* — 관료제가 "이상(異常)"을 분류·봉인하지만 이해는 못 함. 행정 어휘 ↔ 설명 불가능한 형태의 낙차가 우리 제3조와 동형.
  - *Annihilation(서던 리치)* — 변형의 원인이 끝내 설명되지 않음(무변론과 정합).
- **캐넌 정합**: §2.2 "단 한 번의 예측 실패"(단절점) 떡밥과 **공명** — 본사가 통제 못 하는 단 하나가 형태 폭주라면, 미결 §2.1("예측하지 못한 사건")의 후보가 됨. **가장 적은 신규 설정으로 가장 큰 떡밥 회수.**
- **비용**: 신규 캐넌 0. 기존 미결을 *채우는* 방향.

### 후보 B — "설계로서의 이형" (본사가 의도한 형태)

- **기전**: 본사는 형태까지 의도한다. 직종·작업환경 데이터를 기반으로 사람을 그에 맞는 이형으로 변환(stage1 메모리의 "직종 알리바이"를 기전화 — 방역소독반→산성 분사형, 건설조→중장비형). 가장 효율적인 "처리 단위" 형태를 산출.
- **세계 톤**: 차가운 합목적성. 괴물조차 KPI에 맞춰 설계됨. **공포 = 이 해괴함에 *이유가 있다*는 것.**
- **레퍼런스 추적**: *Scorn* (생체기계 합목적 그로테스크), *Dead Space*(네크로모프=시체의 "재활용"). 단 둘 다 *연출 전면화*라 우리 무변론·미설명 톤과 마찰.
- **캐넌 정합 ⚠️**: stage1 메모리 §"변이 알리바이=미설명" 원칙과 **부분 충돌** — "직종이 형태를 정한다"를 기전으로 확정하면 행간이 도식이 되어 신파/설명 위험. 형태에 이유를 *부여*하는 순간 제3조의 "스스로 읽어내게" 가 약해짐.
- **비용**: 중. "의도된 형태"는 본사를 *너무 전능하게* 만들어 §2.2 균열(예측 실패) 떡밥과 긴장.

### 후보 C — "혼종" (의도된 변환 + 폭주한 형태) — A의 안전 변형

- **기전**: 변환(이형화)은 의도, 구체적 형태는 폭주(A). "사람을 처리 단위로 바꾼다"까지가 본사 의도, "어떤 괴물이 되는가"는 통제 밖.
- **장점**: B의 합목적성 떡밥(직종↔형태 라임은 *입말 농담*으로만 살림, 기전 확정 안 함)과 A의 미설명 공포를 둘 다 가짐. stage1 메모리가 이미 "직종 잔흔은 입말에서만, 공문은 직종 금지"라 **이 분리와 정확히 일치**.
- **추천도**: A 다음. 사실상 A에 "입말 농담 여지"를 명시한 버전.

> **추천: A(또는 C)**. 이유 — ①신규 캐넌 0, 기존 미결(§2.1 예측 실패)을 채움 ②무변론·제3조와 정합 ③stage1 몬스터 작업과 충돌 0. B는 떡밥 손해(본사 전능화)·제3조 약화 위험.

## 4. "황혼의 적막" 폐기 — 대체 톤 (서사 관점)

> 이건 서사 충돌 0 사안 — 톤 *단어*의 교체일 뿐. 그래픽 무드 최종 콜은 유저/오케스트레이터, 여기선 **서사가 흩뿌림 레이어에 깔 정서**만 제안.

- **폐기**: "황혼의 적막" (고요·정적·빈 거리의 쓸쓸함) — 이형 바디호러와 톤 마찰.
- **대체 톤 제안 — "처리되지 않은 흔적" (행정 디스토피아 × 바디호러)**:
  - 한 줄: *깨끗이 치워진 도시 ↔ 미처 못 치운 살덩이.* 행정이 닿은 곳은 멀끔하고(통제선·소독 완료 스티커), 안 닿은 곳은 그로테스크하게 증식 중. **두 질감의 경계가 곧 맵 읽기.**
  - 정서: 적막(빈 것)이 아니라 **부조화**(멀쩡한 행정 표지 + 그 옆 이형 증식). 제3조의 시각 버전.
  - 이중 레지스터 그대로 이식: 차가운 행정 표면(공문 톤) × 살덩이의 유기적 끔찍함(괴물) = 같은 낙차 엔진.

## 5. ★맵 서사 흩뿌림 프롭 카탈로그 (핵심 산출물)

> 용도: 맵에 묻어 이 세계를 "한눈에" 읽히게 하는 환경 프롭 후보. **각 프롭 = 한 줄 이야기.** 두 진영(괴물 흔적 / 인간측 흔적) + 두 진영이 충돌하는 경계 프롭. 공간 배치는 LevelDesign 몫 — 여기선 *무엇이 무슨 이야기를 하는가*만.
>
> 제약: ①텍스트 라벨이 붙는 프롭은 전부 렉시콘 §5 경유(공문 어휘) ②제3조 — 프롭도 "사람이었다"고 말하지 않음, 행간으로 ③신파 금지 — 사연 아니라 구조.

### 5.1 괴물 흔적 (이형의 잠식 — "행정이 못 치운 곳")

| 프롭 | 말하는 이야기 | 톤 노트 |
|---|---|---|
| **살덩이 증식 (벽·기둥을 타고 오른 유기 조직)** | 나노 변환은 개체에서 끝나지 않고 구조물로 번진다 — 도시가 천천히 숙주가 되는 중 | 후보 A의 "형태 폭주" 가시화. 깨끗한 벽일수록 대비 강함 |
| **결정화 잔해 더미 (메모리가 안 회수된 곳)** | 처리는 됐는데 회수가 안 됨 = 하청이 못 미친 구역 = 증거가 굴러다님 | 메모리(§5.4)의 환경 버전. 줍는 메모리와 같은 비주얼 |
| **둥지/번데기 (변환 진행 중인 고치)** | 사람이 괴물이 *되는 중* — 유생→성체 변이(stage1 메모리)의 정적 버전 | ⚠️제3조: 고치에 인간 실루엣 *암시만*, 명시 금지. 행간 |
| **분비물·산성 부식 자국 (Venodonte 등 분사형 흔적)** | 어떤 개체가 지나갔는지 = 위협 종류 예고(게임플레이 정보 겸) | 9종 알리바이와 1:1 — 종별 흔적이 다름 |
| **융합된 사물 (괴물 몸에 박힌 작업도구·간판)** | 직종 잔흔 — 한때 무엇이었는지가 형태에 박제됨(입말 농담의 환경 버전) | 후보 C 정합. 공문은 침묵, 프롭이 행간 |
| **꿈틀거리는 바닥 균열 (지하로 번진 군체)** | 잠식은 보이는 것보다 깊다 — 맵 아래가 살아 있음 | 정적이되 미세 애니(맥동). 적막 폐기의 대체 정서=부조화 |

### 5.2 인간측 흔적 (피난 실패 · 격리 · 방역 — "행정이 닿은 곳")

| 프롭 | 말하는 이야기 | 톤 노트 |
|---|---|---|
| **통제선/방역선 테이프 (찢긴 채)** | 행정이 그어놓고 지키지 못한 경계 — 시스템의 한계 | 렉시콘 §5 "방역선/통제선" 기등재. 찢김 = 무용했다는 행간 |
| **소독 완료 스티커 (살덩이 증식 *위에* 붙은)** | 가장 무서운 한 줄 — "처리됨"이라 도장 찍힌 곳이 다시 잠식됨 = 행정의 거짓/무능 | ★경계 프롭(5.3과 겹침). 제3조 정수 |
| **피난 안내 현수막 ("○구역 집결지" — 아무도 없는)** | 대피는 시도됐고 실패했다 — 사람이 있었다는 부재 증명 | 신파 금지: 시신 금지, *빈* 집결지로만 |
| **버려진 민원/보험 서류 더미** | 평범한 일상이 중단된 지점 — 흑막("관리 단위") 떡밥 환경화 | 보험·민원 = 흑막 어휘. 바람에 날리는 종이 |
| **소독 드론 잔해 (추락한)** | 본사 보급/감시 채널의 물리적 존재 — §7 정합표·Carcinoptera 소급 떡밥 | 우리 메모리 보급 드론과 같은 실루엣(오인 떡밥 강화) |
| **방호복 한 벌 (주인 없는, 사번 붙은)** | 이전 현장직의 부재 — 키비주얼3("사번이 당신의 전부") 회수 | ⚠️시신 금지, *빈* 방호복. 사번만 클로즈업 가능한 배치 |
| **'특이사항 없음' 보고 게시판 (현장과 모순되는)** | 게임 제목의 환경화 — 눈앞이 아수라장인데 서류는 평온 | 제목·제3조의 시각적 펀치라인. 입말 무전과 낙차 |

### 5.3 경계 프롭 (두 진영이 충돌 = 대체 톤 "부조화"의 핵심)

| 프롭 | 말하는 이야기 |
|---|---|
| **소독 스티커 ↔ 그 아래 증식** (5.2 재게) | 행정의 표면 ↔ 통제 밖 실체. 후보 A 기원의 1프롭 요약 |
| **멀끔한 통제선 안쪽 / 바깥쪽 살덩이** | 맵 가독성 = 톤. "닿은 곳/안 닿은 곳" 경계가 곧 안전/위험 |
| **본사 안내 키오스크 (정상 작동) + 주변 잠식** | 무변론 룰의 환경 버전 — 시스템은 끝까지 멀쩡한 척 안내 멘트를 재생 |

> **흩뿌림 원칙 3줄 (LevelDesign 인계용):** ①대비로 읽힌다 — 깨끗한 행정 표지는 살덩이 *옆*에 둘 때 가장 무섭다 ②밀도가 변이진행도를 따라간다 — 발원/중심부로 갈수록 괴물 흔적↑·인간 흔적↓(소거의 공간화) ③라벨 붙은 프롭은 전부 §5 어휘, "사람" 단어 0.
