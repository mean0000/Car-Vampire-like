3. 서스테인 오프셋 0.05m 체감 — 유지/증감/삭제
4. 대시 슬로모(유일 전역 예외)가 위협 테제와 충돌하는지

## 4. 충돌 가드

- ZombieController 쪽 연출(스프링·개체 히트스탑)은 **세션 3 좀비 위협 본체와 같은 개체를 만진다** — 커밋 후 세션 3과 순간 소유권 재확인 필요(특히 좀비 피격 리액션 vs 세션 3의 어그로 연출).
- 카메라 킥은 **세션 1의 카메라 재심사(4축)와 같은 리그를 만진다** — 킥 구현은 세션 1의 리그 결론 이후가 안전. 그 전엔 킥 예약 순간의 *이벤트 발화*만 깔아두는 것까지.
