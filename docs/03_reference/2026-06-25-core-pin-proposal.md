## 0. TL;DR (평결)

1. **진짜 충돌은 메커니즘이 아니라 *감정 목표*다.** 새 북극성(Prototype 역량 파워판타지)과 06-24(dread 공포)는 *타이밍 메커니즘 유무로* 싸우는 게 아니다 — **"능력이 주인공이냐(파워판타지) vs 능력이 적이냐(공포)"** 로 싸운다. 유저가 판정할 1번 질문은 이 톤 갈림길이다.
2. **핀 후보 = 오케 "선을 고른다"와 강하게 수렴.** gd가 레퍼 실측 후 변형해 보강한다 → **「관통선 처형」**(아래 §2). 발산점은 한 곳: "선을 *어떻게 입력*하나"(조준 비용).
3. **읽고-베기(06-24)는 제거 아님 → 관대화 + 톤 재배선하면 핀의 *엔진*으로 생존.** 메커니즘(커밋한 적에 입력 맞추면 시스템이 화려하게 응답)은 핀과 양립한다. 부호만 뒤집는다: *실패=피격(공포)* → *성공=보너스(역량)*.
4. **시스템 정합 = 거의 공짜.** 화려함=돈 이코노미가 관전자 함정의 해법(DMC ×0.8 패턴)을 이미 절반 갖고 있다.

## 1. 문제 재정의 — 핀이 뭘 풀어야 하나

헌트: 러프 빌드가 *균일하게 밋밋*(좋은 순간 0). 핀 = **2초마다 반복 · 오직 이 게임만 · 단순 입력 → 과장된 호쾌함 · 크레딧은 플레이어.**

칼날(가장 중요): 너무 자동이면 "게임이 멋지다"(관전자). **가장 단순한 입력에 *의미 있는 순간 결정*을 얼마나 얹느냐가 성패.**

레퍼 실측이 이 칼날의 정답을 줬다 — 아래 §1.1.

### 1.1 관전자 함정의 해답 (레퍼 실측 — 전부 같은 패턴)

| 게임 | 관점 | 자동(시스템이 주는 화려함) | 플레이어 결정(크레딧의 원천) |
|---|---|---|---|
| **DMC5 Auto-Assist** | 3인칭 | 한 버튼→컨텍스트 화려 콤보 | 수동 플레이가 **×1.25 점수**(자동은 ×0.8). 결정에 *점수*를 더 준다 |
| **Hi-Fi Rush** | 사이드 | 공격이 자동으로 비트에 싱크 | 타이밍 맞추면 **데미지↑+피니셔 추가뎀**. 못 맞춰도 진행(관대) |
| **Warframe Slash Dash** | 3D | 사거리 내 적 **자동 연쇄 절단**+모멘텀 | 방향·위치 결정만 입력. "어디로 그을지"가 나 |
| **Hades II** | 탑다운 | Boon 스택의 자동 폭발 | *어떤* Boon을 골랐나(빌드 결정) |
| **Go Mecha Ball** | 아이소 | — | 적 차징 중 치면 캔슬+탄약 드롭(공격적 플레이=보너스) |

→ **공통 비결**: 게임의 화려함 ≠ 내 화려함이 아니라, **내 결정이 화려함의 *형태/크기*를 정한다.** 순수 자동(결정 없음)만 관객을 만든다.

### 1.2 ★진부함 경계 (유저 우려 직답 — Explore 12게임 실측)

탑다운/아이소 로그라이트의 "잘해 보임"은 **거의 다 *사전 빌드 결정*에 산다**(Hades II Boon·Brotato 6무기·Balatro Joker·Mewgenics 번식). *런타임 액션 입력*으로 푼 건 Megabonk·Windblown뿐인데 **둘 다 3D/이동 기반**.

> **결론: 탑다운 단일 평면에서 "런타임 단일 입력의 *공간 결정*"으로 파워판타지를 준 사례는 거의 비어 있다 = 우리 핀의 해자.**
> "대시-슬래시"는 한 문장으론 흔하다. 신선함은 피치가 아니라 **실행**(탑다운 + 군중 밀도 + 화려함=돈 연동 + 커밋 타이밍)에 산다 — 06-24 메모 교훈과 정합.

## 2. 핀 후보

### 핀 A (주력 · 오케와 수렴) — 「관통선 처형(貫通線 處刑)」

> **단순 입력 = 군중 사이로 *한 줄을 긋는다*(조준+발동). 시스템 응답 = 카타나가 그 선 위의 모든 커밋한 적을 한 흐름으로 가른다. 호쾌함 = 걸린 적 수에 비례. 크레딧 = "이 선은 내가 골랐다."**

- **2초 루프**: 호드가 조여옴 → *어느 라인이 제일 굵나*(곁눈 한 번) → 긋는다 → 선 위 적들이 한 번에 갈림(슬로모 방점·전파) → 회수 환급 → 다음 선. = Warframe Slash Dash를 탑다운 군중에 이식.
- **단순 입력 / 깊이 = 공간 판단**: 손가락은 한 동작(긋기). 머리는 *공간 전체 조망에서 최적 선*을 읽음 = 오케 1안 "공간 결정의 파워판타지" 그대로.
- **크레딧이 플레이어에게**: 카타나가 절단을 *완성*하지만, **선은 내가 골랐다.** 같은 호드에서 3마리 선 vs 8마리 선 = 내 판단 차이 = 내 호쾌함의 크기.
- **화려함=시스템**: 절단 VFX·전파 복도·슬로모는 시스템이 준다(애니 디테일 불요 = 탑다운 솔로 제약 정합).

**관전자 함정 방어 (의미 있는 결정 얹기 — 3겹, 노브):**
1. **선 선택 자체** = 매 발동의 결정(어느 표적군). 결정 없는 자동 광역과 다름.
2. **커밋 보너스(06-24 재배선)**: 선 위에 *지금 공격을 커밋한(텔레그래프 중)* 적이 있으면 그 처형이 **증폭**(전파 더 멀리·돈 더·슬로모 더). → "위험한 순간을 골라 그었다"가 더 큰 뽕. *놓쳐도 평타 처형은 됨*(Hi-Fi Rush식 관대).
3. **모멘텀 체인**: 처형 후 회수 환급 → 다음 선이 곧바로 → *호드의 파도를 선으로 서핑*. 멈추지 않는 흐름이 [[reference-sword-action-pong-engines]] "연쇄 가속" 뽕 엔진.

### 핀 B (대안 · "조준 비용"이 부담일 때) — 「쇄도 처형(Dash-Execute)」

선을 *조준해서 긋는 게 아니라*, **대시 방향 = 선**. (Warframe·Katana Zero Dragon 원형 그대로.)

- 입력 = 대시(이미 있는 입력) 한 번. 대시 경로 위 적 자동 절단+관통. 조준 레이어 0.
- 장점: 입력이 더 단순(기존 대시 재활용), 트윈스틱 조준 부담 없음. 06-21 "대시 캔슬 리듬"과 직접 연결.
- 단점: 선 *선택*의 결정 여지가 A보다 얕음(대시는 회피 겸용이라 "최적 선"보다 "안전 선"으로 끌림) → 관전자 함정에 A보다 약간 취약. 커밋 보너스(2겹)로 보강 필요.

**A vs B = 유저 판정**: A = 결정 깊이↑·조준 입력 추가 / B = 입력 단순·결정 얕음. **gd 권고 = A를 주력**(핀의 핵심 가치가 "공간 결정"이라 결정 여지를 죽이면 안 됨), B는 조준이 탑다운서 안 읽히면 폴백.

### 2.1 오케 "선을 고른다"와 수렴/발산

- **수렴 (강함)**: 핀 A = 오케 1안의 직접 정련. "실행이 아니라 공간 결정의 파워판타지" 명제를 레퍼(Slash Dash)로 기계 검증 + 군중 비례·커밋 보너스·모멘텀 체인으로 뽕 엔진 부착.
- **발산 (한 곳)**: **선을 *어떻게 입력*하나.** 오케 1안은 "선을 고른다"까지만; gd는 두 입력 모델(A=조준 긋기 / B=대시 방향)로 쪼개 *조준 비용*을 판정 포인트로 노출. 이게 칼날(결정 깊이 vs 입력 단순)의 다이얼.

## 3. 읽고-베기(06-24) 거취 판정

> **판정 = 🟢 유지(메커니즘) + 🟡 관대화(부호 전환) + 🟡 톤 재배선(공포→역량). 제거 ❌.**

브리프는 06-24를 "고난도 타이밍 실행 = 버려진 무거운 방향, 피벗과 정반대"로 봤다. **로그 본문을 읽으면 절반만 맞다:**

| 06-24 요소 | 핀과의 관계 | 판정 |
|---|---|---|
| "화려함은 플레이어 실행❌, *시스템이 응답으로* 줌"(§3) | 핀 브리프 "단순입력→과장된 호쾌함"과 **동일** | 🟢 유지 — 핀의 토대 |
| "세짐 = 크리티컬 묶음↑이지 안전❌"(§3) | 화려함=돈 이코노미와 동형. "강해질수록 더 화려하게 가른다" | 🟢 유지 — 성장 철학으로 |
| 커밋한 적에 타이밍 맞추면 크리티컬+전파 | 핀 A 2겹 "커밋 보너스"로 흡수 | 🟢 유지(흡수) |
| **빗나가면 그 공격을 맞음(처벌=dread)** | 파워판타지는 *실패 처벌*이 아니라 *성공 보너스* | 🟡 **관대화** — 부호 전환(놓쳐도 평타 처형, 맞추면 증폭) |
| **dread(공포·"칼날 위 생존") 톤** | 능력=두려움의 적 ↔ 파워판타지=능력이 주인공 | 🟡 **재배선** — 이게 진짜 충돌점 |
| 적 공격 = 동작 내장 텔레그래프 아키타입(§5.6) | 커밋 보너스가 성립하려면 "언제 칠지"가 읽혀야 함 | 🟢 유지 — 핀 A 2겹의 필수 인프라 |

**근거:**
- **메커니즘은 양립한다.** "커밋한 적에 입력을 맞추면 시스템이 화려하게 응답"은 공포로도(빗나가면 죽음) 역량으로도(맞추면 잭팟) 튜닝 가능. Go Mecha Ball이 *공격적 파워판타지* 톤에서 "차징 중 치면 보너스"로 작동하는 실측 선례.
- **칼날과 정합.** 06-24의 "타이밍 결정"은 *관전자 함정의 해법 그 자체*다(결정 없는 자동=관객). 이걸 버리면 핀이 다시 자동화로 미끄러진다. 그러니 *결정은 유지, 처벌은 보너스로, 공포 톤은 강등*.
- **이미 깔린 받침대를 버리지 않음**: `parryWindow`+`ParrySlowMotion`+`maxAttackTokens`+커밋 질의 프로토(06-24 빌드)가 핀 A의 "커밋 보너스" 인프라로 *그대로* 재사용된다. 제거하면 자산 폐기.

> ⚠️ **단, dread 톤 자체의 채택 여부는 gd 권한 밖**(코어 방향 = 오케+유저 직접). gd는 "메커니즘은 핀과 양립하니 *버리지 말고 부호만 뒤집어라*"까지만 권고한다. 공포 vs 역량의 최종 톤은 §5 Q1.

## 4. 시스템 정합 (핀 → 무기/성장/런이코노미)

### 4.1 화려함=돈 이코노미 = 관전자 함정 해법의 절반 (충돌 0, 오히려 보강)

기존 권위(메모리 `project_2026_06_13_growth_economy_direction`): *화려함=돈(노히트·광역·고위협·화려처형 → 처리평가 S~D → 퇴근 정산)*.

- **DMC ×0.8 패턴을 우리는 이미 갖고 있다.** "결정에 점수를 더 준다"의 *점수* = 우리 *돈*. → **선을 길게(많은 적) + 커밋 보너스로 그으면 처리평가↑ = 정산 돈↑.** 핀의 결정이 곧 이코노미 입력. 새 시스템 0.
- **자동 vs 결정 = 돈 격차로 표현**: 막 그어도 처형은 됨(평타 등급) / *최적 선 + 커밋 타이밍*은 S등급 = 돈. → "잘해 보임"이 *지갑으로* 증명됨(크레딧이 플레이어에게).

### 4.2 무기 (카타나 2트리) 정합

- 메모리 `project_card_grammar`·카타나 카탈로그: 카타나 = 거합/참격 2트리, 잎 변형(거합=기동 발도, 참격=검기/블링크).
- **핀 A가 카타나 정체성과 합치**: "한 줄을 그어 가른다" = 거합(발도)·참격(검기 면) 둘 다의 상위 추상. 카드 잎은 *선을 어떻게 터뜨리나*를 분기(선 길이↑ / 전파 폭↑ / 커밋 보너스 배율↑ / 체인 회수↑) = [[feedback-pong-over-systematization]] "극단=더 큰 뽕" 정합.
- **성장 = 선이 더 화려해진다**(06-24 §3 "세짐=묶음↑"): 더 길게 긋고·더 멀리 전파하고·더 빨리 체인. *더 안전*이 아니라 *더 큰 학살선*.

### 4.3 익스트랙션 코어(농성 루프) 정합

- `natural-pull-doctrine` §2.5 스폰 디렉터(동심원 무한 젠, 표효 호드 형성) = **핀 A의 무대**. 호드가 *선을 그을 만큼 뭉쳐야* 핀이 산다 → 디렉터의 "수렴 스폰"이 정확히 그걸 만든다. 충돌 0, 상호 강화.
- **핀이 "자연스러운 끌림"을 강화**: §2.3 "뽕 약속이 미끼" = "저 적 뭉텅이를 한 선에 긋고 싶다"가 곧 코어로 들어가는 욕망. 핀 A가 그 약속의 *지불 수단*.

| natural-pull §2.5 스폰 디렉터 | **정합·강화** | 호드 뭉침이 핀의 무대 |
| 화려함=돈 이코노미 | **정합·강화** | 결정=돈 (DMC 패턴) |
| 카타나 2트리·카드 문법 | **정합** | 선을 터뜨리는 법으로 분기 |
| 단일 전투 평면(natural-pull §3) | **정합** | 선 = 평면 위 라인, 높이 불요 |

→ **유일한 충돌 = §0.1("한 마리 쫄깃") ↔ 파워판타지(다수 학살).** 메커니즘 충돌이 아니라 *감정 목표* 충돌. §5 Q1로 격상.
