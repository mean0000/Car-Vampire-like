## 2. 아키텍처 결정 3건 (구현 전 동결 권고)

### 2.1 AudioListener 분리 — 탑다운 제1 함정
카메라(높이 ~20m·피치 58°)에 리스너가 붙어 있으면 **모든 3D 소리가 20m 밖**에서 나고, 좌우 정위가 카메라 기준으로 뒤틀린다. 소리사다리(반경=정보)가 음향으로 안 읽히는 직접 원인이 됨.
- **해법(표준)**: 전용 GO `AudioListenerRig` — **위치 = 플레이어, 회전 = 카메라 yaw**. LateUpdate 추종 ~15줄.
- 검증: 좀비 그르렁이 화면 좌측이면 왼쪽 스피커에서 나는가.
- ⚠️ [[runloop-pitfalls]] — 전용 GO로 만들 것(기존 GO에 컴포넌트 얹기 금지).

### 2.2 AudioMixer 버스 + 3단 스냅샷 (=B-005a의 뼈)
```
Master
├─ Music          ← 스냅샷 3단의 주 대상
├─ Ambience       (도시 드론 — B-005 잔여)
├─ SFX
│   ├─ Guns      (자기 총성은 살짝 덕킹 대상에서 제외 — 항상 선명)
│   ├─ Impacts   (히트 확인음·헤드팝)
│   ├─ Zombies   (그르렁·윈드업·사망)
│   └─ Foley     (발소리·재장전·근접)
└─ UI
```
- **스냅샷 3단**: `Calm / Alert / Combat`. 전환 입력 = NoiseManager 소음 이벤트 + Chase 상태 좀비 수(0 / Investigate·Alert 존재 / Chase≥1). 전환 시간 Calm→Combat 0.5s, Combat→Calm 4~6s(여운 — 전투 끝의 "한숨" 비트와 정합).
- Combat 스냅샷은 Music 볼륨만 올리는 게 아니라 **Ambience를 −6dB 덕킹** — "세상이 좁아지는" 집중 연출의 음향판.
- 음악 소스: USFX는 SFX 라이브러리라 음악 없음. Phase 1은 **드론 루프(USFX Loop 카테고리) + 펄스 레이어**로 3단을 검증하고, 진짜 음악은 별도 트랙(추후).

### 2.3 원샷 풀 + 클램프 (전투질감 §6.2 사운드 적용)
- `PlayClipAtPoint` 전면 대체: 풀링된 3D AudioSource 원샷 헬퍼 1개(`SfxOneShot.Play(clip, pos, bus)`).
- **동시 발성 한도**: 같은 클립군 동시 3개, 초과분 드롭(좀비 호드 그르렁 폭주 방지).
- **킬 사운드 클램프**: 0.15s 창 1회, 초과 병합 — 카메라 킥 클램프와 같은 창 공유.
- 피치 랜덤 ±4~6% 전 원샷 기본 적용(기계적 반복 제거 — 공짜 다양성).

## 3. 소리 설계 — 무기 3계열 촉각 언어와 정합

> 메모리 [[attention-channels-weapon-identity]]: 충격 유무=무기 계열의 촉각 언어. 카메라가 안 흔들리는 무기는 **소리가 그 빈자리를 채운다(B-004의 핵심 가설)**.

### 3.1 발사음 구조 = 크랙 + 바디 + 테일
| 계열 | 크랙(고역) | 바디 | 저역 테일 | 캐릭터 |
|---|---|---|---|---|
| 리볼버 | 날카로움 최대 | 두꺼움 | **길게**(0.4s+, 골목 반향) | "한 발의 무게" — 카메라 킥과 한 몸 |
| 라이플(연사) | 중간 | 가벼움 | **짧게**(테일이 길면 연사 시 진흙됨) | 리듬이 정체성 — §3.2 |
| 샷건 | 폭발적 | 최대 | 중간+펌프 폴리 | 충격 언어 최상단 |

- **저역 테일은 별도 레이어**로 분리(크랙 클립+테일 클립 2발성) — 실내/골목에서 테일만 키우는 공간 연출 여지, B-005 "저역 테일" 항목의 구현형.
- **마지막 2~3발 차별화**(§6.3 확정): 잔량 ≤2 시 발사음에 금속성 클릭 레이어 추가 — 디제시스 잔량 정보.

### 3.2 B-004 연사 리듬 — "사운드가 카메라 충격 0을 채운다"
- 연사는 매발 동일 클립 금지: **발사음 3~4종 라운드로빈 + 피치 ±5%**.
- 3~4발마다 1발 크랙 강세(악센트) — 기관총의 "드르륵" 리듬감은 균일함이 아니라 미세 변주에서 옴.
- 머즐 플래시 리듬(`GunFlashLight`)과 사운드 악센트 **동기** — 시각·청각이 같은 박자를 치면 체감 충격이 합산됨.
- 검증 질문(게이트): "카메라가 고요한데도 연사가 심심하지 않은가."

### 3.3 히트 확인음 — 3계층 탄 판정의 청각판
| 판정 | 소리 | 비고 |
|---|---|---|
| 풀히트 | 젖은 임팩트(두꺼움) | 발사음보다 한 옥타브 아래 질감 — 총성과 분리돼 들려야 "맞았다"가 별도 정보가 됨 |
| 스침 | 얇은 챙/휙 | 데미지 50%가 소리로도 절반 |
| 그레이즈 | 거의 무음(공기) | |
| **헤드팝(보장 원샷)** | 전용 1발 — 둔탁 파열+짧은 무음 갭 | B-009 의식의 보상음. 절대 다른 데 재사용 금지(희소성=학습) |

### 3.4 좀비 — 인식 모델의 청각 텔레그래프
| 이벤트 | 반경(게임플레이) | 소리 설계 |
|---|---|---|
| 그르렁(Chase 진입) | 6~10m 전파 | 낮은 으르렁 — **3D 정위가 곧 정보**(리스너 분리가 전제). 동시 3개 한도 |
| Alert 응시 | — | 짧은 "킁?" 류 — 텔레그래프 1~2초의 청각 짝 |
| 윈드업 | — | 날카로운 흡기/쇳소리 — 0.4~0.6s 윈드업과 길이 일치 |
| 사망 | — | 계열 차별화는 Phase 2, 지금은 1종+피치 랜덤 |
| 배회 무리 | — | 간헐 신음 루프(Dormant 제외) — "저기 있다"의 상시 정보층 |

### 3.5 거리 감쇠 — 소리사다리와 음향의 정합
- 게임플레이 소리사다리(걷기3/달리기6/권총25/샷건50m)는 **AI 판정**이고, 음향 감쇠는 별도지만 **서로 모순되면 안 됨**(들리는데 안 깨거나, 안 들리는데 깨면 공정성 위반).
- 시작값: 좀비류 minDistance 1.5 / maxDistance 25(화면 반경≈12m의 2배 — 화면 밖 접근 경고 마진), Logarithmic. 총성 테일은 maxDistance 60.
- 검증: 화면 밖 좀비 그르렁이 **페이드인으로 미리** 들리는가(LOS 완충 4종 중 "소리" 항목의 실체).

## 4. USFX 셀렉션 가이드 (구매 후 1차 패스)

> USFX 1.6 = 1만+ WAV, 유니티 라벨 태깅. **전량 임포트 금지** — 1.4GB를 프로젝트에 다 넣으면 빌드·임포트 오염. 외부 폴더에 풀고 **선별 복사**(계열당 후보 3~5개 → 게이트에서 1개 픽).

| 우리 슬롯 | USFX 검색어(카테고리) | 수량 목표 |
|---|---|---|
| 리볼버 크랙 | gun, pistol, revolver / Weapons | 후보 5 |
| 라이플 연사 셋 | rifle, machinegun, burst | **라운드로빈용 3~4종** |
| 샷건 | shotgun, blast | 후보 3 |
| 저역 테일 | explosion tail, boom, distant | 후보 5 (크랙과 합성) |
| 재장전 | reload, click, mech | 계열당 2 |
| 풀히트/스침 | impact flesh, hit, squish / whoosh | 각 3 |
| 헤드팝 | burst, pop, crush (저역 강한 것) | 후보 5 — 제일 공들일 슬롯 |
| 근접(방망이/지렛대) | impact wood, metal hit, swing | MeleeSfx 절차음 대체 |
| 발소리 | footstep concrete/asphalt | 걷기·달리기 각 4(라운드로빈) |
| UI(체크 틱·전표) | UI, click, stamp | 정산 화면용 포함 |
| 앰비언스 드론 | Loop 태그: wind, city, drone | Calm/Ambience용 2~3 |

**USFX가 못 채우는 것 (별도 소스 — B-005b "유저 픽업" 잔여)**:
1. **좀비 보이스**(그르렁·신음·윈드업) — USFX의 voice/monster류는 범용이라 톤 미스 가능성 높음. 1순위 대안 = freesound 좀비 팩, 2순위 = 유저 녹음(이불 속 마이크에 으르렁 — 의외로 표준 기법).
2. **숨소리/날숨**(B-009 조준 의식) — 유저 녹음이 최적(마이크 가까이, 들숨 0.25s/날숨).
3. **음악** — 별도 트랙. Phase 1은 드론+펄스로 대체.
