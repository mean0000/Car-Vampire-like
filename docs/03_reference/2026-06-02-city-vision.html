1. 도시 정체성

"봉쇄된 미완성 대도시"
폭발적으로 성장하던 첨단 도시가 발병과 함께 통째로 봉쇄됐다. 뚫린 군 검문소, 멈춰버린 크레인과 미완성 골조, 꺼진 네온의 죽은 도심 — 좀비 떼를 갈아버리며 한복판으로 뚫고 든다. 탈출할 차가 거기 있으니까.
톤 = "황혼의 적막 (Twilight Desolation)" — 따뜻한데 곧 식어버릴 것 같은 적막(§4). 시점 = 3/4 부감. 아트 = Synty 플랫셰이딩 로우폴리. 장르 = 뱀서식 전투 파워판타지 — 구역은 스텔스 회피가 아니라 전투로 돌파.

🌾 평원 (거점 구역과 접함) — 차 + 통신차단 없이는 도보로 못 건넘. 보스의 이동식 통신 차단기를 얻어야 탈출(이동 중 AI 통신 교란) → "왜 위험한 중심으로 파고드는가"의 답
★ 핵심: "통과하는 길"이 아니라 "머물며 파밍하는 도시 구역"이다 (뱀서류).
• 도시 형태(공터 아님) — 거리·골목·건물. 좀비는 거리로 쏟아지고, 건물은 카이팅 동선·떼몰이 초크·전리품. 몰입 우선. (스텔스 엄폐 아님 — 전투 지형)
• 파밍 루프 — 구역 내 지속 스폰(깊이+시간 가중) → 처치 → XP/레벨업(카드) + 재료 수확. 감염 시계 압박 받으며.
• 게이트 = 초크포인트(무너진 대로·검문소·다리) — 충분히 강해지면 엘리트/호드/보스를 뚫어 다음 구역 개방 + 전진 체크포인트(부분 회복) 갱신.
• 되돌이 파밍 OK(뱀서 필수) — 뚫은 구역 재방문 가능. ⚠ 단 "안전 그라인드" 함정 방지: 얕은 구역은 거리 가중으로 저밀도·저보상이라 효율이 낮음 → 보상·시계가 항상 전진을 유도(authority §3).

3. 구역별 상세 (장소 → 에셋 → 그림)

구역정체성주력 에셋지배색레퍼런스
🪖 A. 군 검역 외곽
0–300m		 뚫린 검역 봉쇄선. 군이 막다 실패한 흔적. 트인 교전 공간 + 검문소·바리케이드 전투 지형. Battle Royale(컨테이너·철망·바리케이드·가드타워·군용차·천막) + Street Props(콘·배리어) 군용 올리브 + 모래먼지 + 경고 주황 TLOU 격리구역, The Division(NYC 봉쇄)
🏗️ B. 미완성 증축지구
300–650m		 성장하다 멈춘 도시. 철근 골조·비계의 수직 미로. 좁은 동선으로 좀비 떼를 몰고 카이팅 — 돌파 스펙 요구. Construction(골조·철근·크레인·비계·옹벽) + Generic Base(미완성 주거) 콘크리트 회색 + 녹슨 철근 구룡성채(멈춘 증축), 방치된 공사장
🌃 C. 죽은 환락 도심핵
650–1000m (보스)		 가장 높고 빽빽한 옛 도심. 깜빡이는 네온 잔해, 좁은 골목, 최고 공포. 보스 = 정점. Nightclubs(네온·사인·화재대피계단·셸·쇠창살) + Generic 도로/보도 죽은 네온 적자홍 + 짙은 헤이즈 ★ Hell Express(핵심), Stray, 구룡성채
공통 깔개: Generic 도로(10m)·보도(2.5m) + 버려진 차량 + Western 잔해/혈흔 + Nature 틈새 잡초 — 단 막힌 길·붕괴 구간으로 불규칙하게(격자감 제거).

4. 톤 — "황혼의 적막 (Twilight Desolation)"

공식 톤 네임 = 황혼의 적막. 모노노아와레(物の哀れ) — 활기가 빠져나간 고밀도 폐도시에 따뜻한 황혼빛만 남은 적막. "산뜻하지만 곧 식어버릴 것 같은 쓸쓸함." 모든 라이팅·색·구도 판단 기준 한 마디: "이거 황혼의 적막에 맞아?"

★ 온도 아크 — 무드가 곧 레벨 진행

빛이 안으로 갈수록 따뜻함 → 차가움으로 식어간다: Zone A 따뜻한 황혼 앰버 → B 먼지·식어가는 빛 → C 차갑게 죽은 네온. "곧 식을 것 같은" 예감을 플레이어가 진행하며 실제로 겪게 만든다.

재현 5요소

  • ① 골든아워/황혼 키라이트 — 낮은 태양·따뜻한 앰버 ("산뜻함"의 출처)
  • ② 두꺼운 대기 원근(haze) — COZY Height Fog, 멀수록 흐려져 사라짐 (깊이 + 쓸쓸함)
  • ③ 틸트시프트 디오라마 부감 — 3/4 미니어처 시점 (우리 카메라 그대로)
  • ④ 고밀도 생활 클러터 — 안테나·위성·간판·에어컨·전선·비계 = "살았던 흔적" (Nightclubs 옥상 + 데칼 + 소품)
  • ⑤ 부재(空) — ★적적함의 진짜 정체. 활기찬 무대 + 텅 빔

라이팅·그릿 원칙

  • 빛 = 텔레그래프 — 어둠은 균일이 아니라 대비. 발광/림라이트는 엘리트·출구·상호작용물에만. (네온은 에밋시브뿐 → URP Light + Bloom 직접 부착)
  • 그릿 레이어 — 데칼(핏·녹·때) + 필름그레인·컬러그레이딩 + 먼지·잔불 파티클 (2026-06-01 §6-2).
