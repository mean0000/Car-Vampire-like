> **작성**: 2026-06-11, pm/Gameplay/art/lv 4자 웹리서치 종합 (출처는 각 에이전트 보고 원문 — 세션 로그)
> **분석 축**: ①전투의 시각적 해법 ②연출 ③의도된 느낌 ④레벨디자인 ⑤우리 게임 소화 + 추가 3문항(사운드/카메라 정책/호드 가독성)

## 1. 게임별 핵심 (확인된 사실 위주)

### Hell Express (Full Metal Bagel / Arc Games — 이소메트릭 PvE 코옵 익스트랙션, EA 2026 봄)
- TLOU2·AC오리진 베테랑 팀. 아니메 스타일 + Limbo(저승) 세계관, Death Stranding 무드, Helldivers 1급 외형.
- 긴장 설계 키워드 = **"precision extraction timing under survival pressure"** + 자원 도박. 무장 차량(Hell Trekker)+도보 이중 전투. 부품 스카벤징 총기 크래프팅.
- **우리와 장르 골격이 가장 유사**(익스트랙션+크래프팅+탈것) — 시장 검증 사례. 단 공개 정보 얇음(시각/사운드 상세 미공개, 트레일러 영상 분석 추가 필요).

### PUBG: Blindspot (크래프톤 — 5v5 PvP 탑다운 택티컬, EA 2026-02 → **54일 만에 서비스 종료**)
- **시야 콘 = 조명 = 정보 = 게임 규칙의 삼위일체**: 콘 안만 보임, 조준하면 콘이 연장됨(조준=정보 취득 행위로 승격). 카메라 줌이 아니라 메커닉.
- **차폐 3단 위계**: 완전 차단(벽) / lite cover(하프월·창문 — 부분 시야) / 개활. 파괴 가능 벽 = 동적 맵 재조각. 자세(서기/앉기)별 사격·시야 차등.
- TTK 극단적으로 짧음 → **포지셔닝 경제**(발각=사망, 빗맞히면 위치 노출 페널티). 카메라 충격 최소화(전술 가독성).
- **사운드 = 키플레이**(확인): 총성 3레이어(발사+궤적음+착탄), 걷기/뛰기/앉기 발소리 구분 — 탑다운 시야 한계를 청각이 보완.
- ★평가: "시스템은 강한데 **맵이 못 받쳤다**" + **디자인 호평에도 PvP 인구 붕괴로 54일 사망**.

### DarkSwarm (Bitfire / Ghost Ship 퍼블리싱 — UE5 탑다운 코옵 호드, EA 2026 예정)
- **레이저 사이트** = 탑다운 조준선 식별의 명시적 해법(착탄 전 의도 시각화). muted neon + **적 생체발광** = 어둠 속 호드 식별을 밝기·실루엣으로 해결. 적 타입 구분 = 색이 아니라 **형태(실루엣 카테고리)**.
- **스폰 = 공간 사건**: 땅 뚫고 솟구침/알주머니 분출/벽 분출 — 팝인을 출현 연출로 위장하는 정석.
- **동적 음악 3단**(탐색→긴장→액션) + "적을 믹스에서 더 크게" 패치 + 앰비언스 공포(환기구 소리·군집 이동음·매복 전 침묵).
- 무게 장치 = 탄약 희소+HP 희소+아군 오사. 고어(사지분리)=킬 확인. 광감 경고 수준의 이펙트 강도.
- ★평가: 트레일러의 물량 약속 대비 "느리다" — **호드의 양만으로는 재미가 안 만들어진다**.

## 2. 3종 관통 교훈 (4자 수렴)

1. **조준 의도의 시각화가 착탄 피드백보다 먼저다.** 시야 콘(Blindspot)·레이저(DarkSwarm) — "지금 어딜 겨냥하는가"가 상시 노출. 우리의 레이저+수렴+잔광 트레이서 스택은 옳은 방향. 피드백 루프 = **의도(레이저/콘)→실행(궤적)→결과(착탄·죽음)** 3단이 다 읽혀야 함.
2. **사운드는 장식이 아니라 정보 채널이다.** 확인된 두 게임 모두 청각이 탑다운 시야 한계를 보완(발소리 구분, 적 접근 경고, 매복 전 침묵). 무음 천장 교훈의 외부 검증.
3. **공간이 시스템을 받쳐야 한다.** Blindspot: 시스템 호평+맵 혹평. DarkSwarm: 양≠재미. → 모퉁이 랩(B-008)의 우선순위가 생각보다 높다.
4. **(pm) 우리의 해자 = 싱글 PvE.** Blindspot은 디자인이 아니라 PvP 인구로 죽었다. 코어 재미를 타인 인구에 묶지 않은 것이 우리의 구조적 우위. LOS 긴장이 AI 상대로 성립하는 3조건: ①적이 시야 밖에서 의미 있게 행동(인식 시스템 충족) ②AI의 공정한 무지(벽 너머 텔레파시 금지) ③사각의 능동 운용(모퉁이 문법).

## 3. 추가 3문항 답변

**Q1 사운드 구조** → B-005 구체 스펙: ①좀비 상태 전환 큐(Dormant→Alert 그르렁 / Alert→Chase 울부짖음 — 인식 누적의 청각화) ②**동적 음악 3단**(DarkSwarm 직차용 — AudioMixer Snapshot + NoiseManager 경보 레벨 연결, **에셋 0원으로 긴장 곡선 가동**) ③착탄 표면 구분(벽=둔탁/좀비=육질음 — 육질음이 히트마커보다 먼저 체감됨).

**Q2 카메라 정책** → 3종 모두 고정 시점·줌 비사용(또는 메커닉화)·충격 절제. Blindspot의 "조준=시야 연장"은 우리 주시(리드 5.5m)와 동형 — 외부 검증. 킥 예약제·쉐이크 절제 방향 재확인.

**Q3 호드 가독성** → ①실루엣 카테고리(5계열은 형태로 구분 — 부감 캡처 검증 필수) ②적 발광 색코딩(계열별 glow — 시안=플레이어 정화와 체계 통일) ③스폰=공간 분출 연출 ④밀도 상한≠목표("1~3마리 코너 긴장"이 먼저).
