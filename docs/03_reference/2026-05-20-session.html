아트 & 분위기
세계관 톤

희망 없는 세계

  • 전체 배경: 채도 낮고 탁한 톤
  • Color Adjustments — Saturation↓ Contrast↑ Cold filter
  • 조명/Ambient를 먼저 차갑게, 그 위에 Post-processing
  • Synty 기본 팔레트는 밝음 → Albedo 직접 조정 필요
임팩트 연출

대비 효과로 쾌감 증폭

  • 어두운 배경 × 강렬한 임팩트 = 대비로 더 강하게 튐
  • 시체 Ragdoll 날아감 (파편 X → 로우폴리에 적합)
  • 바닥 피 데칼 — 로드킬 흔적으로 남음
  • 충돌 히트스탑 + 카메라 쉐이크
  • 폭발 파티클은 임팩트 순간에만 채도 높게
고어 필수 파편 대신 Ragdoll
음향 방향 (방향 확정)

사운드가 임팩트를 완성한다

  • 로드킬 타격감 — 묵직한 크런치/스플랫
  • 배경 앰비언스 — 바람, 정적, 무너진 세계 소리
  • 세부 비율 미확정

맵 & 차량
맵 구조

열린 평야 + 도심 폐허 산재

  • 기본: 장애물 없는 넓은 공간 (이동 자유)
  • 폐허 요소: 무너진 건물 잔해, 뒤집힌 차, 부서진 벽
  • 장애물은 미로가 아닌 주행 라인에 변화를 주는 수준
  • 도시 아포칼립스 분위기는 살리되 이동 막지 않음
차량 조작감

묵직한 돌진 + 슬라이딩 선회

  • 돌진 시: 묵직한 충격감 (히트스탑 포함)
  • 선회 시: 자연스러운 슬라이딩으로 다음 라인 연결
  • 즉각 반응 X, 탱크급 관성 X — 그 사이
  • Rigidbody + 방향 보정 혼합 검토 필요
적 설계
일반 좀비

무리가 무기다

  • 개체는 느리고 단순 — 혼자면 위협 없음
  • 엔진 소리에 반응해 몰려옴 (PZ 참고)
  • 무리가 자연스럽게 형성 → 박고 싶은 라인 생성
  • 충돌 피해 없음 — 그냥 쓸림
엘리트 좀비

라인을 강제로 바꾸는 존재

  • 길막형: 정면 돌파 시 차량 피해 발생
  • 무거운 적: 측면 공략 유도
  • 충돌 판정 책임: 좀비(OnTriggerEnter → 차량 속도 읽기)
일반 좀비는 HP 소모 없음 → 핵앤슬래시 쾌감 유지
직진 방지 구조

3가지 자연스러운 제약

  • XP orb — 죽인 자리에 남음, 루프백 유도
  • 엘리트 좀비 — 특정 라인 막음
  • 속도 감소 구조 — 두꺼운 무리에 갇히면 위험
