## 0. 결론 먼저 (TL;DR)

Hell Express는 **"탑다운 + 차량 + 호드 + 어두운 분위기"**라는 표면 DNA를 우리와 공유하지만,
**장르 페이스가 정반대**다 (얘=빠른 4인 협동 액션 슈터 / 우리=느린 솔로 스텔스 서바이벌).

따라서 이 레퍼런스는 **"게임플레이"가 아니라 "비주얼·연출·UI"를 훔치는 용도**다.
- ✅ **가져올 것**: 라이팅 대비 연출, 색 대비 무드, HUD 배치, 차량 구간(바이옴 이동)의 손맛.
- ❌ **버릴 것**: 액션 슈터의 속도감, 화염방사로 적떼 쓸기 = 권능 판타지, 4인 협동 합 → 전부 우리 핵심 감정과 충돌.

## 1. 왜 이 게임이 레퍼런스인가 / 어디서 갈라지는가

| 축 | Hell Express | ZombieCrush | 판정 |
|---|---|---|---|
| 시점 | 아이소메트릭 3/4 탑다운 | Darkwood식 3/4 탑다운 (~60–70°) | **거의 동일 → 직접 참고** |
| 분위기 | 어둠 + 강한 포인트라이트 | 어둠은 "대비"로, 림라이트/이미시브 | **동일 철학 → 직접 참고** |
| 차량 | **게임 중심** (Hell Trekker) | **바이옴 이동 구간만** (액션+스토리) | 부분 참고 (차량 씬 한정) |
| 페이스 | 빠른 액션 슈터 | 느린 스텔스 서바이벌 | **정반대 → 경계** |
| 인원 | 1–4인 협동 | 솔로 | 다름 |
| 전투 감정 | 권능 판타지(화염으로 쓸기) | 킬=대가 있는 수확 | **충돌 → 경계** |
| 톤 | 다크 유머 | Hades식 따뜻한 어두움 | 유사 → 참고 가능 |

**핵심**: 시점·라이팅·톤은 거의 같은 동네. 하지만 "플레이어가 느끼는 감정"은 반대다.
얘는 *"내가 강하다"*를 팔고, 우리는 *"위험하지만 욕심난다"*를 판다.

## 2. 비주얼 분석 (스크린샷 기반)

### 2-1. 라이팅 — 가장 훔칠 가치 있는 것
- 화면 전체가 어둡고, **빛이 나는 지점이 곧 "여기를 봐라" 신호**다.
  - ss0: 캐릭터 **손전등 콘**이 어둠 속에서 길을 가르고, 보스(붉은 곤충)는 자체 발광(이미시브)으로 시선을 끈다.
  - ss1: **화염방사 + 차량 헤드라이트**가 유일한 광원. 적 무리는 빛 가장자리에서 실루엣으로 드러남.
- → **우리 아트 디렉션 "어둠은 균일하게가 아니라 대비로"와 100% 정합.** 이게 1인 개발에 유리한 이유까지 동일(라이트 몇 개로 연출 완성, 텍스처 디테일 불필요).

### 2-2. 색 — 채도 높은 따뜻한 색 vs 차가운 어둠
- ss0: **주황·빨강 풀밭** (지옥 들판)이 화면을 지배 → 단일 강색으로 바이옴 정체성을 박는다.
- 차가운 청록 안개(키 아트)와 대비 → 따뜻함/차가움 충돌로 불안감 연출.
- → 우리 월드 구조(대도시→평원→빙하→숲)에 **바이옴마다 "지배색" 1개** 전략으로 차용 가능.

### 2-3. HUD — 최소·코너 집중
- 좌하단: 캐릭터 초상 + 체력바 + 이름("EDDA") + 보조 자원.
- 우하단: 탄약/자원 카운터 + 상호작용 프롬프트("Hold RB").
- **화면 중앙·캐릭터 주변은 깨끗** → 월드 가독성 확보.
- → 우리 "압박 없는 떠먹임 + HUD 아닌 월드 텔레그래프" 원칙과 정합. **숫자 HUD는 코너로, 정보는 바닥 데칼로.**

### 2-4. 차량 연출 (바이옴 이동 구간 전용)
- ss1: 트럭이 멈춰서 적떼를 정리하는 한 장면 = **이펙트 밀도(파티클·블룸·화염)로 손맛**을 만든다.
- → 우리 차량 구간(코믹 변종 등장)에 **"이동 = 비주얼 스펙터클" 보상**으로 차용. 단 도시 스텔스 루프엔 적용 금지.

## 3. 적용 포인트 (우선순위 순)

> 각 항목은 "우리 핵심 감정/원칙과 어떻게 정합하는가"를 명시한다. 정합 안 되면 넣지 않는다.

### 🟢 P1 — 지금 그레이박스/폴리시에 바로 반영
1. **라이팅 대비 = 텔레그래프 채널**
   - 중요 액터(신호 좀비, 상호작용물, 출구)에만 발광/림라이트.
   - 정합: 핵심 감정 "이벤트 긴장" + 아트 디렉션 가시성 전략. **HUD 없이 빛으로 읽힌다.**
2. **바이옴 = 지배색 1개**
   - 대도시(차가운 회청) / 평원(건조 황색) / 빙하(시린 청백) / 숲(짙은 녹). 색만 봐도 "어디 왔는지" 즉시 인지.
   - 정합: 핵심 감정 "미지의 설렘" — 새 색 = 새 구역 진입의 시각적 보상.
3. **HUD 코너 격리 + 중앙 청정**
   - 체력/감염도 = 좌하단, 자원/탄약 = 우하단, 중앙은 월드.
   - 정합: "압박 없는 떠먹임" + 스텔스 가독성.

### 🟡 P2 — 차량 구간 설계 시
4. **차량 이동 = 비주얼 스펙터클 보상**
   - 도보 스텔스(절제)와 대비되도록, 차량 구간은 의도적으로 이펙트 밀도 ↑ (헤드라이트, 먼지, 충돌 VFX).
   - 정합: 루프의 호흡(긴장↔해방) 리듬. 단 **"적떼 쓸기 권능"이 아니라 "통과/돌파"의 쾌감**으로 한정.

### 🔵 P3 — 폴리시/마케팅
5. **키 아트 공식**: 강한 로고색 + 보색 안개 + 캐릭터군 + 배경 유령떼. 스팀 헤더/위시리스트용 참고.

## 4. 가져오면 안 되는 것 (함정 목록)

> 표면이 비슷해서 베끼고 싶지만, 우리 핵심 감정을 파괴하는 것들. **명시적으로 거부.**

- ❌ **화염방사로 적떼 일소 = 권능 판타지** → 우리 "킬=대가 있는 수확"과 정면 충돌. 학살은 소음·감염 비용을 동반해야 한다.
- ❌ **액션 슈터의 속도감** → 우리는 "느린 템포"가 정체성. 빠른 교전 루프는 스텔스·긴장을 증발시킨다.
- ❌ **4인 협동 합/소란** → 솔로 고립감이 "미지의 설렘/공포"의 전제. 떠들썩함은 톤을 깬다.
- ❌ **차량 중심 설계** → 차량은 어디까지나 바이옴 이동의 양념. 메인 루프는 도보 스텔스다.

## 6. 추가 결정 로그 (2026-06-01 토론)

### 6-1. 렌더 파이프라인 — URP 확정 (HDRP 기각)
- 프로젝트 = **Unity 6 (6000.3.16f1) + URP 17**. 그대로 간다.
- **HDRP 기각 이유**: HDRP의 유일한 진짜 강점 = 포토리얼 고피델리티인데, 우리는 그걸 안 함(로우폴리 통일). HDRP 가면 안 원하는 이점 위해 무게·복잡도·Synty 비호환·마이그레이션 비용만 치름.
- URP의 약점 2개는 보유 에셋으로 이미 메움: **GI 빛 번짐 → HTrace SSGI**, **볼류메트릭 콘/안개 → COZY Height Fog + 라이트쿠키**.
- "언리얼 느낌"의 정체 ≠ 파이프라인. 그건 ①필믹 톤매핑(URP도 됨) ②실시간 GI(HTrace) ③볼류메트릭(COZY) ④**고밀도 리얼 에셋(★가장 큼, 어떤 파이프라인도 안 줌 = 에셋 문제)**의 합. HDRP에 로우폴리 올려도 언리얼 느낌 안 남.

### 6-2. 질감(피델리티) 결정 — **"로우폴리 토대 + 반사실 그릿"**
- **완전한 반사실(B) = 불가능**: 화면 최다 노출인 주인공·좀비·무기가 **로우폴리 버전만 보유**. 반사실 캐릭터/좀비 에셋 없음. 리얼 배경(Post Apocalyptic Town 등)에 납작한 좀비 세우면 "두 게임 붙인" 충돌 → 배경 한정 유지.
- **채택**: 모델은 로우폴리 유지하되, **반사실 "그릿(grit)/묵직함" 느낌은 레이어로 입힌다** (모델 교체 없이):
  1. **극적 라이팅** (HTrace) — 로우폴리도 빛 받으면 "비싼" 질감
  2. **포스트** (필름 그레인·컬러그레이딩·비네트) — 납작한 색 위 "필름 질감" 레이어
  3. **데칼** (핏자국·녹·때) — 바닥/벽에 사용감·현실감 주입 (URP 데칼, 구현 가능)
  4. **안개·먼지·잔불 파티클** (보유) — 화면 밀도 = 프로덕션 퀄 느낌
- 유저 합의: "저 정도면 좋다." → 멋진 스타일라이즈드 게임이 실제 쓰는 방식(모델 안 갈아엎고 묵직함만 획득).

### 6-3. 미결 / 다음 액션 (Unity 오픈 시)
- **시각 비교 테스트** (워크플로우: 유저=눈으로 판정, Claude=빌드):
  > 좀비 1마리 + 간단한 바닥으로 **①납작한 버전 vs ②라이팅+포스트+데칼 "그릿한" 버전**을 캡처해 나란히 제시 → 유저가 "이 정도 질감이면 OK/NO" 눈으로 판정.
- 이 테스트 통과 후 본 라이팅 작업 착수.
