⏪ 되돌리기(롤백) 방법

아래 커밋 로그에서 원하는 지점의 해시를 골라 실행한다. 두 가지 방식:

# 1) 그 시점을 "구경만" (브랜치 안 건드림, 작업본 보존) git stash # 현재 미저장 변경 임시 보관 git checkout <해시> # 그 커밋 상태로 이동(detached) git checkout feat/graphics # 다시 최신으로 복귀 # 2) 그 시점으로 "되돌려서 거기서부터 다시" (브랜치 이동, 이후 작업 버림 — 주의) git reset --hard <해시>

※ reset --hard는 이후 커밋을 버린다. 헷갈리면 Claude에게 "<해시>로 돌려줘"라고만 말하면 안전하게 처리한다.

EDGE(차별점): 컨텐츠 + 로우폴리로 승부. 로우폴리는 의도된 정체성(숨기지 않음), 게임플레이 가독성 최우선, 그래픽은 경계 있음.
축 (상수)잠긴 값
① 카메라·초점하이앵글 3/4 탑다운 ~59°, 캐릭터 ~7% 프레임, 틸트시프트는 게임플레이 밴드 제외 상·하단
② 대기·공기항상 은은한 볼류메트릭 헤이즈 + 대기원근 (COZY)
③ 라이팅어둠 기본 + 모티베이티드 광원 풀(차가운+따뜻한+이미시브), 부드러운 빛 + 강 AO
④ 팔레트채도 낮은 통일 베이스 + 씬당 1~2 액센트색 (시그니처색=경쟁 항목)
