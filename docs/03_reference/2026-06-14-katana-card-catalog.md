## 0. 30초 요약 (먼저 읽는 것)

- **카타나 단일 무기 = 두 트리.** 거합(Mod-A·고수·정지충전 발도 환류 / MGR 잔타츠) ↔ 참격(Mod-B·뉴비·위빙 가속 임계 작렬 / GoT 스트릭+무쌍). §17.1.C가 메카닉으로 정반대 증명 완료.
- **등급 3종 하이브리드 어디 사나** (카드시스템 v2.0 확정):
  - **① 숫자 등급(Common/Rare/Epic)** → *연료·시너지 묶음* 카드 인스턴스에만. 정체성 불변, 수치만 롤.
  - **② 전설 잎 + 변형** → 4잎(벽력일섬·반격베기·플리커·검기발사)은 *결정론 도달*(주사위 0). 도달 후 *변형 3택 → 재분기 1택*으로 빌드크래프트 계속.
  - **③ 신화 와일드카드** → 트리 *밖* 풀. M-1[전개식 모노필라멘트]·M-3[압류집행]. 화려함=돈 가중 RNG로 끼어듦.
- **총 장수 = 65장** (척추 7 + 시너지 6 + 연료 9 + 잎 변형 36 + 신화 2 + 재분기 5는 변형에 포함). 상세 집계 §6.
- **열린 트리**: prereq가 가지를 만든다. 부모 노드 보유 = 자격. 트리 모양은 카드 데이터의 prereq에서 저절로 그려짐(PoE 경로 할당).

## 1. 스키마 (Gameplay 읽는 법)

각 카드 필드:

| 필드 | 의미 | 구현 매핑(권고) |
|---|---|---|
| **id** | 고유 식별자. `kat_{tree}_{class}_{name}[_var_{x}][_refork_{y}]` | ScriptableObject 에셋명 |
| **이름(가제)** | 표시명 — Story 후속 | `displayName` |
| **트리** | 거합 / 참격 / 뿌리(중립) / 트리밖(신화) | `branchTag` enum |
| **문법클래스** | G0연료 / G1키스톤 / G2조건부 / G3시너지활성 / G4변태 / G6대안정체성 | `verbClass` enum (§16.5 재정합) |
| **효과** | 런타임이 *구체적으로* 뭘 하는지 | `effectHooks[]` (VerbKind+훅) |
| **수치(노브 시작값)** | %·초·배수 — 동결 아님 | `valueByLevel` / 노브 필드 |
| **등급적격** | ①숫자=C/R/E 롤 / ②전설=결정론 / 변형=잎 하위 결정론 | `Rarity` 필드 유무 |
| **prereq** | 보유해야 자격인 카드 id(가지 링크) | `requires[]` held-predicate |
| **시너지태그** | 킬축/정밀축/기동축/광역축 (묶음·신화 약가중) | `axis` enum (Kill/Precision/Mobility/...) |
| **depth** | 뿌리0 / 분기1 / 시너지2 / 잎3 / 변형4 | `treeDepth` int |

> ★**등급 규칙(엄수)**: `Rarity{Common,Rare,Epic}` 롤은 **연료(G0)·시너지 묶음(G2/G3)에만**. **잎(G4/G3/G1 종착)·변형·재분기·신화에는 ❌**(잎=결정론 도달, 변형=잎 하위 결정론, 신화=출현 자체가 이벤트). 드래프트 알고리즘 3b단계에서만 롤(카드시스템 §2.2).

## 5. ★잎 변형 (36장) — 잎 → 3변형 + 각 변형 1단 재분기

> ★유저 지시: 각 잎 → **3변형 + 각 변형당 재분기 2갈래**. 변형·재분기 모두 **결정론(등급 롤 ❌)** — 잎 도달 후 *발현 방식*을 가르는 정체성 선택. PoE 키스톤 뒤 노드. 잎 1개 = 도달 1 + 변형 3택 1 + (변형 안에서) 재분기 2택 1 = *9가지 발현*에 근접.
>
> 카드 수 계산(잎당): 변형 3 + 재분기 6(변형 3×2갈래) = **9장/잎**. 단 ★드래프트에선 변형 1택→재분기 1택만 먹으므로, *카탈로그 등재*는 9장이되 *한 런에 보는 건* 변형 1+재분기 1. 4잎 × 9 = **36장**.

## 8. ★총 장수 집계

| 층 | 내용 | 장수 |
|---|---|---|
| **척추** | 뿌리1 + 분기2(거합/참격) + 잎4(벽력일섬·반격베기·플리커·검기발사) | **7** |
| **시너지 묶음** | 거합3(기충전·처형환류·약점개창) + 참격3(콤보가속·처치가산·유지관용) | **6** |
| **연료** | 뿌리 중립3 + 거합 방향3 + 참격 방향3 | **9** |
| **잎 변형** | 4잎 × [변형3 + 재분기6] = 4×9 | **36** |
| **신화** | M-1 모노필라멘트 + M-3 압류 집행 | **2** |
| **합계** | | **★65장** |

- **등급 롤 적격(①숫자 C/R/E)**: 시너지 6 + 연료 9 = **15장**.
- **결정론(②전설, 롤 ❌)**: 분기 2 + 잎 4 + 변형 12 + 재분기 24 = **42장**.
- **신화(③, 롤 ❌)**: **2장**.
- **베이스(롤 없음)**: 뿌리 1 = **1장**.
- ★한 런에 *실제로 먹는* 잎 발현 경로 = 잎 도달 1 → 변형 1택 → 재분기 1택 = 잎당 3장 소비(카탈로그 9장 중). 카탈로그 65 ≠ 한 런 소비량(소수 정예 정신 유지).

## 9. ★구현 시 주의점 (Gameplay 인계 — load-bearing)

1. **등급 롤 위치 엄수**: `Rarity{C,R,E}` 필드는 **시너지(6)·연료(9) 15장에만**. 잎·변형·재분기·신화에 Rarity 붙이면 캐넌 위반(카드시스템 §2.2 — 잎=결정론, 신화=이벤트). 드래프트 알고리즘 **3b단계**에서만 롤. ①에 StS pity 곡선(계속 Common 꽝 방지) 적용 가능, ②③엔 ❌.

2. **prereq = 열린 트리 자격(held-predicate)**. 부모 카드 보유 = 드래프트 자격 풀 진입. 트리 모양은 prereq에서 *저절로* 그려짐(트리 좌표 하드코딩 ❌). **잎 도달 = 사슬 노드 보유 OR 조건**(벽력일섬 = 거합 사슬 1+, 반격베기 = 처형환류 필수, 플리커 = 처치가산 + 킬축 카드 2개 *런타임* 검사, 검기 = 참격 사슬 1+).

3. **잎 변형 게이트**: 잎 카드 획득 직후 *변형 3택*이 드래프트에 등장(잎 도달이 변형 자격을 염). 변형 선택 후 *재분기 2택* 등장. 변형/재분기는 결정론(롤 없이 그냥 3택/2택).

4. **시너지 사슬 결선 = 코드 진짜 빈칸**(`requires` held-predicate + 훅). 거합 chargen→reflux→weakpoint, 참격 combospd→killgain→keeptol 순서가 사슬. reflux/killgain(G3)은 *킬 이벤트 훅*이 필요(발도 킬→게이지 리필, 처치→+1단). 기존 `EffectKind`(전부 스탯)로는 표현 불가 → VerbKind+행동 훅 분리 필요(§16.5 재정합 스펙).

5. **신화 = 별도 타입/풀**(`MythicDef`류, 트리 밖). 드래프트 0단계에서 화려함=돈 가중 RNG로 슬롯 치환(카드시스템 §2.2). **M-1은 🔴 비싸다**(궤적 추적·기하 판정·VFX 신규) — 데모에 M-1만 박고 M-3은 싼 2번째로 가는 단계화 가능. 리롤이 신화 슬롯 다시 굴리게 하면 잭팟감 희석 → 신화 슬롯 리롤 면제.

6. **수치 전부 노브 시작값**(동결 ❌). `valueByLevel`/노브 필드로 플레이 중 조절(유저 인더루프 노브 세션 전제 — "30분에 12번 아니야" 판정). 특히 거합 평타 공속 55%·콤보 임계 5단·발도 데미지 곡선·신화 화려함=돈 가중 k가 1순위 튜닝 대상.

7. **거합/참격 메카닉 베이스는 §17.1.A/B에 실측 코드 위 스펙 확정**(PlayerCombat.cs + MeleeAttacker.cs). 분기 카드(kat_geh_branch/kat_cham_branch)가 그 메카닉을 켠다 — 카드는 이미 정의된 메카닉을 *활성화*하는 스위치(새 시스템 발명 ❌, §17.1 스펙 구현).

8. **이름 전부 가제** — Story 렉시콘 경유 정식명 후속. id로 구현하면 이름 바뀌어도 안 깨짐.
