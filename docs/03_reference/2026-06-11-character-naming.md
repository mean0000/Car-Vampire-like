# 캐릭터 명명 라운드 — 이름 공개 시스템 + 확정/임시 픽

> **작성일**: 2026-06-11 · **상태**: 🟡 부분 확정 (팀장 ✅ / 주인공 임시 2후보 / 여주 미정 / 엘 유지)
> **선행**: 주인공 시트 v1.0(§5 이름 정책 = 고정 이름·사직서에서만), 렉시콘 §5(어휘 관문), 결말 문서 §6(엘 부활)
> **명명 문법 (유저 확정 취향)**: 배드로식 — **성까지 붙여 읽어야 단어가 완성**되고 이름만 보면 무죄. 노골적 단어-이름 금지. 산나비(금 준장·금마리=마리골드) 레퍼런스.

## 1. ★이름 공개 시스템 — "이름은 자기 의지로 쓴 서류에만 존재한다"

본사는 누구의 이름도 부르지 않는다(사번·자산번호·직함). 이름은 **스스로 선택한 서류 위에서만** 드러난다 — 좀비 신원 복원(displayID→restoredIdentity)과 같은 문법을 아군 3인에게 분배:

| 인물 | 이름이 드러나는 서류 | 의미 |
|---|---|---|
| 주인공 | **사직서** (도장 인영) | 자유의 서류 — 제3조 최종 반전 |
| 팀장 | **거짓 시말서** 서명 | 희생의 서류 — 굴욕 양식의 회수(렉시콘 §6.2) |
| 엘 | **팀장 가게 직원 명부** (에필로그) | 소속의 서류 — 자산 목록→명부, 애칭의 정식 승격 |

## 2. 팀장 = 백엽 ✅ (2026-06-11 유저 확정)

- **백엽 ≈ 백업** (업→엽, 배드로식 시프트). 엘을 살린 비밀(동결 백업)이 이름에 숨음 — 결말 문서 §6.4 "부활 경위" 미결에 이름 차원의 답.
- **호칭 3단 진행**: 게임 내 "**백 팀장**"(백=back, 백을 봐주는 사람 — 성만으로도 펀 가동) → 거짓 시말서 서명 "**백엽**"(이름 최초 공개 = §1 시스템) → 에필로그 "**백엽 사장님**".
- **시말서 = 페어플레이 복선**: 중반에 "백엽"을 본 플레이어는 엘 부활(백업)을 예감 가능 — 이름이 미스터리 단서 겸직.

## 3. 주인공(남) — 임시 2후보 (동결 보류, 유저: "임시로 가고 싶어")

| 후보 | 숨은 문장 | 결 |
|---|---|---|
| **정상** (정씨+상) | "**정상** 접수되었습니다" | 본사 자동응답이 늘 그를 "정상"이라 부름 |
| **금일** (금씨+일) | "**금일**도 안전한 작업 되십시오" | 본사의 복붙 안부가 매일 그의 이름을 부름. 금씨 희소 성씨 무드(산나비 결) |

- 금일 채택 시 여주 **안전**(안씨+전)과 묶으면 공문 한 문장에 두 이름("금일도 안전한 작업 되십시오") — 단 외자 '전'의 실명감 낮음.

## 4. 주인공(여) — 미정. 후보 보드

| 후보 | 숨은 것 | 강점/약점 |
|---|---|---|
| **사람** (사씨+람) | "사람을 뽑습니다"·제3조·엔딩 태그라인 3연타 | 화력 최강 / 단어 노골성 최대(단, 노출이 사직서 1회뿐이라 상쇄) |
| **임시현** (임씨+시현) | 임시(비정규) | 실명감 최상, 펀 깊이 숨음 |
| **전산** (전씨+산) | "본사 전산" | 차출 사유 2(전체 데이터) 직격 |
| **안전** (안씨+전) | "금일도 안전한 작업" | 금일과 페어 전제일 때만 |
| 유고은 / 권유미 / 유예 / 인영 | 유고(有故)/권유/유예/인영(印影) | 전 라운드 채굴분, 보존 |

## 5. 엘 = "엘 / L-17" 유지 (개명 비추천 — 권고)

- L-17→"엘" 호칭 단축 자체가 동결된 관계 장치 + 부활 대사 "난 그대로다"와 이름 불변이 정합.
- 대신 **명부 등록 비트**(§1)로 이름 서사 완성. 옵션 레이어: 코드네임 "비고(備考)" — 양식의 세계에서 유일한 자유 서술 칸 = 엘의 위상 (채택 보류).

## 6. 부산물

- **기각/보류 펀 이름 풀 = 복원 신원 재료**: 나태근("나 퇴근")·이순직(순직)·유고은(유고)·한결원(결원)·이공석(공석)·인원·복원·기한·변수·원문 등 — **메모리 판독으로 복원되는 시민/좀비 이름 풀**로 재사용 (김민서와 같은 자리). 펀 이름이 시체로 나올 때의 블랙 유머는 카피 라운드에서 강도 조절.
- **팀장 가게 업종 제안 = 수리점/전파상** (판정 대기): 엘을 고쳐 살린 장소로 자연, 재난 대응업 아님(멸종 설정 무충돌), "고물은 불쌍한 거야"와 결 일치 — 결말 문서 §5.4 업종 미결의 후보.
