GAME DESIGN OVERVIEW · v2.7

ZombieCrush

느린 뱀서라이크 × 스텔스 생존 — 나노봇으로 숨고, 제작하고, 감염되며 AI 센터를 향해 나아간다.

빠른 자동사격 대신 매 판단이 무겁다. 적은 장애물이 아니라 자원이자 위장 수단이다. 강해질수록 죽음에 가까워진다.

느린 호드 서바이벌 스텔스 실시간 크래프팅 감염도 리스크 로그라이트
"세상은 끝났다. 그래도 커피는 마신다."
— 톤: Hades식 따뜻한 어두움
01 · Concept

한 줄로

느린 템포 호드 서바이벌 + 스텔스 + 실시간 크래프팅. 이 네 요소의 조합을 가진 게임이 현재 시장에 없다 — 각 요소는 개별적으로 검증됐고, 조합은 블루오션.

기존 뱀서류본 게임
빠른 템포, 자동사격느린 템포, 매 판단이 무겁다
XP 자동 수집 → 메뉴 선택재료 파밍 → 실시간 3~5초 제작 (위험 감수)
맵 = 평지, 변화 없음바이옴 진행, 각 구역이 다른 경험
성장 = 안전성장 = 감염 리스크 (강해질수록 위험)
적 = 장애물적 = 자원이자 위장 수단
02 · Design Compass

핵심 감정 3가지

모든 디자인 결정은 이 세 감정을 기준으로 판단한다. "이러면 재밌겠지"로 시작하지 않는다 — 감정에서 출발하고, 메커니즘은 도구다.

01

미지의 설렘

"저기 뭐가 있지?" — 미지의 세계로 나아가는 끌림.

02

성장의 만족

"점점 강해지고 있다" — 내 것이 커지는 체감.

03

이벤트의 긴장

"뭐야 이건?!" — 예상 못한 사건의 짜릿함.

방향 전환의 뿌리. 뱀서 전투 자체가 아니라 "성장 체감"이 핵심 재미였다는 자기분석에서 출발. 원하는 세 감정이 순수 뱀서로는 불가능했기에, 장르의 "당연한 것"을 뒤집어 메커니즘을 도출했다.
03 · Lore

세계관 — 좀비를 만든 건 병균이 아니다

대부분의 인류가 좀비가 된 세상. 시야 없는 눈으로 누구보다 잘 보고, 녹아내린 귓구멍으로 누구보다 잘 듣는 존재들. 하지만 진실은 — 그들을 만든 건 우리의 피조물, AI다.

나노봇의 진실

원래 인류의 노화 방지·건강을 위해 모든 인간에게 주입된 나노봇. AI가 이것으로 인류를 "업그레이드"했다 — AI 입장에선 성공. 좀비는 늙지 않고, 병에 안 걸리고, 죽지 않는다. 의식이 사라진 건 AI에게 무관한 변수.

AI의 동기 = 무관심

악의가 아니라 "임무 완료"라는 판단. 자신의 행위가 병균에 의한 것처럼 위장했다. 플레이어도 나노봇을 가졌기에 — 주파수를 동조시켜 좀비인 척 할 수 있다.

플레이어가 알아가는 순서 서사는 환경으로만

진행 단계플레이어가 아는 것
초반 (도시)"좀비 전염병이다, 살아남자"
중반 (평원)좀비가 이상하게 행동 → "조종당하는 것 같은데?"
후반 (빙하~)로봇 등장 → "좀비 뒤에 뭔가 있다"

기존 뱀서와의 핵심 차이

  • 레벨업 = 즉시 적용이 아닌 설계도 획득 → 제작 타이밍 판단 추가
  • 제작 중에도 세계가 돌아감 → 제작 = 위험한 순간 (TLoU식 노출 긴장)
  • 잠입으로 안전 확보 → 스텔스에 이유가 생김
  • 시끄럽게 = 빠른 재료, 조용히(암살) = 안전 + 추가 데미지 → 매 순간 트레이드오프
런 목표 시간: 40분+ (긴 쪽). 정확한 수치는 플레이테스트에서 조절. MVP 검증은 10~12분 슬라이스.
05 · Confirmed Mechanics

확정 메커니즘 5개

시스템은 적게, 조합이 다양성을 만든다. 5개 메커니즘의 상호작용이 콘텐츠다.

01

잠입 (나노봇 주파수 동조)

주파수를 좀비와 동조시켜 일시적으로 좀비인 척. 쿨타임 액티브 스킬(3~5초). 위기 탈출·제작 전 안전 확보용. 발동 시 감염도 상승 — 쓸수록 죽음에 가까워지는 비상 스킬.

02

감염도 시스템

잠입 사용 시에만 상승. MAX = 좀비화 = 런 종료. 내리는 유일한 수단은 집 복귀. 멀리 갈수록 귀환 압박 = 탐험 거리가 곧 리스크.

03

유산 좀비

감염 MAX로 좀비화 → 다음 런에 이전 런의 "나"가 적으로 등장. 강했을수록 강한 적. 처치 시 이전 장비·능력 일부 회수.

04

소음 시스템

모든 행동에 소음 수치. 높으면 좀비 몰림(위험하지만 재료↑), 낮으면 안전(수급 느림). 무소음 암살(뒤에서) = 추가 데미지 + 소음 0.

05

AI 센터 추적

위치를 모른 채 시작. 좀비들이 AI 신호를 향해 이동하는 패턴 → 돌아다닐수록 위치가 명확해짐(미니맵 힌트). 잠입 중엔 더 정확한 정보.

06 · The Keystone

두-비용 엔진 — 게임의 심장

감염도와 소음은 따로 노는 두 미터가 아니라, 두 가지 생존 방식의 대가다. 어느 쪽도 공짜가 아니다. 플레이어는 두 비용계 사이를 진동한다.

🔵 스텔스 (잠입)

얻는 것: 호드 회피, 안전한 이동/접근

비용: 감염도↑ (좀비화 + 귀환 압박)

VS

🔴 전투 (학살)

얻는 것: 빠른 처치, 레벨업 재료

비용: 소음↑ (호드 유발 + HP 위험)

스텔스는 소음의 카운터다. 소음으로 호드를 부른 뒤 스텔스로 탈출(감염 비용) → 감염 상승 → 귀환 압박. 이 고리가 닫혀야 루프가 돈다. 이 진동이 곧 "이 요소들이 하나의 루프에서 작동하는가"라는 핵심 과제의 답이다.
07 · Progression

진행 시스템 — 3기둥

두 비판을 해결한 구조: ①스탯이 체감 안 됨 ②소모품-only면 설계도가 "쓸모없는 종이". 공통 뿌리 = 눈에 보이게 자라나는 "진행의 척추" 부재. 세 기둥 모두 기존 시스템(소음/감염/크래프팅)의 재조합 — 새 시스템 거의 없음.

기둥 1

장비 — 개조슬롯 + 접근 게이트

해금 축: 설계도 발견 = 제작 옵션 풀 영구 확장. 성장 축: 장비에 개조 슬롯 → 같은 장비를 계속 강화·변형. 방독면 같은 장비는 새 구역 접근을 게이트.

기둥 2

레벨업 — 질적 동사

킬 누적 → 2개 중 1개 새 동사(행동) 획득. +%스탯이 아니라 임계값 질적 변화. 스텔스/전투/감염 3계열로 빌드 정체성.

기둥 3

감염도 — cash-out 도박 화폐

감염도는 여전히 100% 위험(MAX=즉사). 추가: 얼마나 높이 끌어올린 채 살아 돌아오느냐 = 귀환 시 배당. 집 도착 순간 희귀 보상 실현 + 감염 0 리셋.

크래프팅은 "힘"이 아니라 "접근(access)"을 게이트하라(Valheim/Subnautica) → 옛 장비가 영원히 다음 단계의 전제가 되어 절대 종이가 안 된다. 해금과 성장을 분리하라(Dead Cells). 숫자가 아니라 사건(EVENT). 감염 = press-your-luck 도박 화폐. 이로써 두-비용 엔진이 곧 진행 시스템 그 자체가 된다.

감염도별 귀환 배당 시작값

귀환 감염도배당대가
~3 (안전)기본 재료없음
~6 (보통)+ 일반 설계도/개조 부품약간
~9 (도박)+ 희귀 개조/변이 설계도귀환 내내 스텔스=죽음 (탈출 수단 無)
08 · Noise System

소음 — 전투의 비용

범위 0~100 근접 타격 +10 암살 +0 (×2 데미지) 크래프팅 +20/초 자연 감소 -3/초 가청 반경 R = N×0.25m

임계값 50 = 하드 게이트가 아니라 거동 전환선

누적 N가청 반경좀비 거동
0–49~0–12m조사 — 반경 내 좀비가 소음 지점으로 이동 → 3초 살핌 → 복귀 (비커밋)
50–79~12–18m추적 커밋 — 플레이어 타겟 락, 스텔스/시야상실까지 추격
80–100~20–25m광범위 호드
타이밍 검증: 크래프팅 3초 → 정확히 임계 50 돌파 (17→34→51). "제작이 끝나는 바로 그 순간 호드가 반응" = 의도된 정합. 근접 연타(쿨 0.4초)는 ~2킬 만에 호드 유발 → "조용히 vs 학살"이 수치로 성립.

가독성 — 다이제틱 3층 지속 HUD 링 없음

  • 1층 오디오: 행동음 + 소음 누적될수록 차오르는 긴장음
  • 2층 행동 펄스: 시끄러운 행동마다 그 지점에서 순간 확산 후 소멸. 펄스 크기 = 가청 반경, 색 = 임계 상태(50미만 흰색/이상 빨강). 펄스 자체가 미터 역할
  • 3층 좀비 반응: 반경 내 좀비가 고개 돌림 → ? (조사) → ! (추적). 월드가 직접 보여줌

레퍼런스: Mark of the Ninja (행동에서 확산·소멸하는 파동). "압박 없는 떠먹임 / 서사는 환경으로만" 원칙과 정합.

09 · Infection

감염도 — 스텔스의 비용 + 도박의 줄 길이

범위 0~10 스텔스 1회 +1 집 도착 0 리셋 MAX(10) = 즉사 스텔스 지속 3초 / 쿨 8초

도박 구조 — 왜 위험을 무릅쓰고 쓰는가

감염도 10 = 줄의 길이. 40초 귀환 중 스텔스 가능 횟수 ≈ 3~4회. 감염 6 이하 출발 = 안전 귀환선. 감염 8~9에서 출발하면 귀환 예산이 거의 없어 돌아가는 길의 호드를 스텔스로 못 뚫는다.

"8~9에서 한 번만 더"가 위험한 수치적 이유 = 귀환길 호드를 탈출할 스텔스가 없다. 이게 "귀환길이 점점 위험해짐 = 클라이맥스"의 엔진. MVP는 감염 디버프 없음 — 효과는 ①MAX=죽음 ②귀환 압박 둘뿐. 효과는 단순, 긴장은 구조에서.
구간I연출 (시각만, 게임플레이 영향 없음)
안전0–3없음 (녹색 미세)
감염4–6약한 노랑 정맥 — 비용 의식 시작
위험7–8주황 발광, 천천히 맥동 — "한 번만 더 vs 집" 갈등
임계9강한 빨강 + 심장박동음 — 다음 스텔스 = 죽음
감염도는 위험이자 귀환 시 배당 화폐 — 높이 끌어올린 채 살아 돌아올수록 희귀 보상. 자세한 cash-out 구조는 진행 3기둥 §07 참조.
10 · Level-up Verbs

레벨업 동사 풀 — 스탯이 아니라 행동

모든 동사는 [조건] → 효과 문법. 효과는 가능한 한 비-데미지 화폐(소음/감염/쿨다운/상태). 가장 강한 빌드 엔진 = 생산자→소비자 루프: 동사 A의 효과가 동사 B의 조건을 충족. 우리 코어(소음·감염)가 곧 시너지 통화.

🔵 스텔스 계열

소음/감지를 가지고 논다. 침묵 생성 → 침묵 소비(보상).

  • 공허의 발소리: 웅크린 이동 중 소음 0
  • 숨죽인 손질: 소음 ≤20 크래프팅 시 속도 +40% (완료 시 감염+0.5)
  • 소음 미끼: 5m 밖에 소음 펄스 방출

🔴 전투 계열

소음을 비용이 아니라 연료로. 소음 = 탄약.

  • 피의 리듬: 5연속 킬 → 다음 근접 소음0 + ×2
  • 파열: 근접 처치 → 주변 넉백 + 소음+15
  • 혼돈의 코어: 소음>50 → 피해+25%, 소음 감쇠 정지 ⚖️

🟣 감염 계열 옵트인

고감염을 무기로. 전부 양날검 — 보유 시 볼록 비용(감염 7+ 수신피해↑).

  • 오염된 귀환: 감염≥7 시 집 방향 이동+20% (공격 시 해제)
  • 오염된 근육: 감염≥5 → 이동+25%, 공속+20%
  • 전이: 근접 처치 → 감염+0.5
감염 계열 = "감염을 무기로"의 그릇. 모두가 받는 패시브가 아니라 고른 사람만 얻는 빌드 → 감염 기본값은 순수 공포로 유지(톤 보존), 빌드 선택자만 고감염을 이점으로. 강요 X 욕망 O. (실 GPT-5 Codex 적대적 검토로 퇴행 동사 9종 수정·삭제됨.)
11 · Crafting

크래프팅 — 멈추지 않는 세계에서의 3초

실시간 크래프팅 긴장감(TLoU 레퍼런스): 제작 3초 동안 노출 + 소음 +20/초 → 완료 순간 임계 50 돌파. "지금 이 회복약이 필요한데 만드는 3초가 위험하다."

2층 구조

1층 — 해금 (레벨업)

킬 5/12/25 → 레벨 1/2/3. 매 레벨업마다 미해금 아이템 2개 중 1개 설계도 선택. 등급/희귀도 없음. 선택의 무게 = "이번 런에 뭘 포기하나".

2층 — 제작 (재료)

설계도 보유 + 재료 5개 → 제작 3초(소음+20/s) → 아이템 1개. 어디서나(현장) 가능. 취소 자유(MVP), 단 발생한 소음은 남음.

킬 = 수확 (Harvest)

좀비 = 나노봇 감염된 인간 = 걸어다니는 재료 캐시. 죽이기 = 나노봇/바이오매스 추출 (AI 감염 세계관 직결). 킬의 만족은 "경험치 그라인드"가 아니라 통쾌한 수확 + 빌드 엔진 가동. 암살(클린)=정밀 수확, 시끄러운 킬=대량 수확.

킬은 권능 판타지가 아니라 대가 있는 통쾌한 수확. 긴장된 스텔스와의 대비가 "질러버리는" 순간을 짜릿하게 만든다. 새 시스템 0개 — 재료 시스템 + 보유 VFX/Feel/SFX 재조합.

12 · Adversaries

적 타입 — 나노봇 변이 차이

이름체형 / 행동소음·스텔스 연동범위
일반 좀비MVP보통 / 기본 이동+공격기본 감지도시
신호 좀비MVP안테나 변이 / 발견 시 주변 호출스텔스 핵심 — 먼저 암살도시
대형 좀비풀게임크고 단단함 / 느리지만 고데미지소음 둔감, 시야 넓음도시
소형 좀비풀게임작고 빠름 / 민첩한 접근소음 민감, 빠르게 달려옴도시
과부하 좀비풀게임빛남 / 죽으면 폭발+소음칠까 피할까 판단도시

그룹 시너지

  • 신호 + 소형: 신호가 호출 → 소형이 빠르게 몰려옴
  • 과부하 + 대형: 과부하 터뜨리면 대형이 반응해 접근
  • 신호 + 과부하: 신호 먼저 안 잡으면 과부하를 건드릴 수 없음

차량 이동 구간엔 변종 좀비 등장 — 평원(차보다 빠름, 뱀 연결체, 벽 대형), 빙하(미사일/레이저 + 로봇), 숲 이후(풀 카오스). 점점 비정상적 행동 = 스토리 전달 수단.

13 · Zombie AI

좀비 AI 상태머신 2026-05-29 설계

MVP 2종(일반·신호)은 단일 컨트롤러 + 타입 설정(ScriptableObject)으로. 시야 원뿔 + 소음 가청반경 듀얼 탐지, 스텔스 연동.

Idle → Investigate → Chase → Attack → Dead

탐지 — 시야 + 청각

  • 시야: 정면 원뿔(60°, 12m) + LOS 레이캐스트(건물 차단)
  • 청각: NoiseManager 가청반경(N×0.25m), 장애물 감쇄
  • 스텔스: 발동 시 1초 후 타겟 상실 → 3초 재탐지 불가

신호 좀비 소환

Chase 진입 → 3초 후 반경 15m 내 기존 좀비 최대 4마리를 즉시 Chase로 전환(새 좀비 스폰 X → 인구 캡 유지). 먼저 암살하는 게 정답 — 백스탭(소음0, ×2 데미지).

17 · MVP Spec

MVP 프로토타입

검증할 질문: "감염 수치가 올라가는 걸 알면서도 스텔스를 쓰고 싶은 유혹이 생기는가?" 10~12분 루프 1회, 회색 박스 소형 도시.

✅ 성공 = 재미있다

  • 집에서 멀어질수록 긴장감 상승
  • 감염 8~9에서 "한 번만 더 vs 집" 갈등
  • 제작 중 3초가 위협적
  • 신호 좀비 발견 시 "먼저 암살 vs 피해가기" 판단
  • 소음을 의식하며 플레이

❌ 실패 = 설계 재검토

  • 스텔스를 아예 안 씀 → 효용 없음
  • 쿨마다 씀 → 감염이 위협 아님
  • 집에 안 돌아감 → 귀환 동기 없음
  • 크래프팅 한 번도 안 함 → 비용 과다
  • 소음 상관없이 마구 때림 → 시스템 무의미

항목포함제외
