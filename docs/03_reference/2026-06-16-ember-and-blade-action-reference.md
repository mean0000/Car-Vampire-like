# 엠버 앤 블레이드 (Ember and Blade) — 액션 표현 레퍼런스

> **왜 박았나 (유저 지시, 2026-06-16):** "액션성을 디게 표현 잘한 게임" → 우리 조준형 뱀서([[vampire_survivors_pivot]])의 **액션감/타격감 레퍼**로 삼는다. 장르 척추가 거의 동일한 동시대 정식작이라 벤치마크 가치가 큼.
> **한계 고지:** 본 문서는 데모 시연기사·스토어·나무위키 기반(2026-06-16 검색). Claude가 직접 플레이/영상 분석한 게 아님 — **데모가 지금 플레이 가능**하니 액션 "느낌"의 최종 판정은 유저가 데모를 직접 만져보는 게 정답. 아래는 *구조적으로 읽히는 것*만.

---

## 1. 한 줄 정체성

라인게임즈(NL팀)의 **불렛헤븐 + 무쌍식 액션 + 로그라이크 빌드성장** 신작. 2026 Q4 예정, **에픽 Top Demos 1위 / 에픽 "2026 기대작" 선정**. 우리와 같은 척추(뱀서형 자동공격 베이스 + 인런 드래프트 + 고정 보스 + 영구 메타).

---

## 2. ★액션을 "잘 표현한" 핵심 — 우리가 훔칠 것

뱀서는 보통 *완전 자동공격*이라 손맛이 없다. 엠버 앤 블레이드의 차별점 = **자동 베이스 위에 "수동 액션 레이어"를 얹어 손맛을 복원**한 것. 우리 "조준 동사" 논제와 정확히 같은 해법.

| 차원 | 엠버 앤 블레이드 구현 | 우리에게 매핑 |
|---|---|---|
| **자동 vs 수동 비중** | 원거리는 자동 발동, **비중은 수동 근접에 실음**. 즉 자동은 바닥, 정체성은 수동 액션. | 우리=자동사격 베이스 + **정체성은 수동 조준 사격**. 같은 철학, 동사만 검↔총. |
| **콤보 입력** | 근접 **버튼 최대 3회 입력 / 홀드**로 콤보 체인. 단순 클릭이 아니라 입력 리듬이 있음. | 우리 조준에 *리듬/박자*를 줄 근거(정조준-한발 의식 [[zone_aim_ritual]] 폐기됐지만 "내 박자로 개전" 정신은 유효). |
| **회피→반격 창** | 적 공격 패턴이 **지면에 전조 표시** → 회피 → **반격으로 데미지 창** 생성. | 우리 적 전조/후방 위협 힌트([[rear_threat_hint_frozen]])와 직결. 위협을 읽히게 → 반응에 보상. 보스게이지 압박과도 짝. |
| **타격감(주스)** | 핵앤슬래시 타격감 극대화, **빠르고 경쾌한 템포**로 정밀 조정. 상위몹·보스일수록 **공격 전조 효과 강화**. | 우리 게임필 4원칙([[juice_textbook_lessons]])의 실전 사례. 전조 강도를 *적 등급의 다이얼*로 쓴다는 게 핵심. |
| **보스전** | 정교한 컨트롤+전략 요구, 보스 AI 긴장감. 바포메트戰서 **패턴 중 카메라 전환** 연출. | 우리 고정보스/보스게이지의 액션 톤 레퍼. 단 ⚠️아래 함정 참고. |

---

## 3. ⚠️ 그들이 밟은 함정 = 우리 선행 교훈의 확증

시연 기자 지적 두 가지 — 우리가 이미 메모리에 박아둔 경고와 **정확히 일치**한다(= 우리 방향이 맞다는 교차검증):

1. **"능력 이펙트가 화려해서 혼란이 나오는 지점이 있다"** → 우리 [[world_transparent_vfx_cone_trap]] / [[juice_textbook_lessons]]의 **정보 레이어 vs 연출 레이어 분리** 원칙 그대로. 화려함이 가독성을 잡아먹으면 안 된다. 부감/쿼터뷰일수록 더 위험.
2. **보스 패턴 중 카메라 전환이 "순간적 혼란"을 낳음** → 카메라가 정보 채널인데 멋 부리다 정보를 끊으면 손해. 우리 카메라 바이블(이원 카메라 [[attention_channels_weapon_identity]])의 "정보는 상시 클린" 기조 유지 근거.

**결론:** 액션 표현은 훔치되, **화려함 ≤ 가독성**은 우리 가드레일로 유지. (액션감은 1층 애니 × 2층 VFX인데, 2층이 1층을 가리면 실패 — [[animation_asset_research]].)

## 4. 우리와 갈라지는 지점 (= 해자 후보, 안 겹침)

- **동사**: 저쪽 근접 검/무쌍 ↔ 우리 **총기 조준 사격**. 가장 큰 차별.
- **개성**: 우리 **사후처리부 2페이즈**(P1 시민 탈출지원→봉쇄→P2 순수 뱀서) + 그로테스크 변종야수(Protofactor). 저쪽은 정통 다크판타지(천사 축복 / 마족·파우스트 보스).
- **압박 구조**: 우리 **보스게이지(시간+처치 복합)** ↔ 저쪽 지역 클리어형.

## 5. 액션 검증 액션아이템 (데모 활용)

데모가 지금 플레이 가능 → **유저가 직접 만져 확인할 체크리스트**(우리 조준 뱀서로 변환 전제):
1. 자동(원거리) ↔ 수동(근접) 전환이 **손에서 어떻게 느껴지는가** — 자동이 수동을 안 죽이나?
2. 지면 전조 → 회피 → 반격 창의 **반응 타이밍 폭**(너무 빡빡/널널?).
3. 군중 한가운데서 **내 캐릭터·내 입력이 읽히는가** (화려함 vs 가독성 실측).
4. 타격감 — 빠른 템포가 *경쾌*로 가나 *가벼움*으로 가나.
