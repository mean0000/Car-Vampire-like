🪖 Zone A — 군 검역 외곽 (0–300m · 게이트① 엘리트)

훔칠 것

  • 군 검문소·콘크리트 장벽·철조망이 만든 뚫린 봉쇄선 실루엣
  • 버려진 군용 차량·천막·모래주머니 = 전투 지형(카이팅 엄폐)
  • 트인 외곽 + 먼지 황혼빛(가장 밝은 구역)

지배색

군용 올리브 + 모래먼지 + 경고 주황(스폿)

빌드 레시피 (보유 에셋)

  • 구조물: BR 컨테이너·바리케이드·가드타워·체크포인트 + 모래주머니
  • 차량: BR 군용차·트럭(정상+파괴) 흩뿌림
  • 가로: Generic 도로(10m)/보도(2.5m) + Street Props(콘·배리어·드럼)
  • 지면: 균열·먼지 데칼, Western 잔해/먼지더미

구현 체크 (그레이박스)

  • 2.5m 스냅 위 도로/지면 → 건물·장벽 불규칙 배치(격자감 X)
  • 게이트① 초크포인트 = 무너진 검문소 게이트(트리거 GO) — 엘리트 처치 시 돌파
  • 바리케이드로 카이팅 레인 형성(떼몰이 동선)
  • 거리 가중 스폰(저밀도, 일반90/엘리트) + 전진 체크포인트(부분 회복)

🏗️ Zone B — 미완성 증축지구 (300–650m · 게이트② 호드)

훔칠 것

  • 멈춘 크레인 + 철근 노출 골조의 수직 미완성 실루엣
  • 비계·발판이 만든 다층 동선(떼몰이/카이팅 지형)
  • 층층이 겹쳐 흐려지는 밀집감(대기원근)

지배색

콘크리트 회색 + 녹슨 철근 주황

빌드 레시피 (보유 에셋)

  • 골조: Construction ConcreteFrame/Rebar 벽·기둥·슬래브(한 건물=한 시스템 통일)
  • 랜드마크: 크레인·물탱크·스모크스택 + 비계·옹벽
  • 미완성 주거: Generic Base 키트(_Destroyed 벽 섞기)
  • 바닥 충진: Construction 자재 적치·콘·배리어(⚠ 하단 비어보임 방지 — 충진재 확인 필요)

구현 체크 (그레이박스)

  • 2.5m/3m층 그리드로 골조 적층(미완성 = 윗층 Rebar)
  • 게이트② 초크포인트 = 무너진 구조물/크레인 붕괴 통로 — 호드 정리/점거로 돌파
  • 좁은 비계 동선 = 호드 몰이 카이팅 공간
  • 스폰 +30% 밀도 + 호드 버스트 트리거(게이트)

🌃 Zone C — 죽은 환락 도심핵 (650–1000m · 게이트③ 보스 → 차 부품)

훔칠 것

  • 꺼진/깜빡이는 네온 잔재 + 옥상 안테나·위성·간판 클러터
  • 화재대피계단·쇠창살·좁은 골목 = 최고 밀집
  • 발치의 골목 + 머리 위 닿지 못하는 거대 타워(원경) → 높이감은 배경이 담당

지배색

죽은 네온 적자홍 + 짙은 헤이즈(가장 어두움)

빌드 레시피 (보유 + 추가)

  • 외관: Nightclubs Base 셸 + 네온·사인·화재대피계단·쇠창살·차양
  • 가로: Generic 도로/보도, 좁은 골목 레이아웃
  • 볼륨(높이): ★ Synty 계열 도시/아포칼립스 팩 추가로 보강(완성 건물 매스) — 또는 골목 밀집+원경 타워로 대체
  • 조명: 네온 에밋시브 + URP Light/Bloom 직접 부착(빨강 펄스=위험)

구현 체크 (그레이박스)

  • 좁은 골목망(2.5m 스냅) + 원경 배경 빌딩(통짜)으로 스카이라인
  • 게이트③ 초크포인트 = 무너진 대로/광장 = 보스 아레나 → 차 부품 드롭
  • 최고 밀도 스폰 + 보스 + 죽은 네온 깜빡임(에밋시브 트윈)
