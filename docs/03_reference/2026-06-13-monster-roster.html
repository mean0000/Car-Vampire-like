인카운터 훅 — 분류에서 나온 공짜 재료

  • 가족 3계보: Rostrokarck(알→유생→성체) / Crustaspikan(유생→성체) / Kupolobrach(유체→성체) — "거물 영역에 들어가면 새끼가 먼저 나온다" = 디제틱 보스 예고가 에셋에 내장.
  • 원거리 속성 스펙트럼: 산성(Venodonte) · 전기(Funglicane/Kupolo계) · 가스(Serpmare/Kupolobrach) · 투석(Crustaspikan) · 스핏 다수 — 속성별 시각 언어 분화 가능.
  • 인간 변이 앵커: 직립 실루엣(Dimaxillosaurus·Fulgurodonte·Crassorrid)이 "사람이 변했다"의 시각 다리. 완전 이형(게·오징어·크라켄)은 변이 말기로 배치 → 스펙트럼 성립.

인게임 스케일 검증 (CombatLab 라이팅 실측)

좌측 방 안 Venosaur(LV3) · 중앙 하단 Caniathrox(LV2) · 우측 Crustaspikan(LV5, 13.2m) — 거물은 건물을 넘는다. URP 변환 후 마젠타 0 확인.
