## 0. 30초 요약 (유저가 먼저 읽는 것)

- **★등급(레어리티) — ✅ 유저 확정 = 3종 하이브리드 (각자 *다른 도파민*, 다른 층이라 안 싸움).** 카드 "특별함"이 셋으로 갈린다:
  - **① 숫자 등급 (Common/Rare/Epic)** — *일반 카드(연료·시너지)*에만 붙는 *숫자 롤*. 정체성 불변, Hades 모델("레어도는 숫자만 커지고 새 동사는 다른 카드가 줌"). **잦은 작은 도파민.**
  - **② 전설 잎 + 변형** — 트리 종착 잎(돌파 사출=벽력일섬 등)에 *도달*(결정론, 주사위 0) → **변형 갈래**(예: [중심 과부하]/[귀환 라인]/[2차 기폭]) 선택 → 그 변형 안에서 *또* 갈래(PoE 키스톤 뒤 노드). **빌드크래프트 깊이.**
  - **③ 신화 와일드카드** — *완전 새 명사/동사*(숫자도 변형도 아닌 새 메커니즘). **가끔 RNG** 등장, **화려함=돈(처리평가)이 높을수록 등장 확률↑**. 트리 *밖* 별도 풀. **잭팟 도파민.** → 풀 드래프트 §6.
- **카드 총 개수**: 데모(검+드론) = **손설계 ~28장 + 신화 2~3**. 풀게임(6무기) = **손설계 ~55장 + 연료 템플릿 1세트 + 신화 풀 ~8**. *Hades급 소수 정예* — 무한 다양성은 *조합*에서 나오지 카드 수에서 안 나온다(Hades 무기6×Aspect4 = authored 소수, 다양성은 boon 조합).
- **드래프트 알고리즘**: 레벨업마다 **3택 1**. 우리 "열린 트리"라서 제시 풀 = *지금 뽑을 자격(prereq) 충족한 노드*만. 일반 카드는 ①숫자 등급을 롤, ②잎은 결정론 도달, ③신화는 *별도 풀에서 화려함=돈 가중 RNG로 끼어듦*. 리롤은 **보편 ❌ → 메타/소비 자원**(20MTD Shana 고유·Halls of Torment 포션 추적).
- **전체 방향 한 줄**: **"열린 트리 + 3택 드래프트. *특별함이 세 층으로 분리* — 파워는 ①숫자 등급이, 정체성·빌드크래프트는 ②전설 잎+변형이, 새 메커니즘 잭팟은 ③신화 와일드카드가 책임진다. 세 도파민이 다른 층에 살아 서로를 안 잡아먹는다."**

> ★**reframe (이게 핵심)**: 옛 권고 "등급 NO"는 *틀린 전제*에 섰다 — "트리 게임은 무등급"은 약하다(**SoD가 실제로 에센스를 common/flawed/rare/legendary로 등급화**, Codex 지적·내 교차검증). 진짜 질문은 "등급을 넣나 마나"가 아니라 **"등급이 *어디* 사느냐"**다. 정체성=②트리(잎+변형), 파워=①숫자 롤(카드 인스턴스), 새 메커=③신화. **"등급 시스템 2개 충돌" 우려도 해소**: 처리평가 S~D는 *런 경제*를 등급화, ①숫자 등급은 *카드 인스턴스 파워*를 등급화, ③신화는 *새 메커니즘 출현*을 게이트 — **셋이 *각자 다른 것*을 등급화하므로 충돌 0, 오히려 *스택***(처리평가↑ → 신화 확률↑ → 더 화려 → 처리평가↑).

> ★**남은 판정 = §4의 Q-B(카드 총 개수=Hades급 소수) + Q-C(리롤=메타 자원) + ★Q-F(신화 빈도/캡·등장확률 곡선).** 등급(Q-A)은 유저 확정으로 닫힘.

### 1.4 ★표에서 뽑은 3대 패턴 (제안의 토대)

> ⚠️ **v2.0 정정**: v1.0은 여기서 "트리 게임=무등급"을 주장했으나 *약한 일반화*였다(Codex 지적·재검증). **SoD는 실제로 에센스를 common/flawed/rare/legendary로 등급화**(아래 §1.1 표 보정 참조)하면서 *동시에* 조합 깊이를 가진다. 즉 "트리형이냐 드래프트형이냐"는 등급 유무를 정하지 않는다 — **등급은 *어느 축*에 붙느냐의 문제**다. 우리 결론(3종 하이브리드)이 정확히 이 교훈을 산다.

1. **★등급은 *여러 축에 동시에* 살 수 있다 — 충돌은 "같은 것을 두 번 등급화"할 때만 난다.**
   - **인스턴스 파워 등급** = Hades(boon 5단)·StS·RoR2·Balatro·Brotato·**SoD(에센스 4단)** = "이번에 받은 *이 카드*가 얼마나 센가"를 *숫자*로 표현. → 우리 **①숫자 등급**의 직계.
   - **정체성/희소성 = 트리 위치** = PoE(Small/Notable/Keystone)·VS(진화 레시피)·Halls of Torment(랭크 잠금) = "*무엇*을 여느냐"는 *경로·prereq*가 정함(주사위 아님). → 우리 **②전설 잎+변형**의 직계.
   - **새 메커니즘 출현 = 별도 게이트** = Balatro Legendary 조커(0.x% 초희귀)·Hades Hex·PoE 유니크 = "전혀 다른 규칙이 *가끔* 끼어듦". → 우리 **③신화 와일드카드**의 직계.
   - → **세 축이 *서로 다른 질문*에 답하므로 한 게임에 셋 다 살아도 안 싸운다.** Balatro가 산 증거: 레어도(어떤 조커=①) ⊥ 에디션(반짝임) ⊥ Legendary(초희귀 새 조커=③)가 *직교 3축*. 우리는 거기에 ②트리 정체성을 더한 것.

2. **★깊이 = 카드 수가 아니라 *조합/시너지*.** SoD(Essence 조합)·Hades(boon 조합)·VS(레시피)·RoR2(스택) 전부 — authored 카드는 *소수 정예*, 무한 다양성은 *서로 먹여주는 사슬*(§16 G3 엔진 심장)에서. → 카드를 수백 장 만들 필요 없다(솔로 개발 현실 정합).

3. **★등급을 쓰는 게임도 "레어도 ≠ 정체성"을 못 박는다.** Hades: "레어도는 *숫자만* 커지고 *새 동사*는 *다른 boon*이 준다." Balatro: 레어도(어떤 조커) ⊥ 에디션(반짝임)을 *직교 분리*. StS: Rare도 덱 안 맞으면 스킵. → **등급은 *정체성을 못 만든다*. 정체성은 *카드 내용*(§16 동사 클래스)이 만든다.** 등급을 넣어도 뽕의 본체는 아니다.

## 2. 우리 제안 (캐넌 재정합 — 각 결정에 레퍼 근거)

### 2.1 ★결정 ① 카드 총 개수 — Hades급 소수 정예 (데모 ~28 / 풀게임 ~55 + 연료 템플릿)

우리 문법(§16 2층 모델)은 카드를 **두 층**으로 나눈다 → 개수도 두 층으로 세야 정확하다(섞어 세면 "수백 장 필요"라는 착시).

| 층 | 무엇 | 데모(검+드론) | 풀게임(6무기) | 손설계 부담 | 레퍼 근거 |
|---|---|---|---|---|---|
| **정체성 척추** (손설계, 적음) | 무기당 7노드(뿌리1+분기2+잎4) | 검 7 + 드론 7 = **14** | 6무기×7 = **42** | ★**100% 손설계 (절차 ❌)** — 정체성은 손으로만 | Hades(전 boon authored)·20MTD(무기당 소수 진화) |
| **시너지 묶음** (체계·재사용) | 가지별 엔진 사슬(G2/G3) | 가지당 2~3 × 4가지 ≈ **10** | 자원축 4개 공유 풀 ≈ **8~10** (무기 수에 *선형 비례 안 함*) | ★상당수 *자원축 단위 공유*(킬축 환류=킬축 가지 전부 공유) | SoD Exodia·Hades Duo·Gunfire Gemini |
| **연료** (템플릿, 많아 보이나 손설계 0에 가까움) | 가지별 방향 +%(`EffectKind`+`branchTag`) | 가지당 3~4종 (템플릿) | **1세트 템플릿** 재사용 | ★`EffectKind`+가지 태그 *템플릿화* = 손설계 거의 0 | Halls of Torment·Brotato 스탯 |
| **합계 (손설계 단위)** | | **≈28장** | **≈55장 + 연료 템플릿 1세트** | ★늘어나는 쪽(연료·시너지)이 *재사용*이라 무기 수에 선형으로 안 큼 | Hades("authored 소수, 다양성은 조합") |

★**왜 이게 옳은가 (레퍼 3중 확증)**:
- **Hades**: 무기6×Aspect4 = authored 핵심 *소수*, 무한 다양성은 boon *조합*. → 카드 수로 깊이 만들지 않는다.
- **20 Minutes Till Dawn**: 레벨업 5택, 무기 진화는 *레벨20에 1회 3택*. 소규모 authored로 충분히 깊다.
- **Death Must Die**: 런당 *신 3명까지만* = 드래프트가 *집중 게이트*. 빌드 쏠림이 곧 정체성. → 카드 풀이 커도 *한 런에 보는 건 소수*.

> ★**솔로 개발 정당화**: 데모는 **검+드론 1슬라이스(직접타격↔컨트롤 양극)** = 손설계 ~28장이면 작동 검증 끝. 풀게임도 ~55장 *손설계*(연료는 템플릿) = Balatro(150)·StS(클래스당 75)보다 *적다*. 이게 가능한 이유 = 우리 깊이가 *카드 수*가 아니라 *6무기×2트리×시너지 사슬*에서 나오기 때문(레퍼 본진과 동일).

### 2.2 ★결정 ② 드래프트 알고리즘 — 3택 + 열린 트리 자격 게이팅 (등급 주사위 없이)

우리 "열린 트리"(prereq 가지, 트리 모양이 카드 데이터에서 저절로 그려짐)와 *드래프트 제시*를 어떻게 맞무느냐가 핵심. **답 = "트리가 *자격 풀*을 정하고, 드래프트는 그 풀에서 3장 뽑는다."**

**알고리즘 (의사 흐름)** — ★v2.0: ①숫자 등급 롤 + ③신화 풀 RNG 끼어듦 추가:
```
레벨업 발생
 → 0. ③신화 게이트 (먼저 굴림 — 잭팟이 자리를 *대체*)
      · 신화 출현 확률 p_myth = base + k·(처리평가 누적 화려함=돈)   ← ★화려함=돈 가중
        (= Brotato Luck이 상위티어 미는 레버를 *처리평가*가 대신)
      · 런당 캡(예: 최대 2~3회) + 직전 출현 후 쿨다운(연속 폭발 방지)
      · 적중 시 → 제시 3장 중 *1슬롯*을 신화 풀(트리 밖)에서 뽑은 신화 카드로 치환
        (Balatro Legendary 조커가 팩에 *드물게* 끼는 모델)
 → 1. 자격 풀 산출 = 지금 prereq 충족한 노드 전부
      · 뿌리(prereq 없음)는 런 시작부터 자격
      · 분기/잎(②)은 부모 노드 보유해야 자격 (= 열린 트리 = PoE 경로 할당, 결정론)
      · 시너지 사슬(G3)은 requires 충족 시 자격 (= Hades Duo "둘 다 보유")
 → 2. 가중 (트리 위치 가중 = ②정체성용, 주사위 아님):
      ⓐ 선택 무기 시그니처 가중 (isSignature) — 내 무기 가지가 더 자주
      ⓑ 연료:정체성 비율 — 초반 연료↑(스노볼 시동), 후반 정체성↑(verbWeightByLevel 0.25→0.60, Hades 곡선)
      ⓒ 미보유 우선 약가중 (중복 연료 범람 방지 — StS pity의 약한 친척)
 → 3. 3장 뽑아 제시 (코드 Draw(3))
 → 3b. ①숫자 등급 롤 — *연료/시너지 카드 인스턴스*에 Common/Rare/Epic 부여 (정체성 불변, 수치만)
        (= Hades 레어도 "숫자만 커짐"·StS pity 곡선 적용 가능 / 잎②·신화③에는 ❌)
 → 4. 1택 → 트리에 반영 → 다음 레벨업의 자격 풀이 *저절로 넓어짐*
```

★**세 등급 축이 알고리즘에서 *다른 단계*에 사는 게 핵심**: ③신화는 *0단계 게이트*(슬롯 치환), ②정체성은 *1·2단계 자격·위치*(결정론), ①숫자는 *3b 인스턴스 롤*(파워만). 한 단계가 다른 단계를 못 건드리므로 충돌 0. ★①숫자 등급은 *연료·일반 시너지 카드에만* 붙고, ②잎과 ③신화에는 절대 안 붙는다(잎=결정론 도달, 신화=출현 자체가 이벤트).

★**레퍼 근거**:
- **PoE 노드 위계**: Small=*prereq 경유점*, Notable=정체성, Keystone=규칙변경. → 우리 자격 게이팅(부모 보유=자격)이 PoE 경로 할당과 동형. "열린 트리"가 곧 PoE 트리의 인-런 버전.
- **Hades**: 3택 1 + Legendary/Duo는 *prereq*(보유 누적) 잠금. → 우리 잎/시너지 사슬 자격이 동일 구조.
- **`verbWeightByLevel` 0.25→0.60**(코드 기존): 초반 연료(스노볼)→후반 정체성(스파이크) 가중 변화 = 런 진행 가중. ★*이미 코드에 절반 있음*.

**리롤/배니시/락**:

| 장치 | 권고 | 레퍼 근거 |
|---|---|---|
| **리롤** | ★**보편 ❌ → 소비/메타 자원** (메모리/현금 소비 or 캐릭터 특성) | 20MTD(Shana 고유 특성)·Halls of Torment(포션)·Hades(Dice=소모) — *보편 무한 리롤은 긴장을 죽인다* |
| **배니시** | 데모 ❌ (풀게임 메타 해금 후보) | Hades(특정 boon 제거)·Brotato(상점) — *후순위* |
| **락** | ❌ (트리 자격이 이미 "다음에 뭐 뜰지"를 예측 가능하게 만듦 — 락 불필요) | PoE(트리는 *계획*이 가능 = 락의 역할을 구조가 흡수) |

> ★**핵심 (v2.0 갱신)**: *정체성*에는 주사위가 없으니(②잎=결정론) 트리 자격이 "다음에 뭐가 열릴지"를 *예측 가능*하게 한다(PoE의 "계획하는 재미"=보편 리롤이 필요 없는 이유). 단 ①숫자 등급은 주사위가 있으므로 **StS pity 곡선(Rare 확률 누적·뜨면 리셋)을 *①에만* 적용**해 "계속 Common만" 꽝감을 막는다. ③신화의 꽝감(Codex가 지적한 "Legendary 떴다 도파민 손실")은 *런당 캡·쿨다운*으로 관리(매번 안 떠야 떴을 때 잭팟). 두 주사위(①숫자·③신화)가 *정체성 결정론*(②)을 못 건드리는 게 설계의 안전장치.

### 2.3 ★★결정 ③ 등급(레어리티) 시스템 — ✅ **유저 확정: 3종 하이브리드** (각자 다른 도파민 층)

> ⚠️ **v2.0 대전환**: v1.0은 "카드 레어리티 = NO"를 권고했다. **유저가 이를 *기각*하고 3종 하이브리드로 확정**했다(오케 종합 = gd↔Codex 충돌 해소). 아래는 그 확정 구조와 *왜 충돌이 안 나는가*의 재정합. 옛 "NO" 논거의 **틀린 전제 두 개를 폐기**한다:
> 1. ~~"트리 게임은 무등급"~~ → **틀림. SoD가 에센스를 common/flawed/rare/legendary로 등급화**(§1.1 정정). 트리형이어도 *파워 등급*은 산다.
> 2. ~~"등급 2개면 충돌"~~ → **각자 *다른 것*을 등급화하면 안 싸운다**(Balatro 3직교축이 증거). 충돌은 "같은 축을 두 번 등급화"할 때만.

**핵심 reframe = 질문이 "등급을 넣나 마나"가 아니라 "등급이 *어디* 사느냐"다.** 카드 "특별함"을 *세 개의 서로 다른 도파민*으로 분리하면 각 도파민이 다른 층에 살아 서로를 안 잡아먹는다:

| 층 | 무엇을 등급화하나 | 도파민 종류 | 메커니즘 | 결정/주사위 | 레퍼 |
|---|---|---|---|---|---|
| **① 숫자 등급** (Common/Rare/Epic) | *카드 인스턴스 파워* | 잦은 작은 도파민 | 일반 카드(연료·시너지) 제시 때 *숫자만* 롤. **정체성 불변** | 주사위(①) + StS pity | Hades 5단·SoD 에센스·StS |
| **② 전설 잎 + 변형** | *정체성·빌드 깊이* | 빌드크래프트 도파민 | 트리 종착 잎에 *도달*(결정론) → 변형 갈래 → 재분기 | **결정론(주사위 0)** | PoE 키스톤·VS 진화·Hades prereq |
| **③ 신화 와일드카드** | *새 메커니즘 출현* | 잭팟 도파민 | 트리 *밖* 별도 풀. *완전 새 명사/동사* | **가끔 RNG, 화려함=돈 가중** | Balatro Legendary·Hades Hex·PoE 유니크 |

**★왜 충돌 0인가 (세 등급 시스템이 각자 다른 것을 등급화)**:
- **처리평가 S~D** = *런 경제*를 등급화(화려한 처형 → 성과급, [[project_2026_06_13_growth_economy_direction]]).
- **①숫자 등급** = *카드 인스턴스 파워*를 등급화(이 연료가 +5%냐 +9%냐).
- **③신화 게이트** = *새 메커니즘 출현*을 게이트(잭팟이 가끔 뜬다).
- → **세 축이 *다른 질문*에 답한다** → 충돌 0, 오히려 **스택**: 처리평가↑ → ③신화 확률↑ → 더 화려한 처형 → 처리평가↑ (양의 피드백 루프 = 뽕 에스컬레이션, [[feedback_pong_over_systematization]] 정합).
- ★**Codex vs gd 충돌이 여기서 풀린다**: Codex "Legendary 떴다 도파민 손실"(결정론 잎엔 잭팟감이 없다는 지적) = **③신화가 메운다**(가끔 RNG 잭팟). gd "결정론 빌드크래프트가 더 뽕"(운으로 Epic 뜨는 것보다 사슬 쌓아 도달) = **②잎이 보존한다**. 둘이 *다른 층*이라 둘 다 가질 수 있다 — 이게 하이브리드의 승리.

#### ② 전설 잎 + 변형 패턴 (잎 → 변형 → 재분기) — 명세

②의 핵심은 *잎에 도달한 뒤에도 빌드크래프트가 계속된다*는 것. PoE 키스톤을 먹은 뒤 그 키스톤 *주변에 또 노드*가 있는 구조. **잎 1개 = 결정론 도달 1번 + 변형 선택 1번 + (변형 안에서) 재분기 1번.**

```
[종착 잎 도달] (결정론 — 트리 사슬 다 차면 자동 자격)
   └→ [변형 갈래] 선택 (3택 1, 잎의 *발현 방식*을 가름 — 정체성 분기, 주사위 아님)
         └→ [재분기] (변형 안에서 또 1택 — PoE 키스톤 뒤 노드)
```

★**예시 — 카타나 거합 종착 잎 [돌파 사출 = 벽력일섬]** (§17.1.D, 유격 절단 "치고빠지기"):
- **도달**: 거합 가지 사슬(정지 충전↔처형 환류)을 끝까지 차면 [벽력일섬] 자동 자격 (결정론).
- **변형 갈래 (3택 — 벽력일섬을 *어떻게 터뜨리나*)**:
  - **[중심 과부하]** — 돌파 *관통선 중앙*에 에너지 응축, 라인 한가운데가 2배 데미지 + 짧은 폭발. → *밀집 코어 분쇄*형(호드 한복판 꿰뚫기).
  - **[귀환 라인]** — 돌파 끝에서 *시작점으로 되돌아오는* 2차 사출(왕복 절단). → *왕복 학살*형(들어갔다 빠지는 치고빠지기 극대화, i-frame 2회).
  - **[2차 기폭]** — 관통선이 짧은 지연 후 *라인 전체 동시 폭발*(MGR 잔타츠 환류와 결선). → *지연 광역*형(꿰뚫고 빠진 뒤 라인 전체가 터짐).
- **재분기 (변형 안에서 또 1택, 예: [귀환 라인] 선택 시)**:
  - [왕복 가속] (왕복마다 다음 돌파 쿨다운↓ = 연쇄 가능) ↔ [왕복 환류] (왕복 킬마다 충전 게이지 환원 = 거합 사이클 가속).

→ **잎 1개가 *9가지 발현*(3변형 × 3재분기 근사)으로 갈린다.** 이게 ②의 빌드크래프트 깊이 — 같은 [벽력일섬]이라도 *내가 어떤 거합 빌더인가*에 따라 다르게 핀다. ★per-잎 변형 *전면 작성*은 후속(§17.1.D 갱신=별건). 여기선 *패턴*과 예시 1개만 못박는다.

★**결론**: **카드 레어리티 = 3종 하이브리드.** ①숫자가 파워를, ②전설 잎+변형이 정체성·빌드크래프트를, ③신화가 새 메커니즘 잭팟을 책임진다. 세 도파민이 다른 층에 살아 충돌 0·스택. (옛 Q-A2 "Balatro 직교 연동"은 ③신화의 화려함=돈 가중으로 *흡수*됐다 — 처리평가가 카드 수치가 아니라 *신화 확률*을 민다.)

### 2.4 ★결정 ④ 전체 방향 (한 줄)

> **"열린 트리 + 레벨업 3택 드래프트 — 카드 *특별함이 세 도파민 층으로 분리*된다. ①숫자 등급이 *잦은 파워*를, ②전설 잎+변형이 *결정론 빌드크래프트*를, ③신화 와일드카드가 *RNG 잭팟(화려함=돈 가중)*을. 세 층이 *각자 다른 것*을 등급화하므로 충돌 0이고, *서로 다른 도파민*이라 한 층이 다른 층을 안 잡아먹는다. 운(③)도 빌드크래프트(②)도 *둘 다* 가진다."**

레퍼 추적 요약: **Hades 5단 레어도/SoD 4단 에센스**(①숫자=인스턴스 파워, 정체성 못 만듦) + **PoE 키스톤 뒤 노드/VS 진화**(②잎 변형=결정론 빌드 깊이) + **Balatro Legendary 조커/Hades Hex/PoE 유니크**(③신화=가끔 RNG 새 메커) + **Brotato Luck 레버**(③ 화려함=돈이 등장 확률을 미는 레버) + **Balatro 3직교축**(여러 등급이 서로 다른 것을 등급화하면 충돌 0) — 전부 우리 익스트랙션·화려함=돈·뽕 북극성에 정합.

## 4. ★판정 포인트 (유저가 누를 갈림 — 여기가 보고서의 목적)

> 🟡 = 유저 결정. 권고는 달았으나 *동결은 유저*. ★Q-A는 유저 확정으로 닫힘 — 남은 골격 = Q-B·Q-C·**Q-F(신화 노브)**.

- ✅ **Q-A — 등급(레어리티) 시스템** → **유저 확정 = 3종 하이브리드 (닫힘).** ①숫자 등급(인스턴스 파워)·②전설 잎+변형(결정론 빌드크래프트)·③신화 와일드카드(RNG 잭팟, 화려함=돈 가중). 세 축이 각자 다른 것을 등급화 → 충돌 0·스택. *판정 불요* — 구조 정합·레퍼 추적은 §2.3에서 확인 완료.

- ★**Q-B — 카드 총 개수 = Hades급 소수 정예?** → **권고 🟢** 데모 ~28 + 신화 2~3 / 풀게임 ~55 손설계 + 연료 템플릿 + 신화 ~8.
  근거: 깊이는 카드 수 아니라 *조합/시너지*(SoD·Hades·VS 본진). ↔ *판정*: 이 규모가 "충분히 다양"으로 느껴질지 vs 더 크게? (트리 크기는 솔로 비용 직결 — §17 Q30와 같은 게이트. ★신화는 *소수 정예*가 핵심 — 많으면 잭팟감 죽음.)

- ★**Q-C — 리롤 = 보편 ❌ → 메타/소비 자원?** → **권고 🟢.**
  근거: 보편 무한 리롤=긴장 죽음(20MTD Shana 고유·Halls of Torment 포션·Hades Dice 소모). ↔ *판정*: 데모에 리롤 *아예 없음* vs 소량 자원 리롤? ★주의: 리롤이 ③신화 슬롯을 *다시 굴리게* 하면 잭팟감이 희석된다 → 리롤은 *일반 카드만* 대상, 신화 슬롯은 리롤 면제(또는 신화 전용 고비용 리롤) 권고.

- ★★**Q-F — ③신화 빈도·캡·등장확률 곡선 (신규 핵심 노브)** → **권고 🟡 노브 세션.** 골격 4파라미터:
  - **base 확률** (처리평가 0일 때 신화 출현 기저율 — 권고 시작값 *낮게*, 예: 레벨업당 2~4%).
  - **화려함=돈 가중 k** (처리평가 누적당 확률 가산 — "S 처형 폭발 후 다음 레벨업에 신화 잭팟" 체감이 목표).
  - **런당 캡** (권고 2~3회 — 매번 뜨면 잭팟 아니라 일상이 됨, 희소성이 가치).
  - **쿨다운** (직전 신화 후 N레벨 면역 — 연속 폭발 방지).
  ↔ *판정*: 곡선이 "가뭄 끝 단비"(거의 안 뜨다 처리평가 폭발 시 터짐)인가 vs "꾸준히 가끔"인가? ★유저 인더루프 노브 세션 전제("30분에 신화 몇 번"을 손으로).

- **Q-D — 드래프트 가중 3축(시그니처·연료:정체성 비율·미보유 약가중) OK?** → 권고 🟢 (코드 `verbWeightByLevel` 이미 보유). ↔ 판정: 초반 연료↑→후반 정체성↑ 곡선이 우리 런 길이(노브)에 맞나?

- **Q-E — 분기/잎 자격(prereq) = "열린 트리" 그대로?** → 권고 🟢 (PoE 경로 할당 = 트리 모양이 데이터에서 저절로). ↔ 판정: 분기 선택을 *게이트 이벤트*로 격상(20MTD 레벨20 모델)할지 = LevelDesign 페이싱 경계(§17 Q32와 연동).

- **Q-G — ①숫자 등급에 StS pity 곡선 적용?** → 권고 🟢 (계속 Common만 꽝감 방지, *①에만*). ↔ 판정: pity 강도(StS는 +1%/Common, +40% 상한). 데모에 필요 vs 풀게임 후순위?

> ★**남은 골격 = Q-B(개수) + Q-C(리롤) + Q-F(신화 노브).** Q-A(등급)는 확정으로 닫혔다. ②전설 잎 *per-잎 변형 전면 작성*은 §17.1.D 갱신=별건(후속 임무).

## 6. ★③ 신화 와일드카드 풀 드래프트 (DO 2)

> **신화 = *완전 새 명사/동사*.** ①숫자(파워 +%)도 아니고 ②변형(기존 잎의 발현 가름)도 아니다 — *지금까지 게임에 없던 메커니즘 한 덩어리*. 트리 *밖* 별도 풀. 화려함=돈 가중 RNG로 가끔 끼어들어 *런을 뒤튼다*. ★레퍼: **Cyberpunk 2077**(모노와이어·만티스 블레이드=실물 사이버웨어 결) · **PoE 유니크**(빌드를 *재정의*하는 한 아이템) · **Hades Legendary/Hex**(드물고 큰 한 방) · **Balatro Legendary 조커**(0.x% 초희귀 새 규칙). ★**솔로 비용 = 신화 *소수 정예*(데모 2~3) — 각이 새 코드라 비싸다.** 결=사이버펑크 실물 테크(만티스·모노와이어·관통선), 이름=*가제*(Story 렉시콘 후속 의뢰).

### 6.1 데모 신화 (검+드론 슬라이스 — 2~3개)

#### ★M-1 [전개식 모노필라멘트] (가제) — 유저 시드, 정제 (데모 ★앵커)
- **새 동사 = "설치 후 일괄 회수"**. 트리에 *설치형*은 없다(우리 동사 클래스 어디에도 없음) → 완전 새 메커.
- **메커니즘**:
  1. **이동기 지점마다 와이어 설치** — 대시·돌파(②벽력일섬·드론 재배치·플리커 블링크 등 *모든 이동 동사*)가 끝나는 지점에 모노필라멘트 와이어를 *자동 설치*(점 사이가 와이어로 이어짐).
  2. **5개+ 설치 시 전체 *회수*** — 와이어가 임계(예: 5개) 쌓이면 다음 입력 또는 자동 트리거로 *전체 와이어를 동시에 거둬들임*.
  3. **와이어 존 내 대상 *순삭*** — 회수 순간, 와이어가 그은 *폐곡선/선분 안에 든 모든 적*이 절단(즉살, 고위협체는 큰 비례 데미지). ★처형 연출 = 화면을 가르는 와이어 그물 + 동시 슬라이스(처리평가 폭발).
- **빌드 시너지 (어떤 플레이가 빛나나)**: ★**기동 빌드**(대시 몰빵·플리커 참격·드론 재배치)가 *이동 자체를 무기화*. 많이 움직일수록 와이어가 촘촘 → 회수 학살이 커짐. = "도망/포지셔닝이 곧 사형선고 그물 짜기". 정적 빌드(거합 정지충전)와는 *상극* → 빌드 정체성을 가른다(트레이드오프 내장).
- **등장 조건**: 화려함=돈 가중 RNG(§2.2 0단계). *기동 메모리 다수 보유* 시 약가중(빌드와 시너지 있을 때 더 잘 뜸 = Hades Duo 정신).
- **★제작 비용 플래그**: 🔴 **높음** — 와이어 설치 추적(이동 궤적 노드)·폐곡선/선분 내 적 판정(기하)·동시 슬라이스 VFX = 전부 신규. *데모 앵커지만 가장 비싼 한 장* → 신화를 *이거 하나만* 데모에 넣고 나머지는 싸게 가는 선택지도 검토(Q-F2).

#### M-2 [만티스 폭주 / 잔영 도살] (가제) — 검 슬라이스용
- **새 동사 = "처형 시 분신 소환"**. 처형(화려한 킬) 1회마다 *지난 N초간 내 이동 궤적*을 따라 도는 *잔영(분신)* 1기 소환 → 잔영이 *내 직전 공격을 자동 반복*(짧은 수명).
- **빌드 시너지**: ★**처형 리듬 빌드**(거합 환류·참격 연쇄)가 빛남 — 처형이 잦을수록 잔영 군단. 화면이 *나+분신들의 동시 베기*로 차오름(파워판타지 절정). 드론(고위협 컨트롤)과도 결선: 분신이 드론 표적을 같이 침.
- **등장 조건**: 화려함=돈 가중 + *처형 카운트 누적* 시 약가중.
- **★제작 비용 플래그**: 🟡 **중** — 잔영=내 직전 클립 재생 + 짧은 수명 AI. Animation 에이전트 협업(잔영도 "한 동작만 돈다" 헌법). 궤적 기록은 M-1과 *코드 공유 가능*(둘 다 이동 궤적 추적) → 묶어서 만들면 비용 절감.

#### M-3 [과적 청구서 / 압류 집행] (가제) — 디제틱 결, 드론 슬라이스용
- **새 동사 = "표식 누적 → 일괄 폭발 정산"**. 드론/공격이 적에게 *압류 표식*을 쌓음(킬 안 해도 누적). 표식 임계 도달 or 처리평가 정산 트리거 시 *표식 단 모든 적이 동시에 "정산"(폭발+즉살)* — 표식 많을수록 연쇄 폭발 광역↑.
- **빌드 시너지**: ★**고위협 컨트롤 빌드**(드론 마킹·area-denial)가 빛남 — 안 죽이고 *표식만 발라두다 한 번에 수금*. 세계관 결(사후처리부 "정산"·"압류")과 디제틱 정합 = Story 렉시콘 강한 후보.
- **등장 조건**: 화려함=돈 가중 + *드론/마킹 메모리 보유* 시 약가중.
- **★제작 비용 플래그**: 🟢 **낮음(상대적)** — 표식 카운터 + 임계 시 일괄 트리거(기존 처형 버스트 VFX 재사용 가능). *데모에서 가장 싼 신화* → M-1이 너무 비싸면 이걸 데모 2번째로.

> ★**데모 권고 = M-1(앵커, 비싸도 시드라 박음) + M-3(싸고 디제틱).** M-2는 비용/시간 여유 시. *3개 다*는 솔로 일정 부담 → Q-F2 판정.

### 6.3 ★신화 설계 가드 (자기검열)

- **뽕**: ③의 단일 판정 = *잭팟감*(떴을 때 "와")이지 분류 깔끔함이 아니다([[feedback_pong_over_systematization]]). M-1 회수 학살·M-2 분신 군단=화면이 화려함으로 폭발 = 뽕. *조건/캡은 잭팟을 *희소*하게 만들 뿐, 메커니즘 자체는 화려해야*.
- **단순성·솔로 비용**: 신화 *소수 정예*(데모 2~3, 풀게임 ~8). 각이 새 코드라 *남발 금지*. M-1/M-2 궤적 추적, M-3/혈채 누적-청구는 *코드 공유*로 묶어 비용 절감.
- **over-systematization 경계**: 6.2 표가 "무기별 잭팟 천장"으로 *분류*처럼 보일 수 있으나 — 각 칸이 *학술 분류*가 아니라 *그 빌드 극단의 화려한 한 방*(유저 직접 판정 대상). 표는 *시드 목록*이지 freeze 아님.
- **재제안 블랙리스트 검사**: 스텔스/은신 ❌(M-1=공격적 그물, 도망 아님)·소비형 레시피 ❌(신화=영구 메커, 소비템 아님)·차량 ❌. 통과.
