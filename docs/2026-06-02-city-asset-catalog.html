도시 배치용 원자재 카탈로그

ZombieCrush · 작성 2026-06-02 · 목적: Claude+Codex가 이 문서만 보고 도시를 자율 조립할 수 있게 하는 참조. "무엇이 있고 / 어떻게 쓰고 / 어떻게 붙이나".
이미지 = 각 팩 내장 데모 씬을 제작자 쇼케이스 카메라로 캡처(docs/city_catalog/img/). 수치는 에이전트가 프리팹 YAML/FBX 정점 직접 검증, 미검증은 추정 표기.

TL;DR — 먼저 알아야 할 3가지

  1. 두 에셋 군은 못 섞는다. Synty 계열(플랫셰이딩·아웃라인 없음·2.5m 약수 그리드) vs Toon City(아웃라인+셀셰이딩·12m 그리드). 한 화면에 섞으면 아웃라인 유무로 즉시 튄다 → 주력 1개 선택 필요.
  2. 완성 외벽 건물이 귀하다. Synty 쪽은 Battle Royale 12채(통짜), Construction=골조뿐, Nightclubs=실내편향 셸 36, Generic=Base 키트. Construction의 "도시 데모"는 우리가 안 가진 POLYGON City/Town 프리팹을 잔뜩 참조(미싱 프리팹 다수) → 멀쩡한 고밀도 도심을 원하면 가진 것만으론 부족, "공사중단/폐허/외곽" 컨셉으로 가야 자재가 맞는다.
  3. 실제 Light가 없다. 네온·조명은 전부 에밋시브 메시 → "빛=텔레그래프" 무드는 우리가 URP Light + Bloom을 직접 얹어야 함.

핵심 분기 — Synty 군 vs Toon City 군

조사 결과 도시 주력 스타일이 갈린다. 이게 블록 크기·코드(chunkSize)·캡처 방향까지 좌우한다.

여정 구조 (2026-06-02 확정)

외곽(집/차고, 평원 옆) → 중심으로 돌파 → 보스가 차 부품 드롭 → 집 귀환 후 차 타고 평원 탈출

  • 평원은 차 전용 — 도보로 못 건넌다. 그래서 "그냥 평원으로 도망가면 되잖아?"가 막힌다.
  • 차(부품)는 도시 심장부에 있다 → 탈출하려면 일부러 가장 위험한 중심으로 파고들 수밖에 없음 (자발적 위험 감수의 동기).
  • 권위 문서(2026-05-31) 대비 난이도 그라데이션만 뒤집음: 중심=원점=최난도=보스. 집(외곽)=시작=최저난도=회복거점=최종 탈출구.

→ 따라서 도시는 "무한 격자 스트리밍"이 아니라 경계 있는(~반경) 여정 = 장소들의 도시로 설계. 모듈 조각은 레고로 쓰되 격자로 깔지 말고 불규칙·붕괴 형태로 조립.

갭 — 가진 것만으론 안 되는 것 (주의)

  • 완성 외벽 고밀도 도심 — Synty 쪽 완성 건물이 부족. Construction_City_Demo는 우리가 없는 POLYGON City/Town 프리팹(SM_Bld_Apartment, SM_Env_SubwayEntrance, SM_Veh_Firetruck 등)을 대량 참조 → 미싱. 우리 자재로는 "공사중단·폐허·외곽 산업" 톤이 자연스럽다.
  • 실제 조명 0개 — 네온/사인/조명기구 전부 에밋시브 메시. 빛 번짐·동적 텔레그래프는 URP Light + Bloom을 직접 부착.
  • 거리 가구 빈약 — Synty엔 가로등·신호등·소화전·펜스가 거의 없음. StreetProps(23) + Nightclubs/Western 소품으로 보충.
  • 탑다운 천장 컬링 — 모듈 건물의 천장은 3/4 시점에서 실내를 가림 → 빌더가 천장 생략/컬링.

Toon City 목적형 도시 · 모듈러 최고

스타일: Toon/CustomToon 셰이더(다크 아웃라인 _OutlineWidth 0.0065 + 셀 음영 램프). URP. 스케일: 1:1, 핵심 모듈 12m. 프리팹 555 (Roads 111 / Buildings 93 / Props 91 / Industrial 71 / Vegetation 61 / Pavement 57 / Advertising 35 / Vehicles 29).

★ 모듈러 결합 규칙
• Roads = 진짜 12m 모듈러 도로 키트: 12×12m 타일, XZ중앙 바닥 피벗, 90° 회전으로 직선/코너/T/교차/곡선 결합. 변형 Road_1x/2x/3x/_Squared/+2/+4/-2, Highway(20×80m), Roundabout(28m).
• Pavement = 1/2/4/8m 보도 타일(_1x1만 코너 피벗) → 가변폭 인도.
• Buildings = 통짜 프리셋(모듈러 아님), 단 footprint가 12m 그리드 정렬(12·24·28m). Skyscraper는 야간 발광 창 메시 분리.
판정: 도로 모듈러 완성도·문서화가 자율조립에 최적. 단 ① 12m라 80m 블록은 84m로 재정의, ② Synty와 비혼용(아웃라인 충돌). 다크 스텔스로 쓰려면 재라이팅/포스트로 아웃라인·채도 제어 필요.

Generic 도시 토대 (도로·보도·Base건물)

스타일: URP ShaderGraph 플랫셰이딩(Generic_Basic, Bloody 변종=좀비향). 1u=1m. 프리팹 490 (Environment 220 / Props 107 / Base 72 / Building 25).

★ 모듈러 결합 규칙 (검증된 수치)
• 차도 10m 그리드: Road_01(10×10), Half(5×10), Small(5×5), Intersection, Crossing(횡단보도), Parking, Ramp(+3m 입체). 코너 피벗, Y축 90° 회전. ⚠ Road_Gravel은 비정형 → 정형 도심 금지.
• 보도 2.5m 그리드: Sidewalk_01(2.5²), Corner(연석 0.15m), Edge(0.18m). 차도와 4:1 정합.
• Base 건물 키트 2.5m / 3.0m 층고: Floor/Wall/Wall_Door/Wall_Window/Pillar/Stairs/Ceiling/Roof. 변형 _Half/_Quarter/_45/_Corner_In/Out/_Destroyed. 벽=1층=3m, 코너 라인 피벗.
판정: 도심 "바닥·경계·토대"를 정확한 2.5m 약수 그리드로 완벽 커버. _Destroyed 벽·Bloody 셰이더로 폐허 직결. 단 거리 소품·차량·식생은 없음 → 타 팩 보충.

Battle Royale 스텔스 차폐물 · 외곽 건물

스타일: 플랫셰이딩 단일 아틀라스, 1u=1m, URP. 프리팹 373 (Props 91 / Environments 43 / Vehicles 22 / Buildings 12).

★ 모듈러 결합 규칙
• 도로만 진짜 모듈러: Road_Straight/Corner/T/Cross/Damaged + DirtRoad. 직선 20×5 등(정사각 아님), 피벗·타일 간격 미검증.
• 펜스/벽 선형 모듈: WireFence, Cinderblock_Wall, BaseWall+Post+Broken, Range_Wall(+Half/Door/Window).
• 건물 12채 = 통짜(House/Warehouse/SmallBuilding/Shack/Tent) — 모듈 조립 X, 빈칸에 통째 배치.
판정: Props 91(컨테이너·펜스·드럼·변압기·버려진 차량)이 탑다운 스텔스 엄폐·시야차단의 1급 자재. 군용 편향이라 도심엔 선별 사용, 건물은 외곽/산업지구에 적합.

Construction 공사중단/폐허 무드

스타일: 플랫셰이딩 단일 머티리얼, 1u=1m, URP. 프리팹 584 (Props ~300 / Buildings 74 / Environments 36). 완성 외벽 없음 = 골조 키트.

★ 모듈러 결합 규칙 (2개 시스템, 그리드 다름)
• House 2.5m / 3.0m층: House_Wall(/Window/Door), Corner 포스트, Ceiling(y=3 내장), Truss.
• Concrete Frame ≈3.13m: ConcreteFrame_Wall/Pillar, ConcreteRebar_Wall(노출 철근=공사중 룩), Concrete_Floor. House와 그리드 불일치 → 한 건물=한 시스템.
• 옹벽 Retainer_Wall(Corner/Angled/End 변형) = 블록 경계/단차. 랜드마크: WaterTower/Crane/SmokeStack.
• 완성 예시는 Scenes/Construction_House_Demo.
판정: "공사중단 도시·폐허" 컨셉이면 강력(철근 골조+크레인+타프). "멀쩡한 도심"이면 부족. Props 펜스/배리어/스캐폴드/floodlight = 스텔스 차폐.

Nightclubs 네온·밤도시 외관 · 모듈 셸

스타일: 플랫셰이딩, 1u=1m, URP. 프리팹 837. "모듈러 140"의 실체: Props/Modular(124)는 실내 가구, 진짜 건물 모듈은 Base_Buildings(36).

★ 모듈러 결합 규칙
• Base_Buildings(36) = 외벽 셸: Wall(/Glass/Window/Door) + Half/Quarter + Pillar + Floor/Ceiling + Stairs. 벽 4m추정/층고 3m추정, 90° 회전.
• Buildings(104) = 외관 디테일: FireEscape(밤 골목 최강), Awning, Railing, Steps, Window_Bars(쇠창살=서바이벌).
• 네온/조명: Neon_Shape×8, 클럽사인 다수, Light_String/Strip/Tube, FX Laser/Fog/Spotlight. 전부 에밋시브 — 실제 Light 0개.
판정: "빛=텔레그래프" 무드의 최강 보급원(네온30+/조명30+/FX20). 단 실내 편향 + 셸 36개라 외벽 다양성 제한 → 외부 디테일·조명 위주 차용. 빨강 에밋시브 펄스(DOTween)로 위험 텔레그래프.

Western 80% 폐기 · 소품만

스타일: 플랫셰이딩, 1u=1m, URP 변환 완료, Synty 호환(단 사막 세피아 팔레트 — Alt 머티리얼로 채도 조정).

  • 건질 것: 배럴/상자/자루/목재더미/사다리·로프, 바위/먼지더미/죽은 나무(아포칼립스), 목제 가구, 랜턴(광원 소품), FX_BloodSplat(좀비물 직접).
  • 버릴 것: 살룬/감옥/교회/기차역 건물, 카우보이/총잡이, 마차·증기기관차, 선인장·간판·교수대 등 서부 전용.
판정: "소품 라이브러리 보충용"으로만 등록. 건물/캐릭터/차량/간판은 조립 후보에서 제외.

다음 단계 — 장소 → 에셋 → 그림 판정

이 카탈로그로 이제 "어떤 도시인가 / 각 장소에 무엇을 / 그 장소의 그림은" 판정에 들어간다. 흐름:

  1. 주력 스타일 확정 (위 §핵심분기) — Synty 군(80m) vs Toon(84m). → 블록 크기·코드 확정.
  2. 도시 정체성 한 줄 — 이미지들을 보고 "이 재료로는 이런 도시"를 판정.
  3. 장소(district) 배정 — 여정(외곽→중심)에 장소를 배치하고, 각 장소에 위 에셋을 매핑.
  4. 장소별 그림 — 레퍼런스(Darkwood/Hell Express 보드) × 우리 에셋 × 지배색·라이팅 판정.
