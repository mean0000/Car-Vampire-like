## 0. Layer 0 정체성 (★2026-07-02 유저 동결 — 문장+3원칙 v1.1)

> **"사후처리부 — 처리는 실적이다. 후퇴하면 실적이 마르고, 파고들어 처리할수록 회사가 너를 먹여 살린다. 회사가 '효율'이라 부르는 것이, 네 화면에서는 간지다."**

무기불가지론 3원칙 **v1.1** (모든 무기가 자기 방식으로 표현해야 함 — Codex 반증 조건 4건 반영):
1. **전진이 공간을 만든다** — 공격은 전진권. 카이팅은 금지가 아니라 열등한 선택. ★전진=거리 축소가 아니라 **위험을 감수한 위치 개선(각·선 점유)**: 카타나=절단선 진입 / 대검=박아 넣는 진입(고정 포탑 ❌ — 차징 중 전진·타격 후 밀림 필수) / 권총=**사선 점유**("가까워지는 권리"가 아니라 "좋은 총선으로 이동할 권리" — 근접 강제 ❌) / 드론=아래 크레딧 제한.
2. **적의 커밋은 위협이 아니라 기회다** — 읽고-처리하면 크게 터진다. 정밀 타이밍 입력 요구 ❌(타이밍-듀얼 기각 준수) — 타이밍은 적이 만든다. ★크레딧 제한: 드론은 자율 딜러 ❌ — **플레이어가 만든 판(조준선·마킹·위치·태깅)의 실행자**. 화면 밖 자동 처리에 실적 크레딧 금지.
3. **화려함 = 실적 = 생존** — 처리평가가 돈·회복을 구동. 디제시스: 회사는 "효율"이라 부른다(간지 라벨 ❌ — 2026-07-02 유저 판정). ★실적=생존의 **가속기이지 생존권이 아님**: 저실적에서도 기본 회복 루트·기본 관대함·기본 픽업 유지(나선 하강 방지 — 저점 안전망).
