## 1. Caniathrox (LV2 · 4족 근접 추격형) — ✅ PASS

**채점:** Codex 8.07(PASS) · LevelDesign 리드 v2 8.53/리드7.5(간발) → v3에서 리드 사전합격조건(cross-pack 아비터) 충족 → PASS. 라운드 v1→v2→v3.

**보유 실제 클립(발명 금지):** JumpBite_RM(제자리물기·net변위0) · JumpLunge_RM(4.67m·★Y0.28 bake로 0) · BiteForward_RM(1.33m) · Spit · Run_RM(2.457m/cyc) · IdleAngry · GetHit · Death.

### 마이크로 타이밍 (1v1 코어 — Codex+LevelDesign 둘 다 keep)
상태머신: `Chase(Run_RM, facing=속도, 예측리드 0.5s)` → 거리분기

| 분기 | 시퀀스(클립) | 타이밍 | 텔레그래프(부감) |
|---|---|---|---|
| <2.5m **Snap-Bite** | Brake→Windup→Strike→Recovery (JumpBite_RM 제자리) | 제동0.10 / 윈드업0.22 / 액티브0.10 / **회수0.30** | 제동 시 **바닥 스키드 데칼+먼지**(개시신호) + **얇은 부채꼴 SDF** 0.18s 선행·직전 테두리 수축. 히트박스=부채꼴 정확일치 |
| 4.0~5.3m **Pounce-Lunge** | Coil→Launch→Land-Recovery (JumpLunge_RM 4.67m, Y bake0) | 응축0.26(speed 0.4배) / 발사 / **회수0.30** | **착지 라인** + **그림자 블롭**(떠오름=작아짐 → 착지=커지며 붉음) |
| 정지 핀 **Acid Spit** | Aim→Fire (Spit) | 조준0.35(예측없음=이동우호) / 발사 | 머리 들기 + **라인 조준선**, 단발 직사 레드오렌지 |

- 속도감: Coil/Windup 느린 응축(0.4배) → Strike 짧은 스냅 → **회수=카타나 처형창**(0.30 적정, 줄이지/늘리지 ❌).
- 정지 중 생명감: 어깨낮춤·꼬리고정·시선락온(압축포즈).

### 호드/공간 레이어 (LevelDesign 렌즈 — v2/v3 신설)
- **A. 커밋 토큰 + 홀딩 링:** 비토큰=홀딩패턴(스탠드오프 링 5~7m + 고유 각도섹터 360°/N 점유, 빠른 선회❌).
- **F. Cross-pack 글로벌 아비터:** 토큰=**플레이어 타깃 단위 글로벌 풀**. 한 플레이어 노리는 전체 Caniathrox 통틀어 **동시 런지 ≤2**.
- **G. 커밋 데드라인 0.5s:** 초과 시 기본=현 각도 강행, 토큰반납=플레이어가 섹터 밖으로 빠져 각이 죽은 경우만.
- **B. 멀티-런지 분산:** 1번만 예측리드점, 2번째 현위치/플랭킹 오프셋+0.2s 스태거, 착지라인 별개.
- **C. 루트모션↔밴드 정합:** 런지 트리거 4.0~5.3m 스윗스팟. >5.3m=Run_RM 접근 후 커밋, <4.0m=Snap-Bite 폴백.
- **H. 케이던스 파동:** 토큰 핸드오프=버스트(2~3회 0.3s) 후 소강(0.8~1.0s 휴지).
- **E. 텔레그래프 렌더:** PickupInfoOverlay(이벤트600) 몸 위.
