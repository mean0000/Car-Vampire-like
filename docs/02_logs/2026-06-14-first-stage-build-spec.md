- **착지 = 즉시 교전(규칙1)**: 드랍 순간 반경 내 모든 띠 인스턴스 어그로. 워밍업 0.
- **회랑 채널 = 디렉터 특성**: 수렴이 *개활 사방*이 아니라 *회랑을 타고 한 줄*로 들어옴 → 호드가 직선으로 압축돼 **대시 한 번에 카빙**(집하장의 액션 정체성). 표효가 회랑에서 울리면 그 회랑 한 줄이 불어남.

### A.10.2 표효 호출 (규칙2 — 어그로 전파+호드 형성)
| 항목 | 집하장 명세(lv 의도) |
|---|---|
| **누가 포효하나** | 우선 = **Caniathrox**(권위 "사냥개/스프린터 본대" = 떼 본능) → 같은 종 회랑 수렴. 보조 = **Fulgurodonte** 코어 등장 시(엘리트 포효 = 코어 띠 강몹 결집) |
| **"유사" 정의** | **같은 종 우선**(Caniathrox 포효 → Caniathrox 수렴), 차선 = 같은 밴드(중간 LV2~3) |
| **반경(모양)** | 회랑 한 채널 길이 정도(좁고 긺) — 개활보다 좁되 회랑 따라 *멀리* 전파. *수치=Gameplay* |
| **발동 계기** | ① 첫 접촉(플레이어가 Caniathrox 떼 인지 거리 진입) · ② Fulgurodonte 코어 등장 · ③ 주기 쿨다운(끊기지 않게) |
| **회랑 울림** | 표효가 *회랑 벽에 갇혀* 한 줄로만 전파 = "이 회랑이 갑자기 불어난다" 액션 무대(개활 사방 불어남과 대조) |

### A.10.3 구심 주입 곡선 (규칙4 — 공간 변조, *모양*만)
중심에 가까울수록 LV4~5 젠 비율↑. **곡선 모양** = 외곽 평탄(LV1 거의 100%) → 중간 완만 상승 → **코어 r0~22서 급상승(LV4~5 주입율 피크)**. 회랑→야드 전이(r22 코너)가 변곡점.
```
강몹(LV4~5) 젠율 ↑
   │                          ╭──── 피크(코어 r0~22, 잭팟의 대가)
   │                      ╭───╯   ← 변곡 = 회랑→야드 코너(r22)
   │            ╭────────╯
   │ ─────────╯  (외곽 평탄, LV1 우세)
   └────────────────────────────→ 중심 접근(r74 → r0)
```
*수치(피크 비율·기울기) = Gameplay.* lv 의도 = **회랑 구간은 완만**(카이팅 본전장 유지), **야드 진입서 급격**(잭팟=대가 체감).

### A.10.4 번짐 곡선 (규칙5 — 시간 변조, *모양*만)
시간↑ → 안쪽(코어) 종이 바깥 띠 풀에 섞임. **모양** = 초반 0(띠 순수) → 중반 완만(중간 띠에 코어종 일부) → **후반 외곽에도 Fulgurodonte/Venosaur 일부 난입**(안전 외곽 잠식 = escalation 공간 구현).
```
바깥 띠의 코어종 혼입 ↑
   │                       ╭──── 후반(외곽도 잠식)
   │                ╭─────╯
   │        ╭──────╯
   │ ──────╯ (초반 0 = 띠 순수)
   └────────────────────────────→ 시간(런 경과)
```
- **할당량 미충족·한 탕 더 커밋 = 번짐 가속**(독트린 §0 escalation). 채우고 퇴근하면 리셋(숨). *수치=Gameplay.*
- 로스터 §4 escalation 4단계(밀도→능력치→유생 분출→보스)와 동일 타임라인 공유 — **싱크 마스터시계 단일 출처**(번짐·escalation·표효 주기가 따로 놀지 않게).

### A.10.5 맵 특성 요약 (집하장)
- **회랑이 호드를 한 줄로 압축** → 대시 카빙이 무서움(데스트랩 0 전제 위에서만 성립 — 막다른 회랑이면 압축=즉사).
- **표효가 회랑에 울림** = 채널 단위로 호드가 불어나는 국지 스파이크.
- 공중(Kupolojuve)도 회랑 위 상공서 **평면 다이브**로 합류(윗면 체류 ❌).
- 동시 alive = 회랑 폭 5m라 **보수적**(lv 의도 = 회랑당 동시 ≤6, §A.3). 디렉터가 회랑별 로컬 캡으로 walkable 밀도 위반 회피.

## B.10 ★스폰 디렉터 (분수광장 — 개활 사방 수렴형)

> **본 절 = 정적 카운트(옛 §B.4) 대체.** 독트린 §2.5 5규칙을 분수광장 개활 기하에 사상. 집하장(§A.10)과 **같은 5규칙, 다른 표정**: 회랑 압축이 아니라 **개활 360° 수렴 = 사방 압박 = 광역 학살**. lv = 풀/표효/곡선 모양/특성/alive 의도, **수치·풀사이즈 = Gameplay.**

### B.10.1 밴드 젠 존 (개활 사방 수렴 — 규칙3)
방사 거리·광장 가장자리·차량 군집에서 솟아 **사방에서 단상으로** 흐른다(회랑 한 줄 압축 없음).

| 띠 | 반경 | LV 풀(로스터 9종) | 디제틱 젠 출처 | 개활 특성 |
|---|---|---|---|---|
| **외곽** | r55~74 | Lacercharias(fodder) · Venodonte(차량/바리케이드 *뒤* 엄폐 사격) | 8방위 방사 거리 끝·파사드 그늘 | 방사 거리 8갈래 = 사방 진입로 |
| **중간** | r22~50 | Caniathrox(방사 거리 쇄도) · Dimaxillosaurus(파사드 코너 매복) · Kupolojuve(상공 군집→평면 다이브) | 파사드 코너·광장 가장자리·상공 군집 비콘 | **개활 = 사방 동시 수렴** = 광역기 한 방 무대 |
| **코어** | r0~22 | Fulgurodonte(개활 램) *또는* Carcinoptera(공중 정예, 택1) · Kupolojuve(호위 군집) · Venosaur(호위 살) | 방사 대로 끝 런웨이·상공·단상 둘레 | 4종 중 **최대 360° 카빙** = 광역 학살 뽕 |

- **착지 = 즉시 교전(규칙1)**: 동일.
- **개활 = 디렉터 특성**: 수렴이 *사방 동시*라 한 줄 카빙이 아니라 **광역기로 쓸어담는** 액션(집하장 대시 카빙과 대조). 공중(Kupolojuve 군집·Carcinoptera)이 **평면 다이브로 평면 호드에 합류** = 사방+상하 입체 압박감(단, 전투는 평면).

### B.10.2 표효 호출 (규칙2)
| 항목 | 분수광장 명세(lv 의도) |
|---|---|
| **누가 포효하나** | 우선 = **Caniathrox**(방사 돌진떼) → 사방 거리서 같은 종 수렴. 보조 = **Kupolojuve 군집**(공중 비콘이 포효 = 비행 위협 결집, 개활의 색) |
| **"유사" 정의** | 같은 종 우선, 차선 = 같은 밴드 |
| **반경(모양)** | **넓고 둥글게**(개활이라 사방 전파) — 회랑(좁고 긺)과 대조. *수치=Gameplay* |
| **발동 계기** | ① 첫 접촉 · ② 코어 엘리트(Fulgurodonte/Carcinoptera) 등장 · ③ 주기 쿨 |
| **개활 울림** | 표효가 *사방으로 퍼져* 광장 둘레 전체서 호드가 불어남(회랑 한 줄과 반대) = "포위당한다" 압박 |

### B.10.3 구심 주입 곡선 (규칙4 — *모양*만)
집하장과 **같은 모양**(외곽 평탄 → 코어 급상승)이되 변곡점이 다름: 회랑 코너가 아니라 **광장 가장자리 진입(r22~)**이 변곡. 개활이라 코어 강몹이 *멀리서도 보임*(끌림) → 욕심·대가 체감이 시각적으로 더 선명.
```
강몹(LV4~5) 젠율 ↑
   │                          ╭──── 피크(코어 r0~22)
   │                      ╭───╯   ← 변곡 = 광장 가장자리(r22)
   │            ╭────────╯
   │ ─────────╯  (외곽 평탄)
   └────────────────────────────→ 중심 접근(r74 → r0)
```
*수치=Gameplay.* lv 의도 = 개활이라 코어 진입 전 **시각 예고가 길다**(번짐 전 단계서 코어종 윤곽 노출) → 주입 급상승을 살짝 *앞당겨도* 됨(가독성 있는 위협).

### B.10.4 번짐 곡선 (규칙5 — *모양*만)
집하장과 동일 모양·동일 마스터시계. 개활 특성 = 번짐이 **사방 외곽 동시 잠식**(회랑은 채널별 순차) → 후반 "안전한 외곽이 없다"가 더 빨리 체감.
```
바깥 띠의 코어종 혼입 ↑
   │                       ╭──── 후반(사방 외곽 잠식)
   │                ╭─────╯
   │        ╭──────╯
   │ ──────╯ (초반 0)
   └────────────────────────────→ 시간(런 경과)
```
- escalation·표효 주기와 **단일 마스터시계 공유**(§A.10.4와 동일).

### B.10.5 맵 특성 요약 (분수광장)
- **개활 사방 수렴** = 광역 학살의 무대(집하장 회랑 압축의 대조군).
- **공중 평면 다이브 합류**(Kupolojuve 군집 + Carcinoptera 정예) = 개활이라 비행 위협이 빛남(평면 호드에 위에서 꽂힘, 전투는 평면).
- 동시 alive = 개활이라 **높게 가능** — 단 **60 agent 한 프레임 path = NavMesh 스파이크**(§B.8) → 디렉터 **스폰 스태거 필수**(한 프레임 대량 스폰 ❌).

# 공통 — 동심원 LV/밀도 + 스폰 마커 요약 (2맵)

> §5.5 시그니처 표 준수. **전부 평면·≥1.5m 분리·정면 팝인 0.**

| 밴드(=젠 존) | 반경 | 집하장 LV 풀 | 분수광장 LV 풀 |
|---|---|---|---|
| 외곽 LV1 | r55~74 | Lacercharias 산발 / Venodonte 컨테이너 *뒤* 지상 엄폐 | Lacercharias 산발 / Venodonte 차량·바리케이드 뒤 지상 엄폐 |
| 중간 LV2~3 | r22~50 | Caniathrox 회랑 돌진 / Dimaxillosaurus 컨테이너 틈 매복 / Kupolojuve 상공 다이브 | Caniathrox 방사 돌진 / Dimaxillosaurus 파사드 코너 / Kupolojuve 군집 다이브 |
| 코어 LV4~5 | r0~22 | Fulgurodonte 램 + Venosaur 호위 (보급 잭팟) | Fulgurodonte 개활 램 or Carcinoptera 공중정예 + Kupolojuve 호위 비콘 |

> **2026-06-14 교체**: 위 표 = **밴드별 젠 풀**(정적 토큰 명단 ❌). 각 띠가 자기 LV 풀을 플레이어 주위로 **무한 수렴**(§A.10/§B.10). 동심 밴드 자체가 젠 존이라 옛 "스폰 마커 role/카운트"는 폐기 — 마커는 **디제틱 젠 *출처*(회랑 입구·컨테이너 뒤·균열·상공 진입점)** 표시 용도로만 남고, *얼마나·언제*는 디렉터가 정한다.

- **마커 = 출처 표시(role 잔존, 카운트 제거)**: Ambient(외곽 출처) / WaveSpawn(중간 출처) / EliteSpawn(코어 엘리트 정원 1) / FlyerSpawn(상공 진입점, 평면 다이브 목표=평면 좌표). **"마커당 X마리" ❌** — 마커는 *어디서 솟나*만, 젠율은 디렉터 노브.
- **트리거 모델 정정**: 옛 "근접 비트 트리거 = 스폰" 폐기. **밴드 젠 = 상시(착지 즉시)**, 릴레이 비트(§A.4/§B.4)는 *지각 공개*만 트리거(콘이 깔 것). **escalation = 마스터시계 시간 변조(번짐)** + 처리 지연 곱(밀도·능력치). 표효 = 어그로 전파 이벤트(주기/접촉). → **시간 기반(번짐·escalation)과 이벤트 기반(표효·착지)의 명시 분리** — 둘이 *드리프트하지 않게 단일 마스터시계*.

## 공통 — ★스폰 디렉터 노브 맵 (lv 의도/곡선 모양 ↔ Gameplay 수치/구현)

> 독트린 §2.5: "젠율·표효 쿨/반경·구심 주입 곡선·번짐 곡선·동시 alive 캡 = Gameplay 디렉터 수치." **본 표 = 그 경계의 단일 출처.** lv는 *모양·의도·상한 방향*, Gameplay는 *값·풀사이즈·런타임*.

| 노브 | lv가 정함(의도/모양) | Gameplay가 정함(수치/구현) |
|---|---|---|
| **밴드 기본 젠율** | 띠별 LV 풀 매핑(외곽 LV1 / 중간 LV2~3 / 코어 LV4~5), 어느 종이 우세한지 | 띠별 초당 스폰수, 풀사이즈(=동시 alive 캡서 도출) |
| **표효 쿨/반경** | 누가 포효(Caniathrox 우선), "유사"=같은 종 우선, 반경 *모양*(집하장 좁고 긺 / 분수광장 넓고 둥글게), 발동 계기(첫 접촉·엘리트 등장·주기) | 쿨다운 초, 반경 미터, 수렴 가속 값 |
| **구심 주입 곡선** | 곡선 *모양*(외곽 평탄→코어 급상승), 변곡점(집하장=회랑 코너 r22 / 분수광장=광장 가장자리 r22) | 곡선 control point 값, 코어 LV4~5 주입 비율 피크 |
| **번짐 곡선** | 곡선 *모양*(초반 0→후반 외곽 잠식), escalation·표효와 **단일 마스터시계 공유** | 시간축 control point, 혼입 비율, 처리 지연 곱 |
| **동시 alive 캡** | *상한 방향*(집하장 회랑당 ≤6 보수적 / 분수광장 개활 높게+스태거 필수) | 정확한 캡 값, 풀사이즈, 스폰 스태거 프레임 분산 |
| **착지 즉시 교전** | 규칙(워밍업 0, 드랍 즉시 어그로) | 인식 반경, 어그로 전파 구현 |

**경계 한 줄**: lv가 "이 곡선은 코어서 급상승한다"까지, Gameplay가 "급상승 = control point (0.7, 0.85)"부터. **수치 단독 변경으로 의도를 못 살림** — 회랑이 데스트랩이면 압축 카빙이 즉사가 되듯, 곡선은 공간 전제 위에서만 작동(R2/R3).

## 리스크
- **R1 (전제·최대)**: **쫄깃함은 이 2맵으로 판정 불가** — 측정 = 공간 가독성/끌림까지만. "끌리는가/읽히는가"는 그레이박스로, "쫄깃한가"는 **게이트0 전투감(인식 3상태·피격 사다리·히트스탑) 선행 필수**(독트린 §3). 맵=무대, 전투감=배우.
- **R0 (디렉터 전환 핵심)**: **호드가 많아도 한 마리가 안 무서우면 무해함만 많아진다**(spawn-director.html 경고). 밴드 젠으로 수를 무한히 부어도 **per-monster 위협(게이트0+종별 애니)이 없으면 "무해함만 많아짐"** = 정적 카운트 폐기의 보상이 사라짐. 디렉터는 *양*을, 전투감은 *질*을 — 둘 다 있어야 뱀서류.
- **R2 (집하장 #1)**: **회랑 데스트랩/walkable 밀도** — V3(골목 ≥2 출구)·동시 alive 보수적 캡 최우선 검증. 막다른 컨테이너 골목 = 즉사.
- **R3 (분수광장 #1)**: **개활 스폰 스파이크** — 60 agent 한 프레임 path = NavMesh 스파이크 → Gameplay 디렉터에 **스태거 필수**.
- **R4 (높이 정합)**: 본 스펙 전반 = 단일 평면. 그레이박스서 **컨테이너/크레인/단상 윗면에 워크어블이 생기면 버그**(NavMesh 윗면 차단 확인). 고지 사격수·등반 표현 0.
- **R5 (artist 의존)**: 비콘 발광·보급등·발광 풀·안개 = 전부 셰이더/VFX(telegraph·킬버스트 자산 재활용 검토). lv는 위치만.
- **R6 (정직)**: 좌표는 150 그리드 시작값이지 최종 transform 아님(에디터 손배치서 스냅·미세조정). 본 스펙 = 그레이박스 박스 프록시 빌드 가능 수준까지.
