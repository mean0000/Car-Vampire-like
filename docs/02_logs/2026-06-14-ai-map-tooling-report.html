AI로 탑뷰 맵을 까는 법 — 도구·MCP·모델 전수 + 우리 파이프라인

에이전트 3종(에셋·레이아웃·MCP) + 코어 웹조사 종합. 한 줄 결론: "AI 맵 생성기" 단일 도구는 우리 게임에 없다. 정답은 *계층 파이프라인* — 설계자가 그래프로 의도를 박고, PCG/WFC가 모듈을 조립하고, AI 에셋이 빈칸을 채우고, 우리 MCP가 실행·검증한다.

★ 우리 추천 파이프라인 (한눈에)

[설계자 의도] 그래프 = 비대칭 컴파운드 + 동심원 난이도 + 추출 (덕코프 골격, 페이싱은 사람이) ↓ Edgar Pro / Dungeon Architect (그래프 PCG, Unity 네이티브) [모듈 조립] Synty 모듈을 룸 템플릿으로 배치 → Tessera (WFC) 사이 통로/필러 ↓ [경계] 자연 장벽(잔해·벽 + 필요시 Gaea 한 장) · 높이=가독성 적이라 터레인 최소 ↓ [에셋 빈칸] Sloyd(파라메트릭 모듈 키트) + Tripo MCP(스타일 소품) + Hunyuan 로컬 → Blender MCP로 그리드스냅·피벗 정규화 → 셀셰이드 한 머티리얼 통합 ↓ [실행] Unity 공식 MCP RunCommand + 프로젝트 배치 DSL(PlaceModule/StampDistrict) ↓ [검증] 디스크 렌더 캡처 → 판정 루프 (필수 강제 스텝 — 에이전트는 뷰포트 못 봄)

A. 방법론 — 탑뷰 맵을 AI로 *어떻게* 까나

AI 터레인/도시 생성기는 우리에게 틀린 패러다임. Gaea·World Creator·CityEngine·Marble은 전부 *리얼리즘 오픈월드/하이트맵* — 탑뷰 바운디드 존(높이=가독성의 적)과 충돌. 맞는 건 4계층 조합:

계층무엇도구왜 우리에 맞나
③ 그래프 POI 배치 (1순위)거점·난이도·추출을 *위상*으로 설계Edgar Pro · Dungeon Architect덕코프 비대칭 추출구·동심원 보상·난이도 띠 = 전부 그래프 결정. 페이싱=재미 뼈대는 AI에 안 맡김
② 모듈러 키트 조립거점을 Synty 모듈로 채움Edgar 룸 템플릿 / 우리 DSL보유 Synty 모듈 그대로 룸으로
④ WFC 사이채움거점 사이 통로·변주Tessera · 2025 WFC 비주얼툴매 런 다른 오픈존(우리 "수동시드→조립기")
① 경계 자연장벽봉쇄/가독잔해·벽 프롭 (+Gaea 1장)높이 최소 — 터레인은 경계만

D. MCP / 파이프라인 — 우리는 양끝을 이미 최선으로 보유

현 상태 (재평가됨)

  • Unity MCP = 공식 1st-party(`com.unity.ai.assistant`) — 커뮤니티판보다 안정. `RunCommand`=임의 C# 실행=배치 만능
  • Blender MCP = ahujasid(22.7k★ 표준) + Hunyuan 로컬
  • → 에셋생성(Blender)→배치(Unity) 황금 워크플로 *양끝 확보*

개선 = 새 서버 ❌, 레이어 ✓

  • 배치 DSL — RunCommand 위에 `PlaceModule/StampDistrict` 헬퍼 → LLM은 좌표/스펙만(raw C# 통째 ❌ = 타임아웃·실수 제거)
  • in-process 커스텀 툴(Agent SDK `@tool`) — 스펙 생성·검증
  • 디스크 렌더 검증 루프 강제 — 에이전트 뷰포트 못 봄(우리 "찰흙" 교훈)
⚠️ MCP 한계(확정): ①SDK 연결 60초 타임아웃 → 큰 맵 청크 배치 ②여러 엔진 MCP 쌓으면 ~50% 오선택 → Unity 단일 유지 ③에이전트 비용 빠름 → 규율. ④computer use 불필요(RunCommand가 더 정확·쌈).

E. 우리 액션플랜 (순서)

  1. 즉시(무료/보유): Tripo 공식 MCP 연결(무료 2,000cr) + RunCommand 배치 DSL 초안(PlaceModule/StampDistrict) + 디스크 렌더 검증 루프 박제(이미 절반). → LevelDesign 스펙(modular_assembly·build_spec)을 *실행 가능*하게.
  2. 레이아웃 PCG 도입: Edgar Pro 평가 — Synty 모듈을 룸 템플릿화, 그래프에 덕코프 의도(비대칭 거점·동심원) 박기. "수동 시드 3장" → Edgar 그래프로 진화.
  3. 에셋 키트 보강: Sloyd 접근 확인($15/mo) — Synty 빈칸(폐허 변종·우리 전용 구조물) 파라메트릭 양산. Scenario로 톤 고정 텍스처.
  4. (선택·후순위): 절차 지오메트리 대량 필요 시 Houdini MCP(`fxhoudinimcp`). 우리 손모듈 방침과 결 다르니 방향 분기 판단 후.
★변하지 않는 원칙: 레이아웃 미적·페이싱 판단은 AI/PCG에 안 맡긴다(CLAUDE.md D항 + 자연끌림 독트린). AI는 *실행기·양산기*, 의도는 오케스트레이터+LevelDesign. 3개 레인이 독립적으로 같은 결론에 도달함.
