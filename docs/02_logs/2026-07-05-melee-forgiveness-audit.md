# 2026-07-05 근접 판정 관용(Forgiveness) 감사 — 3소스 교차

> 유저 문제의식: "쿼터뷰에서 너무 뚜렷한(문자 그대로의) 공격 범위는 플레이어에게 불리하다 — 우리가 놓친 것과 업계 편법을 찾아라."
> 소스 3갈래: ①웹 리서치(업계 테크닉 카탈로그 23종+출처) ②코드 감사(Explore — 판정 사슬 실측) ③Codex 독립 감사(크로스프로바이더). 지휘 = Fable.

## 1. 핵심 진단 — 우리 관용은 "타격 단계"에 몰려 있고, 구멍은 그 앞뒤다

타격 단계 관용은 이미 두텁다(절단선 폭 1.6m·초근접 0.9m 각도/LOS 면제·gather +0.5m·적끼리 비차폐 관통·입력버퍼 0.5s·스윙가드 ±70°·크리 접촉유예 0.5s·끊고-베기 취소·어택 토큰). **구멍은 5곳:**

| # | 구멍 | 근거(수렴) |
|---|---|---|
| G1 | **거리를 피벗-대-피벗으로 측정** — 덩치 클수록 판정이 상대적으로 짧아짐(Crassorrid r=1.8). 절단선 반폭 0.8m < 잡몹 캡슐 반경 0.9m → 몸 가장자리 스침이 판정상 빗나감 | 코드감사+Codex+웹 B8 |
| G2 | **단발 프레임 판정** — AnimationEvent 1프레임 OverlapSphere. 스윙 중 걸어 들어온 적을 못 맞힘(공간 점유감 부재) | Codex+웹 C13/C14 |
| G3 | **조준 = 발밑 평면 투영, 깊이 보정 0** — 적 몸통에 커서를 올리면 조준점이 적 뒤 바닥에 떨어짐(쿼터뷰 시차). PoE2가 "Cursor Targeting" 모드로 공식 해결한 바로 그 문제 | 내 감사+Codex+웹 A7 |
| G4 | **조준 어시스트 전무 + 스윙 시작 잠금 후 보정 없음** — Hades는 기본 ON, GoW는 공격 자동 배향 | 코드감사+Codex+웹 A1/A4 |
| G5 | **LOS 역비대칭** — 내 공격은 장애물 LOS로 차단되는데 적 근접 타격은 LOS 검사 자체가 없음(벽 관통 명중). 업계 관례("모호하면 플레이어 편")의 정반대 | 코드감사(단독 발견) |

부수: 절단선 필터가 초근접 구제보다 먼저 돌아 등뒤 밀착 적이 구제 못 받음(Codex) · 스킬/반격/대시는 절단선 미적용(문자 그대로 부채꼴) · Crassorrid 허트박스 높이 5m<비주얼 7m(단 판정이 XZ 평탄이라 실해 미미).

## 2. 업계 테크닉 카탈로그 (웹 리서치 전문 — 출처 포함)

원문은 아래 §5. 요지: 조준 보정(Hades 스냅·GoW suck-to-target 각도 스케일·아캄 글라이드·PoE2 커서 타게팅) / 히트박스 3종 비대칭(내 공격>비주얼, 내 피격<비주얼, 적 공격<텔레그래프) / 시간 구조(스윕·액티브 프레임·인풋 버퍼·코요테) / 쿼터뷰 특유(Y 평탄·화면 공정성·판정 우선순위) / 페어플레이(어택 토큰·텔레그래프 계약·결과 완충).
★가드레일 3종(과잉 어시스트 실패 모드): 입력 방향 대체 금지(세부 보정만) · 멈출 수 없는 끌려감 금지(짧은 범위+각도 스케일) · 결정(위치 선정) 층 보존 — 우리 "정밀=고수 트리" 캐넌과 정합.

## 3. 적용 제안 (우선순위 — 유저 판정 대기)

**P0 — 즉효·저비용·"분명 맞았는데" 제거:**
1. **표면 거리 판정** — DoHit 거리/절단선/부채꼴 검사를 피벗 대신 `collider.ClosestPoint`(또는 대상 반경 차감) 기준으로. G1 일괄 해소(절단선 실효 폭이 적 반경만큼 자동 확장).
2. **초근접 구제 순서 수정** — pointBlank 검사를 절단선 필터 앞으로.
3. **커서 깊이 보정** — PlayerAim: 커서 스크린레이로 적(레이어7) 픽킹 우선, 실패 시 기존 평면 투영(PoE2 Cursor Targeting 방식).

**P1 — 중간 비용·공간 점유감:**
4. **히트 윈도우** — 단발→짧은 액티브 윈도우(0.05~0.1s 동안 반복 판정, _hitThisSwing 중복 가드 재사용. 클립 이벤트 추가 없이 코드 타이머로).
5. **공격 시작 소각도 스냅** — BeginCombo/액션 시작 시 _aimDir을 근처 적 방향으로 상한 10~15° 보정(커서는 절대 안 건드림 — 판정 측 보정. Hades 원성 반면교사).
6. **LOS 관용** — 초근접 면제 확대·멀티레이(중심+양어깨)·낮은 장애물 무시.

**P2 — 후속(실몹/밸런스 비트와 함께):**
7. 액션(스킬/반격/대시) 모양 패리티(WeaponHitData에 shape 필드 — 오늘 슬롯화 SO에 자연 안착)
8. 적 근접 타격에 LOS 추가(벽 관통 명중 제거 — 페어플레이 방향 정렬)
9. GoW식 각도 스케일 흡인(히트글라이드의 pre-hit 버전)

## 4. 우리가 이미 잘하고 있는 것 (3소스 공통 확인)

어택 토큰(AttackTokenPool=DOOM/아캄 방식) · ThreatArc 텔레그래프 · Y 평탄 판정 · 입력 버퍼 · 디스조인트(칼에 피격판정 없음) · 스윙가드/크리유예(적 공격 완충) · 적끼리 비차폐 관통 — 업계 카탈로그의 절반은 이미 있음.
