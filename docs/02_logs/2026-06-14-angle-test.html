카메라 각도 테스트 — 45° vs 58° vs 65°

실제 엔진 렌더(에디트 모드, 같은 거리·요, 피치만 변경). 윗줄=실제 Synty 건물·컨테이너 + Protofactor 괴수(잠깐 세웠다 삭제), 아랫줄=그레이박스 프레이밍. ⚠️ 디폴트 셰이딩 — 툰/아웃라인/최종 그레이드 미적용(그게 들어가면 더 또렷·더 너그러움).

실제 에셋 (Synty + 괴수)

45°

건물 파사드·괴수 측면 실루엣 보임(드라마↑). 차폐↑.

58° · 추천 절충

정수리로 기울며 플로우↑, 괴수 실루엣 아직 남음.

65°

깨끗한 정수리·필드 가독 최고. 단 괴수가 토큰처럼 납작.

그레이박스 프레이밍

45°
58°
65°

실측 결론 (예상과 다른 점 포함)

  • Synty 에셋은 어느 각도서도 조잡하지 않다. 45°에서도 깔끔(프로 스타일). "45=조잡" 우려는 십중팔구 *그레이박스*를 본 인상 — 실제 에셋은 다름.
  • 진짜 문제는 조잡함이 아니라 다크무드 *가독성* — 괴수가 어둠에 묻혀 작게 안 보임(톤게이트 기존 결론과 일치). 해결책 = 아웃라인/툰 처리지 각도가 아님.
  • 각도의 진짜 차이 = 프레이밍. 45°=파사드+괴수 측면(캐릭터 드라마)·차폐↑ / 65°=정수리·필드 플로우 최고·괴수 토큰화(생명감↓) / 58°=절충(플로우 얻고 괴수 실루엣 유지).
  • → 액션-플로우(서바이버즈)엔 더 가파른 게 맞다는 당신 말은 유효. 단 65°는 괴수 생명감을 깎으니 58° 권고. 당신 눈으로 정하세요.
⚠️ 한계: 디폴트 셰이딩(툰+아웃라인+다크 그레이드 미적용)·정적·괴수 바인드포즈·디오라마는 게임 거리보다 약간 넓게 프레이밍. 최종 룩·움직임의 속도감은 플레이로만 확정. 이 테스트가 답하는 건 "각도별 프레이밍 + 실제 에셋 조잡 여부"까지.
