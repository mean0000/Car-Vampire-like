## 1. 「입체교차로」 (시드 B 계열 — 블록 가림→드러냄)

> **공간 한 줄**: 무너진 고가도로가 십자로 교차하며 코어를 4분할, 거대 램 엘리트가 잔해에 박혀 아래 오염 웅덩이가 발광. **기둥·잔해가 가렸다 드러내는** 블록형 공개.

### 비콘
- **무엇**: 코어 중앙에 **2단으로 무너진 고가 스택**(`SM_Env_Bridge_Broken_01` ×2를 X자로 교차 적층 + `SM_Bld_Concrete_Pillar_01`/`SM_Bld_ConcreteRebar_Pillar_01~03` 기둥 군집으로 받침, `SM_Env_Bridge_Support_01` 보강). 상단 잔해 위에 **Fulgurodonte(LV4 램 엘리트)** 박혀 있고, 그 아래 카빙 교차점에 **오염 웅덩이 발광**(에미시브 데칼/플레인 — Gameplay가 셰이더, lv는 위치만).
- **왜 끌리나(뽕 약속)**: "저 위에 박힌 제일 큰 놈을 떨궈서 아래 웅덩이로 처박고 싶다." 수직 실루엣 = 가장 인상적인 윤곽(독트린 §2.1-2) + 폐허 속 발광(§2.1-3).
- **45° 틸트에서**: 고가 스택 **높이 ~9m**(Fulgurodonte 5.4m + 잔해 받침)이 주변 3층 파사드(~9~12m)와 비슷하나 **십자 실루엣 + 정점 괴수 윤곽 + 하부 발광**으로 곁눈에 박힘. ⚠️ 파사드가 비콘을 완전히 가리지 않게 코어 인접 블록은 **2층 이하(~6m)로 낮춤**(시야선 확보).
- **Synty 프리팹(실재 ✓)**: `SM_Env_Bridge_Broken_01`(BR), `SM_Env_Bridge_01/02`(BR, 데크 연장), `SM_Env_Bridge_Support_01`(BR), `SM_Bld_Concrete_Pillar_01/02/03`·`SM_Bld_ConcreteRebar_Pillar_01~03`(CN), `SM_Bld_ConcreteRebar_Wall_01~05`(CN, 부서진 철근 잔해).

### 리딩 라인
- **4갈래 직선 거리**가 외곽에서 코어로 수렴 — 그러나 십자 고가가 그 위를 가로질러 **"거리 끝에 거대 구조물 다리가 걸쳐 있음"**이 멀리서 보이고, 걸을수록 다리 밑으로 빨려듦. (← `tooncity_road_rules` 직선 + 레퍼 §4 다중 접근 / BotW 引き = 큰 구조물이 시선을 끔)
- 무너진 고가 **잔해 더미가 거리 가장자리를 따라 흘러내려** 발을 가운데로 모음(`SM_Env_Rubble_Pile_01/02`·`SM_Env_Rubble_Plank_01~03`·`SM_Env_Rubble_Stone_01/02` BR).

### 공개 드라마 (릴레이 — 블록형 가림→드러냄)
플레이어가 외곽 거리에서 코어로 진입하며 콘이 차례로 깜:
- **① 비트(외곽 진입, 거리 위)**: 십자 고가의 **윤곽만** 멀리 보임(비콘 상시). 거리 양옆 파사드가 지상 미끼를 *가림*. → 콘에 LV1 Lacercharias 산발만.
- **② 비트(중간 띠, 첫 블록 코너 돌면)**: 파사드 끝나며 콘이 **글린트 캐시**(반짝이 픽업 클러스터, `SM_Prop_Crate_01`·`SM_PickUp_Armor_01` 대용)를 깜 + 그 너머 **고가 기둥 사이로 코어 발광이 새어나옴**. "거의 다 왔다."
- **③ 비트(코어 진입, 고가 밑 통과)**: 기둥 숲을 지나는 순간 콘이 **왈칵 열리며** 박힌 Fulgurodonte 엘리트 + 오염 웅덩이 + 호위 Venosaur(LV3) 전체 노출. = 코어 잭팟. (← 젤다 사선 공개를 *기둥 차폐*로 구현)

### 순환 (카이팅 루프 + 카빙 레인)
- **카이팅 루프**: 코어 둘레를 도는 **고리형 순환로**(고가 기둥들이 자연 회피 축이 됨 — DRG:S 무리 압축). 십자 고가가 코어를 4분할하므로 **사분면 사이를 8자로 넘나드는** 보조 루프(시드 B 8자 카이팅).
- **카빙 레인**: 4갈래 직선 거리 = 대시 관통 레인. 고가 밑 십자 교차점 = 360° 카빙 무대(코어).
- **데스트랩 0**: 각 사분면은 ①둘레 순환로 ②십자 카빙 레인 = **≥2 출구** 보장. 고가 기둥 군집은 통과 가능 간격(≥3m)으로 배치(막힌 포켓 금지).

### 동심원 LV/밀도
- **외곽 LV1**: Lacercharias 산발(저자세 돌진) + Venodonte **지상 산성 견제**(거리 끝·잔해 뒤를 엄폐로, 높이 0 — 옛 "파사드 창에서" 철회. 파사드 창은 스폰 출처 연출만, 사격 발판 아님). 밀도 저.
- **중간 LV2~3**: Caniathrox 돌진떼(끊긴 도로 카빙 레인으로 쇄도) + Dimaxillosaurus 클로(잔해 포켓/블록 코너 매복). 밀도 중.
- **코어 LV4~5**: 🌟 Fulgurodonte 램 엘리트(붕괴 고가/기둥=벽 그로기, *박힌 채* — 플레이어 발밑 평면) + Venosaur 호위 떼. = 할당량/돈/XP 잭팟.
- **스폰 출처 디제틱**: 거리 파사드 문(평면 진입), 고가 기둥 뒤(콘 차단 매복 포켓), 잔해 더미 뒤. **전부 평면 스폰. 정면 팝인 0**.

### 단일 추출 LZ
- **위치**: 4갈래 중 한 거리의 외곽 끝(코어에서 가장 먼 사분면, 외곽 모서리). `SM_Env_Port_Concrete_Slab_01`(BR) 패드 + `SM_Prop_Floodlights_01`(CN) 점등.
- 할당량 N 채우면 LZ 점등 = 끝맺음. 그 전엔 비활성(닫힌 셔터 톤).

## 3. 「발원 격리(분화구)」 (시드 C 계열 — **얕은 보울** 점층, 궁금증 최대)

## 4. 「분수광장」 (시드 A 계열 — 방사 직선 정조준, 광역 학살 뽕)

> **공간 한 줄**: 넓은 시민 광장 중앙 기념비/분수대 위에 비행 군집이 맴돌고, 방사 직선이 또렷이 코어를 정조준. 4종 중 **가장 열려 있고 기준선이 또렷** — 광역 학살의 무대.

### 비콘
- **무엇**: 광장 중앙 **기념비/분수대 단상**(아래 ⚠️ 프리팹 주의) 위로 **Kupolojuve 비행 군집**(LV2 비행)이 맴돌고, 단상 둘레에 **반짝이 캐시 클러스터** + **코어 정예**(Carcinoptera LV4 공중 정예 or Fulgurodonte). 분수 발광(에미시브 — Gameplay).
- **왜 끌리나(뽕 약속)**: "탁 트인 광장 한가운데 비행 떼 = 광역기로 쓸어담고 싶다(독트린 §2.1-1 큰 뽕 약속, 광역 학살)." 비행 군집이 단상 위에서 맴도는 실루엣 = 멀리서 또렷한 미끼.
- **45° 틸트에서**: 단상 **높이 ~4~6m**(=실루엣 비콘 전용, **워크어블 차단** — 적도 플레이어도 못 올라감, CI-7) + 그 위 비행 군집이 **공중 실루엣**으로 맴돎(지상 비콘보다 낮아도 *움직이는 공중 떼*가 시선을 끔). 전투는 단상 *둘레 평면*에서. 광장이 트여 있어 **사방에서 또렷이 보임**(= 4종 중 가장 또렷한 기준선, 시드 A "가장 열림").
- **⚠️ Synty 프리팹 주의(정직)**: **`Fountain`/`Monument` 프리팹 owned 미존재**(Glob 2026-06-14 확인). `Statue`는 **PolygonGeneric에만** 존재 → **독트린 §3 PolygonGeneric 배제 위반**이라 쓰면 안 됨. → **대체안**: 단상 = `SM_Bld_Concrete_Slab_04`·`SM_Bld_Concrete_Floor_*` 적층 단 + 수직 랜드마크 = `SM_Prop_GuardTower_01`(BR, 수직 비콘 — 데모서 항법 비콘으로 검증됨) 또는 `SM_Bld_WaterTank_01`·`SM_Bld_SmokeStack_01`(CN, 도심 수직 실루엣). "분수" 정체성은 발광 풀(Gameplay 셰이더)로, "기념비"는 GuardTower/WaterTank로 치환. **판정 필요**: 이 치환이 "시민 광장/기념비" 정체성을 살리는지(Story 정체성 레이어와 합의 필요).

### 리딩 라인
- **방사 직선 거리/대로**가 외곽에서 단상으로 **정조준 수렴**(시드 A 대각 X자 + 직교) — 가장 직접적인 리딩 라인. 거리 양옆 파사드가 시선을 단상으로 깔때기. (← BotW 삼각형의 법칙 정면 + 시드 A 방사)
- 광장 바닥의 **방사 포장 패턴**(`SM_Env_Road_Cross_01` + 콘크리트 타일 방사 배열)이 발을 중앙으로.

### 공개 드라마 (릴레이 — **방사 정조준, 또렷·기준선**)
- **① 비트(외곽 거리)**: 단상 + 공중 군집이 **거리 끝에 또렷이** 보임(시드 A는 가림이 적어 처음부터 기준선 또렷). → 콘에 LV1 + 거리 글린트.
- **② 비트(광장 가장자리 진입)**: 거리 파사드가 끝나며 콘이 **확 넓어짐** — 광장 개활 + 단상 둘레 캐시 + 정예 윤곽 노출. 가림이 적으니 reveal은 "왈칵"보다 **"트임"**.
- **③ 비트(광장 중앙 접근)**: 단상 도달 = 공중 정예 + 잭팟 전모. 또렷한 정점(드라마는 약하나 기준선이 명확 = 안정·읽힘). (← 독트린 §2.4 "방사 직선=정조준, 또렷·기준선")

### 순환
- **카이팅 루프**: 넓은 중앙 광장을 도는 **링 카이팅**(시드 A "눌러앉아 돌린다") + 외곽 방사 거리로 빠지는 보조 루프. 광장이 넓어 **링 카이팅의 정석 무대**.
- **카빙 레인**: 방사 대각 거리(시드 A X자) = 대시 관통 레인. 광장 중앙 = 최대 360° 카빙(4종 중 가장 넓은 카빙 공간 = 광역 학살 뽕).
- **데스트랩 0**: 광장은 사방 ≥4 출구(방사 거리) = 가장 안전. 외곽 파사드 블록 코너 포켓도 ≥2 출구.

## 7. ★가장 강한 추천 = ② 집하장

**이유:**
1. **독트린 §2.4 "최강 드라마"를 정면 직격** — "건물이 가렸다 골목 끝 왈칵"이 컨테이너 회랑 코너 reveal로 가장 순수하게 구현됨. 4종 중 공개 드라마의 카타르시스가 최고.
2. **비콘 가시성 최고** — 크레인 15m+가 CI-6("키 큰 비콘=상시 보임 / 지상 미끼=콘이 차례로 공개")을 가장 깨끗이 분리 구현(머리 위 크레인은 늘 보이고, 야드 잭팟은 코너 돌 때만 터짐). 끌림 4겹이 가장 또렷.
3. **메타경제 디제틱 정합** — "본사 보급 잭팟"이 growth_economy의 "본사 보급" 축과 서사적으로 맞물림(Story 정체성 레이어가 살리기 쉬움).
4. **키트 정합** — 컨테이너/크레인/항만벽이 한 톤(산업 야드)으로 owned에 완비, 비콘 치환 불요(분수광장과 대비).

**유보(정직):** NavMesh 회랑 데스트랩/밀도 위험이 4종 중 가장 큼 → 그레이박스 시 V3(골목 연결)·walkable 밀도를 최우선 검증. 회랑 폭 ≥5m, 막다른 골목 0, 동시 alive 보수적 캡.

## 8. 미결 / 리스크

- **R1 (전제·최대)**: **쫄깃함은 이 4종으로 판정 불가.** 측정 의존 = 공간 가독성/끌림 합성까지만(독트린 §3). "끌리는가/읽히는가"는 그레이박스로, "쫄깃한가"는 **게이트0 전투감(인식 3상태·피격 사다리·히트스탑) 선행 필수**(run_structure ④ 의존성). 맵=무대, 전투감=배우.
- **R2**: 비콘 **발광·오염 웅덩이·분수·안개 = 전부 Gameplay/artist 셰이더·VFX**. lv는 위치·지오메트리·실루엣 높이만 책임. 핸드오프 경계 명확히(telegraph 셰이더/킬버스트 자산 재활용 가능성 artist 확인).
- **R3**: ④ 분수광장 **기념비 정체성 치환**(Fountain/Monument owned 없음, Statue=Generic 배제) — Story 정체성 레이어와 합의 전엔 "수직 랜드마크+발광 풀" 잠정. 
- **R4 (해소됨)**: ③ 발원 격리 옛 **다층 NavMesh** 위험은 **★높이 규칙(§3)으로 소멸** — 얕은 보울 단일 navmesh ≤30°, off-mesh link 불요. 남은 유일 주의 = 경사 베이크(한 곳이라도 >30°면 보울 바닥 고립). 점층은 잔해 차폐로 보존.
- **R5**: 4종 = **수동 시드 MVP 컨셉**이지 진짜 절차 조립 결과물 아님(모듈설계 P4 "수동 시드 먼저"). 각 컨셉을 손배치 시드 1장으로 만들어 끌림 검증 → 검증되면 모듈화/조립기.
- **R6 (정직)**: 본 컨셉 문서의 ASCII는 개념 레벨이나 **척도는 150×150 확정**(map-scale.png). 실제 그리드 스냅 좌표·프리팹 인스턴스 transform은 **1차 빌드 스펙**(`2026-06-14-first-stage-build-spec.md`, 집하장+분수광장)에서 150 그리드 위 좌표로 박음. 그 외 2종(입체교차로·발원 격리)은 빌드 스펙 미포함(검증 후).
- **R7 (높이 정합)**: 옛 컨셉의 **고지 사격수·다층 카이팅·고도차 떨굼은 전부 철회**(A 정합). 컨테이너/고가/크레인/단상 윗면 = 워크어블 차단(실루엣·오클루전 전용). 비행체만 평면으로 다이브하거나 평면에 텔레그래프 투사. 잔여 표현이 발견되면 = 버그(높이 규칙 위반).
- **R7**: 동시 alive 캡(특히 ② 집하장 회랑·④ 분수광장 개활 스파이크)은 lv가 *상한 의도*만 제시, **풀사이즈·스태거 구현은 Gameplay**.

## 9. Owner 경계 (LevelDesign → Gameplay/artist/Story)

- **LevelDesign(본 문서)**: 4종 컨셉의 비콘 위치·높이·실루엣 / 리딩 라인 기하 / 공개 드라마 릴레이 비트 / 순환 루프+카빙 레인+데스트랩0 / 동심원 LV 배치+스폰 출처 디제틱 위치 / 단일 LZ 위치 / 키트 실선별 / NavMesh 검증 포인트 / 시드 *값* 소유.
- **Gameplay**: 손배치 시드 씬 빌드 / SpawnPointMarker 부착 / 스폰 디렉터·스태거·풀사이즈 / 단일 LZ 점등 런타임(할당량 N 게이트) / NavMesh 베이크+이음새 검증(높이 규칙으로 off-mesh link 불요 — 단일 평면) / 비행체 경로(평면 다이브). **1차 2맵 구현 owner 경계는 빌드 스펙 §끝 표 참조.**
