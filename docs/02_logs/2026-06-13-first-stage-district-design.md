## ★0. 이 문서가 직전 빌드 스펙과 어떻게 다른가 (필독 — 정직한 위상 변경)

직전 산출물 `2026-06-13-containment-zone-graybox-build-spec.md`는 **선형 +Z 침투 시설**이었다: Z0→Z1→Z2→Z3→Z4 일자 진행, 진입≠탈출 1축. 깔끔하지만 **그건 Duckov가 아니라 복도형 캠페인 레벨**이다. 유저가 확정한 아키텍처("도심 한 구역 *안을* Duckov처럼 누비고 탐색→추출")와 **위상이 다르다** — 누비기·비대칭 추출구 3종·동심원 보상이 선형 1축에는 들어가지 않는다.

| 항목 | 직전(선형 시설) | 본 문서(탐색 구역) | 근거 |
|---|---|---|---|
| **위상** | 선형 1축 +Z | **광장 중심 방사형 누비기** | ← Duckov 탐색 구조(레퍼 조사 §2) |
| **추출** | 단일 출구 Z4 | **비대칭 추출구 3종**(개방/키/플레어) | ← Duckov 추출구 3종(레퍼 조사 §3) |
| **보상 분포** | 깊이 따라 선형 증가 | **동심원**(중앙 고밀도·고노출 ↔ 외곽 저밀도·저안전) | ← Duckov 동심원(레퍼 조사 §3) |
| **선택압** | 없음(돌파만) | **루트 선택 + 추출구 선택** | ← Zero Sievert 다중 접근(레퍼 조사 §4) |

**유지(계승)**: 액션 돌파 앵커(처단·돌파·매복·대시) / 시야 콘 = 매복 발생기 + 전방 학살 가시화 / 공격 밀도 규율(직사≤4·곡사≤2·빔≤1) / 스태거 0.3~0.5s / 출현 문법 LV배치 / NavMesh 함정 목록 / 키트 실선별. **전투 동사는 그대로, 공간 위상만 선형→방사로 교체.**

⚠️ **반려 위험 차단**: 직전 선형 설계가 반려된 것이라면, 본 방사형이 정답이다. 반대로 *선형이 좋았는데 다른 디테일이 반려된 것*이라면 — 그건 P0에서 유저가 갈라줘야 한다(§7 판정 포인트 P0).

## 1. 첫 구역 전체 레이아웃 — 어두운 폐허 도심 한 구역

### 1.1 경험 목표 (공간이 만들 플레이어 경험)
들어서면 **무너진 도심 교차로 광장**이 펼쳐진다. 중앙은 노출됐지만 보상이 진하고, 골목·건물 안쪽으로 들어갈수록 안전하지만 빈약하다. 플레이어는 *얼마나 깊이 들어갈지*를 매 순간 저울질하며 누비고, 충분히 챙겼다 싶으면 3개의 다른 성격을 가진 추출구 중 하나로 빠져나온다. **← Duckov: "limited sight cone 탐색 + 비대칭 추출 + 동심원 보상"이 긴장의 본진**(레퍼 조사 §2). 우리가 이미 동결한 시야 콘이 그 긴장의 살아있는 무기다.

### 1.2 동심원 깊이 그라디언트 (← Duckov 동심원, 레퍼 조사 §3)
구역을 **3개 동심 띠**로 짠다. 깊이 = 위험 = 보상 (← Duckov 난이도 띠).

```
                    ┌─────────────────────────────┐
                    │   [띠 C] 외곽 — 골목·건물 안   │ 저밀도·저보상·안전(추출구 인접)
                    │   ┌─────────────────────┐    │
                    │   │ [띠 B] 중간 — 거리·차도│    │ 중밀도·중보상·LV2~3 견제
                    │   │   ┌─────────────┐    │    │
                    │   │   │ [띠 A] 중앙   │    │    │ 고밀도·고노출·고보상·LV4 피크
                    │   │   │  교차로 광장  │    │    │ = 동심원의 눈(eye)
                    │   │   └─────────────┘    │    │
                    │   └─────────────────────┘    │
                    └─────────────────────────────┘
```

| 띠 | 공간 | 밀도 | 보상 | 위협 (출현 문법) | 공간 의도 |
|---|---|---|---|---|---|
| **A 중앙** | 교차로 광장 (28×28m 개방) | 고 | 최고급 코어/strain | LV4 정예 1 + LV2~3 시차쇄도 | 노출 = 비용. 처단 무대(← DRG:S 무리 끊기는 진입로에서) |
| **B 중간** | 4갈래 거리·차도 (폭 8~10m) | 중 | 중급 부품 | LV2 추격자 + LV3 견제, 매복 포켓 | 누비기 본선. 차량·바리케이드로 무리 흘리기 |
| **C 외곽** | 골목·건물 진입 (폭 5~6m, 방 8~14m) | 저 | 하급·키 1개 | LV1 산발 + 매복 1~2 | 숨 고르기 + 추출구 진입 + Hades식 방 craft |

**왜 동심원인가 (← Duckov):** 선형은 "깊이 들어갈수록 위험↑"을 *시간*으로만 표현한다(되돌아오는 가짜보상 위험 — 우리 재미진단 병폐). 동심원은 그걸 *공간*으로 표현한다 — 중앙으로 한 발 들어갈 때마다 위험이 즉물적으로 보이고, 빠질 때는 다른 길(추출구)로 나가므로 "왔다가 되돌아가는" 모션이 없다. **← Duckov가 검증한 구조(2025-10, 3주 300만 장).**

### 1.3 메모러블 피처 = 무너진 고가도로 잔해 (← 레퍼 조사 §4 "메모러블 피처 1개가 맵 정체성")
중앙 광장 위로 **붕괴된 고가도로 한 동강이 비스듬히 걸쳐** 광장을 양분한다(`SM_Env_Bridge_Broken_01` BR). 역할 3가지:
1. **정위치 랜드마크** — 미니맵 없이도 "고가 잔해 아래가 중앙"으로 방향 잡음 (← 레퍼 조사 §4 가독성).
2. **자연 초크 2개** — 잔해가 광장을 가르며 동선을 둘로 압축 → 무리를 한 줄로 몰아 벤다 (← DRG:S/Megabonk 지형으로 무리 끊기, 레퍼 조사 §3).
3. **45° 부감 수직성의 *전술적* 정당화** — 잔해 아래는 콘이 막혀 매복 포켓이 된다. 장식 고저차가 아니라 전술 의미가 있는 수직성만 허용 (← 레퍼 조사 §4 "장식용 고저차 금지").

### 1.4 전체 치수 + 동선
- **전체 바운즈**: ~90×90m 정사각 구역(선형 120×80과 달리 방사형이라 정사각). 솔로 그레이박스 상한 — 더 크면 손배치 비용 폭발(← 레퍼 조사 §1 솔로 스코프 경고, Megabonk이 솔로로 증명한 규모대).
- **동선**: 진입(헬기 안착, 남측 거리 끝) → 4갈래 거리로 누비기 자유 → 중앙 광장은 *선택적*(고위험 고보상, 강제 아님 ← Duckov는 중앙을 강제하지 않는다) → 만족 시 추출구 3종 중 택1.
- **비선형성 (← Zero Sievert 다중 접근, 레퍼 조사 §4)**: 4갈래 거리가 격자로 이어져 어느 추출구든 2개 이상 경로로 도달 → 예측성 방지, 매복 회피 루트 존재.

## 2. 비대칭 추출구 3종 배치 (← Duckov 추출구 3종, 레퍼 조사 §3 직접 차용)

Duckov 핵심: 추출구는 ≥3개이며 **비용 구조가 비대칭**이다. 하나는 안전하지만 노출, 하나는 조건부 은밀, 하나는 고위험 수렴. 우리 3종 + 우리 키트 매핑:

| 추출구 | 위치 | 조건 | 위험 프로파일 | 키트 (실재 확인) | 출처 |
|---|---|---|---|---|---|
| **X1 무조건 개방 (노출형)** | 남서 외곽 띠C, 진입로 근처 (-32, -28) | 항상 열림, 조건 없음 | **저위험·저노출 도주 / 단 보상 챙길 시간 없이 빠짐** — "겁쟁이 출구" | `SM_Env_Port_Wall_01/02` + 안착 마커. 헬기 미사용(진입과 다른 좌표) | ← Duckov 무조건 개방 추출구(레퍼 §3) |
| **X2 키 잠금 (은밀형)** | 북서 건물 안쪽 띠C (-30, +30) | **키 1개 습득 필요**(중앙 띠A 광장에 드롭) | **중위험** — 키 줍는 순간 위치 노출(고보상 미끼), 출구 자체는 은밀 | `SM_Prop_Key_01`(광장 드롭) + `SM_Bld_Warehouse_01` 문 + `SM_Prop_Range_Wall_Door_01`(BR 셔터) | ← Duckov 키·은밀 추출구(레퍼 §3) + Zero Sievert "줍는 순간 노출"(레퍼 §3) |
| **X3 플레어+대기 (고위험 수렴형)** | 북동 띠B 끝, 개활지 (+30, +28) | **플레어 발사 → N초 대기**(헬기 호출) | **고위험·고보상** — 플레어가 전 구역에 위치 노출 + 대기 중 호드 수렴(복귀 각성 트리거) | `SM_Wep_Pistol_Flare_01`(BR) + 안착 마커 + `SM_Env_Concrete_Base_01` 패드 | ← Duckov 플레어·대기·수렴 추출구(레퍼 §3) |

**비대칭이 만드는 결정 (← Duckov):** "지금 X1로 안전하게 적게 들고 나갈까, 키 찾아 X2로 은밀히 더 들고 나갈까, 플레어 쏘고 호드 버티며 X3로 최대로 들고 나갈까." **이 선택이 매 런 다른 이야기를 만든다** — 선형 단일 출구에는 없던 축. 추출구 위치를 외곽 3방에 분산해 "어느 방향으로 누빌지"가 추출 계획과 맞물리게 한다(← Zero Sievert 경계 추출, 레퍼 §3).

⚠️ **밸런스 노브(플레이테스트)**: X3 대기 시간(15~25s), X2 키 드롭 위치(중앙 강제 vs 띠B 타협), X1 보상 페널티 강도. 시작값만 제시 — 측정 후 Gameplay 튜닝.

## 3. 구역 내 인카운터 — 출현 문법 + 액션 처단

전투 동사 = **대시 처단 / 돌파 / 매복(콘 블라인드) / 무리 끊기**. 택티컬 엿보기·스텔스 금지(← 액션 앵커, 유저 2회 확정). 출현 문법(`monster-roster-classification.md`) 준수: LV1 떼만·단독 금지, LV4 단독+호위, LV5 디제틱 예고만.

### 3.1 인카운터 스파인 (동심원 띠별)

| ID | 띠/위치 | 대표종 (LV) | 형식 | 매복/지형 | 출처 |
|---|---|---|---|---|---|
| **D1 진입 튜토** | 남측 거리 끝 (띠C) | Lacercharias ×2~3 (LV1) | 롤링 돌진 `▬0.8×4m` | 없음(안전 기준선) | ← Hades II 첫 방 저강도(레퍼 §3) |
| **D2 거리 견제** | 4갈래 거리 (띠B) | Caniathrox (LV2) 사냥개 + Venodonte (LV1) 산성탄 | B 돌진 + E 조준탄 | 차량 `SM_Veh_Car_Destroyed_01` 뒤 매복 포켓 1~2 | ← DRG:S 무리 끊기 + 공격문법 정지사격 처벌 |
| **D3 고가 잔해 초크** | 중앙 진입 (띠A 경계) | Caniathrox ×3 시차쇄도 (LV2) | B 돌진 | 잔해가 무리를 한 줄로 압축 → 카빙 학살 | ← DRG:S/Megabonk 지형 압축(레퍼 §3) |
| **D4 광장 피크** | 중앙 광장 (띠A) | **Fulgurodonte 램 (LV4)** + Venosaur ×2 호위 (LV3) | B 램 `▬2×12m` + E 스핏 | 광장 장축 = 12m 램 레인, 옆스텝 회피 후 벽 그로기 | ← Hades II "레벨이 적을 규정 + 벽치기 방"(레퍼 §3) |

| **D6 키 드롭 수렴** | 광장 키 마커 (띠A) | 키 줍는 순간 LV2~3 보충 | 혼성 | 줍기 = 잠깐 묶임 = 등 뒤 노출 | ← Zero Sievert 줍는 순간 노출(레퍼 §3) |
| **D7 추출 버스트** | X3 플레어 패드 (띠B 북동) | 복귀 각성 잔존 + CrustaspikanLarvae ×2 예고 (LV5예고) | 호드 + 디제틱 예고 | 패드 등 한 면 닫기, 대기 중 수렴 | ← Duckov 플레어 수렴(레퍼 §3) + 가족 계보 예고(출현문법 §3) |

### 3.2 매복 포켓 (콘 블라인드 — 신규 기하)
시야 콘이 안 덮는 측면/후방에만. 수평 차폐로만 은닉(45° 부감 = 3m 벽이 1.9m만 가림 ← 공격문법 §전제).

| 포켓 | 위치 | 가림막 (실재) | 콘 차단 | 출처 |
|---|---|---|---|---|
| **P1 차량 뒤** | 거리 (-8, -4) | `SM_Veh_Car_Destroyed_01` (BR) | 진행 중 측면 90° 사각 | ← 액션 앵커 매복 |
| **P2 고가 잔해 아래** | 중앙 (0, +2) | `SM_Env_Bridge_Broken_01` 그림자 | 잔해 아래 콘 막힘 | ← 메모러블 피처 이중 활용 |
| **P3 골목 L알코브** | 외곽 (-26, +8) | `SM_Prop_Container_Small`(BR) | L-코너 직후 사각 | ← 직전 스펙 알코브 계승 |
| **P4 키 출구 등 뒤** | X2 건물 (-30, +26) | 창고 내벽 | 키 줍고 나갈 때 후방 | ← Zero Sievert 노출 |

알코브 입구 폭 ≥3m, NavMesh 본선 연결 필수(막힌 포켓 금지 — 매복체가 못 나옴).

### 3.3 대시 레인 (관통 동선)
- **거리 = 직선 카빙 레인** (폭 8~10m): 무리가 와도 전진 대시로 관통, 양끝 열림(데스트랩 없음).
- **광장 = 360° 카빙 무대**: 시차쇄도를 중앙 대시로 가르며 처단. 단 동심원 외곽 3방이 다 추출구로 열려 갇히지 않음.
- ⚠️ **막다른 골목 = 데스트랩 금지**: 외곽 골목 끝은 *반드시* 건물 진입(방) 또는 추출구로 이어짐. 순수 막다른 골목 0개(← 액션 앵커 데스트랩 금지).

### 3.4 스태거 (NavMesh 패스 스파이크 방지)
- D3·D4·D7 호드는 **0.3~0.5s 간격 순차** 깨움(60 agent 한 프레임 동시 = NavMesh 스파이크 ← 직전 스펙 V검증 + 공격문법 Kentriplokame 0.3s 원리).
- 거리 매복은 트립 라인이 달라 자연 시차(플레이어 진행 = 시차 발생기).
- **복귀 각성 (← Duckov 플레어 수렴)**: X3 플레어 발사 = 전 구역 잔존 Dormant 일괄 Chase + 소수 보충(≤4). 대량 신규 스폰 금지(가독성·출처 단일).

## 4. 가독성·밀도 리듬 (← 탑다운 craft 원론, 레퍼 조사 §4)

### 4.1 밀도 40/30/30 교대 (← 레퍼 §4)
동심원이 이 비율을 *공간적으로* 구현한다:
- **40% 개방**: 중앙 광장 + 4갈래 거리 = 처단·카빙 무대.
- **30% 중밀도**: 거리의 차량·바리케이드 산포 구간 = 무리 흘리기.
- **30% 밀집**: 외곽 골목·건물 방 = 매복·초크.

거리에서 광장으로, 광장에서 골목으로 누빌 때마다 밀도 비트가 교대 → 고/저강도 교대(← 레퍼 §4 "10분+ 고강도 = 슬로그"). **평면 반복 절대 금지**(← Death Must Die 반례, 레퍼 §5) — 고가 잔해·차량·건물·골목이 매 화면 다른 실루엣.

### 4.2 색대비 가독성 (← 레퍼 §4 "차폐물은 항상 더 어둡게")
- **바닥/벽 색대비**로 이동 가능 공간 즉시 전달(미니맵 없이). 거리 = 밝은 아스팔트(`SM_Env_Road_*`), 차폐물(차량·컨테이너·잔해) = 더 어둡게.
- **랜드마크 조명**: 고가 잔해 + 추출구 3종에 식별 조명(X3 플레어 = 디제틱 발광). 정위치 앵커.
- ⚠️ **베이스라인 라이팅 의존**: 실제 색대비는 Frozen Golden Hour 베이스라인에서 캡처 판정(← 그래픽 베이스라인 v1). 톤게이트(Protofactor 몬스터 ↔ Synty 도심 동시 캡처) 미통과 시 리스킨 가능.

### 4.3 페이싱 곡선 (톱니 — 동심원 누비기)
```
위협
 ▲                              ┌─ D7 추출버스트(X3 수렴·런 최고점)
 │                  ┌─ D4 ──┐   │   (선택적 — X1이면 이 피크 회피 가능)
 │          ┌─ D3 ──┘ 광장피크│   │
 │   ┌─ D2 ─┘ 잔해초크   ╎이완 └───┘
 │───┘ D1 기준선          ╎(골목 숨고르기)
 └────────────────────────────────────▶ 누비기 진행(비선형)
   진입  거리   중앙광장   외곽골목  추출
```
- ★ **곡선이 선형 스펙과 다른 점**: 누비기가 비선형이므로 플레이어가 *피크(D4 광장)를 건너뛸 수 있다* — 겁쟁이 X1 추출이면 저강도로 끝, 욕심쟁이 X3면 D4 거쳐 D7 수렴. **곡선을 플레이어가 선택한다**(← Duckov 위험 자가 조절). 이게 단일 강제 곡선보다 리플레이성이 높다.
