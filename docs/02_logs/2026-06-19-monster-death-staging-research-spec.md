# 몬스터 죽음 연출 — 티어 스펙 (리서치 종합 · 동결 후보)

**상태:** 제안(proposal). **동결 = 유저.** 두 독립 리서치(라이브 웹 + Codex 크로스프로바이더)가 **거의 완전 수렴**한 결과를 종합. 발산은 1곳(§8).
**날짜:** 2026-06-19 · **권위 관계:** "화려처치=뽕=돈, 잡몹 싼죽음" 캐넌([[feedback_pong_over_systematization]]·성장경제 방향) 정합. 색=색팔레트 v1(시안=액션/마젠타=붕괴/적=레드오렌지).
**⚠️ 미검증 플래그(§1.5):** 두 리서치 다 dev-blog/inference 등급(엔진 teardown 아님). RayFire 가격/세일 **미검증**. Blender Cell Fracture 매뉴얼 직접 인용 아님. "게임 X 내부 구현" 주장은 추론. RayFire 스킨드 내부 베이크의 모든 구성(블렌드셰입 등) 커버 여부는 구매 후 테스트 필요.

---

## 1. 코어 원칙
죽음 연출 예산을 **보상 곡선**으로 쓴다 — 평범한 죽음은 *확인*, 화려한 죽음은 *뽕=돈*. 티어 상승을 게임플레이 보상 트리거(오버킬·노히트 연속·궁극킬)에 묶는다. **잡몹이 화려하면 위계가 붕괴**(엘리트/보스가 안 특별해짐) → 잡몹은 의도적으로 절제.

## 2. 티어 표
| 티어 | 기법 | 주스 | 비용/규율 |
|---|---|---|---|
| **Trash**(초당 다수) | 스케일-제로 팝(0.15s, DOTween) **또는** 디졸브 셰이더(§8 미결) + 풀링 파티클 버스트 + 풀링 데칼 1 | 발광 플래시 1프레임. **히트스탑·쉐이크·래그돌·진짜깁 금지** | 물리 0. 풀링(Destroy 금지). 거리>12m=플래시만 |
| **Elite** | 디졸브 셰이더(0.4~0.6s) + 진짜 깁 2~3(풀링) + 큰 버스트 | 히트스탑 1~2프레임(Feel) + 약쉐이크(0.15s, 횡방향만) + 발광 링 | ~5ms/event 예산. 동시 rich death 캡 |
| **Boss/특별킬** | RayFire 런타임 파쇄(프리캐시+풀링) 또는 Blender 사전조각(죽음포즈 베이크) | 슬로모(timeScale 0.15~0.2, 0.5~1.5s) + 강쉐이크 + 히트스탑 6~8프레임 + 풀스택 | 인카운터당 1~소수만 |

## 3. 스킨드 메시 규칙 (BakeMesh 언제 필요한가)
- **불필요**: 디졸브/정점폭발 셰이더(GPU 스키닝이 정점셰이더 전에 돌아 변형 포즈 위에서 작동) · RayFire SkinnedMesh 모드(내부 베이크) · 파티클 깁(범용 청크) · 래그돌(본 구동).
- **필요**: *정적 지오메트리를 먹는 물리 경로* — Blender Cell Fracture 청크, 자작 비-RayFire 런타임 슬라이서. 이땐 죽는 순간 `SkinnedMeshRenderer.BakeMesh()`로 현재 포즈 스냅(안 하면 T포즈 청크). Cell Fracture는 블렌더에서 *대표 죽음포즈*로 베이크 후 조각(T포즈보다 자연스러움).

## 4. 셰이더 정점폭발 + 디졸브 스펙 (강점 구역 — 1차 도구)
URP ShaderGraph(Lit, Alpha Clip on). 프로퍼티: `_DissolveAmount`(0~1)·`_ExplodeStrength`·`_DissolveNoiseTex`·`_DissolveEdgeWidth`·`_EdgeEmissiveColor`(HDR)·`_EdgeEmissiveIntensity`.
- **정점단계**: object-space 노이즈 × `_DissolveAmount` × `_ExplodeStrength` × 노멀 → Position에 가산(정점 바깥으로 팬아웃). ※셰이더는 청크 분리 못 함 — 소프트 디스인테그레이트만(하드 청크=사전조각 필요).
- **프래그단계**: 노이즈 − `_DissolveAmount` → Alpha Clip(0). 엣지 글로우=`smoothstep(0,_DissolveEdgeWidth, n−amount)` 반전 × `_EdgeEmissiveColor*Intensity` → Emission.
- **구동(런타임)**: ★`MaterialPropertyBlock`로 `_DissolveAmount` 0→1 (DOTween). **절대 `material.SetFloat` 금지**(인스턴스 복제→인스턴싱 깨짐·GC = 호드 최다 버그). 완료 시 SetActive(false)→풀 반납.

## 5. 주스 스택 순서 (Elite 기준, 가감해서 티어 적용)
프레임0: 히트스탑(timeScale 0.05~0.15, 1~2프레임; 파티클은 unscaled) + 발광 플래시(MPB, 레드오렌지/화이트, 1프레임).
프레임1~5: 쉐이크 시작(횡방향, Z줌 금지) + 파티클 버스트(위+밖) + 디졸브 트윈 시작.
프레임5~15: 깁(엘리트, 2~3) + 데칼 스탬프 + timeScale 복귀.
이후: 디졸브 완료 → 파티클 페이드 → 데칼 3~5s 페이드.
**원거리 가독 우선순위**: ①발광 플래시 ②파티클 방사 ③디졸브 엣지 글로우. 쉐이크=느껴지나 안 보임. **데칼=지속 레이어(부감 최적, "여기서 죽었다").**

## 6. 색 전환 (캐넌 정합)
생전 **레드오렌지**(위협) → 킬 프레임 **시안/화이트 플래시**(우리 액션색=킬러색) → 디졸브 엣지=시안 or 마젠타(붕괴) → 데칼=탈채도 적갈(죽은 웅덩이가 살아있는 적으로 안 읽히게). UI 없이 "위협 제거" 가독.

## 7. 퍼포먼스 규율
풀링 전부(VFX 플레이어·깁·데칼·오디오) · `MaterialPropertyBlock` 필수 · Player Settings GPU Skinning ON(호드 50+) · 거리 LOD 게이트(>12m=플래시만, 50~70% GPU 절감) · **동시 rich death 캡**(프레임당 풍부죽음 N개, 초과분 싼 팝으로 강등) · 청크/데칼 1~3s 페이드로 활성 물리 수 bounded · 오디오 보이스 리미팅(AudioMixer).

## 8. ★발산 — 미해결 노브 (유저/프로파일 판정)
**잡몹 죽음 = 디졸브 셰이더(웹) vs 스케일-팝+파티클, 디졸브는 엘리트부터(Codex).**
- 웹: 디졸브가 살아있는 메시 위 GPU라 잡몹에도 충분히 쌈.
- Codex: 동시 30마리 디졸브=프래그먼트가 화면 채워 GPU 비용 → 잡몹=스케일팝, 디졸브 절약.
- **해소**: 우리 밀도에서 디졸브 프래그 비용을 빌드 후 **프로파일**로 확정. 디졸브가 강점·더 예뻐 perf 허용 시 잡몹에도 선호. **기본값=Codex 보수안(잡몹 팝/엘리트 디졸브)으로 시작, 프로파일이 싸다 하면 잡몹 디졸브로 승격.**
