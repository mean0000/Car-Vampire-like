# 무기 전직(찌르기·베기·발도) 레퍼런스 보드 — 2026-07-05

> **상태: 🟡 정체성 재료(리서치 종합).** 전직 구조 동결은 gd 재정합 감사 후 별도.
> 소스 4갈래: 전직별 웹 리서치 3(베기 19항목·찌르기 19항목·발도 20항목, 출처 포함 원문=세션 기록) + Codex 독립 카탈로그(크로스프로바이더). 지휘=Fable. 유저 발안 = 전직 3종(찌르기/베기/발도), 초반=베기 위주, 일섬=발도 파킹.

## 0. 종합 테제 — 셋 다 "선(線)"의 변주 (Codex 종합 + 가르기 코어 동사 정합)

> **찌르기 = 선을 꽂아 핵심 적을 멈추는 자 · 베기 = 선을 이어 군중을 무너뜨리는 자 · 발도 = 선을 저장했다가 한 순간에 전투를 끊는 자.**

우리 코어 동사 "가르기(내가 그은 선)"가 세 전직의 공통 모어(母語)가 되고, 전직은 그 선을 *다루는 방식*으로 갈린다. 차별화 축 = 케이던스 / 판정 모양 / 리스크 구조 / 자원 — 범위·딜·쿨타임 수치로 가르면 실패(Codex).

| 축 | 찌르기(突) | 베기(斬) | 발도(拔刀) |
|---|---|---|---|
| 케이던스 | 짧고 빠른 간격 | 연속 리듬 | 느린 준비 후 폭발 |
| 판정 모양 | 좁고 긴 직선·관통 | 부채꼴·호·이어지는 절단선 | 저장된 선·순간 광폭 절단 |
| 리스크 | 조준 실패·측면 포위 | 근접 체류·과진입 | 차지 중 취약·타이밍 실패 |
| 주 대상 | 돌진몹·엘리트·브루트 | 잡몹 무리 | 위협 타깃·처형각 |
| 트리 | 정밀(중~고수) | 참격(뉴비 관용) | 거합(고수) |

## 1. 억제 스택 경제 삼각 (4소스 교차의 백미)

기존 억제 스택(스태거→×2뎀→도미노)이 세 전직을 하나의 경제로 묶는다:

- **찌르기 = 깊게 꽂는다** — 단일 대상에 스태거를 깊게(Nioh 창="Ki 삭제 최고 효율" 문법). 첫 대상 집중, 관통 후방은 얕게.
- **베기 = 얕게 넓게 쌓는다** — 광역으로 여러 적에게 억제 축적(GoT 달의 형="회전=스태거"). 넉백 아님(§3).
- **발도 = 수확한다** — 억제된 적에게 발도가 꽂히면 즉시 폭발(스태거→절단·도미노 기폭). *쌓는* 전직이 아니라 *거두는* 전직.

타이밍 크리(읽고-베기)도 같은 방식으로 분화: 찌르기=**정식 상속자**(카운터 배수 강화 — 다크소울/엘든링/MH 랜스/세키로 전부 "적이 움직이는 순간의 찌르기"에 배수) / 베기=크리 시 주변 도미노 전파 / 발도=확정 크리·처형.

## 2. 전직별 정체성 시트 (레퍼 근거)

### 찌르기(突) — "면이 아니라 점을 다루는 자"
- **보상 5종(게임사 수렴)**: ①카운터 배수(ER Thrusting Counterattack +30%·DS Leo Ring·MH Counter Thrust) ②가드/아머 관통(ER Piercing Fang — 출처가 카타나 나가키바·GoT Piercing Strike) → **스윙가드·아머 브루트의 정면을 여는 유일 열쇠** ③라인 다단 관통(Varatha 투척·카우치드 랜스 — 속도=딜 환전은 질주 축과 커플링 후보) ④각도 크리(LoL Fiora Vitals — 탑다운 근접 약점의 증명, 타이밍 크리와 구분되는 *공간* 크리) ⑤꽂는 흔적(PoE Impale·포아너 출혈 — 찌르기→베기 시너지 접착제).
- **표현 정답 = DMC Stinger**(섬광 런지), MH 랜스(포크포크)는 판정 구조만. Dead Cells 라피어(회피 직후 0.8s 크리)=대시캔슬 결합 저비용 후보.
- **세계관 코드**: 검도 츠키=3단 미만 금지된 고단자 기술 → 공문 레지스터("찌르기 자격") 재료.
- **함정(Codex)**: 얇은 판정 조준 스트레스(→시각 선 명확·소폭 보정·첫 대상 강타+후방 감쇠) · 단일딜+카운터+관통+사거리 다 주면 타 전직 압도.

### 베기(斬) — "군중의 모양을 바꾸는 자" (광역 딜러 아님)
- **필수 부품(팽이 조롱 방지)**: 회전 중 슈퍼아모(Nioh 상단 — 없으면 첫 피격에 끊겨 조롱거리) · 몸통 통과+넉백 면역(PoE Cyclone) · 시작 프레임 확정 히트(D2 WW).
- **세금 = 단일딜 할인**(Death's Door 북극성이 룰화: 다수 적중 시 마리당 감쇠). 보상은 히트 수 비례(게이지/실적/쿨 환류) — 밀도 보상이 인플레 없이 성립.
- **★넉백 광역은 자멸**(VS Garlic — 밀어내면 밀도 보상을 스스로 깎고 디스폰까지) → **선풍참은 방사 넉백이 아니라 스태거 축적**(gd 드래프트 수정 사항).
- **촌스러움 방지 3원칙**(Warframe spin2win·Mordhau 발레리나 반면교사): 주식 금지(상황 도구) · 회전 1회+시작 포즈·잔심(한 획으로 읽히게, 스탬프 VFX 정합) · 간지=선불 대가와 마무리 무게(젤다 차지→1회전, MH 기인 대회전="콤보 졸업 시험").
- **강화 경로**: 3노브(반경/시전속도/딜)+최상위 1장 성질 도약(VS 진화 문법)+교환형(+반경/−공속). Codex 함정: "기본 공격 강화"로 보이면 정체성 희석 → *절단선을 이어 면을 만드는* 방향.

### 발도(拔刀) — "안 치는 시간까지 공격인 자"
- **납도 메카닉 4답**: (a)카운터 창(MH 태도 거합=무적 프레임+게이지 승급) (b)차지 축적(Nioh 3단 릴리즈 — 일찍 놓으면 연계·풀홀드면 가드 불가: **한 버튼 안 고수/뉴비 공존**) (c)상태 패널티(ER 이속·회복 감소) (d)진입 조건화(공격 파생·펄스 재진입). **쿼터뷰 호드에선 (c)가 공짜(정지=포위)** → (a)+(b) 혼합 + (d)식 실적 조건이 우리 결.
- **★4비트 연출 표준**(TV Tropes Delayed Causality, 정본=DMC3 버질): ①베기(찰나) ②정적(간지 비트로 채움 — 납도 모션·포즈·무음) ③트리거 사운드(딸깍) ④일제 붕괴. **"②의 길이와 ③의 사운드가 손맛 전부"** — 07-05 방향성 붕괴 '어색' 판정의 원인 진단(②가 빈 캡슐·③ 부재). 차별화 기회: 남들은 궁극 전용 → **전직의 평시 문법**으로.
- **침착 게이지**(DMC5 버질 Concentration): 뛰면 새고 헛베면 새고 침착하면 찬다 — "우아함=자원", 발도 고수 트리의 정신.
- **오발 대가(로그라이트 절충)**: 죽음(GoT 일기토 치명상)이 아니라 **납도 풀림+게이지 소각+빈틈**(우쿄 자동 백점프=포지션 손실).
- **입력 문법**: 홀드→릴리즈("놓는" 입력 = GoT 일기토·버질 저스트 릴리즈 — 칼집 반짝=시각 텔레그래프). 세키로 아시나 십자="홀드는 차지가 아니라 조준 대기"(릴리즈 타이밍=위력) — 읽기 무기化 옵션.
- **함정(Codex)**: 호드에서 타이밍 대상 불명확·패링 반격과 상위호환 중복 위험 → 짧은 납도 윈도우·명확한 표식 대상·릴리즈 절단선.
- MGR 블레이드 모드(절단면 직접 조준+잔다츠 회수) = 붕괴를 연출→입력으로 승격할 때의 1차 레퍼.
