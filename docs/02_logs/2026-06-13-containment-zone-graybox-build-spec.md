## ★0. 이 문서가 이전 제안을 어떻게 교체하는가 (필독)

`map-architecture-proposal.md`의 **아키텍처/구역수/스코프/키트 선별/NavMesh 함정 목록은 그대로 유효**하다. 하지만 그 문서의 **인카운터 기제(framing)는 본 액션 앵커가 상위 교체**한다. 한 줄로:

> **"택티컬 엿보기 침투(infiltration)" → "액션 돌파(breakthrough)".** 코너피킹·소리사다리·선제발견 드라마·빡빡한 4m 위빙 통로는 폐기. 대신 **흐름 방 + 매복 포켓(콘 밖 알코브) + 관통 대시 레인**으로 기하를 재author한다.

**무엇이 바뀌었나 (기하 차원):**

| 항목 | 이전 제안 (택티컬) | 본 스펙 (액션 돌파) |
|---|---|---|
| **회랑의 목적** | 코너 너머 "거의 못 볼 뻔" 선제발견, 한 발의 의식 | 측면 알코브에서 매복 터짐 → 대시로 관통 |
| **회랑 폭** | 4~4.5m 빡빡(위빙 강제·5m+면 드라마 소멸) | **5~6m**(대시 카빙·관통 동선 확보, 데스트랩 금지) |
| **L-코너 역할** | 발견 거리 8~11m 조절기(드라마 장치) | **매복 트리거 + 시야 차단(콘 밖 포켓 은닉)** — 발견 드라마 아님 |
| **시야 콘** | 신중 도구(코너 너머 숨김) | **매복 발생기**(뒤·측면 블라인드) + **전방 학살 가시화**(처단 비트) |
| **소리사다리** | Z1 첫 결정(조용/시끄러움 스텔스 선택) | **폐기** — 선택지 없음, 돌파만 |
| **알코브** | (없음) | **신규 핵심 기하** — 콘 밖 측면/후방 매복 스폰 포켓 |
| **대시 레인** | (없음) | **신규 핵심 기하** — 관통 동선, 막다른 데시 데스트랩 절대 금지 |

**유지된 것**: 시설 한 채 · 선형 +Z · 5구역(Z0~Z4) · 복귀 각성(들어올 때 잠든 게 깨어 추격) · 진입≠탈출 · 사전배치 80%/디렉터 20% · 톱니 페이싱 곡선 · 모듈 청크화 · 밀도 규율(직사≤4/곡사≤2/빔≤1) · 스태거 0.3~0.5s.

## 7. 복귀 각성 트리거 의도 + 전방-넓은 콘 가시성 체크

### 트리거 의도 (owner: LevelDesign author → Gameplay 구현)
- **트리거**: Z3 목표 루팅 완료(마커 접촉 + strain 획득) → `ReturnAwakening` 이벤트.
- **동작**: 하위 구역(Z2·Z1) 잔존 Dormant **전원 Chase 전환** + 디렉터 소수 보충 ≤4. **대량 신규 스폰 금지**(가독성·스폰 출처 단일).
- **타이밍**: 루팅 직후가 아니라 **이완 비트(30~45s 무스폰) 이후** 발동 — 숨 고르고 → 각성한 길로. 타이머(폭격 데드라인)는 이완 중에도 계속 감(시간≠밀도 분리).

### 전방-넓은 콘 가시성 체크 (앵커: 콘 = 전방 학살 가시화)
- **복귀로는 +Z→-Z 역주행** = 플레이어가 들어온 길을 거꾸로 본다. 콘이 **전방(이제 -Z, 출구 방향)으로 넓게** 열려 추격 무리를 학살 가시화 → 카빙 관통의 무대.
- **체크포인트**: 회랑(Z1) 역주행 시 콘이 5~6m 폭 전체를 덮어야 무리가 보임(콘 각도 ≥ atan(3/거리)). 폭 5~6m이므로 거리 8m에서 콘 반각 ≥21° 필요 — 표준 부감 콘이면 충족. **★Gameplay 검증: 복귀로에서 콘이 회랑 폭을 다 덮는지 플레이 캡처.**
- **매복 잔존(뒤·측면)**: E7에서도 Z1 알코브 잔존분은 콘 밖 후방 매복 유지 — 각성+매복 이중. 단 복귀는 역주행이라 알코브가 이제 전방 측면 → 일부 가시화(의도된 난이도 완화).

## 9. 페이싱 곡선 (액션 돌파 톱니)

x=공간 진행(E1~E8), y=위협. 이전 제안 곡선 유지하되 비트 라벨을 액션 동사로 교체:

```
위협
 ▲                                         ┌─ E7 복귀각성 (런 최고점·카빙 후퇴)
 │                              ┌─ E6 ─┐   │   ╲
 │                      ┌─ E4 ──┘ 피크 │   │    ╲ E8 탈출(헬기 묶임·유생 예고)

 │───┘ 기준선                      30~45s 무스폰(타이머는 감)
 └──────────────────────────────────────────────────▶ 공간 진행
```

## 10. Owner 경계 + 산출물 핸드오프

**LevelDesign이 author한 것 (본 문서)**: 무엇/어디/몇/왜 + 키트 실선별 + 좌표/facing/groupTag/role + 스태거 의도 + 밀도 상한 + NavMesh 검증 포인트.

**Gameplay 구현 (이 문서 소비)**:
1. `ContainmentZone.unity` 신규 씬 + 위 좌표로 키트 손배치(또는 마커 기반).
2. `SpawnPointMarker` MonoBehaviour 배치(groupTag/role/scatter, isNavMeshValid 스탬프 Editor 툴).
3. SpawnDirector — **스태거 발동**(Z1_E3_Wave 0.4s, Z2_Pack/Air 0.3~0.5s, Z3_Swarm 0.3s), 복귀 각성 일괄 Chase 전환, Relax 30~45s.
4. 구역 전이 = **proximity 트리거**(시간 아님 — 작전 타이머와 드리프트 방지). 작전 타이머 = 별개 글로벌 클락.
5. 조건부 탈출 셔터(Z3 클리어 → 개방 + NavMesh 재연결/off-mesh link).
6. NavMesh 베이크 + V1~V7 검증 + isNavMeshValid 전수 스탬프.
7. 풀 사이즈 = 동시 최대 alive 도출(Z3 = 엘리트1+호위3+군체4 = 8이 최대 단일 구역, 복귀 각성 시 +잔존 → 풀 ~20 권장 — Gameplay 확정).

**노브(플레이테스트 후 튜닝)**: 회랑 폭 5 vs 6m, 초크 폭 5 vs 6m, 시차 간격 0.3 vs 0.5s, 이완 30 vs 45s, Dormant 개수(특히 E3 3마리·Z2 5마리 상한), Venodonte/Kupolojuve 산성·전기 탄속.

**측정 의존 전제 (앵커 §스코프 정직)**: 본 스펙은 **공간이 의도대로 읽히는지**(돌파 동선·매복 사각·복귀 역주행 대비·램 레인)까지 캡처 검증 가능. **쫄깃한지는 게이트0(인식 3상태·피격 사다리·히트스탑) 전투감 구현 후 플레이로만.** 맵은 무대, 전투감이 배우.

**병행 함정**: 톤게이트 미통과 — Protofactor 몬스터 톤이 Synty 도심과 한 화면에 서는지 미판정. 배치 설계는 진행 가능하나 실제 프리팹 배치 캡처는 톤게이트 결론에 따라 리스킨 가능.
