최종 텔레그래프 — 본체 B(언제) + 벡터 C(누구/방향) 결합

바닥 신호(A) 폐기. 모든 커밋 적은 본체가 팽창+발광 포화(회→주황→백)로 "충돌까지 시간"을 깔고(=B, 항상), 그 위에 나를 향한 위협 벡터선이 "이놈이 나를 노린다"를 더한다(=C, 임박·거리 비례). 흰 플래시 = NOW(크리티컬 창) + 오디오 틱(하단 비트). 목표 검증: 동시 커밋 3~4에서도 안 엉키나.
플레이어(조준) 떼(비커밋) 커밋(차오름=B) 벡터=C NOW

조작

볼 것

  • 잡동사니 켜도 본체 신호는 안 묻힘(A와 차이).
  • 동시 3~4로 올려도 각 적이 *자기 자리서* 차올라 안 엉킴.
  • C 페이드 끄기 → 코앞 다수서 벡터가 중앙에 몰려 혼잡해지는 것 확인(왜 페이드가 필요한지).
  • 벡터 끄기 → B만으로도 "언제"는 읽히되 "나를 노리는 놈"이 덜 또렷.
