2. **게이지 스텁** — 상시형: 처리 행동으로 상승(멀티킬·읽고-처리·연쇄), 시간 감쇠(ULTRAKILL 15pt/s 참고), 피격 시 감쇠. 회복·관대함 배율 훅만 노출(Stage 2에서 연결).

## 4. 단계

**Stage 0 — 유저 숙제(병행 가능):** 06-24 프로토(_CombatSlice_ReadAndCut)+Day2 스텝인 플레이 판정 → 읽고-베기 증폭 설계에 피드백.

**Stage 1 — 기준값 (특별 2번 OFF):** 가르기+읽고-베기+배려 기본층+읽기 슬로모+밀어버리기. **목표 밀도에서 검증** — 잡몹 40~80(5마리 랩은 거짓말) + 엘리트 1~2 혼합. 토글 하나씩 끄고 켜며 G4. 배려 기준값 동결. ★관찰(Codex 반증): **커밋 낚시**(사거리 밖 대기-수확 플레이) 발생 여부 · 슬로모가 밀도에서 소음화되는지(고가치 트리거 필터 검증).

**Stage 2 — 실적 결합:** 게이지→회복·관대함(+20~30%) 연결, 감쇠 체감. G5. ★관찰(Codex 반증): **저점 안전망** — 저실적 상태에서 나선 하강 체감 없나(기본 배려 바닥값 유지 확인) · **보험 사육** 유인 없나(전투 종료 시 게이지 처리 노브).

**게이트(구현 시):** 씬/프리팹 편집+3+스크립트 동작 변경+게임감 → **Stab+Codex 자동 게이트, 재량 없음.** 손맛 판정=유저.

## 5. 구현 분배 (모델 라우팅)

- 가르기 손맛·배려 튜닝·읽기 슬로모·밀어버리기 체감 = **게임감 그 자체 → 오케스트레이터 직접.**
- 토글 인프라(배려 on/off 콘솔/인스펙터)·랩 씬 골조·게이지 스텁 수치 배선 = 기계적, 수락기준 객관 → Sonnet-Gameplay 위임 가능(핸드오프 게이트: diff+플레이어블 확인 후 수락).
- 잡몹 넉백 = 게임감 섞임(밀림의 무게) → 오케 직접 또는 Gameplay `model: opus`.
- 몬스터 커밋/텔레그래프 쪽은 별도 트랙([[2026-06-28-monster-attack-redesign-grounding-handoff]] §0.5 정합 조항) — 랩은 기존 구현 5종 재사용.
