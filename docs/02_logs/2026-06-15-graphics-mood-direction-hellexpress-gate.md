# 그래픽 무드 방향 — Hell Express 시각 게이트 결과 & 권고 (2026-06-15)

> 상태: **권고(미동결).** 최종 미적 콜·북극성 채택 여부 = 유저. 이 문서는 시각 게이트(vc+Codex) 실측 + 오케스트레이터 권고 기록.

## 0. 한 줄
"헬익스처럼" = 룩 복제 ❌ → **헬익스의 *원리*만 차용해 우리 관용구(스타일라이즈드 로우폴리·수직 부감 15~20m)로 번역.** 갭의 정체는 엔진/구매가 아니라 **셋드레싱 + 라이팅 설계 작업**.

## 1. 시각 게이트 (독립 두 눈 수렴)
- **vc(VisualCritic, opus)** + **Codex(gpt-5.5, 크로스 프로바이더, vc 매개 없이 독립 실행)** — 우리 peak `docs/captures/style/s4_lighting_grade.png` ↔ Hell Express 공식 스틸 8장 대조.
- 레퍼 스틸: `_tmp_vfx_ref/hellexpress/he_01~08.jpg` (붉은동굴/화염야간/회청폐허/청색림보/사막주간/god-ray풀밭/실내드레싱/대규모전투부감)
- **수렴 결론: "타깃에서 멀다 — 단 URP 기술 한계가 주범이 아니다."**

### 갭 순위 (두 눈 합의)
1. **★셋드레싱 밀도 / 화면 정보량("비어있음")** — 그레이드·LUT·셰이더·구매로 0%. 순수 아트/레벨드레싱 작업. *빛 옆에 드러낼 지오가 없으면 그레이드를 아무리 돌려도 빈 청색 공간이 남는다.*
2. **동기광(diegetic / motivated key light)** — 빛이 "있다"지 "장면을 지휘"하지 못함. 핵심광1 + 보조2~3, 강한 방향성, 라이트쿠키 필요.
3. **색온도 / 팔레트** — 거의 단색 남청. 난색이 면적이 아니라 장식 수준. → 보유 split toning으로 좁힘.
4. **볼류메트릭 빛기둥** — 헬익스 시그니처, 우리 없음. URP 기본 약함 → Renderer Feature / 포그카드 / 콘메시 / 볼류 에셋 필요(엔진 작업, 한 방 아님).
5. **노출 / 블랙레벨** — "고대비"가 아니라 "저노출"로 납작하게 잠김. 하이라이트 앵커 부족.

### 구조적 한계 (카메라)
**수직 부감(15~20m) → 헬익스식 빗금 god-ray·측면 림라이트가 구조적으로 약함.** 헬익스는 아이소 45°라 빛이 화면을 가로질러 빗금을 만든다. 우린 빛이 위에서 와 빗금이 안 생김 → 카메라 각 안 바꾸면 *근사*만 가능.

### 프레이밍 정정 (게이트 최대 수확)
헬익스 = "어두운 단일 룩" ❌ → **바이옴별 그레이드 스윙**(붉은동굴 따뜻 / 청색림보 / 회청폐허 어둠 / 사막 주간 / god-ray 풀밭). 공통분모는 *어둠*이 아니라 **①디제틱 키라이트 + 깊은 그림자 ②상시 볼류메트릭 ③고밀도 드레싱.** → "어둡게 깔면 헬익스 근접"은 잘못된 타깃.

## 2. 오케스트레이터 권고 — 방향
**채택: 헬익스 *원리* 차용 + 우리 관용구 번역.**

**차용할 원리:**
1. 동기광 + 깊고 *읽히는* 그림자(암부에 형태 남기기 — 저노출로 죽이지 말 것)
2. 셋드레싱 밀도 — 빛 옆에 드러낼 지오(보유 POLYGON 프롭/잔해, 부감 실루엣 클러스터)
3. 구역별 팔레트 스윙(split toning + 재질/광원 색, 단색 탈피)
4. 선택적 볼류메트릭(수직부감 한계 인정, 근사, 후순위)
5. 노출/블랙 = 고대비로(하이라이트 앵커 확보), 저노출 금지

**기각:**
- 준사실 PBR 디테일 추격(로우폴리 정체성·솔로 비용 함정)
- 아이소 god-ray 1:1 재현(카메라 구조 한계)
- "어둡게 = 헬익스" 오인

## 3. 작업 순서 (게이트 우선순위 + 보유자산 재사용)
1. **셋드레싱 + 동기광 배치** ← 1순위. 보유 POLYGON으로 즉시. *그레이드 아님.*
2. **구역별 팔레트 / 색온도** ← split toning 보유로 즉시.
3. **노출 / 블랙 튜닝**
4. **볼류메트릭** ← 엔진 작업, 후순위, 근사(무료 오픈소스부터).

## 4. 우선순위 경고 (정직)
**그래픽은 현 병목이 아니다 — 급습 메커닉 재미가 병목.** 이 방향은 *문서화하고 보류*: 메커닉 증명 후, 실제 게임플레이 씬에 **전체 treatment**로 얹어 위 노브 순서로 진행. 룩데브 고아 씬(ScanLit)에서 그래픽 토끼굴 파지 말 것. (treatment ≠ 씬별 원칙 — [[graphics_treatment_not_per_scene]])

## 5. 구매 함의
- **그래픽 에셋 지금 구매 불필요** — 갭 = 작업이지 쇼핑 아님. (볼류는 무료 오픈소스부터, 후순위)
- 환경/캐릭터 에셋은 **Unity 여름세일(6/25, 50%) + 메커닉 증명 후.** 번들 말고 낱개 50%가 이득(Synty 스토어 30% < Unity 50%).
- 주인공 = **Synty Sidekick**(무료 스타터로 프로토타입 → 세일 테마팩). Synty 리그(척추3, Unity Humanoid 자동매핑) → 공격 애니는 휴머노이드 팩 사서 리타겟.

## 6. 유저 판정 대기 (천장 — Claude가 못 가르는 것)
1. 헬익스가 북극성으로 맞나 / 디제틱 라이팅 드라마만 빌리고 디테일은 로우폴리식으로 갈지(방향 분기)
2. 블랙을 더 내릴지 vs "황혼의 적막" 의도 유지
3. 이 정지 캡처가 미적 합격선인가(정지로는 못 가름)
