## 오늘 한 작업

### 1. PROMETEO Car Controller 분석
**목적:** 언덕을 잘 못 오르는 문제의 근본 원인 파악  
**발견:** PROMETEO는 WheelCollider 기반. `motorTorque`를 4개 바퀴에 적용하면 WheelCollider가 접촉 법선을 내부 계산 → 경사면에서 자동으로 힘 방향 보정. FreezeRotation 없이 차체가 지면에 맞게 기울어짐.

**결론 (아케이드 게임 관점):**  
WheelCollider는 레이싱 시뮬레이션용 — 파라미터가 너무 많고, 우리가 공들여 잡은 드리프트 킥/그립/카메라 느낌을 전부 재구현해야 함. ZombieCrush 같은 아케이드 좀비 게임에는 오버스펙.  
**PROMETEO에서 가져갈 것: `centerOfMass` 하나뿐** (무게중심 낮춤 → 경사 안정성 + 코너링 전복 방지).

### 2. 경사 문제 해결 방향 결정: Capsule Collider 교체
**왜 Box → Capsule인가:**  
Box Collider는 모서리가 있어서 경사 전환점에서 걸림 → 차가 언덕을 못 오름.  
Capsule은 모서리 없음 → 경사면에서 자연스럽게 미끄러지듯 올라감.  
코드 변경 없이 Inspector에서만 교체 가능. 최소 침습적 해결.

**적용 방법:**  
차 GameObject → Box Collider 제거 → Capsule Collider 추가 → Direction: Z-Axis → 기존 크기에 맞게 Height/Radius 조정

### 3. CarVisuals.cs — Slope Tilt (지면 추종 기울기) 추가
**왜 B방식(시각 전용)인가:**  
FreezeRotationX/Z를 해제하면 좀비 충돌이나 울퉁불퉁한 지형에서 차가 뒤집힘.  
아케이드 레이싱 게임 표준 접근법: 물리는 수평 고정, 비주얼 메시만 지면에 맞게 기울임.

**구현 내용:**  
- `CarVisuals.cs`에 `Slope Tilt` 헤더 섹션 추가
- 매 프레임 `car.transform.position`에서 Raycast → 지면 법선 감지
- `Vector3.Dot(groundNormal, car.transform.forward/right)` → Asin → 경사 각도
- 기존 Pitch(가감속) + Roll(횡속도)에 경사 기울기를 합산
- Exponential decay lerp로 부드럽게 추종

**Stab 리뷰 발견 및 수정:**  
- `transform.position/forward/right` → `car.transform.xxx` 수정 (자식 오브젝트에 붙을 때 방향 오류 방지)

## 미완성 / 내일 해야 할 것

### [우선순위 1] CarVisuals Slope Tilt 마무리
Stab 리뷰에서 발견된 나머지 이슈들:

**A. groundCheckDist 너무 짧음 (0.5f)**  
경사 전환 시 차가 살짝 들리면 감지 실패 → 차체가 갑자기 수평으로 돌아가 보임.  
→ 기본값 1.0~1.5f로 늘리거나, `car.transform.position + Vector3.up * 0.3f`를 원점으로 올려서 쏘도록 변경 권장.

**B. 합산 기울기 상한 없음**  
오르막 가속 시 `_currentPitch(최대 4°) + _currentSlopePitch(최대 25°) = 최대 29°` 가능.  
의도한 값인지 확인. 과하게 기울어 보인다면 `maxTotalAngle` 상한 추가.

**C. groundLayer Inspector 할당 확인**  
미할당(=0) 시 Slope Tilt 완전히 비활성. 지면 레이어 반드시 할당 필요.
