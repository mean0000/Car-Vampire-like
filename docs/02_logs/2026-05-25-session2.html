Part 01

근접공격 → 원거리 공격 전환

"차로 좀비를 박아서 죽이는데, 왜 잘못 박으면 대미지?"
— 핵심 루프와 모순되는 근접 데미지 시스템 제거

이 게임의 핵심은 "차로 좀비를 치는 것"이다. 충돌 시 차에 데미지가 들어오면 플레이어는 회피 플레이를 하게 되고, 이는 게임이 의도한 방향과 정반대다. AI 나노봇 세계관을 활용해 모든 좀비를 원거리 공격으로 전환했다.

Part 02

투사체 예측 — 3차 진화

이동하는 차량을 맞추기 위한 예측 시스템을 3차례 설계하고 2번 폐기한 과정.

1차 시도 — 폐기
Angular Velocity 기반 곡선 예측
차의 회전 속도로 커브 궤적을 예측. totalLeadTime(1.8초)이 과도해 탄착점이 수십 미터 빗나감. Angular velocity 회전이 예측이 아닌 노이즈로 작용.
2차 시도 — 폐기
Quadratic Intercept 이차방정식
Halo, L4D, Overwatch 등이 사용하는 업계 표준 공식 적용. 그러나 이 공식은 "일정 속도" 투사체용이고, 우리 투사체는 고정 비행시간(Lerp) 방식이라 공식 전제 자체가 맞지 않았음.
3차 시도 — 채택
고정 비행시간 선형 예측
투사체가 항상 flightDuration초 후 도착하므로, 전체 리드타임만큼 현재 속도로 선형 예측. 물리적으로 정확하고 코드 3줄로 해결.

최종 구현

float totalLead = remainSearch + lockTime + flightDuration;
_aimTarget = _target.position + carVel * totalLead;

핵심 교훈: 투사체 모델(일정 속도 vs 고정 시간)에 따라 올바른 예측 공식이 다르다. 복잡한 공식이 항상 정답은 아니다.

Part 03

좀비 변종 시스템

3종 좀비가 80% 코드를 공유(이동, 스폰, 킬, 터레인)하므로 상속 대신 enum 분기를 선택. FixedUpdate에서 공격 로직만 switch로 분기한다.

Ranged (원거리형)
기본 좀비 — 포물선 투사체
  • 사거리 25m에서 정지 후 사격
  • 선형 예측 + 랜덤 산포
  • 착탄 지점 인디케이터 표시
  • Search → Lock → Fire 흐름
Charger (돌진형)
코너 차단자 — 커브 안쪽 점거
  • 직선에서는 위협 없음
  • 코너링 감지 시 안쪽으로 이동
  • 1.8배속 돌진 → 측면/후면 데미지
  • 정면 충돌 시 일반 킬 (보상)
Laser (레이저형)
히트스캔 저격 — 붉은 조준선
  • 30m에서 정지, 2초 조준
  • 붉은 레이저 조준선 표시
  • 히트스캔 즉발 데미지
  • 조준 시작 후 거리 무제한
