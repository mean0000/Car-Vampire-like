ZombieCrush 몬스터 시그니처 오라 보드 — 제안 v1

2026-06-14 · 등급 온도축 + 부위 발광 규칙 + 공격 악센트 + 속성→형태 매핑 · 수치 전부 제안, 유저 판정
핵심 원리 3줄
1. 오라 = 변이 등급 온도계 — 차가운 탁한 청록(약함) → 뜨거운 붉은(강함). 색이 곧 위협도 읽기다.
2. LV1~2 오라색은 플레이어 시안(#2DE2E6)과 절대 섞이지 않는다 — 적은 탁하고 자연스러운 변이색, 플레이어는 형광 포화 인공색. 아래 분리 증명 색칩 참고.
3. 공격 텔레그래프 = 항상 레드오렌지(#FF5A2C) 베이스 — "위험하다" 는 등급 무관 동일 언어, 오라색은 악센트로만 가미.

01 / 플레이어 시안 vs LV1~2 오라 — 분리 증명

두 색을 나란히 놔서 부감 호드(15m 탑다운)에서 "내 시안"과 섞이지 않음을 확인. 판정 포인트.
#2DE2E6
플레이어 시안 — 인공 신호
§3-3 "인공색 = 나" 절대 규약. 형광·포화·날카로운 청. 슬래시 궤적·킬 버스트·HUD. 이 색은 적이 절대 쓰지 않는다.
vs
#4BAF90 (제안)
LV1~2 오라 — 탁한 변이 청록
채도 낮음·녹 방향으로 기울어짐(teal-green). 자연 변이색 — 해조류·곰팡이·바이오매스. 형광 인공감 없음. 부감에서 시안과 즉시 구분 가능 여부가 판정 핵심.
★ 대안 LV1~2 후보 — 더 탁하게(#3d8c72), 더 녹색으로(#5ab87a), 황녹 쪽으로(#88b840). 아래 등급 스트립에서 같이 보고 판정.
#4BAF90
후보 A — teal-green (제안 기본)
청록 중간. 시안보다 녹 방향 + 채도 -40%
#3D8C72
후보 B — 더 탁하게
명도 낮춤. 어둠 속 약한 발광 느낌. 위협감 더 낮음
#5AB87A
후보 C — 녹 비중 높임
자연 변이(균류/이끼) 연상. 플레이어 시안과 최대 거리
#88B840
후보 D — 황녹
가장 "생물학적 변이" 느낌. 시안과 완전 분리. 다소 독성 연상

02 / 등급 온도 그라데이션 — LV1 → LV5

차가운 자연 변이(약함) → 뜨거운 붉은 위협(강함). 색이 곧 실력이자 위험 알림.
LV1 LV2 LV3 LV4 LV5
#4BAF90
LV 1
탁한 청록
발광 강도 약 (어둠 속에서만 눈에 띔). 변이 초기. 눈·등 등 소면적 한 곳만 발광. 호드 최다 등장.
#3D9C78
LV 2
심화 청록
LV1 대비 발광 약간 더 강함. 2곳 이하 발광 가능(눈+등 등). 여전히 차가운 자연 변이색.
#FF7C35
LV 3
주황
온도 전환점. 위협 레드오렌지 계열 진입. 발광 면적 확장(눈+등+관절 1). ThreatArc와 색 계열 정합.
#FF5A2C
LV 4
레드오렌지
위협 경고색과 동일 계열 — 오라만 봐도 "위험" 즉각 읽힘. 발광 부위 3~4곳. Fulgurodonte 전기속성 = 형태(스파크)로 분화, 오라 등급색은 레드오렌지 유지.
#C41A1A
LV 5
붉은 + 검은 입자
변이 말기·위협 극대. 오라색=진홍+어둠(#C41A1A~#1A0000 그라데이션). 검은 입자(어둠 방울) 추가. 발광 부위 4~5곳 + 열기 시머.

03 / 부위 발광 규칙 — 신체 유형별 가이드

전신 발광 X. 변이 핵심부 = 해당 종의 "이야기하는 부위"만 빛남. 부감 15m 가독성 기준.
신체 유형 LV1~2 (탁청록) 발광 부위 LV3~4 (주황/레드) 추가 부위 LV5 (진홍+검정) 전체 부감 가독성 포인트
2족 직립형
Caniathrox 류		 눈 (핵심 1곳) 눈 + 등 척추 라인 + 어깨 관절 전술 부위 5곳 + 검은 입자 trail 눈 발광 = 방향 읽기 핵심. 척추 라인 = 탑다운에서 실루엣 강화
4족 돌진형
Crassorrid 류		 등 혹(변이 핵심부) 등 혹 + 어깨 2곳 + 머리 이마 등 + 머리 + 발굽/발톱 + 입가 탑다운에서 등이 항상 노출됨 = 등 발광이 1순위 식별자
원거리 사수형
Venodonte 류		 입/분비기관 (발사 전 예열) 입 + 복부 발사기 + 눈 전신 분비선 다수 입·복부 발광이 공격 예고 = 텔레그래프와 오라 자연 통합
대형/보스형
LV5 단독 등장		 해당 없음 해당 없음 눈 + 등 + 관절 + 거대 혹 + 입 = 발광 풀셋
검은 입자 상시 방출 (이동 trail)		 진홍+검정의 대비가 "이건 다르다"를 즉시 전달. 부감에서 실루엣만으로 보스 식별
발광 강도 규칙 — HDR 발광(Bloom 트리거) 강도는 등급에 따라 단계적으로 상승.
LV1: Emission intensity 1.5 / LV2: 2.0 / LV3: 3.0 / LV4: 4.0 / LV5: 5.0 + 검은 입자 추가 (전부 제안 — 플레이 중 조정).

04 / 공격 악센트 — 위협 레드오렌지 베이스 + 오라색 가미

ThreatArc·임팩트는 항상 위협색으로 먼저 읽힌다. 오라색은 "누가 공격하는가"를 얹는 악센트.
LV1~2 텔레그래프 / 임팩트 — 위협 85% + 오라 15%
위협 레드오렌지 #FF5A2C (85%)
오라 청록 (15%)
악센트 = ThreatArc 외곽 테두리 실선, 파티클 끝 색조 미세 변화
LV3~4 텔레그래프 / 임팩트 — 위협 70% + 오라 30%
위협 레드오렌지 #FF5A2C (70%)
오라 주황 (30%)
오라 주황이 위협색과 계열이 같아서 자연 통합 — 악센트 비율 더 높여도 가독성 유지
LV5 텔레그래프 / 임팩트 — 위협 60% + 오라 진홍 40%
위협 레드오렌지 #FF5A2C (60%)
오라 진홍 #C41A1A (40%)
보스 텔레그래프 = 어두운 진홍이 섞여 "더 위험한 경고"로 온도 에스컬레이션
충돌 방지 원칙 — 공격 시 오라색이 절대 시안(#2DE2E6) 쪽으로 이동하지 않는다. LV1~2 청록 오라가 공격에 악센트로 쓰일 때도 탁한 teal-green으로 유지 (형광 시안 ❌). 확인 방법: ThreatArc 외곽 악센트 색을 시안 옆에 놓고 육안 비교.

05 / 속성 분화 — 색 대신 형태/입자/패턴으로

기존 "산성=녹/전기=청백/가스=황" 색축은 등급 온도축으로 교체. 속성은 발광 형태·입자 모양·텔레그래프 패턴으로만 분화.
★ Fulgurodonte(LV4 전기)처럼 속성색(청백)이 등급색(레드오렌지)과 충돌하는 경우 → 등급 우선.
산성 (Acid)
형태 분화
오라 — 등급 온도색 유지
발광 형태 — 방울(Droplet) 형태. 표면에서 떨어지는 이슬방울 모양 파티클. 느리게 떨어짐
연기 — 부식 연기 (낮게 퍼짐, 투명도 높음)
텔레그래프 — ThreatArc 위에 방울 아이콘 반복 패턴 (오버레이)
형태 키워드: 방울 · 연기 · 퍼짐 · 느린 낙하
전기 (Electric)
형태 분화
오라 — 등급 온도색 유지 (Fulgurodonte LV4 = 레드오렌지. 청백 금지)
발광 형태 — 스파크(Arc) 형태. 표면에서 튀는 번개 아크, 짧고 불규칙한 선
파티클 — 고속 방사형 점(스파크 튐), 수명 매우 짧음
텔레그래프 — ThreatArc 라인이 직선 지그재그(번개 모양) 변형
형태 키워드: 아크 · 스파크 · 지그재그 · 순간성
가스 (Gas)
형태 분화
오라 — 등급 온도색 유지
발광 형태 — 뿜김(Puff) 형태. 천천히 퍼지는 구름 실루엣, 반투명 넓은 면적
파티클 — 낮게 깔리는 안개 레이어, 천천히 팽창 후 소멸
텔레그래프 — ThreatArc가 원형 확산 패턴 (부채꼴 대신 전방위 확산)
형태 키워드: 뿜김 · 안개 · 팽창 · 면적

06 / 기술 구현 강도 — 옵션 선택 (유저 판정)

구현 비용과 비주얼 퀄리티의 트레이드오프. A→C 순으로 비용 증가.
옵션 A
림 프레넬만 (최소)
MonsterActor 셰이더 림 컬러 = 오라색. Emissive 마스크 텍스처로 발광 부위 제한. 파티클 없음. 가장 가볍고 즉시 적용 가능.
옵션 B
림 + Emissive 펄스 (권장)
림 + sin파 펄스 Emissive 스크롤. 등급별 pulse speed 노브(LV1 느림→LV5 빠름). 파티클 없이 생동감. 기존 킬버스트 셰이더 구조 재활용 가능.
옵션 C
림 + 펄스 + 파티클 (풀)
B + 공격 전조 wind-up 파티클 추가(기존 VfxDirector wind-up 글로우 재활용). 속성 형태도 파티클로. 호드 다수 시 overdraw 주의 — culling 필수.
권장 — 옵션 B를 기본 롤아웃(즉시 가능), LV5 보스 한정 옵션 C 적용. 호드 구성(LV1~2 다수)은 옵션 A/B로 overdraw 억제. 구현 시작 전 유저가 강도 선택.

07 / 부감 색 분리 검증 목업

탑다운 15m 시점. LV1~2 청록몹 + LV4 레드오렌지몹 + LV5 진홍몹 + 플레이어 시안 동시. 색 분리 육안 확인용.
내 슬래시 (시안 #2DE2E6)
LV1 청록 (#4BAF90)
LV2 청록 (#3D9C78)
LV3 주황 (#FF7C35)
LV4 레드오렌지 (#FF5A2C)
LV5 진홍+검정 입자 (#C41A1A)
텔레그래프 (레드오렌지 베이스)
← 시안 vs 청록 분리선
★ 목업에서 플레이어 시안(중앙 슬래시)과 좌측 LV1~2 청록몹이 다른 색역으로 읽히면 분리 성공. 비슷하게 느껴진다면 LV1~2 오라를 후보 C(#5AB87A 녹 강화) 또는 후보 D(#88B840 황녹)로 이동.
유저 판정 포인트
① LV1~2 오라 색 선택 — 제안 기본 #4BAF90 OK? 아니면 후보 B(더 탁하게 #3D8C72) / C(녹 강화 #5AB87A) / D(황녹 #88B840)? 목업 §07에서 시안과 분리 충분한지 확인.
② LV5 검은 입자 방향 — "진홍+검정" 표현을 파티클(구현 비용↑) vs Emissive 마스크(검은 면적, 저비용)로 할 것인지.
③ 구현 강도 선택 — 옵션 A(림만) / B(림+펄스, 권장) / C(풀+파티클). 호드 LV1~2는 A/B, LV5 보스는 C 분리 적용 검토.
④ 속성 분화 방향성 — 색 대신 형태로 분화(전기=스파크/산성=방울/가스=뿜김) 동의? Fulgurodonte(LV4 전기)의 오라색이 청백 → 레드오렌지로 바뀌는 것 OK?
⑤ 공격 악센트 비율 — LV1~2 "위협 85% + 오라 15%" 악센트가 충분히 보이는지, 더 늘려야 하는지.
