# Synty BR 데모 레이아웃 분석 — "왜 이렇게 깔았나" 추론

> **작성**: 2026-06-14 · 출처: `Assets/Synty/PolygonBattleRoyale/Scenes/Demo.unity` 직접 열어 톱다운+줌 캡처 분석 (`docs/03_reference/assets/map_refs/synty_br_demo_top.png`, `_zoom.png`)
> **목적**: 우리가 "무지성 배치"로 망친 맵을, Synty 제작자가 *직접* 이 키트로 어떻게 깔았는지 추론해 제대로 된 방법론으로 전환. (유저 지시: 한 칸 한 뼘 신중하게)

## 0. 한 줄
**우리 맵이 쓰레기였던 이유 = 밀도0·소품0·식생0·단조·통짜도로·단색지면.** Synty 데모는 그 반대 — *진짜 도시처럼* 빽빽·다양·텍스처. "예쁘게"가 아니라 "진짜처럼 채움"이 핵심.

## 1. 전체 구조 (관찰)
- **유기적·비대칭 섬** — 격자 ❌. 물 + 펜스로 둘러싼 바운디드 존(우리 봉쇄벽과 같은 발상, 단 자연 경계=물).
- **밀도 그라디언트** — 빽빽한 중심부(타운·산업 허브) → 듬성한 가장자리. 우리 동심원 의도와 정합.
- **랜드마크 허브** — 중앙 크레인+산업 건물+컨테이너 야드가 눈을 끄는 거점(우리 코어 비콘과 같은 역할).

## 2. 도로 = *진짜 시스템* (우리 최대 실패 지점)
- 검정 아스팔트 **+ 모래/흙 갓길**(★유저가 말한 "좌우 베이지 흙길=외곽, 검정 아스팔트" 규약 = Synty 도로 타일 그 자체).
- **적정 폭**(2차선급) — 우리가 쓴 20m 통짜 막대 ❌. 도로가 *과하게 넓지 않다*.
- **굽어서 군집을 연결** + **교차점**(코너·T·교차로 피스로 물림). 직선 타일을 줄로만 깐 우리와 정반대.
- 도로변에 **사이드워크·가로등·표지·잔해**가 붙어 "길"이 살아있음.

## 3. 클러스터 = 동네 정체성
- 건물을 *군집*으로 묶고 각 군집이 정체성을 가짐:
  - **주거 줄** — 작은 집들이 *줄지어 도로를 향해 정렬*(지붕색 빨강/노랑/회색 다양), 셋백 일정.
  - **산업 야드** — 크레인+창고+컨테이너 스택(우리 코어 야드 모델).
  - **상업/잡** — 중형 건물 묶음.
- 건물이 *띄엄띄엄 부유* ❌ → 블록/군집으로 *도로변에 앉음*.

## 4. ★밀도 + 세트드레싱 (가장 큰 교훈)
- 건물 사이 **모든 틈을 메우는 소품 더미**: 차량(승용/트럭/버스), 크레이트·드럼통·팔레트, 바리케이드, 잔해, 컨테이너, 작은 잡동사니.
- **식생** — 나무·덤불 군집이 모래 바닥을 깨고 생기·차폐 제공.
- → 화면에 빈 공간이 거의 없음. 우리 텅 빈 베이지와 정반대. **밀도가 "진짜감"의 본체.**

## 5. 재질·색·지면
- 지붕색·벽재 **다양**(단조 ❌) → 시각 리듬.
- 지면 = **텍스처(모래/흙)** + 도로/사이드워크/풀 패치가 깔린 *복합 바닥*. 평평 단색 쿼드 ❌.

## 6. 우리 맵에 주는 규칙 (다음 블루프린트의 입력)
1. **도로**: 통짜 20m ❌ → 적정 폭 + 갓길 + 코너/T/교차로 피스로 *제대로 물려* 굽은 망 구성.
2. **클러스터 정체성**: 주거 줄(정렬·도로향·색다양) / 산업 야드(크레인·컨테이너·창고) / 상업 묶음 — 각 동네 다르게.
3. **밀도 의무**: 건물 사이를 차량·잔해·드럼·바리케이드 + 식생으로 *꽉* 채움(빈 베이지 금지). ← 우리 폐허는 여기에 Rubble·Destroyed car 다수.
4. **지면**: 단색 쿼드 ❌ → Synty 지면/도로/사이드워크 타일 복합.
5. **색·재질 다양성** 확보.
6. **밀도 그라디언트 + 랜드마크 허브**(코어 비콘) 유지 = 우리 자연끌림 독트린과 정합.
