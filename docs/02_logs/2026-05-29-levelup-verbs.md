## ★ 2026-05-31 세션 확정 (현행 최상위 기준)

이 세션에서 진행 모델·무기·네이밍을 확정. **카드 전체 명세는 별도 핸드오프 문서**(`2026-05-31-levelup-cards-handoff.md`)에서 다음 세션에 작성.

### 진행 모델: C안 — 누적 + 청크 + 진화 (뱀서식)
- 카드는 **Lv1→3 누적 강화**(같은 카드 또 뽑으면 레벨업), 만렙 시 **진화**.
- 매 레벨은 **청크**(조건완화 / 절 추가 / 체감되는 수치). **미미한 +%스탯 금지.**
- 진행문서 "스탯 금지" 원칙 → **"미미한 스탯 금지, 청크 성장 허용"**으로 갱신.
- 가진 카드를 계속 레벨업 가능 → **풀 고갈 자동 해결**. 인위적 "캐릭터 레벨 티어 게이트" **폐기** (티어 = 그 카드 자신의 레벨).

### 2층 카드 풀
- **기본 카드**(바닥·자주): 청크 스탯 — 무기 / 생존 / 이동 / 유틸. 쉬운 결정, 굴러가게 함.
- **동사 카드**(천장·가끔): 조건부 질적 행동 = 빌드 정체성.
- **+ 무기 시그니처**: 선택한 무기 장착 시에만 드로우 등장.
- 드로우 2택1. 초반 기본↑, 레벨 오를수록 동사↑. 기본/동사/시그니처 모두 Lv1→3, 동사만 진화.

### 무기 / 캐릭터 (MVP 동결)
- **MVP = 단일 캐릭터**, 런 시작 시 **근접(야구방망이) vs 원거리(권총) 택1**.
- **암살(F, 무음 즉사)은 공용** — 무기가 아니라 스텔스 행동. 근접/원거리는 "시끄러운 주력 도구"만 가름.
- **죽은 슬롯 0**: 드로우 풀 = 계열 등뼈 동사 + 선택 무기 시그니처만.
- **post-MVP 비전**: 캐릭터 4종(칼잡이/총잡이/폭파공/드론) × 무기 패밀리. **현실 무기**(나이프·권총·파이프폭탄·FPV드론…) 기본 무기로 시작 → 같은 패밀리 내 강화/분기.

### 무기 획득 모델 — 수직 보장 / 수평 따냄
- **수직(깊이) = 보장**: 시작 선택 + 흔한 상자·부품·레벨업으로 *고른 무기*가 꾸준히 깊어짐 → 루즈 방지.
- **수평(확장) = 따냄**: *새* 무기 패밀리는 위험 구역·엘리트 처치·귀환 cash-out 도박으로 (post-MVP). 코어 빌드를 막지 않는 사치 → 무용담.
- **상자**: 부품 / 설계도(해금) / 소모품. 2택1, 중복 설계도 → 부품 자동 변환(꽝 방지).

### 네이밍 컨벤션 (codex 자문 + 웹 리서치 수렴)
- **기본 카드 = 명확 기능형 이름 + 고정 subtitle** `[조건] → [효과]`. 2지선다 순간판단 최적.
- **진화 카드만 플레이버 허용** (강력한 순간이라 멋이 어울림).
- 리네임 예: 공허의 발소리→**무음 보행**, 혼돈의 코어→**소음 폭주**, 오염된 근육→**감염 가속**, 피의 리듬→**연속 처치**.

### 정합성 수정
- **감염 임계 0~1 정규화**: 문서의 0~10 표기는 코드 `SyncRateManager.SyncRate`(0~1)로 통일. 예: "감염 ≥7" = `SyncRate ≥0.7`.
- **"근접" 전제 동사 → 무기 무관 재서술**: 전투 등뼈(연속 처치·소음 폭주 등)는 소음·킬에만 반응, 무기 불문.

## 0. 리서치 수렴 (설계 근거)

- **외부 검증**: *Mark of the Ninja*는 업그레이드를 **교란/공격 동사 카테고리로 분리** → 우리 3계열(스텔스/전투/감염)과 동일 발상.
- **가장 강한 빌드 엔진 = 생산자→소비자 루프**: 동사 A의 *효과*가 동사 B의 *조건*을 충족. 보상을 **데미지가 아닌 화폐(소음/감염/상태)**로 지급하면 "+%"가 아니라 *질적 행동*으로 읽힘. (Hades 크릿→표식→크릿) → **우리 코어(소음·감염)가 곧 시너지 통화.**
- **감염 계열(위험-보상) 4대 원칙** (Bloodborne/DD/PoE/RoR2/Dead Cells 만장일치):
  1. **볼록 비용(convex)**: 감염 높을수록 *수신 피해도 증가* → 강해도 무섭게.
  2. **빌드 옵트인**: 고감염 능력은 *고른 사람만*, 저감염일 땐 죽은 슬롯 → 기회비용 → 남발 방지.
  3. **능동적 배출구**: 내려가는 길이 능동/위험해야(귀환=위험한 복귀). 가만히=AFK 퇴행 방지.
  4. **연출은 계속 위협적**: 감염↑ = 화면/음향/캐릭터 부패 심화. "수치는 좋아하는데 감각은 비명" = 우리가 원하는 짜릿함.
- **조건 문법 4종** (스텔스 게임): **State**(상태) / **Position**(위치·반경) / **Timing**(시간창) / **Resource**(자원·쿨다운).
- **교란 동사 튜닝축** (Desperados): 반경 × 지속 × 대상상태. (동전=점·순간 / 고양이=이동 / 호각=광역)

## 5. 레벨업 곡선 · 티어 · 공명

### 킬 곡선 (암살 = 킬 +2 카운트 → 스텔스도 레벨업)
```
Lv1→2: 8킬 / 2→3: 20 / 3→4: 38 / 4→5: 62 / 5→6: 92 / 6→7: 130 / 7→8: 175
공식: 다음 = 이전 ×1.4 + 5  [튜닝]
```
- 매 레벨업: **같은 계열 1개 + 다른 계열 1개** 제시 → 2중 1 (혼합 유도).
- 풀 런 ≈ 7동사 누적 (Hades식 축적 모델 + 슬롯캡 없음). 정체성 = 무엇을 골랐나 + 공명.

### 티어
- **T1(Lv1~3)**: 기초 조건+효과, 빌드 방향 예고.
- **T2(Lv4~6)**: 조건부 강화, T1과 시너지.
- **T3(Lv7+)**: 진화 — T1 동사를 직접 강화하거나 새 규칙.

### 계열 공명 (몰빵 보상)
같은 계열 3개 이상 → 조건 임계 완화:
- 스텔스: 웅크림 없이 소음 ≤10이면 S군 발동
- 전투: 연속 킬 카운터 5→3
- 감염: 임계 -2 (I1은 5+, I2는 3+) — 단 볼록 비용도 빨라짐 ⚖️

## 7. MVP 최소 세트 (계열당 3개 = 9개)

전부 "조건 분기 + 수치 데이터"라 **새 애니/무기 없이** 구현 가능:

- **스텔스**: S1 공허의 발소리 · S2 유리 심장 · S3 소음 미끼
- **전투**: C1 피의 리듬 · C2 파열 · C3 단단한 껍질
- **감염**: I1 혼탁한 냄새 · I2 오염된 근육 · I3 전이 (+ 볼록 비용 규칙)

→ 9개로 *세 빌드 방향(스텔스집중/전투집중/감염도박)*이 명확히 갈리는지 검증. 통과 시 풀 풀로 확장.

**런치 후 우선순위**: S4(연쇄암살) → C4(소음폭발, 전투 개성) → I7(감염 화폐 명시) → I6(감염 클라이맥스) → S6+S9/I4(전술 발견 묶음).
