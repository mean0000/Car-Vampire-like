1코어 원칙

죽음 연출 예산을 보상 곡선으로 쓴다 — 평범한 죽음은 확인, 화려한 죽음은 뽕=돈. 티어 상승을 게임플레이 보상 트리거(오버킬 · 노히트 연속 · 궁극킬)에 묶는다. ★ 잡몹이 화려하면 위계가 붕괴(엘리트/보스가 안 특별해짐) → 잡몹은 의도적으로 절제.

3스킨드 메시 규칙 — BakeMesh 언제 필요한가

✅ 불필요

  • 디졸브 / 정점폭발 셰이더 — GPU 스키닝이 정점셰이더 전에 돌아 변형 포즈 위에서 작동
  • RayFire SkinnedMesh 모드 (내부 베이크)
  • 파티클 깁 (범용 청크)
  • 래그돌 (본 구동)

⚠️ 필요

정적 지오메트리를 먹는 물리 경로 — Blender Cell Fracture 청크, 자작 비-RayFire 슬라이서. 죽는 순간 SkinnedMeshRenderer.BakeMesh()로 현재 포즈 스냅(안 하면 T포즈 청크). Cell Fracture는 블렌더에서 대표 죽음포즈로 베이크 후 조각.

4셰이더 정점폭발 + 디졸브 스펙 — 강점 구역, 1차 도구

URP ShaderGraph (Lit, Alpha Clip on). 프로퍼티: _DissolveAmount(0~1) · _ExplodeStrength · _DissolveNoiseTex · _DissolveEdgeWidth · _EdgeEmissiveColor(HDR) · _EdgeEmissiveIntensity.

정점 단계

object-space 노이즈 × _DissolveAmount × _ExplodeStrength × 노멀 → Position에 가산(바깥 팬아웃). ※셰이더는 청크 분리 못 함 — 소프트 디스인테그레이트만(하드 청크=사전조각 필요).

프래그 단계

노이즈 − _DissolveAmount → Alpha Clip(0). 엣지 글로우=smoothstep(0,_DissolveEdgeWidth, n−amount) 반전 × _EdgeEmissiveColor*Intensity → Emission.

★ 구동(런타임): MaterialPropertyBlock로 _DissolveAmount 0→1 (DOTween). 절대 material.SetFloat 금지(인스턴스 복제→인스턴싱 깨짐·GC = 호드 최다 버그). 완료 시 SetActive(false)→풀 반납.

// 디졸브 구동 스텁 (MPB + DOTween)
var mpb = new MaterialPropertyBlock();
int ID = Shader.PropertyToID("_DissolveAmount");
DOTween.To(() => 0f, x => { mpb.SetFloat(ID, x); smr.SetPropertyBlock(mpb); },
           1f, 0.5f).SetEase(Ease.InQuad)
         .OnComplete(() => gameObject.SetActive(false)); // → 풀 반납

5주스 스택 순서 — Elite 기준, 가감해 티어 적용

  1. 프레임0: 히트스탑(timeScale 0.05~0.15, 1~2프레임; 파티클은 unscaled) + 발광 플래시(MPB, 레드오렌지/화이트, 1프레임)
  2. 프레임1~5: 쉐이크 시작(횡방향, Z줌 금지) + 파티클 버스트(위+밖) + 디졸브 트윈 시작
  3. 프레임5~15: 깁(엘리트, 2~3) + 데칼 스탬프 + timeScale 복귀
  4. 이후: 디졸브 완료 → 파티클 페이드 → 데칼 3~5s 페이드

원거리 가독 우선순위: ①발광 플래시 ②파티클 방사 ③디졸브 엣지 글로우. 쉐이크=느껴지나 안 보임. 데칼=지속 레이어(부감 최적, "여기서 죽었다").

6색 전환 — 캐넌 정합

생전 레드오렌지(위협)  →  킬 시안/화이트 플래시(우리 액션색=킬러색)  →  디졸브 엣지=시안/마젠타(붕괴)  →  데칼=탈채도 적갈

UI 없이 "위협 제거" 가독. 데칼은 죽은 웅덩이가 살아있는 적으로 안 읽히게 탈채도.

7퍼포먼스 규율

  • 풀링 전부(VFX 플레이어 · 깁 · 데칼 · 오디오), Destroy 금지
  • ★ MaterialPropertyBlock 필수 (material.SetFloat=인스턴싱 깨짐·GC)
  • Player Settings GPU Skinning ON (호드 50+)
  • 거리 LOD 게이트(>12m=플래시만, 50~70% GPU 절감)
  • 동시 rich death 캡 — 프레임당 풍부죽음 N개, 초과분 싼 팝으로 강등
  • 청크/데칼 1~3s 페이드로 활성 물리 수 bounded · 오디오 보이스 리미팅(AudioMixer)
