## 0. TL;DR

- **역할 삼각(비겹침):** RMB 차징(거합·기존) = **모아서 한 줄을 뚫는다**(정지 충전→관통 집중 화력, 고수) / **E(신규)** = **몸을 던져 앞을 연다**(순간 전진 돌파, 카이팅의 답) / **R(신규)** = **한 번에 다 벤다**(수평 반토막 처형 스펙터클, 정점). 셋 다 "뚫기"(전진)지만 *케이던스·표현·조준 부담*이 정반대라 안 겹친다.
- **카이팅 문제(핵심 미해결)의 답 = E.** E는 **뒤로 갈 수 없는 파워 버튼** — 조준 방향으로만 변위한다. "숨통 트려면 앞으로 가야 한다." 밀도 보상(더 많이 맞힐수록 큰 효과)으로 *호드 속으로 파고드는* 인센티브를 물리로 박는다. 제자리 방사 노바는 카이팅을 못 막으므로(노바 치고 계속 뒷걸음 가능) **기각**, 06-26 "숨통트기/포위일소"를 *전진형*으로 재정합.
- **E 리드안 = A 일섬(一閃, 거합/고수·관통 돌파).** 대안 = B 선풍참(참격/뉴비·포위 숨통), C 인(引, 하이브리드·처형 낚아채기).
- **R = 스타일/킬 게이지 충전 → 수평 반토막+디졸브.** 화이트박스는 *가짜 반토막*(긴 라인 광역 즉사 + 시안 디졸브 + 줌/화이트아웃)으로 오늘 프로토 가능. 진짜 절단(RayFire)은 구매 후 레이어.
- **구현 난도:** E-안A/B = *데이터 + 소폭 배선*(AddGlide·대시 i-frame 재활용). E-안C = *파생 클래스*(타겟 스캔+홈잉 대시). R = *데이터(판정·즉사 디졸브) + 소폭 신규(게이지 컴포넌트) + 에셋(RayFire)*.

## 1. 기술 프레임 실측 (2026-07-05 — 무엇이 이미 배선됐나)

`KatanaWeapon.cs` + `WeaponActionSet.cs` 정독 결과. **E/R 슬롯은 코드가 이미 끝까지 뚫려 있다.**

- **입력 배선 존재:** `OnTick`에서 `input.skillDown → TryBeginInstantAction(_skillRt)`(E), `input.ultimateDown → TryBeginInstantAction(_ultimateRt)`(R). 슬롯 SerializeField(`skillAction` / `ultimateAction`)가 비어 있어 무동작일 뿐, **에셋만 꽂으면 발동한다.**
- **데이터만으로 되는 판정 모양(파생 클래스 불요):** `DoActionHit` = **부채꼴(fan-cone)** — `range` · `arcHalfAngle` · `forwardOffset` · `damage` · `knockback`. ★`arcHalfAngle = 180`이면 **전방위(360° 방사)** 가 데이터만으로 성립(`Vector3.Angle ≤ 180` 항상 통과). → **넉백 노바·광역 스윙·집중 부채꼴은 전부 데이터.**
- **코드가 필요한 것(파생/배선):**
  - *전진 이동(대시 돌진)* — 판정은 데이터지만 **몸을 앞으로 보내는 것**은 SO에 없다. 단, `PlayerMotor.AddGlide(dir, dist, dur)`가 이미 존재(콤보 히트 글라이드가 씀) → **발동 시 AddGlide 1콜 = 소폭 배선**(파생 클래스 아님). 대시 i-frame도 기존 대시 로직 재사용 가능.
  - *절단선(관통) 판정* — `lineCut`은 현재 **콤보 전용**(액션은 부채꼴만). E를 진짜 관통선으로 하려면 `DoActionHit`에 lineCut 파라미터 노출 = 소폭 코드. (좁은 부채꼴로 근사하면 데이터만.)
  - *타겟 스캔/홈잉 대시·투사체·지속 멀티히트 회전* — 새 동작 = **파생 클래스**. (`_hitDone` 가드로 액션은 활성당 1히트라 지속 회전은 코드.)
- **재활용 자산:** 대시 위상 잔상(시안) · `ParrySlowMotion`(클래시/멀티킬 프리즈 소유 경로) · `NotifyHit` 투스테이트 줌인 · killburst/purge-snapshot FX · 죽음 연출 티어(즉사 디졸브). → **R 스펙터클의 절반이 이미 있다.**

**함의:** E-안A/B와 R은 *새 시스템 없이* 오늘 화이트박스 가능. 이 드래프트는 "무엇을 꽂나"에 대한 판정이지 "무엇을 만드나"가 아니다.

## 2. 역할 삼각 분담표 (RMB / E / R — 비겹침)

07-04 확정: **평타 = 거리유지·지속딜·압박완화(전진 ❌)** / **기술 = 전진성·대범위 돌파(뚫기)**. 세 기술 슬롯은 전부 "뚫기"를 하되 케이던스·표현·조준 부담이 정반대다.

| 축 | **RMB 차징(거합, 기존)** | **E 스킬(신규)** | **R 궁극(신규)** |
|---|---|---|---|
| 한 문장 | 모아서 한 줄을 뚫는다 | 몸을 던져 앞을 연다 | 한 번에 다 벤다 |
| 주 역할 | **집중 관통 화력** (라인·강적 처리) | **전진 돌파 + 대범위 숨통** | **피크 스펙터클** (수평 반토막 처형) |
| 케이던스 | 조준·차징 ~1.5s (자주) | 쿨 ~5~8s (반응, 가끔) | 게이지 만충 (드묾, 정점) |
| 전진 성격 | 짧은 committed 발도 런지 | **순간 대시 변위(뒤로 불가)** | 제자리 광폭(이동 아님) |
| 대가/리스크 | 차징 중 **정지=피격 취약**(고수 대가) | 쿨다운 · 대시 끝점 노출 | 게이지 소진 · 발동 경직 |
| 조준 부담 | 높음(라인 정밀) | 낮음(방향만) | 없음(전방 광폭) |
| 스킬플로어 | **거합 = 고수** | 후보별(A/C=고수, B=뉴비) | 캡스톤(누구나) |
| 카이팅 기여 | 중(라인 정리, 정지가 발목) | **★상(전진-전용 변위 = 답)** | 저(리셋용 정점) |

### 2.1 카이팅 문제에 누가 어떻게 답하나 — E가 본진

**진단:** 카이팅 = 호드를 뒷걸음으로 녹이는 퇴행. 원인 = 최적 플레이가 "뒤로 빼며 딜"이 되는 것. **평타가 전진을 못 하게 막힌(07-04) 지금, 전진 인센티브를 물리로 주는 유일한 자리 = 기술 슬롯.**

- **E = 뒤로 갈 수 없는 파워 버튼.** E는 *조준 방향으로만* 변위한다. "포위됐다 → 숨통 트는 버튼"인데 그 버튼이 당신을 **앞으로** 보낸다. 뒷걸음 카이팅과 물리적으로 양립 불가.
- **밀도 보상 노브:** E가 *더 많은 적을 맞힐수록* 효과(넉백/쿨 환류/딜)가 커지게 → 호드 *바깥으로 도망*이 아니라 *속으로 파고들 때* 최대 이득. 카이팅을 손해로 만든다.
- **06-26 재정합:** 06-26 세션 유력 E = "숨통트기/포위일소(밀어내기)". 그때 미결 포크 = *밀침이 이동기만 vs 평타까지*. **여기서 결론: 밀침은 E(기술)에만, 그리고 *제자리 방사가 아니라 전진형*으로.** 제자리 노바는 카이팅을 못 막으므로(치고 계속 뒷걸음) 기각. 07-04 "기술=전진"과 06-26 "숨통트기"의 교집합 = **전진하며 여는 E**.

## 3. E 스킬 후보 (2~3안)

세 안 모두 "전진 변위 + 숨통"이라는 카이팅 답을 공유하되, *뚫기의 형태*와 *스킬플로어*가 다르다.

| 항목 | **A · 일섬(一閃)** | **B · 선풍참(旋風斬)** | **C · 인(引)** |
|---|---|---|---|
| 한 줄 | 관통 돌진 베기 | 전진 회전 광역 | 처형 낚아채기 |
| 뚫기 형태 | 선(관통 복도) | 원(포위 일소) | 점(표적 급습) |
| 전진 | 대시 2.5~4m 관통 | 스텝인 1.5~2m + 회전 | 대상까지 가변 대시 |
| 트리/플로어 | **거합 / 고수** | **참격 / 뉴비** | 하이브리드 / 중 |
| 카이팅 답 | ★상 (far side로 뚫고 나감) | 중 (열되 전진 약함) | 상 (표적으로 끌려 들어감) |
| 대범위 | 선형 복도 | ★상 (전방위) | 저 (단일+미니 전파) |
| 간지 | iai 섬광 대시·시안 잔상·절단선 스탬프 | 원형 슬래시 링·방사 튕겨나감 | 순간이동급 급습·처형 스냅샷 |
| 구현 | 데이터 + 소폭 배선 | 데이터 대부분 + 소폭 배선 | **파생 클래스** |
| 레퍼 | MGR 잔타츠 · Hades II 대시-Aspect · Katana Zero · 20MTD 대시 | Hades II Ω-노바 · 무쌍 회전 · SoD 광역 · Brotato 근접 | Doom 글로리킬 · Hades II 대시-처형 · GoT 스탠드오프 |

### 3.A 일섬(一閃) — 관통 돌진 베기 · ★리드안

- **동작(입력→모션→판정→결과):** E → 조준 방향 **순간 전방 대시(2.5~4m, 짧은 i-frame)** → 대시 경로의 적을 **관통선(폭 넓게)** 으로 전부 베고 **양옆으로 넉백**(복도 개통) → 대시 끝점 착지. 단발 타격.
- **역할 정합:** 전진성 PRIMARY(뚫기), 대범위(선형 복도). RMB(정지 충전 라인)와 **charge-vs-instant / rooted-vs-mobile** 축으로 정반대 → 비겹침. R(제자리 광폭)과도 이동 유무로 분리.
- **트리:** **거합(고수)** — 방향·거리 조준이 실력, 관통이라 정밀. 단 대시 i-frame이 생존을 깔아줘 뉴비도 회피용으론 씀(플로어 이중).
- **간지 논거:** 발도 섬광 대시 + 기존 시안 위상 잔상 재활용 → "슥— 통과하면 뒤에서 갈라진다." 지나간 자리 절단선 스탬프. **06-17 "팍" 수평반토막의 소형 버전 = 뽕의 예고편.** ★납도발도(거합 발도, 07-02 계보) + 오늘 보류 중인 "방향성 붕괴(거합)" 프로토와 **같은 계보 = 일섬이 그 거합 발도의 제품화 후보.**
- **레퍼:** MGR 잔타츠(블레이드-모드 절단선 대시, 킬=재충전) · Hades II 대시-스트라이크 Aspect(대시가 곧 공격) · Katana Zero 대시-through · SoD 블링크 스킬 · 20MTD 대시.
- **구현 난도:** **데이터 + 소폭 배선.** 판정=관통선(DoActionHit에 lineCut 노출=소폭 코드 / 좁은 부채꼴 근사=데이터만) · 전진=AddGlide 재활용 · i-frame=기존 대시 로직. 파생 클래스 불요. Frank 팩 Katana Skill01 클립(S1/S2/S3) 재활용 가능.
- **판정 포인트:** 관통선 vs 부채꼴 근사(Q7) · 대시 거리/i-frame 길이 노브 · RMB와 "둘 다 라인"이라 충분히 구별되나(Q1/Q3).

### 3.B 선풍참(旋風斬) — 전진 회전 광역 · 관용안

- **동작:** E → 짧은 전방 스텝인(1.5~2m) + **360° 회전 베기 1회** → 주위 전 적 광역 피해 + **방사 넉백(포위 일소)** → 앞으로 살짝 밀고 나감.
- **역할 정합:** 대범위 PRIMARY(포위 일소), 전진성(스텝인). 조준 불필요(전방위)라 "포위됐다 → 그냥 눌러" 패닉 해소.
- **트리:** **참격(뉴비)** — 무조준·관용적. RMB(거합 고수)와 스킬플로어 대칭을 채운다(무기 내 고수/뉴비 혼합, [[feedback_weapon_difficulty_mix]] 정합).
- **간지 논거:** 크게 한 바퀴 도는 원형 슬래시 링(발밑 시안 링 VFX) + 적들이 방사형으로 튕겨나감. 무쌍식 "쓸려나가는 질량감" — 07-04 멀티킬 프리즈와 결합하면 "탁" 정지 스펙터클.
- **레퍼:** Hades II Ω-특수 노바류 · SoD 광역 스킬 · 무쌍 회전기 · Brotato 근접 광역.
- **구현 난도:** **데이터 대부분 + 소폭 배선.** 판정=arcHalf 180 + 높은 넉백 + 낮은 데미지(DoActionHit 데이터) · 스텝인=AddGlide · 회전 애니=Frank WhirlWind 계열 클립 존재. 단발 광역=파생 불요. ⚠️*지속 회전(멀티히트)* 원하면 코드 필요 → **단발로 시작 권장.**
- **정직한 트레이드:** 카이팅 답이 안A보다 **약하다**(공간을 *열되* 앞으로 뚫진 않음 = 열고 다시 뒷걸음 가능). 뉴비 플로어·무조준 관용이 강점. "E=방어적 숨통이냐 공격적 돌파냐"의 방어 쪽.

### 3.C 인(引) — 처형 낚아채기 · 프리미엄안

- **동작:** E → 조준 방향 **가장 가까운 *커밋 중이거나 저체력* 적**으로 순간 대시 → 근접 시 처형 베기(크리 배수) → 처형 성공 시 **쿨 환류**(연쇄 처형 가능).
- **역할 정합:** 전진성(표적 급습) + 미니 처형 스펙터클. **읽고-베기 타이밍 크리 엔진(`timingCritEnabled`) 직접 재활용** — 커밋한 적을 낚아 처형.
- **트리:** **거합/하이브리드(중~고수)** — 표적 선택·커밋 읽기가 실력.
- **간지 논거:** 순간이동급 대시 + 처형 스냅샷(purge-snapshot 임팩트 프레임 재활용) + 시안 디졸브. "위협을 콕 집어 지운다."
- **레퍼:** Doom 글로리킬(처형=자원 순환) · Hades II 대시-처형 Aspect · SoD 처형 스킬 · GoT 스탠드오프 스트릭.
- **구현 난도:** **파생 클래스 필요.** 타겟 스캔(최근접 커밋/저체력 적) + 그 적 위치로 홈잉 대시(가변 거리) = 새 동작. 데이터만으론 불가 = **가장 비쌈.**
- **트레이드:** 가장 뽕·서사(사후처리=위협을 지운다)에 맞지만, R의 처형 스펙터클과 톤이 겹치고(피크 아낌 원칙 위반 위험) 비용 최고. 슬라이스 증명 단계엔 후순위 권장.

### 3.추천

**E-안A(일섬)를 리드로 권고.** 이유: (1) 카이팅 명령에 가장 곧게 답(전진-전용 관통 = 구조적 해결), (2) 간지 최고(iai 섬광, 06-17 "팍"의 예고편, 거합 발도 계보 제품화), (3) 저비용(AddGlide·대시 재활용). **안B는 "E를 뉴비 패닉-클리어로"** 원할 때의 관용 대안 — 리드안과 스킬플로어가 반대라 *둘 중 하나 선택*이 곧 "이 무기 E는 고수용이냐 관용이냐" 판정. **안C는 파킹**(비용·톤 중복).

## 4. R 궁극 구체화 (수평 반토막+디졸브, 06-17 유지)

06-17 "팍" = 수평 반토막+디졸브(화려처치 정점). 06-14 설계 의도 = **화려한 처치로 충전 → 대방출**(키스톤 "화려함=돈"을 버튼으로). 뒤집지 않고 구체화.

### 4.1 발동 조건 — 게이지 2안

| 안 | 충전 방식 | 장점 | 단점/재정합 |
|---|---|---|---|
| **R-안1 · 스타일 게이지** | 화려함(킬스트릭·노히트·광역·크리)으로 참 · 만충 시 R | 뽕 정합(화려하게 벌수록 정점 보상) · 키스톤 계보 · 전진 플레이 보상 | ⚠️"화려함=돈" 엔진이 VS 피벗(06-16, 정산·판돈 카빙) 후 살아있나 재정합 필요 |
| **R-안2 · 킬 카운트 게이지** | 단순 처치 N마리로 참 | 확실히 피벗 정합(보스게이지=시간+처치 문법과 동형) · 지금 구현 가능 · 단순 | 화려함 보상 약함(그냥 많이 죽이면 참) |

**권고 = 하이브리드(안2 뼈대 + 안1 가속):** 킬로 기본 충전(피벗 정합·구현 확실) + 화려함(멀티킬·크리·노히트)이 충전 *가속*(뽕 정합). 순수 쿨다운 ❌(정점을 시간으로 주면 뽕이 죽는다). ★게이지 UI 최소(디제틱 발밑 링/무기 발광), over-systematization 금지([[feedback_pong_over_systematization]]).

### 4.2 R 연출 비트 (수평 반토막)

1. **발동(만충 R):** 짧은 정지 + 시네마틱 줌인(`NotifyHit` 투스테이트 재활용) + 월드 채도 뚝(그레이드) + 발밑 시안 확장 링.
2. **발도:** 전방 **광폭 수평 일섬**(화면 폭급 긴 라인/광폭 부채꼴).
3. **임팩트:** 라인 위 전 적 **수평 반토막 → 디졸브(시안)**. 잡몹=즉사 디졸브 / 엘리트=RayFire 슬라이스(구매 후) or 가짜쪼갬(프로토).
4. **여파:** 화이트아웃 임팩트 프레임(purge-snapshot FX 재활용) + 카메라 킥 크게 + 짧은 슬로모(`ParrySlowMotion` 소유 경로).
5. **복귀:** 채도 복원, 게이지 0.

### 4.3 화이트박스 프로토 경로 (오늘 가능 / 구매 후)

- **오늘(가짜 반토막):** R = `WeaponActionSet` 즉발 슬롯(이미 배선). 판정=광폭 부채꼴(arcHalf 큰 값) or 긴 관통선 + 높은 데미지 = **데이터**. 잡몹 즉사 디졸브 = 죽음 연출 티어 재활용 = **데이터**. 줌/화이트아웃/슬로모 = 기존 FX 재활용. → **"긴 수평 라인 광역 즉사 + 디졸브 + 줌/화이트아웃"으로 오늘 프로토.**
- **소폭 신규:** 게이지 컴포넌트 1개(킬 카운트, R만 게이팅). 이게 이 드래프트의 유일한 "신규 시스템"이고 최소 유지.
- **구매 후:** RayFire 진짜 절단(엘리트 수평 반토막). 06-17 유저 7월 구매 예정(미검증 — 확인 필요).

## 6. 🟡 판정 포인트 (유저가 맞다/틀리다 할 단위)

- **Q1 — 역할 삼각 분담이 맞나?** RMB=집중 관통(거합·정지) / E=전진 광역 돌파 / R=수평반토막 스펙터클. 셋이 안 겹치나?
- **Q2 — 카이팅 답이 이거 맞나?** E = "뒤로 갈 수 없는 전진-전용 변위" + 밀도 보상(많이 맞힐수록 큰 효과). 제자리 노바를 기각한 판단 동의?
- **Q3 — E 리드안 = A(일섬 관통 돌파) vs B(선풍참 포위 숨통) vs C(처형 낚아채기)?** (gd 권고 = A, 관용 원하면 B, C는 파킹)
- **Q4 — E 트리 소속 = 거합(고수·A/C) vs 참격(뉴비·B)?** 무기 내 스킬플로어 혼합(RMB 고수 ↔ E 뉴비) 의도가 맞나, 아니면 E도 고수(A)로 통일?
- **Q5 — R 게이지 = 스타일 충전(안1) vs 킬 카운트(안2) vs 하이브리드(권고)?** + "화려함=돈" 엔진이 VS 피벗 후 *런 내 게이지*로 생존하나(재정합).
- **Q6 — R 화이트박스 단계 분리 OK?** 오늘=가짜 반토막(긴 라인 즉사+디졸브+줌/화이트아웃), 진짜 절단=RayFire 구매 후. (RayFire 7월 구매=미검증)
- **Q7 — E 판정 모양 = 관통 절단선(소폭 코드) vs 좁은 부채꼴 근사(데이터만)?**
- **Q8 — E 넉백 → 억제 스택 도미노 결합 강도(노브)?** E 밀침이 뒤 전열 스태거를 얼마나 유발할지.
- **Q9 — 카드 강화가 E/R을 변형하는 결합 방향 OK?** 런타임 modifier 레이어(SO 오염 금지)로, 이 드래프트에선 손잡이만 설계(레이어 신설은 카드 구현 시).
