탑다운 텔레그래프 가독성 비교 — 타이밍-듀얼 크리티컬용 (2026-06-24 탐색)

같은 부감 씬 · 같은 호드 · 같은 커밋 사이클. 다른 건 "적이 곧 친다 + 지금이 그 순간(NOW)"을 어떻게 보여주나뿐. 회색=서성이는 떼(매질·압박), 빨강/주황=공격 커밋 중. 탬버린처럼 닫히는 게 "충돌까지 시간", 흰 번쩍이 NOW(=크리티컬 창). 실제론 NOW에 오디오 틱도 같이 — 여기선 화면 하단 비트로 표시. 최종 판단은 네 눈. 진짜 검증은 인엔진 캡처.
← 잡동사니 켜고 ‘바닥 링’이 어떻게 묻히는지 보세요

A · 바닥 링 (원안) 두 검증자 기각

적 발밑 링이 조여듦 → NOW에 바닥 플래시. 약점: 시선은 이동경로를 훑지 적 발밑이 아님 · 잡동사니/지형과 경쟁해 묻힘 · 여러 개면 "어느 링=어느 적" 매핑 비용.

B · 본체 신호 Codex+uiux 수렴

적 실루엣이 팽창+발광 포화(회→주황→백) → NOW에 본체 흰 플래시 + 화면 마커. 신호 출처=원인(적 몸). 매핑 비용 0 · 잡동사니 영향 0 · 명도로 읽혀 색약 안전.

C · 본체 + 벡터 방향성 추가

B + 적→나 위협 벡터선(이놈이 *나를* 노린다). 여러 개여도 각자 나를 향해 안 겹침. 단 너무 가까우면 중앙 혼잡 → 보조 레이어.
플레이어(조준) 서성이는 떼(비커밋) 커밋(접근) NOW = 크리티컬 창
관찰 포인트: ①잡동사니 켜고 A의 링이 읽히나 ②동시 커밋 3~5로 올리고 어느 게 "누가 NOW인지" 파싱되나 ③시선을 한 적에 고정한 채 다른 적의 NOW를 주변시로 잡히나. — 이 셋이 두 검증자가 A를 깐 핵심 근거.
