## TL;DR

긴 브레인스토밍으로 "우리 게임의 재미가 뭔가"를 바닥까지 팠다. 도착점:

- **재미의 toy = 기계장치가 아니라 *감정 상태*(두려운 압박감·쫄깃함).** Devil Daggers가 무기가 아니라 *공포·분위기*로 도파민을 채우는 것과 같은 원리(유저 통찰).
- 그 위에 코어 전투 동사가 **유력하게** 잡혔다: **원터치 타이밍-듀얼 크리티컬 → 밀집 전파 → 리듬 체인 → 초필살기.** 깊이는 *복잡함*이 아니라 *타이밍*, 화려함은 *시스템이* 준다.
- 적 공격 타이밍 = **B(창발)** 확정 — 메트로놈이 아니라 적 자기 텔레그래프대로(예측 불가 = 공포 우선).
- 단 **dread 방향 자체·메타·스토리는 열린 채.**

## 어떻게 여기 왔나 (벗겨낸 과정)

메커닉(분리/티어 vs 클래스)에서 시작 → 유저가 계속 "더 근본"으로 밀어 한 겹씩 벗김:
1. 카타나 toy(선·거합) → **기각**: 무기는 4클래스, 카타나는 하나일 뿐.
2. 무기-불가지론 toy → **기각**: 런 중 무기 교체 없음(한 무기로 진행).
3. Devil Daggers 단서 → ★**결정적 통찰(유저):** *"무기·메커닉이 아니라 두려운 압박감과 분위기에서 나오는 쫄깃함이 도파민을 채운다."* toy는 *감정 상태*다.
4. 그 위에 동사를 다시 세움 → 원터치 타이밍-크리티컬-전파(아래).

**방법 교훈(중요):** 중간에 유저가 지적 — 에이전트 합창(Codex·pm)이 *내 프레임을 보충/메아리*하고 있었고, 나는 *수렴을 성과로 착각*했다. 바닥 진리에 대한 수렴은 통찰이 아니라 메아리. 또한 *신선함은 피치가 아니라 실행에 산다* — 개념을 신선도로 채점하면 모든 게임이 "흔해"로 기각된다(VS/Hades도 한 문장으론 흔하다).

## 1. 바닥 — 재미의 toy = "쫄깃함 엔진"

재미의 원자는 *동작*이 아니라 *두려운 압박감 + 쫄깃함*이라는 감정 상태. 이걸 만드는 레버:

- **치명성** — 죽음이 가깝고 진짜여야 클렌치가 생김.
- **끊임없음** — 안전한 순간 없이 압박이 조여옴.
- **칼날 위 생존** — *간신히* 버팀("겨우"에 쫄깃함이 산다).
- **분위기** — 위협의 소리·모습(조여오는 떼·어둠·사냥당하는 감각). 두려움은 숫자가 아니라 연출.
- **한 발 뒤** — 상황이 항상 내 처리 능력을 살짝 넘어섬(지배가 아니라 관리).
- **클렌치 → 해방의 박동** — 도파민은 *두려움이 풀리는 순간*에 터짐.

→ 함의: **분위기 트랙(황혼의 적막·오디오·변종야수 호러)은 장식이 아니라 엔진의 심장.** 또한 캐릭터가 *다재다능하면* dread가 죽는다(능력 = 두려움의 적; 단 진짜 적은 *대가 없는 탈출*이지 옵션의 수가 아님 — 세키로식 커밋이면 OK).

## 2. 코어 전투 동사 (유력 — 가설)

**원터치 타이밍-듀얼 크리티컬 → 밀집 전파 → 리듬 체인 → 초필살기.**

- **원터치 / 깊이=타이밍:** 많은 키·콤보 암기 ❌. 깊이 = *언제 누르나(타이밍) × 어디 겨냥 × 어느 커밋한 놈을 고르나.* 손가락은 단순, 머리는 바쁨. **화려함은 플레이어가 실행하는 게 아니라 *시스템이 응답으로* 준다**(타이밍 한 번 맞췄더니 화면이 폭발).
- **타이밍-듀얼 크리티컬:** 패링(방어)이 아니라 *공격 타이밍 듀얼* — **네 무기 공격 타이밍 × 적 공격 타이밍이 겹치는 순간에 꽂은 히트 = 크리티컬.** 적이 *나를 죽일 수 있는 그 순간*에 들어가야 해서 dread가 *코어 동사 안에* 박힘. 빗나가면 그 공격을 맞음(대가 = 쫄깃함).
- **기준 = 상태(커밋), 종류 아님:** 듀얼 대상 = *지금 공격을 커밋(텔레그래프)한 놈.* 잡몹이든 엘리트든 *달려들면* 듀얼 대상, 서성이면 *매질+압박.* 토큰 게이트(maxAttackTokens)로 *동시 커밋 소수* → 40마리 타이밍 재는 피곤 차단. "잡몹 다 타이밍" ❌ / "엘리트만" ❌ 둘 다 회피.
- **크리티컬 "팝"(한 비트 융합):** 데미지 + **밀집 전파**(뒤의 빽빽한 떼를 가르는 복도 = 시그니처) + **회수 단축**(즉시 다음 행동 = 흐름) + 짧은 리포지션 + 슬로모/카메라 방점.
- **체인 = 리듬 = 필살 게이지:** 크리티컬 → 회수 환급 → 다음 커밋 → 크리티컬 … = *달려드는 짐승의 파도를 서핑.* 이 흐름이 곧 리듬이고 쌓이면 **초필살기**(원버튼·플레이어 발동·공격 스펙터클).
- **B 창발 타이밍(확정):** 적은 음악 비트가 아니라 *자기 텔레그래프대로* 공격. 예측 불가 = 공포 ↑. "리듬"은 적들의 들쭉날쭉한 박자에 *올라타는 것*(메트로놈 ❌).

## 3. 떠오른 설계 원칙

- **크리티컬/필살 보상 = 공격·흐름·스펙터클(클렌치의 해방). 지속적 안전 ❌.** 범위↑·회수↑·전파↑·짧은 슬로모 = OK. 보호막·회복·지속무적·방어버프 = dread 살인(독).
- **★세짐 = 크리티컬 보상 묶음이 커지는 것이지 안전이 아니다.** 인런 드래프트·영구 메타가 만지는 표면 = *이 묶음*. "데미지 +10%" ❌, "내 크리티컬이 더 멀리 가르고 더 빨리 흐른다" ✓. → 강해질수록 *더 안전*이 아니라 *더 화려하게 가른다*; 두려움은 상수, 표현의 천장만 오른다. **이게 "세짐이 압박을 줄여 dread를 죽인다"는 최대 난제의 해답**("숙련이 권능보다 앞선다"를 성장 시스템으로 박음).
- **리듬 = 긴장(세키로)이지 그루브(하이파이 러시) ❌.** 흥겨워지면 공포가 사라짐. 박자는 심장박동.
- **듀얼은 의무가 아니라 기회.** 커밋한 놈을 *반드시* 받아칠 필요 없음(닷지·칩 가능). *언제 듀얼을 걸지 고르는 것*이 기술 = 피곤 방지.
- **동시 커밋 cap = 쫄깃↔피곤 다이얼.** 직감상 *낮아야*(동시 듀얼 1~2 = 깨끗, 3~4 = 저글링/피곤). 손으로 잡을 값.

## 4. 열린 질문 (미결 — 동결 아님)

- **dread 방향 자체** — "하나의 맥락 중 하나." 채택 여부는 더 가면서.
- **소모-직원 로스터** (직원 여럿 배치, 죽으면 다음으로 인계) vs 단일 주인공+엘 구조. *소모 공포(attrition)*로 설계하면 강하나, 단일주인공 서사와 충돌. **해소안:** 엘(AI)을 *불변의 축*으로 두고 몸만 소모 → 엘이 작업자를 하나하나 떠나보냄(스토리 코어 살고 호러 깊어짐). 전면 폐기 아니라 주인공 축만 재배치.
- **스토리 재배치** — dread *톤*은 기존 K-행정/봉쇄와 정합(연장), 엎는 건 로스터가 단일주인공과 부딪히는 한 곳뿐.
- **broad-뱀서(대중·파워판타지) vs niche-distinctive(호러-소모, Darkest Dungeon/Lobotomy Corp 관객).** 솔로엔 니치가 해자라고 봄(메타 의견), 단 미결.
- **"충분히 신선한가"** — dread-소모-institutional은 임자(DD/Lobotomy)가 있어 *바이브*로는 안 신선. 신선함은 *충돌/동사/실행*에서. 후보 충돌: 실시간 뱀서 압박 × DD식 로스터-소모("일시정지 못 하는 Darkest Dungeon"), AI가 진짜 주인공(몸=도구).

## 5.5 텔레그래프 가독성 — 검증 + 유저 판정 (2026-06-24)

타이밍-크리티컬은 "적이 *언제* 칠지"가 탑다운서 또렷해야 성립. 오케스트레이터 원안(**바닥 링 수렴**)을 **Codex + uiux가 독립 수렴해 기각**: 바닥은 이동/회피/탄막 판단의 주 채널이라 발밑 신호가 묻히고, 부감서 시선이 *적 몸이 아니라 이동 경로*를 훑어 NOW를 놓침. 잡동사니·다수일 때 "어느 링=어느 적" 매핑 비용. (목업으로 유저 직접 확인: `docs/02_logs/2026-06-24-telegraph-readability-mockup.html`)

**유저 판정 → 텔레그래프 = 적 *본체* 신호(바닥 ❌), B+C 결합:**
- **B = "언제"(백본, 항상 켜짐):** 본체 실루엣 *팽창 + 발광 포화(회→주황→백)* 램프 = 충돌까지 카운트다운. 명도 채널이라 색약 안전. 신호 출처=원인(적 몸) → "바닥→어느 적" 매핑 비용 0.
- **C = "누구/방향"(임박·근접도 비례 액센트):** 적→나 *위협 벡터선* = "이놈이 나를 노린다." 코앞 다수서 중앙 혼잡 방지 위해 *제일 임박/먼 적 위주로만* 진하게.
- **NOW = 본체 흰 플래시 + 화면공간 마커 + 오디오 틱.** 월드가 아니라 *본체/화면*에 박아 "어느 적이 NOW였나"를 안 잃음(uiux 핵심 지적).
- **A(바닥 링) 기각** — 몰리면 안 보임. (멀리서 다가오는 *거리감* 보조로 재활용 여지는 미정.)

검증 = 인엔진 부감 캡처(내 눈/에디트모드 불가 — [[verify_topdown_visually]]).

## 5.6 적 공격 = 동작 내장 텔레그래프 — 아키타입 지도 (Codex + Animation 발산, 2026-06-24)

원리: 탑다운서 NOW가 읽히려면 *수평 발생 / 실루엣 면적 급변 / 바닥 장판 보강* 셋 중 하나. **NOW = 커밋 비트**(최대 위험 + 최대 무방비가 한 프레임에 겹침). 텔레그래프를 위에 얹지 말고 *공격 모션 자체가 예고*되게.

**읽히는 아키타입 (채택):**
- **A 돌진-임팩트** — 접근=예고, ★NOW=*급제동 임팩트 프레임*(돌진 자체 아님 — Animation 교정: "돌진은 예고 최강, NOW는 별도 설계"). Caniathrox `JumpLunge_RM`.
- **C 횡-휘두르기** — 코킹(방향 예고)→수평 호. NOW=호 정점. ★**Dimax(4분할 ClawHit이 Strike 비트에) 즉시 가능 = 첫 검증 1순위.** Venosaur 틀 재활용.
- **B 점프-내려찍기** — ★수직은 부감서 안 보임 → *그림자 데칼 팽창이 진짜 텔레그래프*, NOW=착지(그림자 최대). 그림자 없으면 "역동적인데 뭐하는지 모름" 재발(Animation 교정·[[topdown_readability_axis]] 사고). Caniathrox `Jump_RM`(착지 꼬리 트림).
- **D 충전-폭발** — 제자리라 모션 단독 ❌, *VFX 90%*(부풀기+발광+바닥 링 채움). NOW=방출. Venodonte 원거리, artist 협업.
- (E 구르기-덮침 = Lacercharias, fodder, NOW 창 빡빡 — 후순위.)
