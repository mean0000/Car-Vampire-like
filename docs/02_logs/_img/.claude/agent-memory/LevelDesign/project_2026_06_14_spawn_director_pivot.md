2026-06-14 유저가 1차 빌드 스펙의 **정적 토큰 배치를 반려**("정적 토큰 배치=뱀서류 아님") → **스폰 디렉터(동적 젠) 모델 확정**.

**Why:** 몰려오는 호드 속 액션이 뱀서류의 본질. 고정 "①에 X마리" 인카운터는 타르코프/MOBA로 읽혀 장르 이탈.

**How to apply (5규칙, 독트린 §2.5 = 권위):**
1. 착지=즉시 교전(워밍업 0) · 2. 표효 호출(같은 종 우선 수렴) · 3. 밴드=젠 존(동심 무한 수렴) · 4. 구심 변조(중심 가까울수록 강몹 젠율↑) · 5. 시간 변조(번짐: 안쪽 몹이 바깥 띠 잠식=escalation 공간 구현).

**경계(절대 흐리지 말 것):** lv = **규칙·곡선 *모양*·풀 매핑·맵 특성·alive 상한 *방향***. Gameplay = **젠율·표효 쿨/반경·곡선 control point·풀사이즈·스태거·런타임**. 단일 출처 = 빌드 스펙 "공통 노브 맵" 표.

**보존 필수:** 비콘/잭팟/콘 릴레이 공개(독트린 §2.3)는 **지각 레이어로 유지** — 끌림이 죽으면 안 됨. 릴레이 비트 ①②③ = *공개 트리거*지 *스폰 트리거* 아님.

**두 맵 표정 차이(같은 5규칙, 다른 기하):** 집하장=회랑 한 줄 압축(대시 카빙·표효 회랑 울림) / 분수광장=개활 사방 수렴(광역 학살·공중 평면 다이브 합류·스태거 필수).

**최우선 함정(R0):** "호드가 많아도 한 마리가 안 무서우면 무해함만 많아진다"(spawn-director.html). 디렉터=양, 게이트0 전투감+종별 애니=질. 둘 다 있어야 뱀서류.
