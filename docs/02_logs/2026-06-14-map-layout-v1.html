맵을 쫙 깔았습니다 — 덕코프식 바운디드 구역 v1

보유 POLYGON 단일 가족으로 ~116×116m 바운디드 오픈 존. 길 규약 적용: 베이지 지면=외곽, 검정 아스팔트=도로망(십자 대로 + 사각 링). 동심원 구조(외곽 흙·fodder → 코어 광장·크레인 비콘·정예).

전경 (톱다운) · 베이지 흙 지면 + 검정 아스팔트 도로망(십자 대로+사각 링) + 블록 건물 + 코어 광장·크레인 비콘 + 폐허·괴수 산포. 길 규약 그대로 — 도로망이 또렷.
같은 맵 · 45° 거리감 · 건물·괴수·폐허가 또렷이 읽히는 스타일라이즈드 도심. 조잡하지 않음. 크레인 비콘+괴수가 코어에.

이 v1이 검증한 것

  • 길 규약 작동 — 베이지 외곽 + 검정 아스팔트 도로망이 탑다운서 또렷이 읽힘(당신 규칙 그대로).
  • 한 가족(POLYGON) = 클래시 0 — 도로·건물·컨테이너·폐허·벽이 한 톤.
  • 동심원 구조 성립 — 외곽 흙/봉쇄벽 → 블록 → 코어 광장·크레인 비콘. 덕코프식 바운디드 존.
  • 45°서도 폴리시 — 건물·괴수·폐허 읽힘, 빈 공간 없음 = 초등학생 게임 아님.
⚠️ 한계(정직): 클래리티 라이팅(다크무드/아웃라인/그레이드 미적용 — 최종 룩 아님) · 1196 오브젝트 손배치 v1(절차 조립 아님, 캡처 후 삭제됨) · 지면=임시 솔리드 베이지(최종은 Synty 흙 타일 디테일) · 링 도로 약간 블록키(Synty 직선 타일) · 괴수 바인드포즈. "레이아웃·길 규약·조잡 여부"까지 증명.
