맵을 보유 에셋으로 어떻게 짜나 — 그리고 조잡한가

에이전트 2종(LevelDesign 에셋 감사 · artist 처리 스택) + 오케 실측 캡처로 검증. 결론: POLYGON 단일 가족 + 폐허 어휘 + 처리로 조잡하지 않은 폐허 도심이 됩니다. 신규 구매·임포트 불요.

증거: POLYGON BR+Construction을 폐허 어휘(손상 도로·잔해·파손차량·컨테이너 회랑·크레인 비콘)로 구성 + 클래리티 라이팅. 손배치 디오라마인데도 코히어런트한 폐허 야드로 읽힘 — "초등학생 게임" 아님.

⚠️ 캡처 한계: 클래리티 라이팅(다크 포스트 OFF·키/필 추가 = 에셋 가독용)이지 최종 다크무드 아님 · 손배치 디오라마(절차 조립 아님) · 괴수 바인드포즈. "에셋/구성이 조잡한가"까지 증명, 최종 무드는 처리 후 별도 확정.

LevelDesign — 가족 판정 (셰이더 GUID 실측)

  • 도심 골격 = POLYGON (BattleRoyale + Construction) 단일 가족. 두 팩이 같은 셰이더 GUID 공유 → 섞어도 클래시 0. 기존 빌드스펙(BR+CN)이 이미 안전했음.
  • Toon City 탈락. 다른 셰이더 + 에셋별 디퓨즈 70개(POLYGON은 단일 아틀라스) = 한 화면 클래시 = 유저가 경고한 그 조잡. 결정타: 폐허 어휘 0개(ruin/destroyed/damaged grep=0) → 폐허를 못 짬.
  • 폐허 커버리지: BR = 손상도로 3·잔해 9·부서진 다리·파손차량 5 — 빈칸 없음.
  • 신규 구매·임포트 전부 불요. (POLYBOX City 5.7GB·Top_Down_Post-Apoc PBR 모두 비권장)
  • ★빌드스펙 변경 = 골격 안 바뀜(검증만). 추가: 폐허 어휘 산포 의무 + Toon City 배제 명시 + Fountain 미사용(가족 다름).

artist — 조잡 방지 처리 스택

  • 조잡함 = 6개 독립 신호의 합(C1 납작·C2 빈공간·C3 클래시·C4 머드·C5 VFX빈약·C6 raw). 하나만 잘해도 나머지가 더 도드라짐 → 6개 다 쳐야.
  • ★50%는 셰이더 아닌 라이팅/포스트 — C1(납작)+C6(raw). 쿨 그늘 vs 웜 키 색온도 대비 = 최대 백신.
  • 환경 포스트 아웃라인(depth/normal) = 클래시 최강 백신 — 도시+괴수+VFX를 "한 손으로 그린 그림"으로 묶음.
  • 가독성(톤게이트 진짜 약점): 색온도 대비(공짜)→Fresnel 림(보유)→이미시브→접지 순. 1·2로 대부분 해결.
  • 빈 공간 = 조잡 → 안개 3깊이 + 드레싱/잔해 점유(빈 칸 ≤2). 위 캡처가 이미 그걸 함.

이렇게 짜면 됩니다 (정리)

  • 한 가족(POLYGON BR+CN)으로 통일 — 다른 셰이더(Toon·PBR) 1개라도 들어오면 즉시 제거 = 클래시 차단
  • 폐허 어휘 적극 산포(손상도로·잔해·파손차량) — 깨끗 바닥+어둠만이면 폐허 안 읽힘 = 그게 초등학생 게임
  • 처리 스택: 색온도 대비 + 환경 아웃라인 + 이중온도 그레이드 + 안개 3깊이 + VFX 점유 = 머드·납작·클래시 제거
  • 구성 밀도(빈 공간 0) + 3단 높이 위계 + 밀도 역구배(오브젝트 배치 독트린)
