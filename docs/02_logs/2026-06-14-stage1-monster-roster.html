디제틱 응집 — 2축

① 직종 = 한 도시 노동 인구의 단면

소독 · 경비 · 배전 · 사무 · 건설 · 운전 · 항공 + 익명 보행자. 로스터 자체가 "도심이 사람을 어떻게 먹었나"를 그린다.

② 변이 진행도 = 인간성 잔존도

직립+팔(LV3, 사람 잔존) → 사족·다족 → 완전 이형(LV5, 0). 카피 0줄, 실루엣만. 행간: 약한 LV3가 인간성 최대(최근에 사람).

트림 — 1차 제외 (→ 2차)

Arathrox · Horridomorph (원거리/공중 슬롯 과포화) · Hexateuthis (그랩 = 첫 인상 학습 부담) · Cephalonops (LV2 잉여) · Occisodonte (수변 매복 악어 = 도심 4구역 디제틱 부재)

escalation (지연 시 강화)

로스터 내부 4단계 — 밀도↑ → 능력치↑ → 유생 분출 → Crustaspikan 보스. 신규 종 발명 0.

판정 필요 — 동결은 유저

  • 9종 + 트림 5종 동의? (lv 권고 = 예, 동사 적정)
  • Venodonte LV1 확정 (후보엔 LV1~2, 권위는 LV1 군체 → 정정)
  • Carcinoptera = 분수광장 전용 (집하장 회랑은 Fulgurodonte 단독)
  • 입말 통칭(순찰개·양복·기사님) 블랙코미디 강도 OK? — 취향이라 당신 콜
  • escalation = 로스터 내 4단계(신규 종 0)
⚠️ 이건 배역표입니다. "쫄깃한가"는 게이트0 전투감(인식 3상태·피격 사다리·히트스탑) + 종별 애니(Animation)가 선행 판정. 로스터 = 배역, 연기 = 전투감. 캐넌 충돌 0건 · 구현 가드: 공문 통칭(HUD/정산서)엔 직종 금지, 직종은 입말(무전)·실루엣으로만.
