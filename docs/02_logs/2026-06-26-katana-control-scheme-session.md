### 키맵 합의 근거 (Codex + Gameplay 수렴)
- **차징 = RMB 홀드.** E hold-to-charge는 WASD 검지(D)와 충돌 → 마우스로 이관. 홀드/차징형 입력은 무조건 마우스 버튼.
- **평타 = LMB 단일 + 타이밍 체인.** LMB/RMB 번갈이("좌우 베는 손맛")는 *조준 게임에서 조준손을 흔들고 15분 런 피로*라 폐기. **"베는 느낌은 입력 속성이 아니라 출력(애니) 속성"** — DMC/베요네타는 단일 버튼으로 좌-우-좌 콤보를 애니가 생성. 좌우 교번은 코드에서 애니로 구현.
- **패링 거취 = 발산.** Codex/Gameplay = 타이밍 레이어 유지(전용 키 없음) / Challenger = 대시-퍼펙트회피 하나로 강등. (단 P0 때문에 이 쟁점 자체가 재고 대상 — §3.)
- **좌손 키 = 탭 발동만.** 홀드형은 마우스로. **키 도달거리 ∝ 쿨다운.**

### 추가 스킬 키 우선순위 (3자 수렴)
1개 → **E**(탭) · 2개 → **E + F**(조준형) 또는 **E + Mouse4**(논타겟·버프형) · 3개 → **E + F + Mouse4** · 저빈도 4번째 → **R**.
- 마우스 썸버튼(Mouse4/5) = 좌손 부담 분산에 최적. **단 썸버튼은 누를 때 조준 1~2px 흔들림** → *논타겟/자기버프/범위투사형*에만, 조준 스킬은 좌손키(F).

## 2. 카타나 키트 구조 (설계 방향, 미동결)

### 전직 트리
**기초 베기(기본) → 3종 전직:** ①찌르기(관통/핀포인트) ②참격(기초 베기 강화=광역) ③거합(발도술=충전→한 칼). **찌르기 네이밍·구체화는 맨 마지막.**

### 무기고 차별화 두 축 (나 + Codex 강수렴 — "교전 계약" 동일 단어)
- **축 A (무기끼리 구분) = 교전 계약(engagement contract)** = 거리 × 리스크 × 동사. 칼=초근접 고위험 / 저격=원거리 라인컨트롤 / 샷건=근접 순간제거 / 주먹=밀착압박 / 권총=이동 중 지속딜 / 드론=자율커버. → **LOCK 후보.**
- **축 B (한 무기 안 타입끼리 구분) = 근접 리듬/방출 형태** (★"타격 분포" 아님 — Codex 교정: 분포로 잡으면 총들과 충돌. 리듬으로 잡아라).
  - 참격 = 광역 풋워크 군중베기 (Nioh식 아닌 풋워크). **어필 결 = 멋/스타일.**
  - 거합 = 정지→순간이동+절단 (DMC 버질 심판, 저격 차징샷 아님). **어필 결 = 한방 스펙터클.** "벽력일섬"이 여기 삶.
  - 찌르기 = 적을 뚫고 이동하는 창 압박 (Nioh, 안전한 원거리 사격 금지). **어필 결 = 실용 성능/효율.**
- **찌르기≠저격총 해소:** 축 B에선 비슷(단일대상)해도 축 A에선 정반대 끝(초근접 vs 초원거리)이라 안 겹침 + 찌르기를 애초에 "근접 이동 압박"으로 정의해 총 판타지 여지 제거(이중 안전장치).

### 타입 밸런스 = 간지=돈 경제로
찌르기(효율적이나 간지 낮음 → 정산 적게) vs 참격/거합(화려 → 간지 높음 → 많이 버는데 손 더 감) = **"안전하게 적게 벌기 vs 멋부려 많이 벌기" 리스크-리워드.** 찌르기가 메타 독식 안 하게 *설계에 박아야* 동작.

### 전직 적용 범위 = **발산 (미해결)**
- 나 = 카타나만 3타입 깊게(나머지 5는 축 A로 구분 + 카드 변주, 6×3 폭발 회피)
- Codex = 6무기 전부 대칭(갈래=독립무브셋 아닌 *공유 기본킷 위 타이밍/동작 변조*로 폭발 막음)

### 깊이 모델
전투 깊이 = **공격 애니/버튼 가짓수가 아니라 타이밍 정밀도(저스트 입력).** (애니 리소스 제약을 강점[VFX]으로 뒤집기.) — ⚠️단 §3 참조: 이 "타이밍" 강조가 P0 충돌의 일부.

## 4. 방향 전환 — "움직임 쫙쫙 + 밀어버리기" (세션 말미)

유저가 핵심 긴장을 스스로 발견: **"이런 류 게임은 움직이며 지속적으로 베며 버텨야 하는데, 우린 제자리에서 베는 게 문제."** = 메모리가 플래그한 "호드 vs 개체 충돌"을 *이동* 각도에서 재도달.

**유저 결정 방향:** 움직임을 쫙쫙 넣고 + **밀어버리기(displacement)**로 간다.

- **밀어버리기 = 생존 엔진** — 안 죽이고 밀쳐내 공간을 만드니 둘러싸여도 안 갇힘. 호드-핀 문제 직접 해답.
- **간지/뽕** — 무리를 갈아엎으며 지나가는 파워판타지.
- **★LOCK과 정합** — "밀어버리기+이동 스펙터클"은 무기 불가지론(샷건 폭발넉백·주먹 강타·드론 밀침 다 됨) + 간지 + 스펙터클. → **타이밍-패링 프레임을 되살리는 게 아니라 LOCK이 환영하는 다른 길로 P0를 우회 해결.**

### 미해결 포크 (다음 세션 첫 결정)
**밀침/이동이 키트 어디에 사느냐:**
- (a) **이동 레이어에만** — 대시=적 밀치며 돌파, E=크게 밀어내기(숨통트기). 평타는 제자리 묶음 유지(β/헤이디스 루프). ← **오케 lean** (역할 분리 + 제자리 베기 보존).
- (b) **평타에까지 번짐** — 벨 때마다 전진하며 밀고 들어감(α, 카이팅-베기 쪽). 더 끈적하나 제자리 베기 약해짐.

## 5. E 스킬 후보 (프레임 무관 유틸 — 미결)
1개만 넣기로 함. 셋 다 프레임 무관 + 호드 유용 + 역할 무기불가지론:
- **A. 갭클로저 돌진베기(파고들기)** — 베며 돌진. ★Space 대시와 선 그어야(대시=방어회피, E=공격적 거리).
- **B. 포위 일소/회전베기(숨통 트기)** — 360° 베고 넉백, 공간 생성. **오케 lean** — 키트에 "둘러싸임" 답이 없는 구멍을 메움. §4 "밀어버리기"와 직결(B가 그 모델의 핵심 부품).
- **C. 끌어모으기(셋업)** — 빨아들여 RMB/R로 쓸기. 스킬 간 시너지 담당.
