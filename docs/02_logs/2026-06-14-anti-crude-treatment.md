## 0. 진단 — "조잡함"의 정체 (무엇이 만드나)

"초등학생 게임처럼 보인다"는 단일 결함이 아니라 **6개 독립 신호의 합**이다. 각각을 끄는 노브가 다르므로 분리해서 친다. 라이팅으로 다 메우려 하면 과조명으로 망가진다 (베이스라인 v1 §갭분석의 "순서가 중요" 원칙 승계).

| # | 조잡 신호 | 원인 (기술) | 끄는 처리 | 본문 |
|---|---|---|---|---|
| C1 | **납작함 (flat)** | 키/필 분리 없음·앰비언트 균일·그림자 없음 → 형태가 안 읽힘 | 라이팅 위계 + 색온도 대비 + 접지 | §1 |
| C2 | **빈 공간 (empty)** | 바닥/벽 광활·프롭 0·중경 공백 → "그레이박스 티" | 밀도/드레싱 + VFX 점유 + 안개 깊이 | §5 |
| C3 | **스타일 클래시 (clash)** | 도시(스타일)+괴수(반리얼)+VFX(제각각)가 따로 놂 | 통일 처리(아웃라인·그레이드·색규약)로 한 렌즈 | §3, §4 |
| C4 | **가독성 부족 (mud)** | 어두운 괴수가 어두운 노면에 묻힘·위협이 안 튐 | 림/이미시브 악센트 + 접지 + 시야콘 | §2 |
| C5 | **VFX 빈약 (cheap fx)** | 처치/타격에 점유·잔광·세컨더리 없음 → 행동이 가벼움 | 임팩트 프레임·점유 규칙·라이팅 연동 | §6 |
| C6 | **포스트 부재 (raw)** | 톤매퍼·그레이드·블룸·비네트 0 → "에디터 뷰포트 티" | 통합 포스트 스택 (무드로 덮기) | §4 |

> **핵심 통찰**: 조잡함의 50%는 C1(납작)+C6(포스트부재)다 — *둘 다 셰이더가 아니라 라이팅/포스트로 해결*. 나머지는 C3(클래시)+C4(머드)로, 여기가 **셰이더 통일층**(아웃라인·림)의 일이다. C2/C5는 밀도·VFX 점유 규칙. **여섯을 다 끄기 전엔 어느 하나만 잘해도 조잡해 보인다** — 체크리스트(§7)가 게이트.

## 1. 라이팅 처리 — C1(납작) 격파

> 권위: [[2026-06-10_그래픽_베이스라인_v1]] 1~3층. 이 문서는 **"스타일라이즈드가 납작해 보이는" 안티패턴**에 초점. 바이블 값 변경 없음 — 적용 규율만 추가.

### 1.1 "납작"의 셰이딩 진단

스타일라이즈드 메시는 면이 단순해서 **라이팅이 약하면 즉시 종이처럼 보인다** (PBR 메시는 노멀맵 고주파가 형태를 버텨주지만 Synty는 그게 없다). 역설: 면이 단순할수록 색·밸류 위계가 *더* 중요하다 (바이블 §Hell Express 차용범위 주석과 일치).

| 안티패턴 | 증상 | 처리 |
|---|---|---|
| 균일 앰비언트만 | 모든 면이 같은 밝기 = 풀 그림자책 | 키라이트(Frozen Golden Hour 태양)가 면별 NdotL 차이를 만들게 — sunlightColor ×1.7 유지 |
| 그림자 없음 | 오브젝트가 바닥에 안 붙음 = 떠 있음 | **접지 그림자 필수** (§2.3) |
| 색온도 단일 | 웜만 or 쿨만 → 입체감 소실 | **쿨 그늘(zenith 0.35,0.40,0.75) vs 웜 키** 대비 = 바이블 핵심. 이 한 축이 납작함의 최대 백신 |
| 하이라이트 클리핑 | 흰색 워시 = 형태 정보 소실 | ACES 톤매퍼 + 라이트 풀이 흰색으로 안 타게 (range·높이로 면적 확보, 강도 금지) |

### 1.2 스타일라이즈드 전용 라이팅 노브 (바이블 위에 얹는 규율)

- **키:필 비 = 명확히.** 균일 앰비언트로 메우면 납작. ambientLightMultiplier 2.0은 *바닥 정보 보존*용이지 *키 대체*가 아니다. 태양이 지배광 (검증됨: [[project_graphics_verification_loop]] "태양이 지배광, ambient 기여 0에 가까움").
- **로컬 Ember 풀로 중경에 빛 변주.** 빈 바닥(C2)이 곧 납작(C1)이다 — Ember 풀(intensity 7/range 9/1800K)이 면적 광으로 밸류를 깨준다. 바이블 3층 레시피 그대로.
- **APV 베이크로 GI 바운스.** 스타일라이즈드는 균일 그림자가 치명적 — APV가 그늘 안에 색·밸류 변주를 넣어 "정보 있는 암부"(노출 원칙 2)를 만든다. ScanLit_v2 베이크 검증됨(GI 바운스 작동).

### 1.3 라이팅 검증 (캡처 루프)

- JudgeCam→PNG→Read (MCP Camera_Capture 죽은 프레임 함정 회피, [[project_graphics_verification_loop]]).
- 판정 질문: **"오브젝트가 종이처럼 납작한가, 형태가 읽히나?"** — 유저 눈.
- 회귀 노브: 의심되면 키라이트 끄고 앰비언트만 → 납작함의 베이스라인을 눈으로 확인 후 키 복원.

## 2. 가독성 처리 — C4(머드) 격파 ★톤게이트가 지목한 진짜 약점

> 권위: [[2026-06-13-monster-tonegate-resolution]] §2 "진짜 약점은 톤이 아니라 가독성", §3 "후속작업 = 괴수 림/이미시브". [[feedback_vision_cone_always_on]] "가독성=액터" 라인.

톤게이트의 결정적 발견: **15m에서 톤 충돌은 비이슈, 진짜 문제는 어두운 괴수가 어두운 노면에 묻히는 것.** 해법은 툰이 아니라 **악센트로 위협을 *튀게*** 만드는 것. 이게 안티-조잡의 가장 직접적인 레버 — 액터가 안 읽히면 무드가 아무리 좋아도 "못 만든 게임"이다.

### 2.1 MonsterActor 림/이미시브 (셰이더 통일층의 핵심)

기존 `ActorRimLit.shader`가 이미 **풀 URP PBR + Fresnel 림(이미시브로 가산, 암부에서도 발광)** 을 제공 → 괴수 가독성의 베이스. 톤게이트 하이브리드(아웃라인-전체 / 램프-매트만 / 전기-PBR유지)를 이 한 셰이더 패밀리로 구현.

| 노브 | 역할 | 안티-조잡 효과 | 시작값(캡처 판정) |
|---|---|---|---|
| `_RimColor` (HDR) | 실루엣 분리광 | 어두운 노면에서 괴수 윤곽이 살아남 | §3 색규약 따름 — **적 발광=자연색**(녹/청백/황). 기본 (0.8,0.88,1.0)은 *플레이어용 시안* 이므로 괴수엔 종별 자연색으로 재지정 |
| `_RimPower` | 림 폭 (높을수록 가장자리만) | 면을 안 먹고 실루엣만 = 형태 보존 | 3.0~3.5 |
| `_RimIntensity` | 림 세기 | 과하면 네온 코스프레(조잡), 약하면 묻힘 | 1.2~2.0, **캡처 변주** |
| Emissive 맵 부스트 | 팩 동봉 발광점 = 텔레그래프 | 위협 언어 + 어둠 속 시인성 | 종별 (속성색) |

**가독성 위계 (위→아래로 보강, 하나로 부족하면 다음)**:
1. **색온도 대비** — 괴수(쿨/어둠) vs 노면(웜 그레이드). 바이블 원칙 3.
2. **Fresnel 림** — 윤곽 분리광 (ActorRimLit).
3. **Emissive 발광점** — 종별 속성색 (산성 녹·전기 청백·가스 황).
4. **접지 그림자/링** — 바닥에 붙임 (§2.3).
5. **시야콘 처리** — 콘 안은 선명, 콘 밖은 탈색/고스트로 *위협만 부각* (기존 ConeGhost·LKPGhost).

### 2.2 하이브리드 통일 적용 (톤게이트 §3 결론을 *환경에도*)

핵심 질문 = "Synty 도시 + 괴수 + VFX가 한 룩으로 읽히나". 답 = **아웃라인을 보편 접착제로 쓴다**:

| 대상 | 처리 | 근거 |
|---|---|---|
| **괴수 전체** | **아웃라인 ON (얇게)** + 림 | 톤게이트: "아웃라인=전 몬스터, 유일한 보편 승리, 단 두께 과하면 form 먹음→얇게" |
| 매트/밝은 괴수 (Crassorrid 등 휴먼앵커) | + 램프 포스터라이즈 (MonsterToon 일부 노브) | 일러스트풍으로 산다 |
| 전기/이미시브 괴수 (Fulgurodonte 등) | 아웃라인만, **PBR+Emissive 유지** (램프 OFF) | 정체성이 스페큘러에 있어 툰 양자화가 죽임 |
| **주인공/휴먼** | 셀셰이드 NPR (CharacterToon, 신규) + 아웃라인 | 셰이더 v1 §2b. 인공색(시안) 림으로 "나" 표식 |
| **환경 (Synty 도시)** | 팩 자체가 스타일라이즈드라 별도 툰 불필요. **선택적 환경 아웃라인** (포스트 패스, §2.4) | 아래 |

### 2.3 접지 (grounding) — 가장 싸고 강한 안티-조잡

떠 있는 오브젝트 = 즉각 아마추어 티. 두 겹으로 붙인다:
- **드롭 섀도우** — 키라이트의 실제 그림자 (그림자 없는 오브젝트 = 조잡 1순위).
- **발밑 링/AO 데칼** — 라이트가 못 닿는 곳·동적 액터(괴수·플레이어)에 접지 보증. 바이블 "라이트는 무드, 데칼이 보증" 라인. 위협 데칼(ThreatArc)과 동일 렌더경로(AfterPost 재드로우) 재사용 가능.

### 2.4 환경 아웃라인 (선택적 — *통일성*을 위한 강한 후보)

괴수·주인공만 아웃라인이고 환경은 안 그러면 액터가 "스티커처럼" 분리돼 보일 수 있다(역설적 클래시). **포스트 프로세스 아웃라인** (깊이/노멀 엣지 검출 fullscreen pass)으로 *환경까지* 가는 옵션을 명세:

- **방식**: depth + normal 불연속 엣지 검출 (Roberts cross / Sobel), AfterOpaque 또는 BeforePost fullscreen.
- **효과**: 도시·괴수·주인공이 **같은 잉크 라인 언어**로 묶임 = C3(클래시) 최강 백신. "한 손으로 그린 그림" 느낌.
- **노브**: 엣지 두께(거리 보정), 깊이 임계, 노멀 임계, 잉크색(§3 금/시안 디제틱 가능), 적용 마스크(환경만/전체).
- **트레이드오프**: 인버티드 헐(MonsterToon)보다 화면 균일·환경 포함 ↔ depth/normal prepass 비용 + 얇은 디테일 과검출 위험. **둘 중 택1 or 병용은 캡처 판정** (인버티드 헐 = 액터별 제어, 포스트 = 화면 통일).
- ⚠️ 판정 포인트(유저): "전체 아웃라인이 통일감을 주나, 만화처럼 과한가?" — A/B 캡처.

## 3. 색 규약 — C3(클래시) 화면 통일

> 권위: 셰이더 v1 §3 (3색조 디제틱). 바이블 색상 예산표. 이 문서는 **"규율로 화면을 묶는다"** 는 운용 규칙.

조잡한 게임은 **색이 제멋대로**다 (모든 머티리얼이 자기 색을 외침). polished 게임은 **제한된 팔레트 + 의미 있는 액센트**. 우리 규약을 *전 레이어 강제*하면 그 자체가 통일 처리다.

### 3.1 3색조 강제 (디제틱)

| 색 | 의미 | 누가 쓰나 | 금지 |
|---|---|---|---|
| **시안** (0.35,0.75,0.85) | 정규 기술·정보·플레이어 | 플레이어 림·정보 UI·스캔·추출 마커 | **라이트 금지, 이미시브만 ×2 HDR** (바이블) |
| **마젠타** | 오버드라이브·신호붕괴 | 강스킬·대시 잔상·수렴샷·사망 | **평시 월드 마젠타 = 금지** (에스컬레이션 전용) |
| **금/웜 오렌지** (1.0,0.6,0.35) | 플레이어 키·안전·골든아워 | FollowLight·키라이트·안전구역 | — |
| 자연색 (녹/청백/황) | 적 발광 (변이) | 괴수 Emissive·림 | 플레이어 색(시안/마젠타)과 충돌 금지 |
| 레드 | 위협 액센트 | 위험구역·텔레그래프 채움 | 환경 남용 금지 (액센트 예약) |

### 3.2 통일 운용 규칙

- **베이스 채도 억제 = 액센트가 살 무대.** 셰이더 v1 §1 "화려함=베이스와의 낙차". 월드 머티리얼 채도 풀(Saturation 0 포스트 + 스무스니스 캡). 시안/마젠타가 화면에서 *유일하게 포화된 색* 이 되는 순간 = 화면 주인공.
- **정보 시안 vs 스킬 시안 = 형태로 분리** (셰이더 v1 §3.2): 정보=얇은 라인/윤곽(샤프), 스킬=글로우/볼륨(면). 같은 색이 형태로 역할 구분 → 조잡 아닌 *체계적*.
- **에스컬레이션 4단**: 평시 절제 → 스킬 시안 → 오버드라이브 마젠타 → 풀워시 마젠타(수렴샷·사망 전용). 평시에 강한 색을 다 쓰면 클라이맥스가 없다 = 조잡 (다 외치면 아무것도 안 들림).
- **ACES 채도 규칙**: 액센트 HDR ×2 이하 (×6+면 톤매퍼가 흰색으로 밀어버림 — 검증됨). 눈에 띄게는 휘도 아닌 **채도·배치**로.

### 3.3 그레이드 LUT (이중온도)

- 포스트 스택의 **이중온도 그레이드** (쿨 그늘 / 웜 키)가 *모든 픽셀에 같은 색 도장* 을 찍어 도시·괴수·VFX를 한 화면으로 묶는다 = C3 가장 직접적 통일 처리.
- SplitToning shadows (0.16,0.22,0.38) balance −20 (바이블). 그늘의 쿨 카운터포인트.
- ⚠️ 판정: "그레이드가 무드를 주나, 칙칙하게 죽이나?" — zomboid(잿빛) ↔ ascent(유채액센트) 슬라이더, 제안 ascent 60% (셰이더 v1 §5). 캡처.

## 4. 포스트 처리 — C6(raw) 격파 + 무드로 덮기

> 권위: 바이블 1층 포스트 스택 (`Greybox_ScanLit_v2_Post.asset` → 마스터 승격 예정). 기존 자산 그대로 재사용 — 신규 아님.

포스트 부재 = "에디터 뷰포트 티" = 즉각 조잡. 통합 스택이 깔리는 순간 화면이 "게임"이 된다. **기존 자산 전부 보유** — 깔고 튜닝만.

### 4.1 평시 스택 (클린 — 카메라 v1.3 "평시 틸트시프트 폐지" 준수)

| 효과 | 값 | 안티-조잡 역할 |

| **Tonemapping ACES** | 고정 | raw 리니어 → 필름 룩. 이거 하나로 절반은 "게임" |
| postExposure +0.45 | | 밝기는 앰비언트로, EV로 밀지 말 것 |
| Contrast +10 | (+24는 미드톤 붕괴) | 밸류 분리 |

### 4.2 조준 게이트 스택 (틸트시프트 — AimBlend 구동)

평시엔 끔, **우클릭 조준에서만** 진입 (카메라 §5):
- **스크린스페이스 틸트시프트** (`TiltShift.shader` + `M_TiltShift.mat`, FullScreenPass): center 0.45 / halfBand 0.18 / falloff 0.22 / mode 2D. ⚠️ 거리 기반 DOF는 톱다운에서 죽음 → 화면 Y 기반 (바이블).
- **시야콘 틸트시프트** (`TiltShiftConeDriver`): 콘 안 선명, 콘 밖 블러 0.6 + 채도 −30%. 조준=정보 집중 연출. 가독성 가드레일(근접 0.1 무조건 선명·각속도 200°/s 제한) 준수.
- 조준 줌 −8° (진짜 줌, FOV 제약 해제됨).

> 틸트시프트는 **무드 도구이자 미니어처 효과** — 잘 쓰면 "프리미엄", 평시 상시면 멀미·정보삭제(조잡). 그래서 게이트.

### 4.3 안 할 것 (조잡 유발 포스트)

- **과블룸** (scatter 높임 + threshold 낮춤) = 우윳빛 워시아웃 = 싸구려. threshold 1.1 사수.
- **과샤프닝** = 엣지 링잉 = 아마추어.
- **평시 전체 비네트/블러** = 정보 삭제 (카메라 v1.3 위반).
- **크로마틱 애버레이션 상시** = 멀미 + 조잡. 글리치 순간(SyncGlitch)에만 디제틱하게.

## 5. 밀도/구성 — C2(빈 공간) 격파

> 권위: 바이블 §갭분석 "빈 그레이박스가 심심함의 최대 원인". lv 영역과 접면 (공간/인카운터는 lv, 비주얼 점유는 artist).

빈 바닥·빈 벽 = "그레이박스 티" = 조잡의 가장 흔한 원인. **화면의 빈 공간을 시각 정보로 채우는 규칙**:

### 5.1 3깊이 레이어 (안개로 깊이 만들기)

- **근경(플레이필드 ~20m)**: 안개 면제 (fogStart1 18m+, 바이블). 액션 선명.
- **중경**: 프롭·드레싱·Ember 풀로 밸류 변주. ★빈 중경 = 납작(C1)+빈공간(C2) 동시 유발.
- **원경**: COZY 안개가 배경 밸류 압축 + 빛기둥 캔버스 (Hell Express 원칙 2 "안개가 라이팅의 절반"). 원경 알파 0.45~0.75로 깊이.

### 5.2 드레싱 점유 규칙 (가족 무관 — 어느 팩이든)

- **바닥 브레이크업**: 단색 아스팔트 = 조잡. 데칼(처리구역 스텐실·테이프·균열·웅덩이)로 면 깨기. 셰이더 v1 §4 ascent_3 레퍼 "행정 점령지"(스텐실·테이프·태그). K-행정 디칼("처리구역 제3호").
- **수직 점유**: 빈 벽 = 빈 공간. 간판·파이프·낙하물·디칼로 수직 채움 (Synty 팩 모듈러 프롭 활용 — 자체 큐브 제작 금지, [[feedback_use_existing_assets]]).
- **삼분할 밀도**: 화면을 9분할 시 *빈 칸 2개 이하*. 단 플레이공간(코너·통로)은 비워둠 (가독성 vs 밀도 균형 — 과밀도 = 다른 종류의 조잡).

### 5.3 디제틱 점유 (서사로 빈 곳 채우기)

- 빈 공간을 "행정 점령지" 서사로 채움 = 조잡 아닌 *세계관*. 봉쇄 테이프·바리케이드·표식 = 밀도이자 스토리 ([[feedback_fit_over_convenience.md]] 디제틱 우선).
- ⚠️ 이건 lv(공간 배치)·st(카피)와 협업 — artist는 *비주얼 점유 규칙*만 명세, 무엇을 어디에 = lv.

## 6. VFX 처리 — C5(빈약) 격파

> 권위: [[project_flashy_action_vfx]](킬버스트), [[project_purge_snapshot_fx]](임팩트프레임), [[project_telegraph_pad_shader]](ThreatArc). 게임감=오케스트레이터 직접 영역 — 여기선 *조잡 방지 관점의 점유/연동 규칙*만.

빈약한 VFX = 행동이 가벼움 = 조잡. 화려함(=뽕)은 [[feedback_pong_over_systematization]] 별개 영역이나, **"조잡해 보이지 않을 최소 점유"** 는 처리 스택의 일부.

### 6.1 점유 규칙 (공간을 먹어야 무게가 산다)

- **처치 = 화면 점유** (킬 링·버스트). 카메라 줌 금지 대신 **이펙트의 공간 점유로 킬 존재감** (카메라 §1 "킬 존재감=이펙트 공간점유"). 기존 킬버스트(시안코어+마젠타엣지) 슬라이스1 완료.
- **타격 = 세컨더리** (머즐·트레이서·히트 스파크·히트스탑). 단발의 무게는 카메라 킥+히트스탑+사운드 3종 합 (게임감 영역).
- **임팩트 프레임** (수렴샷): 화이트아웃+잉크+스미어 (InkBlob/SmashShock). 특별 킬 전용 — 남발하면 조잡, 절제하면 프리미엄.

### 6.2 라이팅·색 연동 (VFX가 화면에서 안 떠 보이게)

- **VFX도 3색규약 강제** (§3). 제멋대로 색 = 클래시. 시안(정보)/마젠타(오버드라이브)/자연색(적) 안에서.
- **VFX 블룸 통과** — 포스트 블룸(threshold 1.1)이 이미시브 VFX를 빛나게. VFX 밝기를 HDR ×2 근처로 (블룸 코어 통과하되 워시 안 되게).
- **베이스 채도 억제와 한 몸** — 어두운 베이스 위 VFX = 화려, 밝은 베이스 위 VFX = 묻힘. C5 해결이 §3.2(베이스 억제)에 의존.

### 6.3 ⚠️ Vefects URP 함정 (기록)

Vefects 3팩 = BIRP surface라 URP 변환 불가 → 텍스처 추출 + Feel 머티리얼 복제로 우회 ([[project_flashy_action_vfx]]). 신규 VFX 조달 시 URP 호환 선확인.

## 7. ★조잡 방지 체크리스트 — "초등학생 게임처럼 안 보이게"

캡처 후 이 게이트를 통과해야 "polished". **여섯 다 못 끄면 하나만 잘해도 조잡** (§0). 각 항목 = 유저 눈 판정.

### 7.1 라이팅 (C1 납작)
- [ ] 오브젝트가 종이처럼 납작하지 않고 **형태가 읽히나** (키:필 위계 있나)
- [ ] **쿨 그늘 vs 웜 키 색온도 대비**가 보이나 (단일 색온도 = 납작)
- [ ] 모든 오브젝트가 **바닥에 붙어 있나** (드롭섀도우 + 발밑 링)
- [ ] 암부에 정보가 남나 (RGB 25~35 바닥, 정보 없는 검정 영역 없나)
- [ ] 하이라이트가 흰색으로 안 타나 (라이트 풀 클리핑 없나)

### 7.2 가독성 (C4 머드)
- [ ] **괴수가 노면에서 묻히지 않고 튀나** (림/이미시브 악센트)
- [ ] 위협 텔레그래프(Emissive 발광점)가 어둠 속에서 보이나
- [ ] 플레이어가 한눈에 식별되나 (인공색 시안 림 = "나")
- [ ] 호드 측후방 위협이 콘 처리에도 읽히나 (pm 우려 — 멀미 vs 정보 균형)

### 7.3 통일 (C3 클래시)
- [ ] 도시+괴수+VFX가 **한 손으로 그린 그림처럼** 읽히나 (아웃라인 통일)
- [ ] 그레이드가 모든 픽셀에 같은 색 도장을 찍나 (이중온도)
- [ ] 색이 3색규약 안에 있나 (제멋대로 색 = 클래시)
- [ ] 액터 아웃라인이 환경과 분리돼 "스티커"로 떠 보이지 않나 (환경 아웃라인 검토)

### 7.4 밀도 (C2 빈공간)
- [ ] 빈 바닥/빈 벽이 없나 (데칼·드레싱·수직 점유)
- [ ] 중경에 시각 정보가 있나 (빈 중경 = 납작+빈공간)
- [ ] 안개가 깊이 3레이어를 만드나 (원경 압축)
- [ ] 과밀도로 가독성을 죽이지 않나 (플레이공간은 비움)

### 7.5 VFX (C5 빈약)
- [ ] 처치가 화면을 점유하나 (킬 링/버스트 — 카메라 줌 대체)
- [ ] 타격에 세컨더리가 있나 (머즐·트레이서·히트)
- [ ] VFX가 3색규약+블룸과 연동돼 안 떠 보이나
- [ ] 특별 킬 임팩트 프레임이 절제돼 있나 (남발 = 조잡)

### 7.6 포스트 (C6 raw)
- [ ] ACES 톤매퍼가 켜져 있나 (raw 리니어 = 즉각 조잡)
- [ ] 블룸이 이미시브 액센트를 빛나게 하나 (우윳빛 워시 아닌가)
- [ ] 평시 화면이 클린한가 (평시 블러/비네트/CA 없나 — 카메라 v1.3)
- [ ] 필름 그레인이 디지털 클린을 깨나
- [ ] 조준 게이트 틸트시프트가 무드를 주나 (평시 상시 아닌가)

## 8. 가독성 해법 요약 (톤게이트 진짜약점 직격)

조잡함 6신호 중 **C4(가독성)가 톤게이트가 명시적으로 지목한 약점** — 별도 정리:

1. **색온도 대비** (1차): 괴수(쿨/어둠) vs 노면(웜 그레이드). 휘도 무너져도 색상 대비는 살아남음 (Hell Express 원칙 3). *공짜* — 라이팅·그레이드가 이미 함.
2. **Fresnel 림** (2차): `ActorRimLit` 이미 보유. 종별 자연색. 암부에서도 윤곽 발광. ★톤게이트 권고 핵심.
3. **Emissive 발광점** (3차): 팩 동봉 맵 = 위협 텔레그래프 + 시인성. 속성색 분화(산성 녹/전기 청백/가스 황).
4. **접지** (4차): 드롭섀도우 + 발밑 링 데칼. 떠 있음 방지.
5. **시야콘 처리** (5차): 콘 안 선명/콘 밖 탈색·고스트 → *위협만 부각*. 기존 ConeGhost·LKPGhost·LKPSilhouette.

> 위계 = 싼 것부터. 1·2로 대부분 해결, 묻히면 3·4 보강, 정보과부하면 5로 솎음.

## 9. lv·오케스트레이터에 넘길 의존성

### → lv (가족 판정·공간 배치)
- **D-1 Synty 가족 결정** — 이 처리 스택은 *가족 무관* 설계. 단 **환경 아웃라인(§2.4)·드레싱 점유(§5.2)는 팩 모듈러 프롭에 의존** → 가족 확정 후 캡처 검증.
- **D-2 드레싱 배치** — §5는 *비주얼 점유 규칙*만. 무엇을 어디에(프롭·데칼 위치) = lv 공간 설계. artist는 "빈 칸 2개 이하·플레이공간 비움" 규율만 제공.
- **D-3 인카운터 거리** — 가독성 위계(§8)는 15m 전제. lv가 다른 교전 거리(매복·근접)를 설계하면 림/이미시브 강도 재검증 필요.

### → 오케스트레이터 (직접 판정·캡처 루프)
- **D-4 미적 콜 캡처 세트** (셰이더 v1 §5·§8 승계, 이 문서가 항목 추가):
  - 베이스 탈색 (zomboid 잿빛 ↔ ascent 유채), 제안 ascent 60%
  - 디제틱 밀도 (없음 ↔ ascent_3 네온), 제안 행정점령지 1/3
  - 림/아웃라인 강도, 스펙큘러 캡
  - **★신규: 환경 아웃라인 (인버티드 헐 vs 포스트 엣지 vs 병용)** — C3 통일의 강한 후보, A/B 필수
  - **★신규: 접지 강도** (드롭섀도우만 vs +발밑 링) — C1/C4 직격

## 10. 정직 조항 (못 하는 것)

- **셰이더로 못 지우는 것**: 거미다리·털뭉치·촉수 등 하이폴리 실루엣/지오는 셰이딩 무관 (톤게이트 §2.4 유지). 아웃라인은 *접착*하지만 단순 실루엣으로 *변환*은 못 함.
- **artist는 룩을 단정 못 함**: 모든 §의 "조잡한가" 판정 = 유저 눈 + 캡처 루프. 이 문서는 *끄는 노브가 무엇인지* 만 안다.
- **여섯을 다 끄기 전엔 미완**: 하나만 잘하면 그게 더 도드라져 조잡 (잘 라이팅된 빈 공간 = 여전히 빈 공간). 체크리스트(§7) = 게이트.
- **과처리 = 다른 종류의 조잡**: 과블룸·과아웃라인·과밀도·과채도는 *반대 방향의* 아마추어 티. 모든 노브에 상한이 있다 (절제가 프리미엄).
