### 0.1 높이 규칙 통과 — **9종 전부 단일 평면 ✓**
비행 2종(Kupolojuve·Carcinoptera)은 **평면 다이브 / 평면 ThreatArc 텔레그래프**로만 해소(상공 체류 = 실루엣 비콘일 뿐, 컨테이너/단상 윗면에 착지·체류 ❌). 원거리 1종(Venodonte)은 **지상 엄폐 사격**(컨테이너/차량 *뒤*, 높이 0 — 고지 사격수 철회). 코어 엘리트·잭팟은 전부 *발밑* 평면. → 위반 0.

### 0.2 트림 권고 (스테이지1 = 첫 인상, 과밀 경계)
- **Arathrox(LV2 거미 투사체)·Horridomorph(LV3 도약 거미 베놈)·Hexateuthis(LV3 그랩)·Cephalonops(LV2)·Occisodonte(LV3 악어) = 1차 풀에서 제외(트림).**
  - **왜**: 9종이 7대 역할을 *이미* 다 덮음. 거미 2종(Arathrox 투사체·Horridomorph 도약 베놈)은 **Venodonte(원거리)·Kupolojuve(공중 위협)와 위협 동사 겹침** → 첫 스테이지에 넣으면 "원거리/공중 위협" 슬롯이 과포화돼 첫 인상이 혼란. Hexateuthis(그랩)는 좋은 변주지만 **유일 그랩 = 새 수용성 학습**이라 2차로 미룸(첫 스테이지는 동사 적게). Occisodonte(수변 매복 악어)는 *수변 디제틱*이 없는 4구역(도심)에선 동기 없음 → 후반 바이옴(평원/늪).
- **결과**: 9종 = 7대 역할 1:1 + 가족 시스템 1축. 동사 셋 = {물기, 산성샷, 점프물기/스핏, 전기샷/대시, 클로 콤보, 램, 다이브, 투석/스톰프(보스)} = 학습 부담 적정.

### 0.3 격하/이동 0
앵커 9종의 권위 LV를 *그대로* 채택. Venosaur는 권위가 "LV3 물량 주력"으로 명시 → 코어 *호위*로 쓰되 LV3 유지(엘리트 본체는 Fulgurodonte LV4). Venodonte는 권위가 **LV1**(후보 앵커는 "LV1~2"로 적었으나 권위는 LV1 군체) → **LV1 외곽 원거리로 확정**(정정).

## 1. 역할 커버리지 매트릭스 (겹침 0 증명)

서바이버즈 농성이 요구하는 7대 전투 역할 ↔ 1종씩 배정. **한 역할에 두 종이 들어가면 첫 스테이지 과밀** → 1:1 강제.

| **원거리/조너** | Venodonte | 1 | 산성샷(3연콤보) | 권위 유일 LV1 원거리. 턴치기 처벌·이동 강제. ★지상 엄폐만 |

## 3. 등장(intro) 순서 / 난이도 곡선

> **첫 스테이지 = 첫 인상.** 9종을 한꺼번에 풀면 혼란 → **한 번에 한 동사**씩 소개. 동심 구심 전진 = 외곽→코어 = 자연히 LV1→LV5 순 노출 = **공간이 곧 튜토리얼**.

```
난이도(y) ↑
       │                                    ╭─★ Crustaspikan(보스/escalation)
       │                          ╭─ Carcinoptera/Fulgurodonte(코어 잭팟)
       │                  ╭─ Dimaxillosaurus(매복=첫 "심박")
       │          ╭─ Kupolojuve(첫 수직 위협)
       │      ╭─ Caniathrox(첫 속도 압박)
       │  ╭─ Venodonte(첫 이동 강제)
       │╭ Lacercharias(쓸어담기 — 무해, 손맛)
       └──────────────────────────────────────────→ 동심 전진(외곽→코어) / 시간
        외곽 r62        중간 r36              코어 r13
```

| 순서 | 종 | 첫 등장 위치 | 가르치는 것(수용성) | 곡선 비트 |
|---|---|---|---|---|
| 1 | Lacercharias | 외곽 진입(릴레이 ①, r62) | "쓸어담는 손맛" — 무해한 연료, 광역 첫 카타르시스 | 고조 시작(낮음) |
| 2 | Venodonte | 외곽, 차폐 *뒤*(릴레이 ①) | "가만히 있으면 맞는다" — 이동 강제, 턴치기 처벌 | 잔물결 |
| 3 | Caniathrox | 중간 분기(릴레이 ②, r36) | "거리를 좁혀온다" — 속도 압박, 카이팅 시작 | 1차 고조 |
| 4 | Kupolojuve | 중간(릴레이 ②, 상공 다이브) | "위에서 온다" — 수직 위협(평면 해소), 텔레그래프 읽기 | 고조 유지 |
| 5 | Dimaxillosaurus | 중간 매복 포켓(②~③ 사이) | "코너에 숨어 있다" — 첫 심박(매복 수용), 콤보 압박 | 2차 고조 |
| 6 | Venosaur | 코어 가장자리(릴레이 ③, 엘리트 동반) | "엘리트엔 살이 붙어 있다" — 호위 처리 우선순위 | 고조 |
| 7 | **Fulgurodonte** | 코어 야드/광장(릴레이 ③ 왈칵/트임) | "이게 뽕 타겟" — 첫 코어 잭팟, 램 텔레그래프=벽 그로기 | **정점 1(첫 클라이맥스)** |
| 8 | Carcinoptera | 코어(분수광장 한정, 릴레이 ③) | "개활의 공중 정예" — 다이브 정예 처리 | 정점(분수광장) |
| 9 | Crustaspikan 유생→성체 | 발원 격리 코어(2차) / **escalation 변이 웨이브** | "지연하면 큰 게 온다" — 가족 예고, 보스 사건 | **정점 2(escalation 잭팟)** |

### 3.1 페이싱 = 파동 (선형 ❌)
동심 전진 자체가 **고조(외곽 쓸기) → 게이트 클리어(중간 카이팅 본전장 정리) → 의도적 숨 고르기(중간↔외곽 완충 r50~55 = 저밀도) → 코어 재고조(왈칵/트임 = 정점)**. 둠클락(처리 지연 escalation)이 *선형 압박*이 되지 않게: **할당량 채우면 퇴근(숨)**, 한 탕 더 커밋하면 **escalation 변이로 재고조**. → 단조 "타이머 생존" 회피.

## 4. escalation 변이 후보 (처리 지연 시 변이 웨이브)

> 독트린: "못 채우고 끌면 escalation — 능력치↑·밀도↑·변이(처리 지연=이상개체 변이 가속)." 하드 타임아웃 사망 ❌. **변이 = 같은 종의 *격상*, 신규 종 발명 ❌** → 권위 로스터 내 *상위 LV 동족/틴트*로 표현.

| 지연 단계 | 변이 표현 (로스터 내 재료) | 왜 이 종 |
|---|---|---|
| **1단(경)** | Lacercharias·Venodonte **밀도↑ + Venodonte ×4 틴트로 등급 리컬러**(권위 §0 무료 변형) | fodder가 마르지 않음 + 원거리 견제 빽빽 = 카이팅 압박. 틴트=시각 escalation 공짜 |
| **2단(중)** | Caniathrox·Kupolojuve **능력치↑(속도/투사 빈도) + Venosaur 호위 수↑** | 중간 본전장이 "끊는 견제"에서 "쉴 틈 없음"으로. 호위 두꺼워짐 |
| **3단(강)** | **CrustaspikanLarvae 분출 웨이브**(돛 실루엣 떼) = "성체가 깨어난다" 디제틱 예고 | 가족 시스템 = 에셋 내장 escalation. 유생 떼 = 보스 임박 신호 = 미스터리/위협 동시 |
| **4단(보스)** | **Crustaspikan(LV5 성체)** 강림 — 투석·스피터샷·스톰프·양손스매시 | 데모 최종 후보. 지연의 *대가이자 잭팟*(escalation이 보상이기도) |

- **발원 격리는 escalation이 *디제틱으로 내장*** — 보울 코어가 가족 무대라 유생→성체 변이가 공간과 1:1. 다른 3구역은 유생 분출 웨이브를 *난입*으로(디제틱 출처 = 균열/하수구).
- **앵커 외 보강 후보(2차 escalation 풀)**: 권위 LV5 거물 중 Rostrokarck(거미게 타이탄, 알→유생 가족) / Kupolobrach(공중 돔 보스, 유체 가족) = **다른 두 가족 계보**가 후반 바이옴/2차 escalation에 대기. 1차는 Crustaspikan 1가족만(과밀 회피).

## 5. 6대 북극성 — 종별 강축 (선정 근거)

| 종 | 가장 강한 축 | 근거(권위 킷 → 수용성) |
|---|---|---|
| Lacercharias | **속도감 + 플레이어 수용성** | 저자세 롤링 돌진 = 빠르고 "쓸어담기 좋은" 연료. 무해해서 첫 카타르시스 안전 |
| Venodonte | **위협감 + 영리함** | 3연 산성샷 + (정지사격 처벌 설계) = "가만 두면 맞는다"의 영리한 압박 |
| Caniathrox | **속도감(1순위 직격)** | 권위 "사냥개/스프린터 본대" = 쾌속 추격 = 게임의 속도감 정체성 |
| Kupolojuve | **생명감 + 위협감** | 비행 맴돎 = 살아있는 실루엣(비콘) + 위에서 오는 위협. 평면 다이브로 수용성 확보 |
| Dimaxillosaurus | **위협감 + 영리함** | 매복 포켓의 주인 = 코너 돌면 왈칵 = 첫 "심박". 직립 클로 콤보 = 압박 |

| Venosaur | **장인정신(군중 연출)** | 호위 떼 = 엘리트 둘레를 채우는 살 = 잭팟의 "양감". 단독 약함이 곧 역할 |
| Carcinoptera | **생명감 + 위협감** | 개활 공중 정예 = 빛나는 미끼 + 다이브 정예. 광장에서만 빛남(공간 적합) |
| Crustaspikan(가족) | **위협감 + 영리함(예고)** | 유생→성체 = 에셋 내장 디제틱 예고 = "지연하면 큰 게 온다"의 영리한 escalation |

### 리스크
- **R1(전제·최대)**: **로스터 선별은 "쫄깃한가"를 판정 못 함** — 종이 *맞나/겹치나/평면인가*까지만. 한 마리의 쫄깃함 = 게이트0 전투감(인식 3상태·피격 사다리·히트스탑) + 종별 애니(Animation) 선행 필수. 로스터 = 배역표, 연기 = 전투감+애니.
- **R2(과밀 첫 인상)**: 9종도 동시 노출하면 혼란 → **등장 순서(§3) 강제**가 핵심. Gameplay 스폰 디렉터가 릴레이 비트별로 *새 종 1개씩* 게이팅해야(한 비트에 신규 2종 ❌).
- **R3(겹침 재발 방지)**: 트림 5종을 2차에 넣을 때 **역할 슬롯 충돌 재검**(Arathrox/Horridomorph = 원거리/공중 슬롯 = Venodonte/Kupolojuve와 재겹침 위험). 2차는 *새 역할*(그랩=Hexateuthis 등)부터.
- **R4(높이 정합)**: 비행 2종 다이브 목표·성체 보스 투석 = 전부 평면 텔레그래프. 그레이박스 베이크서 윗면 워크어블 0 확인(§6). 잔여 고지 표현 = 버그.
- **R5(가족 시스템 의존)**: Crustaspikan 유생→성체 escalation은 **Gameplay 런타임(분출·강림) + Animation(상태 시퀀스)** 합작 의존. 1차(집하장+분수광장)엔 가족 *난입*만, 본 무대(발원 격리)는 2차.
- **R6(데이터화 미선행)**: MonsterDef SO·스포너 연동은 분류 동결 후 Gameplay 단계(권위 §4). 본 문서 = 선별·배역까지, 인스턴스화는 핸드오프.

## 9. 한 줄 요약
**앵커 9종 전부 통과 — 7대 전투 역할 1:1 + Crustaspikan 가족 1축으로 4구역을 빈틈·겹침 없이 받침. 트림 5종(거미 2·그랩·곤충·악어)은 역할 과포화/디제틱 부재로 2차. 등장 순서 = 동심 전진 = 공간이 튜토리얼(한 번에 한 동사). escalation = 로스터 내 격상/틴트 4단계(밀도→능력치→유생 분출→보스). 전부 단일 평면(비행=다이브, 원거리=지상 엄폐). 쫄깃함은 게이트0 전투감+애니가 판정.**
