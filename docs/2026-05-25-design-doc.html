I
무기 시스템
4트리 20종 — 발동 방식 · 설계 원칙 · 시너지

①설계 원칙

로드킬이 주 딜

무기는 "보조 레이어". 무기가 운전을 대체하지 않는다. 좀비를 치는 행위 자체가 항상 가장 강력한 수단.

조작 실력과 시너지

잘 운전할수록 더 강해지는 무기 구조. 드리프트, 속도, 급가속이 직접 무기 발동 조건이 된다.

차량 부착물에 한정 안 함

나노봇 SF 세계관으로 오비탈·자동·설치형 모두 허용. 물리적 부착 여부는 고려하지 않는다.

자동 발동

플레이어 별도 조작 없이 조건/주기/항시로 작동. 운전에 집중하면서도 화력이 자동으로 유지.

②발동 방식 분류

유형설명예시
오비탈차량 주변에 항시 활성, 거리/공전 형태 유지나노봇 실드, Wreck Ball
주기N초마다 자동 발동EMP 버스트, 자동 저격 드론
조건드리프트·속도·피격 등 특정 상태 진입 시드리프트 슬래셔, 혈액 나노봇
설치지나간 자리나 특정 위치에 오브젝트 배치나노봇 지뢰, 전기 울타리

⑤핵심 전제

PendingLevels 소진

피트스톱 진입 시 쌓인 레벨을 전부 소진하며 선택. 레벨 3이면 3번 선택, 0이면 UI 미표시.

카드 4장 제시

매 선택 화면에 4장. 해금(신규 무기)과 강화(기존 레벨업)가 보유 무기 수에 따라 혼합.

⑥카드 풀 구성 규칙

보유 무기 수해금 슬롯강화 슬롯
0개40
1~2개22
3~4개13
5개 이상0~1 (해금 가능 시만)3~4
· 같은 트리 카드: 한 화면에 최대 2장 · 동일 무기 카드: 같은 화면에 절대 중복 불가

⑦희귀도 가중치

기본 확률

Normal70% → 40%
Rare25% → 40%
Legendary5% → 20%

→ 화살표는 게임 후반(20분 or Lv30) 최대 변화값

Bank Bonus (레벨 축적 보정)

피트스톱 진입 시 PendingLevels ≥ 5이면 Legendary 확률 추가 보정.

bankBonus = Clamp01((pendingLevels - 4) * 0.03f)
// 레벨 5부터 3%씩 증가

늦게 방문할수록 고등급 카드 확률 상승 → 리스크-리턴 장치

진행도에 따른 확률 공식

timeFactor  = Clamp01(gameTime / 1200f)   // 20분에 최대
levelFactor = Clamp01(playerLevel / 30f)  // 레벨 30에 최대
progression = Max(timeFactor, levelFactor)

Normal:     70% - (30% × progression)   →  70% ~ 40%
Rare:       25% + (15% × progression)   →  25% ~ 40%
Legendary:   5% + (15% × progression)   →   5% ~ 20%

⑧트리 어피니티 (Tree Affinity)

점수 계산

행동점수
해당 트리 무기 해금+2점
해당 트리 무기 강화+1점
피트스톱 완료 후 감쇠× 0.9

최근 선택이 더 큰 영향. 감쇠 덕에 방향 전환도 가능.

가중치 반영 공식

가중치 = 1.0 + affinityScore × 0.5

근접 어피니티 6점 → 가중치 4.0
원거리 어피니티 0점 → 가중치 1.0

· 해금 카드 1.2배 추가 가중치 (해금 우선 유도)
· 한 트리 최대 2장 규칙으로 "우연한 발견" 보장
· 어피니티 0인 트리도 완전히 사라지지 않음
