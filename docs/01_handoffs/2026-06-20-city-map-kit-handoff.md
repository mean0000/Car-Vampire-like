# 핸드오프 — 도시 맵 키트 / 건물 모델링

> 2026-06-20 작성. 탑다운 조준형 뱀서 첫 도시 맵의 **모듈 키트**가 동결됐다. 이 문서는 다음 세션(특히 **건물 모델링 세션**)이 콜드 스타트로 집어들기 위한 진입점.

## 0. 먼저 읽을 것 (진입점)
- **권위 스펙:** `docs/00_authority/2026-06-20-city-map-kit-spec.md` (= `.html` 동일 내용, 보기 편한 버전). **모든 치수·기준·타입은 여기가 단일 출처.** 이 핸드오프는 그 위의 *작업 지시*일 뿐.
- 무드 레퍼 16장: `docs/03_reference/reference_design/`
- 관련 메모리: 절차 사이파이 빌딩 파이프라인 검증(06-20), 실사 A 아트방향 동결(06-19).

## 1. 한 줄 목표
유저가 수급한 **타입별 건물 레퍼 이미지**를 받아, 스펙 §3 타입 카탈로그 + §4 핸드오프 기준에 맞춰 **건물 매스를 모델링**한다. (맵 전체를 자동 생성하는 게 아님 — 유저가 그리드에 손배치할 *부품*을 만드는 것.)

## 2. 동결 결정 요약 (재논의 금지 — 상세는 스펙)
- 카메라 = **탑다운.** 빌딩 = 벽/블로커, 도로·광장 = 플레이 네거티브 스페이스.
- **탑다운 가시면 = 풋프린트 실루엣 + 옥상 + 도로변 하단 12~20m뿐.** 중간 샤프트는 안 보임 → 디테일 예산 거기 안 태움.
- 무드 = 브루탈리스트 사이파이 메가스트럭처(**실사 A / PBR**). 거대 단일 매스 · 하드서피스 그리블 · 수직 발광 스트립 · 헤이즈/포그.
- 그리드 = **48m 셀** · 1 unit = 1m · 맵 6×6 = 288m. 도로 2단(대로 48 / 골목 24).
- 빌딩 조달 = **레퍼 이미지 기반 모델링.** owned 사이파이 빌딩 0개(손배치 불가) · **Synty 섞기 금지**(셰이더 클래시).

## 3. 작업 트랙

### 트랙 A — 건물 모델링 (이 핸드오프의 본체, 별도 세션)
1. 유저가 `docs/03_reference/reference_design/by_type/B{n}/`에 타입별 레퍼를 채운다. **첫 패스는 B1·B2·B3 우선**(벽+랜드마크 최소셋).
2. 타입별로 스펙 §3 슬롯 치수(풋프린트·티어)에 맞춰 매스 모델링.
3. **§4 핸드오프 기준 필수 준수** (아래 체크리스트).
4. 산출 = 건물당 FBX(또는 .blend), 네이밍 `B{타입}_{풋프린트}_{티어}`, 원점 베이스 중앙.

| 타입 | 풋프린트 | 티어 | 역할 | 핵심 레퍼 특징 |
|---|---|---|---|---|
| B1 저층 벽 블록 | 96² / L | 저층 | 블록 경계 벽 | 넓고 낮은 브루탈 매스 + 베이스 그리블 |
| B2 슬랩 타워 | 48×96 | 미드 | 대로변 벽 | 깨끗한 모놀리스 슬랩 |
| B3 그리블 타워 | 48² / 96² | 메가 | 랜드마크 | 트러스/파이프/안테나 하드서피스 |
| B4 발광 스트립 타워 | 48² 슬림 | 미드~메가 | 내비 랜드마크 | 수직 주황/빨강 발광 라인 |
| B5 히어로 포디움-타워 | 96² / L | 메가 150m+ | 맵 히어로(1~2개) | 포디움+샤프트+크라운 풀세트 |

**모델링 체크리스트 (§4 요약):**
- [ ] 1 unit = 1m 실측, 풋프린트 48m 배수 스냅
- [ ] 피벗 = 베이스 중앙, Z=0 위에 서고 +Z 업
- [ ] **비균일 스케일 메시에 굽지 마라** (NavMesh 베이크 깨짐) — 진짜 치수로
- [ ] 디테일은 옥상/크라운 + 도로변 하단 12~20m에만, 중간 샤프트 플랫/저폴리
- [ ] 발광 = 별도 Emissive 맵(알베도에 글로우 굽지 마라, URP 블룸이 띄움)
- [ ] 서피싱 = 실사/PBR 브루탈리스트, Synty 플랫 금지
- [ ] 3단 문법(포디움+샤프트+크라운) 유지

### 트랙 B — 그리드 배치 환경 (보류, 오케스트레이터가 유저 호출 시)
- 도로 = **셀 단위 모듈 타일 손배치**(슬래브 아님, 오토 생성기 폐기). 직선·코너·T·십자·막다른길·광장.
- **그리드 좌표 척추(48m)를 먼저** 깐 뒤 타일·건물 스냅.
- 배치 방식(네이티브 스냅 vs 페인터 툴 vs 스냅 헬퍼) 미정 — 유저가 부르면 그때 결정·착수.
- 실제 메시 도착 전엔 그레이박스 플레이스홀더로 환경 가동, 후에 스왑.
