## §0. 오늘의 판정 — 왜 이 패스인가 (전 세션 공통 컨텍스트)

**4번째 "재미없다" 판정 (유저, 06-12 플레이).** 증언 원문 요지:
- "전투부터가 뭘 어쩌자는 건지 모르겠다. 총을 쏘는 것 자체에서 쫄깃함이 없다"
- "좀비가 위협적이지 않은 것도 크다. 그렇다고 화려한 액션이 있는 것도 아니다"
- "분위기가 하나도 없다. 무언가 압박을 주는 듯한 게 필요하다"
- "UI도 직관적이지 않고 맵·분위기 전부 조악해서 반복의 재미를 모르겠다"

**확정 테제 (유저):** 좀비가 **매우 위협적**이어야 한다 — 대미지 + 속도 + 연출. 위협 0이 모든 안쫄깃함의 뿌리.
- 구조적 배경: 05-31에 "압박=감염시계 담당, 좀비=패시브"로 결정 → 06-09에 시계 폐기 → **위협 담당이 공석인 채 한 달 경과.** 현 좀비 수치는 차량 시대 상속 기본값.
- 비주얼 위협의 운반체 = **메시가 아니라 모션·사운드** (Zero Sievert는 픽셀아트, Zomboid는 로우폴리인데 무서움). 메시 교체 ❌, 연출 패스 ⭕.
- 2026 레퍼런스: Zero Sievert(1.0 2024)·**Zero Sievert 2**(2026-04 EA 발표, 같은 장르)·Project Zomboid B42(물리면 사망 100%)·RE9 Requiem — 시장 흐름 자체가 "좀비를 다시 무섭게".

**프로세스 전환 (유저 합의):** 스펙동결→시공→게이트 파이프라인은 정합성용이지 재미 발견용이 아님(4연속 실패의 구조 원인 후보). 게임감 수치는 **유저 인더루프 노브 세션**(유저가 에디터 앞, 실시간 값 변경)으로 찾는다. 30분에 12번 "아니야"를 듣는 게 목표.

**강등/기각 기록:**
- 벌집 모델(개체 약하게+소음 에스컬레이션) → **후보로 강등.** 소음 긴장 축은 05-31에 "소음=벌점뿐" 판정 이력 있음. 개체 치명화가 우선.
- 동결 문서는 가설이지 사실이 아님 — 유저 손맛 증언이 종이보다 상위 증거. 카메라 권위(45°/15m)도 재심사한다.

**미니 게이트 (전 세션 공통, 단 하나):** ***"좀비 한 마리 보고 심박이 바뀌는가."***

## §2. 세션 1 — 연출 총괄 (Fable 디렉팅 세션, 이 문서 작성 세션)

**임무**: 압박의 무대 만들기 + 카메라 재심사.

1. **카메라 재심사 4축** — [[2026-06-10-camera-system]](45°/15m 동결)을 위협 테제 기준으로 재검. 프리셋 조합을 준비해 노브 세션에서 유저 즉석 전환·판정. 바뀌면 권위 문서 개정까지.
   - 거리(15m→가깝게: 화면 밖=불안), 각도(45°→낮게: 공포 연출↑/정보↓), 추적(고정 추종 → 조준 방향 lookahead: "등 뒤가 화면 밖" 구조 긴장), 반응성(댐핑/관성)
2. **라이팅/무드 적용** — [[2026-06-10_그래픽_베이스라인_v1]] 룩을 CombatLab(노브 세션 무대)에 적용. 미적 콜 = 캡처 보여주고 유저.
3. **sd(Sound) 첫 실전 — 사운드 3종**: ① 앰비언트 베드 1겹(저역 드론) ② 좀비 보컬(평시 으르렁 3D 포지셔닝 = 후방 압박 정보, 발각 절규) ③ B-004 사운드 채널 라우팅/덕킹 검증. **음색 판정은 전부 유저 귀** — sd는 시스템 검증만, 세션 말미 "들어볼 목록" 제출.
4. **소음→어그로 사슬 실측·구현** (Gameplay 위임) — 총성이 실제로 좀비를 끌어오는지 확인, 죽어 있으면 살린다. 단 NoiseManager 쪽에서만 — ZombieController는 세션 2 커밋 후.

## §4. 세션 3 — 좀비 위협 본체

**임무**: 좀비를 "사건"으로. 산출물 = **노브 맵 1장 + 시공**, 최종 수치는 노브 세션(유저+세션1)에서 확정하므로 **시작값으로 박고 런타임 조절 가능하게**.

1. **수치 전수 실측 → 노브 맵**: 좀비 대미지·플레이어 HP·이동/공격속도·Grapple 판정·쿨다운이 *실제로 어디 사는지*(코드 상수/SO/씬 직렬화) 표 1장. ★씬 직렬화가 코드 default를 이기는 함정(§5) 때문에 "진짜 값 위치" 명기 필수.
2. **치명화 시작점**: 좀비 대미지 ×3 / 플레이어 HP 하향(일반 타격 3~4대 사망권) / Grapple 잡히면 절반~즉사권
3. **속도 편차**: 대부분 워커 유지 + 스프린터 ~20% 혼합. **돌진 전 텔레그래프 필수**(없으면 억울한 죽음 양산). 신규 제작 전에 옛 Charger 변종(05-25 구현) 재활용 가능성부터 검토.
4. **연출 패스**: 애니 재생속도 가속, 런지 모션, 어그로 시 변화. (보컬 사운드는 세션 1 소유 — 만들지 말 것)
5. ZombieController.cs는 **세션 2의 일괄 커밋 후에만** 수정. 그 전에는 SO/프리팹/애니메이터에서 가능한 작업 먼저.
