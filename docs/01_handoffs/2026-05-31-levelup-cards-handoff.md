## 1. 확정된 규칙 (그대로 따른다)

### 진행 모델 — C안 (누적 + 청크 + 진화)
- 카드 Lv1→3 누적 (같은 카드 또 뽑으면 레벨업), 만렙 시 **진화**.
- **매 레벨이 청크**: 조건 완화 / 절(clause) 추가 / 체감되는 수치. **미미한 +5% 금지.**
- 가진 카드 계속 레벨업 가능 → 풀 고갈 없음.

### 2층 카드 풀
- **기본 카드**(자주): 청크 스탯 — 무기/생존/이동/유틸.
- **동사 카드**(가끔): 조건부 질적 행동 = 빌드 정체성.
- **무기 시그니처**: 선택 무기 장착 시에만 드로우.
- 드로우 = **2택1**, 초반 기본↑ → 후반 동사↑.

### 무기 (MVP)
- 단일 캐릭터, 시작 시 **야구방망이(근접) vs 권총(원거리) 택1**.
- 암살(F) 공용. 죽은 슬롯 0 (선택 무기 시그니처만 등장).

### 네이밍
- 기본 카드 = **명확 기능형 이름 + 고정 subtitle** `[조건] → [효과]`.
- 진화 카드만 플레이버 허용.

### 감염 수치
- 코드 `SyncRate` 0~1 척도로 표기 (감염 ≥7 = `0.7`).

## 3. 만들 카드 체크리스트 (MVP)

### 기본 카드 — 무기 (권총)
- [ ] 속사 — 연사 속도 +25% (Lv2 +40% · Lv3 +55%)
- [ ] 강선 — 사격 피해 +1 (기본 damage=2 → 청크. Lv2 +2 · Lv3 +3)
- [ ] (후보) 명중 관용 — hitRadius↑ / 사거리↑

### 기본 카드 — 무기 (야구방망이)
- [ ] 묵직한 스윙 — 스윙 속도 +25%
- [ ] 긴 리치 — 근접 사거리 +30%
- [ ] (후보) 강타 — 근접 피해↑

### 기본 카드 — 생존 / 이동 / 유틸 (무기 무관)
- [ ] 강화 골격 — 최대 체력 +30% (Lv2 +50% · Lv3 +75%)
- [ ] 경량화 — 이동 속도 +15% (Lv2 +25% · Lv3 +35%)
- [ ] 자력 채집 — 부품·XP 흡수 반경 +40%
- [ ] 효율 흡수 — XP 획득량 +25%

### 동사 카드 — 등뼈 (계열, 무기 무관) — 목표 7장
- [ ] **무음 보행** (스텔스) — 웅크려 이동 시 소음 0 / Lv2 해제 후 1.5s 억제 / Lv3 웅크림 속도 +30% / ★유령 보행: 웅크림 중 탐지 반경 -50%
- [ ] **소음 미끼** (스텔스) — 액션키(쿨15s) 먼 곳 소음펄스 유인
- [ ] **연속 처치** (전투) — 5연속 처치 → 다음 공격 ×2 + 소음0 / Lv2 4연속+관통 / Lv3 3연속+이동↑ / ★학살의 박자: 광역 처형
- [ ] **소음 폭주** (전투 ⚖️) — 소음>50 → 피해+25%, 감쇠정지 / ★과부하: 소음 광역 방출
- [ ] **감염 가속** (감염 ⚖️) — 감염≥0.5 → 이동+25%·공속+20% / Lv2 ≥0.4+자가축적 / Lv3 ≥0.7 넉백면역+피해↑ / ★변종: ≥0.8 좀비 블렌드
- [ ] **전이** (감염 🟢) — 처치 시 감염 +0.05
- [ ] **오염된 귀환** (감염) — 감염≥0.7 집 방향 이동+20%, 공격 시 해제
- ※ 감염 동사 보유 시 **볼록비용 ON**: 감염 0.7+ 받는피해 +15% (0.9+ +30%)

### 무기 시그니처 — 권총 (2~3장)
- [ ] **관통탄** — 1체 관통 / Lv2 2체+소음-5 / Lv3 3체+넉백 / ★레일샷: 직선 전부+벽 관통
- [ ] **메아리** — 발사 소음을 먼 곳으로 분산(소음 단점→유인 전술)

### 무기 시그니처 — 야구방망이 (2~3장)
- [ ] **풀스윙** — 넉백 반경↑
- [ ] **무음 타격** — 스윙 소음 -50% (스텔스 융합)

### 폴백 (풀 고갈 시 드물게)
- [ ] 응급 키트 +1 / 감염 -0.1 정화 등 반복 유틸 (자주 안 뜨게)

## 4. 코드 현실 — 무엇이 있고 없나 (구현 전 필독)

이번 세션 코드 감사 결과. 카드를 코드로 옮길 때 **없는 훅은 먼저 만들어야** 한다.

### 이미 있음 (바로 활용)
- **소음**: `NoiseManager` — `CurrentNoise`(0~100), `EmitImpulse(v)`, `IsChaseThreshold`(≥50). ※자연감쇠는 내부 envelope, **공개 리셋/정지 없음**.
- **감염**: `SyncRateManager` — `SyncRate`(0~1), `AddSync`, `ReduceSync`, `OnSyncChanged`, `OnSyncMaxed`.
- **스텔스/웅크림**: `PlayerController.IsStealth`, 웅크림 = LeftCtrl(프로퍼티 미노출), `CurrentHP`/`MaxHP`, `Heal`, `TakeDamage`.
- **암살**: `PlayerCombat.FindAssassinationTarget`, `ZombieController.TryAssassinate`/`IsAssassinable`.
- **레벨업 버퍼**: `XPManager.PendingLevels`, `ConsumePendingLevel`, `OnLevelChanged`.
- **업그레이드 UI**: `UpgradeMenuUI`(현재 **무기 카드 전용** — 동사 카드 시스템 없음). `PitStopZone`은 **CarController 체크 = 차량 피벗 레거시**(도보 게임이라 정리 대상).

### 없음 — 새로 만들어야 (카드별 의존)
- ❌ **AbilityManager / 카드 시스템** — 동사 저장·적용·드로우 전부 신규.
- ❌ **OnZombieKilled 이벤트 + 킬 카운터** — 연속 처치·전이 등 on-kill 카드 공통 의존. `ZombieController.Die()`에 이벤트 추가 필요.
- ❌ **데미지/스탯 수정 레이어** — 피해 배수·이동속도·공속·탐지반경 mod (소음 폭주·감염 가속·기본 카드 다수).
- ❌ **근접 공격(야구방망이)** — 현재 기본공격은 권총 히트스캔(`Fire`)뿐. 근접 신규 구현.
- ❌ **넉백** — 풀스윙·연속 처치 관통 등. 없음.
- ❌ **웅크림 상태 프로퍼티 노출** — 무음 보행용.
- ❌ **위치 기반 소음원** — 소음 미끼용(현재 소음은 글로벌 단일값).
- ❌ **집 위치/귀환 이벤트** — 오염된 귀환용.
- ❌ **드론·지뢰 무기** — post-MVP.

## 5. 미해결 / 다음 세션 결정·튜닝

1. **청크 수치** — 각 카드 Lv1→3 증가폭 (속사 +25/40/55 등 시작값, 플테 조절).
2. **기본 : 동사 드로우 가중치** — 초반/후반 비율 곡선.
3. **진화 조건** — "만렙 + 계열 동사 2개" 류 게이트 구체화. 너무 빡빡/헐거움?
4. **볼록비용 수치** — 감염 0.7+ +15% / 0.9+ +30% 시작값 검증.
5. **카드 총량** — 기본 ~8 + 동사 7 + 시그니처 4 + 폴백 = ~20장. 한 런 ~7픽에 충분한 다양성인지.
6. **양날검(⚖️) 검증** — 소음 폭주·감염 가속이 "재밌는 도박"인지 "그냥 나쁜 선택"인지.

```
   "발밑의 정적이 무기가 된다."

[소음 폭주]                        전투 · ⚖️
└ 소음 50↑ → 피해 +25%, 소음 자연감쇠 정지
   Lv2 임계 효과↑ · Lv3 추가 절
   ★진화「과부하」: 쌓인 소음을 광역 피해로 방출

[감염 가속]                        감염 · 🔵⚖️
└ 감염 0.5↑ → 이동 +25%, 공속 +20%
   Lv2 임계 0.4 완화 + 공격 시 감염 +0.02
   Lv3 감염 0.7↑ → 넉백 면역 + 피해 +15%
   ★진화「변종」(만렙+감염 동사 2개) : 감염 0.8↑ 좀비 사이 통과 시 2초 아군 인식

[연속 처치]                        전투 · 🔵
└ 5연속 처치 → 다음 공격 피해 ×2 + 소음 0
   Lv2 4연속 완화 + 강화 공격 1체 관통
   Lv3 3연속 완화 + 발동 시 이동 +30% 2초
   ★진화「학살의 박자」(만렙+전투 동사 2개) : 강화 공격이 주변 1.5m 저HP 좀비 처형

[관통탄]                           권총
└ 사격이 좀비 1체 관통
   Lv2 2체 + 관통마다 소음 -5
   Lv3 3체 + 마지막 대상 넉백
   ★진화「레일샷」: 직선상 전부 관통 + 벽 1회 관통
```
