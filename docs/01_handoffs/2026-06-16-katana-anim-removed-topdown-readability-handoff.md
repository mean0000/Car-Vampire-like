# 핸드오프 — 카타나 공격 애니/사운드 제거 + 탑다운 가독성 원칙 (2026-06-16)

## 한 줄 요약
카타나 공격 **애니메이션 트리거 배선 + 타격음을 전부 제거**(메커닉만 남김)했고, 카타나 애니 팩(Frank/Grruzam) 평가 과정에서 **"탑다운 카메라에선 몸 애니의 화려함이 아니라 *무기 호 + VFX + 수평 텔레그래프*가 가독성을 만든다"**는 원칙을 유저가 직접 눈으로 확인했다. 팩 구매는 **미결** — 질문이 "Frank냐 Grruzam이냐"에서 **"애니 화려함에 돈 쓸 거냐 vs VFX/칼호/텔레그래프에 쓸 거냐"**로 재구성됨.

## 1. 코드 변경 (구현 완료 · 컴파일 검증)

이전 세션에 배선했던 카타나 공격 애니 트리거를 **유저 지시로 전부 제거**. 이유 = 임시로 물렸던 Mixamo 그레이트소드 클립이 ①뼈(스켈레톤) 불일치 리타겟 ②무기 종류 오류(그레이트소드≠카타나) ③루트모션 off 납작화로 **조잡**했고, 제대로 된 카타나 팩 확정 전까지 메커닉만 남기기로.

| 파일 | 변경 |
|---|---|
| `KatanaController.cs` | `FireAttackTrigger` 메서드·3트리거 호출(평타/돌진/참격파)·`_animator` 필드·트리거 해시 제거. **타격음 `MeleeSfx.PlayHit/PlayWhiff` 제거.** |
| `PlayerLocomotionAnimator.cs` | `katanaController` 필드 + 카타나 스탠스 스왑 분기 제거 → 총기 전용 원래 로직으로 환원 |

**남긴 것(애니/사운드 아님 — 게임플레이):** 급습 메커닉(`ZombieController.IsUnaware`·발도 돌진 보장즉살·`IaiKnobs.ambushXp`), `NoiseManager` 소음(좀비 청각=스텔스 게임플레이). VFX는 이미 빠진 상태 유지.

→ 카타나는 현재 **공격 비주얼·타격음 없이 메커닉만**. unity-mcp 리프레시 컴파일 성공·콘솔 에러 0 확인.

## 2. ★핵심 발견 — 탑다운 가독성 원칙 (이 세션의 진짜 산출물)

카타나 애니 팩 평가 중, 우리 카메라(**45° 3/4뷰, fov50, ~15m 부감**, Darkwood식)에서 애니가 어떻게 읽히는지 Frank 무료 체험 클립을 Synty Sidekick에 리타겟해 **유저가 직접 확인**. 유저 평: *"역동적이긴 한데 뭐하는 모션인지 모르겠네, 구르기인가?"*

**원칙: 부감 가독성은 "동작의 축"이 가른다.**

| 잘 읽힘 (구분됨) | 뭉개짐 (구분 안 됨) |
|---|---|
| 수평 동작(지면 가로지름) | **수직 동작 — 점프·구르기·웅크림** |
| **칼이 그리는 호**(지면 평면 스윕) | 높이 변화(위에서 0으로 압축) |
| 실루엣 벌어짐·이동·넓은 스탠스 | 미세 무게이동·손동작·깊이 찌르기 |

**파생 결론(유저가 스스로 도달):**
- 부감에선 **읽힘이 몸 애니가 아니라 *칼 실루엣(호) + VFX(슬래시 트레일·착탄·장판) + 명확한 수평 텔레그래프*에서 나온다.** (캡처에서 유일하게 안 뭉개진 게 큰 카타나였음 = 증거.)
- 따라서 **고급 화려한 애니 팩은 우리 카메라에서 값을 덜 한다** — 화려함의 상당수가 수직·미세 안무라 카메라가 깎음.
- 필요한 건 *화려한* 애니가 아니라 ***수평으로 또렷한*** 애니(읽히는 와인드업 + 넓은 칼 호) — 어느 괜찮은 팩이든 제공.
- **진짜 돈 레버 = 애니 플레이시가 아니라 VFX + 명확한 칼 호 + 케이던스.** (아까 VFX 빼니 공격이 "아무것도 아닌" 게 된 것도 같은 이유.)

→ 연동 메모리: [[topdown_readability_axis]] (신규), [[juice_textbook_lessons]], [[attention_channels_weapon_identity]].

- **무료 체험 검증**: `Frank_RPG_Katana_Tumbling_L.FBX` → Synty 리타겟 **구조 PASS**(사지 안 깨짐, Avatar.isValid/isHuman=True). 단 텀블=수직 동작이라 부감서 납작(최악 케이스). **정작 중요한 *공격* 클립은 미확인**(체험에 텀블뿐).

### 총기 (참고 — 결론: 새로 살 것 없음)
- 3인칭 총기 애니는 시장이 **권총 + 소총(+힙파이어)** 단위로만 출하. 샷건/저격/SMG 전용 풀세트 순수 애니 팩은 **존재하지 않음**(전부 Invector 같은 컨트롤러 템플릿 내장).
- **우리는 이미 전용 턴키 보유**(`Pro Rifle Pack` + `Pistol_Handgun Locomotion Pack`). → 총기 바디 애니는 추가 구매 불필요. 차별화는 무기 모델 + 장전 변형 + VFX.

### 도구
