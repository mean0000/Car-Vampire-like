### CarController.cs 구현
`Assets/Scripts/CarController.cs`

**최종 파라미터 (Inspector 조정 가능):**
| 파라미터 | 값 | 설명 |
|---|---|---|
| maxSpeed | 22f | 최고속도 (m/s) |
| engineForce | 30f | 가속력 (ForceMode.Acceleration) |
| deceleration | 12f | 입력 없을 때 제동력 |
| turnSpeed | 160f | 회전 속도 (deg/s) |
| lowSpeedGrip | 0.85f | 저속 측면 마찰 (안정) |
| highSpeedGrip | 0.40f | 고속 측면 마찰 (슬라이딩) |
| velocitySteerBlend | 0.08f | 선회 시 velocity 방향 전환 강도 |

**핵심 구조:**
- `AddForce + (1 - speedRatio²)` 커브: 저속 킥감 + 최고속 자연 수렴
- Lateral Friction: speedRatio 기반 동적 그립 (저속 0.85 → 고속 0.40)
- velocitySteerBlend: 선회 시 기존 관성 유지하며 서서히 새 방향으로 전환
- `ApplySpeedPenalty(float)`: 좀비 충돌 시 속도 감소용 (외부 호출)

**Stab/Codex 검수 후 수정된 버그:**
- [C-1] `ApplySpeedPenalty`에서 속도=0 시 `normalized` → NaN → `Vector3.zero` 분기로 처리
- [C-2] maxSpeed 클램프 타이밍 이슈 인지, 자연 수렴 커브가 1차 방어선
- [W-1] `Input.GetAxisRaw`를 `FixedUpdate` 내부로 이동
- [W-2] `MoveRotation` 전 `newForward` 미리 계산 후 블렌드
- [W-4] 저속 크리프 임계값 0.1f → 0.01f
- 선회 시 `forwardSpeed` 대신 `speed` 사용 → 회전 각도별 감속 버그 수정
