## 1. 씬 계층 구조

씬 이름: `Greybox_MVP`

```
Greybox_MVP
├── --- MANAGERS ---            (빈 GO, 시스템 스크립트 부착)
│   ├── GameManager             런 타이머(12분), 종료조건(HP0/감염MAX/시간초과)
│   ├── SyncRateManager         감염도 (기존 코드 재활용)
│   ├── NoiseManager            소음 (신규)
│   ├── ZombieSpawner           연속 스폰 (동시 15~25)
│   └── CraftingManager         레벨업·설계도·제작 (후순위)
├── --- ENVIRONMENT ---
│   ├── Ground                  100×100 평면/얇은 큐브 (Ground 레이어)
│   ├── Buildings               큐브 블록들 (Obstacle 레이어) — 거리/엄폐 생성
│   ├── Home                    구석 안전구역 (트리거 + 바닥 큐브)
│   └── LootPoints              재료 큐브 (먼 구역에 배치)
├── --- ACTORS ---
│   └── Player                  캡슐 + PlayerController + (카메라 타겟)
├── Main Camera                 FollowCamera (3/4 리그)
├── --- LIGHTING ---
│   └── Directional Light       중립 평면광 (그레이박스용)
└── --- UI ---
    └── HUD Canvas              감염도 숫자 / HP / 타이머
```

## 2. 맵 레이아웃 & 치수

### 이동시간 → 거리 산출

- 플레이어 속도 **5 units/초** (GDD), 1 unit ≈ 1m.
- 목표 귀환 시간 **30~40초** → 경로 거리 = `5 × 35 ≈ 175 units` (엄폐물 우회 포함).
- **시작 맵: 100×100 units**, 집을 한쪽 구석에. 반대편 구석까지 직선 ≈ 141 units, 건물 우회 시 실제 경로 ≈ 35초.

```
   ┌─────────────────────────┐ 100u
   │ LootPoints (먼 구역)      │   ← 거리-보상 곡선상 보상 높음 (GDD v2.5)
   │   ▢   ▢      ▢          │
   │      ▢   ▢      ▢       │   ▢ = Building 큐브 (Obstacle)
   │   ▢      ▢   ▢          │       거리·엄폐·스텔스 경로 생성
   │      ▢      ▢           │
   │   ▢   ▢      ▢          │
   │ [HOME]                  │   ← 집: 구석, 감염 리셋 트리거
   └─────────────────────────┘
   0u                      100u
```

- **집**: 약 10×10 안전구역. 진입 트리거(Home 레이어) → `SyncRateManager.ReduceSync(전량)`. 입장 시 나노봇 교란 펄스(주변 좀비 흩어짐).
- **건물**: 다양한 크기 큐브, 직선 시야를 끊어 스텔스 경로/엄폐를 만든다 (좀비 시야·소음 차단 테스트용).
- **튜닝**: 귀환이 너무 짧/길면 맵 크기 조정. `목표거리 = 5 × 원하는초`.

## 3. 카메라 리그 (3/4 비스듬한 탑다운)

| 항목 | 시작값 | 비고 |
|---|---|---|
| 투영 | **Perspective** | 분위기·각도감, COZY 안개 호환. (ortho는 대안) |
| FOV | 50 | |
| X 회전(피치) | **65°** | Darkwood식 3/4 (90°=순수탑다운). 60~70 범위 튜닝 |
| 위치 오프셋 | 타겟 기준 `(0, +20, -9)` | 피치 65°에 맞춘 높이/후방. height=20, back=9.3 |
| 추적 방식 | 지수 감쇠 `Lerp(.., 1-Exp(-k·dt))` | 기존 `CameraController` 기법 차용 |
| followSpeed(k) | 6 | 클수록 빨리 따라붙음 |
| Lookahead | 이동방향 최대 3 units | 약하게 (차량처럼 과하지 않게) |
| 실행순서 | `[DefaultExecutionOrder(-50)]` | Feel 카메라 쉐이크 호환 |

> 기존 `CameraController.cs`는 차량 결합이라 **신규 작성**. 살릴 것: 지수감쇠 추적, `_logicalPosition`/`_shakeOffset` 분리(Feel 호환). 타겟은 Player.

## 4. 레이어 & 태그 규약 (★ 시스템 의존)

기존 `ZombieController`가 `groundLayer`/`zombieLayer` 마스크로 지면 레이캐스트·무리 분리를 하므로 **레이어 분리는 필수**.

### 레이어

| 레이어 | 대상 | 쓰임 |
|---|---|---|
| `Ground` | 바닥 | 좀비/플레이어 지면 스냅 레이캐스트 |
| `Player` | 플레이어 캡슐 | 좀비 타겟팅·공격 판정 |
| `Zombie` | 좀비 캡슐 | 무리 분리 OverlapSphere, 공격 대상 |
| `Obstacle` | 건물 큐브 | 이동 차단, 시야/소음 차단 |
| `Home` | 집 트리거 | 진입 감지 |
| `Loot` | 재료 큐브 | 픽업 트리거 |

### 태그

`Player` / `Zombie` / `SignalZombie` / `Home` / `Loot`

### 충돌 매트릭스 (Project Settings → Physics)

| | Ground | Player | Zombie | Obstacle | Home | Loot |
|---|---|---|---|---|---|---|
| **Player** | ✓ | — | △트리거 | ✓ | △트리거 | △트리거 |
| **Zombie** | ✓(레이캐스트) | △트리거 | △분리스티어링 | ✓ | ✕ | ✕ |
| **Obstacle** | ✓ | ✓ | ✓ | — | ✕ | ✕ |

- 좀비-좀비: 물리 충돌 대신 **분리 스티어링**(`CalcSeparation` OverlapSphere)으로 겹침 방지 → 물리 충돌은 꺼서 떨림 방지 권장.
- 플레이어-좀비: 트리거로 공격/피격 판정.

## 5. 그레이박스 프리미티브 규약 (가독성 테스트용)

색 구분은 **"신호 좀비가 무리 속에서 즉시 구분되는가"**(핵심 루프 판단 트리거)를 그레이박스 단계에서 검증하기 위함.

| 오브젝트 | 형태 | 색 | 비고 |
|---|---|---|---|
| 플레이어 | 캡슐 | 시안/파랑 | 정면 표식(작은 큐브)으로 바라보는 방향 표시 |
| 일반 좀비 | 캡슐 | 회색/탁한 녹색 | |
| **신호 좀비** | 캡슐 + 상단 기둥/마커 | **마젠타/노랑** | 실루엣+색 둘 다 차별화 → 즉시 식별 검증 |
| 집 | 큐브/바닥 | 밝은 녹색 | 안전 신호 |
| 건물 | 큐브 | 회색 | |
| 재료/루트 | 작은 큐브 | 금색 | |
| 소음 펄스 | 확산 링(파티클/셰이더) | 흰색/빨강 | §infection-noise §1.4, 행동 시 순간 표시 |

> 게임플레이 카메라 거리(65°, height 20)에서 신호 좀비가 1~3마리 무리 속에서도 튀는지 확인. 안 튀면 마커 강화.

## 6. 조명 (최소)

- **Directional Light 1개**, 중립 백색, 적당한 각도. 그레이박스는 레이아웃·루프 검증이 목적이라 평면광이면 충분.
- COZY/HTrace/안개는 분위기 단계에서. (단, "어둠은 대비로" 가독성 원칙 테스트는 나중에 어두운 앰비언트 + 중요 액터 림라이트로 별도 검증)

## 7. 입력 셋업

| 행동 | 입력(제안) | 비고 |
|---|---|---|
| 이동 | WASD → **월드 XZ** | 카메라 고정 각도라 월드 기준이 직관적. 속도 5 |
| 근접 공격 | 좌클릭 | 바라보는/마우스 방향, 쿨 0.4초 |
| 스텔스 | 우클릭 또는 Space | 3초 지속/8초 쿨, 감염+1 |

> **확인 필요**: 기존 프로젝트가 legacy Input Manager vs Input System 중 무엇을 쓰는지 → 통일. 신규 셋업이면 Input System 권장.

## 9. 검증 체크리스트 (그레이박스 "준비됨" 기준)

- [ ] 플레이어 캡슐이 속도 5로 이동, 카메라가 65°에서 부드럽게 추적
- [ ] 집 구석 → 먼 구역 왕복이 30~40초
- [ ] 신호 좀비가 게임플레이 거리에서 무리 속 즉시 식별됨
- [ ] 레이어 6종·태그·충돌 매트릭스 설정 완료
- [ ] 좀비가 Ground 레이캐스트로 지면에 붙고, 서로 안 겹침(분리)
- [ ] 집 트리거가 플레이어 진입 감지 → 감염 리셋 호출
- [ ] 매니저 GO 5종 배치(스텁이라도)
- [ ] 좌클릭/스텔스/이동 입력 동작
- [ ] HUD에 감염도·HP·타이머 표시

→ 통과 후 `asset-system-mapping.md §6` 구현 순서대로 시스템 살 붙이기.
