## 1. 한 줄 현황

이번 세션 = **순수 설계 대전환.** 코드/빌드는 **미착수.** 옛 방향(익스트랙션·좀비·저격)을 카빙하고 **조준형 로그라이트 뱀서 + 사후처리부 2페이즈**로 척추를 새로 박았다. 다음 = *코어 루프가 재밌나*를 첫 볼트로 검증.

## 2. 동결된 방향 (요약 — 상세는 피벗 스펙)

- **본체:** 조준형 로그라이트 뱀서(20MTD형). 방향 조준+총기, 인런 무기 드래프트.
- **적:** 이상개체(그로테스크 변종, 레퍼 Protofactor). 스탯 티어+소수 특수행동(rigid 분류 ❌).
- **런:** 고정 보스+보스별 파벌. 보스 게이지=시간+처치 → Peak 보스 → 클리어. 영구 메타=총기 업글+캐릭터 성장(보스 티어 게이트).
- **개성:** 사후처리부 2페이즈 — P1 시민 탈출 지원(고정 타이머) → 봉쇄 전환 → P2 순수 뱀서. **시민=순수 양수자원·처벌0.**
- **VS 관습:** 디테일 저작 맵 ❌, 열린 평원·플레이어 상대 좌표계, 카이팅이 유일 방어.

## 4. 열린 결정 (착공 전 유저 판정 필요)

1. **구조 패링 대시 = Phase1 시그니처로 확정?** (권고: 쿨타임 게이트·Phase1 한정. pm은 컷, gd는 Death Must Die식 상시 회피로 일반화 주장 — 스코프를 P1에 가두는 게 제3의 답)
2. **월드 아트 = 실사 통일?** (Protofactor 반실사 ↔ 기존 로우폴리 충돌. 메커닉 먼저, 추후)
3. **Protofactor Monster 팩 구매** (보유목록에 없음)

## 5. 제안하는 첫 볼트 (★유저 확정 대기 — 동결 아님)

**가설:** *"이동·조준·총기로 이상개체 호드를 갈고 즉발 레벨업으로 무기 드래프트를 쌓는 코어 루프 30초가, 그 자체로 손맛이 있나?"*

근거: 나침반 §2(킬 도파민이 모든 것의 기초) + §5(코어가 서기 전엔 P1 개성도 헛것). 검증된 VS 템플릿이라 위험이 낮고, **P1 시민 시스템은 이 코어가 재밌다고 판정난 뒤** 얹는다(2번 볼트).

**최소 슬라이스:**
- 열린 평면 그레이박스 1장(디테일 맵 ❌).
- 플레이어 = 이동 + 방향 조준 + 총기 1종.
- 이상개체 스워머 1종(플레이스홀더 메시) + 스폰 디렉터(기존 자산) Build 곡선.
- 즉발 레벨업 → 무기 드래프트 픽 2~3종.
- **플레이게이트:** "30초 갈기 + 레벨업 픽"이 손맛 있나 — 유저 플레이 판정.

→ 이게 서면 **2번 볼트 = Phase1 시민 탈출 지원**(피벗 스펙 §5 연출 규칙대로), lv 그레이박스 인카운터 스펙 핸드오프.
