2. 기존 씨앗(커밋-크리티컬·방향성 붕괴·살아서 퇴근)도 "부사일 뿐 — 명사·동사가 없다."

## 4. 현재 테이블 위 — 3안 (오케 단독안, 유저 판정 대기)
> **"뭉치면 동기화된다. 동기화를 끊는 한 방이 월급이다 — 단, 너무 늦으면 놈들이 하나가 된다."**

- 나노봇 개체는 근접 시 **동기화**(강해짐). 동기화 군집의 노드 하나를 끊으면 **죽음이 신호를 타고 군집 전체로 전파**(연쇄 붕괴). 회사는 개별 킬이 아니라 **연쇄 붕괴 질량**으로 정산(=급여). 군집을 키울수록 배율↑, 임계 초과 시 **융합 → 특이사항(변이 개체) 탄생** — 욕심이 보스를 만든다.
- 3초 질문: "더 모을까, 지금 끊을까?" — 도박 맥박이 몸이 아니라 **바깥 세계(군집)**에 있음(기준 9 통과). 동작 수는 오히려 감소(한 방=서른 처리, 기준 7 역방향 통과). 한국 유저 독해 = **몰이사냥**(고수 트로프, 기준 8 통과). 카이팅=푼돈 구조(캐넌 미해결 문제 해소). 쿼터뷰=동기화 링크가 위에서 읽힘(시점의 기계적 정당성). 절제(아직 안 죽이기)가 스킬 — 호드 밀도가 곧 경제(조준형 뱀서 피벗 정합).
- 스토리 근거: 이미 캐넌인 단어들로만 지음 — 마젠타=신호붕괴, 싱크 글리치, 압박엔진 싱크가속, 특이사항 없음(타이틀). 방향성 붕괴(거합 문법)=전파 붕괴의 연출 언어로 재사용.
- **리스크 3 (오케 자진 신고):** ①호드 밀도에서 동기화 상태 시각화 = TA 난제(화면 죽 위험 — 단 유저 TA 트랙 정중앙) ②절제 구간이 분 단위면 러시 사망(초 단위 튜닝 필수) ③경제 전체가 아니라 점수판이 되는 순간 부사로 강등.

## 5. RESUME (내일 여기부터)
1. **유저의 3안 판정.** 기각이면 → 기준 스택 9종으로 다음 후보 고민(오케 직접, xhigh). 감이 오면 →
2. **Codex 독립안 교차 (경쟁 규율 — 동결 전 필수).** 같은 브리프(스토리 캐넌 + 기준 스택 9종)를 Codex에 독립 투입 → 오케 3안과 발산 지점 표로 유저 판정. 동일계열 자기검증 금지.
3. **백지화 공식 범위 확정 (미결 — 유저와 확인 필요).** "배경 스토리만 빼고 백지"가 ①코어 루프 논의용 임시 백지인지 ②기존 동결 문서 전체 해동인지 미확정. 특히: 무기 6종 로스터·시야 콘(유저 동결)·간지=최상위 法·카드 시스템·아트 방향(실사A)·조준형 뱀서 피벗 스펙 — 어느 것이 생존하는지 목록으로 확정할 것. **확정 전까지 캐넌 문서 수정/폐기 금지.**
4. 코어 문장 동결 후 → 노브 지도 합의 → 최소 검증 슬라이스 설계(기존 랩 씬 재활용 검토). 착공은 노브 지도 합의 후([[feedback_scope_reply_not_greenlight]]).
