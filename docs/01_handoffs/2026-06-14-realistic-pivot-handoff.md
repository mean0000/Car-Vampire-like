# 2026-06-14 핸드오프 — 맵/아트 방향 대전환 (절차생성·POLYGON 포기 → 실사 Hell Express)

> 작성: 2026-06-14. 이 세션은 "맵을 어떻게 만들까"로 시작해 **아트 방향 자체의 피벗**으로 끝났다. 다음 세션은 *이 피벗을 전제로* 시작할 것. 이전 맵 관련 권위문서·메모리(POLYGON 골격 전제)는 아래 §6에 따라 구식화됨.

## 0. 한 줄
**월드 아트를 실사(Hell Express 풍 스타일라이즈드-리얼)로 전환한다. POLYGON 로우폴리 월드·절차적 맵 생성은 폐기.** 괴수(Protofactor PBR)가 이미 실사 계열이라 오히려 더 정합. 단 ★**"실사 룩 = 색보정"이 아니다** — 색감은 마지막 10%, 본체는 에셋/머티리얼/디테일/라이팅/데칼/볼류메트릭 (§3).

## 1. 오늘의 궤적 (왜 여기까지 왔나)
1. MapGen 엔진 업그레이드 시공(E-1 복합지면·E-3 회랑·E-4 식생·E-2 RoadGraph) → Stab+Codex 리뷰 → 수정 6건 반영(식생 결정론 FNV해시·overlap 가드 등). 컴파일 클린.
2. 생성 맵이 "배치가 개판" → 도로 폴리라인 전환·밀도 폭증·바닥 타일링 시도 반복.
3. ★**완전 바닥 타일링 해결**: 모든 gappy 바닥의 원인 = *피벗이 모서리인 타일을 회전시키면 제각각 밀림.* 수정 = **회전 0 + bounds.center를 그리드 정렬 + overlap** (`MapGenKit.TiledFloor`/`TilePatch`).
4. 유저 교정 연쇄: "배치 안 변했다" → "같은 맵 타일=의미없다" → "보통 어떻게 하나?"
5. **하이브리드 합의**(코드=캔버스/벌크, 손=히어로 배치) → 캔버스 생성 + 손배치 청사진 HTML.
6. 유저: "결국 같은 거 반복 = 의미 없다" → 내가 **과약속·잘못된 방법 고수**를 인정.
7. 맵 에셋 구매 검토 → Synty Apocalypse/City/Woodland. **SyntyPass = 해지 후 보유 불가**(약관 6.2/12.2 확인) → 소유하려면 일회성 구매.
8. 유저가 제약 해제: "로우폴리 아니어도·도심 아니어도 OK."
9. ★**유저 결정: 실사(Hell Express)로 간다. POLYGON 아니다.** 내가 POLYGON 매몰비용·성능 걱정으로 자꾸 POLYGON으로 끈 것을 인정하고 내려놓음.
10. Hell Express(=Full Metal Bagel, 아이소 익스트랙션 슈터) 분석 → 실사 환경은 *손모델링 아님*: 스캐터·스플라인·터레인·라이브러리·**라이팅/분위기**.
11. 무드 룩데브: Protofactor 괴수 + Top-Down Post-Apoc PBR 건물 + 안개/조명/색보정. 1패스 너무 어둠 → 2패스 톤 나옴 → 4변형 비교시트(`mood_compare.png`).
12. ★**유저 최종 교정: "색감만 따라하면 끝이 아니다" — 내가 실사 룩을 과단순화함.** (이 문서 §3가 그 답)

## 2. ★확정된 방향 전환 (다음 세션 전제)
- **월드 아트 = 실사(스타일라이즈드-리얼, Hell Express 톤). POLYGON 로우폴리 = 월드 베이스에서 폐기.**
- **절차적 맵 생성(MapGen 엔진) = 폐기/보류.** 장님 절차배치는 미적 맵에 부적합(이번 세션이 증명). 엔진 코드는 남겨두되 실사 방향엔 미사용.
- **괴수 = Protofactor PBR 유지** — 실사 월드와 정합(POLYGON 시절보다 나음).
- **렌더 파이프 = URP_HighFidelity**(현재). 포토리얼/HDRP까지는 솔로+떼엔 과함 → 스타일라이즈드-리얼에서 멈춘다.

## 3. ★★유저 핵심 교정 — "실사 룩 ≠ 색보정" (오늘의 가장 중요한 교훈)
색보정/안개는 *무드 도달 가능성 증명*용 최저비용 레버였을 뿐, **실사 룩의 본체가 아니다.** 실사 Hell Express 룩이 진짜 필요로 하는 것:
1. **에셋·머티리얼 품질** — PBR 텍스처(알베도/노멀/러프니스/AO/메탈릭), 마모·그런지·젖음·이끼·녹. (날것 에셋은 밋밋 — 텍스처 디테일이 사실감의 본체)
2. **메시/스컬프트 디테일 + 실루엣** — 면 밀도, 부서진 형태, 비대칭.
3. **데칼** — 균열·얼룩·핏자국·기름·포스터를 표면에 투영(지오메트리 아님).
4. **라이팅을 *배치*** — 단일 디렉셔널+그레이드가 아니라, 광원을 *놓고*(가로등·화재·창문 이미시브) + 라이트프로브/베이크 GI + 그림자.
5. **볼류메트릭 안개·라이트샤프트** — 평면 fog가 아닌 부피 안개(빛이 안개를 가르는). Hell Express "림보"의 핵심.
6. **파티클** — 먼지·불씨·물방울·미스트(공기에 생명).
7. **세트드레싱 밀도(스캐터)** — 잔해·소품이 공간을 채움.
8. **색보정 = 마지막 통합 10%** (위 7개가 있어야 그 위에서 작동).
→ 다음 세션은 §3을 *실사 룩데브 체크리스트*로 삼아 색감 말고 1~7부터 잡는다.

## 4. 자산 전략 (실사)
- **보유·즉시 사용**: `Top_Down_Post-Apocalyptic_Pack`(PBR, 임포트됨) — POLYGON 시절엔 "톤충돌"로 반려됐으나 **실사로 트니 정합.** 건물 다수(`Assets/Top_Down_Post-Apocalyptic_Pack/Prefabs/Buildings/`). + Protofactor 괴수 다수.
- **무료 보강**: **Quixel Megascans**(스캔 실사 표면·바위·잔해·식생) — 실사 환경의 표준 백본. Fab/Unity 무료분.
- **스플라인 도로**: `EasyRoads3D Free`(보유) — 타일 도로 지옥 대체.
- **분위기**: `COZY`(날씨/안개/하늘) + URP 포스트. (단 볼류메트릭은 별도 검토)
- **구매 라이선스 주의**: SyntyPass(구독)는 **해지 후 사용 금지**(약관). 소유하려면 일회성 구매. 단 우리는 실사로 가므로 Synty(로우폴리) 환경팩 구매는 **불요** — Megascans + Post-Apoc PBR로 충분 여부 먼저 검증.
