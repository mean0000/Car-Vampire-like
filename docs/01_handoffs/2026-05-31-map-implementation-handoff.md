# 맵 구현 핸드오프 — 모듈형 절차 도심

> **작성일**: 2026-05-31
> **대상**: 이 문서만 받은 다른 세션이 바로 착수 가능하도록 작성. 구현은 주로 Unity 에디터(블록 프리팹) + `ChunkManager` 1개 편집.
> **권위**: `2026-05-31-level-design-authority.md` (런 구조·시계·게이트 전체). **이 핸드오프는 그중 §6 맵 생성만** 떼어낸 실행 지시.
> **모든 수치 = 시작값**. 플레이테스트로 튜닝.

---

## 0. 이 핸드오프의 스코프

| 포함 (이번에 만들 것) | 제외 (다른 핸드오프) |
|---|---|
| 오써드 도심 블록 프리팹 팔레트 (80×80 그레이박스) | 감염 시계 / DoT (SyncRateManager 개조) |
| `ChunkManager`를 단일 프리팹 → **팔레트 결정론적 선택**으로 개조 | 게이트 돌파 로직 (엘리트/호드/보스) |
| 원점 집 블록 + 게이트 광장 슬롯 (결정론적 고정) | 거리 가중 스폰 (ZombieSpawner 개조) |
| 기존 레이어/스폰/좀비 AI와 호환 검증 | 보스 디자인, 평원 전환 |

→ **통과 기준**: 플레이어가 걸어다니면 80×80 도심 블록이 매번 다른 배열로 끝없이 펼쳐지고, 되돌아가도 같은 블록이 그대로 있으며(결정론), 좀비가 건물에 안 끼고 정상 스폰된다.

---

## 1. 현재 상태 (착수 전 반드시 이해)

- **현재 `Greybox_MVP` 씬 = 손배치 100×100 큐브 도시.** 절차 생성 아님. 이건 **건드리지 말고 그대로 둔다** (플레이테스트 베이스라인).
- **`TerrainChunk.cs` = 노이즈 높이맵 지형 생성기** (드라이브/바이옴용). **도심 블록과 무관 — 절대 여기에 건물 얹지 말 것.** 도심은 평지.
- **`ChunkManager.cs` = 재활용 대상.** 플레이어 중심 7×7(viewRadius=3) 그리드로 `chunkPrefab`을 스트리밍 생성/파괴. chunkSize=80. **이 그리드 골격만 살리고, `chunkPrefab` 단일 → 블록 팔레트로 바꾼다.**
- **권장 작업 방식**: 기존 씬 보존을 위해 **새 스크래치 씬**(예: `Greybox_ProcCity`)에서 블록 팔레트 + ChunkManager를 프로토타이핑 → 검증 후 본 씬에 통합.

## 2. 블록 프리팹 팔레트 (그레이박스)

각 블록 = **80×80 units 평지 타일** (chunkSize=80과 일치). 블록 로컬 원점은 **타일 중심** (ChunkManager가 `coord × 80`에 배치 — 기존 TerrainChunk가 이미 중심 기준).

### 2.1 구성 규약

- **바닥**: 80×80 평면/얇은 큐브, **Ground 레이어(6)**.
- **건물**: 큐브들, **Obstacle 레이어(8)**. 직선 시야를 끊어 스텔스 시야선·엄폐를 만든다.
- **블록 경계 정합**: 타일 가장자리 도로가 이웃 타일과 이어지도록 **가장자리에 건물 두지 말 것**(가장자리 = 도로/통로). 어떤 두 블록이 인접해도 길이 막히지 않게.
- 블록 안에 **반드시 통과 경로 1개 이상** (막힌 타일 금지 — 좀비 길막 + 플레이어 갇힘 방지).

### 2.2 블록 종류 (MVP 최소 4종)

| 블록 | 레이아웃 의도 | 스텔스 기능 |
|---|---|---|
| **교차로** | 중앙 열린 공간 + 모서리 건물 4개 | 넓은 시야, 노출 위험. 빠른 통과 |
| **직선 골목** | 양옆 건물 벽, 가운데 길 | 긴 시야선 — 멀리 좀비 보임, 엄폐 적음 |
| **밀집** | 건물 다수 + 좁은 틈새 길 | 엄폐 풍부, 짧은 시야 — 암살 접근 좋음 |
| **광장** | 대부분 열린 공터 (게이트 아레나용) | 게이트 전투 공간. §4에서 고정 배치 |

> **★ 회전 변형은 MVP 필수 (폴리시 아님).** 80m 모듈은 의도된 값(도시 블록 1칸 크기, 스텔스 시야선에 적정)이지만 4종만으로는 80m 격자가 규칙적으로 반복돼 "타일 깔았네"가 티난다. **각 블록에 회전 0/90/180/270° 변형을 적용**(시드로 회전각도 함께 결정)해 체감 다양성 4배 → 격자감 제거. 이게 "월드가 작아 보이는" 문제의 실제 해결책이다(블록을 키우는 게 아님).

## 3. ChunkManager 개조 — 팔레트 결정론적 선택

### 3.1 핵심 요구사항 (★ 버그 트랩)

`ChunkManager`는 플레이어가 멀어지면 청크를 **파괴**하고, 되돌아오면 **재생성**한다. 따라서 블록 선택이 `Random`이면 **되돌아갈 때마다 도시가 바뀐다.** 반드시 **coord로 시드된 결정론적 선택**이어야 한다.

```
블록 인덱스 = Seed(coord) 기반 결정론적 추출
  // TerrainChunk.DetermineZone이 쓰는 시드 패턴 재활용:
  int seed = coord.x * 1000003 + coord.y * 999983;
  var rng = new System.Random(seed);
  int blockIdx = rng.Next(palette.Length);
```

→ 같은 coord는 항상 같은 블록 → 되돌아가도 도시가 그대로.

### 3.2 변경 범위

- `[SerializeField] GameObject chunkPrefab;` → `[SerializeField] GameObject[] blockPalette;`
- `UpdateChunks`의 `Instantiate(chunkPrefab, …)` → **시드로 고른 `blockPalette[blockIdx]`**.
- **TerrainChunk 의존 제거**: 현재 `go.GetComponent<TerrainChunk>().Init(...)` 호출은 도심 블록엔 불필요. 블록은 위치만 잡으면 됨(`coord × chunkSize`). TerrainChunk 호출부를 블록용 배치 로직으로 교체(블록 프리팹엔 TerrainChunk 미부착).
- 나머지 그리드 스트리밍(생성/파괴/needed set) 로직은 **그대로 유지**.

### 3.3 결정론적 오버라이드 (집/게이트)

특정 coord는 팔레트 랜덤 대신 **고정 블록**을 강제한다 (§4 참조). 선택 로직 앞에 오버라이드 체크:

```
if (coord == HomeCoord)        → HomeBlock 강제
else if (게이트 광장 coord)     → 광장 블록 강제
else                           → 시드 기반 팔레트 추출
```

## 4. 집 & 게이트 슬롯 (결정론적 고정)

거리 기준 = 원점에서의 반경 (`BiomeResolver`와 동일 좌표계).

| 슬롯 | coord/거리 | 블록 | 비고 |
|---|---|---|---|
| **집** | coord (0,0) | HomeBlock | 주변 30m 안전지대(스폰 없음). 진입 트리거 = 귀환 |
| **게이트 ①** | 반경 ~200m 방향 고정 | 광장 | 엘리트 아레나 |
| **게이트 ②** | 반경 ~450m | 광장 | 호드 아레나 |
| **게이트 ③** | 반경 ~700m | 광장 | 보스 아레나 |

- 게이트는 **AI 센터 신호 방향**(한 방향)으로 일렬 배치 권장 → 자연 유도. 방향 벡터 1개 정해 그 선상의 coord에 광장 강제.
- **이번 핸드오프 범위**: 집 블록 + 광장 블록을 해당 coord에 **고정 배치**까지. 게이트의 *돌파 로직*(엘리트/호드/보스 스폰·클리어 판정)은 범위 밖 — 광장에 빈 트리거 GO만 플레이스홀더로 둔다.

---

## 5. 기존 시스템 호환 (깨지면 안 됨)

- **`ZombieSpawner.OverlapsObstacle`**: 건물이 Obstacle 레이어(8)면 자동 호환 — 좀비가 건물 안에 안 스폰됨. 블록 건물 콜라이더 레이어만 맞추면 됨.
- **`ZombieSpawner` 스폰 링 20~35m / despawn 60m**: 블록이 끊김 없이 깔리면 문제없음. 단 viewRadius=3 → 7×80=560m 시야이므로 스폰 반경 충분히 커버.
- **좀비 지면 스냅**: 좀비/플레이어가 Ground 레이어(6) 레이캐스트로 바닥에 붙음 → 블록 바닥 레이어 필수.
- **평지 유지**: 도심 블록은 y=0 평지. 높이 변화 주지 말 것(좀비 AI·이동이 평지 가정).

## 6. 검증 체크리스트 (맵 "준비됨" 기준)

- [ ] 플레이어가 걸으면 80×80 블록이 끊김 없이 스트리밍 (구멍/겹침 없음)
- [ ] **되돌아가도 같은 블록** (결정론 — 시드 선택 검증)
- [ ] 블록 4종이 인접해도 길이 막히지 않음 (가장자리 도로 정합)
- [ ] coord (0,0) = 집 블록, 안전지대에 좀비 안 옴
- [ ] 게이트 방향 선상 ~200/450/700m에 광장 블록 고정 등장
- [ ] 좀비가 건물에 안 끼고 정상 스폰/이동
- [ ] 좀비·플레이어가 바닥에 붙음 (Ground 레이캐스트)
- [ ] 막힌 타일에 플레이어가 갇히지 않음

## 7. 이번 범위 밖 (후속 핸드오프)

1. **감염 시계** — SyncRateManager 시간 충전 + DoT 전환 + 게이트 둔화 배수 (authority §2)
2. **거점/귀환** — PitStopZone을 PlayerController 트리거로 개조 (authority §4)
3. **게이트 돌파 로직** — 엘리트/호드/보스 스폰·클리어 판정 (authority §5)
4. **거리 가중 스폰** — ZombieSpawner 거리 스케일 (authority §3)
5. **블록 회전 변형 / 폴리시 / 실제 아트 에셋**

> 이 5개는 게임감·다중 시스템이 걸려 메인(Opus) 세션에서 잡는다. **맵(이 핸드오프)이 먼저 서야** 나머지가 얹힌다.

## 8. 시작 수치 요약

```
블록 크기        80 × 80 units (chunkSize=80 일치)
팔레트           4종 (교차로 / 골목 / 밀집 / 광장) × 회전 4변형 (시드로 함께 결정)
스트리밍         viewRadius=3 (7×7), ChunkManager 기존값
블록 선택        Seed(coord) = coord.x*1000003 + coord.y*999983 → System.Random
집               coord (0,0), 안전지대 ~30m
게이트 광장       반경 ~200 / ~450 / ~700m, 한 방향 일렬
레이어           Ground=6 (바닥), Obstacle=8 (건물)
높이             y=0 평지 고정
```
