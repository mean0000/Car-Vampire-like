### 2.2 재미 장치 브레인스토밍 — 결정 대기 (gd + Codex + 웹, 강한 3자 수렴)
반복 평타를 재미있게 하는 장치. **비어 있던 축 = 에스컬레이션·맥락 변주·프레이즈 릴리스.** 3개 기둥으로 수렴:

- **기둥 A — 킬스트릭 에스컬레이션 + 군중 위축** ★가장 강한 수렴. 킬 쌓을수록 주스 비가시 상승 + **킬하면 근처 잡몹 새 공격 0.15~0.35s 지연**(= "평타=압박완화" 기계적 실현). 화려함=실적=생존·뽕 정합. **오케 추천 1순위(지금 구현 가능)**.
- **기둥 B — 회전형 마그네티즘 + 리타겟 + 히트 소급** ★강한 수렴. 조준 보정 **회전만(전진 병진 0)**·콤보 중 대상 죽으면 자동 리타겟(시체 스킵)·히트 소급 60~80ms. "맞은 것 같은데 안 맞음"·헛스윙 제거.
- **기둥 C — 맥락 감응 결과** ★수렴. 히트스탑 계단(논킬3f/킬6f/처형8f)=엔진 + 시체·환경 잔존 + 킬 티어 + 처형 피니셔+막타정리.

**유저 판정 대기 = 발산 지점:**
1. 에스컬레이션 가시성: 비가시(felt) vs PerformanceGauge(가시 디제틱) — 권고=분리
2. 첫 레버: 히트스탑 계단(지금 가능) vs 사운드 레이어(sd+유저 귀)
3. **킬 → 체력 회복 주나?** Codex 관대(Doom식) vs gd 처형+정리만(체력無) — 원칙③ 경계(저점안전망 vs 생존권). ★유저 판정
4. over-systematization: 메터/스코어 UI 금지, 장치=골라켜는 메뉴(스택 아님)
