# 자투리 메모 (2026-06-10 세션 종료 시점)

> 권위 문서·메모리에 안 실린 소소한 잔여 이슈만. 방향·결정·다음 행동은 전부 권위 문서 3개(헌장 v1.3 / 코어 디자인 v1.3 / 전투질감 파운데이션 v1.1)와 메모리 참조.

1. **좀비 공격/사망 클립 미와이어링** — ithappy `Zombie_Attack`/`Death_*` 클립 존재, `PerformAttack()`에 TODO. 게이트 0 최소셋 ③(런지 윈드업)에서 자연 해소 예정.
2. **스폰 크기 불일치 (기존)** — `ZombieController` 스폰 코드가 `localScale=one` 리셋 → 클론 1.8m vs 수동 배치 3.6m(스케일 2). 어느 쪽이 의도인지 미결정. 캡슐 시절부터의 동작.
3. **보이드 스폰 (기존)** — 구식 스포너가 아레나 밖 바닥 없는 곳에도 스폰. 디렉터(헌장 1번)에서 청산 예정이라 방치 중.
4. **세이브 키 = 에셋 이름** — StrainDef/UpgradeDef 리네임 시 잔액 조용히 소실. Phase 2에서 명시 ID 필드로 교체.
5. **런 내 카드 보너스 × 메타 배율 스태킹** — `(baseDmg + DamageBonus) × metaMult`로 카드도 메타 배율 증폭을 받음. 버그 아님, 밸런스 의도 미문서화 — 플레이테스트 데이터로 판단.

기타: 좀비 캐스팅(밀짚모자→도시 시민)·회백 피부·나노봇 시그니처는 헌장 Phase 2 8번 품목으로 정식 등재돼 있음. 오늘 작업 전체가 미커밋 상태 — 커밋 권장.
