## ★ 디렉팅 동결 사항 (전 세션 구속)

1. **나침반 §4.2 한 문장 (유저 동결)**: *"매우 위협적인 이상개체를, 빠르고 화려하게 처리하고, 살아서 퇴근하는 익스트랙션."*
   - 템포: "시작=슬로울리/화려함=도착지" 폐기 → **빠르고 화려한 처리가 본체**. 레인보우식스급 택티컬 기각(배경과 안 맞고 너무 무거움). 탑뷰 장점 = 넓은 시야 + 빠른 스피드.
   - 적 명사: 좀비(임시 어휘) → **이상개체**(나노봇 변이 몬스터). Protofactor Monster Full Pack Vol 2($35/90%) 구매 — 권장 구조 = **2계층 로스터**(잡몹=기존 ithappy 인간형 변이 초기 / 위협 개체=Protofactor 크리처 "변이가 깊을수록 인간형을 잃는다"). 병렬 세션이 30종 분류·URP 변환 완료 → [[2026-06-12-monster-roster-classification]].
2. **카메라**: F1(45°/15m) 유지 확정, F2~F4 기각 → [[2026-06-10-camera-system]] v1.1. 커서 리드 총량 캡 `maxCursorLead=3m`(비례+캡 = 장르 표준, 순수 고정 기각). 조준 FOV 줌 제거(`aimFovDrop` 0 — 줌인은 조준 방향 정보를 오히려 줄임, 정보는 커서 리드가 담당).
3. **수렴샷 발동 = 같은 좀비 끊김 없는 지속 조준** (구: 홀드 0.82s면 허공도 충전). 3상태 게이트(Charge/Hold/Reset, grace 0.12s=Hold) + 탄 타깃 스냅샷(오발=2배 대미지만, 즉사·연출 불발). ⚠️단, "제자리 0.85s 수렴" 자체가 §4.2 빠른 템포와 충돌 가능 — 재검 후보.
4. **플레이어 = SM_Casual_Male 유지.** Ch44_nonPBR 기준 캐릭터 판정은 당일 기각(다크 디퓨즈가 다크 무드에 묻혀 가독성 불합격) — 에셋은 보존(이상개체 베이스 재활용 후보). 교훈: **플레이어는 "가독성=액터" 원칙의 1순위 — 어두운 모델은 월드가 어두울수록 탈락.**
5. **합성 드론 기각** (유저 귀: "우우우웅 거슬림") — AmbientBedDrone kAutoStart=false(코드 보존), COZY 앰비언스 모듈 비활성. **압박 베드 = 실음원 과제로 이월.** 좀비 보컬·발각 절규는 placeholder로 가동 중(보유 에셋에 실음원 0건 — 구매 필요 영역, [[2026-06-11-sound-prep-spec]] 참조).

## ★ 함정 기록 (재발 금지 — 이번 세션 발굴분)

1. **.mask 디스크 편집은 AnimatorController 베이크 캐시에 미반영** — Refresh/ForceUpdate 무효. 레이어 `avatarMask` null→재할당으로 리빌드 강제해야 적용.
2. **Mixamo 클립의 Bake Into Pose XZ가 ON으로 들어오는 경우 있음**(권총 아크 8종 실제 사례) — applyRootMotion=false에서 슬라이드+스냅백. 임포트 시 전수 확인 필수.
3. **"게임 타이머 = 모션 동기"는 배속 상한 필수** — 리볼버 1.1s에 3.7s 클립 = 3.33배속 경련(머리 73 deg/s). 상한 1.35 + bool 조기 컷이 정답.
4. **장전류 원샷 레이어는 트리거가 아니라 bool** — 무기 교체가 _reloading을 중도 리셋하는 경로에서 트리거는 상태에 갇힘.
5. **애니메이터 전환 배열 순서 = 우선순위** — 조건이 부분집합 관계면(Reload→Empty `!Reload` vs Reload→Fire `!Reload&&Firing`) 뒤의 전환은 죽음. 재정렬 필수.
6. **git index.lock 레이스(다중 세션)** — 프로세스 확인 후 20s+ 묵은 잔재만 제거, 살아있으면 대기. PS 5.1에서 네이티브 명령에 `2>$null` 금지(성공도 실패로 보임). 스테이징 혼입 방지 = pathspec 커밋(`git commit -- <paths>`).
7. 시야 콘 합성 패스가 월드 투명 VFX를 지움(후방 힌트 세션 기록) — 상시 정보 VFX는 오버레이 캔버스로.
