## PART 0 — 선행 결론: 도트 폐기, 3D 최종 확정

유저가 AI 도트(픽셀아트) 캐릭터 가능성을 직접 재조사(DC 갤러리 글 3개 추적: Rika.ai / Ludo.ai / Komiko 등) 후 **3D로 최종 마무리** 결정.
- **AI 도트 도구 실태:** 기능은 실존하나 **프레임 간 일관성 독립 검증 0**. Rika/Ludo 호평은 전부 벤더·제휴 출처. 검증 가능한 건 PixelLab뿐.
- **결정타 = 무기 조합 폭발:** 도트는 "무기 낀 모습"을 무기종×애니×방향×프레임으로 **곱셈** 양산해야 함. 본 게임은 무기강화=설계도/부품이 진행 핵심이라 치명적. 3D는 **덧셈**(리그 1개 + 무기 메시 N개, 손 본 부착, 방향=카메라 회전으로 공짜).
- → **도트 주제 종결.** 캐릭터 파이프라인 = AI 3D→Mixamo (캐논). 메모리 `project_2026_06_07_pixelart_decision`, `project_hero_art_pipeline` 참조.

## PART 1 — 타이틀 화면 (확정)

**풀타이틀: "사후처리부: 특이사항 없음"**
- "사후처리부" 크게 + ": 특이사항 없음" 하단에 작게.
- 부제가 곧 테마: "특이사항 없음" = 본사 공식 입장(은폐된 거짓말). "있음" = 진실.

**글리치 타이틀 연출 (확정):**
- **A (부팅 1회):** 켜질 때 "특이사항 **있음**" → 지직 글리치 → "**없음**"으로 정정·고정. 읽힘=진실이 켜진 순간 은폐됨.
- **B (idle 재발):** 이후 "없음" 고정 상태에서 가끔 "있음"이 한 프레임 새어나왔다 도로 없음. 읽힘=은폐가 계속 샌다.
- **A+B 혼합으로 결정.**
- **글리치 룩 = 디지털 지직** (RGB 분리·스캔라인·노이즈). 검열 블랙바 폐기. Why: 세계관이 "AI 나노봇에게 조종당함"이라 데이터 변경/덮어쓰기 느낌이 맞음. 블랙바는 인간 관료 검열 느낌이라 톤 어긋남.
- **색 분리:** "있음" 새어나올 때 평소(청록)와 다른 경고색(적/노이즈).
- **SFX:** 글리치 시 짧은 효과음 1방.
- **진행 연동(공짜 서사장치):** 새 화면 0. 엘이 삭제데이터 복원할수록 **글리치 빈도 변수만 ↑** → "있음"이 점점 자주 새어나와 본사 거짓말이 무너짐을 타이틀이 스스로 말함.
- **구현:** DOTween + TextMeshPro로 충분(솔로 친화).

## PART 2 — 폰트/로고 방향 (확정)

- **Pretendard = 본문/UI 작은 글씨 전용.** 로고로 쓰는 건 폐기 — 유저: "너무 무난, 게임 메인로고로 본 적 없다". 본문에선 무난함이 미덕(가독·무료·SDF 보유)이라 유지.
- **메인 로고 = 캐릭터 있는 디스플레이 폰트 + 처리(treatment).** 폰트 그대로 타이핑 금지.
- **방향 = A+B 혼합 (유저: "둘다 넣어봐"):** A 관급 공식 부처 워드마크(각진 헤비, 현판/도장) 베이스 + B 디지털 시스템/데이터 글리치. "딱딱한 공식 부처가 데이터 조작당함" = 테마 정중앙.
- **부서 마크 포함:** 작은 인장/배지(도장·나노봇 모티프). 로고 정체성 가장 싸게 올리는 수단.
- 후보 폰트(상업 사용 가능 여부 **확정 전 체크 필요**): 검은고딕(Black Han Sans)·에스코어드림 Black·G마켓산스 Bold(관급), 넥슨 Lv2 고딕(게임), 여기어때 잘난체(임팩트).
- ⚠️ AI 이미지는 **컨셉·무드 확인용**. 실제 로고 글자는 Unity TMP에서 고른 폰트로 재현하므로 AI 생성 글자 모양에 집착 X.

## PART 3 — 메뉴 철학 + 오프닝 플로우 (확정)

### 3-1. 솔로용 린(lean) 메뉴 철학
디제틱 3D 단말 메뉴(이미지 목업 보고) "1인 개발에 안 맞는다" 판정 → **폐기.** 화면마다 맞춤제작 + 서사 글리치 상태 곱셈 + 아트/엔지니어링 동시부담 = 본편 침식.
- **대안 = 정체성을 "싼 것"에서만:** 키아트 배경/씬 + 청록/노랑 팔레트·폰트 처리 + 엘 텍스트 bark(게임플레이 bark 재사용=공짜).
- 단, **글리치 타이틀처럼 "싼데 테마 박는" 연출은 적극 채택.**

### 3-2. 오프닝 플로우 — 사무실 허브
게임 시작 → 추상 메뉴 아님. **사후처리부 지점 사무실 3D 씬에서 시작.** 톱뷰(=게임플레이 카메라 재사용, 새 카메라 0 = 솔로 친화).

```
타이틀(글리치) → [게임 시작]
  → 사무실 씬 [톱뷰, 변주 날씨] : 팀장 + 엘(로봇) + 플레이어 캐릭터
  → 캐릭터 선택 → 캐릭터가 동작/포즈, 팀장이 그쪽 응시
  → [선택 완료] → 팀장 책상 패드(계획서)로 빠른 클로즈업(DOTween 카메라무브)
  → 패드에서 장소 + 난이도 선택 (= 디제틱 미션 셀렉트)
  → 현장 투입 (글리치 와이프 + 엘 부팅 bark + 둠클락 시작)
  → 게임플레이
```

**확정 디테일:**
- **캐릭터 수: MVP = 1명만.** 다수 캐릭터(B)는 post-MVP 확장. 사무실 프레임은 다수 대비해 짜되 MVP는 1명이라 선택은 사실상 확인용. 서사 1인칭 유지에 오히려 깔끔.
- **분위기 = 변주(varied):** 맨날 비/맨날 석양 아님. 사무실 진입 시 라이팅/스카이박스 프리셋 풀(석양·비·흐림·야간…)에서 변주. 거의 공짜(프리셋 스왑, COZY 제거 후 정적 프리셋 방침과 일치). 기본=랜덤.
- **글리치 와이프 = 전환 효과로 재사용** (타이틀 글리치 모티프 공유).
- **솔로 비용:** 사무실 씬 1개(`Assets/hazelwoodloft/` 보유 실내에셋 재활용 후보), MVP 캐릭터 모델 1, Mixamo 애니 재사용, 카메라무브 DOTween.

### 3-3. 보류된 것
- **업그레이드 / 줍는 설계도(재보정·무기강화)** = 이 허브 통합 여부 **나중 결정.** 지금 설계 안 함.
  - ⚠️ 단 보급 모델은 이미 "줍기 아님 → 본사 드론 배달"로 피벗됨(2026-06-07 핸드오프 참조). 허브 통합 논의 시 이 캐논과 정합 확인.

## PART 4 — 다음에 할 수 있는 것 (미착수, 유저 지시 대기)

1. **팀장 패드 = 미션 셀렉트 화면 구성** (다음 자연스러운 단계) — 장소·난이도를 어떻게 보여줄지(지도 vs 현장 카드, 위험도/위험수당 표기). 데모 바이옴/게이트 구조(`level-design-authority`, 감염 시계)와 직접 연결.
2. **현장 투입 순간 연출 구체화** — 글리치 와이프 + 엘 첫 bark + 둠클락(감염 시계) 시작 타이밍.
3. **사무실 씬 실제 셋업** — hazelwoodloft가 낡은 사무실 무드로 쓸만한지 확인 + 톱뷰 구도.
4. **타이틀 글리치 구현** (스펙 동결) — DOTween+TMP. Gameplay 에이전트 위임 가능. 구현 후 Stab+Codex 병렬 리뷰(워크플로우 규칙).
5. **AI 이미지 생성** — 타이틀 키아트(관급 워드마크+디지털 글리치+부서 마크+도시 야경 부감) 컨셉. 프롬프트는 이 세션에서 작성됨(메모리/대화 참조). Gemini가 한글 렌더 유리.
6. **폰트 라이선스 확정** — 후보(검은고딕/에스코어드림/G마켓산스/넥슨/잘난체) 상업 사용 가능 여부 체크 후 로고 폰트 1개 선정.
