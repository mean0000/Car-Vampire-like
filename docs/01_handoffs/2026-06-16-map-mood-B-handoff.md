## 0. 한 줄 요약

탑뷰 뱀서+익스트랙션 슈터의 맵을 **"바닥 타일(무드) + 흩뿌림 프롭(서사=엄폐물)"** 문법으로 잡되,
무드 타깃을 **B = Human Resources 톤(따뜻한 단색조 아이소 + 거대 이형 괴물 + 개미떼 군집)** 으로 확정.
다음 작업 = 그 "따뜻한 빛" 룩을 유니티에서 재현하는 **5겹 셋업 레시피 적용 + 캡처 조정 루프** (Codex 협업).

## 1. 확정된 방향 (이번 세션 판정)

1. **맵 설계 문법 (동결)**: 도시를 *짓지* 않는다. **바닥 텍스처(반복 타일=무드 베이스) + 흩뿌림 레이어(서사 프롭, 몇 종 회전·재배치로 무한 산포)**. 중세 예시="황색 평야 + 꽂힌 깃발/칼". 흩뿌림 프롭 = 그대로 **차폐 3단위계(벽=하드 / 하프월=중간 / 개활=킬존)** 전투 지형이 돼야 함.
2. **카메라가 먼저다**: 모든 것은 **탑뷰/높은 아이소**에서 읽히게. 눈높이 디테일(건물 정면·벽 질감) 투자 금지 — 안 보임. 위에서 본 **실루엣 + 색**으로 승부. (디비전 레퍼는 아이레벨이라 *기각* — 카메라가 틀렸다.)
3. **적 정체성 전환**: 나노좀비 → **"해괴망측한 괴물"(바디호러/이형)**. ★Story 판정: 이건 캐넌 충돌이 *아님* — 나노봇은 외형이 아니라 **세계 작동 기전**이라, 외형을 이형으로 격상해도 strain=메모리·싱크게이지·K-행정 캐넌 거의 다 생존. (상세 §6 st 문서)
4. **"황혼의 적막" 톤 폐기** (별개 사안, 서사 충돌 0).
5. **무드 타깃 = B (Human Resources)**. 유저 명시: "B와 같은 형식의 느낌." 축 A(VW 회로밭=추상·패턴·차분)는 **룩 보조**(팔레트 규율 + 바닥이 정체성을 진다)로만 차용. 골격은 B(스케일·군집·압도).

### 아직 안 정한 것 (다음 세션 판정 대기)
- **괴물 기원 톤 A/B/C** (Story §3): A "오류로서의 이형"(추천, 나노 폭주·본사도 형태 예측 못 함) / B "설계로서의 이형"(⚠️본사 전능화 위험) / C 혼종.
- **첫 맵 컨셉 확정**: lv 슬레이트 7종 중. lv 1순위는 C1 "무너진 대로"였으나 그건 *보유 에셋 기준* 추천 — 무드 B로 무게중심이 옮겨갔으니 재평가 필요.

## 2. ★핵심 기술 진단 — "따뜻한 빛이 유니티에서 안 되는 이유"

유저 질문: HR의 따뜻한 톤을 유니티에서 시도했는데 안 됐다. **이유 = 그건 "빛(Light)"이 아니다.** 라이트로 재현하려 하면 100% 실패. 정체는 **5겹 스택**이고 라이트 비중은 작음. 유니티 기본값이 이 5겹을 전부 반대로 깔아둠:

| # | 겹 | HR | 유니티 기본 (왜 안 됐나) | 고침 |
|---|---|---|---|---|
| ① | **통일 컬러 그레이드 (주범 80%)** | 화면 전체 세피아/앰버 한 색 | 그레이드 비어있음 → 워밍 라이트만 꽂으면 하이라이트만 노래지고 **그림자는 파랑** = 따로 놈 | Tonemapping(ACES/Neutral) + Color Adjustments(색온도↑·채도↓ 모노톤화) + **Split Toning(하이/섀도 둘 다 워밍)** + White Balance |
| ② | **따뜻한 대기 안개 (depth haze)** | 먼 건물 따뜻하게 흐려져 한 덩어리 | **Fog 꺼짐** | URP Fog 켜고 색을 따뜻하게 |
| ③ | **따뜻한 앰비언트 (그림자 색)** | 그림자가 따뜻 | 스카이박스 바운스 = **파란/차가운 그림자** = 워밍 정면 파괴 | Environment Lighting 따뜻한 톤 강제 or 그레이드로 덮기 |
| ④ | **매트 재질 (PBR 반사 죽이기)** | 광택 0 일러스트풍 | URP 기본 PBR = 번들거리는 스페큘러가 매트 무드와 싸움 | Smoothness 바닥 / 토온·언릿 검토 |
| ⑤ | **노출/톤 정리** | 색이 함께 앉음 | — | 위 4개 자리잡으면 정리됨 |

**결론**: 살릴 수 있다. 에셋 정밀도 문제가 아니라 **세팅 레시피**다 (우리 roadtest가 밍밍했던 것도 이 5겹이 0이었던 탓). 단 — **엔진=가능 / 한 방엔=거의 불가(캡처→유저 판정→조정 N회 루프) / 최종 미적=유저 눈.**

## 2.5 ★재검증 결과 (2026-06-16, Codex gpt-5.5 + vc opus 교차 — 두 눈 독립 수렴)

§2의 *방향*은 맞으나 프레이밍에 결함 3개. 착공 전 반드시 반영:

1. **가중치 과장 폐기** — "그레이드 80% 주범 / 라이트 비중 작음 / 100% 실패"는 진단용 수사지 실제 비율 아님. 라이트·그림자·앰비언트·포그·매트·그레이드가 *같이* 맞아야 함.
2. **빠진 겹 추가 = "⑥ 라이트 각도 + 그림자(밀도/소프트니스/방향)"** — 둘 다 최우선 지적. 레퍼는 **확산광=그림자 거의 없음**. 강한 Directional + 긴 그림자를 깔면 레퍼와 실루엣이 어긋남. 각도가 룩의 절반.
3. **알베도가 토대 (최대 리스크)** — 텍스처가 *이미* 베이지/카키여야 함. 틀린 알베도·라이트·재질 위에 Temp/Saturation/Split Toning만 올리면 HR 룩이 아니라 **탁한 황사 화면**. + 채도 무작정 낮추기 금지 — 택시 노랑·차 빨강 액센트는 알베도에서 살림(전역만 -20~-35).

**★부감 거리 가중(우리 ~15-20m 수직):** 5겹 동등 아님. ①그레이드+바닥색=압도적 1순위 → ②변형(방사형)포그=2순위 → 거리포그·매트재질은 거의 안 걸림. 단색조 = 순수 세피아 아니라 **앰버↔올리브 2축**(축 A를 끄는 진짜 색채 근거).

**Codex 구체 시작 노브값 (Volume):** Tonemapping ACES / White Balance Temp +18~30, Tint -3~+5 / Color Adjustments Contrast -8~-18, Saturation -20~-35, Post Exposure -0.2~+0.2 / Split Toning Shadows `#6F6746` · Highlights `#F2C978` · Balance +10~+25.
**렌더/환경:** Directional ColorTemp ~4500K(`#FFD99A`), Intensity 1.0~1.6, Shadow Strength 0.5~0.6, X 45~55°·Y -35~-55° / Ambient Source=Color `#7A6F4E`~`#8A7A55` / Fog `#C9B77F`~`#D2BE84` Exp density ~0.015 / Material Metallic 0, Smoothness 0.05~0.25, Specular Highlights off.
**팔레트 근사:** 하이라이트 `#D8C58D` / 베이스 `#A99A70` / 그림자 카키 `#6D6649` / 오클루전 `#343020`.
**결론:** 이건 URP 기본 PBR이 아니라 토온/일러스트 아이소 룩 → Volume 노브로 안 잡히면 셰이더/머티리얼 규칙까지 가야 함.

## 2.6 ★★레시피 역전 (2026-06-16, 웹 리서치 + Codex gpt-5.5 픽셀 분석 수렴)

§2/§2.5의 "따뜻한 빛=5겹 포스트 스택" 무게중심이 **거꾸로였다.** 두 독립 눈이 같은 결론:

**게임 정체 (웹 리서치):** Human Resources = Uber Entertainment 2014 Kickstarter **펀딩 실패→미출시**. 기술 브레이크다운 *존재 안 함*. 문서로 확증된 **유일한 아트 영향 = Ligne Claire**(Hergé 땡땡 / Geof Darrow — 명확한 외곽 실루엣 + 균일 평면색 + 채도 통제). 디자인 디렉터 John Comes가 명시한 의도 = **극단적 스케일 대비**("거대 이형 vs 개미떼 specks", 미나스 티리스 레퍼). ★따뜻한 세피아 톤은 개발사 진술 *아님* — 스크린샷에서 읽은 인상일 뿐. **HR을 따뜻톤 기법 권위로 삼지 말 것. 레퍼 이미지로만, 따뜻톤 기법은 우리 내부 스택이 근거.**

**Codex 픽셀 판정 (실제 프레임 실측):** 음영 = 연속 PBR 롤오프 아님, **2~3단 면 분리**(밝은 면/중간/암부로 색이 갈라짐) / 스펙큘러 거의 0 / **강한 접지 AO**(다리·차·건물 하단 — 형태 읽기의 절반) / 어두운 라인이 실루엣·패널·균열에 박힘(전역 만화선 아님).

### → 진짜 우선순위 (5겹 포스트 스택보다 이게 먼저)
1. **알베도 단순화** (저채도·큰 색면) — 텍스처 자체가 베이지/카키
2. **2~3단 토온 셰이딩** (NdotL 양자화) ← §2/§2.5에 통째로 없던 항목
3. **스펙큘러 제거**
4. **강한 접지 AO/그림자** ← §2.5 "빠진 6번째 겹"과 동일 결론
5. **외곽선(Sobel)은 대형 적·보스·건물·차에만** — 부감 15-20m서 군중에 걸면 "검은 먼지 노이즈". 군중=어두운 단순 실루엣
6. **따뜻한 컬러 그레이드 = 마지막 양념** (§2의 5겹은 여기 6순위, "주범 80%"는 오진)

### 함정 (지난 "황사 화면"의 진짜 원인)
따뜻 그레이드만 올리고 평면 셰이딩 안 하면 → "HR풍"이 아니라 **일반 3D에 노란 필터 씌운 화면**. 탑뷰 뱀서는 개체가 많아 따뜻 그레이드가 오히려 값을 뭉개 **유닛 판독성만 떨어뜨림**.

### ⚠️ 스코프 경고
이건 Volume 노브가 아니라 **셰이딩 문법 결정**(토온 셰이더 + 텍스처에 그린 패널/균열선 = 아트 파이프라인 작업 또는 토온 에셋 구매). **단 지금 착공 신호 아님** — 그래픽은 현 병목 아님(메커닉 재미가 병목), "방향만 박고 보류"(`graphics_lighting_strategy`). 이번 검증의 가치 = 나중 그래픽 패스서 5겹부터 만지다 황사로 헛도는 함정을 미리 차단한 것.
