- ★**판단 기준 = "뽕"**(시각적 파워판타지 러시). *시스템적 분류(경제 루트·스타일 친화)로 판정 ❌* — over-systematization은 4번 "재미없다"의 출처. → [[feedback_pong_over_systematization]].

### 1.4 키스톤 + 퇴근 정산
- **키스톤 = 화려함=돈.** 스타일 소스: 노히트 연속·광역·고위협·화려한 처형.
- **퇴근 정산** = 런 중 스타일로 "처리 평가"(등급 **S~D**) 쌓음 → **퇴근해야 성과급으로 현금화**(메모리×배수), **죽으면 배수 소멸**. (등급제·런 누적·노히트만 피격 시 끊김 = 노브 기본값.)

### 1.5 카드 문법 v2 (제안서 §16)
- **2층**: 정체성 동사 스파이크(G1~G6) + **방향성 +% 연료**(스노볼, 가지 쪽으로만). 순수 +% 금지 ❌ → 연료층으로 복권.
- ★**G3 시너지 엔진 = 심장**: 가지마다 *서로 먹여주는 사슬*(SoD Exodia)이 터지는 순간 = 뽕.
- 6동사 클래스: G1 규칙변경+대가(PoE) / G2 조건부 / G3 시너지활성 / G4 변태 / G5 전환증폭 / G6 대안정체성. 레퍼 추적.

### 1.6 ★카타나 = 거합 트리 + 참격 트리 (탑다운 상세 스펙, §17.1)
유저 4모드(거합/일섬/반격/참격) 풀림 → gd "일태도"(단일 코어) → **유저 "최소 2 독립 트리"** → **거합 + 참격 2 트리(각자 코어)** 확정. 코드 실측(PlayerCombat: 마우스 조준·LMB 홀드 swing·RMB 정조준 재활용·OverlapSphere 판정·텔레그래프는 45° 부감이라 *발밑*).

- **거합 트리** = 정지 충전 발도→킬 환류 가속. LMB 평타(−40%)/RMB 홀드 충전(정지 2배)/RMB 릴리스 발도(조준선 캡슐 2.5~6m 관통). 차지 1.2s, 킬=게이지+35%, 발밑 시안 링 텔. *멈춤이 곧 화력.*
- **참격 트리** = 콤보 가속(적중마다, 피격 리셋)→5단 참격파(90°×5m). 콤보 윈도우 2.0s, 5단=쿨−60%, 발밑 시안 호 게이지. *노히트가 곧 화력.*
- 구별 4축 정반대: 충전(정지↔적중)·방출(직선 돌진↔확장 부채꼴)·대가(평타−40%↔리셋)·위치(거점↔유동).
- 🟡 **판정 대기**(유저 미응답, §17.1): ①거합 차지=우클릭 정조준 재활용 OK? ②발밑 텔레그래프 OK? ③정지 1.2s 균형? ④참격 5단 유지 vs 참격파 소비 딜레마 충분?

### 1.7 컨트롤 — 린한 KB+M (★06-14 최종 = 린 5)
- **WASD** 이동 · **마우스** 조준(즉각 일치) · **LMB** 주공격 · **RMB** 무기 특수(문맥=든 무기) · **Space** 회피(+완벽회피=반격창) · **Tab** 보조무기 빌림 · **E** 궁극 · **F** 상호작용 · **R** 재장전(근접=무탄약 제외) · **1/2** 무기 슬롯 스왑.
- ★**능동 전투 입력 = 5개**(LMB/RMB/Tab/Space/E) — "린 5" 유지.
- ★**패링 판정(06-14)**: 회피/패링 중 **회피 단일** 채택. 결정타 = 회피만 있으면 잡몹+엘리트 둘 다 커버(게임 성립), 패링만이면 호드 다수를 못 막아 결국 회피 필요. 패링=1:1 듀얼·정밀 타이밍=폐기한 택티컬 극·탑다운 호드 부적합. **단 패링 *반격 뽕*은 [완벽회피]로 흡수** — 텔레그래프를 대시로 통과 시 슬로우+반격창(타이밍=보너스, 강제 아님). 별개 패링 키 ❌("너무 많아짐" → 린 5 복귀).
- ★**궁극(E) = 충전 제한 + 성격은 카드**: **공격형**(화려함 임계 충전→대방출 = 키스톤 "화려함=돈" 엔진을 버튼으로) vs **방어형**(자기보호 패닉). 표현=무기 캡스톤(거합=발도무쌍)·타입=카드·충전=키스톤. 🟡미결: 궁극 카드 뽑기 전 빈 버튼? (a)기본궁 깔고 카드가 변형 vs (b)카드 해금(초반 빈버튼).
- ★**F 상호작용** 신규(추출구·픽업·커밋 등). 캔슬 헌법 스코핑 = [[feedback_player_self_cancel_canon]](플레이어 self-cancel=하드컷, 몬스터만 commit-lock).
- ★**06-14 추가 — 스왑 = 1/2 + Tab 보조무기 빌림** (구 "Q 스왑" 대체):
  - **1/2** = 완전 스왑(주력 교체, 든 무기가 LMB/RMB/Space/E 전부 결정).
  - **Tab** = 비장착 보조무기의 **RMB 특수 1발을 잠깐 빌려 발사** → 다시 주력 복귀. 1번 들 땐 2번 특수, 2번 들 땐 1번 특수.
    - 쏘는 건 **강화된(인-런 빌드된) 보조** — 맨몸 기본형 ❌. **쿨타임으로 남발 방지**("주력=1번" 유지, Tab=가끔 찍는 구두점).
    - 효과: 능동 입력 무기당 5개(LMB/RMB/Space/Tab/E) → 초반 미분화 2클릭 단조 해소 + 2슬롯이 조합 텍스처. 추상 스킬 ❌(진짜 보조무기 빌림 = "무기=빌드" 철학 유지). 레퍼=DMC 건슬링거 찍기·Ultrakill 퀵스위치.
    - 🟡 **B 확인 대기**: "강화된 보조" → 보조도 인-런에 자람 = 카드를 2무기 트리에 분배(주력 깊게/보조 얕게)?
- ★**캔슬 헌법 스코핑 (06-14)**: 애니 헌법(crossfade 금지·commit-lock)은 **몬스터 한정**. **플레이어 = 스스로 캔슬 가능**(발도/베기 중 Tab·대시로 *조기 종료 + 하드컷*, 새 동작은 자기 상태 처음부터 클린 재생). 🟡 **A 확인 대기**: self-cancel = 클린 하드컷이지 블렌드 뭉갬 ❌(애니가 진실 유지)? → 맞으면 거합 충전 중 Tab도 자동 해결(충전 캔슬→보조 특수, 쿨이 남발만 막음). 메모리 [[feedback_player_self_cancel_canon]].
- **궁극(E)** = 화려한 처치로 충전(키스톤 직결)→대방출, *무엇이 터지나는 무기/빌드가 결정*(거합=발도무쌍 등). 별도 스킬 시스템 ❌, 무기 캡스톤을 1키로 회수. **= 별도 스킬은 1개(궁극)뿐, 나머지는 무기+대시.** (SoD 4스킬은 우리한테 안 맞음 — SoD는 스킬=빌드, 우리는 무기=빌드.)
- **대시 몰빵**(바 sprint ❌): 탑다운에선 달리기 화려함=3인칭 환상. 높은 기본 이속 + 화려한 대시(대시-스트라이크·캔슬·위상 잔상)로 기동 뽕. 장르 선례(헤이디스·건전) = 대시만.

## 2. ⏸️ 내일 첫 주제 — "강화 = 우리만의 방식" (파킹)

SoD가 "스킬 강화"의 게임이라면 우리 강화는 **무기 빌드 트리**(카드로 무기 강화·변형)인데, *전달 방식*에서 우리만의 결 3개를 제안함 (유저 "내일 생각"):
1. **엘이 현장 장착** — SoD 메뉴 슬롯 ❌, 엘이 본사 보급 모듈을 전투 중 볼트온(키네틱·디제틱).
2. ★**스타일이 강화를 먹인다** — 화려하게 처리할수록 "돈"(XP) 빨리·좋게 → 더 빨리 강화 (DMC식 스타일 보상). *뽕이 곧 성장 엔진.* **유저가 이걸 핵으로 기울임 — 내일 판정 1순위.**
3. **무기가 눈에 띄게 진화** — 수입 절단구가 모듈 붙으며 형태 변함(탑다운 실루엣 가독).
→ 루프: 화려하게 처리 → 돈 빨리 → 엘 장착 → 무기 화려·강력 → 더 화려하게 ↺.
**내일 판정**: ②(스타일→강화 가속)을 핵으로? 셋 다 묶을지? 그 위에서 강화 시스템 동결.
