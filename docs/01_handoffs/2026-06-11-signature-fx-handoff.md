## 2. 대시 위상 잔상 — PsyOps 그것

**스펙**: 기존 단색 시안 잔상 → **마젠타/시안 가산 HDR 페어**. 갓 생성=두 색 겹쳐 화이트 코어(블룸 통과), 나이(0→1)에 따라 좌우로 0.02→0.14m 찢어지며 분리, 색×(1-t) 페이드. + 대시 중 뒤로 흐르는 시안 스트릭(스트레치드 빌보드, 40/s). 디제틱 = 나노봇 신호가 속도를 못 따라와 채널이 갈라지는 "위상 잔류".

**파일**: `Assets/_Project/Scripts/PlayerAfterimage.cs` 단일 수정 (베이크 1회→CombineMeshes 2회, 제로할당/풀링 규율 유지, 워밍업 ×2).
**시간축**: 의도적으로 scaled — 히트스탑 중 잔상이 멎는 게 "세계가 멎는" 연출과 정합.
**⚠️인스펙터**: 구 `ghostColor` 직렬화 필드 삭제 → 기존 오버라이드 소실, 신규 `ghostColorMagenta`/`ghostColorCyan`은 코드 기본값으로 시작.
**검증 절차**: 아무 플레이 씬에서 대시 연타. 화이트 코어 → 마젠타/시안 분리 → 속도선 3종 확인 + Profiler GC.Alloc 0.
**튜닝 레버**: interval(밀도)/lifetime(잔류)/채널 색 2종(인스펙터), SplitStart·End(찢어지는 폭), GhostHDR(2.5), StreakRate.

## 3. 싱크 글리치 — 화면 전체 신호 붕괴

**스펙**: 슬라이스 변위 + RGB 분리 + 블록 노이즈(마젠타/시안/화이트 솔리드) + 스캔라인 + 버스트 화이트 플래시. 스터터 리듬(60~140ms 시드 재롤, 강도↑=간격↓). 전 타이밍 unscaled(사망 timeScale=0 대응).

**현재 와이어링 (기존 파일 수정 0줄 — 전부 이벤트 자가 구독)**:
- SyncRate 0.7 → 1.0 ⇒ 베이스라인 강도 0 → 0.6 (HUD 비네트와 같은 70% 임계. ★SyncRate는 1=게임오버 방향)
- OnSyncMaxed / OnPlayerDied ⇒ Burst(1, 0.7s) — 사망 글리치 아웃
- `GlitchFX.Burst(strength, duration)` 공개 static — **미래 이벤트용 빈 자리** (§4)

**파일**: `Assets/_Project/Scripts/GlitchFX.cs`(자가 부트스트랩 DDOL, 니어플레인 쿼드, requiresColorOption 런타임 On) + `Assets/_Project/Setting/SyncGlitch.shader`.
**검증 절차**: 플레이 중 하이어라키 `GlitchFX` → 컴포넌트 우클릭 ContextMenu — "Baseline 0.5 토글" / "Burst Small" / "Burst Death".
**리뷰 핵심 (C-1, 수정 완료)**: 풀스크린 씬컬러 재구성 쿼드를 Blend One Zero로 깔면 투명 큐 전체(시야 콘·잔상·파티클·LKP)가 소실된다 — **알파마스크 부분 덮어쓰기로 전환**(일그러진 밴드/블록 픽셀만 알파 1, 풀스크린 점령은 버스트 플래시 60ms뿐). 저강도에서 밴드 띠 안의 투명물 소실이 거슬리면 `bandActive * saturate(I*k)` 가중 튜닝 여지.

## 4. ★내일 결정할 것 — 글리치/마젠타 문법을 어디에 쓸까

지금 확정 와이어링은 싱크 70%+ / 사망뿐. `GlitchFX.Burst()`가 공개 API라 아래 후보들은 **한 줄 호출로 연결 가능**:

| 후보 | 디제틱 | 강도 제안 | 메모 |
|---|---|---|---|
| **엘 파편 획득** | 손상된 AI 데이터가 내 시스템에 유입 | Burst(0.4~0.6, 0.3s) | 데모당 5회 — 희소성 적격. 파편 픽업 자체가 미구현이라 FX가 먼저 대기하는 그림 |
| **캠페인 규칙 폭로(2단 톤폭발)** | 시안 UI가 마젠타로 무너짐 — 본사 거짓의 시각화 | 전용 연출(베이스라인 점령+UI 치환) | 색 캐넌(시안↔마젠타 대립)의 완성형. story_demo_spec 연계 |
| 변종/엘리트 첫 조우 | 엘이 식별 실패하는 개체 | Burst(0.3, 0.2s) | 남발 위험 — 첫 1회만 |
| 타이틀 화면과의 톤 통일 | 타이틀 글리치(기존)와 인게임 글리치가 같은 언어 | — | TitleFX와 셰이더 공유 검토 |
| 피격 순간 | 신호 출렁임 | 비추천 | 빈도 너무 높음 — 발작 가드·피로 문제. HP 비네트가 이미 담당 |

**판단 기준 제안**: 글리치는 "연결이 흔들리는 서사적 순간"에만 — 단순 데미지 피드백으로 내리면 화폐 가치가 떨어진다.
