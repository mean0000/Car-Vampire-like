# Western 시작구역 — 레이아웃 하네스 (리뷰용 v1)

> 🟥 **폐기 (2026-06-03).** Western 시작구역은 같은 날 **"어두운 현대 도심" 피벗**으로 강등 — [[2026-06-03-session-handoff-city-pivot]] 참조. 하네스 워크플로우(표 리뷰→승인→빌드) 자체는 방법론으로 재사용 가능.

> 2026-06-03 lv. **"내가 어떻게 배치하는지 투명하게"** 위한 선언적 빌드 스펙.
> 빌드 전에 이 표를 사용자가 **리뷰 → 수정 → 승인**한다. 승인된 표대로만 빌드한다.
> 좌표는 매직넘버가 아니라 **PolygonWestern Demo 실측값을 그대로 채택**(권위문서 §8에서 추출). 즉 데모에서 "타운으로 읽히는" 검증된 배치를 그대로 가져와 재스킨한다.

## 워크플로우 (하네스 루프)
1. 내가 표를 제시(이 문서). 각 행 = 1배치, **반드시 "이유"(§8 규칙 근거) 포함.**
2. 사용자가 행을 보고 좌표·회전·프리팹·이유를 수정/승인.
3. 승인분만 Unity MCP로 빌드 → 표준 캡처(탑다운+오블리크)로 검증.
4. 검증샷 보고 → 다음 단위.

## 좌표 규약
- 루트 `WesternStart` (빈 GameObject). 모든 좌표는 **루트 로컬**. +X=동, +Z=북, 탑다운.
- 거리 중심선 x=0, 거리는 N-S로 뻗음. 두 점포 줄이 x≈±11에서 거리를 마주봄.
- 월드 배치 위치: **미정(승인 후 결정).** 현재 `WestTown_Map`(~월드 2035,2000)은 지면이 Unity Plane이라 결함 → **이 하네스로 새로 빌드, 구 블록은 폐기 후보(삭제는 사용자 확인 후).**
- 좌석: 건물=y0(기초 묻힘 의도), 지면 메시=y −0.4~−1.3 가라앉힘, 일반 프롭=bounds.min.y→0 (권위문서 §5).
- 프리팹 전부 PolygonWestern 팩 (`SM_Bld_*` / `SM_Env_*` / `SM_Prop_*`, 셰이더 `Synty/Generic_Basic`, URP 정상).

## 동선 요약 (§8-D, 게임 오프닝)
- **시작** = 보드워크 남단(Church 근처, 저밀도 안전 오프닝).
- **진행** = 거리 북상(두 점포 줄=엄폐·첫 조우) → 마차길 합류.
- **이탈** = 마차길 **동쪽 끝 → 다리 → BR 섬**(맵 방향 권위문서 일치).
- **봉인** = 마차길 서쪽 끝="왔던 곳"(잔해로 막음). 분지 메사 링=소프트월.
