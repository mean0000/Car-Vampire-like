# 세션 핸드오프 — 시작구역 도시 피벗 + 데모 역설계 (2026-06-03)

> 내일(클로드)이 이 문서만 읽고 작업을 이어갈 수 있게 쓴 핸드오프.
> 이 세션의 큰 줄기: **(1) 내 배치 과정을 투명하게** 만들려고 Synty 데모 씬을 역설계해 문서화 → **(2) 시작구역을 Western(카우보이)에서 "어두운 현대 도심"으로 피벗** 검토 → **(3) CityPack(POLYBOX) 임포트 대기 중, 무드 테스트로 결정 보류.**

## PART 1 — 오늘 한 일 (상세)

### 1-1. 출발점: WestTown 빌드가 결함이었다
- 직전까지 `RoadTest.unity`의 `WestTown_Map`(월드 ~2035,2000)을 빌드했으나, **지면을 Unity Plane 프리미티브로 깔아 "물 위에 뜬 사각 판때기"**로 보임("이야 엄청 심각하네"). 자체제작 지오메트리 금지 규칙 위반이 근본원인.
- 사용자가 멈추라 하고, **"네가 어떤 식으로 배치하는지 모르겠다"** → 배치 추론을 투명하게 만드는 방향으로 전환.

### 1-2. Synty 데모 씬 역설계 → 권위문서 §7·§8 작성
- Unity MCP로 **BattleRoyale Demo(2195 메시)** + **Western Demo(1515 메시)**의 실제 transform을 추출. 단순 좌표가 아니라 **관계·방향·특이점·동선**까지 추론.
- 결과물: `docs/00_authority/2026-06-03-synty-demo-placement-rules.md`에 **§7(BR 섬)** + **§8(Western 타운)** 추가.
  - **§7 BR 섬:** 두 다리 사이 통과 회랑 / 동(군용)·서(민간) 기능 비대칭 / 밀도는 X30~45 군용척추 집중 / 컨테이너=야드 적층, BaseWall=연속벽, GuardTower=게이트 / **동선은 데모에 없음→우리가 설계**(남다리 진입→착지 체크포인트→북다리 이탈, 끊긴 다리=전진압력).
  - **§8 Western 타운:** "T자"=E-W 마차길(척추)+남향 보드워크(가지) / 북단 기차역·남단 교회로 거리 양끝 막음 / 살롱=사회중심 / 서측=거친면(교수대·코랄·우물) 동측=상업면(살롱·급수탑) 비대칭 / **게임 오프닝 설계**(남단 교회=저밀도 시작→거리 북상→마차길 동쪽 끝→다리→BR섬).
- ⚠️ **중요 깨달음:** Synty 데모는 **플레이 레벨이 아니라 쇼케이스 디오라마**다. 입구·시작·동선은 데모에 안 박혀 있음 → 그건 우리가 설계하는 영역. 데모에서 읽는 건 컴포지션·관계·밀도뿐.
- 작업 방법 메모: 데모 씬은 `OpenScene(Single)`로 열어 추출 후 **반드시 RoadTest로 복귀**(additive 닫기 버그 있음). 탑다운 캡처는 임시 카메라(Euler 90,0,0) 만들어 `Unity_Camera_Capture`, 데모는 저장 안 함(임시 카메라 자동 소멸). `Capture2DScene`는 XY평면이라 탑다운 안 됨.

### 1-3. 하네스(레이아웃 표) 워크플로우 정립
- 사용자 핵심 불만 = "배치 과정이 불투명". 해결책 = **선언적 레이아웃 표**를 빌드 전에 리뷰/승인.
- 결과물: `docs/01_handoffs/2026-06-03-western-start-layout-harness.md` — Western 시작 6존 표(각 행에 프리팹·로컬좌표·rotY·**이유**). 좌표는 데모 실측값 채택.
- ⚠️ **이 하네스는 Western 기준이라, 아래 1-4 피벗으로 그대로는 안 씀.** 단 **포맷(존별 표+이유+캡처검증 루프)은 유효** → 새 도시 팩으로 내용만 갈아끼우면 됨.

### 1-4. 큰 피벗: 시작구역 = Western(카우보이) → "어두운 현대 도심"
- 사용자 지적: Western 에셋이 **너무 카우보이 시대**라 나노봇 SF 종말물 배경과 주제 충돌. 살롱·교수대는 좀비 드레스업해도 "좀비 카우보이"로 읽힘. 첫인상=정체성인데 시작구역으로 부적합.
- 내 판단(동의): 시작은 **"현대 일상이 갑자기 멈춘 곳"**이어야 나노봇 종말 첫인상에 맞음. Western은 후반 황무지 바이옴으로 강등.
- **Hell Express 무드 기준 도입:** 사용자가 "Hell Express처럼 도시 + 어두운 분위기"를 원함.
  - 레퍼런스 문서(`docs/03_reference/2026-06-01-hell-express-reference.md`) 재확인 → **그 무드는 메시가 아니라 라이팅/FX에서 나온다**(6-2 결론: 로우폴리 유지 + 극적 라이팅 HTrace + 포스트 그레이딩 + 그라임 데칼 + 안개/먼지 파티클).
- **에셋 프리팹 실사(이 세션 확인):**
  - **PolygonNightclubs** = 모듈식 *실내* 키트 + **FX 금광**(`FX_Laser_*`/`FX_Fog`/`FX_SpotLights`/네온/`FX_Dancer`). 사용자 확인: 대부분 고지대/루프탑 프리팹 → **길거리 도시 소스 아님. FX/무드 레이어 전용으로 확정.**
  - **PolygonConstruction** = 콘크리트 골조 고층·철근·**크레인**·굴뚝(모듈식) → 도시 수직 실루엣/폐허.
  - **PolygonBattleRoyale** = 턴키 저층 건물(House/Warehouse/SmallBuilding) + 군용.
- **TD(Top_Down_Post-Apocalyptic) 팩:** 주제 적합 1위지만 **Synty와 다른 아트 패밀리** → BR 섬과 섞으면 충돌. 사용자가 이 충돌을 우려 → 단독 사용 아니면 보류.

### 1-5. 현재 상태: CityPack 임포트 대기
- 사용자가 **POLYBOX City Pack(5.7GB, 보유)** 을 지금 다운로드/컨버트 중(오래 걸림). 이게 **시작 도심 메시 본체 후보.**
- "하나씩 직접 모델링" 안 → 1인개발 시간 블랙홀 + 무드는 라이팅에서 나오므로 모델링해도 안 나아짐 + 보유 팩으로 충분. (사용자 동의)

## PART 2 — 확정/단단한 것 (재논쟁 금지)
1. **아트 룩 = 로우폴리 토대 + 라이팅/포스트 "그릿".** 모델 직접 제작 ✕, 모델 교체로 해결 ✕. 무드는 빛/FX/데칼/파티클.
2. **보유 에셋 사용.** 자체제작 지오메트리(특히 도로) 금지.
3. **시작구역 = "어두운 현대 도심"** (나노봇 SF 종말 첫인상). Western은 **시작에서 제외 → 후반 황무지 바이옴으로 강등**(분석 §8은 안 버림, 팩만 바꿔 적용).
4. **Nightclubs = FX/무드 레이어 전용** (건물 소스 아님).
5. **결정 방식 = 시각 테스트.** 추상 판단 ✕ → 빌드해서 캡처 → 사용자가 눈으로 판정.
6. **지면은 절대 Unity Plane/Terrain ✕** (권위문서 §0). 팩 지면 메시 + 엣지 + 원경.
7. **데모 컴포지션 규칙(§1~§8)** = 어떤 팩이든 적용되는 보편 규칙(어깨맞댐·두줄·랜드마크 종착·기능 비대칭·밀도 클러스터·펜스 구획).

## PART 3 — 열린 결정 1개 + 계속 고민할 것
### ★ 단 하나의 진짜 미결: 도심 메시를 뭘로?
**이건 머리로 고르지 말고 CityPack 임포트 후 시각 테스트로 판정한다.**

계속 고민/결정해야 할 하위 질문:
1. **(A) vs (B) 패밀리 전략** — CityPack은 Synty와 다른 패밀리. 시작=CityPack / 섬=Synty BR이면 **다리 건너 충돌**(TD 우려와 동일).
   - (A) CityPack이 충분히 좋으면 **초반 체인 전체를 CityPack 계열로**, Synty BR 섬은 드롭/대체.
   - (B) **다리=바이옴 전환점**이니 룩 변화를 *의도된 전환*으로 수용. 단 라이팅/그레이딩으로 묶어야.
   - → 임포트 전까지 어느 쪽으로 기우는지 생각해둘 것.
2. **Hell Express 무드가 CityPack 메시에서 나오나?** (라이팅 테스트로 확인 — PART 4)
3. **CityPack 컴포지션이 §7/§8처럼 "도시로 읽히나"?** (데모 역설계로 확인)
4. **게임 시작점/동선** — §8(D) 패턴(저밀도 조용한 오프닝→종주→다리 이탈)을 새 도시 팩에 맞게 재설계.
5. **구 WestTown_Map(Plane 결함, 월드~2035,2000) 처리** — 폐기 후보, 삭제는 사용자 확인 후.
6. **라이팅 그릿 테스트는 2026-06-01부터 미결**(레퍼런스 6-3) — 이번이 그 게이트.

## PART 4 — 재개 시 즉시 할 일 (CityPack 임포트 완료가 트리거)
> 사용자가 "임포트 됐다"고 하면 아래를 순서대로. **빌드 전 추상 논의 금지 — 바로 눈에 보이는 것 만들기.**

1. **CityPack 데모 씬 열기** → §7/§8 방식으로 컴포지션 역설계(건물 턴키 여부, 블록/도로 구조, 밀도, 지면 처리). 추출+탑다운 캡처. 끝나면 RoadTest 복귀.
2. **Hell Express 무드 테스트(핵심 게이트):** CityPack 거리 한 토막 깔고 → **COZY 밤 + Height Fog + Nightclubs `FX_Laser`/`FX_Fog`/`FX_SpotLights`/네온 + 필믹 그레이딩 + (가능하면)HTrace SSGI** → 탑다운+오블리크 캡처.
3. 사용자에게 캡처 제시 → **"오 이거다 / 아니다" 한마디**로 판정받기. (패밀리 충돌 고민은 이 캡처 본 뒤에.)
4. 통과 → 시작 도심 = CityPack 확정 → 하네스 표를 CityPack 프리팹으로 다시 채워 빌드. / 실패 → 다음 카드(Construction+BR 조합 또는 TD 단독) 테스트.

## PART 6 — 계속 굴릴 생각거리 (서두르지 말 것)
- 시작구역 "현대 일상이 멈춘 낙차"를 뭘로 구체화할까 — 교외 주택가? 도심 상가? 지하철/역? (Hell Express는 도시·지하 느낌)
- 나노봇 픽션과 도시 드레싱 결합 — 감염흔적/나노봇 오염 비주얼 언어(이미시브 색? 균열? 결정화?)를 어떻게 일관되게.
- 다리 전환을 서사적으로 정당화(도심→다른 구역). "왜 다리를 건너나"의 동기.
- 라이팅 그릿 테스트가 통과하면, 그 라이팅 프리셋을 **모든 바이옴 공통 무드 베이스**로 박아 패밀리 충돌을 라이팅으로 흡수하는 전략 검토((B) 경로의 핵심).
