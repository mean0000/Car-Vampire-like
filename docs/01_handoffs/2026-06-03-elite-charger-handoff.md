## 0. 이 문서가 다루는 것

게이트①은 MVP 수직 슬라이스(집~게이트①, ~300m)의 첫 보스다. 그 전투의 **구조·규칙은 전부 확정**됐다. 남은 건 (a) 수치 튜닝과 (b) 코드 구현이다. 구현자는 1·2절(확정)을 그대로 따르고, 3절(미정)은 플레이테스트로 채운다.

**정체성:** 첫 "이름 있는 위협". 변종 거대 좀비, 단일 표적 **듀얼(1:1)** 축. HP 스펀지 금지 — **패턴을 읽고 위치를 따내는** 싸움이지, 무기로 갈아버리는 싸움이 아니다. 신규 기동 카드(대시 회피/밀쳐내기)를 처음 써먹는 무대.

## 1. 확정된 전투 규칙 (그대로 따른다)

### 1.1 3단 돌진 루프 — 전투의 전부
엘리트의 행동은 이 루프 하나의 반복이다. (추가 공격 패턴 없음 — 첫 보스의 명료함.)

1. **텔레그래프**(예고·정렬) — 몸이 플레이어 쪽으로 정렬 + 돌진 궤적(빨간 라인 등) 표시. **충분히 길어서 플레이어가 맨몸 걷기로 피할 수 있어야 함**(§1.3).
2. **돌진** — 정렬해둔 방향으로 직선 고속 돌진. (조준은 텔레그래프 시점에 고정 = 옆으로 걸어 피하면 빗나감.)
3. **헛침 후 경직(반격 창)** — 벽/허공에 박고 잠시 경직. 이때가 유효타 타이밍.

### 1.2 방향성 장갑 (★ 핵심 스킬)
- **정면 피격 = 데미지 80% 감소** (20%만 박힘).
- **후방 피격 = 정상 데미지.**
- → 승리 동선 = 돌진을 피한 뒤 **등 뒤로 돌아 때린다.** HP를 깎는 싸움이 아니라 **위치를 따내는 싸움.** 이게 HP 스펀지를 회피하는 장치.

### 1.3 회피 수단 = 걷기(맨몸 사이드스텝)
- 기동 카드 없이도 텔레그래프를 보고 **걸어서 피할 수 있다.** = 빌드 편식 하드월 없음 원칙 준수(한 축만 판 플레이어도 돌파 가능).
- 대시 회피 카드가 있으면 무적 프레임으로 더 안전·반격 타이밍 확보 = "있으면 쾌적"이지 "필수 관문"이 아님.
- **대시 등 추가 회피 액션을 강제할지는 보류** — 추후 고민(사용자 명시).

### 1.4 돌진 외 추가 위협 = 잡몹 지속 스폰
- 엘리트와 싸우는 동안 **적은 수의 일반 좀비가 끊김 없이 흘러나온다.** 돌진 라인 회피 + 등 뒤 진입을 잡몹이 방해 = 공간 관리 압박.
- **★ 이것은 §7의 폐기된 "플레이어 추종 트레드밀"이 아니다.** 엘리트 권역에 한정된 **이벤트 범위의 저레이트 흐름**이며, 디제틱 출처(권역 내 문/창문/폐허 등)에서 나온다. 정면 시야 마법 팝인 금지.
- 레이트 방향성: "적더라도 끊기지 않게" (정확값 §3 미정).

### 1.5 리쉬 = 권역 밖 이탈 불가
- 엘리트는 게이트 권역을 **벗어나지 않는다.**
- 플레이어가 권역을 빠져나가면 → 엘리트는 게이트로 복귀 + **풀피 리셋**(§5.1 공통 규칙), 플레이어는 시계만 손해. "준비해서 다시 와라" 강화.

### 1.6 게이트 공통 규칙 (상위 문서에서 상속)
- **싸움 중 감염 시계는 계속 차오른다** — DPS 레이스 긴장. (싸움 중 시계 정지 = 재제안 금지.)
- **이탈 = 풀피 리셋** (위 §1.5와 동일).
- 처치 보상 = **시계 둔화 템(×0.75, 천장 +0.3)** — 다음 더 어려운 싸움의 숨통.
- 권역의 지정 엘리트 **1마리** 처치 = 돌파.

## 2. 구현 메모

- **`BossController`(기존)는 폐기 → 신규.** 현재 코드는 드라이브 시절 잔재(접촉 시 차 연료 충전)로 게이트 로직과 무관.
- 잡몹 지속 스폰은 신규 스폰 모델(`project_2026_06_03_spawn_model` / §7)의 **이벤트 1회성/범위 스폰** 갈래로 구현 — 권역 진입 시 활성, 처치/이탈 시 해제. 추종 트레드밀 재도입 금지.
- 방향성 장갑 = 피격 시 **공격자→엘리트 forward 내적**으로 정면/후방 판정.
- 코드 워크플로우: Gameplay 에이전트 구현 → Stab+Codex 병렬 리뷰 (CLAUDE.md).

## 3. 미정 — 플레이테스트로 채울 수치

맵/플레이감 의존이라 추상 선설계 금지. 슬라이스 빌드 후 손으로 튜닝.

- [ ] **텔레그래프 길이** (맨몸 걷기 회피가 가능한 최소 + 긴장 유지의 균형)
- [ ] **돌진 속도/거리**
- [ ] **경직(반격 창) 길이** (등 뒤로 돌아 몇 대 박을 수 있나)
- [ ] **정면 장갑 정확값** (추천 80% 감소 — 후방과의 체감 격차로 조정)
- [ ] **엘리트 HP / 데미지 배수** (HP 스펀지 안 되게, 1~2 사이클 실수 = 위험 수준)
- [ ] **잡몹 지속 스폰 레이트** ("적더라도 끊기지 않게" — 동시 상한 + 분당 유입)
- [ ] 돌진 쿨다운(루프 간격)
- [ ] 대시 회피 추가 액션 강제 여부 (보류 항목)

## 4. 재제안 금지 (확정 뒤집기 금지)

- HP 스펀지형 엘리트, 싸움 중 시계 정지, 빌드 편식 하드월(특정 카드 없으면 못 깸).
- 정면/후방 무관 균일 데미지(방향성 장갑 폐기).
- 잡몹을 추종 트레드밀로 보충하는 방식.
- 엘리트가 권역 밖까지 추격(리쉬 없음).
