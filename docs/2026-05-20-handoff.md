## 오늘 확정된 것들

### 핵심 메카닉 (신규)
**속도 = 공격력 = 생존력**
- 좀비를 박을수록 시체에 속도가 깎임
- 속도 저하 → 충돌 피해량 저하
- HP 게이지 없이도 직진 반복이 자연스럽게 막힘
- 두꺼운 무리에 갇히기 전에 탈출해야 하는 구조

### 아트 방향
- 세계관 톤: "희망 없는 세계" — 채도 낮고 탁한 배경
- 임팩트: Ragdoll 날아감 + 바닥 피 데칼 (신체 파편 X)
- 대비 효과: 어두운 배경 × 강렬한 임팩트 = 쾌감 증폭
- 레퍼런스 이미지: `docs/images/` 에 저장됨

### 맵
- 기본: 열린 평야 (장애물 최소)
- 폐허 잔해 산재: 뒤집힌 차, 무너진 벽 (미로 아님, 라인 변화용)

### 차량 조작감
- 돌진 시: 묵직한 충격감 + 히트스탑
- 선회 시: 자연스러운 슬라이딩으로 다음 라인 연결

### 적
- 일반 좀비: 피해 없음, 엔진 소리에 반응해 무리 형성
- 엘리트 좀비: 차량 피해 발생, 라인 변경 강제
- 충돌 판정: 좀비가 담당 (OnTriggerEnter → 차량 속도 읽기)

## 내일 다뤄야 할 것 (우선순위순)

### 1순위 — 결정 필요
- [ ] **감정적 훅**: "왜 계속 하는가" — 차량 비주얼 성장(무기·파츠 장착)이 답이 될 수 있는지 구체화
- [ ] **음향 방향**: 타격감(크런치/스플랫) vs 배경 앰비언스 비율 결정

### 2순위 — 검증 필요
- [ ] **Synty 팩 Post-processing 테스트**: 씬에 에셋 올려놓고 채도/색온도 조절해서 "희망 없는 세계" 톤 실제 구현 가능한지 확인
- [ ] **적 AI 수치화**: 소리 반응 범위, 무리 형성 트리거 조건

### 3순위 — Phase 1 프로토타입 진입 전
- [ ] **속도 감소 수치**: 좀비 1마리당 감속량, 최저 속도 임계값
- [ ] **Phase 1 구현 시작**: 차량 이동 + 충돌 판정 + 속도 기반 피해

## 다음 단계: Phase 1 프로토타입

**성공 기준 (GDD 원문):**
> 처음 보는 사람이 5분 내에 "속도 내서 박으면 공격"을 스스로 발견

**구현 범위:**
1. 차량 이동 (Rigidbody, 관성/가속/감속)
2. 좀비 스폰 + 플레이어 방향 이동
3. 충돌 판정 → 속도 체크 → 속도 감소 → 좀비 사망
4. 큐브/캡슐만 사용, 비주얼 없음

**아직 Phase 1에 포함 안 함:** XP, 업그레이드 UI, 무기, 고어 연출
