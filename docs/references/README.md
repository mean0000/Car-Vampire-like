## 각 레퍼런스가 증명하는 것

### Darkwood (Unity) — 톤·카메라의 북극성
- **탑다운 3/4 시점 + 어둠으로 시야를 가림** → "빛이 닿는 곳만 보인다"가 곧 긴장. 우리 가시성 전략(대비)과 동일.
- 빨간 포인트라이트, 검은 비네트, 거친 필름 질감 → **고사양 에셋 없이 "분위기"만으로 공포**.
- → 우리가 노리는 **스텔스 공포 무드의 직접 레퍼런스.** Unity로 만든 게임이라는 점이 핵심.

### Lethal Company (Unity) — "로우폴리도 이렇게 된다"의 결정적 증거
- **모델은 우리보다 더 단순한 로우폴리**인데, **짙은 안개 + 손전등 + 어두운 대비**로 충분히 무섭고 "프로덕션 퀄"로 읽힘.
- 손전등 콘, 거리 안개(atmospheric perspective), 어두운 실루엣 = 전부 **URP 기본 + 라이팅**으로 가능한 것들.
- → "피델리티를 안 올려도, 라이팅으로 충분하다"는 우리 결론(§6-2)의 살아있는 증거. **우리가 도달 가능한 현실적 상한선에 가까움.**

### Hell Express (언리얼) — 비주얼 임팩트의 천장(아트로 분리 차용)
- 우리가 훔칠 건 **라이팅/색 언어**지 반사실 피델리티가 아님(§6-2).
- 키아트의 색 대비, 인게임의 포인트라이트 연출만 참고.

## "Claude가 실제로 만든 것" (역량 실증)

2026-06-01 세션에서 **우리 좀비(ithappy Body_C_1) + URP 기본 기능만으로**(HTrace/COZY 임포트 0개) 라이팅 비교 테스트를 SampleScene에 임시 생성→캡처→삭제함. (이미지는 해당 세션 대화에 보존; 프로젝트엔 흔적 없음.)

- **① 납작(Flat)**: 균일 조명 + 회색 배경 = "에셋 그대로" 밋밋함.
- **② 그릿(Grit)**: 키(warm)+림(cool)+바닥 액센트 + 안개 + ACES톤매핑·블룸·비네트·필름그레인·컬러그레이딩 = **시네마틱·묵직함**.
- 결론: **같은 납작한 로우폴리가 조명+후처리만으로 완전히 다른 질감.** Lethal Company가 증명한 영역에 우리도 도달 가능.

## "URP=저퀄" 반박 — 고퀄리티 URP 게임 (2026-06-01 추가)

> Darkwood·Lethal Company는 *일부러* 저퀄(스타일). "URP가 고퀄도 되냐"의 증거는 아래. **파이프라인 확인 신뢰도를 정직하게 표기.**

| 파일 | 게임 | URP 확인 신뢰도 | 증명 |
|---|---|---|---|
| (검색 출처) | **Zenless Zone Zero** | ✅ **확정** (커스텀 URP, Unity 2023.1) | AAA급 스타일라이즈드 애니, 최상급 라이팅/포스트. 스팀 없어 이미지 X, 출처로 확인 |
| (검색 출처) | Genshin / Honkai: Star Rail / Wuthering Waves | 🟡 강함 (Unity URP기반 커스텀, HoyoToon 등 문서화) | 모바일~PC 확장형 = URP. AAA 스타일라이즈드 |
| `toweroffantasy_01/02.jpg` | **Tower of Fantasy** (Hotta Studio) | 🟡 강함 (Unity 확정, 크로스플랫=URP유력) | 풀3D 애니, 네온 블룸/실내 소프트라이팅 |
| `seaofstars_01/02.jpg` | **Sea of Stars** (Sabotage) | 🟡 추정 (Unity 확정, URP 미공식) | **탑다운 동적광원(어둠 속 빛 풀)+이미시브** = 우리 광원 언어 직결 |
| (Unity 공식) | Unity "Fantasy Kingdom" 데모 | ✅ 확정 (Unity가 URP 증명용 제작) | "cutting-edge 라이팅 + 모바일 최적화" 공식 표방 |

**핵심 결론**: **URP는 AAA급 스타일라이즈드 게임(ZZZ 확정)의 토대.** URP의 천장이 낮은 게 아니라, 한계는 **팀 규모·아트·커스텀 셰이더 물량**이지 파이프라인이 아님.
- 정직한 단서: ZZZ/Genshin/ToF는 **대형 팀 + 커스텀 셰이더**. 솔로가 그 폴리시까지는 못 감.
- **그러나 우리 목표는 그게 아님** — "무드 있는 로우폴리"는 URP가 쉽게 해냄(2026-06-01 그릿 테스트 + Sea of Stars가 증명). URP는 우리 필요엔 **오버스펙으로 충분**.
