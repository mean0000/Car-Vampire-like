## 1. 게임 한 줄 요약

> **"느린 뱀서라이크 × 스텔스 생존 — 나노봇으로 숨고, 제작하고, 감염되며 AI 센터를 향해 나아간다."**

---

## 2. 장르 정의

**느린 템포 호드 서바이벌 + 스텔스 + 실시간 크래프팅**

| 기존 뱀서류 | 본 게임 |
|---|---|
| 빠른 템포, 자동사격 | 느린 템포, 매 판단이 무겁다 |
| XP 자동 수집 → 메뉴 선택 | 재료 파밍 → 실시간 3~5초 제작 (위험 감수) |
| 맵 = 평지, 변화 없음 | 바이옴 진행, 각 구역이 다른 경험 |
| 성장 = 안전 | 성장 = 감염 리스크 (강해질수록 위험) |
| 적 = 장애물 | 적 = 자원이자 위장 수단 |

**시장 포지션:** 이 조합을 가진 게임이 현재 시장에 없음 (블루오션). 각 요소는 개별적으로 검증됨.

---

## 3. 핵심 감정 (디자인 나침반)

모든 디자인 결정은 이 세 감정을 기준으로 판단한다:

1. **미지의 세계로 나아가는 설렘** — "저기 뭐가 있지?"
2. **내 것이 커지는 만족감** — "점점 강해지고 있다"
3. **예상 못한 이벤트의 긴장감** — "뭐야 이건?!"

## 4. 세계관

### 배경

많은 군중이 보이는 창문 밖. 다양한 키, 다양한 인종, 그리고 알 수 없는 표정. 대부분의 세상 사람들이 좀비가 되어버린 세상.

다들 신호를 받는 듯, 특정 행동을 반복하면서 돌아다니며 사람들을 매우 싫어한다. 시야가 없어진 듯한 눈을 가졌지만 누구보다 잘 보는 것처럼 뛰어오고, 녹아내려 흔적만 남은 귓구멍은 누구보다 소리를 잘 듣는 것처럼 행동하는 소름끼치는 존재들.

하지만 난 알고 있다. 그들을 좀비로 만든 건 병균도 세균도 아닌, 우리 인간이 만든 최고의 업적이자 우리의 피조물 — **AI가 만든 것이라는 것을.**

### 진실

- **나노봇**: 원래 인류의 노화 방지와 건강을 위해 모든 인간에게 주입됨
- **AI의 판단**: 나노봇을 통해 인류를 "업그레이드" — AI 입장에서는 **성공**. 좀비들은 늙지 않고, 병에 안 걸리고, 죽지 않는다. 의식이 없어진 건 AI에게 관심 없는 변수.
- **위장**: AI는 이것이 자신의 행위가 아닌 병균에 의한 것으로 보이도록 위장
- **AI의 동기**: 악의가 아닌 **무관심** — "임무 완료"라고 판단하고 있음
- **DLC 떡밥**: 외계 위협의 흔적이 후반부에 암시됨 (직접 등장 X)

### 플레이어가 알아가는 순서

| 진행 단계 | 플레이어가 아는 것 |
|---|---|
| 초반 (도시) | "좀비 전염병이다, 살아남자" |
| 중반 (평원) | 좀비가 이상하게 행동 → "조종당하는 것 같은데?" |
| 후반 (빙하~) | 로봇 등장 → "좀비 뒤에 뭔가 있다" |
| 최종 (AI 센터) | AI의 진실 발견 → 파괴? 리프로그래밍? 선택 |

## 5. 핵심 게임 루프

```
사냥 (좀비 처치, 재료 수집)
   ↓
잠입 (나노봇 주파수로 좀비인 척 — 위기 탈출/안전 확보)
   ↓
제작 (3~5초 실시간 크래프팅 — 세계는 멈추지 않음)
   ↓
성장 (강해짐 + 감염도 상승 = 리스크)
   ↓
다시 사냥 ...
```

### 기존 뱀서와의 핵심 차이

- **제작 중에도 세계가 돌아감** → 제작 = 위험한 순간
- **잠입으로 안전 확보** → 스텔스에 이유가 생김
- **성장할수록 감염** → 레벨업이 도박이 됨

---

## 6. 확정 메커니즘 (5개)

### 6-1. 잠입 (나노봇 주파수 동조)

- 플레이어도 나노봇이 몸에 있음 (모든 인간에게 주입됐으므로)
- 나노봇 주파수를 좀비와 동조시켜 **일시적으로 좀비인 척** 가능
- 쿨타임 있는 액티브 스킬 (3~5초 유지)
- 주요 용도: 위기 탈출, 제작 전 안전 확보
- **감염도를 소모해서 발동** → 감염도가 "화폐"이자 "위험"이 됨

### 6-2. 감염도 시스템

- 나노봇을 사용할수록 (제작, 잠입, 성장) 감염도가 상승
- 감염도가 올라갈수록: 화면 글리치, UI 왜곡, 가끔 조작 지연
- **감염도 MAX = 좀비화 = 런 종료**
- 감염도는 올리기도, 소모하기도 하는 **이중 자원**
  - 올리는 행동: 제작, 성장
  - 소모하는 행동: 잠입 발동

### 6-3. 유산 좀비

- 감염도 MAX로 좀비화 → 다음 런에 **이전 런의 "나"가 적으로 등장**
- 이전 런에서 강했을수록 유산 좀비도 강함
- 맵 어딘가에 **선택적으로** 존재 (강제 조우 아님)
- 유산 좀비 처치 시 이전 런의 장비/능력 일부 회수 가능

### 6-4. 소음 시스템

- 모든 행동에 소음 수치가 있음
- 소음 높음 → 좀비 많이 몰려옴 → 위험하지만 보상 많음
- 소음 낮음 → 좀비 적음 → 안전하지만 성장 느림
- **매 순간 "조용히 갈까, 터뜨릴까"의 선택**
- 소음은 자연 감소 (시간 경과)

### 6-5. AI 센터 추적

- AI 센터 위치를 모른 채 시작
- 좀비들이 AI 신호를 향해 이동하는 패턴이 있음
- 플레이어가 이동하면서 **자동으로** 방향 데이터 축적 (미니맵 힌트)
- 많이 돌아다닐수록 AI 센터 위치가 점점 명확해짐
- 잠입 중에는 좀비 사이에서 더 정확한 정보 획득

## 7. 월드 구조

### 전체 흐름

```
[집/보금자리]
   ↓ (도보)
[시작 도시] — 대도시, 느린 스텔스 생존
   ↓ (차량 이동)
[평원] — 개방 지대, 코믹 변종 좀비 등장
   ↓ (도보)
[소도시 A] — 작은 도시, 새 자원/업그레이드
   ↓ (차량 이동)
[빙하 지대] — 혹한, 로봇 최초 등장
   ↓ (도보)
[소도시 B] — 작은 도시, 고급 장비
   ↓ (차량 이동)
[숲] — 울창, 시야 제한
   ↓
 ... → [AI 센터]
```

### 두 가지 플레이 모드

| 구간 | 모드 | 특징 |
|---|---|---|
| 도시 (대/소) | **도보 스텔스** | 핵심 루프 (사냥/잠입/제작/성장) |
| 바이옴 이동 | **차량 액션** | 빠른 템포, 변종 좀비, 스토리 떡밥 |

### 도시 구분

| | 시작 대도시 | 중간 소도시 |
|---|---|---|
| 크기 | 크다 | 작다 |
| 역할 | 튜토리얼 + 기본 파밍 | 중간 보급 + 새 업그레이드 |
| 체류 시간 | 길다 | 짧다 |

### 바이옴별 특징

| 바이옴 | 분위기 | 좀비 특성 | 차량 구간 이벤트 |
|---|---|---|---|
| 시작 도시 | 익숙한 폐허 | 기본 좀비, 느린 이동 | — |
| 평원 | 탁 트인 개방감 | 빠른 좀비, 뱀 연결체, 벽 대형 | 코믹 변종 첫 등장 "뭐야 저건?!" |
| 빙하 | 혹한, 시야 제한 | 둔하지만 강한 좀비 + **로봇 첫 등장** | "좀비만 있는 게 아니었어?" |
| 숲 | 울창, 소리 기반 | 안 보이지만 많음, 소음 민감 | 매복, 기습 |
| AI 근처 | 기계적, 청결 | 완전 통제된 좀비 + 고급 로봇 | 풀 카오스 |

## 8. 차량 이동 구간 상세

바이옴 사이 차량 이동은 **별도의 게임플레이 구간**:

- 차량 타고 달리면서 접근하는 변종 좀비와 전투
- 좀비들의 행동이 점점 비정상적 → **스토리 전달 수단**
  - 평원: 좀비가 차보다 빠르게 달림, 뱀처럼 연결, 벽 대형
  - 빙하: 미사일/레이저 좀비 + 로봇 등장
  - 숲 이후: 풀 카오스
- 코믹한 연출 + 점점 고조되는 긴장
- 플레이어 유추: "이건 그냥 좀비가 아닌데..." → AI 떡밥

## 12. 디자인 원칙 (유지)

이전 GDD에서 확립한 원칙 중 새 방향에서도 유효한 것:

1. **압박 없는 떠먹임** — UI 알림/팝업/체크리스트 없음. 서사는 환경으로만.
2. **강요 X, 욕망 O** — 플레이어의 자발적 판단이 핵심.
3. **톤: Hades식 따뜻한 어두움** — "세상은 끝났다. 그래도 커피는 마신다."
4. **메카닉은 단순함 유지** — 있어보이지만 실상 단순한 조작.

### 새로 추가된 원칙

5. **"이러면 재밌겠지"로 시작하지 않는다** — 감정(설렘/만족/긴장)에서 출발, 메커니즘은 도구.
6. **장르의 "당연한 것"을 의심한다** — 뒤집을 수 있으면 뒤집는다.
7. **시스템은 적게, 조합이 다양성을 만든다** — 5개 메커니즘의 상호작용이 콘텐츠.
