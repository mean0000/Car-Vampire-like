유저가 비주얼 품질을 강하게 경고("초등학생 게임처럼 안 보이게"). artist가 셰이더/렌더링 TA 관점에서 안티-조잡 처리 스택을 명세함 (2026-06-14).

**핵심 진단 프레임 — 조잡함 = 6 독립 신호의 합:**
- C1 납작(flat): 키/필 위계 없음·균일 앰비언트·그림자 없음 → 라이팅으로
- C2 빈공간(empty): 바닥/벽 광활·중경 공백 → 밀도/드레싱·안개
- C3 클래시(clash): 도시(스타일)+괴수(반리얼)+VFX 따로 놂 → 아웃라인·그레이드·색규약 통일
- C4 머드(mud): 어두운 괴수가 어두운 노면에 묻힘 → 림/이미시브 (★톤게이트가 지목한 진짜약점)
- C5 VFX빈약(cheap): 처치/타격 점유 없음 → 임팩트·점유·라이팅 연동
- C6 raw: 톤매퍼/그레이드/블룸 부재 = 에디터 뷰포트 티 → 통합 포스트

**Why:** 조잡함을 단일 결함으로 보면 라이팅으로 다 메우려다 과조명으로 망가짐. 6개로 분리해야 각 노브로 친다. ★중요: 여섯 다 못 끄면 하나만 잘해도 그게 도드라져 더 조잡 (잘 라이팅된 빈 공간 = 여전히 빈 공간). 또 과처리(과블룸·과아웃라인·과채도)=반대방향 조잡 — 모든 노브에 상한.

**How to apply:** 비주얼 품질 작업 시 6신호 체크리스트로 게이트. 50%는 C1(납작)+C6(포스트)=둘 다 셰이더 아닌 라이팅/포스트로 해결. 나머지는 C3+C4=셰이더 통일층(아웃라인·림)의 일.
